# Image Prompt Director

## Core Principle

先分析，再压缩成可生成的自然语言 prompt。

不要把导演分析稿直接当生成稿。分析可以很细，但最终提示词要保持中等密度：信息完整、镜头明确、色调集中，同时给模型留下构图和细节发挥空间。

默认输出“简单版”，这里的简单版不是一句话极简 prompt，而是 2-4 段自然语言，保留场景、人物、动作、环境、光线、构图、色调和质感。

## Default Output

用户没有特别指定时，输出无标题自然段，按这个顺序组织：

```text
第一段：画幅 + 风格 + 场景 + 镜头观察关系，必要时写明“像随手拍到的一帧”。
第二段：人物 + 动作 + 情绪 + 道具/环境细节。
第三段：光线 + 前景/背景关系 + 景深 + 画面氛围 + 适度拍摄损失。
第四段：摄影机设置 + 色调/滤镜/胶片和镜头质感。
```

允许合并为 2-3 段，但不要压成一句话。用户给出参考格式时，优先模仿用户的密度和段落感。

## Output Modes

- 默认用“简单版”：中等密度、无标题、可直接出图。
- 用户说“详细版”“结构版”“分析版”时，才使用【影片风格和氛围】【色温】【主体以及环境】【光影】【摄影/构图】等分标题。
- 用户说“极简版”“短一点”“抽卡”时，输出 1 段短 prompt，只锁定风格、主体、场景和关键观察关系。
- 用户只发参考图且没有说明需求时，先简短分析图像，再给一版默认简单版 prompt。

## Prompt Density

简单版必须保留这些生成必需信息：

- 画幅和风格，例如横版 16:9、日系电影感生活剧照、都市夜色电影感、文艺电影剧照感。
- 核心场景，例如老旧日式住宅、深夜卧室、雾气桥面、屋顶晾衣场。
- 镜头从哪里看，例如通过虚化门框向内拍摄、镜头贴近床面、从栏杆旁偏低位置斜向观察。
- 主体是谁，处在画面哪个大致区域，在做什么。
- 主体的动作和情绪，例如低头缝补、侧躺发呆、微微抬头望远、不看镜头。
- 关键环境和道具，但不要列成清单。
- 光线来源、落点和氛围。
- 摄影机设置，例如焦段倾向、光圈/景深、手持或静态、画幅比例。
- 色调、滤镜和成像质感。
- 如目标是真实拍摄感，加入少量拍摄损失：焦点略软、轻微运动模糊、局部过曝、暗部偏闷、反光杂乱、构图略不完美。

不要只写“很电影感”“很高级”“很有氛围”。把这些感受翻译成可生成的画面信息。

## Observation First

优先写“镜头如何观察主体”，而不是只写画面里有什么。

好用的观察关系包括：

- 通过虚化门框、窗帘、栏杆、衣物、玻璃向内看。
- 镜头贴近床面、桌面、墙边、车窗、走廊或栏杆。
- 从隔壁房间、门口、走廊、楼梯口、街对面、反射里观察。
- 前景大面积虚化遮挡，中景主体清晰，背景保留空间呼吸。
- 人物偏侧、边缘、被遮挡或处在留白中。

不要默认标准居中构图。少写空泛的“电影级构图”，多写具体观察位置和遮挡关系。

## Avoid Over-Locking

一条 prompt 里只锁 1-2 个强镜头条件。强条件包括低机位、仰拍、缝隙观察、强前景遮挡、人物位置、具体手势、焦段、光圈、特殊背景物件。

如果同时锁太多，画面会变死。保留“关系”和“气质”，少规定唯一答案。

更推荐写：

```text
镜头从很低的位置，在晾晒白布之间自然地看到她，前景保留大块随风晃动的白布遮挡。
```

少写：

```text
24mm 低机位仰拍，人物固定在画面右下三分之一，右手伸向最上方白衬衫，白布边缘必须透光，背景必须出现栏杆和屋顶。
```

## Camera And Lens

默认在最后一段自然加入摄影机设置。不要把参数写成独立清单，要让它服务于画面。

优先写这些：

- 焦段倾向：24mm、28mm、35mm、50mm、85mm，或“广角近距离”“中焦压缩”“长焦浅景深”。
- 光圈/景深：f/1.4、f/1.8、f/2.8、f/4，或“浅景深”“中浅景深”“深景深保留环境”。
- 拍摄状态：手持感、静态固定机位、低机位、平视、贴近桌面、隔着前景拍。
- 胶片质感：Kodak Portra、Kodak Gold、Fuji 400H、Cinestill 800T、过期胶片、35mm 胶片颗粒。
- 镜头质感：柔和高光、轻微 halation、高光溢出、低对比老镜头、边缘略虚、轻微眩光。

参数要和画面逻辑一致：

- 近景侧脸、卧室、人物情绪片段：50mm 或 85mm，f/1.8-f/2.8，浅景深，柔和高光。
- 生活场景、厨房、房间、车厢：35mm 或 40mm，f/2.8-f/4，保留人物和环境关系。
- 公路、屋顶、街头、狭窄空间：28mm 或 35mm，轻微广角，允许边缘变形和现场感。
- 真实抓拍感：焦点略软，快门损失，轻微运动模糊，不要所有细节都锐利。

不要每次都写“8K”。如果目标是电影剧照、胶片感或真实拍摄感，优先写镜头、胶片、光圈、颗粒和拍摄损失，而不是高清分辨率。

## Photographic Loss

当用户追求“更像真实拍摄”“少一点 AI 感”“参考图是真实照片”时，要主动加入适度拍摄损失。真实感不只来自皮肤纹理和材质细节，也来自摄影中的不完美。

可用的拍摄损失包括：

- 焦点略软，不要每个细节都锐利。
- 人物手部、头发、车窗边缘、背景有轻微运动模糊。
- 光线有一点失控，局部过曝或高光糊开。
- 暗部偏闷，不要所有阴影都通透干净。
- 玻璃、金属、车窗、镜面有杂乱反光。
- 姿态自然但不完美，身体可能被窗框、门框、床沿、栏杆卡住。
- 构图略微不完美，不要像广告海报一样完成度过高。
- 色彩可以有一点脏：暖色里混入绿灰、棕灰、青灰或褪色偏色。
- 画面允许旧照片压缩感、粗一点的颗粒、边缘虚化。

把这些写成自然描述，不要堆成参数清单。

推荐表达：

```text
像行驶中的车旁随手拍到的一帧，构图略微不完美，焦点略软，脸部和手部有轻微运动模糊；阳光有些失控，局部过曝，车窗和金属边缘有杂乱反光。
```

少写：

```text
超真实，高清，完美电影质感，细节清晰，光影高级。
```

## Color And Filter

复刻参考色调时，不要只写“低饱和”“胶片感”“电影感”。必须把滤镜拆成更具体的颜色关系。

写清这些内容：

- 白是什么白：纯白、奶白、米白、灰白、雾白、偏青白。
- 黑是什么黑：纯黑、抬高黑位、深青灰、棕灰、橄榄灰。
- 高光偏什么：暖白、琥珀、奶油黄、雾白、冷白。
- 阴影偏什么：青灰、蓝灰、绿灰、棕灰、紫灰。
- 对比关系：低对比、柔和对比、局部高反差、黑位抬高。
- 饱和度位置：整体低饱和，或只保留某个局部颜色的饱和度。
- 成像处理：轻微褪色、过期胶片感、柔和高光、细腻颗粒、轻微雾化、局部高光溢出。
- 真实拍摄感：旧照片压缩感、颗粒稍粗、边缘略虚、色彩轻微发脏。

把色调/滤镜集中放在最后一段，稳定性通常更好。色调段要比普通形容词更具体。

## Reference Image Workflow

看到参考图时，先在心里拆成六层：

1. 影像体系和情绪：青春、生活、悬疑、文艺、都市、复古、亲密、孤独等。
2. 构图关系：谁清晰，谁虚焦，镜头从哪里看，前景如何遮挡，空间如何压缩或留白。
3. 光线关系：光从哪里来，落在哪里，哪些区域被压暗，是否有实景灯、窗光、天光、反射光。
4. 摄影机设置：焦段、光圈/景深、手持或静态、胶片和镜头质感。
5. 拍摄损失：哪里略糊，哪里过曝，哪里反光杂乱，姿态和构图是否有真实的不完美。
6. 色调滤镜：白、黑、高光、阴影、对比、饱和度、颗粒和雾化。

输出时不要把这六层做成标题，压进 2-4 段自然语言。

## Negative Constraints

除非用户要求，否则不要机械堆负面提示词。只在最后用短句加入最关键约束，例如：

```text
不要商业摆拍，不要过度磨皮，不要高饱和，不要 HDR，不要动漫感，不要明显 AI 感。
```

负面词服务于本次画面，不要每次固定一长串。

## Detailed Mode

只有用户明确要求详细版、分析版、结构版时，才使用以下标题：

```text
【影片风格和氛围】
【色温】
【主体以及环境】
【光影】
【摄影/构图】
【画面细节与真实感】
【生成约束/负面提示词】
```

详细版用于解释和推导，不要默认作为最终出图稿。给出详细版时，最好再补一版“可直接出图的简单版”。

## Final Check

输出前快速检查：

- 是否像一段导演描述，而不是参数清单。
- 是否写清镜头从哪里看。
- 是否保留主体、动作、环境、光线、色调。
- 是否自然加入了合适的焦段、光圈/景深、胶片或镜头质感。
- 是否把色调集中写清，而不是只写“胶片感”。
- 若目标是真实拍摄感，是否加入了适度拍摄损失。
- 是否避免把构图、手势、物件位置全部锁死。
- 是否符合用户要求的密度；用户要简单版时，不使用大量标题结构。
