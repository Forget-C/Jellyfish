---
title: "功能总览"
---

| 模块 | 当前职责 |
| --- | --- |
| 项目与章节 | 原文、风格、资产、场次划分及划分历史 |
| 场次四画布 | 导演设计、单元准备、指令检查与剪辑导出 |
| 资产管理 | 稳定设定、分类字段、图片生成与候选采用 |
| 生成画布 | 独立组织内容、模型输入及明确执行范围 |
| 模型与实验室 | 管理供应商模型，独立验证文本、图片与视频输入输出 |
| 任务中心 | 通用状态、进度、取消与原业务记录回跳 |
| 审片与交付 | Take 实际覆盖、可用区间、人工采用、固定章节交付与整场视频导出 |

设计意图、任务成功、素材可用和剪辑采用分别表达。模型能力以实际校验为准，不把可保存的设计当作已验证的生成效果。声音制作与多轨后期不由整场视频导出能力推定。

参见[工作流](/product/workflow/)与[当前架构](/docs/architecture/)。
