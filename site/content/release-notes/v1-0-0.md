本文记录 `main` 从 `a9678194` 到 `747b7a45` 的主要产品变化。

## Added

- 新增场次制作工作台，支持从章节原文划分场次、恢复划分历史、选用参考素材并生成分镜。
- 新增独立生成画布，支持组合文本、媒体和模型卡，执行单卡预检、查看运行历史并另存结果。
- 完善文本、图片和视频实验室，支持提示词模板、参考素材、会话历史和任务结果回看。
- 改进首页与项目概览，支持切换章节、继续制作和按类别浏览项目资源缩略图。
- 完善资产、模型和供应商管理，支持向项目导入独立资产、设置分类默认模型和发起真实测试调用。

## Changed

- 统一场次画布和自由画布的编辑与执行基础。
- 统一任务状态、输入快照和结果历史，改用从 MySQL 领取任务的独立 Worker。
- 统一创建、编辑抽屉和未保存退出保护，扩展中英文界面覆盖。
- 更新 OpenAPI 和前端客户端，新增后端测试及前端检查工作流。
- 缩减 Docker 构建上下文，排除本机依赖和前端测试产物。
- 更新官网与使用文档，加入从章节原文到候选画面的完整示例。

## Breaking Changes

- 从旧版切换需使用空 MySQL 库，旧环境的业务数据和供应商配置不会自动迁移。[数据库升级与回退](https://github.com/Forget-C/Jellyfish/blob/747b7a45e04a38c704ae8499515d9486ea291adc/docs/development/guides/database-upgrade.md)
- 旧场次版本 API 和四画布入口已退役。旧版审片、时间线剪辑和整场导出尚未接入新画布。
- Compose 移除 Redis 和 Celery，改由 Alembic 迁移和系统初始化完成后启动 API 与独立 Worker。
