| 想完成的事 | 从哪里开始 | 可以看到什么 |
| --- | --- | --- |
| 快速试写一个镜头，或测试图片、视频模型 | [生成实验室]({{< relref "generation-labs" >}}) | 一个可返回查看的会话，保留输入和输出 |
| 用同一张参考图尝试多组输入 | [独立生成画布]({{< relref "generation-canvas" >}}) | 模型卡的实际输入、运行历史和可选用的产物 |
| 了解生成等在哪里，或找回运行结果 | [任务中心]({{< relref "task-center" >}}) | 任务状态及可返回的业务记录 |

前两种试验都可以在创建短剧项目前使用。要让镜头对应章节原文，请从[项目与场次创作]({{< relref "/docs/guide" >}})进入。
