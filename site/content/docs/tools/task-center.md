## 查看进度和历史

在应用顶部点击「任务」，打开任务中心。使用「当前页」「运行中」或「最近结束」查看相关任务，也可按任务类型筛选。要找较早的记录，点击「历史」，再用状态、类型、项目或日期筛选。

| 状态 | 如何处理 |
| --- | --- |
| 排队中 | 等待系统开始处理。若持续没有进展，请确认部署的任务服务正在运行。 |
| 运行中 | 系统可能正在生成、等待供应商或保存结果。以本地任务最终状态为准。 |
| 取消中 | 系统已收到取消请求，等待任务结束。 |
| 已完成 | 点击「查看」回到来源页面查看成果。场次拍摄生成的 Take 仍需在剪辑中选择采用。 |
| 失败或已取消 | 查看来源页面中的结果或错误。需要再次生成时，从业务入口重新提交。 |

历史中能找到原任务，即使来源已删除。来源可打开时才显示「查看」。分镜任务的「查看」打开工作台管理中对应的任务详情，可从详情进入原画布。旧版场次任务仍回到原业务记录。关闭页面后可以回来继续查看，后台生成会按原任务运行。

## 取消活动任务

在排队或运行任务上点击「取消」。排队任务立即取消，运行中的任务会先显示「取消中」。供应商可能仍在执行已发出的请求，停止及计费情况以供应商记录为准。

## 重新提交与查看成果

从原业务页面查看失败原因并修正输入或配置，再发起一次生成。新提交会创建另一条记录，原来的任务仍在历史中。新任务使用提交时有效的供应商配置，已排队的图片和视频任务继续使用受理时的配置。

生成后的图片、视频或文本在对应业务页查看。若版本已变化而结果未写入当前内容，可从该业务的候选或历史入口查阅已经保存的成果。
