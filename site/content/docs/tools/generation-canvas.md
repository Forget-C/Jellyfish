生成画布独立于项目，适合组织素材、试写提示词和尝试生成。它与场次工作台分开，使用前无需创建章节或场次。需要按场次准备分镜并生成候选画面时，请阅读[制作分镜与查看结果](/docs/guide/sequence-workflow/)。

## 打开画布并准备输入

1. 打开一级菜单「画布」，在卡片列表中新建或打开画布。新建会直接进入编辑器，列表和编辑器均可修改名称。
2. 从左侧「基础卡」添加文字或媒体内容，从「模型生成」添加文本、图片或视频模型卡。图片内容卡支持上传和从素材选择。需要配置供应商或模型时，请先阅读[配置生成模型](/docs/guide/model-setup/)。
3. 拖动卡片连接点建立连接，也可从卡片菜单使用「连接到…」。打开接收的模型卡，在关联区查看候选，通过正文引用或用途控件明确使用需要的来源。只有符合直接采用规则的唯一用途连接会立即采用，例如普通文本连到模型的文本输入。连接或预览素材后，可以在预检中核实实际使用项。
4. 选定模型，填写正文与所需参数。视频参考的首帧、尾帧、关键帧或主体用途取决于所选模型，按编辑区显示的支持范围配置。画布顶部显示保存状态。

### 试做一张站台静帧

新建「雾海来信 · 站台静帧试验」，放入文本内容卡和图片模型卡。文字卡填写“海雾漫上站台，最后一班列车已经离开。林夏站在暖色站灯下，打开旧信封。”将文本输出连到图片模型卡的文本输入。

[![独立画布上的文本内容卡连接到图片模型卡，右侧显示试验输出](../../../images/docs/canvas/graph.webp)](../../../images/docs/canvas/graph.webp)

打开图片模型卡，补充正文“中景，保留手指和信封的动作。蓝灰海雾，暖色站灯。”如果文本来源显示为「候选」，在卡片详情的关联列表点「采用 @文本1」。截图为这次本地试验完成后的画布。

## 预检并执行一张模型卡

点击模型卡编辑区的「预检运行」，核对实际输入、参考用途、模型和参数。出现阻止运行的问题时，可用「定位问题」返回相关卡片或输入位置，修正后重新预检。

[![运行预检同时展示站台原文、镜头要求和实际采用的文本来源](../../../images/docs/canvas/precheck.webp)](../../../images/docs/canvas/precheck.webp)

本例应同时出现站台文字和镜头要求，并列出 @文本1 的实际用途。若只有镜头要求，返回核对来源的采用状态。

通过预检后点击「确认执行」。本次执行只运行当前模型卡，引用的来源需要已有可用内容。上游内容变化或已有结果失效时，先到来源卡更新结果，再回到接收卡重新预检。关闭编辑区或刷新页面后，可以从「运行历史」查看已受理任务；看到「运行请求结果待核实」时，使用「核实运行请求」取回原请求状态。

## 查看、选用与保留成果

- 模型卡展示当前正式成果。多张图片可逐项预览，预览位置只影响当前展示。下游采用哪张图由实际连接和输入选择决定。
- 打开模型卡的「显示结果卡」可查看各个正式结果，并连接具体结果作为下游候选。
- 需要保留某次结果时，在「运行历史」中找到对应产物，使用「另存为文本／图片／视频内容卡」。新内容卡固定所选成果，可独立使用。
- 运行失败或取消时，从历史查看状态、错误和已保留的未完成成果。旧正式结果仍可查看，是否可继续用于生成以当前预检为准。运行中的任务可从历史请求取消，最终结果以任务状态为准。

[![运行历史显示灯下读信的完整成果与另存为图片内容卡的入口](../../../images/docs/canvas/success-result.webp)](../../../images/docs/canvas/success-result.webp)

在「运行历史」展开所选运行，找到标为「完整成果」的图片。如从任务列表离开了画布，可[从任务中心找回这次输出]({{< relref "task-center" >}}#查看进度和历史)。

## 文件与画布管理

上传及生成的媒体直接进入「文件管理」，可在其他画布中继续选用。文本保存在画布和运行历史中，不会自动生成文本文件。删除画布会清理其专属运行记录，媒体文件继续保留；仍被画布当前内容或历史引用的文件不能删除。画布有运行中任务时，需要等待任务结束后再删除。

<span id="按需使用检查卡"></span>自由画布保留「基础卡」「参考卡」「模型生成」三类。设计与检查六类卡片属于分镜画布，需从项目的场次工作台使用；两类画布通过文件管理复用媒体，不提供整图转换或跨画布动态引用。

技术契约见[生成画布架构与执行边界](https://github.com/Forget-C/Jellyfish/blob/main/docs/development/architecture/generation-canvas.md)，已确认设计范围见[首版检查项目录](https://github.com/Forget-C/Jellyfish/blob/main/docs/development/design/generation-canvas-check-catalog.md)。

## 从 MCP 客户端连接画布

在 Jellyfish 的「系统设置 → 画布 MCP」中点击「开启 MCP 连接」。在客户端选择 Streamable HTTP，填入显示的服务地址，并将临时凭据配置为 Bearer 令牌。连接后，客户端可以发现具名工具，用列表返回的画布引用读取、编辑和运行自由画布或场次分镜画布。还可以从客户端查询生成输入和运行结果、执行画布检查，以及提取和采用场次分镜。

凭据有效期为八小时，期间可用于断线重连。关闭连接、开启新的连接或重启后端会使原凭据失效。已受理的画布任务由任务中心继续跟踪。刷新页面后仍可关闭连接，若需要重新取得凭据，可关闭后再开启。

自托管时，画布 MCP 沿用现有单用户部署的访问边界。连接由单个 API 进程维护。向其他网络开放 `/mcp` 时，用反向代理或防火墙将连接管理接口限制在 Jellyfish 设置入口所在的可信网络。将前端来源加入后端的 `CORS_ORIGINS`，并让 MCP 客户端能够访问设置中显示的后端地址。
