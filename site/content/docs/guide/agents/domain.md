# Domain docs

本项目采用单上下文布局，前后端共享同一套领域术语。

## 位置与读取时机

- **术语表**：根目录 `GLOSSARY.md`。涉及领域概念时读取，并在票据、测试、命名和讨论中使用已定义的术语。
- **ADR**：`site/content/docs/architecture/adr/`，使用 `0001-<slug>.md` 等顺序编号。涉及架构决策时，只读取当前任务相关的记录。
- 项目现有领域语义、架构事实和文档归属继续遵循根目录 `AGENTS.md` 及其指向的相关文档。

术语表和 ADR 尚不存在时，直接继续工作；在术语或决策实际确定时再按需创建。

## 内容边界

- `GLOSSARY.md` 只记录领域概念及其关系；实现细节和需求规格放在相应文档中。
- ADR 只记录难以逆转、需要上下文解释且经过实际取舍的架构决定；本项目以这里配置的 ADR 目录覆盖技能默认的 `docs/adr/`。
- 现有 ADR 与本次方案有冲突时，明确指出冲突及重新讨论的理由。
