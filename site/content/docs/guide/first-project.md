## 建立短剧项目

打开顶部「项目」，点击「新建项目」。用下面的演示资料填写「新建短剧项目」，生成默认设置可以先保留当前值。点击「创建并进入」后，会打开新项目。

| 字段 | 可直接使用的示例 |
| --- | --- |
| 项目名称 | 雾海来信 |
| 项目简介（选填） | 末班车离开后，林夏在海边站台捡到一封旧信。她认得信上的字迹，却没有马上拆开它。 |

[![新建项目抽屉中已填写雾海来信的名称与简介](../../../images/docs/chapter/project.webp)](../../../images/docs/chapter/project.webp)

在右上角选择「创建并进入」。成功后打开这个项目，可以从项目内进入章节。

## 保存第一章

进入项目的「章节」，点击「新建章节」。标题填写「第一集 · 末班车之后」，将以下两段复制到原文。这个虚构短剧也用于官网的真实界面截图。

> 海雾漫上站台，最后一班列车已经离开。林夏拢紧深蓝色大衣，沿着湿漉漉的海边站台走向长椅。她发现一只旧信封，封口留着一枚褪色的邮戳。她拿起信，在灯下认出熟悉的字迹。
>
> 天快亮时，林夏走到堤岸。她把信放进口袋，望着远处逐渐清晰的灯塔。

[![新建章节编辑器中的第一集标题与两段原文](../../../images/docs/chapter/chapter.webp)](../../../images/docs/chapter/chapter.webp)

填写原文后点击「创建并继续」，工作台会直接打开本章的划分编辑器。可以从左侧章节名前的返回按钮回到列表，核对标题与原文预览。点击章节名称可重新编辑原文。

[![保存后的章节列表行显示第一集、原文预览和划分入口](../../../images/docs/chapter/saved.webp)](../../../images/docs/chapter/saved.webp)

此时还没有保存过划分，列表显示 0 场。这个练习的项目创建和手动划分都可以在配置模型前完成。

## 接下来会得到什么

[从原文划分场次]({{< relref "chapter-and-scene-versions" >}}#从原文划分场次)，把第一段命名为「海边站台」，第二段命名为「堤岸晨光」。保存划分后，两场戏可以各自准备对象参考和分镜。
