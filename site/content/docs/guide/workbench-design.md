# 工作台前端设计标准

适用于场次四画布及其工具栏、弹窗和任务抽屉。全站浅色页面保持自身主题。新增或修改这些区域时，先使用现有共享组件；确需例外时，在变更说明中写明原因、影响范围及验证方式。

## 开发顺序

1. 确定当前操作区域的主动作、次动作与状态。生成、应用、保存等业务含义由调用方决定。
2. 从下表选择已有组件；重复业务流程不因布局相似就合并。调整公共颜色或尺寸时修改 `ui/WorkbenchTheme.tsx`，用示例页检查全部状态。
3. 在真实页面接入，保留原有禁用条件、焦点、未保存输入和任务生命周期。
4. 执行本页的验证命令，检查桌面与窄屏截图。完成标准是状态、布局、交互与主题隔离均符合要求，而非仅颜色相近。

## 共享组件入口

目录：`front/src/pages/aiStudio/directing/`。

| 组件 | 用途与边界 |
| --- | --- |
| `ui/WorkbenchTheme` | 局部 AntD 暗色主题与语义 CSS 变量；主题同时覆盖 portal 弹窗及任务抽屉 |
| `ui/WorkbenchButton` | `primary`、`secondary`、`quiet`、`danger` 四种动作；透传 loading、disabled、事件及可访问属性 |
| `ui/WorkbenchIconButton` | 通用纯图标操作；必须提供 `label`，统一 tooltip、可访问名称与点击尺寸 |
| `ui/WorkbenchDetails` | 单个非事务性悬浮详情目标；常规／展开尺寸、窄屏焦点约束与关闭恢复，字段和保存由业务层负责 |
| `ui/WorkbenchModal` | 明确选择、预览、提交与一致性保护的操作容器；正文滚动、固定操作区，关闭保护由业务层提供 |
| `ui/WorkbenchDialogActions` | 左侧次动作、右侧当前主动作；正文滚动不带走操作区 |
| `CanvasTextPreview` | 单份正文按真实溢出折叠，默认六行，可指定四行；短文无切换入口，宽度变化重新测量 |
| `CanvasToolbarMenu` | 菜单持续挂载、Escape 收起与焦点恢复；菜单关闭不终止任务 |
| `WorkbenchChrome` | 顶部身份／版本／保存／画布切换／主操作、当前位置与导航；各画布保留适用的中央工作区 |
| `CanvasBrowse` | 顶部前进／后退、独立面包屑、可收起筛选及对应操作／提示宿主；不承载业务选择状态 |
| `GraphCanvas` / `GraphSubgraphPreview` | 服务端 graph 的通用容器和聚合预览，布局状态使用 `useGraphLayout`，浏览历史使用 `useGraphBrowse`；接入方式见[共享 graph 指南](/docs/guide/canvas-graph/) |
| `components/canvas/Canvas` | 通用视口、几何、标题拖动、卡片鼠标／键盘激活及事件隔离；导演布局、分组和关系留在业务适配 |

使用 AntD 已有表单、选择、提示与语义标签，不重复实现基础控件。任务中心仅在工作台实例采用共享按钮，全站实例保持原主题。AI 设计的生成／检查／应用阶段属于业务组件，不放入通用弹窗。

```tsx
<WorkbenchTheme>
  <WorkbenchModal title="AI 设计" open={open} onCancel={close}
    footer={<WorkbenchDialogActions
      secondary={<WorkbenchButton variant="quiet" onClick={close}>暂不应用</WorkbenchButton>}>
      <WorkbenchButton variant="primary" disabled={!canApply} loading={busy} onClick={apply}>
        应用到当前版本
      </WorkbenchButton>
    </WorkbenchDialogActions>}>
    <CanvasTextPreview text={sourceText} label="原文" lines={4} />
  </WorkbenchModal>
</WorkbenchTheme>
```

实际工作台根部已提供主题，业务组件直接复用即可。`WorkbenchModal` 不自带确认／取消业务逻辑，调用方明确提供 footer。

## 动作与状态

| 语义 | 表达 | 使用规则 |
| --- | --- | --- |
| 主动作 | 较亮灰底、亮文字、清晰边框 | 同一操作区域突出一个当前动作；弹窗放底部右侧 |
| 次动作 | 深灰底、细边框 | 如发起新设计、查看记录；不能表现成不可点击的说明 |
| 低强调 | 无底色或边框，悬停反馈 | 如取消、收起；不会取代主动作的位置 |
| 危险 | 保留红色语义 | 删除等不可轻易恢复的动作；通用灰阶规则不得覆盖 |
| 选中 | 中性灰底，`aria-pressed` 或控件自身选择状态 | 选择不是提交，不用主动作颜色冒充选中 |
| 禁用 | 暗底灰字，原生 disabled | 原因在附近可读区域解释；不只用颜色表达限制 |
| 加载 | 保持尺寸，阻止重复提交 | 图标不改变按钮可访问名称；后台轮询不插入额外加载行 |
| 焦点 | 清晰细蓝描边 | 键盘操作必须可辨，不能因“更简洁”而移除 |

蓝色用于链接、键盘焦点；成功、警告、错误保留业务语义色。旧区域尚存的蓝色主按钮是迁移项，不是新增代码的选项。

常规控件高 32px；显著入口可使用 38px；窄屏固定操作区至少 36px。常规图标 16px，入口强调图标可为 20px。间距使用 4／8／12／16／24px 的有限等级，避免每个按钮单独微调。共享动作的颜色和高度由 tokens 与公共 CSS 决定，业务 CSS 负责位置与布局。

## 文本、图标与内容层级

- 区块按“标题 → 内容 → 辅助信息”组织。正文清楚可读，辅助文字较弱；不要把正文降到占位文字的对比度。
- 用明确动词命名操作，入口、弹窗标题与主动作保持同一业务上下文。
- 原文、用户要求、模型结果与系统状态分区。未填写用所属标题旁的空态标签，不拼接到上一段正文末尾。
- 图标优先搭配短标签。刷新、关闭、撤销等熟悉操作可仅用图标，但必须有可读名称和提示。
- 装饰图标使用 `aria-hidden`；生成、应用、失败原因等关键语义保留文字。
- 长正文用 `CanvasTextPreview` 原位展开，不能同时显示摘要和全文。历史与固定依据可以按需展开。
- 对象摘要卡单击或键盘 Enter／Space 打开详情；子图入口进入对应范围；引用卡标明只读身份并定位原对象。删除与整卡激活重复的“编辑此卡”；卡片独立动作横排优先、空间不足换行。按钮、菜单和标题拖动独立，拖动不打开详情。卡面按类型使用有限尺寸与最多两行字段摘要，不在卡内滚动全文；触摸和键盘都能访问菜单。
- 导演总览继续按全场、跨镜共享、镜头入口和可收起的未关联设计组织。浅灰无箭头结构线不进入业务关系检查；镜头入口保留真实布局预览与计数。导航和明确定位可以移动视口，详情开合与展开不改变视口或布局缓存。
- 单元配置分别从各卡片详情编辑，不设置整份单元总设置入口；种子及额外参数在生成配置详情直接编辑。当前单元准备结论位于顶部状态入口，问题清单仅解释、重试和定位，生成指令使用独立操作。参数沿用直接编辑；前段承接先比较原首帧与拟用落幅，明确应用后一次替换唯一依赖和首帧，取消不修改；指令依据、素材固定依据与历史审片只读查看。单元首帧、尾帧分别使用固定输入位置卡，普通参考按显式组显示；空添加卡不产生输入关系。参考卡使用 360×480 的有限尺寸，为缩略图、对象／用途／来源和问题状态留出空间；激活后只管理当前帧位置或参考组，明确应用后一次更新并可撤销，取消不改原绑定。只读场景可阅读但不能应用。主指令编辑器、素材库、主播放器、内联素材／接缝审查与时间线保持业务工作区，不套用紧凑卡片尺寸或新增提交弹窗。
- 多个真实使用点共享相同语义时才抽组件。标题区目前按上述排版模式实现，不创建万能卡片或表单配置系统。

## 详情与操作边界

桌面详情在右上方四周留边，无遮罩、不侧滑、不挤压画布；常规／展开两档复用同一内容。新对象替换当前目标，重复选择与点击画布空白不关闭。关闭图标或 Escape 退出，内层选择器／菜单先消费 Escape。窄屏使用近全屏的同一内容，标题、保存／只读状态与关闭入口固定可达，焦点限制在覆盖区域。生成画布三类模型、四类命名参考及四类描述编辑卡在桌面按已确认 A 方案例外移除卡名标题栏与关闭按钮，仅保留右上展开／收起；小于 1280px 时自动模态，统一改为右上一步“关闭详情”，热区至少 44×44px，并为顶部字段留出空间。Escape 先消费内部菜单或候选管理，再按桌面收起／退出或窄屏直接退出。参考卡参数位于顶部，底部仅保留状态，不提供生成动作。描述卡复用相同编辑基础，名称在顶部、正文居中、底部仅字数／只读状态；卡面保留原有默认尺寸与缓存尺寸。其他基础内容与导演详情沿用本节通用规则；验收覆盖三区布局、内层 Escape、草稿保留、OS 发送快捷键及桌面／窄屏固定操作可达。入口已消失时回退到有效的工作台控件。

设计字段、资产关联、附加信息、关系、来源版本、任务固定记录、历史审片及导出记录使用详情。关系总览进入只读对象时在当前容器内阅读并返回，不叠加大型窗口。固定来源、记录与媒体区间按原身份解析，不用当前内容重解释历史。

参考选择、原文依据比较更新、时间线整理预览、AI 设计准备／比较／应用、批量预检提交、导出配置提交使用独立操作。AI 设计记录、拍摄任务记录与导出记录提供独立的非模态阅读入口，后台任务不由容器可见性决定。保存冲突、离开、所有权、恢复、复制及未知结果保护继续由原业务逻辑负责，危险删除仍明确确认。

操作弹窗覆盖时，底层详情保持挂载与输入但暂停交互。操作内核对来源、历史依据或参考图时，在同一弹窗内只读进入与返回，保留选择和输入；不打开第二个大型窗口、不激活底层详情、不复制完整编辑器。任务中心及其历史维持原容器；其排除范围不作为新业务详情的实现范例。

## 布局与刷新稳定性

- 四画布的前进／后退位于顶部状态栏，只恢复当前画布、当前版本的浏览位置和视角。面包屑紧贴状态栏下方靠左覆盖在节点与连线上，不计入画布视口高度；长路径可横向滚动。菜单、详情与弹窗位于其上。错误与核实提示单独预留空间。
- 面包屑下方的筛选条与面包屑左对齐、留边悬浮并横向展开，只放真实筛选／选择条件，无独立标题行，右端收起；窄屏条件可换行。默认展开，浏览器按画布类型记住收起状态；收起后保留同样留边的搜索图标按钮，点击展开筛选，不新增搜索框，筛选生效时以可访问圆点提示，不清空选择，不进入导航历史，不改变画布视角或节点布局。没有条件时不显示空面板。刷新、附加信息和编辑视图切换放顶部对应操作区。
- 非阻断画布状态位于右下撤销／重做左侧，窄屏移到其上方靠右，小地图避让；不占用画布视口。待归镜头与未关联设计计数只在导演总览显示，零值隐藏，不提供额外操作；图待同步等状态按当前画布显示。单元准备结论继续位于顶部，错误与失效目标保留明确恢复入口。
- 镜头／单元选择即导航，与面包屑及业务操作对象同步。导演镜头进入单元画布时只继承该镜头的概览；单元概览不保留隐藏单元的准备状态或生成操作，进入指令画布须明确选择单元。具体单元与指令画布之间保留该单元。

- 操作弹窗整体高度受视口约束，标题与动作保留在可见范围；窄屏动作允许换行且至少 36px。主要纵向滚动由弹窗正文承担，底部动作固定；暗灰细滚动条、透明轨道，正文使用 `scrollbar-gutter: stable`。
- 长内容和窄屏不能产生页面横向溢出。差异内容仅保留必要的横向滚动。
- 首载可显示加载占位；后台刷新保留当前内容、展开状态与滚动位置。错误提示使用稳定状态区域，不清空已有结果。
- 详情展开不重建编辑器；关闭、对象切换和重开沿用当前版本的输入保留策略。字段编辑继续自动／手动保存，不新增普通编辑的确认／取消事务。
- 打开工作台浮层默认不自动平移、缩放或重排画布。生成画布常规编辑器为明确例外：固定在卡片下方，打开、切换、收回展开态及桌面窗口缩小时，允许约150ms的最小视口平移；用户输入可打断，减少动态效果时直接定位。关闭或窗口放大不恢复视口，输入和内容更新不反复让位。编辑器字号与尺寸保持稳定，空间不足优先编辑区可操作，卡片可部分出屏；不更改卡片坐标、不重排其他对象。手机、复杂导演和主动展开继续模态。关闭菜单／浮层不丢失未保存内容。

## 可重复验证

开发环境访问 `/dev/workbench-ui`：真实组件的默认、选中、危险、禁用、加载、焦点、长文及弹窗状态。此路由仅开发模式提供，不请求业务数据或执行付费任务。

在项目根目录执行（项目 Node 版本见 `front/.node-version`；安装本机 Chrome、后端测试依赖及 ffmpeg/ffprobe）：

```sh
pnpm --dir front run typecheck
PLAYWRIGHT_CHANNEL=chrome pnpm --dir front run test:workbench-ui
```

若使用 Playwright 已安装的自带浏览器，可省略 `PLAYWRIGHT_CHANNEL`。命令先预检依赖、本机监听及浏览器启动能力，再依次执行组件示例、四画布样式和设计完整性回归，输出临时截图目录。设计完整性可用 `pnpm --dir front run test:design-scope` 单独运行。相关 PR 与 merge queue 由 Frontend checks 工作流执行相同检查。

验收清单：

- 主次动作有区别，普通选择不冒充主动作，危险色与禁用态保留。
- Tab 焦点可见，纯图标可命名，菜单 Escape 与弹窗关闭正常。
- 1440px 与 390px 下按钮不重叠、不越界，长文展开仍只有一份正文。
- 门户弹窗／抽屉继承局部标准，全站浅色任务中心不受影响。
- 轮询、草稿和画布视角使用已有业务回归；业务状态变化时补相关测试，不能用组件截图代替业务验证。

例外应记录：为何现有组件无法表达、例外作用域、替代方案和对应检查。不通过提高选择器优先级或增加散落的硬编码颜色绕过标准。

单元画布的只读投影核实中或失败时，临时配置卡使用当前草稿原字段及共享卡片样式，摘要仍限制为两行；明确的详情按钮暂代整卡激活，以区分本地配置编辑与尚未核实的业务图。例外仅覆盖该临时编辑区，核实成功即恢复原图卡；通过 AI 应用后预览失败、修改、重试及保存恢复浏览器用例验证。


生成画布右键菜单使用 AntD Menu／Menu.Item／SubMenu 的菜单语义，作为普通 WorkbenchButton 的局部例外：菜单需要多级悬停、键盘导航和独立浮层，不能继承动作按钮的固定高度及禁用背景。颜色仍消费 WorkbenchTheme tokens。桌面独立三级浮层、窄屏逐级返回及单行禁用样式通过 `generation-canvas-context-menu` 的真实画布用例和截图验收；不改变其他工作台按钮。

生成画布参考卡与描述卡的顶部参数使用可见字段标签和固定提示位，名称优先，参考角度与图片选择随后排列；按编辑器实际宽度换行。名称错误就近关联控件，底部仅保留状态。已关联名称作为局部例外保持可读文字，并明确显示“已关联”及取消关联入口；普通只读控件保留禁用表达。长名称静态省略，悬停／聚焦可读全文，实际保存值不截断。





画面风格编辑器已采用预设优先的 A 布局：连续 Modal 表面、左预设图库与右侧选中预设详情，右上“高级设置／返回预设”替换主体。默认无预设选中；右侧空态显示当前真实摘要或选择提示。标题、底部及左右栏不增加硬分隔线，桌面只让图库滚动；展开变更明细时在右侧替换预览，超长明细局部滚动。高级设置直接显示全部风格参数及统一的状态／来源开关，不保留 Tab、更多参数或独立正反例。预览、对比和模式切换只更新会话；显式应用只合并声明字段，留在图库反馈结果，撤销复用画布历史。关闭清除未应用预览，模式切换保留浏览位置，保存失败和较早保存回包继续由画布保存机制保护输入。窄屏上下排列，内容区滚动、动作固定。六类独立设计已接入，旧摄影及五分区入口退出；候选添加与字段引用按下述公共规则使用。

机位、光影、焦点、构图与运镜高级设置共用 `VisualDesignRelations`，按各卡声明的端口选择作用／关注／焦点对象、所属镜头和验收要求；设计类来源连线不弹用途菜单，多用途在接收端选择；验收区域独立放在素材候选区下方，默认以居中小三角收起，展开后提供已关联要求缩略卡和下方只读详情；连线直接关联，解除关联同步断线，浏览与定位在只读模式仍可用；模型采用设计时自动带入关联验收要求，无需额外连线。唯一兼容用途的设计正文进入模型独立文本输入时连线即采用；正文显式引用后保护断线。其他上下文与资产关系仍须显式采用。构图保留适用范围、阶段、条件和来源，并允许选择以结构化引用片段定义的运镜画面。所有关系、范围及来源修改继续服从只读状态。

六类画面设计卡的卡面统一使用 `VisualDesignCard`，复用既有 CardShell 的选择、拖动、菜单与位置／尺寸缓存。卡面依次展示 96px 高的类型专属中性用途图解、最多两行标签摘要、超出配置数量及常驻入口；不拿首个预设图片表示当前配置，不在卡面播放视频。空态统一为“尚未填写××”与“选择预设或直接填写设计参数”，高度随有限内容自适应，不用等高留白。普通字段、结构化景别、引用文档、明确状态、范围／来源、已采用关系、画面目标及已创建阶段共同形成卡面配置摘要，同一份摘要同时决定“开始设计／编辑设计”，只读统一“查看设计”。已配置与模型可运行分别表达；空阶段显示“阶段待填写”，不适用等状态保留其原意。

画面设计 Modal 关闭时清除未应用的试选与对比，重开或页面刷新后从已保存的预设声明字段恢复对应图／视频及选中标记；预设之外的自定义参数不抹掉对应预设的用途预览，但仍显示自定义配置，不能声称全部参数与预设相同。无匹配时继续展示真实文字摘要，不自动选第一个预设。应用按钮统一为“应用”，填写／覆盖数量和明细保留在详情中。底部提示与撤销按钮在桌面及窄屏垂直居中对齐。
