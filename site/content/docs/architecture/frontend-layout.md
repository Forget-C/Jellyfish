## 应用壳

`MainLayout` 是所有路由页面的唯一应用壳。顶栏横跨页面，高 48px；左上为蓝色水母标志与单行 Jellyfish 品牌，桌面品牌区域宽 272px。顶栏右侧依次为页面上下文、任务入口和用户菜单。顶栏下方的全局导航宽 64px，设置位于底部；浏览器 `body` 不承担页面滚动。

项目、资产、提示词、文件、模型、Agent、实验室、设置及未找到页共用该外壳。小于 768px 时，全局导航通过“打开主导航”按钮进入抽屉；导航切换或 Escape 关闭抽屉。图标链接提供可读名称、选中状态和键盘焦点。

`#root`、应用壳和主内容区均建立了明确的高度链，并在可收缩的 flex 容器上设置 `min-height: 0` 与 `min-width: 0`。这使子页面能正确计算 `height: 100%`，也避免长内容或宽表格撑破父级。

## 路由内容与滚动

路由出口由 `.app-route-viewport` 承载。它是普通页面的默认滚动边界：没有自行声明滚动容器的页面仍可纵向滚动，且超宽内容不会绘制到应用壳之外。

页面无需为常规列表、表单或详情页重复设置页面级 `overflow`。页面内需要横向查看的表格、代码块或素材带，应在其自身容器上显式使用 `overflow-x: auto`。

前端通过 `src/components/layout/PageLayout.tsx` 提供公共工具栏与工作台容器：

- `PageToolbar`：白色标题与操作栏，默认最小高度 64px、水平间距 16px，窄屏允许换行。
- `WorkspaceLayout`：建立满高、可收缩的工作台根节点。
- `WorkspaceScrollPanel`：作为自然高度内容的默认垂直滚动面板；它会隐藏意外的横向溢出。

项目工作台等带固定工具栏的页面必须使用这组原语；tab 不得依赖父级的 `overflow: hidden` 来裁切自然高度内容。工作台的默认滚动面板不得使用 `overflow: auto`；需要横向浏览的表格、卡片带或代码块必须在自己的局部容器上显式使用 `overflow-x: auto`。

## 满高工作台

场次设计、单元试拍、模型管理等多栏工作台可以在根节点使用 `height: 100%`（Tailwind 的 `h-full`），并把滚动职责分配给实际需要滚动的面板。

- 工作台根节点：`height: 100%`、`min-height: 0`，通常为纵向 flex 容器。
- 可收缩的中间容器：必须保留 `min-height: 0`；横向分栏同时保留 `min-width: 0`。
- 单个可滚动面板：使用 `overflow: auto`；只应在需要裁切视觉素材或固定画布时使用 `overflow: hidden`。

全高的 Ant Design `Card` 应使用 `app-fill-card`，使 Card body 获得可分配的剩余高度；消息列表、表格等内容区再使用 `flex: 1`、`min-height: 0` 和 `overflow: auto` 成为唯一的局部滚动面板。

这样普通页面保持单一、可预期的滚动入口，而工作台仍能拥有独立的列表、画布和检查器滚动区。

## 上下文与任务

`layouts/navigation.ts` 将有效路由映射为可返回的面包屑。项目角色返回对应项目的角色页签，四类资产返回各自分类，场次返回所属章节场次列表。当前对象不生成无效链接，也不把路径 ID 当作名称。

页面通过 `usePageTitle` 发布已经加载且身份与路由匹配的标题。`useNavigationTitles` 仅补取当前页面未读取的上级项目和章节名称；请求结果核对身份及项目归属，离开路由后的迟到结果不写入上下文。加载中使用中性名称，读取失败显示名称暂不可用；长路径或窄屏将上级收进菜单，当前标题截断时仍提供完整提示。

`TaskRuntimeProvider` 位于路由出口外，在页面切换时保持同一轮询实例。任务入口位于顶栏，数量只计算排队和运行中的任务；抽屉沿用当前页、运行中、最近结束、全部及任务类型筛选，保留取消、业务回跳和独立任务历史。运行状态与内容版本历史保持不同语义。用户菜单提供个人设置与语言切换。

## 主题与页面分栏

`main.tsx` 的 Ant Design 主题与 `layouts/shell.css` 共用蓝白浅色基调：主色 `#1677ff`、底色 `#f7f9fc`、面板白色、分隔线 `#e5eaf0`，正文 14px、辅助文字 12px、常规圆角 6px、标准控件高 32px。页签使用蓝色 3px 下划线。

- 模型分类与 Agent 管理使用 `WorkspaceSidebar`，桌面筛选侧栏从全站顶栏下方开始，页签与操作区位于其右侧；默认宽 208px、可收起到 48px；小于 1024px 改为“筛选”入口和抽屉。详情在大屏为 344px 侧区，窄屏为可关闭抽屉。供应商和运行设置不保留无实际筛选内容的空侧栏。
- 实验室桌面会话侧栏宽 208px，小于 1280px 从“会话导航”打开同一会话列表。消息历史独立滚动，输入区固定在其下方。
- Agent 编辑页的参数区默认 344px；手机端上下排列并可滚动。资产编辑保留自身长表单与图片工作区。
- 场次页面使用 `SequenceLayout`：208px 业务导航、48px 阶段栏、64px 版本控制栏、344px 对象详情及32px 状态栏。导航和详情可调整宽度；小于1280px 时改为抽屉，组件与样式使用同一断点。375px 下设计的新建与 AI 操作进入“更多”，保存和确认保留在控制栏；768–1023px 的试拍与剪辑控制栏分行，主操作无需横向滚动。
- 场次设计使用虚拟镜头清单、分镜板和聚焦关系画布，共享对象选择；试拍按单元组织参考、指令、审稿及候选，剪辑按素材库、播放器、详情与时间线组织。内容区域各自滚动，任务记录与版本历史分别通过独立入口打开。
- 业务抽屉中触发的离开保护对话框显示于抽屉之上；关闭接缝抽屉不销毁未保存输入。B 阶段验收证据以[实施计划](../../plans/frontend-shell-and-sequence-workbench-plan/)为准。
