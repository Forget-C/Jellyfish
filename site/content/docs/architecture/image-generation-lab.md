# 图片生成实验室

图片生成实验室是独立于项目、资产和分镜生产流程的调试页面。它用于验证已登记图片模型、图片提示词模板及参考图片对生成结果的影响。

页面仅展示图片相关的提示词模板：首帧、尾帧、关键帧、角色、演员、道具、场景与服装图片模板。文本和音视频提示词不会出现在该选择器中。

参考图片统一使用资料库 `FileItem` 的 `file_id`：用户可在页面上传图片，或从全局资料库中多选已有图片。提交时页面将这些 ID 按选择顺序发送给后端，后端校验其为图片文件并转换为供应商所需的图片引用。

生成请求使用 `POST /api/v1/studio/image-lab/tasks`，必须携带 `session_id`。接口验证指定模型为图片模型，在同一事务中创建用户消息、`image_generation` 异步任务和任务气泡，并用 `image_lab` 关联类型隔离于资产与镜头任务。仅在提交成功后才入队。响应同时返回 `task_id` 与按会话序号排列的用户消息、任务消息，前端以这两条持久化消息直接接管本次提交，不再单独维护一套乐观消息身份。

任务结果通过通用的 `GET /api/v1/film/tasks/{task_id}/result` 轮询；Worker 会将成功、失败和取消状态及结果快照回写任务气泡。刷新后，页面从会话历史恢复提示词、参考图缩略图和生成结果；成功产物沿用现有图片任务机制归档到全局资料库。
