# 生成画布文档存储

项目工作台的“画布生成”入口无需章节或场次。一个项目可创建多张命名画布，通过独立页面 `/projects/{project_id}/generation-canvas?canvas=<id>` 重开；旧 `tab=generation&canvas=<id>` 链接保留画布、运行和节点参数后跳转，不实例化项目页及其章节加载。页面使用铺满视口的画布及悬浮顶部菜单；画布管理菜单提供新建、选择、改名和删除，保存图标及状态留在顶部，运行记录从顶部打开共享单一浮动详情。页面使用局部暗色主题、左侧二级分类图标栏与输出摘要卡。基础内容、命名参考和模型卡在卡片下方编辑，展开为居中 Modal 时保留同一编辑会话；复杂导演卡鼠标单击选中后显示右上编辑按钮，点击按钮打开居中 Modal；卡片获得键盘焦点时 Enter／Space 可直接打开，普通拖动释放不自动打开；字段沿用同一会话与自动保存，遮罩、关闭按钮或 Escape 可关闭。诊断的明确定位动作可直接进入相应编辑容器，预设操作弹窗位于编辑层之上并暂停底层编辑交互。生成画布的本地编辑宿主复用工作台单一详情选择槽，与运行历史互相替换展示并保留会话；左侧添加面板可覆盖下方编辑区，Modal 则覆盖画布工具栏。常规编辑器始终在卡片下方左对齐，保持16px屏幕间距；打开、切换目标、主动展开后收回或桌面窗口缩小时，按实际可用区域最小平移画布。编辑器优先保持原尺寸，整体过大时允许卡片上部出屏；只有编辑器自身放不下才限制宽高并内部滚动。卡片位置、比例及其他卡片布局不变，编辑器字号和控件不随画布缩放。手动浏览或拖动后不拉回，也不因卡片出屏而隐藏编辑器。卡片移动与内容编辑按操作顺序共用撤销／重做，布局整理保留独立撤销，小地图与定位仅改变浏览位置。当前支持四种基础模态内容、独立原文／创作依据、三类模型卡、候选连接、分组、独立布局以及自动保存和恢复保护。文本模型卡提供保存、预检、后台执行和持久文本流；图片模型卡沿用同一入口执行并发布完整有序图片结果。视频模型卡在同一运行入口按固定用途生成一段完整视频，保留文件自带音轨。完整设计决策见 [独立生成画布](adr/0001-independent-generation-canvas.md) 与 [协议边界](adr/0002-generation-canvas-protocol-boundaries.md)。

左侧添加入口按基础卡、参考卡、模型生成、画面设计、表演与调度、叙事与镜头、声音设计、连续性与约束八组展开二级目录；这只是导航分组，业务分类仍为基础内容、模型生成和导演工具箱。点击在当前可见空闲处创建，拖入按释放位置创建，成功后关闭目录，普通卡激活下方编辑、复杂卡只选中并显示编辑按钮，不自动连线或采用。画面设计六个入口分别创建独立类型，编辑已有设计从该卡详情进入。运镜入口 `direction.movement` 提供专属六字段和稳定阶段；六类共用预设优先 A 编辑器，完整运镜输出包含字段、阶段及有效画面状态，旧摄影入口已退出。阶段重命名和重排不改变身份，图片多状态仍要求明确画面目标。

卡面优先展示最终输出；25 类设计卡为明确例外，由共享 `DesignCardBody` 按用户已有配置展示类型用途示意和最多两行标签摘要，统一判断开始／编辑入口，不把已配置当作模型已就绪。普通参数、引用文档、结构化景别、范围来源、已采用关系、画面目标和已创建阶段均进入展示判断，空阶段及不适用等配置如实提示。对应图标与名称位于内容区上方，辅助状态在底部。正文不内联编辑或拖选；普通状态只选中一张卡或一条线。按下不激活，移动超过容差立即拖动，无计时长按门槛；普通卡点击激活详情，拖动只移动；复杂导演卡释放只选中。拖动期间保留原编辑会话，取消恢复原布局且不切换目标。空白点击清除选择并收起编辑展示，输入与保存状态保留；连线选择清除卡片选择和旧详情。连接点、媒体和菜单独立处理事件，键盘激活及移动继续可用。下方编辑区保持屏幕控件尺寸，随卡片移动；卡片出屏暂隐、返回可见时恢复，不拉回视口。关闭与对象切换保留输入和媒体位置，隐藏媒体暂停；窄屏采用近全屏编辑，展开／关闭继续自动保存。基础图片编辑直接提供上传／从素材选择，已有图片以独立的替换／选择动作复用原文件能力；其他媒体沿用加号菜单，参考主图与名称绑定独立。

模型卡复用 `GenerationCardFrame` 的有限预览与固定底部状态。文本、图片、视频模型卡统一为 360×424，预览区为 358×358，底部状态区为 32px，标题和边框合计 34px；图片使用 `object-fit: contain` 完整适配，横图和竖图允许留边，切换结果不改变卡片尺寸。图片模型卡在悬停、选中或键盘聚焦时位于普通卡片上方，避免旧布局中的相邻卡遮挡预览。四类参考卡沿用 300×251，预览区为 185px，底部状态区为 32px。短文本、长摘要、空态、流式增量、失败保留旧成果和媒体多结果均不撑开卡片；完整内容在详情及运行历史查看。图片切换保留在预览区角落，完整图片入口位于卡片底部状态栏右侧；视频保留原生播放与音轨。标题与底部状态补偿画布缩放，正文与媒体仍按原几何缩放。采用数仍只计实际输入绑定，完整问题按原状态说明查看。

生成画布的尺寸按 100% 缩放下包含标题的外框计算。三类模型卡为 360×424，命名参考、基础文本／图片／视频／音频及同模态生成结果为 300×251，四类描述和原文依据为 400×172，25 类设计卡为 360×368。卡面、布局、连线和小地图使用相同的类型尺寸。打开旧画布、断线、复制或撤销／重做恢复卡片时采用规范尺寸；历史缓存只归一尺寸，保留坐标、视口和分组，重叠由用户主动整理。尺寸归一不写入画布文档，也不产生独立撤销项。卡面摘要和预览留在固定区域，生成文本结果保留卡内全文滚动与复制，编辑区沿用自身布局。

基础文本、基础图片共享局部 C 表面和轻量标题：模态图标、既有可读名称及必要弱状态同行，正常已保存不常驻，无头部分割线；展开与收起保留同一编辑会话。基础文本正文下方左侧显示字数、右侧提供低强调导入，格式说明按需查看，只读正文仍可选取复制，不含模型参数或提交。基础图片卡面在固定区域等比完整预览，编辑区完整显示图片，旁侧按标签在上、值在下排列文件信息，并提供独立替换／选择动作；空态为全宽上传与选择区域。文件名、类型与来源读取现有文件接口，尺寸使用实际图片加载结果；未知信息不填示例值，上传与替换失败仍保留原文件。 基础图片编辑的预览区按普通、展开与窄屏模式设置固定高度，并受视口约束；横图、竖图与超宽图均在该区域内 contain 缩放，原图尺寸不参与网格轨道或编辑区高度计算。参考卡卡面与编辑区使用相同的完整缩放约束，避免固有尺寸撑开预览区。首次重开以固定预览及文件信息测量，让位沿用常规编辑器的统一规则。三类模型卡统一复用 `CardComposer` 的 A 紧凑排版：关联区、输入区、参数状态区自上而下排列；桌面无卡名标题栏和关闭按钮，仅右上保留展开／收起，Escape 先关闭内部菜单或候选面板，再收起或退出编辑。绿色对号仅表示已存在实际输入绑定，未采用候选也显示为正方形关联窗口；缺失和依据改变分别保留警告，不能把绿色对号当作输入有效性结论。关联区末尾加号提供上传参考素材、从素材库添加、从当前画布选择，素材库只开放模型已接入的媒体用途；添加只建候选，不自动采用。窗口点击及底部状态入口打开既有引用、用途、摄影范围、顺序和运行结果管理。参数在左、状态在右，中间以“|”分隔；关联数与实际采用数分别显示，模型参数区可横向滚动，“显示结果卡”开关固定在其后。窄屏参数与状态可折行，开关和提交入口仍可直接操作。三类均自动选择已配置且类别匹配的系统默认模型；已有模型、参数与不支持配置保留，不随默认设置切换。图片画幅、分辨率及视频时长的空配置显式选中“默认”，沿用服务端默认语义；视频未填画幅时从已核实选项优先选择 16:9，否则选择首个支持画幅并保存。文本参数仍由模型管理维护，不虚构逐卡覆盖。输入说明只在空输入框显示，普通 Enter 保存最新正文后进入单卡预检；macOS Command+Enter、Windows/Linux Ctrl+Enter 在光标或选区插入换行。组合输入确认、重复按键和引用／指令确认不会触发提交，空输入、只读、检查中及运行中沿用提交门禁。展开与收起保持同一正文、引用和输入法会话。正式结果以卡面为主并保留运行历史；图片模型多结果仅切换本地预览，不改变完整输出集合。候选面板高度受编辑正文实际区域约束，不覆盖右上展开或底部固定操作。卡底以单行小字排列运行状态、真实采用数与必要规格／字数；完整错误按需查看，不将候选计入来源数。 主动打开时按最终编辑尺寸避让顶部、左侧常驻分类栏和底部工具；展开／窄屏暂停背景工具，不以编辑框未越屏代替内容可达。

生成画布空白处可按住 Space 开始拖动视口；开始后先松开 Space 仍保持本次平移，直到鼠标释放，经过卡片不会切换操作。失焦或取消安全结束；输入、播放器、菜单和编辑容器中的 Space 保持原用途。拖动与平移只改变布局／浏览状态，不影响内容、采用或生成依据。卡片跨过拖动阈值时关闭卡片菜单；本次拖动独占方向键、Enter、Space、撤销／重做，缩放保持冻结，直到释放或中断。显式多选模式下 Enter 和不带平移的 Space 均切换焦点卡片选择，不打开编辑器。输入法组合输入期间不触发画布快捷键；Space 激活要求同一目标上的有效按下与松开，平移、Escape、失焦或焦点切换会取消待执行激活；画布内焦点切换保留持续按住 Space 的平移状态，进入输入区则取消平移就绪。卡片菜单打开时隔离画布命令；Escape 先关闭当前展开的内层选择器，再关闭卡片菜单并恢复触发按钮焦点。编辑器在原生内层控件处理后优先关闭候选面板，关闭后保留外部菜单及编辑器；焦点离开候选、展开或收起不改变该顺序。外部菜单与连线取消依次兜底处理 Escape。这些是生成画布的明确交互例外，不修改场次工作台的卡片手势。参考卡摘要仍只使用自身对象和明确绑定的直接名称，不读取描述正文。

仅左右中点各一个几何连接点，侧别与用途分离。拖线、键盘连接和从画布选择直接建立来源连接；常规或收起状态下，同一来源与接收卡只展示一条来源线。展开结果卡后，改按实际结果位置展示下游候选连线，见下方结果卡说明。兼容用途唯一且允许独立增删时连线即采用；多用途先作为候选，在接收卡的正文、字段或关系控件中直接使用，不默认优先验收。素材和设计候选统一在接收卡的关联浮层中选择具体用途。悬浮或选中来源线展示实际用途及引用位置；展开后的单项连线仅显示对应结果位置的用途及引用。纯候选明确显示待接收端选择。

来源连接内部保留每个兼容用途的端口边与各端口 `input_order`，不将这些记录绘成平行线。保存和前端旧数据整理补齐同一对来源与接收卡的兼容候选，保留旧边 ID、已采用绑定、引用与顺序。重复连接定位已有来源线；复制卡片重建入线时按实际生成的用途边恢复顺序。几何侧别仍按本浏览器布局保存，不参与生成依据。

删除来源连接检查其全部用途及保留引用；存在强上下文引用时提示先清理，不能连带删除正文。仅候选或独立弱关联可直接断开，并撤回该来源的全部弱关联。多用途连接取消某个用途不删除其他使用或来源线，最后一项取消后仍保留候选；唯一用途的直接关联解除时同步断线。剪刀、键盘焦点、拖动、悬浮高亮及减少动态效果保持共享画布约定。

卡菜单“连接到…”及键盘连接点可进入目标选择，替代精确拖线。添加面板与连接目标选择互斥；窄屏添加或连接时暂隐原详情，结束恢复同一会话，创建成功则打开新卡。浮层开合不移动视角；显式“适应全部”使用实际可见卡片边界，并为顶部导航、左侧入口和底部工具留白。上述手势与连接展示为生成画布局部规则，不改变场次工作台交互。


筛选只使用蓝紫色边框高亮匹配卡片，不隐藏普通卡、编组成员或原本可见的连线，也不改变操作选择、编辑会话、实际采用或视角。问题条件只使用已确认的失效输出、运行失败与能力诊断。匹配边框与选中轮廓分别表达，清除筛选只移除匹配。堆叠保持收纳并显示匹配数量，只读查看层始终列出全部成员，仅高亮匹配项；适应全部仍包含未匹配内容。

`generation_canvases` 保存项目归属、当前完整文档、内容 revision 和已登记卡片身份／类型。文档包含画布身份、项目身份、名称、schema_version、卡片、候选连接、每目标端口独立输入顺序和分组。文本卡使用 `content.text`、type_version 1、不可变 ID 和一份 text，允许空字符串。后端轻量 `CardDefinition` 使用具体卡类型，前端显式 `rendererRegistry` 和 `CardShell` 消费同一文档。布局、运行状态与运行结果不进入此文档。

人物、道具、服装、场所描述分别使用 `content.character/prop/costume/place`，类别由具体卡类型固定，四类共用 `ObjectDescriptionEditor`，仅展示名称和文本。卡面复用 `GenerationCardFrame` 的预览和固定底部状态，固定为 400×172。编辑复用 `CanvasCardEditor` 的 A 紧凑容器与 `CardComposer`，顶部名称、正文区、底部字数／只读状态自上而下排列，无重复标题栏、关闭或发送按钮，仅右上展开／收起；Escape 退出，长正文只在输入框内滚动，展开与窄屏保留同一编辑会话。内部保留稳定 `object_id`、类别及已有来源数据，不创建旧场次实体。对象身份一旦保存不可替换；同画布同类型描述名称去除首尾空白后唯一，不同类型和不同画布可同名。空名称可以保存并输出已有正文，但不发布对象引用。旧 `content.object` 读取时按原 `category` 转为具体类型，保留卡片 ID、对象 ID、正文、端口、连线、采用和画布外布局；首次保存同步旧类型登记，禁止借迁移改变已保存类别。`content.basis` 原文依据卡及其来源定位和选区功能暂时保留。

描述卡分别声明 `text` 与 `object` 出口。`text` 的 `DescriptionTextPayload` 保留本卡名称、身份、类别、正文和来源定位，模型在所采用正文前标注同一直接载荷的名称、稳定身份及类别，保持用户正文原样；未命名的不完整描述仍只展开正文。标注不按名称反查其他卡片，也不自动采用对应图片。`object` 的 `ObjectReferencePayload` 仅提供身份、名称、类别，属于文本来源上的关系数据，不增加内容模态，也不能接入模型文本端口。它为同类参考卡的名称候选及类别适配的导演业务端点提供统一对象引用。改名后重新读取输出即取得新名称，已采用正文仍沿既有绑定保护断线和删除；未采用候选不额外确认。


四类命名图片参考使用 `reference.character/place/prop/costume`，各自保存名称、本地稳定身份、角度与具体 `image_binding`。名称可独立填写，也可从已连线的同类描述卡对象出口明确选择；候选连线不自动采用。名称关联持久化为 `name_binding`，沿用描述对象身份和名称并随源改名同步，名称关联本身不复制描述正文或主图；模型实际采用该参考时，明确依赖闭包会携带来源描述及已选主图。关联期间名称只读，取消关联后恢复独立命名；换图不覆盖已关联名称。描述卡与参考卡可以同名，同一描述可关联多张不同角度参考。参考唯一键为类型、去首尾空白的名称和角度（空角度按正面），重复或空名草稿不发布有效输出。新增关联图片仅接收 `content.image` 图片内容卡的直接图片出口，四类参考卡使用相同来源规则；模型结果须先另存为图片内容卡再关联。

每卡只选择一个具体文件；从图片来源候选选择时同时固定直接输出身份与结果集身份。来源重生成不替换主图；断开或删除已采用的名称／图片来源前必须取消或替换关联；主图亦可显式另存改绑。切换或取消名称关联前，须先清理参考对象的下游实际采用，避免同一参考卡静默换对象。候选关系沿同一 DAG 校验，更换主图保留已有名称，不分析图片内容。读取和编译重新核实主图文件的可用性与项目归属，文件失效只使图片出口不可用，合法对象引用继续有效。

`NamedImagePayload` 自含名称、具体文件、单个对象的名称／身份／类别及角度；对象出口提供一个不携带图片的引用。缺主图时仍可发布合法对象。图片模型明确采用该图片后在编译文本和预检映射中建立 `类型·名称 = image N（角度）`，不改写用户正文、不要求再次采用映射、不加入穿着／持有／动作指令。描述须从直接文本出口另行采用。

独立导演设计使用 `direction.situation`（角色情境）、`direction.performance`（人物表演）、`direction.performance_rule`（表演规则）。情境保留当前处境、人物关系；表演保留目标、阻碍、潜台词、注意对象、内在调整、身体动作、目光、呼吸、重心、手部、声音、表达、反应顺序、结束状态及避免的表现；规则保留适用说明。每个具体字段用 `ReferenceDesignField` 记录正文与结构化引用、未填写／不适用／明确没有／待确定／提议／事实、背景／设计／约束用途及来源；本卡 `scope` 单独保留范围、阶段和条件，不推断全场或镜头适用性。专用摘要与详情按情境、触发反应动作结束、规则分别组织，字段控件可共享，编辑约每秒保存。

全部25类设计卡共用13px“设计参数”标题行及右端 `DesignScopePopover` 漏斗浮层，复用 `DesignScopeEditor`；候选区与标题行相隔8px，验收展开内容上下各8px。限制为 `scope.description`（内容适用范围）、`scope.phase`（制作阶段）和 `scope.condition`（适用条件）。三项支持常用建议和单值自由文本；`phase` 接受任意字符串或空值，旧 `video/sound/postproduction` 原值保留，仅界面映射中文。未填写的默认提示不保存，不作为模型要求；清空阶段保存为空值，整卡预设不覆盖限制，连线不推断限制。自定义阶段随完整设计输出，卡面和关联验收详情按原文显示；不新增运行条件判断。

三类卡仅提供一个 `text` 出口，强类型 `DesignTextPayload` 声明 `adoption=whole_card`，保留完整结构与状态及本卡来源、范围和必要对象。编译时未填写／不适用不产生要求，明确没有表达否定，提议／待确定保留开放性质；背景不强制转换为可见动作，正文不做语义纠错。人物表演不开放目光等单字段出口，多卡逐卡采用。文本模型可分析不完整设计，实际采用情境／表演的图片或视频生成须有明确主体，不要求节拍、镜头或完整设计计划。

`participant` 只接直接对象出口的人物／服装／道具，情境和表演按稳定对象身份至多一个主体；通用 `effect_object` 已从18类卡片退役，相关对象通过具体字段的文字或完整引用表达；明确的参与、关注和焦点角色仍分别采用。对象可来自描述卡或独立命名参考，单张参考卡只发布一个对象身份。关系只传身份、名称与类别；字段显式引用的文本与具体图片／视频按参数引用规则展开或携带，在模型编译依赖闭包时，明确采用的对象会带入该卡的完整描述或已选固定参考图。人物表演声明可选的 `beat`、`received_event`、`dialogue_basis`、`acceptance_basis` 接收端点，节拍与事件来源可直接选择，所属节拍至多一个、接收事件可多个，`dialogue_basis` 采用对白直接出口，只保留对白身份与说话对象，正文随已采用设计的明确依赖传递；验收关系通过 criterion 连线直接建立，不作为独立工具的必填前提。

表演与规则不再维护独立正反示例。后端拒绝旧示例记录和退役示例端口，普通图片／视频候选须明确正文引用才参与生成；人物表演的现有明确结束状态仍可在图片端指定为画面目标，整卡采用保留全部表演字段。

对白卡 `direction.dialogue` 保存不可替换且画布内唯一的 `dialogue_id`、正文 `content`、可选语言／发音要求 `language_pronunciation` 和可选声画关系说明 `audiovisual_relation`，随画布修订保存。`speaker` 从直接对象出口选择至多一个人物或物件，不从正文或图像推断。`text` 发布完整设计，`dialogue` 以独立 `DialogueReferencePayload` 仅提供对白身份与说话对象；两个出口仍属于文本内容上的不同值种类。人物表演只发布这些必要指代，模型采用依赖该对白的设计时，会自动传递对白完整正文及其明确依赖。语言／发音要求与声画关系说明随实际采用的对白设计和适用条件进入提交文本，留空时不产生要求。对白没有回读表演卡的文本依赖。图片和视频实际采用有正文的对白时须明确说话对象；明确没有对白不要求虚构对象。

声音安排卡 `direction.sound` 使用声源说明、环境声、动作声、音乐约束及可选的声音层次／主次关系字段。声音时机沿用设计适用条件，实际声音配置属于模型生成卡。两类卡都按完整设计采用，保留字段状态、用途、来源与范围；图片编译明确仅表达可见声源或说话状态，不声称图片包含声音；视频按模型实际能力执行声音意图，待后期安排不等于本次已生成声音。

对白通过 `video_example`／`audio_example` 关联表演、口型或声音参考；声音安排通过 `audio_example` 关联音频。固定素材记录具体文件、来源、正向／反例用途、说明及可选递增毫秒区间，复用项目归属、可用性、文件保留和引用删除保护。播放与关联不代表模型采用，本地示例不自动携带；实际采用的明确关系依赖由模型编译闭包递归传递。模型需要本地示例时须明确直接采用或在允许的设计字段引用受支持媒体，不新增音频生成、音频模型输入、音轨替换或隐式转写。

视频生成卡分别显示原生声音输出、声音开关和音频参考输入的模型声明及适配器接入状态。当前视频请求路径尚未提供声音开关配置或音频参考输入。本地可试听的音频仍可作为设计参考，声音设计中的后期制作意图作为设计文字传递。已采用对白或声音安排时，编译及运行预检可以提示不支持、未接入或未知，提示不阻止合法生成。已接入表示当前请求路径可交付模型原生声音，音轨存在及声音设计落实仍取决于实际结果。

“添加另一角度参考”按用户选定的具体对象新建参考卡，并同时建立直接 `object → name` 候选边及带 `object_id` 的名称采用；只复用对象身份，新卡不复制主图，不自动连接或采用到模型。多人图逐对象选择，标题与角度由新卡独立维护，源对象改名沿直接绑定更新，移除或断开仍受既有绑定保护。

视频模型对实际采用的命名图片逐对象编译名称、身份、主图角度、媒体序号、`input_port`、用户填写的 `subject_name` 及用途内 `purpose_position`；同一主图用于不同用途时分别展示映射，媒体保持去重。主体名称映射使用 `@主体组 图片 N`，N 按该组实际图片提交顺序计算；首尾帧及关键帧直接标明用途和关键帧序号，不把候选序号误作组内序号。映射文本进入本次请求及固定历史，不改写用户正文。首尾帧／关键帧采用不自动生成主体输入；主体只按用户明确分组组织，同一身份多角度不自动归组，不按对象名称改换直接来源。每张参考卡只映射本卡对象，不附带其他人物、服装或道具名称。主图角度不规定最终生成视角。

HTTP 边界为 `/api/v1/studio/generation-canvases/{project_id}` 的列表／创建，以及 `/{canvas_id}` 的读取／PUT 保存／删除。读取、写入和删除均限定项目归属，沿用现有项目 API 的访问边界。前端普通请求由 OpenAPI generated client 发出。

模型卡以 `model.text`、`model.image`、`model.video` 区分能力模态，不按供应商复制卡类型。前端复用受控 `ExperimentComposer` 的正文和底部参数布局；文本请求沿用模型管理参数，当前仅接收文本。图片卡配置画幅、分辨率档位和数量；视频仅配置画幅、时长与高级随机种子。`/{canvas_id}/models/{model_id}/capability` 从已接入 DTO 和真实图片／视频能力解析器派生用途、组合、数量及参数范围，未知模型或加载失败保留现场并提示。

画布保存由 `CanvasStore.save()` 负责画布行锁、原请求回执重放、revision 核对及最终落库；`document_save.prepare_document()` 在同一事务内按固定顺序完成文档规范化、身份与引用约束、模型能力和媒体校验，返回规范化文档、累积卡片身份及媒体清单。原始旧文档与清理后的旧文档分别保留原有用途；准备过程包含数据库读取和文件锁定，不提交事务、不替换文件保护。请求摘要仍按原始提交正文计算，回执重放先于当前 revision 与文档校验。

画布编辑保存通过 `saved_media` 从最终规范化文档收集内容媒体、命名参考固定主图和设计示例的文件引用清单。每个引用保留独立保护位置及原有文件诊断信息，同一文件的不同采用位置不合并；示例按列表顺序保留，重复 ID 由原业务校验处理。文件可用性、类型和项目归属检查仍在各业务原校验位置执行，不改变首错顺序；来源资格及固定绑定规则仍由对应模块负责。全部校验成功后，用同一清单在现有保存事务中重建本画布的 `canvas_content` 保护，再完成 CAS 与回执；沿用文件锁及通用 usage 写入，不重新解析固定文件，也不修改运行、历史或其他画布的保护。

模型编辑器对四类参考卡以有效名称显示引用，例如 `@张三`；名称关联描述时使用描述的当前名称，空名称回退原编号。其他卡片继续显示编号。该标签只用于展示，来源身份、绑定 ID、服务端代号、实际媒体顺序和历史运行快照保持原契约；文本模型仍只接收文本输入，不因名称标签获得图片理解能力。预检显示名称标签与实际 `image N` 的对应关系，同时保留原始编译输入。

名称冲突只在当前接收模型的关联来源中判断，包含未采用、暂不可用的来源，不包含无关画布卡片。外画布来源即使卡片 ID 相同，也不解析本地名称或参与本地消歧；保留其原始身份与跨画布诊断。同名组统一依次使用角度、类型加角度、类型加角度加原编号消歧；冲突消失后恢复当前最短唯一标签。匹配 `文本/图片/视频/音频` 加数字的名称始终限定，实际编号的精确匹配优先。名称恰好包含消歧文本时继续提升冲突组的限定层级。已有结构化引用随名称变化刷新显示，不迁移或重建绑定；历史运行保留原快照。缩略关联入口的长名称可截断，悬停提示保留完整消歧标签；普通媒体沿用来源名称提示。

名称引用必须通过候选确认，普通输入或粘贴名称保持文字。名称含编号时，按连续文字识别完整名称及正在输入的名称前缀，跨 DOM 文本节点也不把内部编号自动绑定；紧邻全角限定括号的编号式名称文字不按编号前缀解析，完整独立编号不作为名称前缀保护，仍优先按编号确认；明确选择编号也沿用原规则。候选刷新按来源身份保留高亮，原项不再匹配或不可用时清空；此时回车不替选、不提交，等待明确选择或 Escape。组合输入期间延后候选和标签刷新，结束后更新元数据，保留正文 DOM 与光标。单纯展示标签变化不触发保存、内容撤销记录或生成依据失效；实际名称编辑仍沿用既有依据校验。

候选边以 `source_card/source_port/target_card/target_port` 定义端点用途，`input_order[接收卡][端口]` 持久保存独立边 ID 顺序。新边追加、重复端点拒绝；自连、循环、损坏端点、损坏顺序和分组成员阻止保存并返回定位诊断。卡片移动或分组不改变输入顺序。已保存且端点未变、尚未采用的历史名称类别不兼容候选可保留，不阻塞其他内容或正确名称连线的保存；旧的非图片内容卡参考图来源边在编辑保存时清理，固定图片与下游采用保留。修改旧边端点、创建新跨类候选或实际采用错误类型来源时仍严格校验。新建不兼容连线在 UI 拒绝；新增来源连接在保存时核实接收模型至少支持一个用途。切换模型保留既有配置、候选和采用；实际用途由接收浮层及运行预检依据当前模型能力判断。能力不匹配与无效参数提供运行级诊断，不阻止保留编辑现场；实际使用判断依据输入绑定，提示词通过绑定身份参与编译。

视觉编组保存名称与独立成员，新编组不提供折叠操作；历史已折叠组仍可展开。解散不会删除成员。系统按 macOS Command、其他系统 Ctrl 提供点选增减，普通画布空白拖动框选，触摸从卡片菜单进入选择多个；多选组织菜单锚定选区上方，不新增布局菜单。编组内卡片保持独立编辑与移动，组内空白拖动整体平移，Space 优先平移画布，修饰键优先框选。成员归属通过明确操作改变，不随边框穿越自动变更；混合已有归属不静默只分组部分成员。整理按编组整体平移并保留内部相对位置，布局撤销恢复。几何、尺寸、视角通过 `useGraphLayout` 按项目／画布独立保存在浏览器；分组整体移动也只更新几何，不产生内容 PUT。折叠仍保留成员布局和连接顺序，分组没有集合输出。存储失败显示布局保护警告，继续保留本次会话内布局。

模型正文使用编辑器无关的 `PromptDocument.segments`：`text` 保存原文，`reference` 保存输入绑定身份 binding_id，`instruction` 保存命令、参数及引用。新文档使用 schema_version 2，实际来源只在模型卡 input_bindings 中持久化；编辑器为显示与剪贴派生来源，保存时不再写入第二份来源。读取 v1 旧来源片段时在解析阶段规范化为 v2 绑定，不原地修改原始幂等请求正文或既有运行快照，来源及用途含义保持不变。片段 ID 与指令内引用 ID 在同一正文内唯一，用于诊断定位；不使用正文偏移。文本与媒体输出身份为 `{canvas_id,card_id,port_id,position}`，对象引用另带具体 `object_id` 选择器；选择对象时以对象身份定位，列表重排不改绑。空选择器不写入旧身份，因此旧文本／媒体引用和依据哈希不漂移。不按文件 ID 合并来源。输入重排只改变接收代号，已绑定身份不变。空卡和无结果模型不提供可选择的输出；仍被引用的缺失位置保留占位。

图片模型正文输入 `@` 时列出已连线的直接候选，按代号或来源名称筛选，行内包含缩略图、名称及采用状态；缺失或模型不支持的来源不可选择。方向键切换、回车或点击确认候选，Escape 仅关闭候选；候选打开时回车不触发生成。关联区图片点击与正文候选共用引用插入入口，在活动或保留的光标处插入结构化引用标签；查看与管理仍通过底部候选管理。手动代号在完整边界确认，未命中保持普通文本且不建立采用；有效引用以蓝色下划线展示，失效引用保留稳定身份并提示。重复正文引用复用同一输入绑定。图片模型新增正文绑定以 `prompt_owned` 标记，删除最后一处正文引用只清理正文独占绑定；独立采用与正文复用时标记为非独占，保存重开后仍保留，已有未标记记录沿原行为解析。该编辑来源标记不参与实际生成依据哈希。

共用编辑器支持按分类选择、完整代号确认、中文组合输入、转义及结构化剪贴载荷 `application/x-jellyfish-prompt+json`。输入 `@` 打开候选列表；输入过程中只匹配，在选择、Enter／Tab、明确分隔符或失焦时才绑定完整代号。组合输入期间不转换。同画布粘贴保留来源，未连接时要求手工连接；跨画布载荷保留外来身份并诊断，不自动复制卡片或按同名代号换绑。外部纯文本按目标当前代号确认。添加入口创建可见内容卡并连接，选择已有卡只新增候选边。

`services/generation_canvas/compiler.py` 的公开 `compile_card` 与 `resolve_outputs` 解析实际引用。内容输出来自真实内容卡；运行层通过独立的 `model_outputs` 参数提供已核验的媒体出口和已发布的模型当前结果，不把结果写入编辑文档或虚构未来输出。编译仅在结构化引用处展开文本一次，实际媒体按接收端顺序选出使用子集，并提供本地代号、稳定来源与实际媒体位置映射。通用 `[media:N]` 表达用于无模型能力的基础编译；图片预检在结构化引用处写出 `image N`，对应实际提交图片数组的第 N 项。普通文字中的 `图片3` 或 `[media:1]` 均保持原样，展开内容不再次解释。

`content.basis` 保存创作依据的正文、来源定位和可选选取起止位置，无章节绑定或持续输入。通用文本和创作依据可通过明确选择文本文件导入形成自身内容。来源定位不成为隐式读取授权。

设计卡保存时，`design_bindings.inspect_design_bindings` 集中解析直接候选、匹配连线、检查绑定 ID 与接收端口，并区分绑定声明合法性和来源可用性。它按调用方传入的绑定顺序返回结果，去重限于本次集合，沿用允许草稿身份的保存解析规则；公开输出和执行仍要求来源就绪。六类设计关系校验各自保留对象资格、数量、稳定身份规则及原诊断；验收依据的跨类型检查、校验器顺序与首错行为保持不变。媒体示例和文件保护继续独立校验。

单卡输出由小型 `CardOutputHandler` Protocol 处理，只接收本卡、明确采用的直接输入和本卡已发布结果，处理器不持有完整画布或数据库。外层负责查找直接候选；模型编译内层只接收本卡配置、已解析候选与能力。输出使用稳定来源外壳及带 kind 判别的正文／媒体 payload，旧 text/file_id 读取字段是该 payload 的只读投影，历史旧输出可解析为同一形式。运行依据哈希继续以实际文本／文件和身份计算，不把重复的 payload 传输投影算作输入变化。跨层值契约位于 core/contracts，公开 API 和前端生成类型保持一致。

`GET /{canvas_id}/cards/{card_id}/outputs` 返回对应已保存 revision 的本卡输出与直接候选，不增加绑定或发起任务。前端模型候选、已采用来源正文与正式输出消费此响应，并复用已保存 compile 接口刷新后端诊断；仅接收与保存基线相同 revision 的响应，较旧查询不能覆盖较新修订。采用标识依据已保存卡片，本地编辑与已保存来源分别展示。编辑器有变化时约每 1 秒合并保存，持续输入期间也提交；在途请求串行完成后只提交最新文档。无变化不提交，相同失败正文暂停自动重试，修改或手动保存后继续；未知结果重放原请求，冲突保留本地内容。手动保存和运行预检立即冲刷待保存修改，保存失败不继续预检。约 1 秒是合并周期，下游刷新仍需等待保存及输出计算；保存与刷新不采用候选、不发起模型，也不改变历史。

图片模型详情中的文本依据与参考图片分别明确采用、取消及调整采用顺序，全部写入同一 `input_bindings`；提示词引用仍按绑定身份定位。取消采用同时移除正文中对应引用。图片编译按接收端绑定顺序形成实际使用集合与媒体顺序，候选连接排序不覆盖该选择；重复引用同一输出只提交一次，不按文件 ID 合并不同来源。参考数量与重复文件限制来自所选模型能力，页面提示与后端预检一致。展开来源图片或切换生成结果预览只改变显示，不采用成果。

图片当前输出引用保持卡片、端口和位置身份；来源重生成时该位置更新，位置消失则保留选择并明确报缺失，不退回第一项。需要固定某次成果时，在运行历史中明确另存为图片内容卡，固定具体文件并保留运行、节点、位置及完整／未完成来源；它可经新直接候选连接再明确采用。另存、预览和保存均不运行模型、不回写输入；原始运行历史及独立图片卡的文件使用关系继续保护文件删除。

`GET /{canvas_id}/cards/{card_id}/compile` 返回已保存正文的基础编译预览、实际使用集合、映射及结构化诊断，不提交任务。保存未完成正文与允许运行分开；未使用的不兼容候选是 warning 且不阻塞，实际使用的不兼容输入与无效参数阻止运行。正文和指令内实际引用共同保护断线及删除来源，定位到稳定片段；保存检查最终文档，因此可清理引用后立即断线／删卡并一次保存。视频指令同时编译为预检中的标准 `video_media`，由同一次受理直接用于真实供应商请求。


单模型提交采用 `POST /{canvas_id}/precheck` → `POST /{canvas_id}/runs`。预检绑定保存 revision、实际引用的结果集、编译后的正文和有效模型参数／供应商路由，十分钟内可提交；不占用节点。受理先锁文档并重放原回执，再核实预检及活动占用；运行、固定依据、真实 Task、占用和回执同事务写入。相同身份不同正文为 `IDEMPOTENCY_CONFLICT`，过期依据为 `PREVIEW_STALE`，重叠执行为 `RUN_SCOPE_BUSY`。单卡仅执行自己一次，不自动补跑上游；实际引用的失效成果为 `INPUT_STALE`。

画布使用 `canvas_node` 生成目标及 `text_chat/image_generation/video_generation × canvas_node × async_polling` 提交矩阵。此 delivery 表示后台 Task 受理协议，画布观察仍使用 SSE。目标指向独立运行节点，任务来源可回跳项目、画布、运行及节点；不创建实验室消息。受理冻结的模型名、有效参数、供应商身份、路由及凭据保存在服务端节点私有快照和 Task 私有执行输入中；公开预检、运行、事件不携带凭据。Worker 使用该配置调用 `llm.astream`，关闭 SDK 自动重试，每次有效增量在短事务中持久累计正文及事件。离开或刷新页面不改变 Task，也不重发模型请求。

`current_state.CanvasCurrentState` 集中查询当前正式输出与当前模型依据，供快照、规划、保存和结算直接调用；结构索引继续复用 `CanvasOutputContext`，纯依据计算仍由 `execution_basis` 负责。查询不缓存动态输出、文件状态或配置，沿用调用方事务及原配置锁策略；结算发布前核实资格，发布后重新查询事件携带的输出视图。历史成果另存及来源校验由 `historical_content.CanvasHistoricalContent` 集中处理，供内容准备接口与文档保存直接调用。首次另存核实固定内容和完成状态，已保存内容仅保护来源不可变；文件可用性检查仍保持准备与保存各自的阶段及诊断。

`TaskService` 仍是唯一任务写入口。领取、进度和唯一终态裁决后调用窄范围画布事实同步；成功、失败、取消、排队取消、过期和启动中断均在 Task 的原事务更新节点与事件。完整成功才创建 ResultSet；相关当前依据仍匹配时整体更新当前输出指向，不推进编辑 revision。失败及取消保留未完成正文和旧正式成果。正式指向即使依据已变也保留，`basis_current=false` 表示不能作为单卡有效输入；实际内容仍可显示和绑定引用。结果集身份作为实际输入依据的一部分，未使用候选和无关文档编辑不使已有成果失效。

`GET /{canvas_id}/runtime` 返回一致快照；generated `GET /{canvas_id}/events/connection` 提供公共 SSE 地址，传输层逐段解析并恢复订阅。每张画布的一条连接复用 `snapshot`、`node.updated`、`text.delta`、`node.finished` 和 `run.finished`，单次运行结束不关闭连接。事件头行锁使事实、事件游标和提交顺序一致；快照使用同一把锁复制事实及游标。既有 Task 写入遵守 Task → event head 顺序，受理只创建新 Task；流每次追读使用独立短事务，释放所有锁后才 yield。恢复游标之后只重放已提交事件，过期／超前游标发送权威快照，前端按游标去重；没有运行状态轮询。

检查卡 `review.check` 只接收模型生成卡的 `check_basis`，专用连线固定一张检查目标。检查读取已保存目标的同一次实际编译及公开模型能力，技术预检继续决定生成请求可否执行。检查报告按原检查卡身份单独保存，固定目标、依据、选择和结果。打开历史报告时，用当前生成目标和各项的实际检查输入标记逐项比较。启用范围的改变单独提示，相关输入未变的结论仍适用。画布布局、无关修订和刷新技术预检令牌不影响逐项比较。明确数值的时长规则只核对直接采用的单一镜头，预计差异为风险建议。

类别开关与单项排除随检查卡保存，单项身份由规则及实际采用来源确定。新来源沿用类别开关；软件新增类别仅初始化给新卡。范围不明或缺少生成时长时，保留适用项及暂不可执行原因。整卡报告分别记录实际执行和跳过理由。

P01 从实际采用的设计和验收要求中列出有效字段。检查卡单独保存文字模型选择，模型不可用时规则项仍可执行。受理固定本轮采用要求、提交文本、相关素材用途和私有执行配置，每项独立排队。Worker 终结任务后，报告查询投影任务状态和已校验的提交片段。单项重查创建新报告，先前结果和执行失败各自保留。P01 只核对输入含义及素材用途，媒体内容和生成产物由其他检查处理。

P02 比较实际采用的设计字段和提交补充文字，报告引用冲突双方。共同范围不明确或要求尚未确定时，只给风险建议或无法判断。结构化景别冲突由技术预检继续处理。P09 从已采用的验收要求、明确约束或可见结果派生项目，结合提交文本提示哪条要求需要明确对象、条件或可观察结果。缺少某类设计卡不会产生检查项。

P04 核对实际采用的动作、触发事件、结构化延迟与进出画，并引用对应设计字段。P05 比较前态、变化、关联事件、后态和保持要求。前后状态变化需引用明确的变化或事件；不同阶段或条件的事件不作同范围依据。明确的保持冲突须定位同一对象及范围。两类检查均沿用独立文字模型和原报告证据。

P06 对同一个镜头时长项优先执行明确数值规则，文字模型只补充预计、固定、最低及分段的来源与范围解释。分段、范围不明和无法核实的数值不与请求秒数强行比较。P07 结合实际采用的动作、延迟、运镜和对白文字评估节奏风险，拒绝直接累加并行动作，经验语速仅作建议。两类文字结论支持固定原依据复核。

P03 用实际采用字段的素材关联、已采用描述的对象身份或正文中的结构化引用定位单项参考素材，保留提交用途。已接入的百炼图片理解模型只读取该项的项目图片。报告记录观察模态、文件和可见证据。未接入的模态、模型或不可用文件仍保留适用项。执行期读图失败和不可见特征分别记录为无法判断。

P08 只核对本次实际采用的对白、声音安排及声音策略。明确的制作要求按原生声音输出、声音开关和音频参考输入逐项对照能力声明及适配器接入状态。含糊但与制作方式相关的文字可由检查模型辅助分类，程序核实引文和能力状态后给出结论。能力不匹配作为风险提示，实际音轨保持未核验，非法参数与素材输入继续走技术预检。

生成后文字检查要求用户先选定具体历史产物。R01 使用原运行节点保存的公开依据和产物正文，固定运行、节点、输出位置、结果集和原生成修订。预览展示检查方式及预计调用次数，执行时重新核对当前检查卡修订、产物依据和调用数量。一次调用核对这份产物内的所选文字要求。失败或取消运行保留的片段可以手查，报告标明仅观察保留内容。报告回看始终使用固定产物，生成状态独立记录。

图片或视频产物的 R01、R02、R03 读取原生成要求和所属项目的固定文件。图片使用原图，视频只发送实际解码的静帧并记录时间。只对有明确关联的对象附带原参考图片。同一画面和对照范围共用一次模型调用，报告仍逐项保留证据。静帧仅支持观察时刻的画面判断，动作过程、未观察区间、音轨和声画同步未核验。

R04 从固定原依据中派生动作、反应和镜内活动。百炼已接入的 Qwen3-VL-Plus 视频文件接口接收去除音轨的实际视频，服务端核对重封装前后的视频包时间，并记录原产物提交区间及请求采样率。模型估计的证据区间单独显示，仅保留落在实际范围内且可覆盖多个采样时刻的证据。结束状态可用真实末帧单独检查；读不到视频序列时，动作过程仍为无法判断。音轨与声画同步未核验。[百炼视觉理解](https://www.alibabacloud.com/help/zh/model-studio/vision)

检查报告可单独请求取消。排队检查立即终结，执行中的检查显示已请求取消，等执行器确认终态后再显示已取消。保存断线、换目标或删除检查卡时停止原连线对应的检查，生成任务和其他检查独立运行。编辑检查项和开关保留本轮已固定范围。换目标后仍可在原检查卡读取历史；删卡后从画布「检查归档」查看原报告和固定依据。

原报告复核读取指定结论及当次固定依据，按原数值规则重新判断，或使用原文字检查任务保存的私有配置和观察输入重新调用模型。用户补充说明只用于本次定位线索，结论仍需来自原依据。复核创建关联的单项报告，原依据无法读取时给出对应提示。

参考图、历史产物静帧及连续视频报告可以按原依据复核。复核只执行所选项目，沿用原报告的媒体身份、观察方式及模型路由，并重读实际字节。已记录的静帧时刻或视频提交区间须重新对上。原媒体或读取能力不可用时保留无法判断和原因，未实际观察的内容不进入证据。

活动模型卡不可删除，活动画布和项目也不能删除；取消意图尚未形成真实终态时仍保持占用。文档保存校验最终保留的卡片集合，仍允许修改活动卡的后续输入。本地任意内容编辑立即失效预检，并拒绝迟到的旧预检响应；独立布局改变不失效。运行信息和当前模型输出始终在编辑文档之外归并，不影响未保存提示词或保存 revision。

空间设计使用 `direction.anchor`、`direction.blocking`、`direction.activity`、`direction.environment` 四种专用卡。锚点维护稳定 `anchor_id`、名称、位置、方位、空间关系和尺度，走位维护稳定 `blocking_id`、位置、朝向、主动权、路径和切换原因；已建立身份不可改绑。镜内活动保留持续任务、注意对象、对主戏的作用、路径、延迟依据／毫秒、入出画、结束状态、景深层次与强度；环境活动与刻意留白及理由分开。它们完整发布强类型设计，不提供单字段采用。锚点与调度另外发布 `anchor`／`blocking` 身份出口，仅含身份名称，供直接关系选择。

空间关系 `space`、`participant`、`position_anchor`、`area_anchor`、`effect_object` 按直接候选、类别和数量校验，参与者可为人物、服装、道具，不能为场所；所属空间／参与者／区域各至多一个实际对象。`change_event` 与 `trigger_event` 用途独立，分别接收直接事件身份且至多一个，不展开事件正文。`SpatialDesignRelations` 保留明确用途；模型采用走位或活动时，明确关联的锚点、所属场所描述随依赖闭包进入输入；本地示例媒体不进入依赖，实际引用和已选固定参考图按素材规则携带。空间工具不要求节拍或镜头，可独立生成；文本可分析未完成设计，视觉生成采用走位或镜内活动时须明确参与者。范围只保存创作者声明，不自动判定适用性。

空间锚点保留固定参考图片与坐标标记，标记绑定具体例图；站位与走位、镜内活动、环境活动与留白不再维护本地素材示例，普通候选通过正文引用采用。

四类参考卡共用 `ReferenceCard`、`ReferenceCardEditor` 和 `NamedImageReferenceEditor`，每卡仅表示一个对象、一张图片和一个角度；多角度可以通过名称关联共享同一描述对象身份。复用 `GenerationCardFrame`，保留 300×251 几何及固定底部状态，保留已有坐标、手动放置与视口。编辑框顶部依次为不可输入的关联图片 Select、可选择同类描述候选或确认自定义输入的名称 Select、可自定义角度 Select；名称控件始终保留下拉箭头，关联名称后禁用并提供取消关联图标。正文为固定区域缩放的图片或“从当前画布选择”空态，底部仅状态，无发送动作和“更多参考设置”。

图片 Select 仅展示已连线的有效图片内容卡候选，选项包含缩略图与名称；空态按钮与更换图标直接打开当前画布选择器，只展示未连线的有效图片内容卡，选择时同时创建来源边。参考卡不提供上传、拖放、素材库或来源菜单；这些导入动作由图片内容卡承担。主图固定具体文件、来源及结果集，上游替换图片不自动更换已选文件。独立名称为空时可以从新选图片的文件名称补全，已有手动名称及关联名称保留。名称搜索过程不修改文档，选择候选或确认自定义项后保存。

参考名称按类型、名称、角度联合判重，空名或重复项允许保存草稿并提示，但不发布有效对象和图片输出，已采用它们的模型无法运行。跨类型允许同名，编译映射带类型标识，如 `人物·小雪 = image 1（正面）`。独立身份由 `object_id` 或卡片 ID 提供，关联期间使用描述对象身份，改名和换图不改身份。旧多对象参考格式不再自动转换；请求须使用当前单对象结构，同类描述名称关联及合法候选继续有效。已有的直接文件绑定继续保留；编辑保存时移除不符合新规则的图片来源边，并仅解除旧固定图片的非图片内容卡来源指针，保留文件、结果集、卡片身份、画布位置及下游采用。读取不改写原始历史。原型归档于 `codex-prototype-reference-card-a`（`b37fbfac`）。

命名参考保存校验直接使用最终文档、旧绑定及文件事实，不读取整张画布的模型运行成果。同次修改图片内容与参考绑定按最终文件核对；未变固定主图仍保留原文件。设计卡等其他保存校验按各自职责读取所需成果。

## 单模型提交与固定输入

当前新请求仅允许 `kind=single`（省略时同样为单卡）且不能携带 `card_ids` 范围；旧 `target/selection` 请求及范围参数由服务端返回 `SINGLE_MODEL_ONLY`，旧预检凭据也不能绕过该门禁。输入 DTO 仍可解析旧枚举，以便返回明确业务诊断；历史运行、快照与已受理任务继续可读及观察。单模型消费已采用的有效输出及明确设计依赖闭包，上游缺失或依据过期阻止提交，不自动补跑。

模型、命名参考和导演卡可组成混合链路，执行范围只包含实际需要运行的模型。单卡身份出口保持必要标识；模型编译完整设计时递归传递明确采用的描述、固定参考和上游设计，本地示例不自动进入输入。固定参考主图保留明确选定的文件，上游发布新结果不会替换主图或强迫来源重跑；另行采用模型当前输出时使用其已发布有效结果，不把未来生成结果当作当前输入。人物描述等未采用内容、候选增减与展示代号变化不改变实际依据；名称、角度及主图变化影响采用它们的输入。

当前模型媒体与普通媒体一样，在读取正式输出时核验文件可用性。文件撤回后保留原输出位置和绑定身份，标记不可用并产生定位诊断，预检不能以来源将来重跑的承诺放行。固定图仍须保留直接采用关系；删除来源前可明确另存独立图片并改绑，历史与文件保护沿用原有生命周期。

规划入口直接构造当前单模型的计划，固定其直接采用输入、真实模型能力与有效供应商配置，不执行上游模型或框选范围，但固定完整明确依赖内容。新计划保留既有单节点结构和空依赖列表，供受理与执行快照消费。公开 `basis` 不含凭据，私有 `execution_snapshot` 不进入预检、历史 DTO 或事件；后续编辑不改变受理依据。历史运行的等待节点和终态推进继续按已受理快照恢复，不因新请求范围收窄而取消。

画布内部 `execution_basis` 统一输入编译、诊断组合、公开依据、哈希和私有快照序列化。当前配置由 runtime 查询并按原受理锁序核验，编译和快照保存使用同一份模型能力；历史恢复只消费已受理文档、配置、能力和本轮依赖结果，整组替换来源输出，不回退旧位置。快照 JSON 与哈希字段保持既有语义；依赖及受理游标仍由编排层添加，模块不查询数据库或推进任务。通用 Gate 继续在原位置使用 `FrozenGenerationConfig` 校验配置，并保留缺配置时的当前配置回退；此回退不表示历史等待节点的执行快照可以缺少固定配置。

必要上游失败或取消使尚未创建 Task 的后继成为 `blocked`；下游自身输入校验失败为 `failed`。独立分支继续，旧正式结果仍可查看但不能作为本轮失败分支的后备来源。确认的任务启动中断会终结本轮等待节点，不自动补交；已有 Task 保持其真实状态。整轮取消终结全部等待节点并请求取消已有 Task。全部节点终结后释放范围占用并结束生命周期，不计算整轮成功等级。

所有已知媒体输入在受理事务以 `canvas_run` usage（`canvas_id:node_id`）持久保护，包含尚无 Task 的等待节点。后续编辑移除内容卡或引用不会改写该保护及固定输入。受理和终态调度均先取得 event head 再保护具体输入文件；受理只创建新 Task，不取得既有 Task 锁。

### 公共连接策略

`CanvasCatalog.connection_policies` 由后端 `connection_policy.py` 声明具体端点的连接、解除采用、断线与提示语义。前端拖线、键盘连接、来源选择、连线详情及文档操作消费同一目录，后端保存同步使用同一策略。仅唯一兼容用途的设计正文到模型文本输入随线采用，以及验收要求到设计验收依据随线关联；多用途与其他来源均为候选，查看来源不等于采用，也不会自动运行或通过验收。

明确选择来源、内容和用途时可在同一次编辑中补足来源边。普通取消采用保留候选边及同源其他用途，只删除该绑定拥有的配置。任何正文或内联指令引用都保护取消采用，并提供引用定位。整条来源断线汇总全部用途；受保护引用存在时原子拒绝，只有可随断线解除的直接关联才能一起撤回。构图定位是公开策略中的确认例外：没有其他受保护用途时，确认后同时清除定位与连线。

当前文档的冲突选择通过备份迁移清理，变更文档推进 revision，阻止旧请求覆盖清理结果：合法明确采用补足缺失边；未采用的旧直接关联边移除；非法来源、用途及单值冲突撤回相关采用与所属配置，不选择第一项。恢复与撤销使用当前规则。结果未明的保存请求先原样重放取得回执，不更换请求正文；执行快照及媒体文件不改写，不支持的历史执行要求从当前画布重新提交。

## 单模型范围与并行观察

模型提交按钮位于下方编辑区右下角，展开时保留同一入口；卡面和顶部没有批量、全画布或运行到目标操作。提交先保存，成功后预检并核对实际输入，确认后只执行当前模型。多选、编组和堆叠不形成生成范围；单模型多个结果仍按原能力契约交付。模型编辑区加号可上传为独立内容卡或选择未连线来源，用途选择只建立直接候选，实际采用独立进行。

文档行锁使同画布受理原子核实执行占用；等待节点也占用。执行范围无重叠即可并行，仅共同读取同一结果不构成冲突；`RUN_SCOPE_BUSY` 的 target 包含冲突 card_id、run_id 和 node_id。取消意图未达到真实终态前不释放占用，终态后由用户明确发起新的运行。

正式发布的 `node.finished` 事件携带权威 `current_outputs`，前端按画布游标归并完整有效性视图，范围外下游只标记依据改变。所有运行共用同一 SSE，一个运行终结不关闭其他运行观察；快照和重放沿用同一游标，不追加重复正文。画布路由的数据库依赖使用 function scope，在发送成功响应前提交事务，保证保存后预检、凭据后受理和回执后观察可由下一 HTTP 连接立即读取。

## 取消与独立历史内容

`POST /{canvas_id}/runs/{run_id}/cancel` 与 `POST /{canvas_id}/runs/{run_id}/nodes/{node_id}/cancel` 明确取消范围，并返回真实运行节点。执行中的任务接收意图后仍为 `running`，以 `stage=cancelling` 展示取消中；排队任务沿用 TaskService 立即终结规则。未知或失败回包不释放范围占用，也不推断终态。取消命令先按已冻结范围的拓扑顺序锁定整轮既有 Task，再逐个调用 TaskService，避免持有事件头后等待另一个 Task。每锁定父节点后重新读取后继 Task 身份，确保等待节点在并发调度中刚获得 Task 时也不会漏取消；单节点取消仅向指定 Task 发取消请求。

任务来源链接通过 `run/node` 打开运行历史并定位节点。用户关闭历史（含顶部开关、Escape 和窄屏关闭）或切换到卡片详情时替换当前地址，移除本次 `run/node` 定位参数，保留画布及其他参数；刷新后保持默认关闭，不新增关闭操作的浏览器历史步骤。新的任务来源链接仍可再次定位，历史记录及运行状态不受关闭影响。

运行快照和节点事件提供安全的固定 `basis`、实际状态、累计正文、成果和正式结果集身份。源卡删除后运行记录仍在，任务中心来源仍保留项目、画布、运行与节点身份。成果非空不表示成功；未完成正文保留在历史中，不替换旧正式输出。

`GET /{canvas_id}/runs/{run_id}/nodes/{node_id}/outputs/{position}/content` 为已终结文本、图片或视频成果准备独立内容卡。前端将它加入当前编辑文档并走既有 CAS 保存队列。卡片的 `origin` 固定画布、运行、节点、输出位置及 `incomplete` 标记，服务端校验来源归属、实际成果与完成状态；保存后正文可独立编辑，来源不可移除或改写。这项显式操作不改变原模型输出指向，不会跟随后续运行更新。图片内容以独立 `canvas_content` 引用固定文件，后续替换不改变历史成果或原模型输出。

## 关联结果卡

模型卡参数栏的“显示结果卡”按卡保存，默认关闭。开启后，画布将每个正式输出投影为一张对应模态的结果卡，保留模型卡原有预览、状态和尺寸。正式输出位置决定结果卡身份，更新文件、正文或生成结果集时保留布局。收起结果后恢复来源的紧凑连线，结果位置继续随现有浏览器布局缓存保留。运行中、失败和取消沿用既有正式结果，临时正文和未完成成果仍在原预览或历史中查看。

关联结果直接读取模型的正式输出，画布展示使用模型到结果的更新线与结果到下游的候选线。切换显示沿用相同的候选、引用、输入用途和能力校验。显示偏好保存在模型卡编辑文档中，实际执行依据继续按模型配置及使用内容计算；结果到达时只更新运行状态与画布展示。

下游连接范围可限定为明确结果位置，或接收整源但排除已断位置。同一来源输出端口到同一接收卡的各兼容用途共享范围，保存校验、候选解析与断线保护均按实际输出位置判断。展开后从单项结果建立连接只提供该项候选，整源连接仍接收新增输出位置。仍连接的历史位置暂时缺失时只显示缺失提示，未被引用的缺失占位不占输入代号。折叠只显示仍有实际路径的紧凑连线，首次生成前预先建立的整源连接继续可见。

选择模型与结果之间的“随生成更新”线可用原有断线操作固定结果。浏览器从显示中的正式结果集定位历史产物。它将独立内容卡、候选范围和全部下游引用作为同一次文档编辑提交，保留用途、引用身份与输入排列。服务端校验同模型的成功结果及历史来源，并将固定证明与文档修订一同保存。撤销删除模型或独立卡时，用该证明核对原固定关系并保留独立编辑过的内容。接收模型换型后保留的候选，可沿原用途迁移到独立内容。撤销迁移仅恢复证明覆盖的接收卡、用途和位置。扩大范围或新增用途仍须校验当前模型能力。固定中间项时，普通内容边可保存经历史输出核对的原用途边和位置作为排序锚点。原边删除后，独立内容按自己的输入顺序继续参与候选。

固定后的内容使用普通内容卡身份和编辑规则。旧批次不会重新投影为关联卡，同位置再次生成时显示新的关联卡，原下游路径仍指向固定内容。用户显式连接模型时，展开图中仍作为候选提供的已固定位置从模型卡直接画线，可单独断开。撤销恢复当前结果的关联，重做恢复当时捕获的独立内容。两个操作均沿用现有文档历史，不改写结果集、历史运行或已提交任务的输入。

关联结果卡随所属模型移除。单独删除时提示先断开更新线，固定后的内容按普通卡片删除规则处理。批量选中模型和其关联结果时，按真实卡片提交一次删除，并检查最终保留的消费者。保留的引用会阻止删除并定位下游，所选的模型仍受活动运行保护。允许删除后，连线、输入顺序和编组同步更新，布局缓存清理对应位置。撤销恢复文档关系，关联结果继续按当前正式输出投影。独立内容及运行历史按各自生命周期保留。

## 图片执行和归档

图片模型的预检、受理、取消、历史与结果继续消费统一运行控制器和每画布一条 SSE。实际引用按接收端顺序形成输入子集；重复引用同一输出只提交一次，不同来源即使指向同一文件也保留各自位置。模型能力明确限制的数量及重复文件在预检诊断，不静默截断或按文件去重。图片公开参数为卡片的数量、画幅与分辨率配置。

Task 私有配置固定媒体提交及后续每次查询的模型、供应商路由和认证；受理后的模型管理或画布修改不改变本次请求。已保存图片逐项登记 TaskOutput，只有全部预期图片归档成功才建立完整 ResultSet，并在当前实际依据仍匹配时整体替换当前指向。预览位置仅为本地显示状态，所有输出位置仍供下游选择。旧成功结果保留在该画布历史中；失败、取消或下载／归档失败只列出已持久保存的未完成成果，不建立正式结果集，不清除旧正式输出。

终态媒体以 `canvas_history` usage（`canvas_id:node_id:ordinal`）保护每个已归档文件。用户可预览历史与未完成图片，并显式另存独立内容卡；来源校验同时核实终态、位置、文件和未完成标记。画布生命周期清理由对应删除边界释放自身历史引用，不能以清理通用 Task 历史替代。

删除画布在同一数据库事务中清理编辑文档、运行记录和本画布的 `canvas_content`、`canvas_run`、`canvas_history` 使用关系；不请求删除媒体字节。其他画布的独立内容、其他项目的资产使用和项目上传保留不会被此操作释放。项目删除继续由活动运行保护及现有外键级联清理本项目关系。上传保留仍须显式清理；该新增清理入口在数据库提交后返回成功，并在文件服务原有锁与引用校验边界确认无其他使用者后单独登记文件删除。页面对删除或释放保留的失败展示真实拒绝原因；网络结果未知时提供重新读取核实入口，不凭局部响应宣告全部引用已释放。


画布输出解析通过 `CanvasOutputContext` 在单次操作内复用已验证文档、卡片／边索引及保序入边。出口和候选解析每次显式接收当前模型结果与草稿模式，不缓存动态出口、诊断、文件状态或模型配置。读取、编译与依据计算共享该结构上下文；预检与提交分别建立上下文，保存中的新文档与旧画布分别处理，Worker 发布及历史快照恢复各自使用对应阶段的数据。上下文不进入快照或依据哈希；文件可用性、配置读取与锁、结果新鲜度及诊断顺序仍由原流程核实。单卡输出处理器只接收本卡、已采用输入和已有结果，不获得整图或数据库。

## 视频用途与单视频执行

共用 Composer 的四条本地系统指令为 `/首帧参考`、`/尾帧参考`、`/关键帧参考` 和 `/主体参考 "名称"`。选择和手写均保存为相同的 `instruction` 片段及独立配置块。手写内容在 Enter／Tab 或失焦时按固定语法形成指令，连续引用保留顺序，遇到正文结束；不调用 LLM。正文可与配置同行。缺引用、缺主体名、重复首尾帧、错误类型、超量及不支持用途／组合均可保存，预检按片段及引用路径定位并阻止执行。

视频详情按选定模型的真实用途提供独立采用、取消、排序及主体分组；普通候选连接不采用或执行。实际用途、顺序及可选 `subject_name` 均以 `input_bindings` 为权威，正文和指令只通过绑定身份参与；旧主体指令读取时规范化名称到绑定；旧v2曾跨主体名称共用同一binding时，按原明确指令拆分用途，保留多组及正文隐式代指，不任选一组。独立主体采用必须明确填写分组，缺失／清空返回绑定定位诊断。首尾帧各至多一项，关键帧按绑定顺序进入 `VideoMediaInput.frames`。主体绑定按规范化名称合并到 `subjects`，同一组内重复来源只一次；不检查素材人物冲突。同一素材仅归属一个显式组时，正文对应引用替换为 `@主体名`，保留周围正文。无显式组或归属多组时，直接引用使用按实际媒体子集编号的隐式 `@mediaN` 组，不任选一个命名组。指令引用本身即为实际输入，无需正文重复。展开文本中的命令、引用及普通 `[media:1]` 字样从不再次解析。

视频编译在 `compiler.py` 内通过 `build_video_inputs` 一次计算标准媒体 DTO、正文主体代指及命名图片的用途位置，供正文与映射共同消费；它仅接收规范化后的模型卡和实际媒体，不读取数据库或产生诊断。候选代号按模态从 1 编号，总体 `media_position` 按实际媒体从 1 编号，`purpose_position` 按用途内图片从 1 编号，DTO `ordinal` 按关键帧或主体组内图片／视频混合顺序从 0 编号；主体组内来源去重，重复关键帧保留。缺失来源的显式名称仍参与自动代指避碰。旧绑定规范化继续由 schema 处理，错误用途、能力限制及来源失效诊断仍在原编译流程按既有顺序和定位产生。

视频 Adapter 的内部用途事实集中在 `core/integrations/video_adapter_usage.py`，由画布能力投影和供应商请求构造共同消费；帧枚举仅去空、保序并保留重复项，不产生诊断。OpenAI 单图选择优先级仍为关键帧、首帧、尾帧，画布独立收窄为首帧；可灵保留模型、关键帧与 Turbo 帧拒绝的原校验顺序。各供应商的端点、媒体格式化、模型能力覆盖和错误行为仍由原流程负责；保存与编译诊断保持原定位及顺序。场次单元的参考能力读取本次保持既有实现。

画布依据 Adapter 事实收窄开放用途：OpenAI 只开放首帧；Vidu 接入命名图片／视频主体及帧用途；火山接入首尾帧及关键帧；可灵按已接入模型限定帧用途。画布统一禁止命名主体与帧参考组合，能力覆盖配置不能扩大真实字段支持或突破画布策略。公开参数仅模型、画幅、时长及高级随机种子，不提供音频参考、时间码、通用视频编辑或续写。

每次视频任务仅收取一个输出，直接保存下载的完整字节。提交与每次轮询消费 Task 的固定有效路由和认证；运行中修改模型或供应商配置不改投既有任务。统一结果集、历史、终态事件及 `canvas_history` 文件保护与图片共用。成功后依据不符的成果仅入历史；失败／取消保留已存成果并标记未完成。显式另存视频内容卡固定来源和文件引用，不改写原运行或当前结果。原生视频预览保留完整文件及音轨；历史记录同时展示受理时固定的 `video_media` 用途、分组和顺序。帧用途仅接受图片，视频转帧等隐式转换在预检返回绑定定位诊断。


## 叙事与镜头设计

`direction.narrative` 保留观察视点、信息变化、人物关系变化、关键转折与待确定问题；`direction.beat` 保留行动目标、阻碍、预期变化与必须呈现内容；`direction.event` 保留动作或变化说明；`direction.shot` 保留叙事作用、可见结果及预计时长。所有字段沿用 `ReferenceDesignField` 的状态、用途与来源，本卡范围和阶段独立保存，默认完整设计输出。预计时长不代表真实媒体区间，生成不自动确认节拍、镜头或版本。

节拍、事件和镜头分别通过 `beat`、`event`、`shot` 出口发布 `NarrativeReferencePayload`，只含类别、稳定身份与名称。已建立身份不可改绑，同类名称和独立身份唯一；普通正文名称不会建立身份。镜头可直接选择多个参与对象、覆盖节拍、关联事件与调度依据；覆盖节拍与运镜阶段复用稳定ID排序交互，支持拖动、Ctrl/⌘+Shift+方向键和原有上下移动；覆盖节拍用已采用 `InputBinding` 数组顺序排序，保存重开保留顺序，不维护第二份顺序或据此自动执行；节拍可选择多个关联事件。对象类别、直接候选与来源有效性在保存时校验，未采用候选也进入统一 DAG。摄影所属镜头沿相同 `shot` 契约接入，不以完整场次计划为前提。

人物表演的所属节拍与接收事件、调度的变化事件、镜内活动的触发事件保持不同用途。完整输出的 `narrative_relations` 记录直接身份及用途，模型消费本卡及已采用身份关系指向的完整节拍、事件、锚点、调度等明确依赖；示例媒体不自动传递。参考画面与预演通过固定素材关联维护，不代表实际覆盖或自动执行。验收依据通过验收卡的 criterion 连线建立，不建立反向输入。
四类叙事卡复用共享卡面与预设优先 A 编辑器；名称与可展开的显式关系在两种模式均可编辑。预设只填写声明的通用设计指令，不改变身份、名称、关系、预计时长或待确定问题。字段候选与引用沿用画面设计及表演调度规则，有效字段引用的图片／视频随整卡采用携带，明确采用的关系依赖由编译闭包传递，本地示例不自动携带。锚点和其他设计正文统一整卡引用，编译递归传递有效依赖。旧文字中的代号保持字面。镜头可见结果只有有效引用时仍提供原有画面目标，不自动抽取视频帧；预计时长不控制模型生成时长。

## 摄影范围与图片画面目标




图片卡独立保存 `frame_targets[{binding_id,state_id}]`，仅定位已采用导演输出声明的 `frame_states`，不增加或拆分采用记录。运镜卡起始／结束画面和明确创建的运镜阶段提供目标；人物表演与镜内活动从现有 `exit_state`、镜头设计从现有 `visible_result` 提供可选目标，不解析动作自由描述或新增通用阶段。明确多状态运镜用于单张静帧时必须指定目标，视频仍可使用完整过程。目标被清空或删除时须替换或取消；完整设计文字与字段仍保留。

结构化景别可声明明确目标和状态，只有同目标、同状态且必须同时满足的事实设计／约束单值冲突阻止相关生成。图片目标属于另一明确状态时不将其他状态当成本张图的硬要求；提议、待确定、背景和普通文字不升级为冲突，不自动筛选采用范围。模型能力预检仍独立执行；六类画面设计预设通过专用可视化选择器编辑，示例不扩大模型能力。

同卡保存修订刷新期间，前端保留上一已保存候选、输出和正在编辑的控件，标明原修订；不因短暂加载卸载目标选择器。切换卡片不保留另一卡数据，旧响应不能覆盖新范围。


运镜高级编辑将 `phases` 展示为“运镜关键画面”，与原起始、结束字段共同使用单行序列导航和单项编辑，提供全部画面选择。关键画面编辑横跨整宽，下方短横线轻分隔后以两列直接展示运动方式、路径、速度与触发条件，窄屏单列。关键画面列表独立横向滚动，导航行右侧固定添加按钮；限制已填写时显示状态点，引用定位自动切换画面。范围、制作环节与条件随完整设计传递，不自动筛选画面。关键画面名称、排序与当前编辑选择不改变稳定阶段身份；字段引用、构图定位和编译契约继续使用原身份。 设计卡详情不重复展示常规保存进度，统一沿用画布状态，保留异常与只读反馈；设计参数标题及漏斗位于内容滚动区外。运镜分隔线上下间距为4px，画面输入区随可用高度在120–140px间收敛。桌面阶段区与参数区使用稳定高度，切换画面只替换阶段正文，短内容优先首屏完整，长正文局部滚动；窄屏参数单列并保留必要正文滚动。中间画面名称双击或F2原位编辑，Enter或失焦确认、Escape放弃；新增后直接改名。Tab支持拖动和Ctrl/⌘+Shift+左右键排序，排序不切换当前画面；标题左侧常驻12px铅笔提示，与文字间隔4px，无独立按钮或焦点；鼠标、触摸双击标题或F2改名，拖动后取消双击识别。删除为贴近右上边缘的10px悬浮角标，24px热区不遮挡标题，编辑名称时隐藏，是常规32px图标按钮的局部尺寸例外；删除角标悬停、聚焦或触摸选中时显示，通过浮层脱离滚动容器，不占Tab宽度，不增加Tab高度。起始与结束固定；被构图或图片模型定位的画面删除前提示影响，确认后保留失效定位并阻止相关生成，不自动改绑；普通删除沿用撤销。全部画面入口仅在Tab溢出时显示在导航行。

## 创作要求与验收关系

`direction.creative_control` 保留控制程度、发挥范围、保持项与待定事项；`direction.guidance` 保留优先级、参考要求、声音策略与禁止项；`direction.criterion` 保留稳定 `criterion_id` 和可观察标准。三类均使用 DesignField 的用途与状态，发布完整设计文本，不解析自然语言或检查图片真实性。参考要求和声音策略不自动建立素材输入或音频生成。

验收要求卡不再声明通用 `effect_object` 输入或提供“作用对象”选择。素材／描述与设计来源通过合法文本、图片或视频端口连接为候选；标准可直接写普通文字，需要稳定来源时在字段中明确引用完整内容。只连接、预览或名称相同不会采用来源。描述／设计不支持来源字段级采用，媒体仍选择具体输出，不扩大为来源全部素材。创作控制、生成指导、不可改事实与表演规则也已移除通用作用对象；一般对象通过各自字段的完整来源引用表达，不新增随设计附着机制。

验收要求另发布 `criterion_reference`，仅提供身份与名称；设计卡自身输出保留该关系。验收卡连接人物表演、镜头、机位、光影、焦点、构图和运镜时只兼容验收关联，连线直接采用；验收卡不再作为任何设计字段的文本引用来源，其他设计卡不新增验收端口。解除关联同步断线，可通过画布撤销。验收卡直接连接模型的完整文本输入仍保留。

验收区独立放在素材候选区下方，跨预设／高级设置保持同一区域；有已关联要求时候选行添加按钮后固定显示12px辅助文字“验收 N”与10px展开三角，位于提示之前且不随素材列表滚动，默认收起；素材列表独立横向滚动。展开提供缩略卡列表和下方单卡只读业务详情，首次查看第一张，浏览不保存或产生撤销记录。关闭重开恢复收起；只读画布可以浏览和定位源卡，不能解除关联。无关联时隐藏整区。

后端读取不再清理旧验收候选、字段片段或用途边，也不推进 revision；保存按当前结构及引用规则校验。历史记录不改写；含旧冲突用途的固定输入在供应商请求前明确拒绝，须使用当前画布重新提交。

后端不再将18类退役通用对象用途转换为候选，也不补写字段引用；当前合法用途和字段引用继续按原规则校验。旧本地恢复、撤销与重做产生的退役结构保存时拒绝。包含废弃绑定的未执行／等待／重试快照在模型请求前明确失败，已发起请求和完成历史保留原依据。

模型实际采用设计卡时，编译自动附带其直接关联的完整验收输出，无需额外画布连线或持久模型绑定。完整输出保留名称、标准及其明确引用、用途与状态、范围／条件／阶段及来源；标准正文明确引用的文字与图片／视频沿用现有解析、素材用途和模型能力检查，独立正反例不携带。同一要求按稳定输出身份去重，设计输出中的关系保留各使用来源。未采用设计不扩大模型输入；完整依赖闭包只追踪已采用关系和有效字段引用，不遍历候选祖先。空标准或不适用字段保持现有省略规则，失效的有效字段引用阻止运行。

标准修改影响下一次生成及当前成果依据判断，不自动执行模型；新运行快照固定验收正文及其动态来源，不追加后续编辑内容。验收关系不代表审查通过、真实覆盖或剪辑采用。验收卡只读列出实际使用方；所有连线继续受统一 DAG 约束。

创作控制、生成指导与验收要求不再维护正反示例；候选预览不代表采用，需要影响生成时在允许的字段中明确引用。后端拒绝非空退役示例记录，素材文件与当前有效用途保持原保护。


## 空间规则、连续性与事实

`direction.space_rule` 保留空间依据、可拍区域、轴线、尺度和适用范围；可选单个所属空间，以及明确作用对象。`direction.continuity` 保留空间／造型／手部与道具／环境／摄影／对白声音分类，前态、变化、后态、后续约束，可选单个参与对象与关联事件。`direction.fact` 保留不可改事实、来源依据、范围、制作阶段和条件。三个类型通过专用结构化文本编辑与 `DesignTextPayload` 完整输出，仍使用既有字段状态、用途及直接关系机制，不建立场次、章节或完整工作单前置要求。

空间规则的作用对象仍可明确接收结构化对象、锚点、调度、节拍、事件或镜头引用；不可改事实已移除此通用用途，改由事实与来源依据字段明确引用完整来源。完整设计被模型采用时，其有效字段引用和明确业务依赖沿统一依赖闭包携带，候选不自动进入生成。空间／参与对象／事件分别校验字段资格、直接来源与数量。候选未采用不产生关系，全部候选继续统一无环。约束正文和证据真实性不由系统推断；纯文本不纠错，提议与待确定也不升级为已确认硬要求。已知结构化摄影目标／状态冲突继续由统一编译校验处理。

连续性有效前态和后态分别声明 `field:before`、`field:after`；两者同时存在时，图片生成须明确本张图目标，完整采用仍包含前态、变化、后态与保持项。空间规则、连续性和不可改事实不再维护固定证据与前后态素材记录；素材由普通候选预览，明确字段引用后才参与生成。连续性与不可改事实的音频候选仅供本地试听。

## 画面风格与可视化预设

独立 `direction.style` 卡通过 `StyleDesignFields` 保存风格方向、视觉特征、材质、色彩及自定义说明，以 `DesignTextPayload` 完整设计输出；不开放摄影局部范围。风格图册提供原创建模示意、效果对比与大图，摄影五个入口提供景别／构图示意、机位对比、运镜短视频、光影与焦点示意。它们都是意图说明，不是已接入模型的专用控制或生成质量保证。

画面风格编辑器默认进入 A 预设图库，左图库与右选中预设详情并列；右上高级设置直接显示同一份风格参数，无设计参数／参考与关联 Tab、更多参数或独立示例管理。默认无选中预设；应用后留在图库，撤销复用画布文档历史。桌面图库独立滚动，头尾和详情固定；高级参数及窄屏内容使用独立滚动。标题工具和动作通过保留的卡片容器宿主呈现，保存、焦点、只读及关闭仍属于既有画布生命周期。摄影尚沿用原分区编辑器。

预览与对比只更新选择器本地状态；明确“应用到当前卡片”后，预设成为本卡可编辑结构化字段。摄影预设只修改当前区域声明的字段，关系、范围、其他区域及自定义说明保留；不保存隐藏预设对象或第二份设计。保存重开后继续使用普通字段编辑。独立风格仍按完整设计采用，摄影沿用声明范围。

内置 SVG 与三秒 MP4 是原创几何示意，不是项目文件，也不是媒体输出。选择预设不建立素材绑定或模型采用，不传递示例中的主体、场所或媒体。已保存的旧风格示例仍按直接 `image_example`／`video_example` 合法来源固定关联并接受项目归属、可用性与删除保护，新风格界面不再提供独立示例配置；这些示例同样不随风格文本跨级传给模型。普通媒体输入须直接连入并明确采用；设计明确依赖的素材和已选固定参考随依赖闭包携带。


机位、光影、焦点已分别成为 `direction.camera`、`direction.lighting`、`direction.focus` 独立类型。每类只接受本类字段，以完整 `DesignTextPayload` 输出，并保留所属镜头、验收依据、适用范围与来源；焦点额外保留关注／焦点对象关系。它们复用风格的 A 预设优先界面，没有摄影分区、更多参数或独立示例。新增类型的示例列表不接受内容，不复制摄影整套字段；预设仅合并其声明字段，未声明参数与关系保留。旧摄影卡及其分区入口已退出；后端不再转换旧摄影文档。

## 权威类型目录与输入边界

`/{canvas_id}/catalog` 核实项目及画布归属后，提供 `CanvasCatalog`：卡片类型／版本、产品分组及导演子类、四种内容模态、真实输入／输出端点、接受值种类、采用单位、可定位设计字段和摄影五入口。目录从 `CanvasDocument` 的实际卡类与端点声明建立；图保存校验与目录使用同一值种类兼容规则。目录逐卡声明真实类型及添加入口，旧摄影的尚未替换入口仍属于一张旧卡；关注／焦点为作用对象的具体用途，30个物理输入标识覆盖28类逻辑端点。

前端通过 generated client 获取目录，并由 `CanvasCatalogContext` 提供给画布与各专用编辑器。目录核实前或读取失败时不开放卡片编辑，失败可明确重试；不以本地端点表静默回退。专用表单、模型能力与实例输出范围各自保持原职责，不将静态目录用作万能表单或生成能力承诺。`CanvasResolvedOutput.modality` 限定文本、图片、视频、音频；对象／事件／对白等通过独立值种类表达关系，不增加第五种内容模态。缺失业务引用保留文本模态的不可用占位。

创作依据的 `basis` 明确输出同时保留正文和只读来源、选区定位；编译正文不把定位元数据当作创作指令。通用导演素材通过本卡正文明确引用；普通设计卡不再保存独立正反示例、字段定位及媒体区间。摄影及连续性的专属字段限制保持有效。

导演详情提供可折叠候选连接管理，与直接采用和素材关联分开。设计来源断开按整对卡片检查全部用途；资产候选仍按来源出口及接收用途精确保护。删除来源仍检查所有有关实际采用，不静默清理或替换绑定。


模型输入框明确选择 `ExperimentComposer` 的 workbench 外观，消费宿主共享 tokens 与工作台按钮；默认实验页面外观不变。引用往返时仅增加 `binding_id` 不重建编辑 DOM，按稳定片段身份同步最新绑定元数据；显示标签确实变化时才更新文本，保留继续键入、组合输入和复制选择。预检诊断关闭操作弹窗后再打开相应详情、聚焦稳定片段；不在底层仍 inert 时抢焦点。候选管理优先显示来源自身名称／标题或权威目录人类标题，短ID辅助区分，完整身份不从协议或历史删除。


## 只读堆叠与成员保护

画布组织记录以 `kind=group` 表示可编辑视觉编组，以 `kind=stack` 表示只读堆叠；默认仍为 group，旧 `collapsed` 标记不自动解释为堆叠。两者保持扁平成员归属，不提供集合输出。堆叠沿用成员卡片身份及原相对位置，整体移动仅平移成员；解除后恢复成员多选。整理布局也将组织视为整体，保留成员相对位置。

堆叠默认呈现叠卡、当前封面与总数，悬浮或聚焦可解除；点击进入只读查看层，正文、图片放大及媒体播放可用。查看层关闭只退出阅读，仍保持堆叠。成员编辑／诊断入口受堆叠门禁，诊断定位堆叠并提示先解除。内部成员线收纳隐藏，外部线保留原成员、方向和用途，在堆叠边缘落点；不生成集合端点。

服务端保存检查仍保留的堆叠，禁止修改或删除成员、成员输入顺序和入线；删除外部来源若会连带断开入线，同样返回 `STACK_READ_ONLY`。显式解除后恢复正常编辑。外部来源自身内容与外部接收卡输入仍可更新；成员模型预检须先解除。已受理任务及输出发布独立于收纳状态，继续更新，不冻结结果或改写历史。


### 快照中的运行受理顺序

画布运行快照按受理时事件头的提交游标排序，不依赖秒级创建时间及随机UUID的字典序。该序号保存在节点私有执行快照，属于运行观察元数据，不参与生成依据哈希、供应商输入或公开DTO；同一运行的节点具有相同受理序号，事件日志裁剪后仍可恢复新运行的先后。旧运行缺少该元数据时使用尚保留的首事件游标；若旧事件已全部裁剪，只有原时间与ID可回退，不能据此声称精确还原同秒历史先后。

### 画布手势与键盘

已选卡片拖动时保持多选集合和相对位置；拖动未选卡片时切换为单选。靠近画布边缘时自动平移，卡片跟随指针；Escape 取消整次移动并恢复起始视口，意外中断保留最后位置。移动和连续方向键操作各记为一个历史项。Cmd/Ctrl＋单击增减选择，Shift＋框选追加；Space＋拖动或中键平移。滚轮围绕指针缩放，拖动中暂停缩放；编辑器滚动不影响画布。方向键移动卡片 10 个画布单位，Shift 为 50；画布空白焦点下方向键平移。加减号以视口中心缩放，0 适应全部；拖动期间包括 0 在内的缩放入口均暂停。

Delete／Backspace 对所选卡片执行整批保护检查并统一确认，受运行、引用或堆叠保护时阻止整批删除。删除只影响画布对象和相关连线，媒体文件保留；撤销恢复文档与原位置。输入框、输入法组词、菜单及弹窗拥有自己的键盘操作，画布不接管。Cmd/Ctrl＋Z 撤销画布操作，Shift＋Z 或 Ctrl＋Y 重做；普通视口浏览不进入历史。生成画布视口禁止容器原生滚动，焦点切换和堆叠显隐不能绕过 transform 改变卡片屏幕位置。

画布视口获得键盘焦点时显示局部键盘操作提示，不给整张画布描边；指针操作隐藏提示。卡片选中及整卡键盘焦点仅描绘正文轮廓，不包围外置标题；独立按钮保留各自焦点反馈，不改变布局。小于 1280px 的编辑器自动模态，以至少 44×44px 的“关闭详情”入口一步退出，不再显示展开／收起；关闭保留输入与选择，内层选择器、菜单及候选仍先消费 Escape。桌面展开／收起与布局保持原规则。

常规编辑器让位约150ms，减少动态效果时直接定位；指针按下、滚轮、键盘操作和窗口失焦可打断，停止后不续移。关闭编辑器及窗口放大不恢复视口。重复点击、输入、保存及生成内容更新不重新让位；连线期间的临时隐藏与真实关闭分开，恢复同一编辑器不触发二次让位；自动让位只改变浏览视口，不进入撤销。取消拖动恢复拖动开始时的视口，保留此前打开产生的让位。常规编辑器可覆盖其他卡片，不推开其他对象；拖动入口仍属于卡片，编辑区不新增拖动把手。手机、复杂导演及主动展开继续使用模态，内层菜单、候选、选择器的Escape优先级不变。


### 右键菜单、卡片剪贴板与封面

生成画布页面统一屏蔽原生右键。空白提供新建节点、粘贴与撤销，不包含重做；卡片标题和展示区提供复制、复制副本、设置为封面、下载与删除。编辑器、输入、工具栏、弹窗、连线、编组和堆叠不穿透触发菜单，文字仍使用原有快捷键。右键新建按“新建节点→八类分类→节点”最多三级组织，共用左侧目录、顺序和摄影创建入口；搜索只保留在左侧添加面板。菜单使用屏幕坐标、边缘避让，不随画布缩放；菜单内列表独立滚动。外部点击及外部滚轮只关闭菜单并消费事件，Escape逐层退出，恢复卡片或画布焦点；拖动、框选与连接期间禁止开启。Shift+F10／菜单键及卡片“…”提供替代入口，原有多选、连接和展开编辑保留。

右键已选卡片保留集合，未选卡片切换为单选，但不切换编辑会话。复制与副本都要求自身没有真实引用（包括失效绑定、名称、图片来源、导演关系）；候选及自身媒体不构成限制，被其他卡片引用也不阻止。复制保存配置快照，手动粘贴才创建；副本立即创建且不改写剪贴板。新卡使用新卡片及领域身份，保留名称、正文、模型参数和自身媒体，不携带连线、候选顺序、组或堆叠归属及运行成果。批量全部合格才执行，保持相对位置。剪贴板按项目存于当前标签页会话，支持刷新与同项目跨画布，不跨项目或同步其他标签页；粘贴前核实文件可用性及项目归属。

关联结果卡使用同一复制入口。复制时捕获当前可用的正式结果正文或文件，粘贴和复制副本均创建普通独立内容卡。副本使用新身份，沿用文件归属及保存校验。复制不携带更新关系、连线或正式生成来源，原结果和下游继续按既有关系更新。模型在复制后发布新结果时，剪贴板仍保留复制时的内容。结果缺失或不可用时提示原因。

右键新建及粘贴以右键点为落点，键盘粘贴使用视口中心；副本向右下偏移32画布单位，连续操作错开。创建后只选中新卡，收起旧编辑器并保留会话；完全不可见时最小平移，不缩放。新建、粘贴、副本、删除及封面各为一个撤销步骤，批量整体撤销并恢复位置。复制、下载、菜单及视口平移不进入内容历史。编辑区快捷键始终归文字，菜单拥有当前键盘事件；只读、运行、删除及堆叠保护仍适用。

`CanvasDocument.cover_file_id` 固定一张图片文件，不绑定卡片的当前结果序号。单张直接设置，多张单选；多选卡片禁止设置封面。画布列表显示缩略图，刷新保留，文件不可用使用占位。封面由服务端校验图片类型和项目归属，并以独立 `canvas_content` 使用记录保护；删除原卡或重新生成不替换封面，也不改变模型生成依据。

下载只消费当前正式输出集合，不含候选或全部历史。单项直接下载，文本为UTF-8 `.txt`；多项打开默认不选的选择面板，可多选、全选并打包ZIP。旧正式成果标明旧状态。面板固定打开时的输出身份，后台新成果不替换所选；失败保留选择可重试，打包失败不下载不完整压缩包。

菜单外部关闭只消费同一主键点击，右键重定位不留下点击拦截器。卡片快捷键仅由画布本体、卡片及卡片布局移动入口接收，编组、堆叠、连线及独立操作控件不因处于视口内部而继承。媒体校验期间允许平移和缩放，粘贴提交时按最新视口计算键盘落点及可见性；右键显式世界坐标继续保留。下载选择复用 AntD Radio／Checkbox，二进制经 generated client 的附件传输支持读取。


右键菜单采用 AntD Menu 的独立菜单语义，而非工作台动作按钮。主菜单约220px，子菜单240px，桌面行高40px、触屏44px；禁用项仅弱化文字，原因通过提示与可访问描述表达，不增加第二行。主菜单在新建项后分隔，卡片菜单共用外观。首次显示前完成测量，桌面子菜单独立定位、必要时向左或向上避让，不改变父菜单尺寸和锚点；放不下时只滚动该级，使用暗色细滚动条。

悬停约120ms展开、离开父子区域约200ms收回子级；允许指针跨越间隙，点击与触屏同样可进入。视口宽度不足760px时，在固定宽度的同一浮层逐级进入，顶部“返回上一级”保留各级滚动位置并恢复父项焦点。左右键进入／退出一级，Escape关闭最深一级，根级退出；Tab关闭整组并恢复原触发焦点。菜单按键不传给底层编辑器，只读禁用状态适用于所有层级。


### 前端文档操作

`canvasOperations` 集中卡片更新、删除和候选连接的业务保护及文档变换，复用目录连线规则与实际引用保护。模块不持有编辑状态；成功返回完整文档，拒绝返回原因及必要定位信息。Graph 保留确认、反馈、焦点和几何，成功的复合操作只向现有编辑器提交一次。新建来源与摄影复制的连接步骤复用相同规则；旧参考图来源清理仍由独立 effect 触发，不合并其历史项。保存、运行、布局缓存及快照撤销保持各自职责。

### 独立景别与构图

景别与构图使用独立内容身份，限定所属文字字段与结构化景别，模型仅整卡采用。公开设计输出保留字段状态、用途及景别结构；普通连接不自动采用。编辑器复用预设优先的 A 容器，预设与高级参数修改同一份数据，不自动关联运镜或继承其他设计内容。构图与运镜在高级设置保留范围／来源、明确对象、所属镜头及验收关联；构图输出保留这些明确采用的关系身份和必要映射，不展开关系来源的正文或媒体。旧摄影类型已退出，不作为构图卡别名。

### 严格文档格式与历史执行保护

后端只接受当前画布文档结构，不再自动升级 schema_version、拆分 content.object、转换旧参考卡、清理摄影卡或退役用途。旧格式保存返回原有结构或端点诊断，不产生文档、修订、保护或回执写入。CanvasStore.get/list 不再执行清理或更新 revision。身份账本按原值保留，遗留 content.object 墓碑继续阻止卡片 ID 被复用，不推断其类别。

存量旧编辑文档须在上线前显式核查并处理；读取不会修复数据。原请求摘要、保存回执、历史节点、结果集和事件不做迁移。snapshot_support.require_supported_snapshot 直接检测原始历史输入，Worker 和等待节点恢复共用，保留示例、验收／对象、摄影诊断优先级，并拒绝旧对象和参考结构；检测不调用文档转换或改写快照。

实际引用旧设计的模型保留 `missing_designs`，公开编译返回阻止运行的 `DESIGN_BASIS_MISSING`，用户显式处理后解除。仅候选连线不虚构缺失采用。冻结的旧摄影／示例／局部采用依据不能套用当前文档清理后继续执行，等待节点返回 `LEGACY_DESIGN_SNAPSHOT`；历史记录保留原事实，其他有效运行继续可读。旧摄影输出仅保留不可执行的历史读取结构，不再发布或投影为新设计。


独立构图卡的 `frame_target` 整体关联同画布运镜卡；起始、结束或阶段只表达构图作用位置，不截取运镜卡的局部内容。编译带入完整运镜设计及有效依赖；画面定位仍校验状态有效性和同目标景别冲突，并参与环检查。运行快照冻结完整依赖，后续修改不改变历史任务。

## 画面设计与表演调度参数引用

画面设计六类字段、运镜阶段画面及表演与调度七类文本参数使用 `ReferenceDesignField`。可选 `document` 是带稳定来源身份的文字／引用片段；存在时它是正文权威，普通 `text` 只作旧文字兼容与卡面投影。其他导演 `DesignField` 不扩展，设计字段不复用模型的 `input_bindings` 所有权，也不因编辑某字段移除另一字段的引用。模型指令的剪贴内容进入设计时展开为字面参数及稳定引用，不配置接收模型用途。

画面设计六类与表演调度七类提供直接文本、媒体与明确关系候选端点，仍服从目录资格、项目与画布归属、DAG 及稳定输出规则。来源仅来自已连线实际输出；设计正文允许整卡互引；缺失和跨画布引用以保留草稿及可定位问题表达，不换绑同名内容。字段文字只展开一次，展开后的代号或指令不再次解释。用户输入的未确认代号保留并诊断，转义内容按字面处理。

`design_field_references` 分别枚举所有保留引用及当前有效引用：前者用于删除／断线／名称切换保护，后者用于本次输出。`DesignTextPayload.material_references` 仅声明有效字段实际引用的媒体，携带稳定来源、字段身份、文件、结果集及可用性；`reference_issues` 只包含有效字段问题。阶段使用稳定阶段 ID 定位；未引用候选及停用字段不扩大实际媒体依赖。图片与视频接收端只消费明确采用设计中的有效素材声明；其他模型消费设计媒体时明确阻断，不能只消费文字而静默丢图。

编译在依赖展开后由 `input_preparation.prepare_inputs` 集中准备原始引用、候选身份索引、实际采用、携带素材与视频用途。准备结果仅在此次编译内使用，不写回文档；正文与诊断编译消费同一结果。设计字段标签、实际媒体位置和视频 DTO 序号保持各自语义，依赖展开与媒体标签重渲染仍按原阶段执行。

图片模型采用上述十三类设计时，设计有效参数中明确引用的图片进入实际编译媒体列表，无需补建模型至原素材的边或独立采用绑定。直接采用与设计携带按稳定输出身份合并，保留各设计／字段来源；不同身份即使对应同文件也不静默合并。最终提示词从结构化字段引用重建实际图片位置，设计局部代号和字面文字不会按字符串替换。导演设计明确列为主要依据，模型正文列为补充说明，结构化冲突仍诊断。

模型输入管理显示实际携带素材及来源定位；移除通过修改设计引用或取消整卡采用完成。候选资格仍要求真实直接连接，携带路径不授权额外的未连线正文引用。合并后的类型、数量、重复文件与有效性统一校验；图片不支持的视频／音频引用明确阻断。视频以 `design_media_uses` 保存稳定来源对应的明确用途、顺序与主体名称；这是接收方式配置，不是新候选、设计引用或额外连线。仅实际携带来源激活配置，移除最后引用或整卡采用后保留的配置不产生输入。直接采用的有效明确用途可以复用；同源同用途／规范化分组去重，同源不同用途保留。缺用途、空主体分组、错误媒体类型、数量超限及不支持用途／组合均定位到接收端配置并阻止运行；视频不猜首帧或主体名，不把音频隐式转换为视频。最终视频 DTO 与来源列表参与依据摘要及固定任务快照，预检后更改有效用途使预检过期，提交后的修改不改变既有任务。

执行依据冻结直接输入及已采用设计的完整有效依赖闭包，包含字段引用的文本模型结果，恢复时不读取后来变化的上游结果。当前成果过期检查先解析这些明确依赖的模型结果；实际相关来源变更会传播，未引用候选不扩大依据。图片真实任务参数消费规范化媒体列表，并复用既有文件占用和结果集保护。


表演与调度复用画面设计的 `DesignPresetEditor`、`DesignScopeEditor`、字段引用及素材携带流程。六类默认浏览过程／路径预设，空间锚点直接编辑位置及参考图标记。预设只写声明字段，不自动创建对象关系或引用；应用、撤销、只读和会话恢复共用原机制。关系控件在预设模式可操作；高级设置显示真实参数、状态／来源开关；仅空间锚点保留参考例图及图片标记。七类卡面共用有限尺寸、用途图解和最多两行真实配置摘要，关系、特殊状态、范围、延迟、空间锚点的例图及标记也参与配置判断；配置不等于可运行。

七类参数仅支持图片／视频素材携带，音频不新增携带能力。人物、场所描述文本沿用现有正文展开，命名参考图沿用名称／角度消歧及具体图片映射；引用不推断参与对象等关系。示例关联、反例标记和候选连接本身不触发携带，正文明确引用同一素材才按普通参考输入处理，不从自然语言推断负向用途。

锚点与其他设计来源统一整卡引用，接收端字段只决定引用位置，不选择来源字段。编译保留引用标记并递归带入有效上游内容；未采用候选及未生效字段不扩展运行依赖，保留引用仍保护断线与删除。真正需要独立复用来源某个字段时，应先评估拆卡，不新增字段级输出。


旧表演调度字段首次进入引用编辑表面时，原文字以 `DesignFieldText.literal` 片段保留，不能因聚焦、失焦或再次保存自动确认其中的旧代号／指令；纯查看不改写字段。实际编辑后该片段标记随参数文档保存，显式候选插入仍建立正常引用。复制进入模型提示词时由模型保存适配层剥离该设计专用标记。七类普通图片／视频候选可在正文中明确引用；仅空间锚点保留本地固定例图。

## 声音与约束共享设计编辑

声音设计两类及连续性与约束六类已接入共享卡面与 A 编辑器。对白、不可改事实直接编辑，其余六类预设优先；预设仅合并声明的通用设计指令，不改身份、关系、制作安排或具体事实前后态。连续性分类独立选择，切换不清空参数与证据。对白正文只允许普通文本来源引用，展开为台词；其余七类允许文本、图片、视频与自足锚点定位引用。锚点及其他设计正文按整卡引用和明确依赖规则传递。

有效图片／视频字段引用随整卡采用携带，无需模型额外连线；选择连续性画面目标不按字段过滤素材，不自动设首尾帧。本地音频仅试听与参考，不能字段引用或模型采用；本地视频区间不裁剪实际引用文件，界面明确完整视频提示。对白版本仍由用户维护，历史运行依据固定；模型采用设计时递归带入明确依赖的完整设计与已选素材。旧字面代号和固定证据保持，引用失效保留定位问题。

设计目录的每项字段附 `default_value`，由真实保存模型的字段默认工厂生成，用于统一前端配置与预设匹配判定，不改设计字段的状态用途语义。全部设计卡的音频引用在字段解析阶段标为不支持；既有保留引用可定位处理，本地示例仍可试听和保留。上传／素材库按真实目标端口连接本地示例，不将音频升级为模型输入。连续性分类仅筛选对应约束预设，不修改正式六岗归属、真实证据或既有前后态。


## 独立设计关联与依赖闭包

设计来源兼容用途唯一且接入模型独立文本输入时，连线即采用；验收关联是唯一兼容用途，连线即生效；其他多用途关系在接收卡内明确选择。独立输入允许多项时逐项追加。资产、所属镜头／节拍、对白依据、锚点等上下文关系保持候选选择和引用保护。单项替换也必须先满足独立增删条件；只有数量唯一不足以自动采用。模型正文显式引用独立设计后，该关系受到引用保护；解除正文引用后才允许断线。卡内解除独立关联与断线同次撤回采用，不留下无效连线。独立关联由连线持有，清除正文引用后仍保留设计采用，直到明确解除关联。

引用以来源整卡为单位，接收正文或字段可以承载整卡引用，不支持来源字段选择。编译从实际采用根节点追踪已生效业务关联、有效字段引用与构图运镜定位，递归传递完整设计及已选资产；候选、示例和不适用字段不进入执行依赖。每个稳定来源只提交一次，菱形路径与直接／间接同时采用不重复导入，保留各接收位置的来源标记及媒体用途。同文件不同输出身份不静默合并。

新独立设计关系保存时自动绑定，旧多用途候选线保留；旧的唯一直接生效用途未采用线清理并提示数量，已有采用保持。编辑来源只更新当前依据，不自动生成；提交快照冻结依赖闭包，历史快照按受理时编译规则恢复。依赖缺失、素材用途未配置或模型能力不支持时定位问题并阻止运行，不跳过内容。


### 设计字段来源与用户设定

设计字段用 `authorship` 明确区分 `user`（用户设定）、`model`（模型提取）和 `unknown`（未标记历史数据）。`metadata_fields` 记录模型实际返回的状态、用途及来源项，保存重开不补出未返回的默认元信息。未知类别为默认且序列化时省略，不根据状态、用途或来源文字推断，不批量迁移历史字段，也不改写已保存的运行快照。本次不新增模型提取入口。

手填正文、增删或替换字段引用、结构化景别及主动应用预设均产生用户设定：有内容时内部为 `fact/design`，清除字段原提取定位；清空正文、引用及结构化值后为 `empty`。聚焦、查看和未改变实际内容不转换来源。预设仅改变其声明字段。用户设定的生成文本保留字段名、正文与完整来源引用，省略内部“事实／设计”标签；提取与历史字段继续保留原生效语义，提取字段保留有意义的元信息。否定与待定意图由用户在正文表达，空白不推断为“明确没有”。

设计字段的状态、用途及定位不提供编辑入口，作为对应输入框下的辅助说明；缺项省略，无信息不占位。历史字段仅展示不同于字段真实默认值的元信息及明确否定／不适用状态，不标注为模型提取。有正文但未生效的字段明确提示“不参与生成”。设计卡级来源只读显示为“卡片原始来源”，局部编辑后保留，不声称当前所有字段仍与原文一致；独立原文依据卡的来源编辑不受影响。

叙事概览、事件与刺激、空间规则、空间锚点不再维护通用 `effect_object`。一般对象在对应正文中用纯文本或完整来源引用表达；事件／锚点稳定身份、所属空间、图片标记及下游事件／锚点用途保留。当前文档只清除废弃用途，合法来源保留为字段候选，不自动补引用；同源其他用途、原有文字和元信息不变。旧固定快照与旧编辑恢复沿用通用对象退役保护，不能恢复该用途。

情境、人物表演和镜内活动已退出通用 `effect_object` 用途；一般涉及对象使用处境、关系、动作、任务等字段的完整来源引用，纯文本不自动设置身份。`participant` 继续明确主体，表演的节拍、事件、对白、验收及镜内活动的区域锚点／触发事件保持。后端拒绝退役通用用途；当前同源主体和字段引用继续保留；保存重开及撤销恢复不能重建废弃用途，旧冲突固定依据按统一规则要求重新提交。

批量删除按最终保留的消费者检查引用保护：一并删除的内部正文、角色及定位关系不阻止整组删除，集合外的有效或暂不生效引用仍受保护。检查继续保留来源类型上下文，独立设计采用沿用原有可解除规则。删除及其相关连线／绑定在同一次编辑中完成，画布撤销／重做原子恢复；共享标准和来源依赖始终按现存采用路径重新计算，最后路径退出才撤回，不缓存最终依赖列表。
五类画面设计的通用 `effect_object` 已退役；字段完整引用承担一般对象依赖。`attention_object`、`focus_object`、所属镜头及验收关系保留原语义，构图画面定位和运镜阶段不受影响。后端不再按类型清理旧通用绑定，退役用途直接拒绝；当前有效采用按稳定输出身份去重。


声音安排的通用声源对象用途已退役；声源通过声源说明、环境声、动作声等字段的纯文本或完整来源引用表达。对白说话对象和本地音频参考保持，音频不新增字段引用。后端拒绝旧声源通用绑定，历史运行与当前有效关系保持。


### 本地示例功能的保留与退役

当前仅空间锚点、对白、声音安排保留本地固定媒体参考。空间锚点的图片标记依赖固定例图；对白与声音安排保留用途、说明及区间，仍不形成模型输入。其余设计卡不再提供独立正反示例或证据编辑：创作控制、生成指导、验收要求、角色情境、人物表演、表演规则、镜头设计、站位与走位、镜内活动、环境活动与留白、空间规则、连续性、不可改事实，以及未开放示例入口的叙事概览、节拍、事件，后端拒绝其非空旧示例记录。视觉六类同样严格拒绝旧示例。上文中的固定示例校验与文件保护仅适用于仍保留该能力的三类卡。

后端不再将退役示例端口转换为普通候选，不在当前卡片端口契约中的旧连接保存直接拒绝。普通同模态候选及当前仍开放的例图能力不变，连接和预览不代表采用。

后端读取与保存不清理退役示例；客户端恢复的草稿也须符合当前保存契约。已完成运行和原始快照保持不变。包含退役示例或端口的等待、排队及重试在请求发出前返回 LEGACY_DESIGN_SNAPSHOT；检测不会修改历史输入。

多字段短参数复用 `design-preset-fields` 与 `design-preset-fields-compact`：桌面两列、窄屏单列，输入框使用一致的紧凑高度与辅助信息槽；叙事概览、节拍、镜头、空间规则、连续性、不可改事实、创作控制、生成指导和声音安排接入。单个主要正文及长表单、媒体区保留正常阅读高度与必要滚动。既无可展示关系、也无失效绑定时不渲染空关系区。

构图的标准景别选择器位于景别字段标签右侧，与文字独立编辑。运镜候选通过浮层明确选择字段引用或画面定位，连线不自动定位；一张构图卡最多定位一个明确画面，已有无连线定位仍在候选中回显。解除定位保留候选；仅用于定位的连线断开前确认，并在同一历史步骤清除定位及连接；存在字段引用时先处理引用。目标失效保留警告及生成阻断，不自动改绑。
