# 资产图片管理

资产管理页中的演员、场景、道具和服装使用统一的图片卡片交互。资产详情页保留完整的图片槽位、提示词和历史结果管理；列表页用于快速浏览和发起默认生成。

## 卡片行为

- 卡片封面优先展示正面视角的已生成图片；没有正面图时展示其他可用图片。
- 没有可用图片时，封面区域展示空状态和“快速生成”入口。
- 卡片的“快速生成”使用该资产的正面图片槽位；如果历史数据没有图片槽位，会先创建正面槽位。
- 生成请求沿用资产详情页的既有流程：渲染该槽位提示词，再创建图片生成任务。创建任务后，任务状态和结果仍由既有任务系统处理。

## 多视角预览

点击卡片封面会打开图片预览。预览弹窗按需读取单个资产的图片列表，避免资产列表加载时为每张卡片额外请求图片。

- 预览默认选择正面图，若不存在则选择任一已生成图片。
- 弹窗只展示已绑定文件的图片视角，并提供正面、左侧、右侧、背面等切换按钮。
- 没有任何已生成图片时，弹窗提供“快速生成正面图”入口。

## 职责边界

- 资产管理页：封面浏览、快速生成、已有视角预览、跳转编辑。
- 资产详情页：编辑资产元信息、管理图片槽位、调整提示词、查看和采用历史生成结果。
