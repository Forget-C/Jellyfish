本计划解决三个问题：试拍关系图与导演设计关系图的体验不一致；当前单元准备混入全计划范围；参考、依赖等操作仍依赖图外分类按钮。目标是让用户围绕当前单元直接看清“拍什么、输入什么、依赖什么、还需处理什么”，并通过节点进入对应编辑。

## 1. 现状与决策

以下为 2026-09-30 改造前的代码事实与本轮决策；落地后的当前行为见第 9 节及架构文档。

| 当前事实 | 目标决策 |
| --- | --- |
| `DesignRelations` 有缩放、平移、聚焦、节点布局和关系操作；全场设计采用 `DesignSceneOverview` 节拍行总览 | 统一详细关系图的节点样式、选择反馈和画布操作，保留设计全场总览的现有结构 |
| `ProductionRelationGraph` 独立绘制固定四列：输入与依赖、生产单元、指令与检查、候选产出 | 拍摄准备改为以当前单元为中心的输入与依赖图；指令、检查、候选详细内容回到对应步骤 |
| “全场关系”实际遍历当前生产计划的所有单元，并挂接其固定来源和产出 | 从当前单元准备区移除范围切换，在计划层提供准确命名的“生产计划总览” |
| 四个分类按钮使用空 `objectId` 打开编辑分类；已有节点点击也主要切换分类 | 节点携带具体对象身份，直接定位编辑项；增加空状态与追加入口后移除分类按钮 |
| 图中参考只显示媒体类型和用途；`ReferenceBinding` 已有文件、人物、资产来源、输入位置和主体分组 | 展示角色／物件／场所、实际输入缩略图与状态，复用既有选图及编辑能力 |
| `productionGraph.ts` 已区分当前草稿和指令的固定单元，依赖绑定计划版本与单元身份 | 保留历史与当前草稿边界，不因换图形表现而重新解释引用 |

首期以现有工作区、资产、模型能力及连续性接口完成前端改造，不预设新增后端契约或数据库迁移。共享范围限定为实际重复的画布交互和节点样式，业务投影与编辑规则仍留在各自模块。

## 2. 范围与成功标准

本轮包含：单元准备图、计划只读总览、参考节点与具体编辑定位、图形交互统一、空状态与窄屏操作、受影响测试和落地后的架构同步。

成功标准：

1. 导演设计与拍摄准备的详细图具有一致的节点、关系标签、选中态、缩放、平移、适应画布和详情交互。
2. 当前单元准备区不再提供“当前单元／全场关系”切换，也不保留四个重复分类按钮；无输入时仍可通过节点完成准备。
3. 点击镜头范围、具体人物、参考素材、落幅或中央单元，能定位对应对象；无需再从整份表单寻找目标。
4. 参考图区分资产关联、资产可选素材与本次已选输入；缩略图对应真实 `file_id`，不自动挑选或发送资产默认图。
5. 计划总览可查看当前计划的跨单元关系，关闭后保留原单元、未保存草稿和画布位置；明确进入其他单元时沿用草稿保护。
6. 历史来源只读，计划固定设计、草稿保存、确认派生、指令与任务来源、人工采用语义不变。
7. 1440、1024、768、375px 下可完成同一准备流程，支持键盘和触屏，不依赖悬停或拖线才能操作。

本轮不包含：新主 tab、跨全部历史计划的无限关系图、通用节点工作流引擎、自由拖线建立业务引用、AI 自动补齐输入、自动绑定资产图片、批量参数编辑、改写历史版本或自动开拍。后续若出现字段缺口，先记录具体需求并修订范围；实际变更接口时按项目规则同步后端、OpenAPI 和 generated client。

## 3. 页面职责与导航

| 位置 | 展示内容 | 操作边界 |
| --- | --- | --- |
| 导演设计关系图 | 镜头、节拍、事件、调度、人物及其他设计依据 | 维护设计关系，不承接模型输入配置 |
| 拍摄准备 | 当前单元、覆盖范围、关联对象、具体参考、必要的外部落幅来源 | 通过节点编辑当前计划草稿；外部来源只读 |
| 生产计划总览 | 当前计划全部单元、覆盖摘要和显式依赖；跨计划来源作为边界节点 | 默认只读，支持定位单元和进入现有拆分／重组操作 |
| 指令与检查 | 所选指令正文、固定输入、检查记录与问题 | 延续现有精确计划／单元／指令身份，不随准备草稿修改而替换 |
| 试拍与候选 | 本单元执行状态、候选素材及审片入口 | 延续明确执行和人工采用流程 |

“生产计划总览”入口放在计划级工具区，与“拆分或重组生产计划”同一层级。首期复用现有计划 Drawer 的容器位置，提供只读总览与明确的重组入口，避免新增嵌套抽屉或主导航 tab。未保存计划可浏览本地草稿总览；重组操作仍遵守现有保存、确认要求。

当前单元准备图只展开所选单元的输入和必要依赖。来自其他单元的落幅显示来源计划、单元与实际片段／落幅身份，不递归展开整场。总览中的邻接、顺序或同名不会产生依赖边。

准备区不再展开全部指令、检查和候选节点；仅在已有真实记录时提供简洁的数量／来源摘要和对应步骤入口。没有记录时不创建虚假的产出节点。多个历史记录仍由对应步骤显式选择，不自动切到最新记录；现有候选跳转剪辑验收与来源追溯能力保留在候选和固定输入详情中。

## 4. 单元准备图与节点动作

中央单元显示编号、模型、时长、画幅和草稿状态；输入与依赖围绕它分组。关系文字区分覆盖、设计关联、本次输入和实际落幅依赖。设计人物等上下文关联不等于模型已接收输入。

| 节点 | 摘要 | 点击与后续动作 |
| --- | --- | --- |
| 生产单元 | 模型、时长、画幅、当前准备状态 | 打开单元参数，可编辑模型、时长、画幅和更多设置 |
| 镜头／动作范围 | 固定设计中的镜头编号、本次动作范围 | 定位具体覆盖项，编辑动作范围；追加、移除覆盖项沿用现有规则 |
| 角色／物件 | 名称、与覆盖镜头的明确关系、本次参考数量 | 定位该对象输入；“添加参考”带入对象上下文与可用资产来源 |
| 场所 | 固定设计中的场所关联、已选空间参考 | 选择空间参考，缺少资产关联时明确指向设计／资产准备入口 |
| 参考素材或主体组 | 实际缩略图、数量、用途、主体或帧位置 | 预览、定位具体参考，支持添加、更换、移除、排序和合法用途调整 |
| 实际落幅 | 来源计划和单元、落幅缩略图、有效性 | 查看固定来源，编辑当前单元对该来源的依赖，显式绑定或替换实际落幅 |
| 空状态／添加节点 | 添加覆盖镜头、添加参考、添加落幅依赖 | 直接打开对应编辑器；集合非空后仍保留追加入口 |

图承载关系、状态和操作定位，详情面板承载长文字、模型选择、多图排序等表单。桌面使用现有 Inspector；窄屏使用现有详情抽屉。节点中的预览与编辑动作区分，避免点缩略图同时修改选择。

建议呈现的用户路径：生产单元 → 角色“张三” → “本次未选参考” → 点击添加 → 在张三上下文选择图片 → 节点出现已选缩略图和输入位置。选图先更新当前计划本地草稿，仍需原有保存与确认流程。

### 对象定位与空状态

- 节点身份至少区分计划版本、单元、对象种类与对象 ID；同名人物、其他计划中的同名单元不能合并。未保存草稿身份与持久化版本区分。
- 扩展当前只传编辑分类的上下文，使它能够定位 `coverage.id`、`participant.id`、`reference.id`／主体组，以及依赖的来源计划与单元。选择失效时说明原因，不回退编辑另一对象。
- 空状态节点是界面入口，不作为虚构参考、依赖或覆盖项写入计划。新增对象由用户提交明确选择后产生。
- 在已有若干参考时仍可添加新对象、非人物参考和临时素材，不能只允许从现有人物节点选图。
- 缺失来源、读取失败、尚未配置分别表达。可选参考或未声明的依赖不一律视为错误；已声明而未满足的依赖明确提示并沿用真实提交校验。

## 5. 参考输入的关系与状态

### 对象范围与固定依据

人物／物件上下文来自计划固定设计及当前单元覆盖镜头的明确引用，直接关系和节拍等间接关系分别标明。部分动作覆盖无法确定某人物是否实际出现时，显示“设计关联”，不宣称它是本次必需主体。缺失明确关联时不按正文猜人物，不将全场人物自动列为必需输入。

已选参考始终完整展示，即使它绑定的人物不在当前覆盖镜头中。无人物绑定的构图、场所、首尾帧、视频或临时素材使用独立分组；不能因图的筛选或聚合而遗漏实际输入。

| 状态 | 表达及处理 |
| --- | --- |
| 未关联资产 | 设计对象尚无项目资产关联；指向合法的设计／资产操作，也允许显式选择已有素材或上传临时参考 |
| 资产暂无可选素材 | 已有关联，但没有当前可选素材；提供资产准备入口，不伪装成已发送参考 |
| 本次未选参考 | 有可选素材但没有选入此单元；提供添加，不默认判为不可生成 |
| 已选入本次输入 | 展示实际文件、输入位置、主体组与顺序；与“可供选择”的图片明显区分 |
| 输入待处理 | 展示已知的文件问题、能力不支持、分组冲突或依赖失效，并定位具体项 |
| 能力或素材状态未知 | 说明尚未核实／读取失败并提供重试，不把未知判为兼容、无素材或失效 |

资产状态和单元输入状态可以同时存在，不能压成互斥的单一枚举。例如，当前资产暂无图片，但历史计划中固定的已选文件仍可能有效；应同时展示当前资产信息和历史输入，不用资产现状覆盖已保存事实。

### 选择与分组规则

- 复用 `ReferencePicker` 的本场资产、已有素材、上传入口。点击人物节点可预定位相关资产，并为临时素材提供明确的人物绑定确认；已有素材入口允许扩展选择。
- 资产关联属于设计，具体输入属于单元。更改设计关联须走设计编辑与版本衔接，不能从准备图直接改写已确认设计；移除本次参考不解除资产关联。
- 选图上下文携带当前计划、单元、人物及模型身份。快速重复选择、切单元、换计划或模型后的迟到回调不能向其他对象添加输入。
- 主体多图可在图中聚合为卡片，但保留每张图的 `reference.id`、文件、顺序、用途与 `subject_group_id`。合照绑定多人物时不复制文件或按人数自动拆组。
- 没有分组信息的历史参考按已有语义展示；不按人物名称或最新资产信息自动合并历史主体。图片以外媒体按类型预览，音频等现有记录仍可见；新增能力以既有模型接口为准。
- 从落幅绑定生成的参考与普通参考按同一 `reference_id` 对应，图中避免重复表示成两份实际输入。移除依赖声明沿用现有“参考素材保留”的语义并明确说明；移除被依赖引用的参考要提示依赖待处理，不能静默显示已满足。
- 更换模型后重新获取能力，保留原有草稿和已选参考，标出不兼容项；不静默删图、换输入位置或自动继续生成。

## 6. 图形统一与版本边界

详细画布统一卡片层级、字体、状态、关系标签和选择反馈。平移、缩放、适应画布、聚焦与布局移动采用一致操作；只读、缺失和待处理对象具有可区分的标记，状态不只依赖颜色。

布局移动与关系编辑分开；移动卡片不改覆盖顺序、输入顺序或业务引用。连线点击可查看依据与相关对象，但业务增删通过合法编辑动作完成。仅在确有相同语义时抽取共享节点样式或画布逻辑，不把 `DesignRelations` 的设计数据结构强行用于生产计划。

窄屏优先保留可读的节点卡片及文字关系，可采用紧凑关系列表；提供与画布相同的对象动作。键盘可选择节点、打开详情、关闭后返回触发位置；缩略图加载失败不隐藏其对象身份。大量参考按组折叠并支持展开，不逐张创建无上限节点。

浏览、聚焦、缩放、展开总览和只读查看不产生业务写入，不触发草稿替换。切换计划或单元、进入设计修改等明确上下文切换沿用现有草稿保护，保存失败或冲突时保留输入和原目标。画布浏览状态按项目、场次、计划与单元隔离；返回后恢复仍有效的选择和位置。

修改已确认计划仍在保存时派生新版本，旧指令、检查、Take 与落幅保持原计划及单元身份。当前草稿不能成为既有指令的固定输入；产出摘要和只读来源详情须说明所依赖的保存版本，缺失时不拿当前草稿替代。历史场次及只读版本详情不出现新增、替换或删除操作。

| 编号 | 场景 | 通过标准 |

## 10. 添加参考交互简化

> 本节记录第一轮简化；当前交互已由第 11 节的统一 modal 方案接替。

2026-09-30 已完成后续简化。默认路径为“绑定人物／物件 → 对应资产的具体图片 → 完成选择”。从对象节点进入时预选该对象，通用添加入口要求用户选择；资产对应关系沿用计划固定设计，不在此重绑设计资产。

- 添加入口隐藏当前单元已经选入的具体文件，资产卡片只保留已选／可新增数量。部分选入的资产仍可追加其他图片；全部选入时显示“暂无可新增素材”，不会重复展示已选缩略图。
- 多个对象分别显示对应资产，选入图片仅绑定与该资产对应的所选对象；不把每张图绑到所有已选人物，也不自动挑选默认图。未关联对象显示明确提示。
- 已选内容的预览、更换、移除和排序继续使用单元详情。更换素材仍保留参考身份与顺序，当前被替换文件不计入其他已选过滤。
- “更多参考方式”按需展开场所资产、已有素材、上传与输入位置；默认界面不铺开全场资产或来源 tab。模型仅支持帧输入时直接显示位置选择，避免隐藏实际输入语义。
- 素材库同样隐藏已选文件。模型能力校验、迟到上传隔离、显式保存与确认流程保留。

## 11. 对象与参考统一 modal

2026-09-30 完成。角色、物件、场所及参考主体点击后直接进入同一 modal，准备区移除右侧参考编辑表单与选图 Drawer。已有输入默认使用紧凑管理视图，添加／替换才展开候选；通用“添加参考”默认仅展示本次新增内容，可在同一 modal 查看本单元全部参考。资产图片、素材库、上传及输入位置在弹窗内配置，独立“更多参考方式”入口移除。桌面宽度 640px，长内容内部滚动，底部应用／取消操作保持可达。

对象范围保留当前单元的明确设计关联与实际输入对象，未关联角色／物件仍可操作；未关联场所新增节点入口。临时空间参考按真实用途与文件绑定展示。未提取素材可从添加入口补充，不因此自动新增设计人物或把全场人物铺入当前单元。

### 保存与版本边界

- modal 使用独立草稿。选图、改绑定、替换、移除和排序均在明确应用后才更新单元；取消或关闭不应用，查看没有业务写入。
- 人工参考可修改人物／物件绑定；资产来源参考的参与者只能来自该资产在固定设计中的关联，保留后端契约。修改设计资产关联使用 modal 内的版本流程入口；有未应用输入修改时先应用或取消，不能绕过设计确认与计划依据。
- 替换保留 `reference.id`、顺序和仍适用的分组。被依赖引用的输入改变时提示落幅待复核，历史固定来源不随当前草稿改变。
- 能力失败可重试；关闭、切换选择上下文后的迟到上传不写入。单元输入在 modal 打开期间变化时阻止应用覆盖。
- 镜头范围、单元参数和落幅依赖继续使用原有编辑器；计划保存、确认派生、指令与检查、拍摄和采用语义不变。
