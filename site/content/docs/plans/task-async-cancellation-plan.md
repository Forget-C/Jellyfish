## 当前状态

任务已统一到 TaskService、tasks 主表和独立 Worker。原计划中的 TaskManager、GenerationTaskLink、Celery 和可恢复执行路径不再推进。

已实现的边界：

- 异步接口返回任务 ID，业务页面及任务中心从同一任务表查询状态和历史。
- 排队任务立即取消，运行任务登记取消意图并由唯一终态入口裁决。
- 终态不可被迟到结果覆盖；取消后不交付新的业务结果。
- 远端 ID 已持久化的媒体任务在重启后继续轮询，不重新提交。
- 本地文本执行中断后失败，重新提交形成新任务历史。
- 同步脚本线程超时或停止后不再发送后续模型请求，线程退出前仍占用容量。

当前实现见 [任务执行架构](../../architecture/task-execution/)，启动与排查见 [运行与排查异步任务](../../guide/task-async-cancellation-plan/)。

不引入强制杀死单个 Python 线程、自动重放本地执行、分布式工作流恢复或旧任务状态兼容层。供应商是否继续执行与本地取消分开表达。
