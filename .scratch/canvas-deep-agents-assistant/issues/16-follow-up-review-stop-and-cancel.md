# 16: 生成后接续审看，分别处理停止与取消

Status: ready-for-agent
Completion: complete
Blocked by: 09, 15

**What to build:** 用户明确交代生成后审看时，后台能跟进相应运行和结果。关闭侧栏、停止助手、取消生成分别产生可见且可恢复的效果。

对应[实现规格中的用户故事](../spec.md#user-stories) 11、24、25、26。

## Acceptance criteria

- [x] “生成一版，完成后看看动作是否连贯”受理后，关闭侧栏或离开画布；回来能在原对话定位该次结果、观察时段和审看反馈。普通生成完成不会自行触发点评。
- [x] 生成已提交、审看尚未开始时停止助手，该次运行仍可继续；已应用编辑保留，待执行的写入和点评终止。通过独立入口可对进行中的生成发出取消请求，界面展示实际运行状态。
- [x] 原结果暂不可读、生成失败或已取消时，反馈引用正确的运行并说明可用依据，不点评不存在的成片或自动再提交。
- [x] 使用专用 MySQL 和真实 Worker，在已请求停止后重启；恢复流程不会重新启动该轮尚未执行的编辑或点评。重复收到完成通知时，原对话只接续一次约定的审看。
