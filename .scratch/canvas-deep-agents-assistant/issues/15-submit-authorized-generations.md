# 15: 按明确授权生成指定数量

Status: ready-for-agent
Blocked by: 06

**What to build:** 用户可以把编辑和生成意图写在同一句话里。助手分别核对两类授权，按批准后的输入与明确数量提交，恢复时复用已有运行回执。

对应[实现规格中的用户故事](../spec.md#user-stories) 23、24、25。

## Acceptance criteria

- [ ] 仅要求或批准改提示词时，运行数为零。“改好后生成一版”在编辑获批且预检通过后提交一次；若拒绝编辑或预检失败，说明原因并保留真实状态。
- [ ] “生成三版”产生三次有独立稳定标识的提交，每版可追溯到授权消息、目标模型卡、输入依据和对应运行。重复接收同一授权不会增加版数。
- [ ] 在专用 MySQL 和真实 Worker 中，于生成已受理、助手尚未收到回执时中断并重启。先按原请求标识核对，一版只有一条业务提交，部分已受理的多版也能逐版核对。
- [ ] 用户得到与原画布对应的结果或失败原因。失败可以提出修正，效果不理想可以讨论改法；只有新的明确指令才允许重跑或追加版本。
