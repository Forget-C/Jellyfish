# 11: 局部改镜头时保护共享设计

Status: ready-for-agent
Completion: complete
Blocked by: 10

**What to build:** 用户要求只调整镜头三时，助手沿实际采用关系找到控制运镜的来源，展示影响并保护使用同一来源的镜头四。

对应[实现规格中的用户故事](../spec.md#user-stories) 7、14、16。

## Acceptance criteria

- [x] 设置镜头三、镜头四共用一张运镜卡，并加入一张仅候选、尚未采用的相似卡。助手识别两个真实使用方与实际生效字段。
- [x] 调整前给出只影响镜头三的方案。预览列出需要新增或修改的卡片、引用与采用关系，用户可放弃或审批为一组。
- [x] 批准、保存并重开后，镜头三使用新配置，镜头四的卡片关系和实际采用参数保留原值；撤销可还原原先的共享关系。
- [x] 另验收已有专属运镜卡和仅有视频提示词的情形，能直接改到实际来源。审批前若共享关系已有变化，按最新依据核对。
