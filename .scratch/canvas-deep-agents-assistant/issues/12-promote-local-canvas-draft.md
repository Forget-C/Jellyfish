# 12: 空白自由画布先聊、首次保存再归档

Status: ready-for-agent
Blocked by: 10

**What to build:** 在新自由画布先讨论想法、选参考素材。本机草稿在第一次保存时带着原对话和附件成为正式画布。

对应[实现规格中的用户故事](../spec.md#user-stories) 5、10、25。

## Acceptance criteria

- [ ] 空白草稿仅聊天、挑选参考或刷新时，可以在当前浏览器继续讨论；首页画布数量保持原值。
- [ ] 分别验证用户主动保存和首次批准建卡建议两条路径。每条路径只创建一张正式画布，重开可见原消息顺序、所选附件，以及本次实际接受的卡片。
- [ ] 首次保存已经受理但客户端未收到回执时，重试仍归到同一画布和会话。附件用途、消息和建卡结果各出现一次。
- [ ] 从另一个空白草稿开始对话，确认它不会继承前一张草稿的选材、建议或消息。
