# 10: 按画布目录建卡、连线并采用参考

Status: ready-for-agent
Completion: complete
Blocked by: 07, 08

**What to build:** 把对话里选定的参考图加入画布、连到指定视频模型卡并设为首帧。助手按画布类型创建卡片和修改配置。

对应[实现规格中的用户故事](../spec.md#user-stories) 6、7、8、10、15。

## Acceptance criteria

- [x] “把这张图用作首帧”展示选定素材、目标模型卡、将创建的参考卡、连接和采用用途；批准后生成配置实际使用该文件作首帧。
- [x] 建卡、连线和设置用途作为同一组应用，一次撤销恢复之前的文档和引用。目标或端口失效时不留下部分卡片或连接。
- [x] 从自由画布验收建基础内容卡、参考卡或模型卡，并从业务入口尝试创建分镜专用设计卡。禁止操作返回明确原因，现有文档保持有效。
- [x] 在分镜画布中通过助手新建设计卡并修改其配置。保存、重新打开、校验引用时都沿用现有卡片规则。
