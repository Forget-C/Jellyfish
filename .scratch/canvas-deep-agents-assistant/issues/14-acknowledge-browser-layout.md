# 14: 分组和布局由浏览器执行并回执

Status: ready-for-agent
Completion: complete
Blocked by: 07

**What to build:** 用户在助手中要求分组、移动卡片或整理布局，由当前画布编辑器实际执行，侧栏展示执行结果。

对应[实现规格中的用户故事](../spec.md#user-stories) 8、15、27。

## Acceptance criteria

- [x] 在浏览器里发起分组与布局调整，核对分组成员、卡片实际位置和重新打开后的布局。执行过程中和收到编辑器回执后可区分待执行与已完成。
- [x] 从一组已批准但尚未执行的布局变动离开页面，它保持待执行；重新打开原画布后按最新元素和布局核对，只对仍适用的目标执行。
- [x] 目标已删除或相关布局已被手改时，如实展示未执行或需要核对的结果，不覆盖新状态；重送同一已执行命令不重复移动。
- [x] 同次应用的画布编辑可按原有撤销体验恢复；布局沿用当前浏览器的存储范围。
