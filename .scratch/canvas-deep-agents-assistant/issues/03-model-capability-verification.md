# 03: 管理员主动验证模型能力

Status: ready-for-agent
Completion: complete
Blocked by: 01

**What to build:** 管理员在模型管理页选择一项能力，用当前型号与接口发起实际验证，并查看结果适用于哪份配置。

对应[实现规格中的用户故事](../spec.md#user-stories) 21、22。

## Acceptance criteria

- [x] 可分别发起工具往返、读图、读取连续视频和听音频的验证。仅导入或保存模型配置不发起这些测试。
- [x] 工具验证涵盖模型发起无副作用的工具调用、接收工具结果并继续作答；只返回文本或只发出调用时不能显示完整往返通过。
- [x] 使用已知媒体和可控供应商验证各模态实际收到的输入。接口报错或仅收到静帧时，如实展示该项结果，保留原声明和来源。
- [x] 重开可查验证项、时间、供应商配置、型号和接口标识。更改型号或接口地址后，历史结果标出原配置，当前配置可重新发起验证。
