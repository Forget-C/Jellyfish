# 01: 模型管理可查看和维护有效能力

Status: ready-for-agent
Completion: complete
Blocked by: None

**What to build:** 在模型管理中维护具体供应商配置下某个型号的能力。管理员可以看到模型声明了什么，以及通过当前接入实际能使用什么。

对应[实现规格中的用户故事](../spec.md#user-stories) 21。

## Acceptance criteria

- [x] 新建、编辑、重新打开模型时，分别展示文本、图片、连续视频、音频输入、文字输出和工具调用。每项声明支持“支持／不支持／未知”及来源，已知时可记录上下文上限。
- [x] 同名型号绑定不同供应商配置时，修改其中一条声明只影响该配置。管理页与读取接口对同一配置返回一致的声明和有效能力。
- [x] 用一个声明支持视频、当前操作只接入静帧的例子验收。界面能说明限制，能力读取结果只开放实际接入的路径。
- [x] 导入模型只读取目录，旧记录缺项显示未知。现有类别、默认模型与生成卡仍可使用，提交给供应商的模型参数中没有混入能力声明。
