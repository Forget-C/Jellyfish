# 07: 分组审批、部分接受与手改冲突

Status: ready-for-agent
Completion: complete
Blocked by: 06

**What to build:** 让一次请求形成多个可独立审批的改动组，保留等待期间的人工编辑，并能在进程中断后接着审批或找回原回执。

对应[实现规格中的用户故事](../spec.md#user-stories) 14、15、16、25。

## Acceptance criteria

- [x] 用户能在侧栏接受一个组、保留或放弃另一个组。相互依赖的多项编辑作为一个组完整应用；其中一项失效时不会留下半组写入。
- [x] 一次应用选择的编辑进入同一次撤销。验收同时核对界面状态、实际字段及撤销后的内容。
- [x] 等待期间手改同一字段时，保留最新可见草稿，展示最新差异并允许重新拟稿。修改无关卡片不会单凭整图修订变化阻止独立组应用。
- [x] 在专用 MySQL 与真实 Worker 下，等待审批时中断并重启，能找回原请求、分组和当前草稿冲突；已提交写入但回执尚未送达时中断，恢复或重复确认都只产生一次生效的修改。
