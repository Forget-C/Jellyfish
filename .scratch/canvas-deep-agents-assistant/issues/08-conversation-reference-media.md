# 08: 把样片交给助手讨论

Status: ready-for-agent
Blocked by: 04

**What to build:** 在已保存画布的对话中上传素材或从文件管理选取素材，用图片或视频静帧比较两个参考方案。

对应[实现规格中的用户故事](../spec.md#user-stories) 10、11、25。

## Acceptance criteria

- [ ] 本地上传和选取已有文件均可作为消息附件。附件使用既有文件身份并登记对话用途，重开原对话后仍能定位到对应参考。
- [ ] 用户发来两张图或两段样片的静帧比较构图，回复可定位到真正送给模型的图片或帧及其对应素材；素材读不到时交代本次可用依据。
- [ ] 仅用于对话的参考不会创建内容卡、连线或模型输入。核对画布文档、素材用途与所选模型实际收到的内容。
- [ ] 换到另一张画布后，助手只能按该次会话与选材取用参考。缺失或不适用的附件不会被描述为已观察。
