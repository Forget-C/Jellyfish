# 06: 把一条建议审批写回原卡

Status: ready-for-agent
Completion: complete
Blocked by: 04

**What to build:** 用户明确提出单卡编辑后，在侧栏查看字段差异，继续修订、拒绝或确认。确认后沿用画布保存与撤销入口。

对应[实现规格中的用户故事](../spec.md#user-stories) 6、7、13、15。

## Acceptance criteria

- [x] 在已有视频模型卡上请求放慢推近，预览显示目标卡、字段、可见原值和拟议值。仅问如何拍摄时只产生建议。
- [x] 继续修改建议可得到更新后的预览；拒绝或放弃后原卡不变。确认后同一目标写入成功，重开画布能读到保存值。
- [x] 单卡写入经过当前画布目录、字段和已有引用校验；用自由画布的视频提示词及分镜画布的已有运镜卡分别验收合法写入。
- [x] 本次确认关联来源消息、审批结果和业务回执，一次撤销可恢复原字段。仅批准编辑时生成运行数为零。

集成记录 `137681f3`。自由画布视频提示词和分镜运镜均通过预览、确认、写回和一次撤销。
