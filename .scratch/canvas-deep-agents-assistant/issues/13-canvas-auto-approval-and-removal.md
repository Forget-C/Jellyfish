# 13: 按画布自动审批，区分明确删除与推断删除

Status: ready-for-agent
Blocked by: 07

**What to build:** 用户为当前画布选择自动审批，能回看哪些编辑因哪条明确指令而执行，哪些删除或解除引用仍等候确认。

对应[实现规格中的用户故事](../spec.md#user-stories) 17、18、25。

## Acceptance criteria

- [ ] 默认要求人工审批。开启或关闭后重开画布能看到当前设置，其他画布继续使用各自的设置。
- [ ] 开启时，明确编辑某个字段可直接写入；明确指定删除某张已有卡或解除某条已采用引用时，校验真实目标和影响后执行，可撤销。
- [ ] 以“整理一下画布”为例，助手推断出的删除或解除已采用引用动作显示为待确认；拒绝后卡片与引用仍在。仅问建议不会因开启自动审批而写入。
- [ ] 审批记录能追溯来源消息、当时审批模式及实际结果。自动路径同样检测手改冲突，不把编辑授权当作生成授权。
