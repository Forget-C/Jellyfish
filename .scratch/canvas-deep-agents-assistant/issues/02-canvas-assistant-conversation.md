# 02: 两种画布打开助手并接续文字对话

Status: ready-for-agent
Blocked by: None

**What to build:** 在已保存的自由画布和分镜画布上，从右侧悬浮图标打开助手，用全局默认文本模型完成一次文字对话并在重开时接续。

对应[实现规格中的用户故事](../spec.md#user-stories) 1、25。

## Acceptance criteria

- [ ] 通过真实画布入口打开、收起侧栏，用户始终可以操作卡片。仅打开侧栏不调用模型；发送文字后可看到答复。
- [ ] 沿用项目模型接入，升级 Deep Agents 及其兼容依赖。首版由一个 Agent 处理每次请求，画布业务工具及专业技能按后续票据接入。
- [ ] 消息与轮次记录当前画布会话、消息顺序、请求标识和实际模型。刷新后还能读到原问答，重送同一次请求不会多出一份已完成对话。
- [ ] 用两张已保存画布交替提问，再重开第一张。每张画布只显示自己的消息，恢复后可以继续对话。
- [ ] 在本次锁定的依赖上回归既有结构化输出、文本流、媒体检查和单卡提交，记录真实结果。选型时的隔离实验单独列作参考。
