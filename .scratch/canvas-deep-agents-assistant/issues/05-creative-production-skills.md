# 05: 按创作意图调用专业 Skill

Status: ready-for-agent
Completion: complete
Blocked by: 04

**What to build:** 让同一个助手按意图加载镜头与场面调度、图片生成指导、视频生成指导三类专业技能，支持创作者指定或组合专业角度。

对应[实现规格中的用户故事](../spec.md#user-stories) 9、12、13。

## Acceptance criteria

- [x] 三类技能作为产品维护的只读 SKILL.md 发布，通过简介发现，按需加载正文和参考资料。用户从画布发出调度、生图、视频提示词问题时均能获得相应专业建议。
- [x] 用“只从摄影角度看”和“先调整走位，再改写视频提示词”分别验收点名与组合。回复显示实际使用的专业能力，消息记录对应标识和版本。
- [x] 在给定的镜头与原文样例中，建议区分原文事实、已有画布依据和新增拍法，并解释至少一项可供用户权衡的叙事或视觉效果。
- [x] 用户继续说“保留景别，只改运镜”时可以细化建议；只咨询不会写卡、建卡或发起生成。自动化断言目标、作用范围和可观察结果。
