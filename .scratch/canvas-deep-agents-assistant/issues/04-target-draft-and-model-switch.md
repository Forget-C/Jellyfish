# 04: 锁定提问目标、读取可见草稿、切换助手模型

Status: ready-for-agent
Completion: complete
Blocked by: 01, 02

**What to build:** 用户选择所选卡片或整张画布，基于发送时可见的内容提问。在需要工具或特定媒体能力时可切换模型，接续同一请求。

对应[实现规格中的用户故事](../spec.md#user-stories) 2、3、4、19、20。

## Acceptance criteria

- [x] 从选中卡发问时，读取活动编辑器中尚未提交的字段值，以及这张卡实际采用的来源。用户指定整张画布时扩大分析范围。
- [x] 发送后改选另一张卡，原请求仍关联发送时的画布、目标身份和草稿依据。用两个同名卡片验证定位不依赖卡名。
- [x] 管理页、选择器、运行前检查和暴露给助手的工具一致反映当前模型的有效能力。仅能聊天时可讨论粘贴的文本，要求读卡或调用工具时明确提示缺少的能力。
- [x] 从侧栏切换兼容模型后能处理原请求，保留原目标和草稿依据。该选择按画布保留，各图片、视频模型卡的生成配置保持原值。
- [x] 用双画布入口和可控模型核对实际收到的目标内容、使用的模型与请求次数；仅分析时不写入画布，也不提交生成。
