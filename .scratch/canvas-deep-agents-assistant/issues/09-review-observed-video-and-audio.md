# 09: 按实际画面和音轨审看片段

Status: ready-for-agent
Completion: complete
Blocked by: 05, 08

**What to build:** 接入第四类产品 Skill“成片审看”，根据实际收到的图片、连续画面或音轨定位问题，并可接续生成指导。

对应[实现规格中的用户故事](../spec.md#user-stories) 9、11、12、24。

## Acceptance criteria

- [x] 对同一份带已知时间点的样片，分别提供静帧、连续无声画面、可对齐的画面和音轨。记录实际输入及观察时段。
- [x] 静帧点评定位到相应画面；动作与运镜判断有连续画面依据；声画同步结论有相同时段的画面和音频依据。证据不足时说明可判断的范围。
- [x] 回复区分媒体观察、原文事实和创作建议，显示使用的审看技能并记录版本。用户可以要求只评价某个专业角度或继续讨论改善方法。
- [x] 在画布上验证对已生成结果及对话样片的审看。点评效果欠佳的产物时可以给修正建议，生成次数保持原值。
