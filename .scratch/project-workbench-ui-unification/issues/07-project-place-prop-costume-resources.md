# 07: 项目场所、道具和服装资源统一

**What to build:** 用户以统一方式浏览和关联项目场所、道具与服装，并通过图片预览、名称详情和更多操作完成管理，保留每类资源的真实业务信息与关联语义。

**Blocked by:** 06 项目演员资源与图片卡片交互统一

**Status:** ready-for-agent

- [ ] 三类页面接入紧凑工具栏，从资产库关联为唯一突出的主动作，新建为次要操作，查看资产库为轻量链接；去掉重复标题和装饰性外层卡片，空状态不重复整套按钮。
- [ ] 复用06的卡片能力；场所封面裁切填充，道具和服装完整比例展示，封面约160px；名称14px／600、摘要最多两行且缺失显示未填写简介，保留有效标签或关联状态。
- [ ] 名称进入对应既有详情，图片仅作预览；内部ID不常驻，无虚构元信息，网格随内容宽度减列，业务信息可自然换行。
- [ ] 无图或加载失败提供类型图标与文字而非空预览；点击或Enter打开完整比例图片，Esc关闭并恢复焦点。
- [ ] 更多菜单保留编辑和取消关联，确认清楚说明具体资源与影响，不把项目关联移除改成全局删除；菜单与弹窗顺序、执行锁和失败上下文保持有效。
- [ ] 关联资产弹窗统一外层标题、间距、按钮及滚动，矮屏主要操作可达；保留各类创建、关联和编辑接口语义，场所资产不得与章节场次混用。
- [ ] 通过真实页面及隔离响应逐类覆盖创建与关联入口、详情目标、预览、取消关联、失败恢复和空列表，避免只验证一种资源后推定其他类别通过。
- [ ] 按规格双主题、四种视口及网格断点检查不同图片比例、长名称、标签换行、键盘焦点和弹窗；验证排除范围不受影响，完成必要检查并同步对应资源规范。

规格覆盖：用户故事1–5、31、33–37、39–42、49–52；Q2、Q7、Q8、Q12、Q13、Q15。06提供卡片和图片交互；01为传递依赖。仅调整前端展示与入口，不变更资源归属、接口或表结构。
