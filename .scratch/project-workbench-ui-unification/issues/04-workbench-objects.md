# 04: 工作台对象与参考步骤统一

**What to build:** 用户在本场对象与参考步骤中识别关联对象、参考图和需核对的信息，按真实状态提取或核对对象，并能处理冲突、失败和继续下一步。

**Blocked by:** 03 工作台管理导航与响应式工具栏统一

**Status:** ready-for-agent

- [ ] 将对象步骤动作接入03的当前动作区域；提取或核对对象随真实状态成为主动作，继续下一步使用轻量操作，次要动作按当前页面范围组织。
- [ ] 白色对象卡表面使用12px圆角、12–16px内间距，沿用统一字号和雾蓝双主题，保留对象关联、参考图片及冲突信息；不套用项目列表固定四行布局。
- [ ] 历史场次、来源变化、对象准备过时、候选核对、错误、冲突及任务状态保持可见，必要的核对、恢复和重试入口不藏入更多菜单。
- [ ] 整理本步骤涉及的关联资产弹窗外层标题、间距、按钮和正文滚动；标题16px／600、分节14px、操作13px，矮屏底部操作可达，菜单先关闭再打开弹窗，保留顶层Esc和焦点恢复。
- [ ] 保留现有提取、核对、采用、关联、差异、历史、取消、未保存和任务保护语义；不改变请求条件、任务身份或资产归属。
- [ ] 管理页面的调整使用作用域或明确样式选项，场次内嵌资产档案与独立画布中的对象展示保持原布局及主题。
- [ ] 复用真实页面测试与既有隔离后端，覆盖初始、可提取、需核对、来源变化、冲突、进行中、失败及恢复状态；检查继续下一步及关联请求结果，不验证供应商生成质量。
- [ ] 按规格双主题、四种视口及相关断点检查长名称、参考图、状态换行、动作及弹窗可达性；完成共享调用方回归和必要检查，同步实际落地的对象步骤规范。

规格覆盖：用户故事25、27–30、49–52；Q6、Q10及Q15中的本步骤关联弹窗。03提供动作区域；不依赖画布步骤票据。
