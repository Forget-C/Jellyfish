# 01: 项目内容工具栏与章节操作统一

**What to build:** 用户在项目内部页通过路径定位和一条紧凑内容工具栏理解当前位置，在章节列表编辑原文或按真实状态继续制作。先在此完整流程中接入可复用的项目工具栏能力，供后续项目页面使用，不全局改变通用组件默认值。包含章节原文编辑弹窗的外层样式。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**Completion:** resolved

- [x] 保留面包屑及语义标题；章节标题、真实数量、搜索集中于单条工具栏，新建章节在右侧，正文无重复标题及装饰性外层标题卡片；未知数量不显示为零。
- [x] 工具栏只展示当前页相关操作，移除与子页面重复的通用制作动作；后续页面可接入自身操作，其他页面在迁移前仍可正常使用。
- [x] 沿用两种雾蓝外观与现有偏好；标题16px／600、操作13px、辅助12px；桌面工具栏约52–56px、控件32px，窄屏控件36px；页面边距20px／手机16px，区域间距20px、控件间距8px，保留输入和焦点边界。
- [x] 点击章节名称仍打开原文编辑器；状态仅表达信息，移除名称旁重复的制作入口。待补原文显示编辑原文和轻量工作台管理；已有原文无场次显示划分场次；已有场次或场次状态未知显示工作台管理。
- [x] 划分入口定位既有独立工作台管理的场次划分步骤，不恢复停用的章节组合抽屉；缺原文时仍能管理已有场次和历史。行内动作轻量化，实心蓝主要留给新建章节。
- [x] 保留原文预览、字数、可靠场次数、创建、搜索、分页和错误反馈；加载、未知、空数据和失败不混淆。
- [x] 从工作台返回时保留章节定位及对应操作焦点；目标不在当前筛选或分页时，已有定位反馈仍可达。
- [x] 原文编辑弹窗标题16px／600、分节14px、操作13px，正文在可用视口内滚动且底部操作可达；原文保存、差异核对、历史和未保存保护不变。
- [x] 复用既有真实页面测试，通过隔离响应覆盖上述状态、编辑与返回流程；导航纯逻辑测试仅作为补充。按规格的双主题、1440×900、1366×768、1024×440、375px及相关断点检查布局、键盘顺序和焦点，普通内容允许纵向滚动。
- [x] 对共享工具栏实际受影响页面完成回归，确认独立画布与其浮层不受样式污染；按影响范围执行前端类型检查及必要检查，落地后同步对应长期规范和布局说明，不提前声称实现完成。

规格覆盖：用户故事1–14、49–52；Q1、Q2、Q3及Q15中的章节原文编辑。仅前端布局、样式与入口表达，保留既有接口、路由身份、数据及任务语义，不伪造业务数据。
