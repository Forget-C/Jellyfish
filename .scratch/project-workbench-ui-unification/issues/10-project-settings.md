# 10: 项目设置分组与保存布局统一

**What to build:** 用户在紧凑、清晰的项目设置表单中编辑基本信息和生成默认设置，通过表单末尾保存或取消，并在失败时保留输入继续处理。

**Blocked by:** 01 项目内容工具栏与章节操作统一

**Status:** ready-for-agent

- [ ] 接入01的页面工具栏，保留路径定位和单一内容标题，不显示与设置无关的制作动作或重复顶部保存按钮。
- [ ] 表单左对齐、最大宽度约640px，按基本信息与生成默认设置分组；白色表面12px圆角、16px内间距，常规输入36px，长文本独占一行。
- [ ] 沿用规格的双主题、现有浏览器偏好和文字层级，使用留白组织分区，保留输入、校验错误与键盘焦点边界；窄屏适应内容宽度，不强制固定高度。
- [ ] 保存与取消仅集中在表单末尾，滚动后始终可达；保留既有修改状态、保存锁和防重复提交行为，不新增字段或更改默认配置语义。
- [ ] 保存失败保留本轮输入并显示错误；成功后已保存基准有效，取消恢复已保存值；不新增或更改已有未保存保护流程。
- [ ] 通过真实页面操作和隔离HTTP响应覆盖初始加载、编辑、取消、保存进行中、保存失败保留输入、重试成功及成功后再次编辑取消；核对请求与可观察结果，不测试内部组件状态。
- [ ] 按规格双主题、1440×900、1366×768、1024×440、375px及相关断点检查长文本、错误信息、底部操作和键盘顺序；不将首页一屏限制推广至设置。
- [ ] 完成受影响前端检查，核对共享表单样式未影响排除范围，落地后同步项目设置的长期规范；相关架构说明只记录已实现事实。

规格覆盖：用户故事1–5、46–48、51–52；Q2、Q14。01提供工具栏接入；不依赖其他资源页面。只调整前端布局和样式，保留接口、保存及保护语义。
