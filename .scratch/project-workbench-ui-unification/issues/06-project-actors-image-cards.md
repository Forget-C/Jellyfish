# 06: 项目演员资源与图片卡片交互统一

**What to build:** 用户在项目演员页完成从资产库关联、浏览、进入详情、预览图片和取消关联的完整流程。在本流程中形成可复用的资源卡片样式与图片交互选项，供后续资源及文件页面接入，避免改变未迁移调用方。

**Blocked by:** 01 项目内容工具栏与章节操作统一

**Status:** ready-for-agent

- [ ] 使用01的单条紧凑工具栏，从资产库关联为实心主动作，新建为次要操作，查看资产库为轻量链接；移除装饰性外层卡片及重复标题，空状态不重复整套操作。
- [ ] 卡片按封面、名称、摘要、真实业务信息和更多操作排列；封面约160px并完整展示图片，名称14px／600单行截断且可获取完整名称，摘要最多两行、缺失时显示未填写简介。
- [ ] 保留有效标签或关联状态，内部ID不常驻，不编造时间、计数和关联；网格按实际内容宽度减列，元信息可换行，不强制固定卡片行数。
- [ ] 名称进入既有详情；图片仅负责完整比例预览，以键盘可操作控件提供可访问名称和可见焦点，点击或Enter打开，Esc关闭并恢复触发焦点。
- [ ] 无图或图片加载失败时显示类型图标与明确提示，不出现破图或可打开的空预览。
- [ ] 更多集中编辑和取消关联，菜单先关闭再打开编辑或确认层；确认说明演员对象与影响，仅取消项目关联、不删除全局资产；执行中防重复提交，失败保留对象及上下文。
- [ ] 关联资产弹窗沿用标题16px／600、分节14px、操作13px，统一外层间距与按钮，正文视口内滚动且底部操作可达；保留既有创建、关联、编辑及保护流程。
- [ ] 卡片能力以页面作用域或明确选项接入，采用统一白色表面、12px圆角、12–16px内间距及双主题；检查共享调用方，未迁移资源、独立详情、场次内嵌档案和画布不被隐式重排。
- [ ] 同一真实页面测试入口使用隔离HTTP响应覆盖关联、详情、编辑、取消关联成功与失败、防重复提交、缺图、图片失败、长名称、两行摘要及键盘预览和焦点；不以组件内部状态或CSS快照替代行为验证。
- [ ] 按规格双主题、四种视口及实际网格断点检查布局与弹窗；完成共享调用方回归及必要检查，落地后同步资源卡片和预览相关长期规范。

规格覆盖：用户故事1–5、31、33–37、39–42、49–52；Q2、Q7、Q8、Q12、Q13及Q15中的演员关联弹窗。01提供工具栏；此票交付完整演员流程及其他票据确需复用的卡片能力，不单独建设无使用方的基础层。
