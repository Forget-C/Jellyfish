# 05: 工作台分镜与画布步骤统一

**What to build:** 用户在本场分镜与画布步骤中辨认已有画布及真实任务状态，发起当前允许的生成动作、创建空白画布或继续已有画布，并在需要时查看任务、取消和重试。

**Blocked by:** 03 工作台管理导航与响应式工具栏统一

**Status:** ready-for-agent

- [ ] 接入03的动作区域，按真实状态展示生成新分镜画布主动作；新建空白画布等次要动作进入更多，原有请求条件与任务身份不变。
- [ ] 画布卡采用白色12px圆角表面、12–16px内间距，突出名称、真实任务状态与打开入口；沿用统一字号和主题，不套用项目列表固定四行布局。
- [ ] 错误、冲突、历史与任务进行状态直接可见，保留相应重试和恢复入口；不以视觉简化隐藏必要反馈。
- [ ] 画布创建与任务详情仅统一外层标题、留白、按钮层级和滚动；标题16px／600、分节14px、操作13px，长正文和矮屏下底部主要操作可达。
- [ ] 更多菜单关闭后再打开后续弹窗，保留可访问名称、顶层Esc和关闭焦点；创建、取消、重试、未保存及任务保护沿用现有语义。
- [ ] 打开画布保持正确项目、章节、场次及画布身份；独立生成画布、场次画布及其内部弹窗的布局和主题不变。
- [ ] 通过真实页面操作、受控HTTP响应及既有隔离后端覆盖空列表、多画布、长名称、创建、任务进行中、失败、取消、重试和有效打开；不调用真实生成供应商。
- [ ] 按规格双主题、四种视口及相关断点检查卡片、动作分组、弹窗滚动和键盘操作；对独立画布进行受影响回归，完成必要检查并同步画布管理相关长期规则。

规格覆盖：用户故事25、27–30、49–52；Q6、Q10及Q15中的画布创建与任务详情。03提供动作区域；不依赖对象步骤票据。
