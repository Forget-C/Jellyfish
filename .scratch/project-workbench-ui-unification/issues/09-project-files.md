# 09: 项目文件浏览与批量下载统一

**What to build:** 用户默认专注浏览项目关联文件，使用章节筛选、预览和单文件下载；主动进入批量模式后选择并下载文件，退出时清空选择。

**Blocked by:** 06 项目演员资源与图片卡片交互统一

**Status:** ready-for-agent

- [ ] 接入单条紧凑工具栏，将章节筛选与当前页操作集中展示，移除重复标题和装饰性外层卡片；沿用规格中的主题、字号、留白和控件尺寸。
- [ ] 默认浏览时不显示复选框；显式开启批量模式后显示复选框、选中数量和批量下载，退出批量模式清空所有选中项，再次进入不恢复旧选择。
- [ ] 单文件下载为紧凑图标按钮，提供提示、可访问名称及可见焦点，不再独占卡片整行。
- [ ] 复用06的可访问图片预览及缺图／加载失败处理；保留实际支持的图片、视频和音频预览，预览行为与选择独立，不改变勾选状态。
- [ ] 沿用实际项目关联范围、章节筛选、分页与真实下载路径，不扩展为全站文件列表，不使用模拟下载成功；筛选和分页中的选择处理沿用既有语义，下载对象不得错位。
- [ ] 加载、空数据、读取失败和下载失败保留明确反馈及可用恢复路径，未选文件时不发起空批量下载；现有防重复操作行为不退化。
- [ ] 真实页面测试隔离HTTP响应，覆盖默认浏览、进入／退出／重新进入批量模式、选中数量、筛选分页、预览不改选择、单项及批量下载的实际请求对象或浏览器下载结果，而非仅检查点击提示。
- [ ] 按规格双主题、四种视口及网格断点检查文件卡片、筛选、长名称、批量状态、键盘和预览焦点；页面正常滚动，操作不被裁切；完成受影响检查并同步文件页规范。

规格覆盖：用户故事1–5、36–37、40、43–45、52；Q2、Q9及适用的Q12、Q13。06提供共享图片交互；01为传递依赖。文件无需机械套用资源摘要字段或项目固定四行卡片。
