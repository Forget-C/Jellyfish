# 02: 项目概览摘要与制作入口统一

**What to build:** 用户通过项目概览识别当前制作、已有生成画布和有限的章节场次摘要，并通过含义明确的入口继续操作或查看完整内容。

**Blocked by:** 01 项目内容工具栏与章节操作统一

**Status:** ready-for-agent

- [ ] 接入01的紧凑工具栏，取消重复标题和无关动作；保留当前制作、生成画布、章节场次三个区域及原有当前制作章节选择依据。
- [ ] 当前制作展示真实章节与状态，下一步明确对应编辑原文、划分场次或工作台管理；不使用不能说明目标的泛化进入文案，不因摘要截断改变当前工作身份。
- [ ] 生成画布保留真实封面、名称和有效打开入口；不新增假画布、虚假进度或推算状态。
- [ ] 章节场次改为按章分组的紧凑列表，最多三个有场次的章节；当前制作章节有场次时优先，其余按章序排列，每章最多前三个场次并保留原场次顺序。
- [ ] 场次名称加箭头进入工作台管理并明确定位该场次；不为每项重复长按钮文案，不为凑满数量添加占位记录。
- [ ] 超出摘要范围时提供查看本章全部场次和查看全部章节入口，分别去往该章工作台管理与章节列表；摘要条数不冒充总数，不从不完整响应推算全项目数量。
- [ ] 空数据、加载、失败和重试独立表达；沿用规格中的雾蓝双主题、字号、20px区域间距及链接悬停和可见焦点反馈，正文正常纵向滚动。
- [ ] 真实页面测试以隔离响应覆盖当前章有／无场次、超过三章与每章三场、稳定顺序、未知数量、失败重试和所有跳转；复用概览及首页活动相关回归，不调用真实生成供应商。
- [ ] 按规格双主题和四种视口及相关断点验证摘要、长名称和入口可达性；执行受影响检查并同步概览相关长期规则，不重做首页或项目列表。

规格覆盖：用户故事1–3、5、15–22、52；Q2、Q5、Q11。01提供工具栏接入能力；实施批次不新增其他阻塞。
