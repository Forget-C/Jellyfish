# 03: 工作台管理导航与响应式工具栏统一

**What to build:** 用户进入工作台管理后清楚辨认项目、章节和场次，通过本章侧栏与步骤切换继续工作；宽窄屏均能操作当前场次。为后续对象和画布步骤提供一致的动作区域，并整理场次名称与顺序弹窗。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**Completion:** resolved

- [x] 保留普通应用一级菜单和返回项目、章节的面包屑；左侧只承担本章场次切换，不叠加完整项目导航。
- [x] 桌面场次侧栏256px，保留场次名称、元信息和状态；移除结构分割线与选中描边，使用浅蓝选中底色及明确的可访问当前项状态，不能仅靠颜色区分。
- [x] 桌面工具栏按左侧场次身份与编辑、中央步骤、右侧当前动作排列，提供供对象及画布步骤接入的动作区域，迁移过程中原动作仍可用。
- [x] 保留对象与参考〔本场〕、分镜与画布〔本场〕及轻底色选中样式，场次划分沿用既有独立入口；切换不改变当前场次身份、查询上下文或任务生命周期。
- [x] 窄屏按场次身份与切换、步骤、主动作与更多分组换行，中等宽度可合并；长名称可换行，不缩字或裁切强制固定行数，主动作可达且正文自然滚动。
- [x] 复用现有场次切换抽屉并保留关闭焦点恢复，DOM与键盘顺序符合视觉顺序；菜单和弹窗按当前顶层处理Esc。
- [x] 场次名称与顺序弹窗标题16px／600、分节14px、操作13px，正文视口内滚动、底部操作可达；保存、取消、错误及已有保护流程不变。
- [x] 沿用规格的双主题、紧凑字号、留白和控件尺寸，样式限定在工作台管理；独立画布及其内部弹窗、场次内嵌资产档案不被重排。
- [x] 通过真实页面操作及既有隔离后端验证场次切换、步骤、深链接、旧链接兼容、返回章节、抽屉焦点和场次信息编辑；此票不以真实供应商生成为验收条件。
- [x] 按规格双主题、四种视口及实际断点检查长名称、动作可达性、横向溢出和键盘顺序；完成受影响检查并同步导航、滚动与布局相关长期说明。

规格覆盖：用户故事1–3、23–26、29–30、49–52；Q1、Q4、Q6、Q10及Q15中的场次信息弹窗。不依赖项目内部工具栏票据；两者属于不同页面上下文。
