# 02: 统一模型列表与详情操作

**What to build:** 用户在单一模型表格中比较配置，通过名称查看完整信息，继续使用编辑、测试与默认模型配置，而无需切换视图或挤占列表宽度。依据规格 Q3–Q6、Q12–Q15，覆盖用户故事 13–17、41–50 的本页部分。

Blocked by: 01（统一管理布局，完成供应商管理）.

Status: ready-for-agent

- [ ] 复用管理区已统一的视觉与工具栏，不新增独立主题；模型仅保留表格，移除表格／卡片切换与重复常驻详情。
- [ ] 默认展示名称、类别、关联供应商、默认标记、简述和操作；缺失信息明确未知，不从不充分数据推断默认状态或供应商。
- [ ] 名称打开只读详情抽屉，完整参数 JSON、描述及创建人等信息移入详情；列表截断内容可查看全文，详情和代码局部滚动不造成整页横向溢出。
- [ ] 行尾保留编辑、测试和更多；编辑使用既有弹窗，低频及危险操作次级化，不丢弃有效业务能力。
- [ ] 默认模型配置保留为模型页次级入口，默认选择、模型类别及供应商约束沿用现有规则。
- [ ] 搜索、筛选、排序、分页、新增、编辑和测试形成可演示的完整前端流程，沿用现有接口及路由；抽屉关闭后恢复合理焦点。
- [ ] 首次加载不提前显示零；成功为空、无匹配、失败、字段未知分别呈现；刷新失败保留列表及条件，重试不清空筛选，计数区分可靠总量与已加载数量。
- [ ] 危险动作说明对象与影响，执行中防重复、失败保留上下文；所有关联、权限和不可删除限制仍生效。
- [ ] 使用真实浏览器和 HTTP 隔离响应验证名称详情、编辑保存、测试、默认配置、筛选及失败恢复，不测试内部组件状态，不调用付费服务。
- [ ] 覆盖两种主题、规格约定视口、长名称与参数、大量数据、空和失败状态、键盘访问及局部横向滚动；完成本票受影响检查，不等待最终票据补功能测试。
