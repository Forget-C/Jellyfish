# 04: 统一资产卡片与预览、编辑、生成入口

**What to build:** 用户在四类资产的稳定网格中识别资产，点击图片预览、点击名称编辑，通过唯一生成入口发起现有任务，删除经明确确认。依据规格 Q3–Q5、Q8、Q12–Q15，覆盖用户故事 22–27、41–50 的本页部分。

Blocked by: 01（统一管理布局，完成供应商管理）.

Status: ready-for-agent

- [ ] 先定位并修复图片撑大卡片的原因；标题统一为“资产库”，保留演员、场景、道具、服装现有分类及地址参数，删除重复分类卡头。
- [ ] 四类资产使用单一卡片网格及共用工具栏，搜索靠左、新建靠右，保留现有刷新、筛选或分页能力，不新增后端字段。
- [ ] 卡片固定展示封面、名称、最多两行描述及标签，封面基准高约 160px；缺图、图片加载失败、缺描述或标签时使用稳定占位，同排分区对齐，图片不撑破容器。
- [ ] 图片点击打开现有预览并能完整查看；名称使用强调蓝与轻量箭头进入现有编辑页，移除重复详情入口，不重排独立资产档案页面。
- [ ] 卡片底部只有一个“生成／重新生成”入口，缺图区域不重复展示；生成中显示状态、禁止重复触发，成功和失败反馈来自实际响应，不改变原有图片与生成语义。
- [ ] 删除收进“更多”，确认对象名称和影响；失败保留上下文，执行中防重复，既有权限及关联限制保持有效。
- [ ] 加载、成功为空、无匹配、读取失败、刷新失败、未知字段按规格区分；刷新失败保留列表和筛选，计数不伪造总量，不用示例覆盖真实失败。
- [ ] 卡片随实际内容宽度减少列数，手机单列；列表与预览各自滚动，抽屉或弹窗不超屏，关闭预览后焦点合理恢复。
- [ ] 使用真实浏览器与 HTTP 隔离数据覆盖四类资产、预览、编辑入口、单次生成、防重复、删除确认、缺图及失败恢复；生成仅验证前端请求与状态，不调用付费服务。
- [ ] 覆盖两种主题和约定视口、长文本、不同图片比例及多数据，完成本票受影响检查，并检查共享资产展示组件的受影响消费者。
