- [x] 默认字段为名称、类型、默认标记、简介、更新时间、操作；简介单行并可查看全文，未知更新时间显示“—”，不伪造字段。

- 已实现单一表格、唯一类型筛选抽屉、名称直接编辑、测试入口及次级默认／删除操作。原“复制”“导出”没有处理函数，保留为“暂未接入”禁用项；原页面没有有效启停能力，未新建接口或改动独立编辑页。
