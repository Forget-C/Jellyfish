# 07: 统一 Agent 表格与编辑、测试入口

**What to build:** 用户通过单一 Agent 表格和唯一类型筛选定位对象，点击名称直接进入原编辑页，执行测试或经确认的管理动作，不再经过重复详情面板。依据规格 Q3–Q5、Q7、Q12–Q15，覆盖用户故事 18–21、41–50 的本页部分。

Blocked by: 01（统一管理布局，完成供应商管理）.

Status: ready-for-agent

- [ ] 仅保留表格，取消卡片／表格切换和重复常驻详情面板；类型只保留一个筛选入口，不再同时使用重复分类页签。
- [ ] 默认字段为名称、类型、默认标记、简介、更新时间、操作；简介单行并可查看全文，未知更新时间显示“—”，不伪造字段。
- [ ] 名称使用轻量进入指引并直接进入原 Agent 编辑页，独立编辑页不重排；行尾保留测试，其余有效动作归入“更多”。
- [ ] 共用工具栏中搜索靠左、新建靠右，排序及批量管理次级化；搜索、类型筛选、排序、分页及新建沿用现有能力。
- [ ] 默认设置、启停、复制等已有有效动作不因界面精简丢失，现有测试流程、权限和 API 语义不改变。
- [ ] 首次加载不显示零；读取失败显示错误与重试，不呈现“暂无 Agent”或“总计 0”；成功为空、筛选无结果、字段未知独立表达，刷新失败保留数据和条件。
- [ ] 计数区分可靠总量与已加载数量。批量操作选择数量准确，删除确认包含对象或可核对的数量与名单，不要求手动输入名称；执行中防重复、失败保留上下文，保留关联限制。
- [ ] 表格仅局部横向滚动，窄屏工具栏换行、控件高 36px；操作可达，键盘顺序与视觉顺序一致。
- [ ] 使用真实浏览器及 HTTP 隔离响应覆盖名称编辑、测试入口、搜索筛选、新建保存、默认及既有批量动作、删除确认和失败恢复；不改写真实 Agent 或调用付费服务。
- [ ] 两种主题、约定视口、长名称、多数据、空与失败状态检查通过，完成本票受影响检查，不依赖最终票据补齐核心功能测试。
