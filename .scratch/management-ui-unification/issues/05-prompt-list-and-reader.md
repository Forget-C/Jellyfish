# 05: 统一提示词列表与阅读双栏

**What to build:** 用户通过分类列表查找模板并在充足的正文区域阅读，窄屏使用阅读抽屉，继续通过既有弹窗编辑或按规则恢复默认。依据规格 Q3–Q5、Q10、Q12–Q15，覆盖用户故事 33–38、41–50 的本页部分。

Blocked by: 01（统一管理布局，完成供应商管理）.

Status: ready-for-agent

- [ ] 顶部采用共用工具栏，搜索明确为模板名称或简介；保留现有添加能力，不声称支持正文全文搜索。
- [ ] 桌面左栏约 300px，展示分类及模板名称，移除树连接线并以浅底标记选中；右栏弹性占满，去掉外层套详情卡的装饰性容器。
- [ ] 选择模板只更新阅读内容，不自动进入编辑；初始无选择显示简洁引导，不自动选中或修改模板。
- [ ] 阅读顺序为名称与属性、简介、正文、变量与默认值；正文 13–14px，不受矮小预览框限制，必要横向滚动仅限代码局部。
- [ ] 编辑沿用现有弹窗；系统预置、默认标记、编辑权限、删除及恢复默认规则保持有效，覆盖动作说明对象和影响，执行中防重复、失败保留输入及上下文。
- [ ] 桌面列表与正文分别滚动；小于 1024px 先显示列表，点击后打开阅读抽屉，关闭后恢复列表位置和合理焦点，抽屉及操作不超出视口。
- [ ] 搜索及分页保留既有语义，加载、成功为空、无匹配、首次失败、刷新失败分别呈现；重试保留条件，不用空态掩盖错误。
- [ ] 使用真实浏览器与 HTTP 隔离响应覆盖查找、分页、选择阅读、编辑保存、预置权限、恢复默认确认和失败恢复，不修改真实模板。
- [ ] 两种主题、约定视口、长正文、长模板名、多分类、键盘与滚动检查通过，完成本票受影响检查，不推迟到最终票据才验收核心行为。
