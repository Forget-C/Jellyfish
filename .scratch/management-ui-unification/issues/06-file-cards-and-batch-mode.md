# 06: 统一文件卡片与显式批量模式

**What to build:** 用户在稳定文件卡片中浏览真实可用信息，明确区分预览与批量选择，并能识别未接通能力及数据读取失败。依据规格 Q3–Q5、Q9、Q12–Q15，覆盖用户故事 28–32、41–50 的本页部分。

Blocked by: 01（统一管理布局，完成供应商管理）.

Status: ready-for-agent

- [ ] 使用共用紧凑工具栏和单一卡片网格，搜索文件名或标签、标签筛选靠左，批量管理位于次级入口，移除重复“文件列表”卡头。
- [ ] 卡片固定展示缩略图、文件名、类型、时间、标签；缺图用类型图标，长名称可获取全文，缺失时间或数据不编造。
- [ ] 普通浏览与选择分开，仅在既有预览能力可用时启用预览；不让整卡点击同时承担预览与批量选择。
- [ ] 显式进入批量模式后显示复选框、“已选 N 项”和批量工具；退出后恢复普通浏览，选择数量与所选对象一致，不引入隐式批量操作。
- [ ] 核对标记、导出等现有能力，尚未接通的显示“暂未接入”并禁用；移除虚假成功反馈，不新增上传或为通过测试伪造后端业务能力。
- [ ] 首次读取失败显示区域内错误与重试，不呈现“暂无文件”或零总量；刷新失败保留已有列表及条件，成功为空和筛选无结果分别表达。
- [ ] 仅有已加载数量时明确该口径；示例若确需展示须独立标注，不能替代真实失败或启用真实操作。
- [ ] 既有可用批量动作保留原语义、权限和防重复处理；涉及危险操作时可核对对象数量及名单，失败保留上下文，不为本票新增删除能力。
- [ ] 手机单列、控件可换行、内容区正常滚动；预览与批量控件具有可访问名称、键盘反馈，无整页横向溢出。
- [ ] 使用真实浏览器及 HTTP 隔离数据覆盖浏览、筛选、批量选择、未接通能力禁用、失败重试和两种主题的约定视口；只验证现有可用能力的请求，不修改真实文件。完成本票受影响检查。
