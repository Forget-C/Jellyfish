# 01: 统一管理布局，完成供应商管理

**What to build:** 用户进入管理区后，通过一致的导航与紧凑工具栏查找供应商、查看配置状态、打开只读详情并执行现有编辑或测试。以供应商页作为共用布局的第一个完整落地点，其他管理入口仍可使用；不单独交付没有可演示页面的样式层。依据《管理页面布局与视觉统一》规格 Q1–Q6、Q12–Q15，覆盖用户故事 1–12、15–17、41–50 的本页部分。

Blocked by: None (can start immediately).

Status: ready-for-agent

- [ ] 先复现并定位主按钮透明底白字问题，区分样式覆盖、构建或预览环境原因；修复后两种主题下正常、悬停、加载、禁用及焦点状态可辨识，不靠逐页掩盖根因。
- [ ] 管理区保留五个入口及既有导航历史行为；桌面侧栏 216px、菜单高 40px，低于 1024px 为导航抽屉，关闭或选中后焦点合理恢复。
- [ ] 顶栏、32px Logo、品牌文字和主题偏好保持不变；不改变独立画布或无关页面的布局与主题。
- [ ] 供应商页应用标题 16px、计数 13px、桌面控件高 32px／字号 13px、约 240px 搜索、20px 页面留白及 12px 圆角；搜索靠左、新增靠右，排序和低频操作次级化，窄屏控件高 36px、允许换行。
- [ ] 保留供应商、模型、运行设置三个轻量业务页签，去掉重复大卡头与装饰性嵌套边框；必要共用整理保持其余页面可运行，不做无关大范围重构。
- [ ] 供应商仅保留表格，展示名称、地址摘要、凭据配置状态、状态和操作；未知状态不推断为已配置，列表及只读详情不展示密钥。
- [ ] 名称打开按需只读详情抽屉，补充完整地址、描述、创建人等已有信息；不再常驻压缩列表。编辑使用现有弹窗，测试和其他有效业务动作保持原语义，低频及危险动作进入“更多”。
- [ ] 搜索、排序、分页、新增、编辑、测试沿用现有接口与权限；表格长文本可获得全文，局部横向滚动不推动整页，操作区和列表滚动职责明确。
- [ ] 区分骨架、成功为空、筛选无结果、首次读取失败、刷新失败与字段未知；刷新失败保留已有内容和筛选，重试不清空条件，不重复弹出错误。有可靠总量才显示“共 N 项”。
- [ ] 现有删除或覆盖动作确认对象及影响，执行中防重复、失败保留上下文，保留关联限制；本票不增加后端能力或改变 API 契约。
- [ ] 复用管理导航、外观偏好及页面交互浏览器测试，在 HTTP 边界使用隔离数据验证本页完整流程、失败恢复、键盘与抽屉焦点；不调用真实付费服务或修改真实数据。
- [ ] 完成本页两种主题及约定桌面、1024px、375px 视口检查，运行受影响类型检查和回归；共用变化核对首页、项目页及尚未迁移的管理入口，不把本票测试推迟到最终验收。
