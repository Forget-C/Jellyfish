# 管理页面布局与视觉统一

Status: ready-for-agent

确认日期：2026-11-10

## Problem Statement

管理页面与已统一的首页、项目页存在明显的视觉和操作差异。大标题独占一行，搜索、计数、筛选与新增分散排列；白色页签条、外层卡片和详情卡重复分割内容。用户切换管理对象后，需要重新寻找搜索、主要动作和详情入口。

模型、供应商和 Agent 的多视图及重复详情增加操作复杂度；Agent 类型同时出现在筛选与页签中。资产卡片存在重复生成、编辑与详情入口，提示词阅读区受嵌套容器限制，文件批量工具在未选择对象时仍占据主要位置。

当前预览还观察到部分主按钮透明底白字、资产图片撑大卡片，以及文件和 Agent 读取失败后呈现空列表及零计数的问题。这些是待定位的缺陷，不是新设计应保留的行为。需要区分样式或预览环境问题与业务能力不足，不能通过重新排版或模拟成功掩盖问题。

## Solution

将管理区统一为“固定二级导航、紧凑工具栏、按任务选择的内容布局”。继承首页和项目页的雾蓝主题、文字层级、间距、圆角和交互反馈；保留表格比较配置、卡片识别媒体、双栏阅读提示词的不同用途。

本次覆盖模型管理的供应商、模型和运行设置，以及资产库、提示词模板、文件管理和 Agent 管理。保留现有路由、接口、权限和业务规则；独立编辑页面不重排。数据缺失、失败和未接通能力明确呈现，布局调整不扩展后端或数据库。

## User Stories

1. 作为管理区用户，我希望五个管理入口使用一致的视觉层级，以便切换页面时快速理解内容。
2. 作为用户，我希望顶栏、Logo 和品牌字号保持已确认尺寸，以便管理页面与首页、项目页衔接自然。
3. 作为用户，我希望继续使用现有两种雾蓝主题及浏览器偏好，以便获得一致的阅读体验。
4. 作为桌面用户，我希望侧栏稳定显示五个管理入口，以便快速切换管理对象。
5. 作为窄屏用户，我希望通过导航抽屉访问相同入口，以便内容区域不被固定侧栏挤占。
6. 作为用户，我希望标题、计数、搜索和操作紧凑排列，以便尽快看到业务内容。
7. 作为用户，我希望搜索与常用筛选靠左、主要创建动作靠右，以便形成稳定操作习惯。
8. 作为用户，我希望排序和批量管理不占据主要操作层级，以便识别当前最重要的动作。
9. 作为用户，我希望表面、留白和对齐区分区域，以便减少嵌套边框造成的视觉干扰。
10. 作为用户，我希望主按钮、状态文字和焦点清晰可见，以便在两种浅色背景下可靠操作。
11. 作为供应商管理者，我希望在表格中比较名称、地址、凭据配置状态和状态，以便判断配置情况。
12. 作为供应商管理者，我希望列表只显示凭据配置状态，以便识别缺失配置而不暴露密钥。
13. 作为模型管理者，我希望比较模型名称、类别、供应商、默认标记和简述，以便选择需要管理的模型。
14. 作为模型管理者，我希望默认模型配置保持可达，以便继续维护现有默认规则。
15. 作为模型或供应商管理者，我希望点击名称按需查看只读详情，以便阅读完整参数而不压缩列表。
16. 作为模型或供应商管理者，我希望编辑和测试保留明确入口，以便沿用既有操作流程。
17. 作为配置维护者，我希望长描述、完整参数和创建人移至详情，以便列表保持可扫读。
18. 作为 Agent 管理者，我希望使用单一表格比较名称、类型、默认标记、简介和更新时间，以便快速定位对象。
19. 作为 Agent 管理者，我希望类型筛选只出现一次，以便避免重复或相互影响的筛选入口。
20. 作为 Agent 管理者，我希望点击名称直接进入现有编辑页，以便减少经过重复详情面板的步骤。
21. 作为 Agent 管理者，我希望测试操作保持可达，以便检查既有 Agent 的行为。
22. 作为资产管理者，我希望四类资产共享稳定卡片布局，以便通过封面和名称快速识别资产。
23. 作为资产管理者，我希望点击图片预览、点击名称编辑，以便明确区分查看图片与修改资产。
24. 作为资产管理者，我希望只有一个生成或重新生成入口，以便避免重复操作造成的困惑。
25. 作为资产管理者，我希望生成中有明确状态并防止重复触发，以便避免重复提交任务。
26. 作为资产管理者，我希望缺图、缺描述或缺标签时布局仍稳定，以便同排卡片信息保持对齐。
27. 作为资产管理者，我希望删除位于次级入口并要求确认，以便降低误删风险。
28. 作为文件管理者，我希望卡片固定显示缩略图、名称、类型、时间和标签，以便判断文件用途。
29. 作为文件管理者，我希望预览和批量选择是不同操作，以便不会因查看文件而改变选择状态。
30. 作为文件管理者，我希望进入批量模式后才显示复选框和批量工具，以便普通浏览保持简洁。
31. 作为文件管理者，我希望看到所选数量及真实可用的批量能力，以便知道哪些操作能实际执行。
32. 作为用户，我希望未接通功能明确标注且不可执行，以便不会把占位成功提示当作真实结果。
33. 作为提示词维护者，我希望在分类列表与正文之间快速切换，以便比较和阅读模板。
34. 作为提示词维护者，我希望搜索明确限定在名称或简介，以便理解搜索结果的范围。
35. 作为提示词维护者，我希望选择模板仅更新阅读区域，以便不在无意中进入编辑。
36. 作为提示词维护者，我希望完整阅读正文、变量和默认值，以便不受矮小预览框限制。
37. 作为提示词维护者，我希望系统预置、默认、编辑和恢复默认规则不变，以便保持现有权限与保护。
38. 作为窄屏提示词用户，我希望打开阅读抽屉后能返回原列表位置，以便连续浏览模板。
39. 作为运行设置维护者，我希望使用限宽、清晰分组的表单，以便舒适编辑全局运行参数。
40. 作为运行设置维护者，我希望显式保存并在失败后保留输入，以便重试时无需重新填写。
41. 作为管理区用户，我希望列表和正文承担必要滚动，以便操作区保持可达且不出现重复滚动。
42. 作为表格用户，我希望宽表格只在局部横向滚动，以便不会把整页导航拖出视口。
43. 作为用户，我希望加载、成功为空、筛选无结果和失败分别展示，以便判断下一步该创建、调整筛选还是重试。
44. 作为用户，我希望刷新失败保留已显示数据和筛选条件，以便不中断当前工作。
45. 作为用户，我希望数量与未知字段按真实数据口径显示，以便不会把部分加载或失败误认为零记录。
46. 作为用户，我希望危险操作确认说明对象与影响范围，以便明确将要删除或覆盖的内容。
47. 作为批量操作者，我希望核对所选对象和数量，以便执行前发现误选。
48. 作为用户，我希望操作执行期间阻止重复提交、失败后保留上下文，以便安全恢复工作。
49. 作为键盘用户，我希望所有入口具有可访问名称、可见焦点和正确焦点恢复，以便无需鼠标也能完成操作。
50. 作为维护者，我希望使用隔离数据验证前端行为，以便回归测试不修改真实业务数据或调用付费生成。

## Implementation Decisions

### 范围与模块职责（Q1、Q5）

- 修改管理区共用布局与工具栏，以及供应商、模型、运行设置、资产库、提示词模板、文件管理、Agent 列表及其按需详情呈现。
- 资产档案、Agent 编辑等独立编辑页面不重排；入口可以调整，进入后沿用原业务布局和保存机制。
- 保留现有地址、分类参数、导航选中、返回与浏览器历史行为；不因视觉调整改变业务对象身份。
- 保留现有接口、权限、关联限制和默认规则，不修改后端、表结构或 API 契约，不借本次改版扩大接口重构。
- 先定位主按钮底色丢失、资产图片尺寸失控和失败误显示为空的问题。环境或样式覆盖须定位原因，不以新设计默认值解释缺陷。
- 接口不足的新增展示只能使用独立、明确标注的示例。真实请求失败不能被示例或假成功掩盖；需要后端的能力列为后续工作。

### 通用视觉（Q2）

| 项目 | 确认规则 |
| --- | --- |
| 顶栏与品牌 | 保留现有尺寸；Logo 32×32，品牌桌面 20px／700、手机 18px／700，行高 28px、图文间距 8px；桌面顶栏 56px，手机 56＋44px |
| 主题 | 雾蓝微渐变为默认，保留雾蓝纯色和现有浏览器偏好；不新增管理主题 |
| 页面背景 | 默认 125 度、从 #F0F5FC 至 #F7F8FB 的微渐变；纯色为 #F7F8FB |
| 内容色彩 | 白色表面，主文字 #263244，次级文字 #536174，强调色 #245FC5，选中底色 #E4EDFB |
| 管理侧栏 | 桌面 216px；菜单高 40px、字号 14px；浅底选中，无结构性分割线 |
| 标题与计数 | 页面标题 16px／600；计数 13px、次级色 |
| 列表工具栏 | 桌面单行基准约 52–56px；控件高 32px、字号 13px |
| 搜索 | 默认约 240px，可按可用宽度收缩，不横跨整页 |
| 间距 | 内容左右桌面 20px、手机 16px；大区域 20px、区域内 12–16px、控件组 8px |
| 表面与文字 | 内容表面圆角 12px；条目名称 14px／650，正文 13–14px，辅助信息 12px |

- 移除纯装饰外框、重复卡头及大卡片套小卡片；以留白、对齐和轻底色建立层级。
- 表单边界、选中反馈、错误状态和键盘焦点必须可辨识；图标操作具有可访问名称。
- 主要操作使用实心强调蓝，筛选或导航选中使用浅底色。修复主按钮透明底白字问题，并检查悬停、禁用、加载状态。
- 不新增装饰性统计卡、不通过隐藏必要信息或缩小字体强塞内容，也不为填满页面添加无用内容。

### 导航、工具栏与视图（Q3、Q4）

- 左侧保留模型管理、资产库、提示词模板、文件管理和 Agent 管理五个入口。
- 模型管理保留供应商、模型、运行设置三个业务页签；资产库保留演员、场景、道具、服装四个现有分类页签。“场景”为既有 UI 标签，对应领域中的场所资产，本次不更改领域定义或批量改名。
- 业务页签轻量呈现，去掉厚重白条和重复标题；有空间时页面标题与页签同排，搜索等工具组成下一行，不强行把所有控件塞在一行。
- Agent 类型只保留一个筛选入口，不再同时展示重复的分类页签。
- 搜索与常用筛选靠左、新建靠右；排序和批量管理放入次级入口。名称统一为“资产库”，移除重复分类卡头和“文件列表”卡头。
- 供应商、模型、Agent 只保留表格，取消表格／卡片切换；资产和文件只保留卡片网格；提示词使用分类列表加正文阅读双栏。
- 表格保留轻表头、列对齐和悬停反馈，减少外围框、竖线及密集横线；长内容截断后可获取全文。

### 供应商、模型与 Agent（Q6、Q7）

| 对象 | 默认字段 | 名称操作 | 行尾操作 |
| --- | --- | --- | --- |
| 供应商 | 名称、地址摘要、凭据配置状态、状态、操作 | 只读详情抽屉 | 编辑、测试、更多 |
| 模型 | 名称、类别、关联供应商、默认标记、简述、操作 | 只读详情抽屉 | 编辑、测试、更多 |
| Agent | 名称、类型、默认标记、简介、更新时间、操作 | 直接进入现有编辑页 | 测试、更多 |

- 供应商凭据只展示配置状态，不展示密钥；未知状态不推断为已配置。
- 模型和供应商详情展示完整参数、长描述、创建人等补充信息，按需打开，不常驻占据列表宽度。编辑使用原有弹窗，不新建编辑流程。
- 默认模型配置保留在模型页的次级入口。
- Agent 名称使用可点击指引，简介最多一行并可查看全文，未知更新时间显示“—”；取消重复常驻详情面板。
- 低频和危险动作收进“更多”，不删除仍有效的业务能力，不改变测试、默认选择、启停等原有语义。

### 资产卡片（Q8）

- 固定展示封面、名称、最多两行描述、标签。封面基准高约 160px，同排信息位置稳定；缺图或缺少描述、标签不改变卡片分区高度，使用稳定占位。
- 缩略图不得撑大卡片，预览仍能完整查看图片。保留四类资产识别与既有图片处理行为。
- 图片点击打开现有预览；名称使用强调蓝与轻量箭头，点击进入现有编辑页。
- 卡片底部紧凑操作区只保留一个“生成／重新生成”入口；缺图区域不重复出现生成按钮。生成中显示状态并阻止重复触发。
- 删除放入“更多”并保留确认；不再显示重复详情入口。
- 项目卡片没有底部动作的规则不扩展到资产生成，避免删掉独立业务动作。

### 文件卡片（Q9）

- 固定展示缩略图、文件名、类型、时间和标签，缺图用类型图标。
- 普通浏览与批量选择分开；仅在现有预览能力可用时启用预览，不让整卡点击同时承担预览和选择。
- 显式进入批量模式后才显示复选框、“已选 N 项”及批量标记、导出等工具。
- 未接通的能力显示“暂未接入”并禁用，不触发虚假成功提示，不新增上传能力。

### 提示词双栏（Q10）

- 桌面左栏约 300px，展示分类和模板名称，取消树连接线，使用浅底选中态；右栏弹性占满剩余宽度。
- 搜索移至顶部，明确限定为模板名称或简介，不暗示支持正文全文搜索。
- 选择模板只更新右侧阅读内容，不自动编辑；未选择时显示简洁引导，不自动选中模板。
- 阅读顺序为名称与属性、简介、正文、变量与默认值。正文使用 13–14px，不限制成矮小预览框，代码确需横向浏览时仅在局部滚动。
- 编辑沿用现有弹窗，系统预置、默认标记、编辑权限和恢复默认规则保持有效。

### 运行设置（Q11）

- 表单靠左，最大宽约 640px；字段纵向排列，标签 13px、控件高 36px、字段间距 16px，右侧允许合理留白。
- 取消重复标题与大说明框；“默认模型在模型页维护”改为轻量说明和跳转入口。
- 保留显式保存，执行中阻止重复提交，失败保留输入。表单控件不套用列表工具栏的 32px 高度。

### 滚动与响应式（Q12）

- 管理页允许内容滚动，不套用首页桌面一屏容纳全部内容的专属规则。
- 桌面顶栏、侧栏、页面操作区保持可达，列表或正文承担主要滚动，避免页面与列表重复滚动。提示词双栏分别滚动。
- 小于 1024px 使用管理导航抽屉，工具栏允许分行，操作控件高 36px，视觉顺序与键盘顺序一致。
- 提示词小于 1024px 先显示列表，选择后打开阅读抽屉；关闭后恢复列表位置和合理焦点。
- 卡片按实际内容区宽度减少列数，手机单列；宽表格仅在自身容器横向滚动，不产生整页横向溢出。
- 抽屉不超出屏幕，按需浮层打开和关闭不丢失必要上下文，不能依赖隐藏溢出来裁掉操作。

### 数据状态与危险操作（Q13、Q14）

| 状态 | 展示及恢复行为 |
| --- | --- |
| 首次加载 | 接近目标列表结构的骨架，不提前显示零计数 |
| 成功为空 | 对象化“暂无”文案，有权限及既有能力时提供创建入口 |
| 筛选无结果 | 无匹配结果，并提供清除筛选 |
| 首次读取失败 | 区域内错误说明和重试，不能显示为空列表 |
| 刷新失败 | 保留已显示数据及筛选，标注刷新失败并可重试 |
| 未知字段 | 明确“未知”或“—”，不推断为零或成功 |

- 有可靠总量才写“共 N 项”；仅有当前加载数量时写“已加载 N 项”。不把请求失败变成“总计 0”。
- 重试不清空筛选，不连续弹出重复错误通知。
- 删除确认展示具体对象名称；批量删除显示数量并允许核对对象，不默认要求手动输入名称。
- 恢复默认等覆盖操作说明影响范围。执行中防止重复提交，失败保留上下文，成功后更新相关列表。
- 既有权限、关联限制和不可删除规则继续有效，界面收敛不绕过保护。

## Testing Decisions

### 已确认的测试边界

用户在完整设计确认后，额外确认以真实浏览器页面作为主要测试边界，复用现有管理导航、主题和页面交互测试。在 HTTP 边界提供隔离数据与失败响应，不测试组件内部状态，也不为了覆盖率新增低层测试边界。

好的测试通过用户可见结果验证行为：点击后到达正确页面或抽屉，操作发出预期请求，成功后列表反映响应，失败后保留输入及筛选，布局和焦点可用。不得用内部状态、类名或组件结构匹配代替行为验收；可用实际几何尺寸及计算样式验证明确的外观约束。

### 模块、先例与覆盖

- 复用已有管理导航浏览器回归，覆盖五个入口、页面路由、编辑入口、筛选、窄屏导航和选中反馈。
- 复用现有外观偏好测试，验证两种主题、存储恢复、主按钮可读性及独立画布主题隔离。
- 参考现有页面交互回归扩展供应商、模型、资产、Agent、提示词及运行设置操作；文件未接通能力只验证真实限制和占位，不伪造业务成功。
- 验证单一表格或卡片视图、默认字段、只读详情、名称编辑去向、唯一生成入口、批量选择、模板阅读与现有编辑操作。
- 覆盖长名称、长描述、多个分类、大量数据、缺图及图片加载失败、首次加载、成功为空、筛选无结果、读取失败、刷新失败及重试。
- 搜索、筛选、排序、分页、编辑、保存、测试、生成和删除确认使用隔离数据；HTTP 边界验证必要的请求身份与避免重复提交，不调用付费生成或更改真实业务数据。
- 验证密钥不出现在供应商列表和只读详情的可见内容中；保留现有编辑凭据流程的权限及遮蔽机制，不额外暴露秘密。
- 验证键盘激活、Tab 顺序、可访问名称、焦点样式、抽屉关闭后的焦点恢复，以及失败后的可恢复操作。

### 视觉与响应式验收（Q15）

| CSS 视口 | 检查重点 |
| --- | --- |
| 1440×900、1366×768 | 顶栏尺寸不变；侧栏、工具栏层级统一；主按钮可辨；卡片封面不撑破；表格与阅读区域利用空间 |
| 1024×768 | 桌面侧栏断点、工具栏空间、局部滚动、主要操作可达 |
| 375×812 | 两行顶栏、导航抽屉、控件换行、单列卡片、提示词阅读抽屉、无整页横向溢出 |

- 两种主题均检查，补充 1024px 断点两侧和桌面与手机顶栏切换处的检查，防止边界漏档。
- 页面内容不强制一屏展示；验收主要操作、内容滚动和局部横向滚动的归属，不能把合理纵向滚动判为失败。
- 实现时按仓库要求运行类型检查及受影响回归；共享布局或主题改动扩展验证到首页、项目页等受影响消费者。
- 自动化浏览器与截图检查只能证明相应前端行为；HTTP 夹具测试不代表真实后端业务链路、供应商能力或生产部署已验收。

## Out of Scope

- 后端实现、数据库表结构、API 契约变更及未授权的接口重构。
- 重排资产档案、Agent 编辑等独立编辑页面的业务布局。
- 修改生成画布或场次画布的布局、主题、任务机制及业务内容。
- 新增文件上传、补齐尚未接通的导出或批量标记后端能力。
- 新建管理专属主题、装饰性统计面板、额外视图模式或为填满页面增加模拟业务内容。
- 改变权限、系统预置保护、默认规则、关联约束或现有持久化语义。
- 在真实业务数据上执行破坏性验收，或为视觉回归调用付费生成。
- 本次规格发布不授权开始实现、拆分票据、提交代码或部署。
