# 12: 下一轮排队、编辑与移除

Status: ready-for-agent
Blocked by: 02

**What to build:** 工作期间可用发送菜单把另一项工作排到下一轮，排队内容显示在输入框上方。

对应[后续实现规格中的用户故事](../spec.md#user-stories) 11、23。

## Acceptance criteria

- [ ] 当前轮次结束前可查看、编辑或移除等待消息；编辑后处理最终内容，已移除项不被受理。
- [ ] 重连恢复待处理队列，轮到该项时只受理一次并分配新的轮次身份；当前任务的目标及批准范围保持原值。
- [ ] 以一条工作中的任务和两条后续消息演示排队、修改、删除和恢复，核对公开事件及最终会话顺序。

## Comments

### 实施与验证记录

下一轮队列可编辑、移除和恢复。浏览器演示当前任务、两条后续消息、修改和移除；后端检查独立轮次身份和并发受理。
