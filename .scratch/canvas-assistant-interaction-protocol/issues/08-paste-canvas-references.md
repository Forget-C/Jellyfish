# 08: 粘贴卡片或编组到对话

Status: ready-for-agent
Blocked by: 02, 06

**What to build:** 用户能用粘贴和 @ 明确指向对象，发出消息时固定来源画布和可见成员。

对应[后续实现规格中的用户故事](../spec.md#user-stories) 6、7、20。

## Acceptance criteria

- [ ] 单卡及多选逐项可移除；复制 A、B 后改选 C，「这两张」仍指 A、B，只有明确提及当前选区或未指定对象时才用选区解释指代。
- [ ] 正式编组为可展开引用。成员从 4 张增到 5 张时，可沿用或更新；原成员已删除时标明失效项，调整前不执行涉及该项的动作。请求重试沿用受理时的引用。
- [ ] 先复制卡、再复制剧本文字，粘贴得到最后复制的文字；粘贴到助手引用原对象，粘贴到画布仍按既有副本规则处理。
- [ ] 跨画布引用核对读取权；修改源卡回到源画布提出并审批。真实页面可从输入草稿一路核对到助手实际采用的目标。

## Comments

### 实施与验证记录

剪贴板支持单卡、多选和正式编组引用。后端冻结受理时引用并校验跨画布读取权，源卡写入仍在源画布审批。受控页面核对引用、提案目标和保存结果。
