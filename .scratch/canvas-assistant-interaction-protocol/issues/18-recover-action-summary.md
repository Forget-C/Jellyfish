# 18: 从一条摘要核对写入、排版和生成

Status: ready-for-agent
Blocked by: 07

**What to build:** 一次批准可以列出编辑、排版和生成；原回复末尾按各执行方回执汇总结果，后续进展就地更新。

对应[后续实现规格中的用户故事](../spec.md#user-stories) 22、23。

## Acceptance criteria

- [ ] 用「改提示词、整理卡片、生成一版」展示已写入、等待编辑器、已提交生成三个独立状态及对应入口。纯咨询直接回答；冲突能从摘要回到对应组。
- [ ] 仅等待实际依赖。获批提示词生效后，纯展示排版不阻塞视频提交；生成输入实质变更时该动作等待新差异获批。
- [ ] 在隔离 MySQL 与真实 Worker 中中断回执、重启并重开画布。编辑器只接续待执行布局，Worker 查原请求，业务提交数恰为一版；产物就绪后原摘要更新。

## Comments

### 实施与验证记录

摘要分别展示业务写入、编辑器排版和生成。隔离 MySQL Worker 测试核对重启后按原请求恢复；新增审批测试核对输入变化时的原值与新值、重放和重新批准后恰好运行一次。浏览器验证组合审批和原回复摘要。
