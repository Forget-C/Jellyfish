# 10: 回答创作问题并恢复本轮

Status: ready-for-agent
Blocked by: 02

**What to build:** 需要决定创作取向时，助手在当前轮次请求选择或自由输入，用户可离开后继续回答。

对应[后续实现规格中的用户故事](../spec.md#user-stories) 12、23。

## Acceptance criteria

- [ ] 在会实质改变交付的场景展示具体问题及可选答案，也接受自由回答；回复携带问题身份，回到提出问题的轮次接续。
- [ ] 待回答时断线、关面板或重开，从原快照恢复同一问题和已知状态；重复答复不会启动两轮工作。
- [ ] 同屏留有「批准生成一版」时选择「采用紧张逼近」只更新创作方向，生成仍待审且提交数为零。

## Comments

### 实施与验证记录

创作回答绑定原轮次问题，使用原 Deep Agents 检查点接续。浏览器和后端覆盖面板重开、回复重放及与生成审批的隔离。
