# 13: 针对一个字段修订提案

Status: ready-for-agent
Blocked by: 07

**What to build:** 用户可在对话的具体差异上反馈，修改该字段及其依赖部分并保留其他独立组决定。

对应[后续实现规格中的用户故事](../spec.md#user-stories) 13、15、17。

## Acceptance criteria

- [ ] 在镜头 03「时长 8 秒 → 5 秒」上输入「改为 6 秒」，新版本绑定来源提案、组和字段，展示正确的新差异。
- [ ] 新版本重新核对最新字段及组内依赖；旧版本不再接受这次批准，已决定的独立组不被重审或重复应用。
- [ ] 已存在整份修订入口仍可使用。字段级反馈在原对话完成，卡片布局保持原样。

## Comments

### 实施与验证记录

时长等字段可从原对话修订，版本绑定组及字段，已决定独立组保留原回执。后端测试覆盖版本替换、组内依赖与冲突，整份修订入口继续可用。
