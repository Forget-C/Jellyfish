# 17: 委派分镜设计与素材审看

Status: ready-for-agent
Blocked by: 02, 09

**What to build:** 主助手可按任务分派给分镜设计和素材与连续性审看两个注册角色，汇总各自的可核对交付。

对应[后续实现规格中的用户故事](../spec.md#user-stories) 4、8、9、23。

## Acceptance criteria

- [ ] 原生委派与普通文本结构化委派遵守同一角色、资源、版本、工具和预算约束。首版一层委派，简单任务可直接交付。
- [ ] 可并行的任务并行交付，有依赖的步骤等待实际结果。对话展开可见任务范围、模型、Skill、素材时段和失败原因。
- [ ] 审看失败时列明覆盖范围，可交付无依赖的部分；必须先通过审看的后续步骤保持等待。子任务只交回依据与候选建议。
- [ ] 重启后已完成子任务只计一次；停止后不再分派，迟到结果不会追加到已停止轮次的提案。

## Comments

### 实施与验证记录

两个只读专业子任务可由原生或结构化路径调用。后端回归覆盖并行依赖、失败范围、持久结果和停止后拒绝迟到结果；回执列出范围、模型、技能和观察依据。

### 本轮遗漏复核

普通文本模型的结构化委派完成后由主助手复核、综合结果，再决定是否形成提案。回归覆盖审看失败后独立任务仍交付，依赖任务受阻。
