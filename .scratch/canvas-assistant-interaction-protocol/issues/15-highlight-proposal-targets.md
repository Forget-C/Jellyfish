# 15: 用青绿色外阴影查看提案范围

Status: ready-for-agent
Blocked by: 07

**What to build:** 在画布上识别当前查看的提案版本涉及哪些元素，对话保留差异、结果与主动定位入口。

对应[后续实现规格中的用户故事](../spec.md#user-stories) 20、21、27。

## Acceptance criteria

- [ ] 卡片外阴影可与蓝色选中和筛选描边共存，卡面布局、选区、输入焦点保持稳定。仅参考过的卡不亮，新卡成功创建后出现；连接变动提示连线和端点。
- [ ] 查看另一提案切换范围，关闭面板、继续编辑后保留。手动隐藏再刷新能恢复原选择；其他版本的迟到回执只更新原审批卡。
- [ ] 主动定位支持面板外可见区域与折叠组外框。删除后保留名称和回执并关闭定位，撤销后原审批卡标明「曾写入，后已撤销」。

## Comments

### 实施与验证记录

青绿色外阴影独立于蓝色选中，保留卡片布局。受控浏览器核对真实选区、显示与隐藏以及关闭面板后的范围；回执跟随原提案的删除、定位和撤销状态。
