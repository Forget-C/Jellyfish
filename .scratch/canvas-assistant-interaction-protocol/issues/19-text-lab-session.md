# 19: 文本实验室接入共用会话协议

Status: ready-for-agent
Blocked by: 02, 06

**What to build:** 用户通过共用会话与对话组件从文本实验室提交、阅读流式回复、停止并回填历史。

对应[后续实现规格中的用户故事](../spec.md#user-stories) 24、27。

## Acceptance criteria

- [ ] 从真实实验室打开或恢复文本会话，流式更新原回复，保留模态参数、素材、历史分页和输入回填。
- [ ] 主动停止或断流后保留已收到的文字。能核对终态时显示真实终态，暂时无法核实时说明未知；重连不会重复发起生成。
- [ ] 每轮模型输入独立；回填并主动发送产生新轮次。复用真实页面及隔离 SSE 验证重复事件、停止、焦点与历史阅读。

## Comments

### 实施与验证记录

文本实验室保留会话、模态配置及历史。隔离 SSE 与浏览器覆盖重连复用请求键和事件游标、并发去重，以及按已知终态或未知显示。

### 本轮遗漏复核

SSE 发出的文字可从历史恢复，重放原请求遵守事件游标。当前进程缺少上游运行时保留部分回复并标明终态未知，不创建新供应商请求。
