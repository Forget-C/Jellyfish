## Acceptance criteria

- [ ] 核对实际型号、接入及各项声明，验证完整工具往返，记录供应商实际收到的文本、图片、静帧、连续画面或音轨；缺失能力明确记录。
- [ ] 以同组已知素材分别运行「改一句提示词」与「审看整场后改两张卡」，人工核对命中目标、画布类型边界、证据时间段及专业判断。
- [ ] 分别记录两项任务的调用次数、响应时间、token 消耗、可复核的回执与观察结论。与可控模型的结果分开呈现。
- [ ] 外部条件为可用测试模型配置；条件未满足时注明未实测项与原因。以真实记录作为本票验收依据。
