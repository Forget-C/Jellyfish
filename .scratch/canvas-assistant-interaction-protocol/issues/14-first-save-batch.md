# 14: 未保存自由画布首次批量写入

Status: ready-for-agent
Blocked by: 07

**What to build:** 用户在新草稿中一次确认「建两卡并连接」，成功后正式画布和原对话一起可恢复。

对应[后续实现规格中的用户故事](../spec.md#user-stories) 17、18。

## Acceptance criteria

- [ ] 首次创建画布、应用获批组、归档会话及记录回执在同一事务完成。未勾选独立组待审，已应用改动可撤销。
- [ ] 连线非法或同组写入失败时整组回滚，保留本地草稿和提案，没有空的正式画布。
- [ ] 隔离 MySQL 中模拟成功后响应丢失，按原请求重试只得到一张画布、两张目标卡、一条连接和一份决定记录。

## Comments

### 实施与验证记录

首次保存以同一事务创建画布、应用获批组和保存会话决定。隔离 MySQL 已覆盖响应丢失后的同请求重放，并核对画布、卡片、连线与回执数量。
