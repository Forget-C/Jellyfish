# 16: 自动审批经过代码校验与独立复核

Status: ready-for-agent
Blocked by: 07

**What to build:** 用户可按画布授权自动审批，并在每组结果中核对规则、模型、授权依据与决定来源。

对应[后续实现规格中的用户故事](../spec.md#user-stories) 13、16、17。

## Acceptance criteria

- [ ] 默认人工；自动模式中服务先核对目标、字段、版本、数量、依赖及权限，再由独立只读审批 Agent 核对原话、实际影响和已拒绝内容，签发前复查。
- [ ] 明确授权的合法编辑通过独立复核后执行。推断删除、不明确的解除采用或数量不清的生成保留人工判断，业务校验失败显示受阻；复核超时或无效输出转人工。
- [ ] 隔离环境并发验证人工拒绝、权限撤回及版本变化。迟到复核不会推翻人工决定或触发写入；人工批准直接走业务校验。

## Comments

### 实施与验证记录

人工为默认模式。自动方案先校验确定性条件，再调用独立只读审批 Agent，签发前对版本、权限和用户决定复查。回归覆盖人工决定、权限撤回、版本变更和无有效复核时等待人工。
