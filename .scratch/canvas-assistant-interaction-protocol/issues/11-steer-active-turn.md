# 11: 运行中补充指令与停止后续动作

Status: ready-for-agent
Blocked by: 05

**What to build:** 同一任务执行时可继续输入，「只改 03，先别生成」约束尚未执行的动作并反馈真实受理状态。

对应[后续实现规格中的用户故事](../spec.md#user-stories) 10、14、23。

## Acceptance criteria

- [ ] 工作期间默认发送为补充到本轮，用户可见本轮已收到指令。补充改变目标或数量时，原待审版本停止接受批准。
- [ ] 对尚未提交、已受理、受理情况暂时未知三种生成状态分别验收：停止后续提交、显示已有任务、先查原回执。停止助手不会把已受理任务显示为已取消。
- [ ] 指向审批卡的明确确认经业务决定入口处理；停止主轮次后迟到结果不产生新提案、写入或追加生成。

## Comments

### 实施与验证记录

补充指令归入当前逻辑轮次，旧执行租约失效。受控测试核对迟到结果不会制造新提案或追加生成，已受理的生成继续显示原任务。

### 本轮遗漏复核

公开 API 验证运行中补充可把范围从镜头四改到指定的镜头三，重发仍返回原轮次；点名不存在的镜头不会被替换为当前选区。
