# 01: 审批冲突与决定重放

Status: ready-for-agent
Completion: complete
Blocked by: None

**What to build:** 通过现有按钮批准编辑时，为这一次决定保存逐组结果，使冲突、拒绝和成功在网络重试后都可核对。

对应[后续实现规格中的用户故事](../spec.md#user-stories) 14、17。

## Acceptance criteria

- [x] 用隔离 MySQL 复演已知缺陷：手改字段使审批全部冲突，将字段恢复原值，再重发同一决定。两次得到相同的冲突结果，画布修订、撤销记录和运行数均不增加。
- [x] 批准混合组时记录每组结果；重启后重放仍返回原有成功、冲突或拒绝记录，成功组只写入一次。成功写入与相应回执同事务保存。
- [x] 决定标识绑定来源、提案版本、动作和所选组。用户核对最新差异后可只对冲突组另作决定；旧决定的内容和结果仍可查询。

## 验收记录

实现提交为 `7fae7fa7`。隔离 MySQL 上的审批和生成套件共 25 项通过，覆盖全组冲突、字段还原后原决定重放、新决定写入，以及部分批准后 Worker 和 HTTP 服务重启。前端类型检查和后端 Pylint 通过。
