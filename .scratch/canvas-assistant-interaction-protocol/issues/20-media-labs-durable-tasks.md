# 20: 图片与视频实验室恢复原任务

Status: ready-for-agent
Blocked by: 02, 06

**What to build:** 两种媒体实验室复用会话与对话组件，以各自参数直接受理一次后台生成并在原会话恢复。

对应[后续实现规格中的用户故事](../spec.md#user-stories) 25、27。

## Acceptance criteria

- [ ] 图片和视频分别从真实页面提交素材和参数。主动发送授权该次提交，保持本模态校验、草稿、结果预览与历史分页。
- [ ] 受理后关页、重开或重试，恢复同一任务及实际进度，结果归回来源会话。失败或结果未明时据实显示，不因恢复重复提交。
- [ ] 回填历史后核对图片参数及视频素材配置。只有用户主动再次提交才开启新轮次和新任务；运行状态从实际回执派生。

## Comments

### 实施与验证记录

图片和视频实验室沿用共用会话身份，由原任务回执派生展示状态。实验室浏览器回归覆盖原任务恢复、参数与素材回填；重复提交使用同一受理键，主动发送另开轮次。
