# 21: 双画布完整创作旅程验收

Status: ready-for-agent
Blocked by: 08, 09, 10, 11, 12, 13, 15, 18

**What to build:** 用可控模型、已知素材和真实浏览器，在两个画布完成同一导演任务，核对跨票功能组合后的结果。

对应[后续实现规格中的用户故事](../spec.md#user-stories) 1、2、5、6、7、10、11、12、14、15、19、20、21、22、23。

## Acceptance criteria

- [ ] 两种画布分别复制目标镜头、先给方案、回答问题，在工作中补充和排队；核对问题回答及排队项没有批准待办，实际采用的引用未随改选变化。
- [ ] 对具体字段修订、勾选部分组并回复「确认」。验证当前版本、业务回执、画布实际保存内容、外阴影和真实选区一致，未获批组仍待审。
- [ ] 自由画布按目录限制；分镜局部调整时其他镜头的共享来源与配置符合预览。批准前相应业务提交数为零，允许生成一版时由真实 Worker 只提交一版。
- [ ] 关页或重连后读原回复末尾摘要，核实任务身份、素材及实际观察依据。将本票的受控结果与真实供应商报告区分记录。

## Comments

### 实施与验证记录

自由画布及分镜画布使用真实页面入口、应用 API 和可控模型验收。浏览器覆盖草稿、复制引用、创作问题、运行中补充、排队、部分审批、阴影、共享关系及操作摘要。Worker 重启与精确生成次数另在隔离 MySQL 测试核对。
