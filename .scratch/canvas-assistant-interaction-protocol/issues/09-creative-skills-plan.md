# 09: 用五项专业 Skill 先给方案

Status: ready-for-agent
Blocked by: 04

**What to build:** 同一助手能按需组合专业技能，以只读方案回应「把这一场压到 15 秒」，用户决定何时准备提案。

对应[后续实现规格中的用户故事](../spec.md#user-stories) 4、5、8。

## Acceptance criteria

- [ ] 支持剧本拆解与画布规划、镜头与场面调度、图片生成指导、视频生成指导、成片审看，可按任务组合或由用户用 / 点名，历史可核实实际使用的技能版本。
- [ ] 「先给方案」与 /plan 可读取材料并交付镜头取舍、时长、步骤及涉及卡片。查看和讨论方案期间画布修订与生成提交数均不增加。
- [ ] 「按此方案继续」开始准备具体修改，后续依授权执行；简单编辑可直接展示差异。两种模型路径的观察与建议均受实际素材依据约束。

## Comments

### 实施与验证记录

两条模型路径接入五项专业 Skill，保留实际采用的技能及版本。方案模式允许先读取和讨论，具体改动另行生成可审提案，专业观察附实际证据。

### 本轮遗漏复核

「按此方案继续」和普通用户指令沿统一自动上下文生成可审批提案；页面验证没有审批时画布修订不变。
