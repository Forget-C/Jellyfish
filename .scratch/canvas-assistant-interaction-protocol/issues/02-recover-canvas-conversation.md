# 02: 从画布恢复一次完整对话

Status: ready-for-agent
Completion: complete
Blocked by: None

**What to build:** 从双画布真实问答建立可复用的会话接入标准，用户重开或重连后仍能找到同一轮回复。

对应[后续实现规格中的用户故事](../spec.md#user-stories) 3、22、23。

## Acceptance criteria

- [x] 自由画布与分镜画布分别走打开或恢复、发送、读快照和订阅有序事件四个公开操作。接入能力可查询，两张画布的会话与偏好相互独立。
- [x] 同一请求重试只受理一次。事件关联会话、轮次及相应业务对象；断线后从快照与遗漏事件补齐，重复或迟到事件不会产生重复消息或倒退已知状态。
- [x] 从原有会话读取历史回复、旧单组建议和已知回执；未核实的状态保持未知。相同契约可供其他 Agent 接入，业务数据和运行方式由接入方负责。

## 验收记录

提交 `fa4f5b7a`。双画布公开接口验收覆盖快照、按游标补读、重复发送及会话隔离。双画布真实浏览器旅程、前端类型检查和后端 Pylint 通过。当前事件接入覆盖已完成轮次，后续提案和动作事件由对应票据接入。
