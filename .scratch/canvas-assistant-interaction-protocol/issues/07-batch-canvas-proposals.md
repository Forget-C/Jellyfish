# 07: 一份提案完成跨卡编辑、建卡和关系变更

Status: ready-for-agent
Blocked by: 01, 02, 04

**What to build:** 同一统一批量提案可以编辑现有字段、创建新卡并引用它建立关系，逐组预览、批准和撤销。

对应[后续实现规格中的用户故事](../spec.md#user-stories) 1、2、13、17、19。

## Acceptance criteria

- [ ] 普通文本结构化请求和原生工具调用均能形成版本化提案，展示目标、组依赖、原值、拟议值、动作数量和共享影响；审批前没有持久修改。
- [ ] 同批新卡可被后续动作稳定引用；一组中的编辑及连线一起生效或回滚。独立组可部分批准；一批生效编辑沿用一次撤销。
- [ ] 覆盖建卡、改卡、删除、建立与解除连接、解除采用的校验。自由画布仅接受允许目录，分镜画布允许合法设计卡；共享来源的局部修改不会误改另一镜头。
- [ ] 从公开事件和页面核对提案创建、被替代、决定及执行成功／受阻／失败。旧版本的组不可再次生效，冲突展示原值、当前值和拟议值。

## Comments

### 实施与验证记录

普通文本和原生工具共同产生版本化提案。受控回归覆盖跨卡编辑、同批建卡和连线、部分决定、原子应用、目录限制与冲突。分镜浏览器核对共享运动设计在单镜头上的局部调整。
