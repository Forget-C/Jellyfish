# 05: 版本原文依据与章节工作入口

**What to build:** 每个场次版本使用明确选定的原文依据；章节返回最近编辑的版本，原文修订及历史场次身份均有清楚的处理方式。

**Blocked by:** 01

**Status:** ready-for-agent

- [x] 同一有效场次的 A、B 版本可固定不同原文依据；章节原文更新不自动改写任一方案。
- [x] 进入受影响版本时提示内容有修改，展示现用原文和差异，允许明确更新或继续旧依据；该提示与未保存状态分别表达。
- [x] 明确更新 B 只改变 B 并向有关内容提供实际依据变化信息，供后续指令及审片适用性判断使用；A 可按旧依据继续创作，执行仍须满足其他条件。
- [x] 章节列表保留各场次，每场默认进入最近编辑的版本；浏览某版本不把它当成最近编辑、最新创建或章节交付版本。
- [x] 最近工作入口、切换版本及原文提示不改变章节已交付内容，不新增章节页有修改未交付提示或并列 A／B 方案状态。
- [x] 重新划分明确保留原场次身份时延续版本独立依据；退出当前划分的场次及成果只读，禁止新任务。
- [x] 新场次使用新身份，拆分或合并不按同名、相似原文自动迁移或复制旧方案。
- [x] 验证 A、B 原文不同、只更新 B、返回最近编辑版本和历史场次只读；后续执行、重试与交付入口须沿用此有效性边界。
