# 15: 人工采用与保留空白的时间线

**What to build:** 用户明确将 Take 的真实区间采用到整场时间线，替换、裁短和删除保留其他片段位置，预览真实表现画面、原声及时间线空白。

**Blocked by:** 03, 14

**Status:** ready-for-agent

- [x] 采用须明确执行，素材预览或生成成功不自动加入时间线；同一 Take 可多次采用，各片段有独立身份、源区间及时间位置。
- [x] 待拍占位、真实媒体片段及时间线空白分别表达，预计时长不作为实测媒体区间；空时间线可保存。
- [x] 替换、裁短、删除默认保留其他片段位置及开头／片段间空白，不自动推移、变速、截短或紧排。
- [x] 用 8 秒素材替换 5 秒占位且后面紧接片段时，要求选择有效不重叠源区间或明确调整位置；冲突解决前保留原时间线。
- [x] 移动和重排展示新位置并校验重叠；独立紧排操作明确范围及修改后位置，不把紧排隐含在普通编辑中。
- [x] 采用、区间、位置及紧排属于可保存、可撤销／重做的内容编辑，撤销恢复原位置和空白，不删除源素材或执行记录。
- [x] 预览按真实源区间播放画面及原声，无音轨素材保持静音；开头和片段间空白按原时长播放黑场静音，不直接跳过。
- [x] 片段操作针对明确片段身份，源素材预览和时间线选择分开；采用同一 Take 两次时调整其中一次不影响另一次。
- [x] 关联与时间线操作都有可见按钮和适用的键盘入口，不能只靠拖拽；验证长内容和窄屏下可完成基本采用与区间调整。
- [x] 使用真实有声、无音轨素材及占位验证保存回读、8 秒替换冲突、裁短／删除后保留位置、显式紧排及撤销，测量预览时长和声音区间。
