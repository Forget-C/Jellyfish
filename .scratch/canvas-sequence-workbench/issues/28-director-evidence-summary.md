# 28: 原文与关联依据卡的紧凑展示

**What to build:** 用户通过原文、人物／物件、节拍、事件、空间锚点、场所和缺失引用七类紧凑卡片识别设计依据，明确来源版本与关联有效性，并通过现有详情入口查看或编辑真实内容，不被长文和引用清单占满画布。

**Blocked by:** 25 — 镜头、摄影与验收卡的紧凑展示

**Status:** ready-for-agent

- [ ] 各类型按下表显示主体摘要，范围与状态仍来自真实数据。

| 卡片类型 | 必须展示的信息 |
| --- | --- |
| 原文依据 | 原文短摘录、采用的来源版本、是否存在原文更新 |
| 人物／物件 | 名称、关联角色或道具的绑定情况 |
| 节拍 | 行动目标、预期变化 |
| 事件 | 事件说明 |
| 空间锚点 | 锚点说明 |
| 本场场所 | 已关联的场所名称，未关联时明确提示 |
| 缺失引用占位 | 缺失对象标识、关联对象缺失提示 |

- [ ] 沿用 25 的同类型固定尺寸、固定槽位、文本截断规则，依据卡可比设计卡更矮；无内部滚动或原位展开，不为填满空间拼接全文。
- [ ] 摘要只读取已有字段；人物／物件没有简介字段时不编造简介，角色／道具绑定来自真实关联，不按名称推断类型或镜头归属。
- [ ] 场所名称来自已关联项目资产；加载、读取失败、确认未关联和对象缺失分别表达。失败保留已知身份并提供现有重试入口，不用旧上下文名称替代新对象或误报未关联。
- [ ] 原文版本更新与未保存编辑分别表达；读取失败不伪装成没有更新。短摘录来自当前方案选定的原文依据，不自动换成章节最新内容。
- [ ] 原文卡可进入完整原文与差异查看，明确更新或继续使用旧依据仍遵循原规则，不因查看、缩略或导航自动更新依据。
- [ ] 可编辑依据卡进入准确对象 Modal，完整内容、问题、引用与影响范围可读；编辑关闭保留草稿，手动／自动保存、刷新回读及撤销保持原行为。缺失占位不伪造正文、编辑对象或替代身份。
- [ ] 关键字段缺失、待确定、明确没有和不适用分别表达；待处理数量覆盖完整对象，未保存与范围信息独立，图标具备可读提示，无问题不表示已验收。
- [ ] 依据展开／隐藏、镜头切换、总览与刷新继续沿用真实身份及位置记忆；固定尺寸不被旧内容高度缓存覆盖，不新增业务关系或自动改写设计。
- [ ] 桌面与 390px 窄屏覆盖长原文、多对象名称、来源有更新／继续使用旧依据、资产读取失败重试、缺失引用及依据卡编辑保存回读；详情全文完整可达且关闭后焦点和浏览位置有效。
- [ ] 完成受影响的摘要、来源和引用回归、Modal 与布局稳定性检查及前端类型检查，按实际交付同步文档；其他三画布保持原行为。

## 范围边界

本票依赖 25 的紧凑展示和固定尺寸能力，不依赖其他本轮卡片或导航票据。使用现有来源与资产读取能力，不改变后端契约，不为缺失引用自动建立对象，也不扩展项目资产编辑职责。
