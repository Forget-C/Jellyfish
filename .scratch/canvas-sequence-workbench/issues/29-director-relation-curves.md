# 29: 四类柔性连线与关系辨识

**What to build:** 用户通过柔性曲线、四类关系颜色和简短图例理解导演画布中的真实关联；悬停、选中或键盘聚焦时能识别准确关系与两端对象，展开或隐藏依据时仍能追溯原路径。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 导演画布使用平滑贝塞尔曲线替代避障折线，取消自动节点避障；连线始终在卡片下层，允许经过其他卡片背后时被遮住，不覆盖卡面文字，不提供手动转折点。
- [ ] 当前十五种关系标签全部按下表分类，提供与实际渲染一致的简短图例。

| 关系类别 | 现有关系标签 | 颜色方向 |
| --- | --- | --- |
| 设计关联 | 摄影设计、调度依据、节拍表演、连续性变化 | 低饱和青色 |
| 对象与依据 | 参与对象、覆盖节拍、关联事件、调度人物、位置锚点、变化事件、表演人物、对白依据、共享场所 | 灰蓝色 |
| 验收要求 | 验收依据 | 低饱和紫色 |
| 全场约束 | 全场约束 | 中性灰色 |

- [ ] 类别颜色与直接／间接含义独立；实线／虚线继续表示相对于镜头的直接／间接展示关系，不将虚线解释为推测、缺失或未完成。
- [ ] 箭头沿用已有引用展示方向，端点保持真实对象身份，不改写为执行、拍摄或剪辑顺序。
- [ ] 默认弱化细线；悬停、选中或键盘聚焦关系时突出连线及两端卡片，显示准确名称。完整关系说明具有可访问名称，不能仅靠颜色识别含义。
- [ ] 隐藏依据后压缩的多跳关系按最后一段分类，聚焦时展示完整路径；“覆盖节拍 → 节拍表演”表现为设计关联色与虚线，重新展开依据恢复原关系路径。
- [ ] 缺失引用保留原类别和直接／间接属性，由占位卡提示问题，不增加错误关系类别；没有明确镜头关系的对象不猜边，未绘制的字段引用不随配色改动补线。
- [ ] 移动卡片、缩放、切换镜头／总览、隐藏或展开依据及对象删除后，曲线端点和聚焦对象保持正确；关系查看不修改内容、触发编辑或改变布局。
- [ ] 移除本轮替代后已无用途的导演专属避障实现和仅约束旧路由的断言，保留卡片防重叠、真实关系及其他画布的有效验证，不删除无关实现。
- [ ] 桌面与 390px 窄屏覆盖十五种标签、四类图例、实虚线、箭头、多跳压缩、缺失引用、穿过卡片背后的遮挡及鼠标／键盘聚焦；不得把允许的遮挡继续判为路由失败。
- [ ] 完成相关关系与浏览器回归、前端类型检查，并验证其他三画布保持原连线行为，按实际交付同步文档。

## 范围边界

现有画布已提供真实节点、关系及节点几何，本票可独立完成，不依赖紧凑卡片或小地图；能适配当前节点尺寸及后续固定类型尺寸。只改变导演画布的关系呈现，不增加业务关系、拖线编辑、路由编辑或新布局框架。
