# 25: 镜头、摄影与验收卡的紧凑展示

**What to build:** 用户围绕当前镜头阅读固定尺寸的镜头、摄影与验收要求摘要卡，快速识别核心内容和待处理项，再进入对象 Modal 查看全文、编辑并保存。镜头选择集中到工具栏，摘要更新不改变用户已经整理的布局。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 镜头卡显示镜头序号、可见结果、叙事作用、预计时长与参与对象；参与对象范围待核对和明确无参与对象分别表达。
- [ ] 摄影卡显示所属镜头、构图重心、运动路径、结束画面；验收卡显示验收要求正文，不把其他专业字段拼入摘要。
- [ ] 三类卡片分别采用同类型固定宽高和布局。标题最多一行，主要正文块最多两行，辅助信息使用短行或紧凑标签，多值显示少量名称与“＋N”；无内部滚动、无原位展开、长文不撑高。
- [ ] 摘要直接取当前指定字段，编辑后同步更新，不生成独立 AI 摘要。关键缺项保留“未填写／待确定”，不拿其他字段补位；“明确没有／不适用”不计为缺项。
- [ ] 待处理显示图标与数量，数量仍覆盖整个对象的已有问题；未保存使用独立图标，两者具备可读名称和悬停、键盘提示。适用范围保留短文本，无问题不显示完成勾号。
- [ ] 卡片点击进入原对象 Modal，全文、完整问题与引用保持可读；编辑和关闭保留同一场次草稿，手动／自动保存、刷新回读和撤销维持原语义。共享验收要求仍指向同一对象，影响范围准确。
- [ ] 镜头选择从卡面集中到工具栏；空镜头与失效选择保持真实提示，不自动创建镜头或选择替代对象。切换镜头及从明确对象入口定位继续可用。
- [ ] 固定类型尺寸参与现有多列布局和增量补位；旧缓存尺寸不能恢复出同类不同高度。保留有效位置和视角记忆，普通编辑、缩放、窗口变化及 Modal 开关不重排。
- [ ] 验证镜头／总览往返、刷新、新版本隔离、对象增删、手动移动、重新整理及一次撤销；浏览布局不写入设计内容。
- [ ] 在本票中先完成上述真实页面所需的最小共用结构调整，同类复用展示组件、相同语义复用基础结构；不增加万能卡片配置系统。尚未转换的其他卡片和其他三种画布继续正常工作。
- [ ] 桌面与 390px 窄屏验证 5 张及 30 张验收卡、长短文混合、缺项、摘要外问题、多值截断和 Modal 完整编辑保存，卡片不重叠且操作可达。
- [ ] 完成受影响的摘要、布局和业务回归及前端类型检查，按实际变化同步实施记录、架构事实和导演卡片的局部设计规则；不把其他票据尚未实现的类型标记为已完成。

## 范围边界

仅改导演画布中的上述三类内容卡及其必要入口、布局衔接。保留现有 AI 设计流程、真实关系和统一保存，不增加手动建立设计、拖线编辑或后端契约。连线样式与小地图分别由 29、30 交付，不阻塞本票验收。
