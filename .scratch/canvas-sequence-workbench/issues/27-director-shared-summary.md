# 27: 全场工作单摘要与概览去重

**What to build:** 用户从唯一的全场概览入口及四类全场工作单快速阅读共享设计，再进入 Modal 查看和编辑完整内容。全场范围、声音执行方式与共享影响明确，展示范围控制从卡面集中到工具栏。

**Blocked by:** 25 — 镜头、摄影与验收卡的紧凑展示

**Status:** ready-for-agent

- [ ] 各类型按下表显示主体摘要，并明确显示“全场适用”。

| 卡片类型 | 必须展示的信息 |
| --- | --- |
| 全场概览 | 观察视点、本场信息变化、关键转折 |
| 表演适用规则 | 适用说明 |
| 环境活动与留白 | 环境活动、留白理由 |
| 声音安排 | 声音执行方式、声源、环境与动作声 |
| 提示词指导 | 编译优先级、禁止项 |

- [ ] 将读取同一份导演设计的“全场共享”入口卡与“全场概览”工作单统一为一张全场概览卡；同一视图不重复展示，保留原设计对象的数据身份、编辑能力和真实关系，不复制业务内容。
- [ ] 其他四类全场工作单仍独立展示，不把全场设计再次塞进一个大而全的卡片；没有现有绘制关系的工作单不猜测连线。
- [ ] 沿用 25 的固定类型尺寸、固定摘要槽位、文本截断、无内部滚动与原位展开规则；摘要直接来自当前字段，空字段与明确没有、不适用保持真实语义。
- [ ] 声音执行方式以“待后期／同期生成／待确定”等真实短文本表达，不只显示图标，不伪造完成状态；不把未知旧值误标为已完成或默认执行方式。
- [ ] 待处理数量覆盖整个工作单，未保存与全场适用范围分别表达；图标具有可读名称、悬停及键盘提示，摘要外问题仍在 Modal 完整可读。
- [ ] 展示范围、全场总览及关联依据显隐等画布控制集中到工具栏；范围切换仍保留选择和浏览位置，完整六岗编辑与整场 AI 设计入口保持可达且作用范围清楚。
- [ ] 合并后点击概览及其他工作单进入正确 Modal，全文、问题、引用与全场影响保持可读；关闭保留草稿，保存回读及撤销保持原行为。
- [ ] 单镜头与全场总览中修改共享内容保持一致；合并不使导航、关系端点、布局缓存或整理后的定位指向失效入口，无镜头时仍可定位全场概览。
- [ ] 桌面与 390px 窄屏验证概览唯一性、全场工作单长短文与缺项、工具栏范围切换、完整六岗入口、共享编辑保存、总览往返与刷新恢复，且其他三画布不受影响。
- [ ] 完成受影响的摘要、身份与导航回归、真实 Modal 保存回读和前端类型检查，按实际交付同步文档。

## 范围边界

本票依赖 25 的紧凑展示和固定尺寸能力，不依赖 26、28、29 或 30。全场概览去重属于展示整理，不新增业务对象、共享版本、审批或后端契约；原有保存和 AI 建议应用规则继续生效。
