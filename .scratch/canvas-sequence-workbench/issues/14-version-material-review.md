# 14: 素材预览与方案独立判断

**What to build:** 用户在编辑画布浏览同场次已有 Take，记录当前方案的真实覆盖、可用区间和素材审查；共享素材不共享可变判断。

**Blocked by:** 08

**Status:** ready-for-agent

- [x] 编辑画布可浏览当前方案及同场次其他版本产生的已有素材，先打通真实素材复用，不要求先在新流程生成视频。
- [x] Take 保留固定生产依据、原所属版本和媒体来源；人工选择其他版本素材不复制执行历史、不重写来源。
- [x] 实际覆盖判断、可用区间和素材审查结论按当前场次版本独立保存；修改 B 的判断不改变 A 或共享 Take 的生成事实。
- [x] 实际覆盖根据真实素材和源区间人工判断，预计动作和生成成功不等于实际覆盖；动作偏差不冒充计划已经完成。
- [x] 区间受真实文件身份和实测时长约束，无效引用或越界区间明确定位；可用判断与是否剪辑采用分开。
- [x] 预览明确源素材身份，不自动播放、加入时间线、替换采用或猜测该 Take 的某一次片段区间。
- [x] 当前判断变化不改写已固定的审片记录，保留结论形成时的真实依据；依据不适用时明确待核对。
- [x] 关联来源已变的素材保留为旧依据候选，可查看并人工决定适用性，不自动计入当前覆盖。
- [x] 验证 A、B 共享同一 Take 但使用不同判断和区间，刷新后各自保持；首期不提供单个单元或部分计划跨版本复制。


## 实现边界核对（2026-10-14）

- 现有素材审片写入直接修改共享 Take 的 annotation；不可用作本票据的当前方案判断保存入口，否则 A/B 方案会互相覆盖。
- 当前场次版本内容尚未包含素材判断。新增判断应属于场次版本内容，沿既有统一保存、撤销与修订保护流程保存；共享 Take 只提供不可变生产来源、文件与执行事实，不承载当前方案的可变判断。
- 素材库读取同时覆盖同场次既有生产计划 Take 和新场次版本产生的 Take，明确来源种类与原版本身份，不能仅支持新视频执行产生的候选。
- 区间校验复用实际文件与实测时长约束；当前版本镜头／动作覆盖引用独立核验，不把原生产计划覆盖自动复制为当前判断。
- 首条完整验收路径：已有素材出现在编辑画布 → 明确预览 → A、B 两个场次版本分别记录判断及区间 → 刷新后互不影响 → 共享素材来源不变。随后补齐越界区间、文件不可用与依据变化恢复。

本节记录实现前的边界核对；后续实施状态见下节，第 14 张票据尚未全部完成。
