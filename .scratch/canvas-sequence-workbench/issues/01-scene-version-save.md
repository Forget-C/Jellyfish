# 01: 新建场次版本并手动保存

**What to build:** 用户明确新建一份空的场次版本，修改设计内容并手动保存，刷新后继续同一方案；四种画布逐步接入同一版本内容，不再由用户维护各层版本。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [x] 尚无版本时浏览不写入业务数据；明确新建后得到保留场次原文入口的空方案，不虚构镜头、单元、模型或时间线。
- [x] 顶部只有一个场次版本选择器；先打通人工设计字段的编辑、手动保存与刷新回读，后续票据新增内容沿用同一保存语义。
- [x] 保存更新同一场次版本且标识不变；无镜头、未选模型等业务缺项允许保存，缺项不被伪造默认对象补齐。
- [x] 已有对象身份、项目归属、已填写引用和字段格式仍须校验；非法输入被拒绝，失败后保留页面输入及位置。
- [x] 保存状态区分未保存、保存中、已保存和保存失败，收到成功结果后才显示已保存；保留现有并发校验，不覆盖服务器已变化的内容。
- [x] 保存不创建新场次版本、逐次保存历史或用户管理的设计／计划草稿，不自动执行生成、审片、采用或交付。
- [x] 显式创建的场次版本持久保留，不增加自动过期或按保存时间恢复的入口。
- [x] 版本中的当前可编辑内容与既有生成、审片及交付的固定依据分别表达，当前保存不得改写历史事实；旧数据自动迁移映射不在本票据中自行决定。
- [x] 演示创建空方案、编辑、保存、刷新回读和非法引用失败；核对版本数量、版本身份与实际持久内容一致。
