# 26: 表演与动作设计卡的紧凑展示

**What to build:** 用户通过表演、调度、角色情境、镜内活动、连续性和对白六类紧凑卡片识别主体、行动与变化，进入对象 Modal 查看完整设计并编辑保存；共享对象在不同镜头中始终对应同一份内容。

**Blocked by:** 25 — 镜头、摄影与验收卡的紧凑展示

**Status:** ready-for-agent

- [ ] 各类型只展示下表的主体摘要，另保留适用范围及真实状态区。

| 卡片类型 | 必须展示的信息 |
| --- | --- |
| 表演 | 人物与所属节拍、可见身体动作、行动目标 |
| 调度 | 人物／物件、位置与朝向、行动路径 |
| 角色情境 | 人物、当前处境、人物关系 |
| 镜内活动 | 人物／物件、持续任务、景深层次 |
| 连续性 | 连续性领域与对象、前态 → 后态、后续约束 |
| 对白 | 说话对象、对白内容 |

- [ ] 标题优先识别对象，例如“张三 · 节拍 02”；类型由分组或类型标识表达，正文不重复堆砌类型名称。
- [ ] 沿用 25 的紧凑规则：同类型固定尺寸、指定字段固定槽位、截断文本、无内部滚动与原位展开；摘要直接来自当前字段，不递归展示全部数据或另生成 AI 摘要。
- [ ] 关键缺项显示简短“未填写／待确定”，“明确没有／不适用”正常表达；缺失引用不以同名人物、节拍或相邻对象替代。
- [ ] 待处理图标与数量仍统计完整对象，包括未放上卡面的字段；未保存标识、适用范围分别表达，纯图标可通过悬停和键盘获取含义，无问题不表示完成或验收通过。
- [ ] 各类卡片点击进入准确对象 Modal，完整字段、引用、问题与共享影响可读；关闭保留草稿，手动／自动保存、刷新回读及撤销保持一致。
- [ ] 同一共享工作单从不同镜头进入仍编辑同一对象，关联镜头跳转和来源卡片定位继续有效；没有镜头关联的工作单保留真实范围，不因人物相同猜测归属或补线。
- [ ] 长对白、多人物名称、复杂连续性变化及空字段不改变卡片尺寸或布局。新类型使用统一固定尺寸，不恢复旧缓存中的内容测量高度。
- [ ] 桌面与 390px 窄屏验证六类卡片摘要和全文、摘要外待处理项、跨镜头共享编辑与持久化、普通编辑后位置保持，以及人物／节拍失效后的准确提示。
- [ ] 完成受影响的摘要与 Modal 业务回归、布局稳定性检查和前端类型检查，按实际交付同步文档；其他三画布保持原行为。

## 范围边界

本票依赖 25 已验证的紧凑卡片展示与固定尺寸衔接，不依赖全场工作单、关联依据、连线或小地图票据。保留真实领域对象和现有关系，不新增动作设计字段、手动建立工作单或岗位状态。
