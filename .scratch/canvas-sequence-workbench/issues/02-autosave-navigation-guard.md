# 02: 自动保存与离开保护

**What to build:** 用户可选择自动或手动保存；同版本内自由浏览，跨场次、跨版本及离开页面时正确处理修改和在途保存。

**Blocked by:** 01

**Status:** ready-for-agent

- [x] 自动保存默认开启，按当前用户与设备记住偏好并跨场次共用；偏好不属于场次版本内容。
- [x] 自动保存开启或关闭时顶部均可手动保存；两种方式共用校验、并发保护和错误反馈，不重复提交同一保存。
- [x] 同一版本内切画布、节点或关系导航保留输入，不弹保存确认；无未保存修改的跨上下文切换可直接进行。
- [x] 有修改且自动保存开启时，跨场次或版本先等待保存成功；失败停留原版本并保留输入、焦点及编辑位置。从已有版本新建空版本也遵循同一保护，不能借新建丢弃输入。
- [x] 自动保存关闭且有修改时提供保存并切换、放弃修改并切换、取消；放弃恢复最近一次成功保存的内容，不撤回已自动保存的变化。
- [x] 已有保存请求先确定结果，不能通过切换绕过保护；保存期间产生的新修改不得被旧成功响应清除或误标已保存。
- [x] 异步响应仅更新所属版本，不覆盖新打开的上下文；失败或结果不明不能伪装成成功。
- [x] 应用内及浏览器前进／后退、离开工作台遵循同一上下文保护；刷新或关闭提供适用的离开提醒，并与后续恢复流程衔接。
- [x] 验证保存成功、失败、取消切换及在途请求期间继续编辑，确认最终上下文和保存内容与用户选择一致。
