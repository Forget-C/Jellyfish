# 06: 导演画布的人工设计流程

**What to build:** 用户在独立的导演画布中从原文手动起稿，编辑全场六岗设计、镜头及资产关联，并清楚区分视图布局和业务关系。

**Blocked by:** 01

**Status:** ready-for-agent

- [x] 采用已确认的全工作区画布布局：顶部悬浮控件、左侧当前画布工具、左下角视口控制；按钮及弹出内容底色可读。
- [x] 无镜头时显示原文起点及当前不存在镜头，提供手动起稿和 AI 设计入口；浏览不自动建立镜头，AI 行为由对应票据交付。
- [x] 导演画布以当前镜头及其人物、场所、动作、摄影等关系为中心，全场共享节点可编辑完整六岗设计和共享内容。
- [x] 单击主体查看或编辑，更多菜单与右键等价；标题拖动只改变布局，镜头排序使用明确业务操作，不推导依赖或剪辑顺序。
- [x] 角色、场所工具选择项目已有对象；点击与拖入具有相同关联语义，不在场次画布中删除共享项目资产。
- [x] 连接点表达已有关系，关联通过明确节点操作修改；首期不提供自由拉线编排。
- [x] 解除关联与删除分开；仍被引用的工作对象须展示并定位引用，解除后才能删除，不抹去共享媒体或历史执行记录。
- [x] 同一时刻只打开一个业务编辑区；右侧面板默认隐藏，展开覆盖画布且不重排节点，关闭后继续原编辑。
- [x] 节点选择、详情、关联和布局移动有键盘或可见按钮入口，输入框的文字操作不被画布快捷键抢占；关闭浮层恢复有效焦点。
- [x] 演示从空场次手动建立并保存六岗设计、关联资产和排序镜头，刷新回读；验证移动节点不改变业务顺序、删除引用对象被阻止。
