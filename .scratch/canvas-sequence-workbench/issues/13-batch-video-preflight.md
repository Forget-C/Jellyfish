# 13: 批量预检与逐项拍摄

**What to build:** 用户选择多个单元的指令及对应检查，逐项预检并明确提交可执行项；某项改变或失败不阻塞其他独立项。

**Blocked by:** 11

**Status:** ready-for-agent

- [x] 保留明确选择单元指令和匹配检查、逐项预检、明确提交可执行项的流程；不扩展批量生成指令。
- [x] 每项预检固定其实际输入，显示可执行数量、受阻数量及具体问题，能够定位有关单元。
- [x] 提交前再次核对相关输入，变化项标记需重新预检；不得用旧通过状态提交新输入，也不得静默提交该项已变化前的旧输入。
- [x] A、B、C 预检后只修改 B，A 和 C 可由用户明确提交；按钮数量与实际提交项一致，B 重新保存并预检后才进入新的提交范围。
- [x] 逐项展示任务、失败、取消、成功及提交待核实状态；未知提交核实原请求，不能批量点击造成重复执行。
- [x] 逐项取消，失败和取消不自动重试；成功只登记各自 Take，不自动采用。
- [x] 进行中的输入和后续编辑相互独立，后台完成不抢占当前编辑，错误归属对应版本及单元。
- [x] 验证部分缺项、预检后编辑、提交未知和部分取消，核对每项实际输入、提交数量及结果来源。
