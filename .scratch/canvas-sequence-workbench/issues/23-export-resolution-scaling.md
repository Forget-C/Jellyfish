# 23: 导出尺寸选择与缩放提示

**What to build:** 用户在默认 1080 和较小的 720 档间选择导出尺寸，看到真实宽高及需要放大的片段，并获得构图和时间关系一致的成片。

**Blocked by:** 22

**Status:** ready-for-agent

- [x] 保留默认 1080 档并增加 720 档，界面显示实际宽高；16:9 对应 1920×1080／1280×720，9:16 对应 1080×1920／720×1280，1:1 对应 1080×1080／720×720。
- [x] 所选档位、实际宽高及固定格式／编码／帧率属于本次导出配置，提交后编辑不改变该记录；不修改源素材或单元生成参数。
- [x] 依据实测媒体宽高判断缩放，不用请求画幅或名义分辨率替代；填满时计入居中裁切后剩余的有效画面尺寸。
- [x] 需要放大时明确提示涉及片段，允许普通缩放；高分辨率按目标尺寸缩小，不自动重拍或 AI 超分，不宣称放大增加真实细节。
- [x] 同一固定剪辑用两档分别导出，构图、源区间、时间位置及播放速度一致，不因改尺寸重新紧排或裁取其他范围。
- [x] 三种比例、两种适配及混合高低分辨率组合中，预览与实际输出构图一致；横屏填满竖屏按有效裁切尺寸正确提示。
- [x] 用 24、30、60fps 的真实有声／无声素材验证两档输出均为 30fps，时长、速度和音画同步正确，文件参数与记录一致。
- [x] 只提供两档尺寸，不增加 4K、自定义尺寸、编码或帧率选项。
