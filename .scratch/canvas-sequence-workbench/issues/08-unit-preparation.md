**What to build:** 用户从镜头明确建立生产单元，配置覆盖、模型、实际参考和依赖，保存未完成准备并定位当前单元的执行缺项。

- [x] 无关联单元时展示当前不存在单元及建立入口，只有明确创建才产生数据；多个关联单元必须明确选择。
- [x] 单元画布围绕当前单元展示动作覆盖、模型参数、对象、参考文件及用途、前段依赖，保持镜头／单元身份和来源可查。
- [x] 参考采用实际素材并明确用途，已填引用校验项目归属和有效性；参考操作有可见入口，不依赖自由拉线或拖拽。
- [x] 未选模型等业务缺项可保存，非法已有引用仍拒绝；缺项定位到具体单元，不阻止已准备好的无关单元。
- [x] 新单元默认继承创建时的场次输出画幅，随后独立保存、允许修改；后续输出画幅变化不批量改写既有单元。
- [x] 模型不支持所选画幅时保留选择，允许保存但阻止生成并提供改模型／参数入口，不静默回落。
- [x] 准备缺项时主操作定位补齐，准备满足且无指令时提供生成指令入口；后续指令票据完成实际生成链，不用浏览代替明确操作。
- [x] 验证同镜头多单元、独立缺项、有效和失效参考及模型画幅不支持；输出画幅编辑交付后验证旧单元保留原值、新单元继承新值。
