# 20: 完整方案另存为新版本

**What to build:** 用户在关联任务全部明确终态后，将点击时完整编辑另存为独立场次版本；全过程保护原内容、共享素材来源及未知创建结果。

**Blocked by:** 05, 10, 16

**Status:** ready-for-agent

- [x] 复制点击时完整编辑，包括未保存修改、原文依据、六岗设计、镜头、单元、当前指令、参考、素材判断及依据、时间线、输出画幅与片段适配。
- [x] 为创建副本不预先保存原版本；原版本保留此前成功保存的内容，已自动保存内容不回退；已有保存请求先核实并准确体现其最终结果。
- [x] 全部关联任务无任务或已核实成功、失败、取消等终态才允许另存为；排队、执行中、取消未完成、提交未知及任务读取失败均阻止并说明原因。
- [x] 实际创建副本时再次保证任务条件成立，不能只禁用前端按钮；检查与创建之间出现新未终态任务时停止且保留输入，覆盖普通及恢复入口。
- [x] 另存为不自动取消任务；未应用 AI 建议、未审片或未采用不冒充未结束任务，失败／已取消任务不要求先重做成功。
- [x] 开始后整页 loading，禁止输入、导航、重复另存为和其他业务提交，不再发起新自动保存；成功切换新版本后恢复，明确失败回原现场并保留输入。
- [x] 创建超时或响应丢失时保留现场并核实同一次创建，不当作明确失败重建；刷新也根据保留的请求身份先核实，避免重复版本。
- [x] 新旧版本当前内容和判断独立，媒体文件共享引用；修改副本的原文、覆盖、审查、区间、采用或构图不影响原版本。
- [x] 保留复制时的参考文件、资产来源及项目风格依据，另存为不切换最新原文或项目选择，不触发下游生成。
- [x] 生成、检查及审片的固定历史保持真实来源，任务历史不复制或重跑；复制内容的关联完整且不伪造在新版本执行过的记录，原版本后续任务也不写入副本。
- [x] 首期只提供整份另存为和人工复用同场次素材，不复制单个单元／部分计划，不按名称隐式重绑。
- [x] 验证带未保存内容复制、在途保存、任务检查与创建之间的竞态、取消未终态、整页锁定、创建响应丢失后刷新及 A／B 判断隔离；后续导出任务也须纳入相同限制。
