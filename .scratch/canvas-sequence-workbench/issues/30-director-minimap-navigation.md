# 30: 命名分区与小地图导航

**What to build:** 用户在大量导演设计卡片中通过命名分区、区域定位和小地图找到工作区域，保持可读缩放及已有布局；镜头与全场总览往返时仍恢复各自的浏览现场。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 系统按具体对象类型命名分区并显示数量，增加适度视觉边界，空分区不占位；分区只是视觉组织，不成为业务对象或关系端点。
- [ ] 保留原文与共享背景在上方、当前镜头为主锚点、设计工作单在右侧及下方、依据按需展开的组织方式；同类按现有空间规则排列一至三列，放不下的分区整体换行。
- [ ] 新增当前视图小地图，桌面默认显示且可收起，390px 窄屏默认收起；展开／收起入口可访问，不遮挡必要业务和画布操作。
- [ ] 小地图只显示分区轮廓、卡片位置和当前视口，不显示正文与密集连线。节点移动、视图切换、依据显隐及增删后，地图反映当前实际可见布局，不复制业务对象。
- [ ] 点击地图位置或拖动视口框只平移画布，保持缩放和节点坐标；打开小地图不自动适应全部，不将拖动视口误判为卡片拖动或业务编辑。
- [ ] 既有区域与对象定位入口继续可用，用户保持可读缩放时能定位画布外对象；键盘用户仍能使用可见定位入口和地图开关，关闭后焦点有效。
- [ ] 普通编辑、缩放、窗口变化和 Modal 开关不触发重排，新增对象补位、删除对象清理、隐藏依据保留位置；分区视觉和小地图不改变这些规则。
- [ ] 镜头与总览独立记忆布局和视角，刷新恢复；首次进入、返回已访问镜头、共享对象跳转及新版本隔离继续遵循现有规则，不被小地图开关覆盖。
- [ ] 保留卡片单独移动、当前视图重新整理及一次撤销，整理保持缩放并定位当前镜头或无镜头时的全场概览；“适应全部”仍是用户主动操作。
- [ ] 全部地图、分区与定位行为只改变浏览状态，不产生设计未保存标记、业务数据写入或跨设备同步。
- [ ] 桌面与 390px 窄屏验证 5 张及 30 张验收卡、地图默认状态和开关、点击平移、视口拖动、节点移动、区域定位、镜头／总览往返、刷新、版本隔离、增删及整理撤销，卡片与必要入口可达。
- [ ] 完成布局与导航回归、真实 Modal 编辑及保存流程回归和前端类型检查；验证其他三画布保持原行为，按实际交付同步文档。

## 范围边界

现有画布已提供命名分区、节点几何及视角，本票可独立完成，不依赖卡片或连线票据；地图使用实际几何，兼容当前尺寸及后续紧凑卡片。保留区域定位能力，不增加分组自由命名、整组拖动、嵌套、折叠或子图。
