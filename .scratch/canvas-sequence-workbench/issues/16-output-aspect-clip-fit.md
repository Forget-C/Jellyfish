# 16: 输出画幅与逐片段构图

**What to build:** 用户设置整场输出画幅，并为每次素材采用选择完整显示或居中填满；预览展示真实构图，配置独立保存且不改变源素材。

**Blocked by:** 15

**Status:** ready-for-agent

- [x] 场次版本输出画幅默认 16:9，可选 9:16 和 1:1；与单元生成画幅、导出像素尺寸分别表达。
- [x] 每个片段默认完整显示，等比例放入目标画幅并留黑边；填满须明确选择，首期等比例铺满并居中裁切。
- [x] 16:9 素材进入 9:16 输出时，完整显示保留全画面、上下黑边，填满裁切左右；预览准确体现两种构图。
- [x] 同一 Take 的两次采用可分别配置，修改某片段不影响另一片段、源文件或其他场次版本。
- [x] 输出画幅及片段适配可保存、撤销／重做，刷新回读一致；修改不自动重拍或改写现有单元参数。
- [x] 输出为 9:16 时新单元默认 9:16，改为 1:1 后旧单元仍为原值，新建单元默认 1:1；不支持的生成画幅仍遵循单元准备校验。
- [x] 画幅或裁切改变计入画面验收适用性判断；既有审片、交付及导出固定记录保持原配置，不冒充当前画面已通过。
- [x] 预览配置可被后续交付和导出固定使用，不新增生成参数联动或自由裁切功能。
- [x] 验证三种画幅、两种适配和同 Take 多片段独立设置；后续导出票据使用同一构图规则验证真实文件与预览一致。
