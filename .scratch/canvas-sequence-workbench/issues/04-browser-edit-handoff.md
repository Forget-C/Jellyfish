# 04: 同一浏览器的编辑权交接

**What to build:** 同一浏览器只允许一个工作台页面编辑；用户可以明确交接到另一页，关闭或冻结的原页不会破坏未保存内容。

**Blocked by:** 03

**Status:** ready-for-agent

- [x] 已有编辑页时第二个工作台页先只读，允许浏览并显示转到此页编辑入口；只读页不保存内容或写入未保存缓存。
- [x] 原页有修改时先保存或明确放弃再交接；取消或保存失败保留原页现场和编辑权，已有在途保存先核实。
- [x] 交接成功后新页成为唯一编辑页，原页转为只读，不能继续写入业务内容或共享的那一份未保存数据。
- [x] 原页意外关闭时新页先恢复或丢弃既有未保存数据，不直接用新上下文覆盖。
- [x] 原页冻结或失联而未确认关闭时显示原编辑页未响应，提供取消、重试和定位原页；不无限等待且不按超时强制抢占。
- [x] 只有核实原页已失去编辑能力后才交接；旧页恢复须重新核对编辑权，已交接则保持只读，不恢复旧保存和缓存写入。
- [x] 使用两个真实浏览器页面验证正常交接、保存失败、取消、关闭、冻结及恢复；本票据不扩展多设备、多用户同时编辑同一章节。
