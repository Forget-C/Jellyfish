**What to build:** 用户在真实时间线上检查接缝并审阅整场，分别理解覆盖、素材审查、采用、画面验收和声音状态，历史结论有固定依据。

**Blocked by:** 15

**Status:** ready-for-agent

- [x] 编辑画布分开展示实际覆盖、素材审查、剪辑采用、接缝审查、整场验收和声音状态，不用单一完成百分比混合这些事实。
- [x] 素材入口记录观察与审查，片段入口调整源区间，接缝入口检查相邻真实片段，时间线区域提供整场审片入口。
- [x] 接缝及整场结论绑定当时真实剪辑、区间及呈现配置，保留成立内容、覆盖缺口和待处理问题，不只绑定可变版本名称。
- [x] 剪辑、采用区间、输出画幅或裁切改变后重新判断有关结论适用性；旧通过结论不能冒充当前通过，未变化的有效判断不无故失效。
- [x] 固定审片记录保留发生时依据，修改当前素材判断或剪辑不改写历史结论。
- [x] 画面通过与声音完成分别判断，待拍占位、缺少实际覆盖和声音待后期均如实展示，不把预演视为真实覆盖。
- [x] 审片、采用、生成及导出分别触发；审片结果不自动采用、生成或交付，导出成功也不能改变验收结果。
- [x] 验证旧剪辑通过后调整区间或构图，当前适用性正确变化而历史仍可还原；输出画幅能力接入后覆盖构图变化的真实预览。
