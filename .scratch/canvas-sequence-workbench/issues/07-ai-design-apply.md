# 07: AI 设计预览与整次应用

**What to build:** 用户预览整场 AI 设计或预先限定范围的局部修订，再明确应用；冲突或越界时整次拒绝，成功应用可一次撤销。

**Blocked by:** 03, 06

**Status:** ready-for-agent

- [x] 发起整场提取时明确整场范围，不因当前镜头选中而缩小；局部修订在发起前明确目标和允许修改的字段。
- [x] 结果先预览范围、差异及真实来源，再由用户点击应用到当前版本；查看、应用和后续执行分别授权，不新增 AI 草稿层级。
- [x] 等待或预览期间相关内容改变时重新核对，不以旧建议覆盖新人工编辑；来源失效的结果不能作为当前有效依据应用。
- [x] 六镜头方案仅修订第二镜头允许字段时，其他镜头及范围外字段保持原样。
- [x] 应用范围内整体成功或整体不应用；引用冲突、越界修改须列出问题及关联位置，不静默跳过冲突只应用剩余部分。
- [x] 镜头身份不按名称匹配；删除或替换仍被单元等对象引用的镜头前须处理引用，不删除已有素材或伪造对新设计的实际覆盖。
- [x] 首期不提供从整份建议任意勾选镜头或字段后自动拼装；可回原字段手动修改或另发限定范围修订。
- [x] 成功应用作为一次可撤销编辑，按当前保存模式处理；预览及失败不改变当前内容，后台完成不抢占其他编辑。
- [x] 验证整场及限定范围成功、等待期间人工编辑、引用冲突、越界、来源失效和应用后一次撤销；建立单元能力接入后补齐真实引用链的验收。
