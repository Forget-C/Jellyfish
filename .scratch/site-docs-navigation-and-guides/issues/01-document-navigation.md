# 01: 统一文档导航，保留旧网址与章节锚点

Status: ready-for-agent
Blocked by: None

**What to build:** 读者从任一既有入口进入指南，都能看到与文章归属一致的目录，并落到原先引用的内容。

## 验收标准

- [ ] 清点现有公开网址和章节深链接，覆盖拆出的旧版拍摄、剪辑与交付段落。
- [ ] 桌面侧栏、移动菜单和面包屑按安装与配置、制作第一场戏、独立工具与任务、旧版场次工作台、开发与贡献组织。
- [ ] 从顶部导航、产品页指南链接、侧栏、上一篇／下一篇和旧书签进入文章，逐页核对可见分组、顺序、高亮、面包屑及标题。以原「场次创作、拍摄与交付」地址为必测入口。
- [ ] 沿用官网 Playwright 验证方式，对同一源码的根路径预览及空目录完整构建的 /Jellyfish/ 预览分别检查桌面与手机；移动端实际展开菜单，记录入口、视口和落点。
