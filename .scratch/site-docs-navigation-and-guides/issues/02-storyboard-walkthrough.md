# 02: 完成《雾海来信》分镜图文样章

Status: ready-for-agent
Blocked by: None

**What to build:** 带读者从已保存的「海边站台」场次生成分镜，核对输入并查看第一张候选图。

## 验收标准

- [ ] 在隔离项目实际完成生成分镜、等待就绪、进入画布、核对模型输入、预检执行和打开结果，记录每一步的可见完成标志。
- [ ] 补拍生成面板、「分镜已就绪」卡片和模型卡预检，复用实际画布和候选图。步骤就近配图注、替代文字和可复制的示例输入。
- [ ] 读者能区分已提交、分镜就绪、已有候选图，并从实际画面回答「林夏此刻是否打开了信封」。
- [ ] 自动核对图片加载和原图入口，人工检查桌面和手机上的按钮用词、场次、状态及关键控件的可读性。
