# 02: 完成《雾海来信》分镜图文样章

Status: ready-for-agent
Blocked by: None
Resolution: completed

**What to build:** 带读者从已保存的「海边站台」场次生成分镜，核对输入并查看第一张候选图。

## 验收标准

- [x] 在隔离项目实际完成生成分镜、等待就绪、进入画布、核对模型输入、预检执行和打开结果，记录每一步的可见完成标志。
- [x] 补拍生成面板、「分镜已就绪」卡片和模型卡预检，复用实际画布和候选图。步骤就近配图注、替代文字和可复制的示例输入。
- [x] 读者能区分已提交、分镜就绪、已有候选图，并从实际画面回答「林夏此刻是否打开了信封」。
- [x] 自动核对图片加载和原图入口，人工检查桌面和手机上的按钮用词、场次、状态及关键控件的可读性。

## Comments

已完成。《雾海来信》隔离项目以本地模型响应驱动实际 API、SQLite、Worker 和业务前端。浏览器提交「海边站台 · 灯下拾信」，等待「分镜已就绪」，从「查看并采用分镜」进入，在同一画布新增图片模型卡，核对实际提示词，预检、执行并打开 836 × 470 的演示图片。确认生成面板、就绪卡和预检截图均取自该次走查。

浏览器回归先在旧样章因缺少确认面板原图入口失败；新版部署前缀页面在 1440 与 375 像素宽度通过五张图解码、原图链接及页面宽度检查。人工核对了就绪卡在两种屏宽下的实际渲染。
