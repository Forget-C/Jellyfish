# 06: 在实验室完成文本、图片和视频试验

Status: ready-for-agent
Blocked by: 01, 02
Resolution: completed

**What to build:** 读者能在同一短剧设定下按模态准备输入、查看输出并从最近对话返回。

## 验收标准

- [x] 文本试验复用实际改稿对话，给出可复制的本轮提示词及所需上下文。
- [x] 补拍用站台参考图做图片试验、用本地首帧做视频试验的输入与结果，各说明模型选择、参考用途和输出位置。
- [x] 从最近对话找回三类试验，验证截图中的操作入口、结果状态与正文一致。

## 验收记录

使用真实工作台实验室和本地隔离演示响应，通过浏览器分别发送文本、图片和视频提示词。核对图片请求确实携带站台参考图，视频请求包含灯下拾信的首帧；打开并播放三秒本地演示片段，再从最近会话逐个返回文本、图片和视频记录，核对本轮输入及可预览产物。实际模型的输出可能不同。

新增四张操作截图及两份可下载的练习图片，复用既有对话截图。桌面 1440px、手机 375px 下逐张滚动检查五张图已解码，原图入口正确，文章无横向溢出。两份输入素材均从构建后的网址返回成功。
