# 09: 验收整套文档的连续阅读路径

Status: ready-for-agent
Blocked by: 03, 04, 05, 06, 07, 08

**What to build:** 在整合后的官网验证新用户、独立试验者、旧项目维护者和开发者都能沿实际入口完成阅读。

## 验收标准

- [ ] 从同一源码完整构建到空目录，记录根路径与 /Jellyfish/ 预览地址和源码状态。
- [ ] 按教程从安装走到《雾海来信》的第一张候选图，沿独立工具、旧版书签和开发贡献入口抽查跨篇导航。
- [ ] 复查所有受影响的公开网址、章节锚点和媒体；在桌面及手机记录实际落点、当前目录、截图可读性和原图访问情况。
- [ ] 核对脚本错误、横向溢出及读者可见的状态；记录实际走查结果，修复并复验影响验收的问题。
