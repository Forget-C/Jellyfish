# 07: 从独立画布运行模型，并从任务中心找回结果

Status: ready-for-agent
Blocked by: 01, 02
Resolution: completed

**What to build:** 读者从独立画布提交一次模型运行，能在任务中心查看状态、回到来源并找到产物。

## 验收标准

- [x] 在独立画布用演示素材完成输入连线、模型卡预检和明确执行，拍摄实际输入与运行历史中的产物。
- [x] 拍摄同一次运行的任务列表和已完成任务的「查看」入口，核实返回的业务对象与结果。
- [x] 补充一条可复现的失败记录，标明失败原因和从原业务页面重新提交的位置；确认原记录仍可查。

## Comments

已用独立画布与本地图片供应商走查：采用文本来源后，预检显示站台原文、镜头正文及 @文本1 映射。供应商第三张媒体下载故意返回 HTTP 503，随后恢复供应商并从图片模型卡重提。浏览器分别从任务历史中选择失败和成功记录的「查看」，验证进入同一画布且运行 ID 与点击的任务一致；原错误为「失败 · 未完成」，重试得到完整图片，两条记录均可查。

五张实际操作图已就近加入指南，前缀静态构建以及 1440/375 像素的图片解码、原图链接和页面宽度检查通过。
