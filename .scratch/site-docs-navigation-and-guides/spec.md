# 官网文档改版：从安装到第一张候选图

Status: ready-for-agent

## Problem Statement

读者从官网侧栏、产品页和旧书签进入同一篇操作指南时，可能看到不同版本的目录和正文。本地已观察到实时预览与静态预览对同一场次文章返回不同标题。之前只验证了首页目录顺序和部分正文，没有沿实际入口逐页核对可见菜单。用户截图对应旧版文章，但具体访问入口尚未确认。

现有教程把对象准备、生成分镜、旧版单元拍摄和剪辑交付放在同一条阅读路径中。一段文字里有多个按钮和状态，第一次使用工作台的人很难判断该点哪里、何时等待，以及操作是否成功。

## Solution

使用一套按任务排序的文档目录，保留已有公开网址与章节深链接。首次使用者从安装进入一个可以照做的短剧项目；独立试验、旧版项目维护和开发协作均有自己的入口。先验收全站深层导航，再用《雾海来信》的「生成分镜与查看候选画面」验证图文教程写法。两项通过后，依次扩充安装至首张候选图的主线、独立工具和旧版工作台指南。

## User Stories

1. 作为首次安装者，我希望能依次准备环境、启动服务和检查工作台，以便识别安装完成的标志。
2. 作为模型配置者，我希望看到供应商、模型选择和首次调用成功的不同界面状态，以便确认配置有效。
3. 作为短剧创作者，我希望能复制示例项目名、章节名和两段原文，以便从空项目开始练习。
4. 作为编剧，我希望看懂原文选区、划分草稿和已保存版本的区别，以便确认每场戏的范围。
5. 作为场次创作者，我希望在本场选好角色、场所和道具参考，以便继续设计镜头；需要修改资产图片时能找到专门指南。
6. 作为第一次生成分镜的人，我希望区分已提交、分镜就绪和已有候选图，以便在合适的时机进入画布或查看结果。
7. 作为审看候选图的人，我希望用具体动作对照镜头要求，以便判断是否需要另一种拍法。
8. 作为独立试验者，我希望能分别找到实验室和独立画布，以便试写提示词或组合输入。
9. 作为查找后台任务的人，我希望能看懂运行状态并回到来源记录，以便找回结果或处理失败。
10. 作为已有旧版场次的用户，我希望从既有链接继续找到版本、单元拍摄、Take 采用和交付说明。
11. 作为使用手机的读者，我希望展开菜单就能定位当前章节，并能看清截图中的关键控件。
12. 作为从产品案例、旧书签或相邻文章进入的读者，我希望看到一致的目录和正确的段落，以便继续阅读。
13. 作为开发者，我希望从专门栏目找到本地联调和贡献说明，以便快速进入协作流程。

## Implementation Decisions

### 目录与网址

| 栏目 | 阅读顺序 |
| --- | --- |
| 安装与配置 | 准备安装环境 → 启动并检查服务 → 配置生成模型 |
| 制作第一场戏 | 创建项目与第一章 → 从原文划分场次 → 为本场选参考图 → 生成分镜与查看候选画面 |
| 独立工具与任务 | 管理资产图片 → 使用生成实验室 → 使用独立画布 → 查看与处理任务 |
| 旧版场次工作台 | 打开已有场次版本 → 准备单元与拍摄 → 审片、剪辑与交付 |
| 开发与贡献 | 本地开发环境 → 反馈问题与参与贡献 |

以 Hugo 的内容归属、导航标题和排序作为桌面侧栏、移动菜单及面包屑的共同依据。网址与栏目归属可以不同。修改前清点线上使用的文档路径、章节锚点和产品页的深链接；文章拆分时为旧地址及片段保留能到达对应内容的入口。在新目录下更新正文、产品案例和前后篇导航。新手主线以看见一张候选图为完成标志。

实时预览和部署前缀预览使用同一源码状态。静态预览从空输出目录完整构建，让文章、导航、脚本与样式来自同一构建；验收时记录两个入口所用的源码状态和预览地址。

### 教程版式与样章

每篇操作指南先说明入口、前提、可观察的完成标志，再按读者动作分节。每节围绕一个目标，步骤之后紧跟对应截图和一句图注，指明应核对的控件或结果。示例原文、提示词和命令保留可复制文本。失败、取消、恢复与历史处理在主流程后按需阅读。图片提供有意义的替代文字；宽画布可打开原图，细小控件辅以可读的局部图。

样章使用隔离环境里的虚构项目《雾海来信》、第一集《末班车之后》、已保存的「海边站台」场次和本地演示媒体。角色为林夏，道具为旧信封。正文从生成面板开始，经任务提交、「分镜已就绪」、打开画布、核对输入和模型卡预检，到预览候选图结束。使用真实业务界面截图，说明演示数据来源。候选画面用“林夏此刻是否已经打开信封”作为核对题；每次实际生成允许有不同输出。

## Testing Decisions

**首批验收一：深层页面导航一致性。** 复用官网已有的 Playwright 浏览器验证方式。对同一源码的根路径预览和从空目录构建的 `/Jellyfish/` 预览，在桌面及手机视口走真实阅读路径。先以原「场次创作、拍摄与交付」公开地址复现，再逐篇核对文档。覆盖顶部「文档」、可见侧栏、产品页操作指南、上一篇／下一篇、旧书签及章节锚点。手机实际打开菜单。比较可见分组和顺序、当前高亮、面包屑、文章标题与目标章节；检测页面和图片加载、脚本错误及横向溢出。任一入口仍显示旧版菜单，或旧片段只能到达泛化首页，都属于未通过。验收记录保留入口、视口、预期与实际落点。

**首批验收二：样章可操作。** 在隔离项目从已保存的场次依文实际走查：打开生成面板并提交，找到就绪卡片，进入分镜画布核对输入，预检、执行并打开候选结果。自动检查截图加载与原图入口；人工在桌面和手机核对当前界面、按钮用词、场次与状态，以及截图阅读尺寸。逐步记录操作、看到的完成标志和对应截图。通过标准为读者能区分三个状态、按图找到下一步，并根据实际候选图回答信封核对题。

**扩展验收。** 两项首批验收均通过后再批量扩充。逐篇核对演示字段、命令、截图、图注及下一步链接；涉及生成、资产采用和旧版交付的页面分别验证实际结果和适用入口。完整构建后复查全部受影响的公开路径、章节锚点与媒体资源。

## Out of Scope

本规格限定于官网文档、相关导航与引用、演示数据及截图采集。产品运行时能力变更、生产数据采集、对外部署和远端发布另行安排。此阶段交付规格，实施票据在后续阶段拆分。

## Further Notes

用户已确认上述两项首批验收方式。现有五张来自真实工作台的演示截图可以作为起点；补拍清单表达所需业务状态，实际取景以读者可识别、可操作为准。首批验收状态须在实施时用新构建和实际走查记录确认。
