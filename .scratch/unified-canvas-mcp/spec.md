# 通过 MCP 操作统一画布

Status: ready-for-agent

## Problem Statement

Jellyfish 的后端已经支持编辑和运行自由画布与场次分镜画布。用户希望在自己选择的 MCP 客户端中完成同样的工作，并能回到 Jellyfish 查看修改和生成结果。外部客户端需要能发现实际可调用的操作，识别所操作的画布，在连接中断后查回已提交操作的结果。

## Solution

用户在 Jellyfish 中开启连接，将服务地址和临时凭据交给 MCP 客户端。客户端通过 Streamable HTTP 连接现有后端的 `/mcp`，发现具名工具，直接调用统一画布协议的业务操作。有效会话均可使用完整工具集。用户关闭连接或凭据到期时，该凭据失效，已受理任务继续执行。

## User Stories

1. 作为用户，我希望在 Jellyfish 中开启和关闭 MCP 连接，以便决定外部客户端何时可以操作画布。
2. 作为客户端使用者，我希望凭据有效时能断线重连，以便继续查阅画布和任务。
3. 作为客户端使用者，我希望能发现工具及其参数，以便区分两类画布共用的操作和各自的专属操作。
4. 作为创作者，我希望搜索、分页浏览、新建和重命名自由画布，以便整理独立创作。
5. 作为分镜创作者，我希望列出或创建指定项目、章节和场次的画布，以便在正确的场次开始工作。
6. 作为创作者，我希望凭列表或创建结果中的画布引用读取文档、修订号、卡片目录和模型能力，以便构造有效编辑。
7. 作为创作者，我希望预演自由画布草稿并单独执行首次保存，以便决定何时创建持久化画布。
8. 作为创作者，我希望按预期修订保存文档或删除画布，以便发现并发改动，并在存在活动运行时看到删除受阻的原因。
9. 作为创作者，我希望针对已保存画布或当前可见文档预演编辑，查看每组的实际差异，以便选择要应用的修改。
10. 作为创作者，我希望只提交选中的组，能查看来源冲突和原提交回执，以便与编辑器上的手动修改协同工作。
11. 作为持有布局的客户端使用者，我希望预演卡片移动，在应用前按最新坐标取得投影，以便将结果应用到自己的布局。
12. 作为创作者，我希望编译已保存或指定文档的生成输入，核对视频引用、准备视频帧，并按单卡、目标或框选范围预检，以便在运行前定位输入问题。
13. 作为创作者，我希望提交运行、查回受理结果、读取任务运行、快照和增量事件，并能取消运行或指定节点，以便控制异步生成。
14. 作为创作者，我希望查询卡片输出并准备将所选输出用于内容卡，以便继续使用生成结果。
15. 作为创作者，我希望预览和执行生成前、后的画布检查，查询可检查的产物、当前和归档报告，取消检查或发起复查，以便核实设计要求落实到哪个产物。
16. 作为分镜创作者，我希望读取提取和重试依据，发起提取、重新提取或重试，查看历史任务和当前候选，以便处理场次原文的变化。
17. 作为分镜创作者，我希望预览候选差异、采用到画布、按原回执撤销或重做，并检查已保存分镜的连续性，以便核对最终采用的内容。

## Implementation Decisions

- 以可独立调用的业务操作发布具名工具。通用工具接收同一种 `canvas_ref`。自由画布引用含画布标识，场次分镜画布引用另含项目标识。按场次工作的入口显式接收所需的章节、场次等定位参数。后端核对实际归属，向调用方返回可定位的业务诊断。
- 连接凭据由 Jellyfish 签发。初始化、重连及后续调用都受凭据有效性约束，关闭连接应使已建立连接上的后续访问也失效。协议会话标识与连接凭据用途各异。
- MCP 工具负责参数和结果转换，直接复用画布协议已有的修订、事务、来源校验、幂等和回执语义。自由草稿预演和首次保存沿用各自的业务效果。布局由宿主提供当前坐标并应用投影。
- 已保存画布的分组编辑预演返回差异及服务端可验证的 `preview_ref`。提交引用原预演、选中组和 `request_id`。后端复核原差异所依赖的来源并逐组返回结果。编译预演文档时明确其依据，调用方可以区分预期输入与当前已保存输入。
- 任务标识和回执按业务操作保存。连接关闭、凭据过期或客户端丢失响应后，已经受理的工作仍由任务系统跟踪，用户可在新的有效连接中查回结果。

## Testing Decisions

主要验收入口为真实 MCP 客户端通过 Streamable HTTP 调用实际后端路由。使用测试数据库，外部生成使用可控替身。断言工具发现结果、业务诊断、可重读的画布修订、任务和回执。复用已有画布 API、编辑冲突、运行协议和场次分镜测试的场景与数据准备方式。

| 验收项 | 从用户或客户端可观察的结果 |
| --- | --- |
| 浏览器与客户端接入 | 一条端到端用例从 Jellyfish 开启连接，使用取得的地址和凭据完成工具发现，关闭后原客户端再次调用被拒绝。 |
| 凭据生命周期 | 缺失或无效凭据无法访问。有效凭据可断线重连，到期后原连接及重连均无法继续访问。 |
| 完整工具覆盖 | 将各协议可独立调用的业务操作逐项对应到实际工具发现结果，核对适用画布、参数和输出。内部归属校验通过对应工具的失败场景验收。 |
| 双画布 | 分别列出、创建、读取和编辑两类画布。自由草稿预演后仍未创建，首次保存后可读。项目与画布不匹配、作用域错误或修订过期时，原文档可重读且未被改写。 |
| 编辑与布局 | 预演 A、B 后只提交 B，重新读取可见 B 生效；另一次预演后修改其依赖来源，提交返回冲突。重复相同提交得到原回执。使用最新坐标计算投影并由宿主应用。 |
| 输入与结果 | 对同一视频卡分别编译已保存和预演文档，核对正文、参考图及预检诊断。验证运行产物、检查报告和复查结果可通过工具定位。 |
| 异步运行 | 提交后模拟响应丢失，相同请求重试只受理一次。关闭连接后允许任务完成，再用新连接查回同一任务和结果。另以活动运行核对显式取消。 |
| 场次专属能力 | 从场次依据提取候选、预览差异并采用，重读画布核对修改，以原回执验证撤销和重做。 |

## Out of Scope

多用户账号、角色与项目授权，助手会话、提案和审批工具，以及远程控制浏览器布局。

## Further Notes

ADR 0019 记录了接入方式与单用户边界，ADR 0018 记录了画布业务协议。画布检查、分镜候选的预览与采用均属于此次交付的画布能力。
