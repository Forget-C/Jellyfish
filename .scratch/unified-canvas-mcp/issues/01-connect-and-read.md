# 01: 开启 MCP 连接并读取两类画布

**What to build:** 用户从 Jellyfish 开启连接，以临时凭据使用真实 MCP 客户端定位并读取画布。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent
Completion: complete

- [x] 浏览器端到端用例取得地址和凭据，通过 Streamable HTTP 连接 `/mcp`、发现并调用工具，再从界面关闭连接。
- [x] 自由画布支持名称搜索和分页，分镜画布按项目、章节和场次列出；返回的 `canvas_ref` 均可用于读取文档及修订号。
- [x] 类型或项目与实际归属不符时可定位错误。缺失或无效凭据无法访问，有效会话可发现同一套工具。
- [x] 有效期内断线可以重连；用户关闭连接或凭据到期后，原连接后续调用与持原凭据重连均被拒绝。
- [x] 使用真实 MCP 客户端逐项核对本票业务操作与实际发现的具名工具，验证适用画布、参数和返回值。
