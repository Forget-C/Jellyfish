# 项目与资产库界面一致性修正

确认依据：本轮grilling Q1–Q12及完整方案最终确认。实施基点e0d1ca8b；范围为前端布局、展示与入口，保持已有接口和业务保护。测试边界与审查基点已另行确认。

- 普通项目与制作流程取消面包屑、项目侧栏取消返回项目列表，通过一级菜单进入项目列表。
- 制作流程采用资产详情式无边框左箭头紧接标题。工作台明确返回章节并恢复定位，划分返回原场次，无有效目标则返回章节。使用已有草稿保护。
- 项目资源和资产库共用基础展示模式：160px封面、14px/600名称与箭头及更多、13px/20px两行简介。简介缺失显示未填写简介。标签、角色演员/服装关联移至已有详情；删除关联等业务语义保留。
- 两处网格一致，少量卡片不铺满整行。场所cover，其余contain；缺图/失败一致，不打开无效预览；既有多视角能力保留。
- 工作台256px本章侧栏，身份、步骤、当前操作连续排列，步骤无重复本场标注；状态、历史、冲突直接可见。
- 划分整体编辑布局：宽桌面220–240px列表/自适应原文/300–340px编辑，中宽列表+原文及右侧编辑抽屉，关闭不丢草稿并恢复焦点；窄屏三视图切换。顶部保存新版本/放弃，AI/历史/原文次级。保留选区、映射、历史、差异预览与保存保护。
- 设置左对齐最大800px，两组表面；名称简介整行，风格双列、种子比例双列，窄屏单列，开关说明横排。末尾保存取消，不增加固定保存条。
- 验证真实页面+隔离HTTP/既有隔离后端，同资产跨页、少量卡片、明确返回、抽屉草稿与保存保护，主题及断点；不验证真实供应商生成质量。独立画布布局保持原范围。
