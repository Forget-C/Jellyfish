# 02: 三行对象卡片与项目资源选用

**What to build:** 创作者在稳定的三行对象卡片上查看身份与提取描述，通过图片搜索或同名快捷入口选用当前项目资源，或填写设定创建并选用新资源。点击名称进入实际资源详情编辑与生成，返回保留浏览现场。本票完成项目来源的完整交互，资产库来源与直接上传由后续票据接入，不显示不可用的占位功能。

**Blocked by:** 01 — 打通对象主图的动态生产引用。

**Status:** ready-for-agent

- [ ] 保持最小 228px 卡宽、现有自适应网格和 160px 完整比例图片；内容留白桌面 16px／手机 12px，区域间距 8px，不因按钮数量扩大卡宽。
- [ ] 第一区域保留名称、类型与右侧 dropdown；第二区域为提取描述，固定 20px 高、单行省略，空值显示“未填写描述”；第三区域为操作区。
- [ ] 正常宽度动作同排，间距 8px；极窄容器或放大字体允许操作区域内部换行，同一网格行底部对齐，不缩小字号、不截断动作、不横向滚动。
- [ ] 菜单仅含“描述与出处”和适用的“清空”。完整描述与出处可读；没有删除提取对象、查看库中资产、独立编辑对象参考或解除关联菜单项。
- [ ] 有有效资源时名称打开对应项目资源详情；无选用时名称为普通文字，不能隐式创建资源。详情标题显示实际资源名称，卡片及派生引用保留故事对象名称。
- [ ] 编辑资料与生成图片统一在现有对应类型详情内完成，返回恢复筛选、滚动与焦点；资源无图仍可进入详情准备图片。
- [ ] 无选用且有同名项目候选时显示“选用同名／选用／创建”，无同名时显示“选用／创建”；已选用含无图或原选用失效时显示“重新选用／重新创建”。
- [ ] A 存在时为推荐主动作，否则突出创建；同名查询按类型、范围及服务端名称规则进行，不以模糊结果冒充精确同名，待查询或失败不表示无匹配。
- [ ] 同名入口打开图片、名称、来源、描述与采用效果的 Modal，须明确“确认选用”，不自动合并；无图项目对象可作为候选。
- [ ] 通用选用采用图片网格，支持名称或描述搜索、分页、选中态及成员图片预览；预览与选择独立，选中候选不立即提交，不选择本场固定单图。
- [ ] 重新选用在同一弹窗说明动态画布影响，原资源、独立固定图片与已受理任务保留；取消不改变原选择，失败保留候选，冲突刷新核实，不自动替代。
- [ ] 填写设定创建复用资源编辑器，预填提取名称、描述；保存与生成参数由用户明确提交，不因打开入口自动创建或生成。
- [ ] 重新创建新项目资源并替换选用，原资源保留；名称冲突要求调整，不覆盖。新资源保存成功即选用，生成排队或失败不回滚到旧资源。
- [ ] 新资源创建成功但选用失败时重试原资源身份，禁止重复创建；生成期间清空或重新选用后，迟到结果不覆盖当前选择；遵守既有草稿与离开保护。
- [ ] 清空二次确认说明保留名称、描述、出处、资源和图片，并影响仍沿用本场对象的动态画布；确认后动作与预览状态正确更新。
- [ ] 覆盖三类对象的读写权限、空态、加载失败、后台刷新、重复提交、键盘操作与焦点恢复，操作不超出当前项目范围。
- [ ] 通过公开 API 验证项目同名查询、选用、填写设定创建与部分成功恢复；通过真实页面验证所有状态矩阵、窄屏与放大字体、预览及详情往返，复用已确认的两个测试边界。
- [ ] 完成受影响接口同步、类型检查和适用回归及文档更新；不将资产库导入、项目上传或画布角度引用提前纳入本票。
