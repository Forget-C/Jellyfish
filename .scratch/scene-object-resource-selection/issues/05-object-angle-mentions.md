# 05: 通过 @ 引用主图与多角度

**What to build:** 画布作者在现有提示词引用候选中选择对象主图或指定角度，用 `@张三`、`@张三-左侧` 等标签表达用图要求；引用保持对象身份，实际生产提交时解析当前图片，并支持同一对象多角度及已有固定图片方式。

**Blocked by:** 01 — 打通对象主图的动态生产引用。

**Status:** ready-for-agent

- [ ] `@对象名` 默认选择当前主图，明确角度选择该角度当前有效默认图；主图与正面默认图不同的情况可正确预览、保存和生成。
- [ ] 输入 `@` 或对象名／角度筛选现有候选，候选展示缩略图、主图或支持角度及必要消歧信息；鼠标或键盘明确选择后才建立结构化引用，普通文字不自动绑定。
- [ ] 标签显示 `@张三-左侧` 等，内部保存稳定提取对象来源与选择器，不按连字符拆分身份；同名、真实名字包含角度后缀、改名和特殊符号不能错绑。
- [ ] 资源支持的角度作为可选值，不将旧参考卡自由角度说明自动转换成资源角度，不从提示词文字猜测角度，不增加场次卡角度 Select 或重复的独立角度配置入口。
- [ ] 场次派生引用显示故事对象名，资源改名不修改该称呼；画布对象名被明确编辑时标签按稳定身份更新。
- [ ] 预览按当前关系解析，预览不是任务输入固定时点；资源更新不要求改写引用配置，实际生产提交仍经由提取对象读取当前选用。
- [ ] 缺图候选不可用；已有引用后来缺图、对象无选用或资源失效时明确诊断，不退回其他角度或任意图片，必需参考缺失时阻止提交。
- [ ] 同一对象可同时引用主图和多个角度，保存和解析不只按资源 ID 去重，不合并不同选择器，也不将其解释为多个角色。
- [ ] 相同文件可复用媒体输入，但保留各处文字引用与映射；不同图片超出模型数量或能力时明确提示，不静默丢图，不把整个资源集合发给模型。
- [ ] 明确指定某张图片沿用现有固定图片引用，独立于默认图与场次选用变化；不新增固定文件编号语法，也不把正常固定图能力当成旧格式兼容。
- [ ] 实际图片／视频任务记录并保护解析得到的具体文件；角度默认图更换只影响新任务，已受理任务、同一固定输入重试及历史核对不漂移。
- [ ] 公开 API＋真实任务流程验证主图与角度差异、多角度同身份、同文件复用、模型能力、文件保护及错误输入；浏览器验证候选预览、搜索与键盘选择、标签、消歧及错误恢复。
- [ ] 复用现有命名参考、提示词绑定与媒体映射测试，完成所需契约同步、类型检查、后端检查及适用文档更新；不改整个画布布局，不依赖资源卡片或导入上传界面改版。
