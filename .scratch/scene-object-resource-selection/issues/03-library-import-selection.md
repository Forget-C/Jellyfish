# 03: 资产库导入并选用

**What to build:** 创作者在对象选用弹窗中切换到资产库，通过图片搜索核对来源后导入独立项目副本并选用；同名快捷入口同时展示项目与资产库候选，让来源选择、名称冲突和复制效果可理解、可恢复。

**Blocked by:** 02 — 三行对象卡片与项目资源选用。

**Status:** ready-for-agent

- [ ] 通用选用弹窗提供“项目资源／资产库”切换，默认项目资源；两类来源均有图片搜索、分页、选中态和成员图预览，不恢复文本 Select。
- [ ] 人物候选为库中演员，导入后形成项目角色；场所和道具同类导入。不加入项目演员、服装或其他项目候选。
- [ ] 同名快捷入口同时查询项目及资产库的同类合法候选；两边都有结果时共同展示、项目排前，标注来源，用户明确选择，不自动合并或选用。
- [ ] 查询中、查询失败、无匹配、无封面和图片加载失败分别处理；切来源或搜索不让迟到响应覆盖当前结果，不以失败冒充无同名。
- [ ] 项目候选仍使用“确认选用”；库中使用“导入并选用”，明确创建独立项目副本、后续修改不影响库中原件。
- [ ] 库中对象需至少一张有效图片；导入复制全部有效成员、主图、视角与默认选择，不复制基础设定、长期参考、任务或未采用候选。
- [ ] 导入得到独立项目对象与文件身份，修改或删除来源不破坏副本；选用仅绑定新项目对象，不恢复资产库共享关联。
- [ ] 项目存在同类同名对象时，可返回选用该对象或调整副本名称导入，不能覆盖或自动合并；故事对象名称与出处保持原样。
- [ ] 选用确认前取消不改变旧关系；受理后重复请求不会重复导入。导入成功但选用失败时可核实并重试同一个副本，不再复制一份。
- [ ] 来源在提交前被删除、权限失效或场次修订变化时明确报错并保留可恢复现场，不自动选择替代资源，不接受跨项目或错误类别。
- [ ] 成功后卡片、详情与派生动态画布读取副本，已有独立固定图片及任务输入不变；无图项目对象的原有可选行为保持不变。
- [ ] 公开 API＋真实任务流程验证类型映射、复制隔离、名称冲突、无有效图、复制失败恢复与重复请求；浏览器验证两个来源、双同名、搜索分页、预览、取消与确认及键盘焦点。
- [ ] 完成适用契约同步、类型检查、后端检查、回归与文档更新；保持既有导入所有权规则，不新增存量兼容或实际库清理动作。
