# 06: 存量对象选用转换与冲突清理

**What to build:** 维护者能预检并核对旧场次单图准备的影响，将有效记录直接转换为对象级选用，对无法明确转换的冲突按批准清单清理；转换后的场次仍能选用资源并参与动态生产，正常画布、任务和文件保护保持有效，不新增旧格式兼容分支。

**Blocked by:** 01 — 打通对象主图的动态生产引用。

**Status:** ready-for-agent

Completion: pending-actual-data-approval

- [ ] 先产出可审阅的预检结果，区分可直接转换记录、独立场次上传、无有效资源归属记录及其他冲突，包含精确身份、必要依赖和文件保护变化，不以名称猜测归属。
- [ ] 有效项目资源选用保留原对象身份，直接转为对象级关系，取消场次固定单图语义；提取名称、描述、出处和资源成员图片保留。
- [ ] 原场次独立上传能明确归属时加入对应项目资源，不覆盖既有主图或角度默认图，其他选用该资源的位置可使用这些成员；不为缺省归属临时创建猜测资源。
- [ ] 无法直接转换的冲突可移除，但清理范围逐项明确，不将冲突标签扩大为删除整个画布、任务、项目资源或文件的授权。
- [ ] 仅解除已核实无用途的场次单图文件保护，保留画布、任务及历史仍需要的保护；不能因资源删除或旧字段退出而连带清理实际被使用的文件。
- [ ] 正常固定图片引用继续生效，不自动转换已有画布或历史任务，不重新解释固定用图；用户明确更换来源后才采用动态对象方式。
- [ ] 不引入旧场次单图格式的读取兼容分支、按名称恢复或隐式读取迁移；正常固定图片能力与待退役场次字段明确区分。
- [ ] 先使用隔离数据执行转换与清理，验证公开接口读取、页面展示以及选用到真实生产任务的结果，不仅检查数据库字段形状。
- [ ] 隔离用例覆盖可直接转换、独立上传、资源失效、引用保护与冲突项；执行失败或重放不能重复加入成员、扩大删除范围或改变已保留内容。
- [ ] 为实际环境核实具体数据及依赖，给出执行前保护、操作范围与执行后核验方式；现有方案同意只确定处理方向，须取得该清单对应的范围确认后才执行实际库变更。
- [ ] 实际影响范围变化时重新说明并确认，不沿用其他历史清理授权；未获具体确认时完成预检和隔离验证，明确报告尚未执行的实际处理。
- [ ] 获得适用授权并执行后，核验清单内外记录、资源图片、画布与任务保护及场次读写结果；保留可核对的处理结果，不把预检成功当作实际清理完成。
- [ ] 沿用已确认的两个测试边界和现有维护机制，不建立额外生产服务或持续兼容框架；完成适用检查并同步最终存量处理事实。
