# 01: 打通对象主图的动态生产引用

**What to build:** 创作者选用已有项目资源后，新画布中的对象参考经由提取对象解析当前资源主图，实际图片／视频生产提交时才固定本次用图。清空、重新选用及主图更新影响未来生产，已受理任务和明确采用的固定图片保持独立。本票先打通默认主图这条完整路径，复用现有操作入口并完成必要页面适配；卡片改版与角度选择由后续票据交付。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

Completion: resolved

- [x] 人物、场所、道具均能选用当前项目的角色、场景、道具；项目内直接复用，无图对象也可选用，错误类型和跨项目资源被拒绝。
- [x] 场次准备持久化资源类型与身份，不继续保存本场固定单图选择；页面按需读取主图及可用状态，移除角度及单图选择入口，不要求加载或冻结完整成员集合。
- [x] 新分镜画布的引用链为“画布对象参考 → 场次提取对象 → 当前选用项目资源”，不能复制当时的资源 ID 作为长期绑定，也不能用名称寻找资源。
- [x] 分镜文字规划不读取或向模型传递资源图片，不为初始化单图内容卡提前固定图片输入或整套图片集合。
- [x] 新画布的对象参考能够预览主图并通过现有结构化 `@对象名` 入口实际用于图片／视频生产；所需契约、接口、页面与真实任务链路一并完成。
- [x] 提取对象的名称、描述、出处与所选资源分别维护；资源改名不修改故事名称，画布引用标签不因资源改名而失效。
- [x] 修改主图或重新选用资源后，无须改写已有动态画布绑定，下一次新生产读取当前主图；多张派生画布遵循同一关系。
- [x] 清空有确认并只解除资源选用，提取对象、画布参考卡及正文引用保留；后续动态引用显示无选用，不删除资源或图片。
- [x] 资源在管理入口被删除时动态引用显示失效，不因动态引用存在而一概阻止删除，不自动选择同名替代，不删除提取对象或画布参考卡；仍遵守本次之外的删除规则。
- [x] 资源失效、资源无图和缩略图加载失败分别表达；加载失败可重试，缺少必需参考时阻止生产，不擅自选用其他图片。已有允许无参考的场景须明确按无参考继续。
- [x] 实际生产提交时完成身份、权限、文件及模型能力校验，受理时记录并保护实际用图；排队、执行、同一任务重试和历史核对不重新读取当前主图。
- [x] 已受理任务不因清空、重新选用、图片更新或资源删除而改变输入；迟到结果留在原目标，不恢复旧选用。受保护文件不能因资源删除而被连带清理。
- [x] 现有正常固定图片引用继续独立生效，不自动改成动态引用；此能力保留不等于新增旧场次单图格式兼容分支。
- [x] 复用修订冲突及重复提交保护；只读可查看、不可修改，选择或清空请求提交中阻止同卡冲突操作，后台生成不阻止用户清空或重新选用。
- [x] 通过“公开 API＋真实任务流程”验证选用到实际媒体任务的完整路径、主图更新、清空与失效、任务输入固定及文件保护；使用隔离存储，只替代外部模型调用。
- [x] 通过真实页面浏览器交互验证主图展示、默认引用、清空确认、重新选用、只读和错误恢复；沿用现有场次对象、分镜及画布命名参考测试入口。
- [x] 完成受影响接口生成、类型检查、后端适用检查与回归，并同步本票已落地的文档事实；不执行存量实际库清理，不顺带完成后续票据范围。
