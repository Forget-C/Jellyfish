# 07 接入人工与自动审批策略

阶段 2 · 独立审批组件

**What to build:** 授权用户可手动决定，也可授权服务根据代码规则与独立审批 Agent 的逐组复核签发自动决定。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 人工与自动审批都经同一决定服务；查询结果可区分决定来源、版本与选中组。
- [ ] 通过可控复核器分别验证授权范围内且通过复核、超出授权、复核未通过三种情况。只有满足授权、代码规则和复核要求的组得到自动批准。
- [ ] 删除卡片、解除已采用引用、发起模型卡运行分别检查用户对该动作的明确指令；仅有通用授权时不得放行。
