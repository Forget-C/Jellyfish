# 04 单卡运行、结果查询与协议完整性验收

阶段 1 · 完整画布能力协议

**What to build:** 普通后端调用方能将一次编辑从预演推进到显式单卡运行，并查询这次运行的结果。

**Blocked by:** 02, 03

**Status:** ready-for-agent

- [ ] 在两种画布上预演并应用两个镜头，再编译、显式运行所选卡，按原请求或任务标识查到状态、回执和产出。
- [ ] 重复编辑不增加绑定；用可控执行器模拟提交结果未知，调用方能按原标识追踪，新增提交次数为零。
- [ ] 逐项核对 01 的清单，验证四组协议覆盖已有公开业务操作和各自适用的画布；整条路径可脱离 Agent 使用。
