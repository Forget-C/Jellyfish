# 09 封装画布读取、批量预演与输入检查工具

阶段 3 · Agent 工具

**What to build:** 创作助手可以通过面向任务的工具调查画布、预演多个镜头并检查预期生成输入。

**Blocked by:** 07, 08

**Status:** ready-for-agent

- [ ] 从相同的画布起始状态分别调用工具与公开协议，核对字段差异、无变更和来源冲突三种结果一致。
- [ ] 两个镜头的工具预演能显示依赖、目标和独立改动组；输入检查能核对单份完整描述及实际角色图。
- [ ] 只要方案时可以连续读取、预演及修订；审批请求数、画布写入数和生成提交数均为零。
