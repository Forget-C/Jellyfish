# 08 恢复获批生成并核对原任务

阶段 2 · 独立审批组件

**What to build:** 业务执行方在生成提交中断时可核对原任务，将实际结果关联回用户的审批决定。

**Blocked by:** 06

**Status:** ready-for-agent
Completion: complete

- [x] 明确批准生成后，记录决定、组和可追踪的原请求标识；任务受理后能查到对应任务与回执。
- [x] 用可控执行器模拟外部已受理、本地尚未取得结果，重启并重复消费同一决定，实际提交总数为一。
- [x] 对结果仍未知的请求保留可查询状态，随后取得结果时更新原任务回执，能从决定查回对应产出。
