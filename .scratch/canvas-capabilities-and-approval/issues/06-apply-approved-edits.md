# 06 消费审批决定并恢复画布写入

阶段 2 · 独立审批组件

**What to build:** 画布从持久化决定接续执行获批组，用户可分别核对批准内容和实际写入结果。

**Blocked by:** 05

**Status:** ready-for-agent
Completion: complete

- [x] 两个独立镜头只批准第一个，仅第一个写入；待审或已拒绝组保持相应状态。画布保存与写入回执在同一事务完成。
- [x] 分别在批准后执行前、写入后调用方收到回执前中断；恢复及并发重试同一决定时，已生效组返回原回执，每组最多产生一次效果。
- [x] 执行前复核来源、依赖和字段。执行失败可查回执；冲突时保留原决定并展示原值、当前值与建议值，用户核对新差异后可作出新决定。
- [x] 恢复可由业务执行方完成，即使模型没有继续回复也能查询处理结果。
