# 11 验证原生工具模型与纯文本模型行为一致

阶段 3 · Agent 工具

**What to build:** 两类可控模型通过各自的适配入口完成相同任务，用户获得一致的预演、送审结果和可读反馈。

**Blocked by:** 09, 10

**Status:** ready-for-agent

- [ ] 从相同初始状态分别运行原生工具模型和纯文本模型；只要方案时仅返回预演，明确送审后可核对相同的差异、所见版本和选中组。
- [ ] 分别输入无效参数、失效对象及有效改动，核对领域结果一致；失败时仍有可读反馈。
- [ ] 检查两种适配入口的用户可见输出，覆盖增量内容和最终消息，工具的中间 JSON 全程不可见。
