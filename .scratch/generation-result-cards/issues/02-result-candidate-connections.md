# 02: 按结果管理下游候选与断线保护

**What to build:** 创作者可以单独连接或断开某项关联结果与下游卡片，仍受现有引用保护；同批其他结果和其他下游不受影响。结果数量改变或切换显示后，下游候选准确反映用户保留的连接范围。

Blocked by: 01 — 显示并持续更新关联结果卡

Status: ready-for-agent
Completion: integrated

- [x] 从关联结果建立连接只提供该项结果的候选，不将同来源其他位置一起静默接入；不能重复候选或自动采用。
- [x] 断开 R → B 时检查该项结果在 B 的全部相关保留引用和用途。存在引用则拒绝并说明原因；解除后仅移除对应结果到该消费者的路径。
- [x] 持久化并在服务端解释逐结果连接范围。不能因当前连接按来源卡归并，就连带移除同来源其他结果或其他消费者的关系；直接提交非法最终文档同样受服务端保护。
- [x] 开关关闭后显示的 A → B 只代表真实保留的候选范围，不能恢复已断位置或扩大来源范围；重新开启、保存重开和后续生成均保持明确断线决定。
- [x] 对继续接收 A 输出的关系，新增输出位置自动成为候选但不自动引用；单项显式连接和仍接收模型结果的关系不能被混为相同范围。
- [x] 结果数量减少时，有连接或引用的缺失位置保留稳定身份和缺失占位，不改绑其他位置，不将旧内容继续声明为当前可用输出。
- [x] 缺失位置再次出现时恢复更新；无连接、无引用的缺失关联结果卡可以收起。没有正式内容的缺失位置不能提供可用引用。
- [x] 既有整来源连接和输入用途仍按原行为工作；本票的必要调整限制在结果范围及引用保护，不扩展无关导演卡连接语义，也不通过静默历史修复规避校验。
- [x] 真实浏览器旅程覆盖三项结果中单独断开一项、同结果多个用途、多个消费者、开关折叠和重开，以及数量从三变二再变四；公开候选和编译输出验证用户实际输入。
- [x] HTTP 回归覆盖引用阻断、错误位置或模态、不兼容目标、非法来源范围和保存重开；可复用现有纯文档操作回归定位原子变换错误，但不只验证内部结构。
- [x] 同票完成涉及的公开契约、生成客户端、架构说明与必要检查，不将服务端范围解释留作后续票据。
