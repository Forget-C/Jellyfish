# 04: 通过现有复制入口创建独立副本

**What to build:** 创作者对关联结果使用现有复制操作，即可粘贴出一张承载当前内容的独立内容卡，继续编辑和连接；原关联结果及其下游保持不变，并继续随模型更新。

Blocked by: 01 — 显示并持续更新关联结果卡

Status: ready-for-agent
Completion: integrated

- [x] 复用现有复制及粘贴入口，不增加“复制为独立卡”菜单；关联结果被视为其当前可用内容，而非把模型配置或更新关系复制到副本。
- [x] 副本获得新内容身份并固定复制时的正文或文件，不复制上下游连线，也不保留正式生成来源记录；不修改原卡的来源或历史。
- [x] 副本可按普通内容卡编辑、连接、删除和保存重开；文件复用及删除保护沿用现有内容复制规则，不重复生成文件或发起模型任务。
- [x] 模型在复制后或粘贴前发布新结果时，副本仍使用复制时捕获的内容；原关联卡继续更新，既有候选和引用不变化。
- [x] 同一结果有下游消费者时仍可复制内容；不把原卡的下游引用迁移到副本，也不因副本外观相同而合并身份。
- [x] 缺失或不可用的输出不给出伪造内容副本，沿用现有操作拒绝与原因反馈；只读、剪贴板和跨画布规则不扩大原有权限或动态引用范围。
- [x] 文本、图片、视频按实际已接入结果验收；音频只复用已有内容能力，不声称新增音频模型已接入。
- [x] 通过真实画布复制入口验收副本独立、原卡跟随、复制后模型更新及保存重开；公开保存和输出读取验证副本身份、内容及无正式来源记录。
- [x] 本票不依赖上游断线固定功能；复用既有内容复制和校验即可完成。按实际契约影响同步客户端与文档，并运行受影响检查。
