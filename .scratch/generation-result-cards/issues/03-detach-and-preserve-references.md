# 03: 断开上游固定内容并迁移引用

**What to build:** 创作者断开模型到关联结果的线后，当前内容成为可独立编辑的普通内容卡，保留真实生成来源及所有下游连接和引用；后续模型生成产生新关联结果但不接回原固定路径。固定、撤销与重做始终保持内容和引用一致。

Blocked by: 02 — 按结果管理下游候选与断线保护

Status: ready-for-agent
Completion: integrated

- [x] 仅通过现有断线交互触发固定，不新增“固定为独立卡”菜单或按钮。操作捕获用户所选的具体正式成果，不使用稍后到达的结果替换。
- [x] 固定的文本或文件转换为独立内容身份，保留真实运行、节点及结果位置等已有来源信息；复用来源真实性和文件使用保护，不能固定不存在、未正式交付或不属于当前项目画布的结果。
- [x] 已被 B 引用时允许断开 A → R。所有保留消费者对该项结果的引用、用途、顺序、提示词绑定及其他已支持来源引用一起迁移到独立内容，保持当前解析内容不变。
- [x] 创建独立内容、迁移引用和解除更新关系是一次完整保存和编辑历史操作；无效来源或保存修订冲突不能产生部分转换状态。
- [x] 独立结果可按普通内容卡编辑和连接，显示开关不再控制它。禁止通过手动重连 A → R 恢复跟随，误断使用撤销。
- [x] 下一次正式生成成功才产生新的关联结果卡；旧结果重放、刷新或开关重开不会立即重建刚固定的路径。新关联结果不自动接回原固定消费者，原独立内容始终不变。
- [x] 覆盖部分固定的批次：第一项固定、第二项对 B 断线、第三项继续更新；后续第四项按仍接收 A 输出的关系进入候选，前两条退出路径不恢复。不同消费者分别保持自己的路径范围。
- [x] 撤销固定恢复与模型当前输出的关联，包括最新位置缺失的情况；重做恢复原操作固定的具体内容，而非重做时的新结果。不回滚模型历史，也不新增任务。
- [x] 固定期间 A 已产生新关联展示时，撤销和重做不产生重复位置卡、重复候选或误连下游；相关布局和引用作为完整操作恢复。
- [x] 原始结果集、运行记录及已经提交任务的固定输入不改写。固定独立文件继续受使用关系保护，晚到运行事件不覆盖独立内容。
- [x] 真实浏览器旅程覆盖多消费者固定、继续生成、独立内容编辑、保存重开以及跨次生成的撤销重做；HTTP 回归覆盖来源伪造、无效位置、冲突、原子失败和固定依据保持。
- [x] 所有实际支持的正式结果模态遵守相同行为，不新增音频生成入口；同票完成所需公开契约、客户端、文档同步及受影响检查。
