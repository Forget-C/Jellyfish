# 01: 显示并持续更新关联结果卡

**What to build:** 创作者可以通过模型卡下方“显示结果卡”开关展开当前正式结果，每项结果独立展示并随模型后续正式输出按位置更新；关闭后恢复原有紧凑图示，重开画布保留选择和布局。开关不改变实际输入或模型执行。

Blocked by: None

Status: ready-for-agent
Completion: integrated

- [x] 新建和已有模型卡默认关闭显示，开关逐卡保存；无正式结果时可提前开启但不创建空结果卡，首个正式结果到达后展示。只读模式不能修改开关。
- [x] 关联结果是现有模型输出的展示，不引入普通内容卡的数据输入或第二份实际输出；同一结果供多个下游使用时只显示一张关联卡。
- [x] 按实际内容复用文本、图片、视频、音频预览；真实生成验收使用已接入的文本、图片和视频能力，不新增音频生成入口或伪造音频生成链路。
- [x] A 的原有预览、状态和尺寸保持，结果卡可查看、播放和移动，但不能直接改写正文或替换媒体。结果布局沿用现有机制，不自动重排其他卡片。
- [x] 未断开的结果按输出位置更新并保留布局，不按图像语义或相同文件猜测对应关系；正式输出的依据过期状态如实保留。
- [x] 生成中、失败或取消继续沿用现有正式结果，临时流式内容不成为正式结果卡；后台结果展示不反复改写编辑文档或历史运行。
- [x] 展开和折叠前后候选及实际引用相同，编译出的文本、媒体和用途不变；开关不触发生成，也不作为生成输入参数使成果过期。
- [x] 关联结果继续沿用模型输出的连接资格，不能因为采用图片卡外观绕过目标仅接受独立图片内容的限制；保持现有 DAG 和能力检查。
- [x] 本票只交付显示与跟随行为；尚未实现的结果操作不作为可成功执行的入口暴露，不将关联结果交给普通内容卡更新、删除或复制逻辑造成数据损坏。现有模型卡复制行为不扩展为复制运行成果。
- [x] 通过现有真实画布浏览器旅程验证开关、正式结果到达、位置更新、保存重开与无隐式运行；用公开输出及编译读取核对显示前后语义一致。检查可见标签、键盘焦点、只读和窄屏参数栏。
- [x] 同票完成所需持久化和公开契约同步；按实际影响执行项目必要检查并同步受影响的现行文档，不建立新测试框架或平行保存机制。
