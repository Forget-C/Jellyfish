# 生成画布：结果卡显示、断线独立与下游引用

Status: ready-for-agent

日期：2026-11-07

产品行为、测试边界及五张纵向票据的拆分与依赖均已由用户确认，本规格及票据已发布到项目本地任务系统。发布不代表功能已经实现，也不授权自动开始实现。

## Problem Statement

创作者将模型卡连接到下游卡片后，生成结果会进入下游候选列表，但画布上只有模型之间的连接，难以直接观察每项结果如何继续被使用。创作者还需要在持续试生成的同时，保留某个满意结果，让下游继续使用该结果而不被后续生成覆盖。

用户希望用一个显示开关展开结果卡，通过现有断线操作固定内容，通过现有复制操作产生独立副本。显示、候选连接、实际引用与内容固定必须保持不同含义，不能因切换显示而重复候选、恢复已断连接或改变实际输入。

## Solution

在模型卡下方参数栏增加“显示结果卡”开关，默认关闭，逐卡保存。开关开启且存在正式结果时，每项结果展示为一张对应模态的关联结果卡；模型卡仍保留原有预览、状态与尺寸。

以下 A 表示模型卡，R 表示某项结果卡，B 表示下游消费者，仅用于说明，不规定产品命名：

| 用户动作 | 显示与业务结果 |
| --- | --- |
| 关闭显示 | 折叠仍关联的结果，按实际保留关系显示 A → B。 |
| 开启显示且有结果 | 显示 A → R → B，同一项结果不重复加入候选。 |
| 再次生成成功 | 按输出位置更新仍关联的 R，保留其位置及下游连接。 |
| 断开 R → B | 先检查引用保护；允许后移除该结果到 B 的候选路径。 |
| 断开 A → R | 固定当前内容，R 成为独立内容卡，保留来源及所有下游连接、引用。 |
| 固定后再次生成 | A 产生新的关联结果卡；原独立 R 不变，新卡不自动接回原下游。 |
| 复制关联 R | 使用现有复制入口产生独立副本，不复制连线或正式生成来源记录；原 R 继续更新。 |

关闭或重开显示不能恢复任何已明确断开的路径。已独立的内容卡不再受 A 的开关控制。关联结果卡不提供额外的“固定为独立卡”或“复制为独立卡”菜单。

## User Stories

1. 作为创作者，我希望在模型卡下方参数栏切换结果卡显示，以便按需观察结果流向。
2. 作为创作者，我希望开关默认关闭，以便已有画布保持原来的展示习惯。
3. 作为创作者，我希望每张模型卡记住自己的开关选择，以便重开画布后继续原来的工作方式。
4. 作为创作者，我希望尚无结果时也能提前开启显示，以便生成成功后自动看到结果卡。
5. 作为创作者，我希望尚无正式结果时不产生空结果卡，以便不把未来产出误认为可用内容。
6. 作为创作者，我希望每项结果单独显示，以便分别连接、固定和复制多张生成图片。
7. 作为创作者，我希望结果卡按实际内容展示文本、图片、视频或音频，以便直接阅读或预览。
8. 作为创作者，我希望展开结果后模型卡保持原有预览、状态和尺寸，以便生成入口及周围布局保持稳定。
9. 作为创作者，我希望开关不改变候选、引用或实际生成输入，以便自由调整显示方式。
10. 作为创作者，我希望同一项结果在下游候选中只出现一次，以便不会混淆展开前后的来源。
11. 作为创作者，我希望关联结果卡可以移动，以便整理画布而不改变内容关系。
12. 作为创作者，我希望关联期间不能直接改写结果内容，以便避免自己的修改被下一次生成覆盖。
13. 作为创作者，我希望重新生成按输出位置更新关联卡，以便原有连线继续指向该位置的当前结果。
14. 作为创作者，我希望结果更新后保留卡片位置，以便不会在试生成时反复整理布局。
15. 作为创作者，我希望固定某项具体内容时使用断开上游连线，以便操作和画布关系一致。
16. 作为创作者，我希望固定后卡片保持当前内容，以便后续生成不影响满意的版本。
17. 作为创作者，我希望固定后保留真实生成来源，以便追溯该内容来自哪次结果。
18. 作为创作者，我希望固定结果时保留下游已有引用，以便不必解除再重新插入引用。
19. 作为创作者，我希望同一结果的所有下游引用一起转为固定来源，以便各消费者保持一致。
20. 作为创作者，我希望固定操作一次完成并能整体撤销，以便不会留下部分转换的引用。
21. 作为创作者，我希望固定后再次生成出现新结果卡，以便继续试验而不覆盖独立内容。
22. 作为创作者，我希望新结果不自动接回已经固定的下游路径，以便由我决定是否引入新候选。
23. 作为创作者，我希望独立内容不随模型卡开关隐藏，以便固定成果始终可见和可用。
24. 作为创作者，我希望断开下游连线时受到现有引用检查保护，以便不会产生失效引用。
25. 作为创作者，我希望解除相关引用后可以单独断开某项结果，以便不会影响同批其他结果。
26. 作为创作者，我希望切换开关不恢复已断连接，以便显示操作不会撤销我的连接选择。
27. 作为创作者，我希望结果数量增加时，新增项进入仍接收模型输出的下游候选，以便继续按现有方式挑选新结果。
28. 作为创作者，我希望新增候选不会自动成为实际引用，以便输入采用仍由我决定。
29. 作为创作者，我希望仍有连接或引用的输出位置消失时显示缺失占位，以便知道需要处理哪项来源。
30. 作为创作者，我希望缺失位置不被其他图片替代，也不继续冒充旧内容，以便不会误用结果。
31. 作为创作者，我希望同一缺失位置再次出现时恢复关联更新，以便保留的连接和引用继续生效。
32. 作为创作者，我希望无连接且无引用的缺失结果卡可以收起，以便减少无用占位。
33. 作为创作者，我希望生成中、失败或取消时保留现有正式结果，以便继续查看已完成成果。
34. 作为创作者，我希望临时流式内容不会成为正式结果卡，以便下游只使用正式交付内容。
35. 作为创作者，我希望删除关联结果卡时看到不能删除的原因及先断上游的提示，以便使用一致的断线操作。
36. 作为创作者，我希望删除模型卡时检查保留消费者的引用，以便不会破坏仍在使用的结果。
37. 作为创作者，我希望允许删除模型卡后关联结果卡一起移除、独立卡保留，以便删除范围符合归属关系。
38. 作为创作者，我希望批量删除按最终保留的消费者检查，以便内部引用不会阻碍删除整个工作片段。
39. 作为创作者，我希望用现有复制入口直接复制关联结果，以便保留一份独立内容同时继续更新原结果。
40. 作为创作者，我希望副本不复制下游连线或正式生成来源记录，以便遵守普通内容复制的现有规则。
41. 作为创作者，我希望撤销固定后跟随模型最新结果、重做时恢复原先固定的内容，以便编辑历史与生成历史各自准确。
42. 作为创作者，我希望撤销和重做不触发模型执行，以便不会意外消耗生成资源。
43. 作为创作者，我希望关联结果沿用模型输出的连接资格，以便显示开关不会绕过业务限制。
44. 作为创作者，我希望断开上游后按普通内容卡判断连接能力，以便独立内容可用于相应的下游用途。
45. 作为创作者，我希望独立卡不会因重新拖线而恢复跟随并覆盖内容，以便固定状态保持明确，误断通过撤销恢复。
46. 作为创作者，我希望保存重开后连接、固定状态、引用和内容仍一致，以便可靠地继续创作。
47. 作为只读查看者，我希望可以查看结果而不能修改开关、连接或内容，以便沿用画布权限边界。

## Implementation Decisions

1. 沿用领域术语“生成画布”“模型卡”“内容卡”“结果集”“输出标识”“输入代号”“输入用途”。“关联结果卡”描述模型当前某项输出的可视化状态；断开上游后是普通独立内容卡，不引入新的运行任务种类。
2. 区分模型到结果的更新关系、结果到消费者的候选连接、消费者的实际引用。模型到结果的线不是给普通内容卡新增数据输入，不改变基础内容卡仅输出自身内容的契约。
3. 优先复用现有模型正式输出身份与解析机制。关联期间展示同一来源位置，不因展开新建第二份实际输出、复制文件或改变消费者输入代号对应的来源。具体数据字段和端点签名由实现确定，不在规格中虚构既有 API。
4. 显示偏好按模型卡持久保存，默认关闭；结果卡位置沿用现有布局机制。偏好与布局不作为模型生成参数或实际输入依据，切换显示不得使有效成果因生成依据改变而过期。后台结果发布继续独立于编辑文档，不为更新卡面而反复改写文档内容。
5. 复用模型参数栏、共享卡壳及对应模态的预览组件。模型卡保持现有预览、状态和尺寸。关联结果禁止直接编辑内容；固定后的普通内容卡遵守现有编辑规则。复用现有控件、主题、焦点与只读行为。
6. 一项正式输出对应一张关联结果卡；多消费者复用该结果卡，不为每个消费者复制一张。关联卡按来源输出位置更新，不按图片语义、文件相同或人工移动位置猜测结果对应关系。
7. 需要表达逐输出位置的连接范围与已断路径。当前按来源卡归并连接的实现不能直接用于逐结果断线；删除某项结果到 B 的连接不得同时移除同来源其他结果或其他消费者的有效路径。该结果被 B 以多个用途引用时，仍检查全部相关保留引用。
8. 开关关闭时只折叠真实存在的关联路径；不能因显示 A → B 而扩大 B 的候选范围，也不能恢复已断开的输出位置。重新打开时还原相同范围。显示投影和实际候选解析必须一致。
9. 断开模型到结果的线时，固定用户操作所对应的具体正式结果，保留文本或文件及真实来源；创建独立内容身份，并将所有保留消费者对该结果的引用、用途、顺序、提示词绑定和其他已支持的来源引用一致转到独立内容。原始运行记录、结果集和已提交任务的固定输入不改写。
10. 固定内容、迁移下游引用及解除更新关系作为一次完整文档操作保存和撤销。复用现有保存修订、冲突处理、来源真实性校验与文件使用保护；校验失败不能提交半转换状态。迟到的生成结果不能替换本次操作所指定的固定内容。
11. 固定后，新一次成功生成才形成新的关联结果卡；开关重开、页面刷新或旧结果重放不能立即把刚固定的路径重新创建。新卡不自动接回原固定路径，其他未断位置继续正常更新。
12. 对仍接收 A 输出的下游，新增输出位置自动成为候选，不能自动采用；显式断开的路径与固定退出的路径不重新接入。实现需同时覆盖部分结果固定、部分断线以及其余结果继续连接的混合场景。
13. 结果数量减少时，有连接或引用的缺失位置保留稳定身份和明确缺失状态，不回退到其他位置，不将旧媒体当成当前可用输出。该位置恢复后沿原关系更新；无连接、无引用的缺失关联卡可以收起。独立内容不参与此更新。
14. 沿用当前正式结果发布、失败保留旧成果、依据过期及流式临时预览规则；仅正式结果更新关联卡。缺失或不可用结果不能被伪装成成功生成内容，也不能凭空固定或复制不存在的内容。
15. 关联结果卡单独删除时拒绝操作并说明先断开上游，不增加固定菜单。删除模型卡沿用活动运行及引用保护；允许删除后移除其关联展示，独立卡不受影响。批量删除只检查最终保留的消费者，不以将同时删除的内部引用阻止整个操作。
16. 复制关联结果复用现有复制入口和独立内容复制行为：捕获当前可用内容，新建身份，不复制连线，不保留正式生成来源记录。原关联卡不改变。复制模型卡仍沿用既有规则，不因本功能复制模型运行或成果。
17. 撤销固定恢复与模型当前输出的关联，若该位置已缺失则展示缺失状态；重做恢复当时固定的原始内容。模型在此期间新增的关联展示不得造成同一输出位置重复展示、重复候选或误接下游。后台生成历史不随文档撤销回滚，也不因此发起任务。
18. 关联结果卡沿用原模型输出的连接资格、模态与能力限制，不能因外观类似内容卡而连接原本禁止的目标。固定后按对应普通内容卡资格判断。禁止通过手动重新连回模型将独立内容变成持续更新结果；误断仅用现有撤销恢复。
19. 显示开关、结果变化、断线固定、复制和撤销均不隐式调用模型。不新增音频生成入口；音频内容展示沿用已有能力，不能以伪造正式音频结果声称真实生成链路已接入。
20. 修改集中在画布图展示与编辑操作、候选及引用解析、文档保存校验、历史内容准备与保护、相关公开契约。API 层继续负责收参鉴权和响应，业务转换在 service 层；前端继续使用 OpenAPI generated client。新增通用跨层值放在既有 contracts 边界内。
21. 公开 schema、端点或语义变更时同步后端、OpenAPI 与 generated client；持久化状态须能保存重开。沿用严格文档校验，不通过兼容别名、读时静默修复或改写历史运行来规避新行为。实施后同步受影响的当前架构与操作文档。

## Testing Decisions

以下测试边界已由用户确认，作为本规格及对应票据的验收基线。

1. 主要测试边界为真实生成画布的用户操作旅程：使用现有浏览器 runner、真实页面、隔离后端与受控模型产出，验证点击开关、拖动和断线、引用管理、复制、删除、撤销重做以及保存重开。以用户可见结果与公开读取状态断言正确性，不断言组件内部状态、私有方法调用或某种新数据结构。
2. 补充测试边界为现有公开画布 HTTP API。通过真实保存、输出读取、编译、运行状态与历史内容准备接口验证服务端规则；仅在已有供应商及存储适配边界控制外部依赖。用于覆盖浏览器不适合穷举的伪造来源、跨项目或画布来源、无效输出位置、被引用断线、冲突保存与原子失败。不得仅靠前端阻止非法操作。
3. 优先扩展已有图连线、图片多结果、运行状态、历史内容与会话恢复测试。现有图片测试已覆盖有序结果、第三项缺失不回退和另存内容固定；历史内容 HTTP 测试已覆盖来源真实性与不可变来源；画布操作测试已覆盖整批删除保护与多用途引用保护。复用这些夹具，不建立新的测试框架或平行模拟业务系统。
4. 如现有纯文档操作测试能更直接定位原子变换错误，可补充其公开操作入口用例；这只是既有回归的扩展，不增加新测试接缝，也不替代浏览器和服务端验收。
5. 开关旅程：初始关闭、无结果提前开启、首个正式结果到达、逐项展开、关闭恢复、重开恢复、逐卡记忆和只读不可操作。开关前后候选数量、实际引用、编译后的正文和媒体保持一致，且没有新增生成请求。
6. 多结果旅程：使用明确不同的结果集验证按位置更新、卡片位置不变、数量增加、数量减少、被引用缺失位置、缺失恢复及无用占位收起。独立卡内容不参与更新；不能按相同文件或图片内容猜测身份。
7. 下游断线旅程：正在引用的结果不能断开；解除相关引用后仅断开指定结果到指定消费者的路径；同批其他结果、其他消费者和其他合法用途保持。切换开关、刷新和下一次生成均不能恢复已断路径。
8. 固定旅程：B 已引用 R，另一个消费者也引用 R；断开 A → R 后所有现有引用仍解析到相同固定内容，顺序与用途保持。保存重开、A 再次生成、切换显示后独立 R 不变，新关联结果不自动接回原下游。
9. 混合旅程：一批三个结果中，第一项固定、第二项对 B 断线、第三项继续连接；下次生成四项时，第一项的新关联结果不接回原固定路径，第二项不恢复，第三项正常更新，新增第四项按仍接收 A 输出的关系进入候选。各消费者单独检查，不能用一条汇总连线掩盖候选范围错误。
10. 原子性与竞态：在固定时推进模型正式结果、制造保存修订冲突或无效来源，断言固定内容不会被迟到结果替换，失败不产生部分迁移。继续运行的任务消费原已受理快照，历史记录不改写；成功后独立文件仍受使用关系保护。
11. 编辑历史旅程：固定某次结果后生成新版，撤销恢复最新关联，重做恢复最初固定内容；另覆盖最新位置缺失及已有新关联卡的情况，不产生重复节点、候选、下游连接或生成请求。
12. 删除与复制旅程：关联 R 删除被拒绝并说明先断线，菜单没有额外固定或独立复制项；现有复制命令产生独立内容且无连线、无正式来源记录；删除 A 受保留引用保护，合法删除清除关联卡并保留独立卡；批量内部引用不阻止整组删除。
13. 资格与异常输入：关联结果不能绕过模型来源的连接限制；固定后可按内容卡资格连接；手动重新连回 A 不恢复更新。覆盖错误模态、不存在的结果位置、不支持的目标与循环连接，复用既有目录及能力规则。
14. 展示验收围绕实际变更：文本、图片、视频和已有音频展示能力正确；模型卡尺寸不变；开关有可见标签和键盘焦点；状态不能只靠颜色；关联内容不可编辑；桌面及窄屏参数栏不遮挡执行入口。截图是辅助证据，不能替代候选与引用断言。
15. 实现完成后按影响范围运行相关浏览器与后端回归，以及项目规定的前端 typecheck、后端应用 Pylint；公开契约变化须校验生成客户端来自加载当前工作区改动的后端。共享图或来源解析改动影响面较广时扩展到相应生成画布回归，已通过且代码环境未变的检查不重复运行。本次规格整理不表示这些实现测试已经运行或通过。

## Out of Scope

- 新增音频模型、供应商接入或其他生成能力。
- 更改模型执行、重试、计费、任务恢复与结果发布机制。
- 自动采用候选、自动执行下游或自动补跑上游。
- 按图片语义寻找跨次生成的对应关系；绑定某个人物、构图或文件作为动态输出身份。
- 把全部历史结果自动铺到画布上，或增加历史版本选择卡。
- 在关联状态直接编辑结果内容，或把编辑后的内容同步回模型结果集。
- 给普通内容卡增加持续数据输入，或手动把独立卡重新绑定为模型动态输出。
- 额外的“固定为独立卡”“复制为独立卡”菜单、工具按钮或确认流程。
- 跨画布动态引用、改变其他画布类型或场次工作台流程。
- 模型卡整体视觉改版、新设计系统、无关布局重构或全局自动重新排布。
- 新建测试框架、通用事件系统或额外兼容层。
- 本次发布规格及票据时另建站点计划、发布说明或直接开始实现。

## Further Notes

产品行为依据本次对话 Q1–Q18 的最终确认，包括用户对 Q12 和 Q14 的修正：删除只说明先断开上游，复制复用现有操作并自动得到独立卡；不添加额外操作入口。Q17 明确普通复制不保留正式生成来源记录，与断线上游后固定内容保留来源不同。

现有术语表及 ADR 0001、ADR 0002 是基础边界。早期 ADR 的首版范围排除了“结果选择卡”；本功能扩展的是正式结果的展示和断线固定，不引入运行中人工选择关卡或改变结果集。基础内容卡无数据输入、输出身份与输入代号分离、后台结果不改写编辑文档及已受理输入固定等约束继续成立。

关联展示优先沿用模型输出身份，固定操作才建立独立内容身份。逐结果连接范围、固定退出后不自动恢复、撤销时避免重复展示是本功能必须落实的新行为，不能用纯 UI 插卡冒充完成。规格未指定某个字段名或数据库结构，不表示实现可以省略服务端校验和持久化语义。

本规格与五张实现票据已发布到项目本地任务系统的 generation-result-cards 功能目录，状态均为 ready-for-agent。01 无阻塞；02 与 04 依赖 01；03 依赖 02；05 依赖 03。实施时仅领取阻塞票据已完成的任务；发布规格与票据不自动授权功能实现。
