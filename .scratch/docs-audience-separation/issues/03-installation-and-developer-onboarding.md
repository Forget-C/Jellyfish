# 03: 分离产品安装与开发入门

**What to build:** 让普通用户能按官网说明安装、配置和启动应用，让首次贡献者能通过简短开发入口启动环境并找到完整工程资料。将详细前后端开发、项目结构、OpenAPI、AI 工作流、供应商扩展及相关参考从官网移入开发文档。

**Blocked by:** 01 — 建立开发文档与技能配置入口

**Status:** ready-for-agent

需求依据：[实现规格](../spec.md)，重点覆盖用户故事 2、8、11、12、17、19、34；所有删除与验证边界沿用母规格。

- [ ] 官网应用安装与 Docker 部署说明面向自行部署的产品用户，操作前提、配置来源、启动入口和可观察结果明确。
- [ ] 应用运行要求与官网维护工具要求分别表达；详细站点维护说明在合适的仓库入口可发现，不作为普通用户使用应用的必要步骤。
- [ ] 官网开发快速开始只保留环境准备、前后端与 Worker 启动、基本检查和进一步阅读，链接到详细开发指南。
- [ ] 当前项目结构、前后端组织及 AI 工作流进入架构或开发指南；OpenAPI 同步、供应商扩展与接口、配置参考按其职责归位。
- [ ] 对已有安装、启动、接口生成和配置说明核对实际代码与命令入口，明确开发与部署的不同适用条件，不通过修改业务代码满足旧文档描述。
- [ ] 开发及站点维护 FAQ 归入开发资料；官网保留与现有产品安装或使用材料相关的问题说明，不扩展为全产品的新问题库。
- [ ] 根项目介绍、相关维护说明、审查索引和现行正文中的受影响引用同步更新；避免简短入口与详细指南分别维护矛盾的启动方式。
- [ ] 验证产品安装说明和开发入门两条阅读路径、本票涉及的配置与接口参考、链接资源及站点构建；未实际运行的环境或部署检查如实注明。
