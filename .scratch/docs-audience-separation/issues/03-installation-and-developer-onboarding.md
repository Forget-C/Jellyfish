**What to build:** 让普通用户能按官网说明安装、配置和启动应用，让首次贡献者能通过简短开发入口启动环境并找到完整工程资料。将详细前后端开发、项目结构、OpenAPI、AI 工作流、供应商扩展及相关参考从官网移入开发文档。

**Blocked by:** 01 — 建立开发文档与技能配置入口

**Status:** ready-for-agent

需求依据：[实现规格](../spec.md)，重点覆盖用户故事 2、8、11、12、17、19、34；所有删除与验证边界沿用母规格。

- [x] 官网应用安装与 Docker 部署说明面向自行部署的产品用户，操作前提、配置来源、启动入口和可观察结果明确。
- [x] 应用运行要求与官网维护工具要求分别表达；详细站点维护说明在合适的仓库入口可发现，不作为普通用户使用应用的必要步骤。
- [x] 官网开发快速开始只保留环境准备、前后端与 Worker 启动、基本检查和进一步阅读，链接到详细开发指南。
