# 13: 核对同范围冲突与判断依据

Status: ready-for-agent
Blocked by: 11
Resolution: completed

**What to build:** 用户可通过 P02、P09 核对当前采用要求是否冲突，以及哪项判断需要补足依据。

- [x] P02 引用冲突双方和共同对象、时间或条件。用固定机位与同一时段持续绕行验收，并覆盖不同阶段或待定方案不构成明确冲突的反例。
- [x] P09 指出实际已采用的哪条要求缺少对象、适用条件或可观察结果。没有机位卡时核对现有提交文本与其他已知依据，不推断设计遗漏。
- [x] 技术预检已能识别的硬冲突继续由原链路处理。同一缺陷关联多项时共享证据，不夸大为多个独立问题。
