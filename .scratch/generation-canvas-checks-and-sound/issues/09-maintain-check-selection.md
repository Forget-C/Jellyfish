# 09: 保存检查项选择与排除

Status: ready-for-agent
Blocked by: 08
Resolution: completed

**What to build:** 用户可保存检查类别和子项的选择，并在已采用内容变化后看到检查项按实际来源更新。

- [x] 首次连接按已知输入派生适用的基础项。覆盖空值、不适用、明确没有、提议及背景等状态。未采用卡片、同名对象和视觉编组不产生预期要求。
- [x] 类别、子项、来源与人工修改可追溯。重开、刷新来源或重复派生后，开关和排除选择保留，且不会重复生成同义子项。
- [x] 既有类别的新子项沿用类别开关，软件新增类别默认关闭。来源移出采用范围后，其项目不再约束当前输入，历史报告仍可查。
- [x] 适用但缺少执行条件的项目说明原因。关闭项不进入本轮整卡检查，也不算作本轮通过；显式单项执行清楚标明实际范围。

来源为[实施规格](../spec.md)与[原型记录](../prototype.md)。
