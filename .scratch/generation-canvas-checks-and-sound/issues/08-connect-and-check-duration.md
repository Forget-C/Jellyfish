# 08: 连线并完成首次时长检查

Status: ready-for-agent
Blocked by: None
Resolution: completed

**What to build:** 用户将检查卡连到模型生成卡的专用检查输出，在生成前查看实际编译依据，并用明确时长数值完成首次检查和重查。

- [x] 保存并重开后，检查卡仍指向唯一目标。公开接口拒绝非专用端口、多目标和跨项目连接。观察边不改变生成输入，也不触发上游执行。
- [x] 生成前可读取本次实际文本、参数、采用来源、媒体用途、模型能力和技术诊断。连接只列出适用项，检查由用户发起。
- [x] P06 先覆盖来源和范围明确的数值比较。预计 12 秒对生成 5 秒显示差异或风险，同范围的明确最低或固定时长冲突有证据时才显示不符合。规则执行无需检查模型。
- [x] 首轮显示「检查」，之后显示「重新检查」。整卡执行所选项，单项重查只执行当前项，每次固定目标、依据与配置并产生独立报告。
- [x] 使用公开接口和浏览器流程验证：关闭业务检查不影响 T01–T06 的既有职责，非法实际输入仍由默认技术校验处理；业务结论由用户自行判断是否继续生成。

来源为[实施规格](../spec.md)与[原型记录](../prototype.md)。
