# 05: 生成卡显示原生声音输出能力

Status: ready-for-agent
Blocked by: None
Resolution: completed

**What to build:** 用户选定生成模型后能查看原生声音输出声明与当前接入状态，并在采用现有声音设计时收到相应提示。

- [x] 通过模型端能力声明和当前接入信息，准确表达可用、明确不支持、声明支持但未接入、未知。切换生成模型时提示随之更新。
- [x] 用现有对白或声音安排验证采用声音设计后的提示。缺少可靠声明时保留未知，返回音轨也不构成声音设计已落实的证据。
- [x] 声音设计不匹配作为提示展示。非法实际输入仍由默认技术预检处理，旧模型和旧画布缺少新增声明时仍可按原流程使用。

来源为[实施规格](../spec.md)与[原型记录](../prototype.md)。
