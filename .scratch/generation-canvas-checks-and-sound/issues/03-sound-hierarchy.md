# 03: 声音安排卡编辑并采用声音层次

Status: ready-for-agent
Blocked by: None
Resolution: completed

**What to build:** 用户能在声音安排卡中填写「声音层次／主次关系」，例如「对白优先，雨声退后」，并在生成卡采用该安排时核对实际请求。

- [x] 可选字段完成填写、保存、重开与清空。旧卡兼容，未填写时没有额外主次要求。
- [x] 采用声音安排后，实际编译内容保留对白和雨声的主次关系以及既有适用条件。声源、环境声、动作声与音乐约束各自保留。
- [x] 声音出现时机沿用现有适用条件，具体起止与变化可以在相应声音字段表达。退役的整卡 production 字段继续按现有契约处理。

来源为[实施规格](../spec.md)与[原型记录](../prototype.md)。
