# 23: 用原媒体复核画面和过程

Status: ready-for-agent
Blocked by: 20, 22
Resolution: completed

**What to build:** 用户可复核参考素材、静态画面或连续视频报告，让补充的证据位置与原媒体重新对照。

- [x] 分别用生成前参考、生成后静态画面及连续视频报告验收。实际重读原媒体，并在新报告记录此次观察的模态、时间点或区间。
- [x] 新报告引用实际观察而非复述说明。无法读取原媒体、读取能力缺失或过程证据不足时准确表达原因。
- [x] 替换当前素材或产物后，复核仍指向原身份，不会以当前版本补齐缺失的历史证据。原报告及结论边界可查。

来源为[实施规格](../spec.md)与[原型记录](../prototype.md)。
