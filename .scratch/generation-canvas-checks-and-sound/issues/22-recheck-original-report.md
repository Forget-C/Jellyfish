# 22: 基于原报告补充说明并复核

Status: ready-for-agent
Blocked by: 17
Resolution: completed

**What to build:** 用户可在原报告上为一项结论补充线索，针对原要求和原依据重新核对，并收到关联的新报告。

- [x] 规则、生成前文字和文本产物报告均可逐项复核。实际复核读取原目标、原要求、原依据及原结论；保留原报告及关联。
- [x] 补充说明作为本次待核实线索，证据仍来自实际依据。规则条件不受说明绕过，说明不进入后续普通或自动检查。
- [x] 原依据不可读取时明确提示无法复核。普通重查仍针对当前输入或当次选定产物，和原报告复核使用各自目标。

来源为[实施规格](../spec.md)与[原型记录](../prototype.md)。
