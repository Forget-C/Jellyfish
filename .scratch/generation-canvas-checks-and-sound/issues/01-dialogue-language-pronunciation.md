# 01: 对白卡补充语言与发音要求

Status: ready-for-agent
Blocked by: None
Resolution: completed

**What to build:** 用户能在对白卡中填写「语言／发音要求」，并在生成卡采用该对白后核对本次请求如何表达语言和发音。

- [x] 用「普通话，清楚读出人名」完成填写、保存、重开和再次编辑。旧对白卡可继续打开，缺省或清空此字段时不新增要求。
- [x] 采用对白后，实际编译文本保留语言／发音要求及其适用条件，并能定位到对白来源。未采用的对白不进入请求。
- [x] 说话对象与对白正文沿用现有行为，语气、气息、情绪和节奏继续由人物表演卡表达。

来源为[实施规格](../spec.md)与[原型记录](../prototype.md)。
