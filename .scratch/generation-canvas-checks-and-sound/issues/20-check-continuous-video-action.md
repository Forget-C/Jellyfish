# 20: 核对视频中的行动和表演

Status: ready-for-agent
Blocked by: 19
Resolution: completed

**What to build:** 用户可对选定的视频产物执行 R04，观察动作、反应和镜内活动是否在原要求对应的区间落实。

- [x] 使用具备连续视频观察能力的实际接入和小规模真实样例，记录模型读取方式、观察区间与证据。
- [x] 报告关联原要求及实际可观察动作过程，区分动作偏差、艺术表现建议和无法判断。结束状态可单独引用所观察画面。
- [x] 只有静态帧、视频描述或连续读取能力未验证时，明确标为无法判断或当前不可执行。实际声音和声画同步仍标为未核验。

来源为[实施规格](../spec.md)与[原型记录](../prototype.md)。
