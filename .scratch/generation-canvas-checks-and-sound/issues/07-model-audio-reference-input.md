# 07: 生成卡显示音频参考输入的可用状态

Status: ready-for-agent
Blocked by: 05
Resolution: completed

**What to build:** 用户能查看所选模型是否能接收音频参考，并据当前接入情况理解能否把素材用于生成。

- [x] 覆盖可用、明确不支持、未接入与未知。仅当现有适配器实际接收音频参考时，生成卡才开放对应入口。
- [x] 模型切换后按目标模型刷新提示。本地可试听的素材保留原用途，不能据此判定模型可接收它。
- [x] 非法实际素材输入由默认技术预检处理。验收分别核对能力提示和实际输入合法性。

来源为[实施规格](../spec.md)与[原型记录](../prototype.md)。
