# 12: 取消检查并保留原报告归属

Status: ready-for-agent
Blocked by: 11
Resolution: completed

**What to build:** 用户能独立停止检查，并在断开、换目标或删除检查卡之后查看原目标已完成的报告。

- [x] 取消可阻止待执行检查。对已开始的检查请求取消，界面区分取消请求与真实终态，覆盖供应商暂未停止的情况。
- [x] 断开、换目标或删除检查卡时停止相关检查，不波及生成任务。已完成报告可按原目标与原依据查看，未完成任务不会被改绑。
- [x] 编辑项目或切换开关时，已经固定配置的执行继续按原范围运行。用户可使用明确的取消动作。

来源为[实施规格](../spec.md)与[原型记录](../prototype.md)。
