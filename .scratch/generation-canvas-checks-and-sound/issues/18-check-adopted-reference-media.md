# 18: 核对实际采用的参考素材

Status: ready-for-agent
Blocked by: 11
Resolution: completed

**What to build:** 用户可通过 P03 核对本次已采用的参考素材是否与明确对象及素材用途相符，并知道哪些内容实际被观察。

- [x] 按显式关联定位对象、实际参考和素材用途。结构校验读取映射，视觉判断只传入本项需要的实际媒体。
- [x] 用真实素材验收可见对象和用途。文件名、不同视角或未声明身份不作为错误证据；不可见特征显示无法判断。
- [x] 媒体无法读取或模型不具备相应能力时保留适用项，说明未观察的范围，其余可执行项目继续。报告和样例记录实际观察模态。

来源为[实施规格](../spec.md)与[原型记录](../prototype.md)。
