# 24: 自动检查完整交付的结果集

Status: ready-for-agent
Blocked by: 12, 19
Resolution: completed

**What to build:** 用户开启生成后自动检查后，可在提交前看到本次计划，并在完整交付后获得每个产物的独立检查报告。

- [x] 开关默认关闭，开启不追溯历史。提交前显示产物数量、检查方式和预计调用，有可靠计价依据才展示费用。提交时固定开关、所选项目和检查模型。
- [x] 提交后改开关、项目或模型只影响之后提交的自动检查，普通手动检查使用当次选择。独立取消和目标关系变动沿用检查任务取消规则。
- [x] 用完整多产物交付验收逐产物执行及报告关联，覆盖未展示在当前预览中的产物。重复完成通知只触发一次，任一产物检查失败后其余结果仍可查。
- [x] 运行失败、取消或未完整交付不触发自动检查，合法保留产物仍可手查。自动检查结果与生成成功状态、采用和重拍操作分开。
- [x] 可共用相同媒体的观察调用，逐产物、逐项保留实际证据和结论。以已有静态画面检查走通浏览器与公开任务链路。

来源为[实施规格](../spec.md)与[原型记录](../prototype.md)。
