# 06: 生成卡显示声音开关的可用状态

Status: ready-for-agent
Blocked by: 05
Resolution: completed

**What to build:** 用户能单独查看所选模型是否支持控制声音开关，并在已有真实执行途径时使用对应配置。

- [x] 用支持原生声音输出但不支持开关的例子，验证两项能力分别显示。切换模型时按各自声明和接入情况更新。
- [x] 覆盖可用、明确不支持、未接入与未知。有现成执行途径时，控件反映实际参数；其他情况只显示状态与原因。
- [x] 设计文字中的后期制作意图不会隐式改写声音开关。非法实际参数继续走默认技术预检。

来源为[实施规格](../spec.md)与[原型记录](../prototype.md)。
