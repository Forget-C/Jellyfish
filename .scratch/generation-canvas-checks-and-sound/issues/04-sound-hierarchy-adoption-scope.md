# 04: 按生成目标核对声音层次的适用范围

Status: ready-for-agent
Blocked by: 03
Resolution: completed

**What to build:** 用户可以让多个生成目标复用同一张声音安排卡，并从各自的实际请求中核对该声音层次何时适用。

- [x] 构造同一声音安排与多个生成目标的场景，分别验收已采用且条件匹配、已采用但条件不匹配、未采用。
- [x] 匹配的目标保留适用的主次要求。条件不匹配时沿用既有适用条件语义，不能将层次作为本次无条件要求。未采用的目标请求不含该层次。
- [x] 保存重开后，各目标的采用关系、条件和实际编译结果仍对应。若 03 已满足行为，以可复现验收收尾。

来源为[实施规格](../spec.md)与[原型记录](../prototype.md)。
