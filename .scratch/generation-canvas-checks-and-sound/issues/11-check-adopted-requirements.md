# 11: 用独立模型核对已采用要求

Status: ready-for-agent
Blocked by: 09
Resolution: completed

**What to build:** 用户在检查卡单独选择检查模型，执行 P01 后看到实际采用要求是否传入本次请求，以及判断所依据的来源和片段。

- [x] 检查模型选择可保存。未选择或缺所需能力时说明原因，规则项仍可执行。模型只收到本项必要的已采用内容。
- [x] 对照采用要求和实际文本、素材用途核对关键含义，区分否定、条件、提议与阶段。报告引用来源字段和提交片段，不以逐字相同为标准。
- [x] 任务执行状态与业务结论分开。超时、服务不可用和无法解析作为执行失败；证据不足显示无法判断，部分成功结果保留。
- [x] 用户可只重试失败项或明确发起新一轮检查。轮询不触发新调用，模型选择不静默更换，也不自动完整重跑。
- [x] 通过真实公开任务链路和可控模型替身核对请求、结果、失败分支和调用次数，并用小规模真实文字样例验收语义观察。

来源为[实施规格](../spec.md)与[原型记录](../prototype.md)。
