# 17: 手动检查固定的文本产物

Status: ready-for-agent
Blocked by: 11
Resolution: completed

**What to build:** 用户选定一份已交付文本产物后，可按它实际生成时的依据执行 R01，并查阅针对该产物的报告。

- [x] 报告固定具体运行、产物身份及原生成依据。更换当前输出、修改设计或切换历史位置后，仍可读到原报告和原产物的关联。
- [x] R01 对照实际产物文本与原依据的明确内容或事实要求，提供来源和输出片段。文字产物只列出可执行的文字检查，主观叙事效果作为建议。
- [x] 明确选择产物后才可手动执行；报告区分依据缺失、无法判断和执行失败。非法或跨项目产物访问被拒绝。
- [x] 开始前可看到目标数量、检查方式和预计调用情况。结论和生成状态分别显示；本票也覆盖合法保留的未完整交付产物可手查。

来源为[实施规格](../spec.md)与[原型记录](../prototype.md)。
