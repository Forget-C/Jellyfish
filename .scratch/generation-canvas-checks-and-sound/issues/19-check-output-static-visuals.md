# 19: 核对产物外观和静态画面

Status: ready-for-agent
Blocked by: 17, 18
Resolution: completed

**What to build:** 用户可选定一张图片或一份视频产物，针对固定的原生成依据检查可见内容、对象外观、静态摄影和风格。

- [x] 完成 R01 的视觉分支、R02 和 R03。报告分别引用原要求及真实图片或视频画面，对象身份、外观和可见结果可定位。
- [x] 用真实图片和有实际时间位置的视频帧分别验收。不可见部分、未限定外观差异及抽帧未覆盖区间按证据边界表达。
- [x] 静态帧只支持所观察时刻的判断，不用于推断物理焦距或全程表现。适用项缺读取能力时显示无法判断。
- [x] 执行前提示产物数量、检查方式与预计调用。同一媒体和观察范围可共用分析，仍保留每项证据和结论。

来源为[实施规格](../spec.md)与[原型记录](../prototype.md)。
