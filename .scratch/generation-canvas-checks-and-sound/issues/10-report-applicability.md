# 10: 区分当前结论和历史报告

Status: ready-for-agent
Blocked by: 08
Resolution: completed

**What to build:** 用户修改本次生成输入后，能区分仍适用的结论、需要重查的结论和固定的历史记录。

- [x] 相关来源、采用关系、有效参数或能力变化时，仅受影响的结论不再代表当前输入。以多个不同来源的检查结果验证失效范围。
- [x] 移动卡片及单独刷新技术预检凭证不使业务结论失效。检查配置与历史报告有差异时，界面能说明当前选项和报告实际执行范围。
- [x] 旧报告的目标、依据、配置和结果保持可追溯。按当前输入重查产生新报告；旧结论不影响生成许可。

来源为[实施规格](../spec.md)与[原型记录](../prototype.md)。
