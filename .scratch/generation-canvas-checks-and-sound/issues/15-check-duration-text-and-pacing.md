# 15: 核对文字时长和节奏风险

Status: ready-for-agent
Blocked by: 11
Resolution: completed

**What to build:** 用户能看到自由文字中的时长要求是否适用于本次生成，以及动作、运镜和对白是否有节奏拥挤风险。

- [x] 补齐 P06 自由文字判断，给出来源和范围。区分预计、最低、固定、分段及本次目标无法对应的时长要求，和既有明确数值规则共用一致的结论口径。
- [x] P07 基于实际采用动作、停顿、运镜与对白，以及明确的生成秒数给出风险理由。覆盖并行动作不能简单累加的例子。
- [x] 经验语速和艺术节奏判断作为风险建议，证据不足时说明边界。P07 的证据为请求与设计文字，实际发音、语速和口型未核验。
