# 02: 对白卡补充声画关系说明

Status: ready-for-agent
Blocked by: None
Resolution: completed

**What to build:** 用户能在对白卡中说明说话与画面的关系，例如「画外说话，画面保持在听者身上」，并核对被采用后的实际提交文本。

- [x] 声画关系为可选字段，填写后保存并重开仍可见、可编辑。旧卡缺省或用户清空时不产生要求。
- [x] 采用对白后，声画说明随来源及适用条件进入实际请求。换成另一张对白卡时，本次请求不携带原卡说明。
- [x] 画内、画外或听者镜头等文字按设计表达。表演节奏由人物表演卡维护，声音执行由生成卡承担。

来源为[实施规格](../spec.md)与[原型记录](../prototype.md)。
