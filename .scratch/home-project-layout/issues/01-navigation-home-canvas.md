# 01: 顶部导航与首页生成画布入口

**What to build:** 创作者通过顶部首页、项目、管理、实验室进入对应领域，点击 Logo 返回综合首页，并在首页识别最近生成画布。完成可独立访问的首页首个模块和普通页面导航，提供后续页面共用的默认视觉约定。

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent
**Completion:** integrated

- [x] 普通页面顶栏保留左侧 Logo、右侧任务和用户，中间为四个一级菜单；移除旧一级图标栏，个人设置仍可由用户菜单进入。顶部“项目”始终进入项目列表。
- [x] 根地址进入首页。项目、管理、实验室入口可访问现有业务页面；本票据阶段管理默认进入模型管理，二级导航及恢复上次页面由 06 完成，实验室内部整合由 07 完成。
- [x] 首页与项目列表没有空置的固定左栏；必要的面包屑移到内容标题上方。既有业务地址、项目定位参数和实验室兼容跳转继续可用，菜单选中态随实际页面变化。
- [x] 首页上方展示生成画布名称、所属项目和封面，按最终 A 的顺序和首张卡片略宽的方式排布。跨项目最近更新首版使用明确标记的示例数据；有真实封面及对象时复用，示例不进入虚构对象或触发业务操作。
- [x] 普通页面默认雾蓝微渐变为 #F0F5FC → #F7F8FB，内容表面为白色，强调色 #245FC5、选中底色 #E4EDFB、正文 #263244、辅助文字 #536174。渐变仅用于页面背景，控件和内容表面使用纯色。
- [x] 使用留白、对齐、轻底色区分区域，取消结构性分割线和普通展示卡描边；保留表单、错误、选中、键盘焦点的可辨识边界。桌面约 56px 顶栏、20px 外边距、20px 页面标题、16px 区块标题，避免重复引导文案和大字标题。
- [x] 手机顶栏分两行，分别容纳 Logo／任务／用户与四个一级文字入口，内容边距约 16px。桌面 A 的精修从 1024px 起应用，不覆盖已确认的窄屏方案。
- [x] 生成画布、场次画布保持现有独立布局、导航、任务入口、主题、浮层和响应式行为；任务运行时在普通页面导航及进入画布时保持既有连续性。
- [x] 复用现有应用壳、路由和键盘验收，在正式页面验证点击、刷新、前进后退、两类画布入口及任务连续性；检查宽屏、桌面断点和手机的焦点、溢出及遮挡，运行受影响的前端检查和类型检查。

范围：只调整前端布局、导航与样式，复用 React、Ant Design 和既有业务行为，不新增接口、表结构或跨项目画布汇总能力。真实读取失败不得由示例掩盖。不迁移原型专用路由、方案切换条或内存模拟操作到正式产品。后续首页项目进展和会话由 08 补齐。
