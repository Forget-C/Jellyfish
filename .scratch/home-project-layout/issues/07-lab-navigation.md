# 07: 实验室类型与会话导航整合

**What to build:** 实验室用户在同一左栏选择文本、图片、视频类型，访问当前类型的历史会话或开始新会话，输入区始终保持可用。

**Blocked by:** 01 — 顶部导航与首页生成画布入口。

**Status:** ready-for-agent
**Completion:** integrated

- [x] 同一左栏容纳文本、图片、视频三个类型入口、当前类型会话列表及新建入口，不叠加第二条常驻侧栏；原型的占位顶栏不作为正式交互。
- [x] 类型入口进入既有模式输入界面，历史入口使用真实原会话地址；类型、当前会话和菜单选中状态保持一致。
- [x] 保留首次有效提交后才创建会话的现有行为；点击类型或新建入口不提前创建持久会话，不新增按类型恢复上次会话机制。
- [x] 会话长列表独立滚动，输入区保持可见。空态与真实请求失败明确呈现，不以示例掩盖失败；若有新增但缺乏数据能力的展示，明确标记示例且不可触发虚构操作。
- [x] 应用普通页面的留白、紧凑标题与轻底色选中态；中等宽度及手机按需打开二级导航，保留键盘可达性、清晰焦点和关闭后的焦点恢复。
- [x] 既有实验室模式、会话地址及旧路由兼容跳转继续可用；刷新、前进后退能恢复 URL 表达的上下文，现有会话操作和任务行为保持。
- [x] 复用实验室路由兼容与会话验收，在正式页面验证三种类型、历史恢复、新建到首次提交、长列表滚动和输入区；检查宽窄屏与键盘操作，运行受影响的前端检查和类型检查。

范围：只整合导航与布局，不改变模型运行契约、接口和表结构，不新增草稿隔离与持久化、离开保护或失效链接恢复改造。本票据不依赖首页会话模块或管理领域改版。
