# 02: 外观选择与本地偏好保存

**What to build:** 用户在用户菜单或个人设置中选择雾蓝微渐变、雾蓝纯色，两处同步且立即生效，刷新或重开同一浏览器后恢复偏好，同时保持两个独立画布的原有主题。

**Blocked by:** 01 — 顶部导航与首页生成画布入口。

**Status:** ready-for-agent
**Completion:** integrated

- [x] 用户菜单提供“外观”入口，展示两种主题的预览、名称和当前选中标记，键盘可完成打开、选择和关闭，关闭后焦点返回合理位置。
- [x] 个人设置使用相同外观偏好替换失效的“深色模式”开关；两个入口显示一致，选择立即应用，不依赖个人资料保存。
- [x] 默认雾蓝微渐变为 #F0F5FC → #F7F8FB，雾蓝纯色背景为 #F7F8FB。两者共用白色内容表面、#245FC5 强调色、#E4EDFB 选中底色、#263244 正文、#536174 辅助文字；渐变不进入表单、卡片、列表、按钮和弹窗。
- [x] 偏好保存到当前浏览器，刷新及重开后恢复；没有有效记录时使用默认微渐变。存储不可用时仍可在当前页面切换，不中断其他功能。
- [x] 外观仅作用于普通页面。切换后进入生成画布、场次画布并打开其浮层，确认独立主题及交互保持原样。
- [x] 使用真实页面的用户操作验证两处同步、刷新恢复、无效记录回退与存储不可用；覆盖宽屏和窄屏的可达性、焦点和可读性，运行受影响的前端检查和类型检查。

范围：浏览器本地偏好，不新增接口或表结构，不提供深色模式、跟随系统、跨设备同步、更多配色或动画渐变。不以组件内部状态或原型演示代替正式页面验收。
