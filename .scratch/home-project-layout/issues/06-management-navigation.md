# 06: 管理领域的统一二级导航

**What to build:** 用户在管理领域通过一条左栏切换管理对象，在内容区完成类别切换和筛选，并在再次进入管理时继续上次的二级页面。

**Blocked by:** 01 — 顶部导航与首页生成画布入口。

**Status:** ready-for-agent
**Completion:** integrated

- [x] 管理左栏依次提供模型管理、资产库、提示词模板、文件管理、Agent 管理；各入口访问真实现有页面，正式交互以规格为准，不沿用原型中禁用的占位菜单。
- [x] 首次点击顶部“管理”进入模型管理，后续恢复上次访问的管理二级页；不会因此自动打开具体记录编辑页。直接访问既有详情地址仍正确打开该对象。
- [x] 供应商、模型、运行设置及资产类别在内容区切换；分类和类型筛选放在工具栏或筛选面板，避免与领域导航并排出现重复常驻侧栏。
- [x] 管理页面采用普通页面的紧凑标题、留白、纯色内容表面与轻底色选中态；表单、错误和键盘焦点仍可辨识，现有管理操作与反馈不变。
- [x] 菜单选中态与真实地址、详情归属一致；刷新、前进后退和跨领域返回均保留正确上下文。中等宽度与手机使用可关闭的二级导航抽屉。
- [x] 在正式页面覆盖五个管理入口、恢复上次二级页、既有详情地址、内容区分类及筛选；复用受影响管理页面的已有操作验收，检查键盘、焦点恢复和宽窄屏溢出，运行受影响的前端检查和类型检查。

范围：仅前端导航、布局及必要的本地页面偏好，不新增后端偏好接口或表结构，不改管理对象的业务契约。缺少新增展示数据时标注示例，真实读取失败保留反馈。本票据不依赖项目改版、实验室改版或外观选择。
