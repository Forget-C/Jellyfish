# 08: 首页项目进展与最近实验室会话

**What to build:** 回到首页的创作者能在生成画布下方查看项目进展和最近实验室会话，辨认当前章节或对话，并通过真实入口继续工作。

**Blocked by:** 01 — 顶部导航与首页生成画布入口。

**Status:** ready-for-agent
**Completion:** integrated

- [x] 在首页生成画布模块下方补齐项目进展和最近实验室会话，桌面左右约为 2:1，窄屏按项目进展、会话顺序纵向排列，保留最终 A 的整体模块次序。
- [x] 项目进展突出项目名、具体章节、当前状态与下一步动作，动作紧贴对象；有合适真实预览时使用小缩略图，百分比和资产计数不抢占主要层级。
- [x] 最近实验室会话使用轻量列表，展示类型、名称、摘要和更新时间；复用现有会话列表字段，真实会话通过既有地址打开。
- [x] 真实项目和章节动作使用现有规则及目标地址，准确进入对应对象；无需等待项目列表、概览或实验室内部改版完成。
- [x] 优先复用既有数据，缺少可靠字段或汇总的项目制作进展明确标为“示例数据”，与真实内容分区；示例不能触发业务操作或虚构跳转，不把现有聚合字段解释为制作完成率。
- [x] 加载、真实空态、读取失败与示例可区分；真实读取失败保留反馈，不替换成示例来表现成功。
- [x] 使用约 20px 页面标题、16px 区块标题、桌面 20px 外边距及轻底色状态，避免重复说明、同质化大容器和大字标题；两区不因长名称或窄屏而溢出。
- [x] 在正式首页验证模块次序、真实项目／章节／会话落点、示例不可操作、空态及失败反馈；检查宽屏、桌面断点、手机和键盘操作，运行受影响的前端检查和类型检查。

范围：只完成首页组合与既有数据展示，不新增跨项目汇总接口、表结构、进度计算、实验室草稿能力或首页模块自定义。不将原型内存数据操作迁入产品；不依赖 02、03、05、07。
