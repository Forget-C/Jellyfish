# 04: 项目内二级菜单与上下文导航

**What to build:** 用户进入具体项目后，通过清晰标注项目身份的分组左侧菜单访问创作、项目资源和项目管理内容，并能返回项目列表切换项目。

**Blocked by:** 01 — 顶部导航与首页生成画布入口。

**Status:** ready-for-agent
**Completion:** integrated

- [x] 项目内横向导航页签替换为左侧二级菜单；顶部显示当前项目名称和“返回项目列表”，项目切换经项目列表完成，不添加第二条常驻导航栏。
- [x] 分组默认展开：“创作”依次为项目概览、画布生成、章节；“项目资源”依次为演员、角色、场景、道具、服装；“项目管理”为文件、项目设置。
- [x] 菜单访问既有内容与操作，保留项目页签定位参数和旧入口兼容；资源详情等深层页面保持正确项目上下文、选中项和必要的内容区面包屑。
- [x] 画布生成使用现有入口进入独立生成画布；场次画布保持独立工作区，不套入项目左栏，不改变其主题或浮层。
- [x] 桌面左栏约 216px、菜单行约 40px，使用留白分组与轻底色选中态。中等宽度和手机按需打开二级导航抽屉，关闭后不遮挡内容，切换页面后可正常继续操作。
- [x] 首页及项目列表仍没有固定左栏；切换项目后项目名、内容和选中项同步，不残留上个项目的上下文。
- [x] 在正式路由逐一验证各组菜单、项目切换、深层链接、刷新、前进后退以及生成画布和场次画布入口；覆盖键盘、抽屉关闭与焦点恢复、宽屏及窄屏，运行受影响的前端检查和类型检查。

范围：调整项目导航容器与入口，不改造资源、文件、设置或画布的业务逻辑，不新增接口和表结构。概览与章节内容布局由 05 完成；本票据以既有内容验证菜单可用。
