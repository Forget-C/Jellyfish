# 05: 统一固定来源与业务记录阅读

Status: ready-for-agent
Blocked by: 01 — 导演设计卡接入悬浮详情

**What to build:** 创作者在悬浮详情内阅读指定来源版本、生成指令的冻结依据和场次业务任务固定记录，始终看到记录发生时的内容。相关只读内容能够由后续操作 modal 复用，而不复制一套阅读器或完整编辑器。

规格依据：《场次四画布公共组件与统一交互》的固定来源、生成记录、只读模块及普通阅读迁移约定。

## Acceptance criteria

- [x] Sources、SceneSourceRevision 对应的“来源版本 · 只读”普通入口迁入悬浮详情；指定项目、场次和来源版本的解析及权限行为保持原状。
- [x] PromptReader 的“生成指令的冻结依据”普通来源阅读链路在同一详情内完成，不再打开另一个 Drawer；长内容可展开，必要时局部返回。
- [x] 场次业务“任务固定记录 · 只读”入口迁入详情，保留已有链接参数、上下文解析、聚焦记录和业务回跳。这些记录与通用任务中心明确分开。
- [x] 当前场次内容、章节原文或指令后续发生修改时，已选来源和固定生成依据仍显示原数据；只读内容不能变成对当前对象的隐式编辑。
- [x] 将真实重复的只读内容与容器分离，允许在详情或操作内辅助阅读时复用；保持接口简单，不把所有调用入口强制绑定到详情或增加完整对象编辑开关。
- [x] 本票迁移普通阅读入口；独立操作 modal 内的接入由 06 完成。未迁入的操作阅读路径仍可用，不因新详情位于不可交互的底层而出现无法阅读或无法返回的过渡状态。
- [x] 浏览、展开和返回不触发保存、生成或采用，不改变视口；加载、错误和后台刷新保留已有可读内容、滚动及展开状态，使用稳定反馈区域。
- [x] 不同普通入口指向同一固定记录时复用规范阅读内容；焦点、Escape、标题、只读身份和近全屏窄屏行为遵循 01。
- [x] 在真实工作台使用固定来源和“当前内容后来变化”的夹具验证数据真实性，覆盖来源→冻结依据→返回、业务记录链接进入、加载错误与刷新；检查 1440px／390px 和键盘关闭，前端 typecheck 及相关版本／导航回归通过。
- [x] 同步只读详情与可复用阅读内容的职责说明，移除本票已迁普通入口的旧容器调用；不清理仍被其他流程使用的阅读器或旧页面。

## Scope boundaries

不改变来源数据契约、版本解析或跨画布业务导航，不新增数据恢复与保存阶段。操作内只读辅助阅读规则由 06 落地，AI 设计自身的状态／历史展示拆分由 07 落地，导出记录由 10 落地。

工作台任务中心及其任务历史完全排除在迁移范围外；不修改后端接口或全站主题。
