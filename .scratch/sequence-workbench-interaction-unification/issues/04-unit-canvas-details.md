# 04: 统一单元画布摘要与详情编辑

Status: ready-for-agent
Blocked by: 02 — 统一导演三类卡片与画布基础交互

**What to build:** 创作者在单元画布通过一致的卡片行为查看单元，使用悬浮详情调整模型参数与前段依赖，并按现有明确确认流程选择参考。卡片保持简洁，单元配置、保存和参考绑定行为仍与改造前一致。

规格依据：《场次四画布公共组件与统一交互》的三类卡片、单元详情迁移及参考选择边界。01 的详情能力通过 02 的依赖已具备。

## Acceptance criteria

- [x] 单元画布复用公共画布、适用的卡片和工作台布局区域；单元身份、当前位置、主要操作与保存状态可辨，不强制复制导演布局或新增无用途工具栏。
- [x] SceneUnitCanvas 的模型参数与前段依赖编辑迁入同一详情容器，使用已有单元身份和选择规则。普通对象主点击、卡内动作、菜单和拖动符合公共约定。
- [x] 参数和依赖沿用直接 patch 及现有校验；“完成编辑”原本只是关闭的行为不变成一次提交，不新增通用确认／取消。
- [x] 普通参考信息查看使用只读详情；ReferencePicker 的选择、确认及取消继续使用独立操作，取消不修改已有绑定，不承诺撤销已发生的文件上传副作用。其容器与辅助阅读归一由 06 负责。
- [x] 生产单元与镜头身份、前段固定依据、实际落幅和参考语义保持原状；不把旧依据替换成当前最新内容，不改变生产准备或依赖检查结果。
- [x] 摘要使用有限尺寸和最多两行字段，无卡内全文滚动；完整配置可在详情阅读。普通状态、只读、错误及缺失信息清楚可辨。
- [x] 自动／手动保存、切换单元、关闭重开、详情展开均保持现有输入与保护；纯浏览不保存，面板操作不自动平移、缩放或重排画布。
- [x] 键盘和触摸能够进入详情、调整参数、查看参考及关闭；1440px／390px 下标题、保存状态和操作可达，端内菜单先处理 Escape。
- [x] 在真实工作台验证参数与依赖修改、只读限制、保存模式、单元切换与参考选择确认／取消；复用四画布样式及场次版本回归，前端 typecheck 通过。
- [x] 同步单元画布适用的组件、详情边界和验收说明，仅删除本票迁移产生的旧调用及无效导入。

## Scope boundaries

不改变生成能力、模型参数含义、参考选择规则或跨画布对象携带。批量拍摄由 08 处理；本票不为现有内联操作增加 modal。

沿用局部工作台主题，不修改任务中心、后端或对外接口，不引入草稿或额外场次版本状态。
