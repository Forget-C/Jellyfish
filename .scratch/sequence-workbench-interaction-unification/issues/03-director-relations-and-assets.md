# 03: 归并导演关系、附加信息与资产关联

Status: ready-for-agent
Blocked by: 01 — 导演设计卡接入悬浮详情

**What to build:** 创作者在同一个悬浮详情区域查看导演附加信息、对象关系与全场关系，并完成本场人物、物件、场所的项目资产关联。查看关系不再叠出第二个大型窗口，返回原对象后可以继续编辑。

规格依据：《场次四画布公共组件与统一交互》的单详情容器约定，以及资产关联、附加信息、对象关系和全场关系总览迁移条目。

## Acceptance criteria

- [x] 导演入口使用的 SceneAssetLinks 迁入详情；选择、解除和添加沿用原有直接变更语义，不变成暂存后统一提交。
- [x] 导演定位、缺陷、关系来源等附加信息与对象详情共用同一位置，不保留另一个竞争的右侧详情区。
- [x] SceneRelationDetails 的依据、共享、场所、人物和引用等只读信息使用同一详情容器；不因可复用容器改变对象身份或业务关系含义。
- [x] SceneWorkbenchOverview 的全场关系总览使用展开详情；查看关系对象或附加信息时可在容器内局部返回，不叠加旧关系 modal。
- [x] 已迁移的同一对象从卡片、菜单、关系和问题入口打开时使用规范详情入口；需要编辑时复用完整编辑器，不在只读关系内创建第二份编辑表单。
- [x] 切换详情、关系和总览不丢失现有未保存输入，不改变画布视口或节点位置；用户明确点击源／目标定位仍执行原有导航。
- [x] 查看信息不触发业务保存；实际资产关联仍遵守当前场次版本的自动／手动保存和只读限制。不得把资产绑定等同于生成参考选择。
- [x] 长关系信息及窄屏使用 01 的尺寸、滚动和焦点规则；标题和返回、关闭入口可达，内层控件先处理 Escape。
- [x] 在真实工作台回归关联／解除、关系总览到对象的阅读与返回、问题入口编辑、主动定位，以及未保存输入保留；检查 1440px／390px 布局，前端 typecheck 与受影响浏览器回归通过。
- [x] 更新本票涉及的工作台说明与验收记录，清除本次迁移产生的旧容器调用和无效导入，保留无关旧页面实现。

## Scope boundaries

固定来源内容及其阅读器由 05 负责；本票复用现有来源入口，不改变来源解析。不得要求 02 的卡片重构完成才能接入 01 的详情能力。

不改变跨画布业务映射、不新增保存阶段、不修改后端接口；任务中心及其历史保持现状。
