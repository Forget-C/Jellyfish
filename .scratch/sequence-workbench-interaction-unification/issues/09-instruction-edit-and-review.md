# 09: 统一指令、编辑画布交互与审片回放

Status: ready-for-agent
Blocked by: 02 — 统一导演三类卡片与画布基础交互

**What to build:** 创作者在指令与编辑画布使用一致的摘要卡、详情入口和辅助控件，同时保有完整指令编辑、媒体播放和时间线工作空间。历史接缝与整场审片回放通过展开详情阅读，现有内联操作仍然直接可用。

规格依据：《场次四画布公共组件与统一交互》的工作区差异、公共卡片、历史回放迁移及保持内联清单。依赖 02 提供通用画布／卡片行为，其依赖链包含公共详情容器。

## Acceptance criteria

- [x] 指令与编辑画布接入适用的公共卡片、当前位置和辅助工具区域；身份、保存、切换与当前主操作归属一致，不为不适用功能增加空区域。
- [x] 普通摘要对象采用单击详情、标题拖动和独立菜单／按钮行为；引用保留只读身份与已有定位规则。有限摘要在详情可查看完整信息，不产生重复完整编辑入口。
- [x] 主指令编辑器、主播放器和时间线继续作为业务工作区，不压入紧凑摘要卡或全部收进详情；长指令、媒体信息与实际剪辑操作保持可用。
- [x] SceneReviewPreview 的历史接缝／整场审片回放使用展开只读详情，明确对应记录、媒体和区间，必要时可在同一详情局部返回。
- [x] 历史回放不被当前时间线或素材修改重解释；查看回放不修改审查结论、采用安排或当前编辑内容，保留已有媒体播放控制和区间语义。
- [x] 指令建议、指令检查、直接单次拍摄、素材审查、接缝审查和整场验收的现有内联主操作保持原形态，不因含 AI 或检查结果新增 modal。
- [x] 当前单元、素材选择和现有业务定位保持原规则；面板开合、展开或切换不改视口与布局、不触发业务保存，编辑则沿用当前自动／手动保存和输入保留。
- [x] 空内容、长指令、密集素材及长时间线在 1440px／390px 可用；公共颜色、控件状态、图标与焦点一致，必要主操作不被详情或媒体控件遮挡。
- [x] 从真实工作台验证指令编辑与保存、素材查看和时间线基本操作、历史接缝／整场回放以及详情关闭重开；以真实可观察行为验证输入、区间、视口与焦点，不以纯样式截图代替。
- [x] 前端 typecheck 与受影响四画布样式、场次版本、导航和审片回归通过；同步工作台指南中的主编辑区例外、回放容器与验收说明。

## Scope boundaries

时间线整理预览的独立确认容器由 06 负责，导出操作与记录由 10 负责；本票保持这些现有入口可用，不以它们为额外前置依赖。

不改变指令内容算法、模型调用、Take 实际覆盖、审查或采用规则；任务中心、后端接口、跨画布映射和新增保存概念不在范围内。
