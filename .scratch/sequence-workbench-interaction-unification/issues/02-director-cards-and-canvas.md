# 02: 统一导演三类卡片与画布基础交互

Status: ready-for-agent
Blocked by: 01 — 导演设计卡接入悬浮详情

**What to build:** 创作者在导演画布单击对象卡查看详情、单击子图入口进入范围、单击引用卡定位原对象；拖动、菜单和卡内按钮各自执行明确动作。通用视口与卡片机制可供其他画布复用，同时导演的分组、布局和业务关系仍保持原义。

规格依据：《场次四画布公共组件与统一交互》的公共组件、三种卡片及视口约定。依赖 01 提供对象卡主点击后的完整详情路径。

## Acceptance criteria

- [x] 在改变交互前先分离必要的通用画布机制与导演业务适配，再接入导演真实场景。通用 CanvasSurface 负责变换、测量、定位、适用的拖动和事件隔离；导演对象类型、分组、镜头适用范围、业务关系和默认布局留在业务适配。
- [x] 对象摘要卡单击选中并打开 01 的详情；子图入口单击进入对应范围；引用卡明确显示引用／只读及来源身份，点击沿用原有定位规则。
- [x] 子图入口保留适用的真实计数与布局预览；共享对象及引用不因抽取组件变成内容副本，结构引导线与可检查业务关系仍分别表达。
- [x] 按类型使用有限卡片尺寸，每个摘要字段最多两行，不使用内部滚动承载全文；摘要字段由业务提供，完整内容在详情可读，缺失、只读、未保存和业务状态不混为一类。
- [x] 可拖动卡片仅从明确的标题拖动区启动；拖动结束不误打开详情，菜单和卡内按钮不触发整卡动作。
- [x] 三类卡片无需双击即可完成主动作；键盘焦点可见、整卡动作可通过键盘触发，菜单在 hover／focus 时可见，触摸环境有持续可达入口。
- [x] 已有缩放、平移、适应画布、小地图、明确定位与布局持久化正常；浏览或调整展示布局不触发业务保存。用户手动位置不因抽取公共机制被重排。
- [x] 通用机制切换后四画布现有入口均可用，不强迫其他画布采用导演图布局；指令编辑器、播放器与时间线不套用紧凑卡片尺寸。其他画布卡片接入由 04、09 完成。
- [x] 在真实导演画布验证三种点击行为、事件隔离、输入方式、真实预览和视口稳定，覆盖密集节点、长摘要、空场次及 1440px／390px；复用导演布局、画布导航与四画布浏览器回归。几何或缓存算法变更时运行对应现有算法测试，前端 typecheck 通过。
- [x] 同步工作台设计指南中的卡片、拖动、公共画布职责与已落地的视觉规则；记录任何受限于真实内容的必要例外及验证方式。

## Scope boundaries

不建设通用节点编辑平台、可配置布局引擎或表单系统，不改变镜头、生产单元、共享关系或跨画布业务导航。必要预重构应保持各提交可验证，不残留本票不再使用的兼容层。

沿用工作台公共主题和基础控件；任务中心、其他页面主题、后端及接口契约均不改动。
