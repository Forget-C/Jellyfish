# 01: 导演设计卡接入悬浮详情

Status: ready-for-agent
Blocked by: None (can start immediately)

**What to build:** 创作者从导演设计卡打开唯一的悬浮详情，在同一位置阅读完整内容、编辑并沿用当前场次版本的保存方式。桌面可以继续操作画布，窄屏可以完整编辑；展开、切换和关闭不会改变画布视角或丢失既有编辑状态。这条真实路径同时交付后续迁移复用的工作台详情容器。

规格依据：《场次四画布公共组件与统一交互》的公共组件、布局、悬浮详情及生命周期约定。

## Acceptance criteria

- [x] 演进现有 WorkbenchChrome、局部主题和基础控件，明确顶部身份／版本／保存／画布切换／主操作、左上位置、右侧详情、底部辅助区域；不需要的区域省略，其他画布中央工作区保持可用。
- [x] SceneDesignPanel 的完整字段从独立 modal 迁入详情，卡片及本票涉及的同对象入口使用同一完整编辑器。先分离必要的业务内容与旧容器，再接入真实卡片，不创建仅供演示的空容器。
- [x] 桌面详情位于右上方并四周留边，无遮罩、不侧滑、不推挤画布；提供常规／展开两档，不支持自由拖动或任意缩放。
- [x] 新对象替换当前详情目标；重复点击当前对象和点击画布空白不关闭。打开、关闭、切换或展开不改变画布缩放、平移、节点位置，也不触发业务保存。
- [x] 展开使用同一内容会话，保留输入、有效焦点与滚动位置；关闭和重开、切换对象沿用现有输入保留策略。标题显示对象身份和适用的保存／只读状态。
- [x] 自动保存和手动保存分别正常工作；失败、只读和未保存状态保持可见。不新增“草稿”“应用到当前版本”或关闭即提交的普通字段编辑流程。
- [x] 新工作单的必填关联和“建立工作单”显式动作保留；不能因选择关联自动创建，也不新增通用确认／取消底栏。
- [x] 关闭按钮和 Escape 可用，内层菜单／选择器优先处理 Escape；关闭后恢复有效触发焦点，原入口消失时使用合理回退。
- [x] 窄屏使用近全屏但留边的同一详情内容，标题、状态与关闭入口可达，正文滚动；焦点限定在当前覆盖区域。桌面不锁定画布焦点。
- [x] 现有操作 modal 打开时，底层详情保持挂载与输入，详情和画布暂时不可交互；关闭后恢复有效入口。既有保存、所有权、离开和结果未知保护不被新面板绕过；全部确认操作及辅助阅读归一由 06 继续完成。
- [x] 使用既有灰阶、语义色、控件尺寸与间距；portal 继承工作台主题。loading、disabled、selected、hover 和 focus-visible 可区分，不污染全站浅色页面。
- [x] 在真实场次工作台浏览器入口覆盖以上编辑、保存、视口、焦点与 modal 覆盖行为，检查 1440px 和 390px 的长内容及关闭重开；公共状态复用现有 Workbench UI 示例，前端 typecheck 通过。共享布局改动覆盖四画布相关回归，影响不明时扩大测试范围。
- [x] 同步工作台设计指南中本票已落地的详情容器职责、导演设计卡编辑说明与验收方式；未迁移功能保持明确归属，不提前宣称整份规格已完成。

## Scope boundaries

公共容器只拥有展示、尺寸、关闭与焦点机制，业务内容和保存由原调用方负责。保留后续详情接入位置即可，不创建万能表单、插件注册系统或跨画布对象映射。资产／关系、固定来源和其他画布的迁移分别由后续票据承担。

任务中心及其历史不迁移；不修改后端或对外接口，不增加跨刷新输入恢复能力，不清理无关旧代码。
