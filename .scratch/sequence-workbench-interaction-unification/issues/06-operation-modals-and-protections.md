# 06: 统一确认操作、辅助阅读与阻塞保护

Status: ready-for-agent
Blocked by: 05 — 统一固定来源与业务记录阅读

**What to build:** 创作者在参考选择、原文依据更新和时间线整理等独立操作中完成明确确认，并可在当前 modal 内阅读相关材料再返回。底层详情输入保持不变；冲突、恢复、所有权及结果未知等必须先处理的情况继续可靠阻塞。

规格依据：《场次四画布公共组件与统一交互》的独立 modal 边界、Q19 只读辅助阅读例外及保留阻塞清单。依赖 05 的只读内容复用能力，以及其依赖链上的公共详情容器。

## Acceptance criteria

- [x] 参考选择、原文依据比较／更新、时间线整理预览继续作为独立操作，复用 WorkbenchModal 与公共动作区，保持既有确认、取消、校验和关闭条件，不因内容长或有 AI 就额外拆出 modal。
- [x] ReferencePicker 在确认前保持本地选择，取消不改变原绑定，确认按原有方式提交；已有上传副作用保持真实，不承诺取消会回滚已上传文件。
- [x] SceneSourceBasis 保留原文比较、选择及明确更新；仅阅读依据走详情或当前操作内的只读阅读。SceneTimelineEditor 保留预览、取消和确认前原内容未变校验。
- [x] 操作中查看来源、冻结依据、参考图等相关材料时，在当前 modal 内进入只读阅读并返回，复用 05 的内容或其他已有相同语义只读模块；选择、输入与操作状态不丢失。
- [x] 辅助阅读不打开第二个大型 modal，不激活底层详情，也不提供完整对象编辑副本；普通对象完整编辑仍归唯一详情容器。
- [x] modal 打开时底层详情与画布不可交互，已打开详情仍保持挂载和输入；关闭后恢复有效触发焦点。正文滚动不带走必要操作，窄屏控件不越界。
- [x] 嵌套控件先处理 Escape；关闭只影响当前允许关闭的最上层，不能穿透底层。必要的短危险确认可覆盖操作，但不得由此扩展为多大型 modal 堆叠。
- [x] 保存冲突、离开未保存内容、编辑权交接和未保存编辑数据恢复保留现有决定与保护；打开面板或更换容器不能绕过校验、丢弃输入或引入另一层版本概念。
- [x] 复制场次版本过程、提交结果未知和核实流程保留既有关闭限制与阻塞，不误当作可随意关闭的普通后台任务。不修改原请求凭据、权限或重复提交保护。
- [x] 在已有独立操作的真实入口验证只读辅助阅读与返回，不以仅有组件示例代替；AI、批量拍摄、导出的目的拆分分别由 07、08、10 完成，本票提供其可复用规则并保持原流程可用。
- [x] 浏览器回归覆盖参考确认／取消、依据更新、时间线原内容变化、只读阅读输入保留、底层隔离与焦点、冲突／恢复／所有权／未知结果保护；使用既有隔离夹具，检查 1440px／390px，前端 typecheck 与受影响回归通过。
- [x] 更新工作台设计指南的 modal 边界、辅助阅读例外、焦点与阻塞约定，明确普通字段编辑没有新增通用提交步骤。

## Scope boundaries

不改参考、原文、时间线、保存或版本业务算法；共享容器只统一展示与交互保护，业务关闭条件仍由调用方决定。不要复制业务流程或引入新的全局操作状态机。

任务中心及其历史不迁移；不修改后端、接口契约、全站主题或跨画布业务映射。导出成果的实际删除流程由 10 接入本票的短危险确认规则。
