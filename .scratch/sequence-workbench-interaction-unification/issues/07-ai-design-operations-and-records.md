# 07: 分离 AI 设计操作与记录阅读

Status: ready-for-agent
Blocked by: 06 — 统一确认操作、辅助阅读与阻塞保护

**What to build:** 创作者准备和提交 AI 设计、比较建议并作出已有确认时使用独立 modal；只想看任务状态、历史或诊断时使用悬浮详情。操作容器关闭后，支持后台运行的任务继续，重新进入可以接续既有工作。

规格依据：《场次四画布公共组件与统一交互》的 AI 设计复合功能拆分、任务生命周期及操作内只读阅读约定。

## Acceptance criteria

- [x] SceneDesignSuggestions 的准备、范围选择、提交、建议比较和已有明确确认保留 modal，原输入要求、可用条件、差异与确认校验保持原义。
- [x] 纯状态、历史与诊断阅读使用详情；普通阅读与明确操作入口可辨。同一完整操作不同时复制到 modal 和详情中。
- [x] 操作过程中需要的相关进度仍可显示在当前 modal；不能因为出现任务状态就强制中断当前操作或切换容器。
- [x] 关闭界面不取消已有支持后台运行的任务；重新打开读取既有任务与结果。当前会话的要求、范围和选择按原规则保留，不新增跨刷新持久化承诺。
- [x] 生成记录与建议所依据的固定来源继续明确；查看相关依据或参考在当前 modal 内只读进入并返回，复用 05、06 的内容和行为，不能激活底层编辑器。
- [x] 既有 AI 设计建议确认保持原义，不自动采用或跳过校验，也不把它扩展成普通字段编辑的“应用到当前版本”阶段。
- [x] 轮询保留已有正文、展开与滚动；错误反馈位置稳定，不清空用户输入。重复提交、结果核实、只读和权限限制继续生效。
- [x] 详情与操作 modal 的开关不会修改画布视角，modal 覆盖时底层不可交互；关闭和 Escape 遵循当前层与有效焦点恢复规则。
- [x] 在真实 AI 设计入口覆盖准备→提交→关闭→任务完成→重开→比较／确认，以及仅查看历史／诊断、辅助阅读返回和失败核实；使用已有夹具控制响应，不发起真实付费生成。
- [x] 1440px／390px 下长原文、要求、结果与操作区可读可达；前端 typecheck、受影响的场次版本、设计完整性及工作台浏览器回归通过，并同步该功能的容器边界说明。

## Scope boundaries

不修改 AI 设计生成策略、业务范围、建议数据、确认算法或后端契约。普通历史阅读复用既有只读内容，不重建另一套生成流程或隐藏可编辑副本。

保留当前场次版本的自动／手动保存语义；任务中心、跨画布业务导航、其他 AI 内联工具均不属于本票迁移范围。
