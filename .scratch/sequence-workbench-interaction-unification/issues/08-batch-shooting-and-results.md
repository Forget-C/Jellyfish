# 08: 分离批量拍摄提交与结果查看

Status: ready-for-agent
Blocked by: 06 — 统一确认操作、辅助阅读与阻塞保护

**What to build:** 创作者在独立 modal 中选择生产单元、预检并明确提交批量拍摄；提交后可以回到画布，通过非模态入口查看已有任务状态和结果，无需重新进入一套提交流程。

规格依据：《场次四画布公共组件与统一交互》的批量拍摄目的拆分、操作容器及任务生命周期约定。

## Acceptance criteria

- [x] SceneVideoBatch 的选择、预检、失败原因展示与明确提交保留操作 modal，实际提交范围和禁用条件保持原有规则。
- [x] 已提交任务的状态与结果使用详情或已有适合的非模态业务展示；查看已有批次不触发再次提交，不复制整套选择／预检操作到详情。
- [x] 同一操作中必要的进度仍可显示在 modal；用户可以按现有规则关闭界面，已提交任务生命周期不受容器可见性影响，重开仍能找到原任务。
- [x] 提交前选择及同一会话输入按原规则保留；后续轮询不重置选择、滚动或正在阅读的内容，错误在稳定区域展示。
- [x] 未知提交结果、固定请求凭据、核实及重复提交保护保持有效。核实原提交与按原规则发起新任务仍可区分，不引入新的自动重试或自动采用。
- [x] 固定记录使用已有身份和依据；相关只读辅助材料在当前操作 modal 内阅读并返回，复用 06 的规则，不叠加大型窗口或激活底层详情。
- [x] 任务状态与生产准备、素材审查和剪辑采用分别表达；生成成功只登记既有结果，不表示自动采用或实际覆盖。
- [x] 保留原有业务回跳和定位；单纯打开、关闭、切换状态阅读不改变画布视口，不触发保存或生成。
- [x] 在真实批量拍摄入口使用隔离夹具覆盖选择→预检→提交→关闭→状态更新→结果查看，以及预检失败、重复提交阻止和未知结果核实；不执行真实付费生成。
- [x] 验证 1440px／390px 的长列表、状态反馈、键盘和焦点恢复；前端 typecheck 及受影响工作台回归通过，同步批量操作与结果阅读边界的说明。

## Scope boundaries

不改变生产单元映射、批量选择规则、生成能力预检、模型调用、结果登记或跨画布导航。无需等待 04 的单元卡片迁移即可接入已有批量入口。

不改任务中心或其历史，不新增后端接口、保存阶段、跨刷新输入恢复或第二套任务状态管理。
