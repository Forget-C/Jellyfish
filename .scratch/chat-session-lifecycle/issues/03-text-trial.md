## What to build

文本试模通过已绑定的会话客户端直接运行用户选择的模型，保留逐轮输入、流式显示、历史回填和运行恢复。

## Acceptance criteria

- [x] 通过统一路径提交，在模型输出结束前取得 202；页面从 SSE 显示增量或完整正文。
- [x] 重新打开可恢复模型、部分正文和已知终态；断流且无法核实终态时保留部分正文并显示状态未知。
- [x] 相同请求身份与输入重传返回完整原回执与原游标，模型只执行一次；输入冲突返回 409。历史回填后主动发送开启新轮次。
- [x] 旧文本运行的已知终态仍能恢复。翻阅较早历史时继续接收新事件，分页位置不覆盖会话已处理游标。
