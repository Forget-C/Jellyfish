## What to build

画布助手复用实验室验证过的轮次管理，通过一条订阅接收原发送和续答输出，保留画布问题卡、审批及选区交互。

## Acceptance criteria

- [x] 未保存画布首次发送前自动保存。绑定后从统一快照恢复引用、提案版本、分组审批、冲突、执行结果、当前问题和进度。
- [x] 连续回答 Q1、Q2 后从旧回执回放；只为当前待答问题展示可操作卡片，已答问题不会闪现。
- [x] SSE 首帧或问题核实快照挂起时仍可按已受理的轮次停止；确认停止后立即能发送，迟到响应不会重新锁住输入。
- [x] 关闭面板只解除订阅，重新打开从快照及其游标恢复原轮次。用浏览器验证断线期间可编辑的正文和附件不会被旧轮次清除。
