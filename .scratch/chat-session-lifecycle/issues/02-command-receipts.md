# 02：固定原发送与每次问题卡续答的回执

Status: ready-for-agent

Completion: resolved

Integration commit: 9b5e7b45
Blocked by: None

## What to build

画布与实验室用户可安全重传原发送或某一次续答。从现有公开入口验证相同行为，迁移后的路由复用这套受理逻辑。

## Acceptance criteria

- [x] 在同一事务内关联命令身份、原始输入和已提交的受理事件。并发发送相同命令只登记一次，通过实际模型调用或任务提交次数验证。
- [x] 原发送按会话与请求 ID 找回；同一身份改变正文、附件或显式参数返回 409。先查原受理记录，再判断当前轮次是否忙碌。
- [x] 连续回答 Q1、Q2 后逐项重传原发送和两个答案；逐字段比较三份原回执，并从各自的原游标验证 SSE 起点。
- [x] 每个问题只接受一个答案；同答案在下一次追问期间、本轮中断、停止或结束后仍取回原回执，改答返回 409。历史画布缺少独立续答受理事件时沿用原有回放起点。
- [x] 在允许发送时主动发两次“继续”得到两个新轮次，各写一条消息；网络重传其中一次只返回对应回执。
