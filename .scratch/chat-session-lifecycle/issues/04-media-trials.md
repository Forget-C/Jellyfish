## What to build

两个试模页面共用媒体任务受理、事件与快照，用户可重开会话查看原任务及产物，并回填各自的生成参数。

## Acceptance criteria

- [x] 分别通过图片、视频页面提交，生成完成前取得 202；从 SSE 取得任务身份、进度、失败或归档产物。
- [x] 并发重传同一请求只产生一个任务，返回该命令完整原回执与原游标；同一身份改变输入返回 409。
- [x] 图片恢复参考图和生成参数；视频恢复首尾帧、主体参考、时长、分辨率。回填后主动生成建立新请求。
- [x] 历史翻页不移动实时游标；旧媒体受理事件从原游标重放时保持已提交的载荷，任务后来的进度不会改写原受理事实。
