# 05：实验室聊天由统一客户端管理活动轮次

Status: ready-for-agent

Completion: resolved

Integration commit: 6470b4aa
Blocked by: 01, 02

## What to build

用实验室聊天交付共享的轮次跟踪：客户端管理命令、回执、订阅、游标、停止目标和当前待办；页面管理可编辑的正文、附件和任务卡。

## Acceptance criteria

- [x] 一条会话订阅处理发送与续答。收到 202 但 SSE 首帧挂起时可停止，服务端确认停止后立即可发送；若终态先于回执到达，迟到回执不能重新激活轮次。
- [x] 断线期间可编辑草稿 B，确认 A 结束或被拒绝后才开放下一次普通发送。A 的迟到结果仅清理其提交版本，即使 B 的正文和附件与 A 相同也保留 B。
- [x] 页面仍打开但 202 丢失时先核实 A，需要重传时使用原请求 ID、原正文、附件和参数；恢复后只有一次受理和执行。
- [x] 关闭页面或切换会话只解除订阅，旧响应不能更新新会话。重新打开先取快照再订阅；已受理轮次可找回，未受理命令不自动补发，快照之后才受理的命令能通过 SSE 出现。
- [x] 按最后已处理游标恢复；旧回执或快照不倒退页面，重复事件不重复展示。停止结果未知时先核实。助手回复结束后允许下一轮，后台媒体任务仍可更新。
