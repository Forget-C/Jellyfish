# 05: 参考、前段依赖与执行依据闭环

Status: ready-for-agent
Blocked by: 03

**What to build:** 用户在单元总览和子图中查看、选择及调整参考，编辑前段依赖，并阅读六岗设计如何进入本单元执行。服务端提供准确绑定、固定来源、范围分区与准备问题，现有业务检查继续决定是否可执行。

**依据：** [实现规格](../spec.md)；[共同执行规则](../README.md)。前置：[03 单元 graph 浏览](03-unit-graph-browsing.md)。可与 04 并行。

## Acceptance criteria

- [x] 每单元一个参考集合卡，总览与子图访问同一集合；后端提供缩略图信息、计数、问题和明确绑定目标，参考作为输入指向单元。
- [x] 查看、选择、追加、替换、移除和排序复用现有参考组件及保存行为。同文件在不同单元内的身份、用途、输入角色、主体关联和顺序保持独立。
- [x] 待准备参考要求、实际素材绑定和模型是否接受输入分别表达；未准备时保留已有准备入口，不自动选图或伪造输入。
- [x] 前段依赖卡展示准确固定来源、实际帧／落幅、绑定与复核状态；详情沿用现有依赖编辑器，保存回读保留历史身份。
- [x] 只读“本单元执行依据”消费既有 `unit_scope`／`resolved_design_fields`，区分执行、约束、背景、未解决项及视频／声音／后期阶段，支持来源字段定位。
- [x] 部分动作不因完整镜头可见结果而扩大，图成员或连线不反推执行选择；四类配置不变成六张岗位卡，单元组织不改写导演设计。
- [x] 缺失文件、来源不可用、能力未知或前段采用替换时，后端如实投影缺失／未知／待复核。即使场次 revision 不变，也不以旧图准备状态保证外部证据仍有效。
- [x] 最终编译、预检与试拍沿用实际输入校验；结构完整、准备度、任务状态、素材审查和剪辑采用分别表达，多覆盖项执行限制不放宽。
- [x] 当前对象删除后，历史生成依据和固定依赖仍按原身份阅读；既有只读保护、取消、迟到上传及跨单元隔离行为保留。
- [x] 编辑只更新当前相关内容，保存后由服务端重新返回图；未知／失败不通过前端补图或逐编辑投影接口掩盖。

## Validation

- API 验证同文件不同绑定、不同输入角色／顺序、移除后的独立性、固定依赖身份、缺失来源与范围分区；复用真实准备与指令校验边界。
- 浏览器验证总览／子图参考入口、选择调整、依赖详情、取消、保存回读、执行依据和来源定位；用受控证据变化验证未知及待复核状态。
- 回归部分动作、共享设计、声音／后期与历史删除目标；证明图完备不绕过真实编译／预检。
- 承接 A05 的前段依赖、A06、A07、A08、A09；完整试拍旅程由 08 汇合验证。执行相关接口、类型和后端检查。

## Scope and handoff

复用 03 的投影器、视图、目标及共同读取上下文，补足领域投影而非新建第二套准备状态引擎。动作覆盖、生成参数、组织要求及新增流程由 04 负责；本票与其通过既有内容更新方式集成。
