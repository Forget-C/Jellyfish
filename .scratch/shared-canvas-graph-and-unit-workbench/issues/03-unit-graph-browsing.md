# 03: 单元总览、镜头筛选与子图浏览

Status: ready-for-agent
Blocked by: 02

**What to build:** 用户在单元画布通过全部／指定镜头浏览真实单元与参考摘要，点击单元进入其完整子图，并通过既有详情入口继续工作。后端单元投影器和前端单元浏览共同验证共享 graph 能力可被第二种画布复用。

**依据：** [实现规格](../spec.md)；[共同执行规则](../README.md)。前置：[02 导演迁移与公共导航](02-director-subgraphs-and-shared-navigation.md)。

## Acceptance criteria

- [x] 单元投影器使用共同协议、构建工具、读取上下文和完整性校验；不复制基础注册／校验逻辑。导演与单元投影器运行同一组一致性断言。
- [x] 后端提供全部镜头、指定镜头和单元子图的成员、边、锚点、入口、真实依据、配置摘要和参考计数；前端不从 coverage 数组重建视图或准备状态。
- [x] 总览呈现“镜头依据 → 单元聚合入口 ← 参考素材”；左上角悬浮导航承担返回、前进、面包屑和镜头筛选，镜头卡不承载筛选器。
- [x] 点击单元进入独立子图，面包屑为“单元画布 › 单元”；子图显示所有覆盖项与完整依据，不因入口镜头裁剪，也不在总览原地展开。
- [x] 一镜多单元、跨镜头单元、同镜头多个覆盖项保持准确身份和关系。当前单 coverage 执行限制继续真实显示，不复制或自动拆分单元。
- [x] 正常入口恢复当前版本上次筛选，首次使用全部镜头；导演入口定位所选镜头；精确单元链接或任务回跳直达单元，不用第一个覆盖项替代。
- [x] 返回恢复筛选、缩放和视口；聚合预览、手动位置及缓存隔离复用共同能力。保存 revision 变化不重置稳定节点位置。
- [x] 删除、无权限、缺失引用、固定历史及无稳定 ID 目标按规格表达；历史记录不改写，失效目标不按同名匹配。
- [x] 四类配置及参考具有真实摘要，已有设置／参考详情仍可访问；保存前使用当前编辑内容，旧图不覆盖输入。本票不提前移除 04、05 尚未替换的可用编辑入口。
- [x] 读取／保存返回两类一致快照的 graph；失败真实可见，单元已迁移视图不退回前端业务组装。

## Validation

- API 验证一镜多单元、跨镜头、同镜头多 coverage、缺失依据与历史目标；读取和保存的两图版本／revision 一致。
- 共同 graph 契约测试同时运行两个投影器，证明一致性规则真实复用；检查非法引用和视图结构被定位和拒绝。
- 浏览器验证三种视图、不同入口、任务回跳、历史导航、聚合预览、保存后布局及现有编辑入口可用。
- 承接 A01、A02、A03、A09、A10、A17、A18；新建编辑细节由 04，参考和执行依据深层行为由 05 完成。执行必要类型、接口和后端验证。

## Scope and handoff

03 完成后，04 可接入三类配置的专属详情和新增流程，05 可接入参考、前段依赖及执行依据。两个后续任务复用本票稳定目标和视图，不各自重新推导 graph 成员。指令／剪辑 graph 和新生成能力不在范围内。
