# 01: 共享 graph 契约与工具落地，打通导演全场卡片

Status: ready-for-agent
Blocked by: None

**What to build:** 用户打开导演画布即可从服务端 graph 阅读原文依据与全场卡片，并通过现有详情编辑可编辑内容、保存后读回相同结果。首个功能同时落地供导演和单元共用的后端契约、图工具与快照读取方式。

**依据：** [实现规格](../spec.md)；[任务与共同执行规则](../README.md)。本票无前置依赖，可与 06 独立开展。

## Acceptance criteria

- [x] 基础协议表达图种类、版本与 revision、强类型节点载荷、业务对象引用、边、视图、问题、来源和编辑目标；不使用任意数据袋，不把导演专有范围语义强加给其他画布。
- [x] 共同构建工具实际承担注册、索引、重复冲突和完整性校验；覆盖唯一身份、闭合引用、可见边端点、无环层级、有效入口／锚点／问题／编辑目标及快照一致性。
- [x] 共同读取上下文固定内容和 revision，提供复用证据加载的边界；构建工具不做 I/O 或鉴权。契约保留纯数据职责，业务投影进入 service，API 仅组织请求和响应。
- [x] 导演原文依据和全场卡片的标题、摘要、成员及关系由后端提供。前端直接消费真实 graph，不再对本票迁移部分查原始业务数组拼展示图。
- [x] 版本读取及保存返回与内容一致的图；实际使用 generated client，同步 OpenAPI。graph 不另作业务持久化，不接受前端节点／边写入。
- [x] 原文依据沿用原有选择与只读语义；可编辑全场卡片通过现有详情修改、取消及保存。未迁移的导演区域仍可使用，不将未迁移部分声明为完成。
- [x] 保存前显示图待同步；编辑器读取当前内容。提交 A 后输入 B，A 的返回只推进基线，B 不被覆盖或误标为已保存。
- [x] 缺失引用显式可见；外部／历史目标带来源上下文。无稳定 ID 的历史项标明 revision 内有效，不在读取时改写身份。
- [x] 本票已迁移内容加载或图响应失败时显示错误与恢复入口，不退回前端拼图，不丢当前输入；保留固定历史的只读规则。

## Validation

- 通过版本 HTTP 读取、保存、重读验证真实内容、revision 与 graph 一致；不得仅比较界面成功提示。
- 共同图公开边界覆盖重复 ID、悬空边／成员、循环层级、无效目标、跨 revision 临时目标；建立后续两个投影器可共用的断言。
- 浏览器验证原文阅读、全场详情修改／取消／保存回读、图待同步、迟到响应及图失败；原导演未迁移区域通过必要回归。
- 承接 A09、A10、A12、A18 的本票范围；A10 的双投影器验收在 03 完成。按共同规则执行接口同步、前端类型检查和共享后端相关测试／静态检查。

## Scope and handoff

共同接口只包含当前确定的图职责，采用少量函数或小型构建器，不引入通用表单、插件、反射路径或继承框架。后端投影和前端首个消费者同票交付，不留下仅有 DTO 的未使用基础设施。

向 02 提供已验证的基础图协议、公共构建／校验、读取保存一致性和首个渲染消费方式；其余导演节点与完整导航由 02 完成。周期调度由 06 改造，本票保留既有串行与输入保护并兼容其集成。
