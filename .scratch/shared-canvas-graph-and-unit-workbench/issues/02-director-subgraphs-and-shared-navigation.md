# 02: 导演镜头子图与公共导航完成迁移

Status: ready-for-agent
Blocked by: 01

**What to build:** 用户可以基于后端 graph 浏览导演全部设计内容，在总览与镜头子图间前进、返回、预览、编辑和定位来源，保存后保持布局。形成可被单元画布直接复用的图容器、导航、聚合入口和布局状态能力。

**依据：** [实现规格](../spec.md)；[共同执行规则](../README.md)。前置：[01 共同契约与首个消费链路](01-shared-graph-and-director-global-cards.md)。

## Acceptance criteria

- [ ] 复用 01 的协议和工具，补齐导演其余设计对象、镜头视图、成员、关系、摘要、计数及来源；相关图业务编排位于 service 层。
- [ ] 全场、专属、共享、虚拟引用、待归镜头和未关联等已有设计语义正确保留；`placement`、`uses`、`applicability`、`paths` 不被简化为错误的统一范围。
- [ ] 总览、镜头子图和聚合预览消费同一后端视图成员；预览不另行拼图，不改变用户浏览历史或布局缓存。
- [ ] 图容器、悬浮返回／前进／面包屑、聚合入口和布局状态可由第二种画布复用。公共层不按导演中文标签、ID 前缀或专属焦点选择器推断业务。
- [ ] 导演具体渲染器、编辑命令、布局规则和旧布局缓存迁移留在业务适配部分；节点种类使用穷尽的强类型分派，不建立动态表单引擎。
- [ ] 返回与前进恢复视图和视口；稳定节点保存后保持手动位置，缓存按用户、项目、场次、版本和视图隔离；临时身份不跨 revision 复用。
- [ ] 现有详情编辑、关系查看、来源定位和从导演镜头进入单元准备的入口继续可用。旧图目标失效时不会定位到其他同名对象。
- [ ] 导演相关详情、来源和检查消费者完成迁移；已替换的前端业务组装清理，不保留失败回退。图错误和只读历史处理不覆盖当前编辑内容。

## Validation

- 版本读取／保存接口及投影器共同断言验证各类设计对象、适用范围、缺失引用和固定历史；对外 schema 变化同步 generated client。
- 浏览器验证总览进入镜头、返回／前进、聚合预览、关系详情、字段来源定位、编辑保存和手动位置恢复；包含已有布局缓存迁移。
- 按工作台规范验证实际页面、键盘和窄屏；复用必要的几何结果测试，避免把具体组件拆分写成测试约束。
- 承接 A02、A03 的导演入口部分、A09、A10、A17、A18；单元入口的新目标表现由 03 联合验证。完成相关前后端检查。

## Scope and handoff

前置 01 提供协议、公共图工具和版本快照链路；本票完成导演整体迁移及公共导航／预览，因此 03 可直接作为第二个消费者接入。指令和剪辑图不迁移，无关业务不重构。
