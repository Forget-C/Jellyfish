## 所有票据共同遵循

- 每张票据交付完整可观察行为，包含必要的契约、业务服务、接口、生成客户端、界面及测试变化；实际未受影响的层无需机械修改。
- 后端公共契约、构建工具、完整性校验和读取上下文在 01 落地；02 补齐导演投影，03 以单元投影验证真实复用，05 补齐参考／依赖／执行依据的业务投影。基础构建器不承担 I/O、鉴权或业务准备判断。
- 分阶段迁移时，尚未迁移的区域维持既有可用行为，不伪称已使用新图；已迁移区域不得在失败时退回前端业务拼图。最终导演和单元均完成迁移，指令和剪辑 graph 不在本轮范围内。
- 后端提供节点、边、成员、摘要、计数和业务状态；前端负责渲染、编辑交互及几何布局。graph 与内容属于同一已保存快照，当前输入不被旧图覆盖。
- 六岗、单元身份、真实执行范围、当前单 coverage 执行限制、固定历史来源和人工采用边界沿用规格。不得增加草稿、第二套保存、逐编辑投影请求、批量／跨镜头生成能力或任意历史请求账本。
- 对外契约改变时同步 OpenAPI 与 generated client，先确认运行中的后端加载当前改动；前端按项目规则执行类型检查，后端执行相关测试和 Pylint。共享基础设施变化运行相应完整测试集，选用 skill 的额外验证要求一并执行。
- 行为测试优先使用版本读取／保存及业务 HTTP 接口、真实浏览器旅程；共同图公开边界覆盖非法结构。复用同代码和环境下已通过的结果，相关改动或新疑点出现时重跑。
- 每张票据保存验收证据和未完成项，补齐因本票改动失真的文档；08 汇总当前生效架构。纯票据发布不代表功能验收通过。
