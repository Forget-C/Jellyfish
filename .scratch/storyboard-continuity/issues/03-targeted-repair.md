# 03: 一次定向修正与复核

**What to build:** 系统发现冲突后，最多进行一次自动定向修正并复核，用户能看见处理进展及仍未解决的问题，原文和人工要求得到保护。

**Blocked by:** 02

**Status:** ready-for-agent

Resolution: completed

- [x] 草案语义审查发现冲突后最多一次自动定向修正，随后复核；与现有纠错流程协调，不因嵌套重试形成无限循环。
- [x] 只自动调整系统补充设计，优先最小受影响范围；保护原文事实、用户已确认和人工修改的要求。
- [x] 修正后复核受影响镜头及相邻依赖；不无故改写无关镜头，自动修正不能改变忠实提取的补充权限。
- [x] 两项受保护要求无法兼容时交由用户选择；一次修正后仍有冲突，保留问题及候选，不自动应用或不断重试。
- [x] 展示修正与复核阶段，保留可恢复结果；异常延续已有失败保留与重试规则，未完成不标通过。
- [x] 通过浏览器和公开接口验证可修正、仍冲突、受保护要求、复核失败及次数上限，核对最终候选和实际应用范围而非内部函数形状。

验证边界：复用现有真实浏览器与服务端公开接口；仅替换外部 LLM 和媒体供应商响应，保留真实保存、引用校验、输入编译和任务状态。使用隔离数据，不以真实付费生成作为自动测试前提。
