# 09: 上游新结果提醒与重新采用

**What to build:** 已固定采用前镜画面的后镜在上游出现新成功结果时收到提醒，可对比并重新选帧，也可继续保留旧采用。

**Blocked by:** 07

**Status:** ready-for-agent

Resolution: completed

- [x] 工作台显示来源镜头有新结果；提醒不自动替换固定图片、结果身份或时间位置，不阻止后镜生成。
- [x] 用户可预览新旧成功结果并重新选帧或保持旧采用，新的采用仍经用途校验、确认和原子保存。
- [x] 重新采用仅更新后镜输入，已有视频保留并提示依据已变，不自动生成、不连锁更新后续镜头。
- [x] 保存重开后固定关系和更新提示语义一致，不把共同画布动态输出预览统一改成固定承接。
- [x] 浏览器和公开接口模拟上游产生新成功结果，验证旧采用仍固定、真实任务使用所选文件、重新采用可撤销且不产生自动媒体任务。

验证边界：复用现有真实浏览器与服务端公开接口；仅替换外部 LLM 和媒体供应商响应，保留真实保存、引用校验、输入编译和任务状态。使用隔离数据，不以真实付费生成作为自动测试前提。
