# 08: 参考组合冲突的明确切换

**What to build:** 用户采用首帧与已有主体参考不兼容时，能看清影响并选择取消或明确切换，原有卡片与素材不会被自动删除。

**Blocked by:** 07

**Status:** ready-for-agent

Resolution: completed

- [x] 按当前模型能力列出不兼容的主体参考和采用关系；当前 Vidu 首帧与主体参考不混用，不绕过共同预检。
- [x] 提供保留原主体参考并取消采用，以及明确确认切换首帧并停用不兼容主体输入两条路径。
- [x] 仅修改目标模型的采用关系，参考卡、素材及其他模型输入保留；支持的主体或帧参考实际进入任务，不伪称两者同时有效。
- [x] 创建素材、接入首帧、停用冲突输入作为一次完整操作，失败保持原状，一次撤销恢复原关系及新增画布内容。
- [x] 采用确认前重新核对当前模型和输入，不因浮层打开后发生编辑而覆盖新配置，冲突变化需重新核对。
- [x] 浏览器及公开接口覆盖取消、确认、能力变化、提交失败、保存重开及一次撤销；核对真实编译输入并回归普通画布参考校验。

验证边界：复用现有真实浏览器与服务端公开接口；仅替换外部 LLM 和媒体供应商响应，保留真实保存、引用校验、输入编译和任务状态。使用隔离数据，不以真实付费生成作为自动测试前提。
