# 07: 后镜采用固定画面

**What to build:** 用户从工作台后镜视频卡进入视觉承接浮层，选择本画布更早镜头的成功结果及帧，明确用途后固定采用，并能一次撤销。

**Blocked by:** 06

**Status:** ready-for-agent

Resolution: completed

- [x] 入口位于后镜视频卡操作菜单，不增加页面或视图；默认推荐前镜，可选本画布更早镜头的具体成功视频结果。
- [x] 在浮层预览定位并选择帧及用途；连续动作且机位合适可推荐尾帧作首帧，切换景别不默认选尾帧或首帧用途。
- [x] 用途必须映射当前模型实际支持的输入，不能添加未参与执行的虚假连续性用途；本票对不兼容组合明确拒绝采用，不静默停用输入。
- [x] 创建选帧素材卡、接入目标采用关系作为一次完整操作，失败保持目标原状，无半完成连接；成功一次撤销恢复原关系及本次新增画布内容。
- [x] 采用固定到具体视频结果、图片文件和时间位置，保存重开及真实生成输入均一致，不使用随上游变化的动态连接冒充固定采用。
- [x] 卡面只显示简短来源，通过引用浮窗定位；未采用或没有前镜成功结果时可提示风险后直接由用户生成，不强制补齐前镜。
- [x] 用户确认采用不自动发起图片或视频生成；撤销不删除历史视频或其他卡使用的素材文件。
- [x] 浏览器和公开接口验证选择、支持用途、实际任务输入、失败原状、重复确认、撤销、重开及可跳过承接；普通画布动态连接与单卡执行保持现状。

验证边界：复用现有真实浏览器与服务端公开接口；仅替换外部 LLM 和媒体供应商响应，保留真实保存、引用校验、输入编译和任务状态。使用隔离数据，不以真实付费生成作为自动测试前提。
