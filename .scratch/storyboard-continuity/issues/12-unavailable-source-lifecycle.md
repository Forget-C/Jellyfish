# 12: 来源不可用后的独立使用

**What to build:** 用户在来源卡片或视频不可用后仍可使用已保存的选帧图片生成，同时能够区分来源导航失效与实际输入图片丢失。

**Blocked by:** 07

**Status:** ready-for-agent

Resolution: completed

- [x] 固定图片仍可读取时，来源卡片或视频不可用不使目标采用失效，预检和任务输入继续使用该图片。
- [x] 引用浮窗明确来源不可用，不能执行失效定位或重新选帧；保留已记录的来源身份与时间，不伪造可用来源。
- [x] 选帧图片自身缺失时遵守共同画布现有缺失输入规则，不声称参考有效或用另一张图片静默替代。
- [x] 复用文件保留与删除保护，撤销或来源变化不删除其他卡已采用文件；不得为测试来源不可用绕过产品保护。
- [x] 若现有保护无法满足已确认行为，先说明额外共同基础改动及影响并取得确认，不擅自扩展删除语义。
- [x] 使用隔离数据通过浏览器和公开接口验证来源失效、图片仍有效、图片缺失、保存重开及真实输入；回归历史固定成果和普通画布文件保护。

验证边界：复用现有真实浏览器与服务端公开接口；仅替换外部 LLM 和媒体供应商响应，保留真实保存、引用校验、输入编译和任务状态。使用隔离数据，不以真实付费生成作为自动测试前提。
