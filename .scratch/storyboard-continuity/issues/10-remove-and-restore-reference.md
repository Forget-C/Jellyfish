# 10: 移除承接与恢复原参考

**What to build:** 用户可以从后镜视觉承接入口移除当前关系，保留选帧素材，并在核对现有配置后选择恢复此前停用的主体参考。

**Blocked by:** 08

**Status:** ready-for-agent

Resolution: completed

- [x] 移除仅解除目标承接采用关系，选帧图片素材卡和历史成果保留，其他使用该素材的卡不受影响。
- [x] 恢复前核对当前模型、参考和输入配置，展示拟恢复项与不兼容项，由用户明确确认。
- [x] 用户在采用后新增或修改的输入不能被旧配置盲目覆盖；模型不兼容时不强行恢复，不静默删除现有关系。
- [x] 移除或确认恢复作为可撤销的完整画布操作，失败保持操作前状态，保存重开后关系一致。
- [x] 浏览器和公开接口覆盖只移除、恢复、取消恢复、模型变更、输入已编辑、失败和撤销，并验证素材与实际生成输入。

验证边界：复用现有真实浏览器与服务端公开接口；仅替换外部 LLM 和媒体供应商响应，保留真实保存、引用校验、输入编译和任务状态。使用隔离数据，不以真实付费生成作为自动测试前提。
