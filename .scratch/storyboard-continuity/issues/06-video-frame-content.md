# 06: 通用视频选帧与来源素材

**What to build:** 用户通过通用选帧交互预览已有视频、定位一帧，确认后得到可独立查看与复用的图片素材，并能追溯来源视频和时间位置。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

Resolution: completed

- [x] 面向可用视频提供预览和时间定位及明确确认，采用本地真实视频抽帧，不调用生成模型；未确认不创建卡片。
- [x] 确认后保存独立图片文件并形成普通图片素材卡，记录具体来源视频文件、结果身份和时间位置，保存重开后可读取和复用。
- [x] 来源复用现有引用浮窗和索引机制，不堆叠重型说明；在来源可用时能定位来源。
- [x] 同次确认重复提交不重复创建素材，主动选择另一帧视为新的操作；抽帧失败不留下半完成画布内容。
- [x] 仅补齐已批准的通用选帧、图片保存及来源记录，普通画布不被引入镜头顺序、连续性审查或新版本机制。
- [x] 浏览器和公开接口以真实本地视频验证选定时间对应图像、保存读取、来源、幂等及失败；不以占位图代替成功抽帧。
- [x] 回归共同画布原有保存、历史固定成果、图片参考和单卡生成；复用文件保护，发现额外基础扩展先确认。

验证边界：复用现有真实浏览器与服务端公开接口；仅替换外部 LLM 和媒体供应商响应，保留真实保存、引用校验、输入编译和任务状态。使用隔离数据，不以真实付费生成作为自动测试前提。
