# 01: 场次共同状态与逐镜继承

**What to build:** 创作者提取分镜后，能够在现有设计卡中查看、编辑同一场次的共同状态和每镜的继承、变化、结束状态，并让这些设计通过实际采用关系进入生成输入。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

Resolution: completed

- [x] 共同状态覆盖人物与道具位置、朝向、持物手、动作状态和摄影机轴线一侧；使用现有空间、站位、表演与连续性设计卡表达，不建立隐藏设计正文。
- [x] 每镜明确继承状态、允许变化、结束状态；摄影展示变化不自动成为剧情动作，对象出画不代表其场内状态消失，必要背景对象约束及采用关系不遗漏。
- [x] 完整分镜模式的必要补充标为提议；忠实提取的未写明信息保留待定；均不擅自增加原文没有的剧情动作。
- [x] 以雨夜车旁等待为样例，环境、人车同框、持棍细节三镜继承等待状态，第三镜保留必要人车空间关系；不将该样例硬编码为通用规则。
- [x] 首次及重新提取复用候选、差异确认和保存机制；未应用前保留已有画布，卡片保存重开后内容及引用一致。
- [x] 通过既有浏览器和公开接口测试核对提取模式、落卡内容、引用和实际预检输入；仅替换外部模型响应，保留真实保存与编译。

验证边界：复用现有真实浏览器与服务端公开接口；仅替换外部 LLM 和媒体供应商响应，保留真实保存、引用校验、输入编译和任务状态。使用隔离数据，不以真实付费生成作为自动测试前提。
