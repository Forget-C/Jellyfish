# 04: 新分镜首屏对准视频主区

**What to build:** 新分镜首次进入同一张工作台画布时先看到视频主区。创作者能按镜头顺序浏览视频卡，在窄屏上也可以直接操作第一张卡，重开时回到上次的浏览位置。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

Resolution: completed

- [x] 新分镜应用后，视频卡按镜头顺序横排和换行，同一镜头的多个片段相邻，卡面可区分镜头和片段；其余卡片不占据视频主区。
- [x] 宽屏首次视口对准首排；窄屏首次完整显示一张视频卡及其卡面操作区域。布局验收不依赖专项按钮已经接入；按钮接入后也不被视口边缘或画布工具遮挡。
- [x] 再次进入时恢复已保存布局、位置和缩放；窗口变窄不移动已放置卡片，已有画布首次通过本功能打开也不迁移或自动重排。
- [x] 按 Q18 复用共同画布布局和视口能力；初始排布、排序和焦点由分镜入口提供，不新建视图。真实浏览器分别验证宽屏、窄屏和重开，以及普通入口不启用专项初始策略。
