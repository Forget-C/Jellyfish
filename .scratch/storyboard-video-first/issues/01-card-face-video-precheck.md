# 01: 已配置视频卡从卡面生成

**What to build:** 创作者从工作台打开分镜画布后，可以在已配置的视频模型卡表面点击「生成视频」，核对实际输入并明确确认执行当前卡，无需先展开模型编辑器。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

Resolution: completed

- [x] 工作台入口打开新建或可识别的已有分镜画布时，已配置的视频卡可从卡面发起现有预检。已有画布不因此迁移、重排或补叠。
- [x] 预检使用已保存的配置和真实采用关系。取消或关闭预检不创建媒体任务；确认后只运行当前卡，其他镜头和上游模型不自动执行。
- [x] 按 Q17 复用共同卡面操作接入点和现有保存、预检及执行链路；文案、适用卡片和启用条件由分镜层提供。
- [x] 真实浏览器验证工作台入口、普通自由画布和从普通入口打开同一分镜文档。普通入口无专项按钮，原模型编辑器仍可完成预检，两个入口使用同一份文档。
