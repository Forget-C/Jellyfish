# 07: 重提取确认解除受影响的堆叠

**What to build:** 创作者在分镜重提取差异中看见本次需要解除的自动堆叠，明确确认后一次应用差异并解除对应堆叠，必要时可以一次撤销。人工堆叠仍由用户自己解除。

**Blocked by:** 06 — 默认堆叠设计并独立展示素材与参考

**Status:** ready-for-agent

Resolution: completed

- [x] 根据用户实际选择应用的差异识别受影响的自动堆叠，包含编辑、删除成员或变更受保护的输入关系。未选中的变更和未受影响的堆叠不被列入或解除。
- [x] 移动自动堆叠不改变归属；解除时成员在移动后的位置附近恢复展示。用户解除后自行重组的堆叠按人工堆叠处理；若挡住选定的差异，提示具体堆叠并要求手动解除后再核对。
- [x] 用户确认「应用并解除受影响的堆叠」后，应用与解除作为一次操作。取消或失败不留下部分修改；一次撤销恢复卡片、引用、堆叠和位置，既有人工覆盖和孤儿提示规则继续生效。
- [x] 在真实浏览器验证确认、取消和撤销，并通过公开重新提取应用接口验证未确认不会解除自动堆叠、未解除的人工堆叠仍受保护。不放宽共同保存或堆叠校验。
