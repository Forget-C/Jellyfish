# 03: 视频卡显示任务状态与后续操作

**What to build:** 创作者在原视频卡上看到任务进度、结果预览和下一步操作，能够在任务结束后重试或再次生成，而不会重复提交进行中的任务。

**Blocked by:** 01 — 已配置视频卡从卡面生成

**Status:** ready-for-agent

Resolution: completed

- [x] 未运行时显示「生成视频」；排队或运行时显示对应状态并禁止重复提交。
- [x] 失败后显示「重试生成」，沿用原有错误反馈；成功后保留结果预览并显示「再次生成」，不改变既有结果卡展开规则。
- [x] 重试和再次生成均重新预检、由用户明确确认，只执行当前卡。其他卡的任务不改变当前卡的操作状态。
- [x] 使用已配置的视频卡、真实任务状态及受控媒体供应商响应，从浏览器覆盖排队、运行、失败重试和成功后再次生成。状态与文案规则留在分镜层，普通入口保持原样。
