## Acceptance criteria

- [x] 当前指令卡集中提供修改指令、发起检查、查看并确认结果、生成视频和任务状态入口，明确作用于当前单元。
- [x] 卡片展示指令摘要、模型、时长、画幅、参考数量和检查状态；详细报告在检查工作区阅读，缺项能定位到原单元配置。
- [x] 准备缺项、依据已变、检查待查看或确认、任务执行中和提交待核实分别表达，动作按现有状态显示及禁用。
- [x] 现有准备、指令依据确认、六岗审稿及视频执行硬门槛保留；指令或相关输入失配后，旧检查不能授权新生成。
- [x] 从已有当前指令即可完成本票流程，不以 01 的新 AI 起草入口作为实现前置。
- [x] 纯提示词路径从场次保存内容、视频准备、固定任务输入到实际供应商请求，指令、模型及生成参数一致，不凭当前最新单元覆盖已提交输入。
- [x] 受控供应商响应经过真实结果保存与候选登记流程；输出保存未完成前不报告可用候选，不自动加入时间线。
- [x] 单次、保存并生成、批量、预检、取消、原请求核实及原依据重试保持原有规则；检查通过不自动提交视频。
- [x] 键盘、只读、窄屏及任务期间继续编辑保持可用；当前单元的阻塞不错误限制其他独立单元。
- [x] 完成相应浏览器、场次 HTTP 和供应商请求验证，以及受影响的类型检查、后端检查和契约、文档同步。
