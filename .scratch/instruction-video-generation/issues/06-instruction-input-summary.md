# 06: 指令画布只读输入核对与回跳

**What to build:** 用户在指令画布的一张“本次输入”卡核对首帧、尾帧及参考组，查看大图、来源和承接信息，修改时回到同一单元的准确输入卡片。

**Blocked by:** 03 — 首尾帧独立配置并进入视频生成；04 — 参考组按组编辑并进入视频生成

**Status:** ready-for-agent

**Spec:** [AI 指令起草与参考媒体视频生成链路](../spec.md)，实施决策 5、6、10；验收 A14、A20。

## Acceptance criteria

- [ ] 指令画布保留一张只读“本次输入”聚合卡，内部按首帧、尾帧和参考组清楚分区，展示当前明确单元的实际输入。
- [ ] 首尾帧显示缩略图、输入角色、来源、承接对象及可用状态；参考组显示对应人物／物件或用途、缩略图和数量。
- [ ] 未选择、待绑定、不可用与加载或读取失败分别表达，不能用默认候选冒充已选素材，也不能把读取失败当作无输入。
- [ ] 同图首尾帧保持两个位置；同组多图按组呈现；来源、对应对象和输入位置不混为一个分类。
- [ ] 点击图片查看大图，来源及承接依据可查看；卡片连到当前指令卡，准确表达本次生成媒体输入。
- [ ] “修改”进入同一个明确单元并定位首帧、尾帧或目标参考组；依赖 03、04 提供的输入身份及编辑目标，不凭卡片标题、数组位置或图片文件猜测对象。
- [ ] 回跳保留当前未保存编辑，其他单元或旧的浏览选择不能覆盖本次明确目标；不在指令画布直接换图或拖线编辑。
- [ ] 本次输入展示遵守已有当前编辑和保存快照机制；历史任务的固定输入继续从生成记录查看，不被当前参考替代。
- [ ] 依赖状态可基于既有合法绑定或待绑定数据独立验证；本票的回跳目标不以 05 新承接操作完成为前置。
- [ ] 键盘、只读、窄屏、大图关闭和焦点恢复符合工作台约定；完成对应图投影与浏览器测试、类型检查及必要契约和文档同步。

## Validation

- 通过场次接口构造无输入、首帧、首尾帧、主体多组和合法承接输入，验证后端投影与浏览器显示一致。
- 实际点击大图、来源及每个修改入口，断言目标单元和输入卡片准确，并确认没有提交生成或修改参考请求。
- 验证同一图片占用两个位置、参考组重排和当前未保存编辑的场景，避免错误定位或旧数据覆盖。
