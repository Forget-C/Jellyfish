# 场次工作台样式优化

状态：Q1–Q8 已确认，实施完成；验证结果见 [验收记录](validation.md)。
日期：2026-10-14

## 目标与成功标准

以用户提供的图1为视觉参考，将图2对应的场次工作台调整为中性黑灰、低对比容器、内容优先的创作画布。参考图1的配色、层次和工具组织，不因参考图内容较少而隐藏必要业务信息。

- 导演、单元、指令、编辑四种画布及其共用工具栏保持一致外观。
- 顶部区分场次身份、画布切换、当前操作；低频操作有明确归属。
- 节点摘要与展开入口清晰，正文、媒体预览、检查失败和下一步操作易读可见。
- 关系导航与对象编辑不同时占用右侧区域，切换保留未保存输入。
- 保持保存、版本、任务、素材审查和剪辑采用的既有业务语义与保护。
- 空场次、密集节点、长指令和剪辑时间线均可操作；桌面与窄屏的关键控件不相互遮挡。右侧浮层覆盖部分画布内容属于已接受的展示方式。

## 已确认决策

### Q1：范围

统一优化四种场次画布及共用工具栏。项目工作台和其他页面暂不纳入。工作台内部的编辑区、菜单及弹窗沿用同一视觉语言。

### Q2：调整深度

允许在保留现有功能的前提下重新分组顶部操作、收纳低频按钮、调整侧栏与卡片内容展示层级。

### Q3：顶部操作

- 左侧：场次名称、版本与保存状态。
- 中间：四画布切换。
- 右侧：当前画布主操作、任务与更多。
- 新建和另存为归入版本菜单。
- 自动保存开关归入保存菜单。
- 导出分辨率和导出记录归入导出面板。
- 撤销与重做保留图标入口。

保存失败、待核实、只读等关键状态及其恢复入口继续可见，不能因正常状态收纳而被隐藏。

### Q4：右侧面板

关系树默认收起，保留固定图标入口。关系导航与对象编辑共用右侧区域，一次展示一个；切换保留未保存输入。

### Q5：节点内容

默认展示关键信息与状态；原文和长指令提供摘要及明显的展开或编辑入口。媒体预览、检查失败和下一步操作保持可见。正文保留易读对比度，不照搬参考图很暗的辅助文字。

### Q6：面板与画布

用户选择面板悬浮覆盖，视角完全不动。打开、切换或关闭右侧面板不改变画布可用宽度、缩放、平移和节点位置，不为面板自动定位或重排节点。面板可能覆盖部分节点，由用户关闭面板或手动平移查看；保留清晰的关闭入口。

这项规则针对面板开关行为；用户主动点击关系定位、适应画布和缩放等明确导航操作仍沿用相应视口行为。

### Q7：复杂详情

六岗设计、原文差异、历史记录等复杂内容继续使用宽弹窗，统一其视觉样式。右侧共用区域负责关系导航与轻量编辑，不将全部长表单强行迁移到窄侧栏。

### Q8：实施授权

用户已确认按本规格开始实施，并在完成后验证四个画布的样式和交互。

## 视觉落地建议

以下为实现起点，最终以真实内容截图检查；不是从参考图精确取样得到的色值。

| 要素 | 建议 |
| --- | --- |
| 背景 | 近黑色 `#0d0d0d`，低对比细点阵 |
| 节点与面板 | 中性深灰 `#1b1b1b`，悬浮工具表面 `#242424` |
| 边框 | 细描边 `#2d2d2d`，减少明显投影 |
| 文字 | 正文 `#e5e5e5`，辅助内容 `#a3a3a3`，正文以 14px 与约 1.6 行高为起点 |
| 强调 | 蓝色只用于当前选中、焦点与必要主操作；错误与警告保留明确语义 |
| 节点标题 | 在节点外统一展示名称，去掉同一节点内重复标题；正文内有意义的分节标题保留 |
| 圆角与间距 | 节点约 10–12px 圆角、20px 内边距；保持节点布局适应真实内容 |
| 工具 | 左侧统一窄图标工具条，图标提供悬停提示及键盘可用名称；底部导航与缩放紧凑分组 |
| 顶部 | 桌面尽量维持紧凑单行，窄屏按操作分组收纳，不靠无限换行或缩小文字容纳所有入口 |

布局只为展示服务；折叠、平移与查看详情均不触发业务保存、生成或采用。

## 改造前事实与实现边界

- 当前路由使用 `front/src/pages/aiStudio/directing/CanvasSequenceWorkbench.tsx`。
- 四画布共用 `DirectorCanvasSurface.tsx` 与局部 `canvasWorkbench.css`；蓝灰色主要来自此局部 CSS 的硬编码。
- 当前工作台使用局部深色主题；无需修改全站主题或替换 Ant Design。
- 当前工具栏直接排列大量操作并允许换行；节点标题存在内外重复。
- 既有画布位置与视口不属于业务版本内容，应保持这一边界。
- 不为本次样式调整新建全站设计系统，不修改后端或接口契约。
- 没有新增领域概念，暂不修改 `GLOSSARY.md`；普通可逆样式与布局选择不单独创建 ADR。
