# 06: 暂存保存与图修订保护

Status: ready-for-agent
Blocked by: 03

**What to build:** 场次工作台以本地暂存承接编辑，以带 revision 的保存提交真实数据；画布只展示对应已保存修订的权威关系图。编辑、保存失败或关闭恢复均不丢失未确认内容。以[功能规格](../spec.md)为准。

- [ ] 初次加载以服务器版本初始化暂存；存在本地恢复数据时先核对版本身份、基础 revision 与未完成请求状态，不把旧暂存静默配对到新修订。
- [ ] 自动保存按停止编辑约一秒触发、连续编辑至多约五秒提交一次；手动保存走同一事务路径。每次冻结提交快照、预期 revision 和 request_id，同一时刻只保留一个在途保存。
- [ ] 保存响应仅在版本身份、request_id、新 revision 和快照业务等价性通过后推进已确认基线与关系图；在途新增编辑仍留在暂存并继续提交，响应正文不得覆盖较新的输入。只有当前暂存已确认时显示“保存成功”，在途显示“保存中”。
- [ ] 可确定的校验失败保留暂存并提示；结果不明按同一 request_id 核实或重试；revision 冲突停止自动保存，展示本地与服务器差异，由用户处理后再保存，不自动覆盖或重基。
- [ ] 暂存可在关闭后恢复；图清楚标示上次已保存 revision 与关系更新中，未保存时暂缓画布关系操作，字段编辑可继续；可访问的状态提示覆盖保存成功、失败和冲突。
- [ ] 真实浏览器及保存接口流程覆盖延迟响应、连续编辑、失败重试、关闭恢复、409 和 null 与空参与对象名单的语义区别。
