# 08: 单元依据中的约束与背景

Status: ready-for-agent
Blocked by: 04, 07

**What to build:** 后端按已保存场次修订为每个单元形成一份固定输入，区分已选执行动作、适用约束和实际消费的解释背景；指令建议、依据确认、检查与视频预检使用相同范围。以[功能规格](../spec.md)为准。

- [ ] 已选动作、全场及局部适用约束、实际消费的解释背景分开输出并保留来源身份、字段或条目及适用原因；摄影、空间、连续性前后态和岗位禁止项在适用阶段作为约束进入，即使不是已选动作。
- [ ] 全场规则仅在确实全场生效时纳入各适用单元；局部例外缩小作用范围。背景按明确消费依据纳入，场次级核心背景与有明确相关范围的人物情境分别处理；展示为背景不等于每个单元都消费，也不自动转成动作或约束。
- [ ] 对声音、后期等非视频阶段的规则保留阶段语义，不误交给视频模型；未选动作、待归镜头和未关联项不自动进入单元固定输入。
- [ ] 参与对象等范围未知且影响背景或约束纳入时，保存和浏览仍可用，受影响单元的检查与视频提交阻断并指出待补范围；null 不按全部或空名单解释。
- [ ] 只有实际消费变化影响相应单元的依据确认和检查：全场视频规则影响所有相关单元，局部动作、约束和背景只影响消费它们的单元；保留原正文与历史检查，要求受影响单元重新确认。
- [ ] 真实接口贯穿两个同镜单元、局部例外、未知范围、阶段归属、背景消费原因及影响范围；工作台显示单元依据和失效原因。
