# 02: 后端真实关联数据

Status: ready-for-agent
Blocked by: 01

**What to build:** 用户能在六岗原工作单中建立或修改真实引用、设计适用范围和作用阶段；这些关系进入同一场次版本，保存后回读一致，而不是靠画布位置或前端固定映射决定。以[功能规格](../spec.md)为准。

- [ ] 场次版本分别表达对象直接引用、内容用途与全场、指定镜头或单元出现项的适用性；共用人物、事件、锚点、名称或当前镜头数量不自动产生适用关系。已有语义明确的镜头归属（如摄影工作单 shot_id）直接复用，不要求重复声明。
- [ ] 人工建立、解除和改绑关系后，经现有场次版本保存与读取可核对对象身份、引用字段、范围和阶段；同一设计仍只有一个岗位正式归属。
- [ ] 人工编辑时，有真实引用但镜头范围未定、完全未关联的独立设计项均可保存，同时明确显示设计尚未完整；完成的整场自动设计不得含此类缺项，旧局部建议按规格的延期边界视为普通编辑，AI 来源不产生另一套使用状态。场次背景不需要任意“标成背景”的关联开关。
- [ ] 非法目标、跨项目或跨版本引用、矛盾范围、删除仍被引用的对象均拒绝写入且不部分保存；规则的局部例外明确缩小场次内范围，项目风格已有的条件与例外仍按原契约处理。
- [ ] 通过人工编辑、保存、回读及异常输入的真实接口和工作台流程验证数据库中的关系；同步对外契约与前端生成客户端。
