# 07: 单元选择本次执行项

Status: ready-for-agent
Blocked by: 02

**What to build:** 生产单元明确选择本次要拍出的镜头、节拍、事件及可观察动作；同镜头的不同单元可以选择不同执行项，保存回读和后续生成均保留选择身份。以[功能规格](../spec.md)为准。

- [ ] 单元出现项以稳定身份表达节拍、事件、镜内活动、表演行动和可见连续性变化，记录其可适用镜头或单元范围；镜头有关联仅形成候选，不自动成为本次执行要求。
- [ ] 用户可在单元中增删、改选执行项并保存回读；同一镜头下两个单元选择不同动作时，后续指令依据能分别识别，不合并成整镜或整场动作清单。
- [ ] 服务端拒绝不存在、跨版本或范围不适用的选择；未选项、待归镜头项和未关联项不会因共用对象或场所自动进入执行范围。
- [ ] 拍摄准备明确检查应拍出的动作和可见结果是否已有负责的生产单元；已有镜头范围但尚未分配单元时显示准备缺项，不自动替用户选入单元，也不阻断完整且不受影响的其他单元。
- [ ] 单元选择的对外契约、生成客户端、真实接口和工作台流程覆盖编辑、回读及非法选择。
