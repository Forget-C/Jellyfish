# 05: AI 提取应用真实关系

Status: ready-for-agent
Blocked by: 04

**What to build:** AI 建议与人工编辑使用同一份场次设计关系契约；完成的整场自动设计中，每项保留内容都有符合语义的全场或镜头范围。用户审阅并明确应用后，画布显示真实写入的关系。以[功能规格](../spec.md)为准；2026-10-20 确认的完整性要求替代原“允许 AI 输出合法未关联备用项”的验收口径。旧局部修订保留入口及行为、冻结扩展，产品重规划延期。

- [x] AI 按“岗位 → 具体内容／字段职责 → 范围”生成：固定全场内容直接归全场，镜头工作单继承明确归属，范围可变的条目明确声明；后端校验完整性与一致性。背景、规则与动作进入各自语义字段，不给整个岗位统一赋范围。
- [x] 复用已有明确镜头归属，不要求重复适用性；人物、事件、锚点的普通引用不能替代归属。内容恰好适用于当前全部镜头不因此成为全场内容，缺少范围不能通过背景标签或全场范围兜底。
- [x] 建议预览不写入版本；明确应用后保存回读与人工关系校验、画布分类和来源检查一致，不自动生成新的用户版本。
- [x] 整场生成的非法身份、目标、缺失或含糊范围、矛盾范围最多自动修正一次；仍不合格则建议未完成，保留结果与具体缺项供查看，不能作为完整方案应用，不部分应用或伪造关联。
- [x] 整场修正可补关系、调整镜头设计或增加必要镜头承接有效内容，保留原文事实和用户约束，不删除有效内容或随意归全场来通过检查。
- [x] 真实任务结果、应用接口与浏览器流程覆盖整场生成首次完整、一次修正成功、修正后仍不完整可查看但不可应用、整场补镜；以实际调用次数验证最多一次修正。不包含历史数据迁移或专门的历史补齐流程。
- [x] 局部修订复用既有范围与应用保护，仅做主线兼容回归；范围外原有缺项不阻断文字修改，局部任务成功或已应用不代表整场完整，相关编辑仍接受统一的缺项展示与单元检查。不新增局部关系补齐、六岗联动或影响分析能力。
