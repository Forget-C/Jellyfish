# 04: 场次背景与设计归位

Status: ready-for-agent
Blocked by: 03

**What to build:** 导演画布清楚说明每项设计为何处于场次背景、全场规则、镜头适用、待归镜头或未关联位置，不把非执行性背景误说成缺失关系。以[功能规格](../spec.md)为准。

- [ ] 后端按字段或独立条目的内容用途给出“场次背景”展示分类及无需逐镜引用的原因；它不是可编辑关联状态，不计入待归镜头或未关联数量，也不补造镜头连线。
- [ ] 同一工作单含背景与规则时仅保留一张可编辑原卡，逐项说明用途；不以整卡类型、名称、布局或引用次数自动提升为全场规则。
- [ ] 独立的节拍、镜内活动、对白、摄影与连续性变化不能因缺少镜头关联就改标背景；有引用但范围未定与完全未关联分别显示原因和处理入口。
- [ ] 单镜、多镜、条件式全场规则、无镜头和混合卡片的保存回读及真实浏览器归位一致，仍可检查直接引用来源。
