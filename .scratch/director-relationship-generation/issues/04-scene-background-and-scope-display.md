# 04: 场次背景与设计归位

Status: ready-for-agent
Blocked by: 03

**What to build:** 导演画布按字段或条目分别说明内容用途、全场或镜头范围及缺项原因；待归镜头与未关联表示设计未完整，全场背景无需补造关系。以[功能规格](../spec.md)为准。

- [ ] 后端按字段或独立条目分别确定用途与范围；全场背景说明无需逐镜引用，不计入待归镜头或未关联数量，也不补造镜头连线。背景用途不能代替范围，局部背景仍需明确镜头范围。
- [ ] 同一工作单含不同用途和范围时仅保留一张可编辑原卡，逐项说明；全场身份按具体职责与定义确定，不以整卡类型、名称、布局、引用次数或恰好关联当前全部镜头判定。
- [ ] 独立的节拍、镜内活动、对白、摄影与连续性变化不能因缺少镜头关联就改标背景；有引用但范围未定与完全未关联分别显示原因和处理入口。
- [ ] 单镜、多镜、条件式全场规则、无镜头和混合卡片的保存回读及真实浏览器归位一致，仍可检查直接引用来源。
- [ ] 已有明确镜头归属的工作单直接正确归位；全场背景的摘要不再同时显示“未建立镜头关联”。人工缺项标明设计未完整，保存成功不代表完整性通过。
