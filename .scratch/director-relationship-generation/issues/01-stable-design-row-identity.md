# 01: 设计行的稳定身份

Status: ready-for-agent
Blocked by: None

**What to build:** 让可单独定位、关联或选择的设计行在编辑和保存后保持同一身份，作为[功能规格](../spec.md)中真实关系与生成去向的基础。

- [ ] 新建的镜内活动、表演行动等可独立使用的设计行有稳定身份；编辑正文、重排或改绑关系后，保存回读仍定位原行，不按数组位置或文本内容替换对象。
- [ ] 语义上只有一项要求的字段可用所属对象身份加稳定字段路径定位；列表中的独立规则与约束各有身份，重复或无效身份不能写入。
- [ ] 画布定位、工作单编辑与删除引用保护使用相同身份；失效对象明确提示，不跳到同名或相邻行。
- [ ] 新数据的创建、保存、重排和回读经真实接口与浏览器验证；历史固定快照仍可读取，不自动迁移或补写旧身份。
