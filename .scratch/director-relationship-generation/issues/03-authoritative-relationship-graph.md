# 03: 保存修订的权威关系图

Status: ready-for-agent
Blocked by: 02

**What to build:** 用户在导演画布检查一条连线时，能看到它来自同一已保存场次修订中的哪条真实引用；图是服务端读模型，不是第二份可编辑关系。以[功能规格](../spec.md)为准。

- [ ] 版本读取与保存确认返回绑定同一版本身份及 revision 的图；直接边给出引用拥有者、字段和目标，间接关系保留完整真实路径，不能按名称或共同参与对象补边。
- [ ] 画布连线、关系检查及对象定位消费权威图；前端仅负责布局、聚合、筛选与导航，压缩视图仍可查看全部直接引用。
- [ ] 图不保存另一份关联真值；改绑后再次保存和回读会更新图，旧修订图不会冒充当前关系，缺失引用明确定位。
- [ ] 真实接口与浏览器验证保存内容、图修订、连线来源和导航一致；同步公开响应契约及生成客户端。
