## 交付目标

在已有模型卡和检查卡上查看参数、运行状态、检查报告及历史产物，使用固定运行结果验证反馈。 [前端 i18n 规格](../spec.md)

## 验收条件

- [x] 在两种语言下打开已有模型卡，选择同一模型和参数；检查标签、约束提示与提交的模型标识和参数。
- [x] 打开检查卡，核对检查项、目标、运行中及失败状态；使用本地化的操作查看问题或重试，定位到原检查目标。
- [x] 读取固定的检查报告与历史结果，核对结果对应的运行、卡片和产物；模型输出和用户输入按原文展示，状态、日期和操作名称随语言切换。
- [x] 在浏览器中核对本模块适用的加载、空态、校验、确认、成功和错误反馈，包括图标按钮、输入框及弹窗操作的可访问名称。
