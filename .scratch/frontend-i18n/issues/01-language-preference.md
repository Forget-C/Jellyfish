# 01 首次访问、语言切换与偏好恢复

Status: ready-for-agent
Blocked by: None
Resolution: completed

## 交付目标

普通页面和独立画布从应用根入口读取同一语言偏好。完成首页、账户菜单、个人设置和公共错误页的双语体验，供其他模块复用。 [前端 i18n 规格](../spec.md)

## 验收条件

- [x] 在浏览器首选英语的新上下文打开首页，首次显示简体中文。已存偏好无效或存储不可读时也能以中文进入应用。
- [x] 从账户菜单切换 English，核对首页标题、菜单、设置表单、组件库控件、代表性日期及 HTML 语言属性；个人角色显示英文名称，仍选中原角色。
- [x] 刷新后仍为英文；在同源新标签页直接打开已有独立画布，首屏的画布外观控件、组件库和页面语言一致。切回中文并刷新后恢复中文。
- [x] 在两种语言下访问不存在的页面，通过对应语言的返回操作回到首页；用可访问名称找到语言入口和表单控件。
