## 验收条件

- [x] 在中、英文界面筛选同一类资产或文件，查看详情、创建日期及来源。格式跟随语言，资源标识、用户命名和时间含义一致。

- [x] 在浏览器中核对本模块适用的加载、空态、校验、确认、成功和错误反馈，包括图标按钮、输入框及弹窗操作的可访问名称。
