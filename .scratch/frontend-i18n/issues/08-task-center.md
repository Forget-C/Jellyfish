## 交付目标

用两种语言查看后台任务、理解进度与诊断，完成取消操作或返回任务来源页面。 [前端 i18n 规格](../spec.md)

## 验收条件

- [x] 准备排队、运行和已结束任务，使用当前语言打开任务中心与历史，筛选状态和类型；切换语言后，已选条件及对应任务集合一致。
- [x] 核对通知、数量、进度、耗时与日期的格式和单位，确认数字代表相同业务值。
- [x] 取消一个可取消任务并通过另一任务回到来源页面；比较两种语言下的任务 ID 和跳转目标。
- [x] 分别触发带稳定标识的已知错误和仅含自由文本的诊断，检查前者的译文、后者的原文及周围操作的可访问名称。
- [x] 在浏览器中核对本模块适用的加载、空态、校验、确认、成功和错误反馈，包括图标按钮、输入框及弹窗操作的可访问名称。
