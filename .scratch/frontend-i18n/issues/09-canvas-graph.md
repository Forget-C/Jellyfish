# 09 生成画布列表、添加卡片、连线与重开

Status: ready-for-agent
Blocked by: 01
Resolution: completed

## 交付目标

贯通从生成画布列表到保存、重开画布文档的路径，验证分类名称、菜单动作和端口标识各自的用途。 [前端 i18n 规格](../spec.md)

## 验收条件

- [x] 在英文画布列表搜索并打开画布；分别从分类列表和右键子菜单定位同一卡片类型，确认英文标签下子菜单可以展开，搜索能找到所见的卡片。
- [x] 添加两张相互兼容的卡片，输入中文正文并连接端口；验证菜单、连接提示及保存反馈。比较中英文操作使用的卡片类型和两端端口标识。
- [x] 保存、关闭并重开，核对卡片、连接两端、配置及用户正文。切回中文后可继续编辑同一画布。
- [x] 在已保存画布上仅改变界面语言，核对没有新增业务保存或画布文档改动。
- [x] 在浏览器中核对本模块适用的加载、空态、校验、确认、成功和错误反馈，包括图标按钮、输入框及弹窗操作的可访问名称。
