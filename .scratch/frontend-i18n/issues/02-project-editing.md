Status: ready-for-agent
Blocked by: 01
Resolution: completed

## 交付目标

覆盖项目搜索、筛选、项目概览、导航和项目设置，支持在已有项目中切换语言后继续编辑。 [前端 i18n 规格](../spec.md)

## 验收条件

- [x] 从带有筛选条件的项目列表进入已有项目，切换语言后，项目概览和导航显示译文，返回列表时保留原有搜索与筛选条件。
- [x] 选择含既有中文风格值的项目，输入中英混合项目名、修改选项后切换语言。检查输入、选中项及编辑位置，确认单独切换语言未触发项目保存。
- [x] 从相同基线分别通过中、英文界面保存同样的修改；比较保存请求的业务字段和重新读取的项目，既有风格取值及用户输入一致。
- [x] 核对项目列表空态、表单校验和保存反馈，能通过本地化的可访问名称执行搜索和保存。
- [x] 在浏览器中核对本模块适用的加载、空态、校验、确认、成功和错误反馈，包括图标按钮、输入框及弹窗操作的可访问名称。
