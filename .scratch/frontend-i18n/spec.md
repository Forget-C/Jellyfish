# 产品前端中英文切换

Status: ready-for-agent
Resolution: completed

## Problem Statement

用户可以从账户菜单选择英文，但主导航切换后，首页标题、项目操作、任务提示和部分日期仍显示中文。通过链接直接进入独立画布时，组件库与页面还可能使用不同的语言。部分编辑器用中文标签判断操作类型，直接替换标签可能导致英文菜单失去子项，或者保存不同的业务值。

## Solution

产品前端支持简体中文（`zh-CN`）和英语（`en-US`）。首次访问默认中文，之后以用户在本浏览器的明确选择为准。普通页面与独立画布共用这一偏好。切换时更新界面文案、无障碍名称和显示格式，用户可以在当前位置继续编辑和保存。

覆盖首页、账户设置、项目与章节、管理区、实验室、任务中心、生成画布、场次工作台及公共页面。各模块一并覆盖加载、空数据、错误、校验、确认和成功反馈。

## User Stories

1. 作为首次访问者，我希望在英语浏览器中也能看到中文首页，以便从一致的默认界面开始使用。
2. 作为英语用户，我希望在账户菜单选择 English 后，当前页面和组件库控件立即改用英文，以便继续当前操作。
3. 作为回访用户，我希望刷新、打开同源新标签页或直达独立画布时沿用已选语言，以便从收藏链接继续工作。
4. 作为使用屏幕阅读器的用户，我希望页面语言、按钮名称、输入提示和弹窗操作使用同一语言，以便找到并执行操作。
5. 作为查看任务和资产的用户，我希望按所选语言阅读日期、数量、进度和错误提示，以便判断当前状态及下一步操作。
6. 作为项目编辑者，我希望切换语言后保留未提交的项目名、文本、选项和筛选条件，以便接着编辑。
7. 作为使用已有项目的用户，我希望中文和英文都能识别原先保存的风格等选项，以便沿用原有配置。
8. 作为使用个人设置的用户，我希望角色名称随语言切换，同时保留已选角色，以免重复选择。
9. 作为画布编辑者，我希望通过英文分类和右键菜单找到同一种卡片，以便添加卡片并连接兼容端口。
10. 作为创作者，我希望在英文界面中看到自己输入的中文名称、剧本、提示词和模型输出原文，以便核对作品。
11. 作为再次打开画布的用户，我希望保存的卡片、连接、配置和正文能在两种语言下完整恢复，以便继续创作。

## Implementation Decisions

- 沿用 i18next、react-i18next 和 Ant Design 的语言包。应用根入口统一解析语言偏好，驱动页面翻译、组件库和 HTML 语言属性。读取已有有效选择；偏好缺失、无效或无法读取时使用中文。按当前语言格式化日期、数字和数量，保留业务规定的时区、单位和精度。
- 公共文案共享资源，业务文案按模块组织。将带变量的提示写作完整句子，使英文可以调整语序、空格及单复数。动态插入的用户文本保留原文。
- 菜单动作、筛选、角色、卡片类型和端口按稳定标识判断。既有契约若以中文作为选项值，前端为该值提供双语标签，读取旧数据和提交请求时沿用原值。
- 展示预设名称和操作说明时提供译文；写入作品的预设参数、提示词指令、引用目标及用户输入沿用其业务含义。内置菜单项和用户自定义项目即使恰好同名，也应分别处理。
- 有稳定标识的系统目录项和已知错误可在前端映射文案。服务端或第三方只提供自由文本时展示原始诊断，周围的重试、关闭和上下文提示使用当前语言。

## Testing Decisions

以现有浏览器用例为主要验收入口，从页面观察交互、请求和保存后重新读取的结果。以下三条路径由用户确认。资源检查补充验证各模块中英文词条和插值参数对应关系。

| 验收路径 | 操作与可观察结果 |
|---|---|
| 1. 首次访问 → 切英文 → 刷新 → 直达画布 | 在浏览器首选英语、没有已存偏好的上下文打开首页，确认默认中文。从账户菜单切英文，检查首页标题、设置项、组件库控件、可访问名称、页面语言和代表性日期。刷新后仍为英文；另开同源标签页直接访问独立画布，首屏也使用英文。切回中文后重复检查持久化。 |
| 2. 编辑项目 → 切语言 → 继续保存 | 打开含既有风格值的项目，输入中英混合项目名，修改一个选项，保持未提交后切换语言。检查输入、选中项、编辑位置及已有筛选条件。切换本身不触发业务保存。分别从同一基线在两种语言下执行相同修改，比较提交的业务字段与重新读取的结果。个人设置另核对已选角色的双语标签。 |
| 3. 英文画布 → 找卡片 → 连线 → 保存 → 重开 | 用英文分类和右键子菜单查找卡片，添加两张可连接的卡片，输入中文正文，连接兼容端口并保存。重新打开，核对卡片类型、端口标识、连接两端、配置和正文。单独切换语言不产生画布文档改动；切回中文后能继续编辑同一张画布。 |

复用应用外壳与设置、项目设置、画布右键菜单和画布保存的既有浏览器场景。比较两个独立操作产生的记录时，按业务身份和关系核对，排除服务端生成的时间戳及随机标识。模块迁移还应抽查桌面和窄屏的英文长标签，保证关键操作可见且可达。

## Out of Scope

官网、产品指南、历史发布说明、仓库文档的翻译；后端语言协商、API 契约和数据迁移；作品内容与模型输出的翻译；账号级跨设备语言偏好和其他语言。

## Further Notes

全前端扫描用于定位遗漏，验收以三条可切换的用户流程和业务数据一致性为准。实施优先核对了参与筛选、分支判断和持久化的中文字符串。
