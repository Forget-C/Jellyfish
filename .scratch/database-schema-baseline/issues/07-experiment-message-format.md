# 07 统一实验消息的输入恢复格式

Status: ready-for-agent

Blocked by: 01

父规格：[数据库结构清理与 Alembic 初始基线](../spec.md)

## What to build

让用户从新创建的文本、图片和视频实验会话恢复实际提交的输入，并可查看对应任务的结果。

## 验收条件

- [x] 逐类核实三种实验的当前消息生产者均写出恢复所需的输入，覆盖各自支持的模型、提示词、媒体引用和生成参数。
- [x] 删除从旧消息正文或旧 payload 字段猜测输入的回退路径；通过新会话验证三种实验的输入恢复与结果查看。
- [x] 使用专用库验证并发追加消息仍按会话分配唯一序号；任务状态与输出通过现行任务关系获取。

## Comments

- 2026-11-20 完成并合入 `codex-database-schema-baseline`。文本、图片和视频现行消息恢复及结果读取通过回归，图片和视频省略模型时仍记录实际默认模型，专用 MySQL 验证会话并发追加的唯一序号。
