# 09 从正式基线验收现行业务

Status: ready-for-agent

Blocked by: 08

父规格：[数据库结构清理与 Alembic 初始基线](../spec.md)

## What to build

从同一专用 MySQL 库的空库状态经正式迁移和种子启动系统，连通 API 与 Worker，用本次新建的数据验证用户仍能完成主要创作和制作流程。

## 验收条件

- [x] 显式检查目标后，通过正式入口建库和初始化；用本轮创建的配置及外部模型替身运行，保留真实任务受理、Worker 执行、持久化与结果读取。
- [x] 从创建项目、章节和场次开始，保存并重开画布，单卡生成后能取得任务结果及文件。重放返回原回执，冲突提交被拒绝。
- [x] 复用各领域已验证的流程，串联章节划分恢复、资产来源与主图、画布当前结果和文件删除保护，核实引用指向本轮创建的对象。
- [x] 走通生产计划、批次、拍摄和剪辑，验证现行 Take 可获取；核实现行接口与客户端可在退役结构缺席时工作。
- [x] 记录正式基线上的实际运行结果。验证全程只使用专用测试库和本轮创建的媒体，不对当前库做试迁移或部署切换。
