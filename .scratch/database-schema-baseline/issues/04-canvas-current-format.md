# 04 简化现行画布的预检、运行与结果读取

Status: ready-for-agent

Blocked by: 01

父规格：[数据库结构清理与 Alembic 初始基线](../spec.md)

## What to build

让新建画布只用现行文档、绑定和运行快照格式完成单模型预检、受理、执行与结果查看。

## 验收条件

- [x] 核实文档、绑定、运行顺序的现行写入点，移除旧格式解码和从事件反推旧运行顺序的查询；新画布保存、重开后引用仍有效。
- [x] 核实预检成功只会产生单模型请求，清除冗余的 kind 和 card_ids 持久化；验证卡片身份、修订、输入摘要与有效期，明确拒绝批量执行。
- [x] 通过 API 提交并重放同一请求，仅产生一次运行。经 Worker 和模型替身完成后，可查看固定输入、历史结果集及当前结果。
- [x] 保留失效引用、版本冲突和在用文件的保护。核对影响到的前端读写，公开契约发生变化时同步生成客户端。
