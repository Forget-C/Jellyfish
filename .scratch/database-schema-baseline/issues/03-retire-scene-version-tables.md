# 03 移除旧四画布的 12 张专属表

Status: ready-for-agent

Blocked by: 02

父规格：[数据库结构清理与 Alembic 初始基线](../spec.md)

## What to build

使保留的设计、拍摄和剪辑流程在缺少旧四画布存储的情况下可用，为最终初始迁移确定应剔除的 12 张表。

## 验收条件

- [x] 按父规格逐项核对 12 张表，移除 ORM 定义、剩余业务引用、嵌入数据访问与仅供旧记录转换的脚本；核实共享调用方仍可工作。
- [x] 在专用测试库用新数据走通生产计划设计、编译、批次、拍摄、Take 查看和剪辑，仍可读取 directing_takes 的素材与文件。
- [x] 目标模型中已无 directing_scene_takes 等 12 张专属表。各旧表的功能归属、删除依据及现行替代读写路径（如有）可核对。
- [x] 同步 ADR 0014 的新库适用边界并保留原决策背景；旧 revision 链的整体替换由 08 完成。

## Comments

- 2026-11-20 完成并合入 `codex-database-schema-baseline`。新库结构核对确认 12 张旧四画布专属表缺席。现行设计、生产计划、批次、拍摄、Take、剪辑和文件读取通过业务回归，ADR 0014 保留原退役决策的适用范围。
