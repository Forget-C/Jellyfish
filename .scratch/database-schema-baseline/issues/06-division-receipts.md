# 06 简化章节划分历史与回执

Status: ready-for-agent

Blocked by: 01

父规格：[数据库结构清理与 Alembic 初始基线](../spec.md)

## What to build

让章节划分的保存、历史展示、恢复和重试只处理新系统写出的请求与业务版本。

## 验收条件

- [x] 移除旧回执导入、旧划分输入解码、多套历史请求摘要及仅供旧回执使用的查询。同步历史抽屉、OpenAPI 和生成客户端。
- [x] 在新建章节保存两个划分版本，能查看历史并恢复；恢复后当前指针指向正确版本，同章当前成员的位置唯一。
- [x] 相同请求重放返回原回执，不新增版本；同一请求身份提交不同内容时返回冲突。核实现行回执、快照与当前指针各自的用途。
