# 05 统一资产来源，清理占位风格

Status: ready-for-agent

Blocked by: 01

父规格：[数据库结构清理与 Alembic 初始基线](../spec.md)

## What to build

角色入库后可从统一的来源类型和 ID 找到原角色；图片来源资产如实表达未提供风格，详情、选图与生成均消费这份事实。

## 验收条件

- [x] 核实角色入库的来源写入方及筛选、读取方，消除重复的演员来源列；现行响应所需信息可从统一来源派生。
- [x] 在专用库通过角色入库和重复入库验证来源识别、主图及副本身份；核对列表筛选、详情、编辑权限与生成输入。
- [x] 图片来源资产允许持久化缺失风格值，清除创建时的占位值与读取时隐藏该值的逻辑。核实新建和编辑手工资产的必填规则仍生效。
- [x] 项目归属、章节使用关系及独立副本的现行语义得到保留；同步受影响的公开契约与调用页面。
