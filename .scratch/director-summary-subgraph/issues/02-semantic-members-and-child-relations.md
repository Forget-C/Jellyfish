# 02: 完整成员与子图关系

**What to build:** 用户在“全场概览”子图中看到当前场次版本所有属于“整场设计表达”的卡片及真实设计关系；与组外设计对象的关系通过逐对象边界节点闭合，且默认镜头视图只显示与当前镜头相关的投影。

**Blocked by:** 01: 共享设计卡汇总与下钻

**Status:** ready-for-agent

- [ ] 从完整场次设计对象集合按内容主题、业务类型与适用范围选取调度、角色情境、节拍表演、镜内活动、摄影、连续性和对白工作单；不按共同父节点、邻接、路径可达性或自由文本相似度吸收成员。未关联当前镜头的合格工作单仍在子图中。
- [ ] 子图展示成员之间来自当前版本的真实设计对象引用；一步字段引用用实线，多步推导用虚线，并可核对原引用者、来源字段和路径。默认镜头视图保留原有相对于镜头的直接／间接语义。
- [ ] 对每个确有跨组引用的组外设计对象显示一个只读边界节点，保留对象身份、关系方向与标签；缺失目标显示缺失引用占位并指向引用者。原文、场所与项目资产、生产单元不生成子图边界节点。
- [ ] 默认镜头视图只投影当前镜头原本可见的真实关系；同一业务对象在内外视图指向同一份场次设计内容，子图浏览不产生复制或新关系。
- [ ] 汇总成员数和已有核心内容数随新增、删除和编辑动态成员更新；同类只有一张卡时不显示分区标题。首次进入保持卡片可读，其他内容可通过平移和小地图定位。
- [ ] 用 A→B→C、A→D→C、A→F→E、未关联镜头的工作单、反向引用及缺失引用验证：C、E 是否入组只取决于成员规则，组外目标不会被截断或伪装成新对象；运行相关图与浏览器回归及类型检查。
