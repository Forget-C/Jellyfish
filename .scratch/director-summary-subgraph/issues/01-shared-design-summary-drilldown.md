# 01: 共享设计卡汇总与下钻

**What to build:** 在默认镜头视图中，用户通过一张“全场概览”汇总卡浏览当前场次版本的五张固定共享设计卡，并可进入独立子图阅读、再返回原画布。此票先交付固定卡片的完整浏览闭环；动态工作单在 02 接入。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 汇总卡取代固定共享设计卡在默认镜头视图中的散列展示，固定尺寸内显示全场核心信息、最多两个不同内容域的短摘，以及本阶段成员总数、已有核心内容数、待处理和未保存状态；不创建新的业务对象或设计关系。
- [ ] 总导演、表演、镜内执行、声音、提示词五张卡在子图中始终存在；正文为空也可查看并通过现有全局编辑入口进入编辑，子卡片显示核心内容与适用范围。
- [ ] 从汇总卡进入子图、返回默认镜头视图均可直接操作；返回时保留原镜头选择和画布现场，浏览本身不修改或保存场次设计。
- [ ] 当前镜头原本关联固定共享设计的真实关系投影到汇总卡，关系仍能核对原引用；额外的“全场约束”说明线改为“全场适用”标记，避免产生相反方向的假关系。
- [ ] “已填写”依据真实核心字段判定；结构存在、默认枚举值、对象或关联 ID 不单独计入，明确填写、明确没有或不适用可以计入；未应用的 AI 设计建议不计入。
- [ ] 无场次版本时保留现有空状态；已有全场关系入口、叙事视点及全局编辑入口仍可达。验证默认镜头下钻、空卡、返回、保存回读和不写入行为，并运行受影响的前端检查。
