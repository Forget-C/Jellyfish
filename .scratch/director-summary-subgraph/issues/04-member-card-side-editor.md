# 04: 子卡片侧栏编辑

**What to build:** 用户在子图中直接阅读成员卡片的核心内容和待处理信息，点击“编辑此卡”后在画布旁修改该卡片，无需先进入全场六岗弹窗；编辑仍属于同一场次版本草稿。

**Blocked by:** 02: 完整成员与子图关系

**Status:** ready-for-agent

- [ ] 每张固定共享设计卡和动态工作单都显示核心内容、待处理信息、适用范围与可见的“编辑此卡”操作；空卡可进入编辑，卡片摘要不遮蔽关键状态。
- [ ] 点击操作后打开对应卡片的专属侧栏，保留子图上下文和当前焦点；窄屏仍可完成查看、修改与返回，画布不因开关侧栏意外重排。
- [ ] 侧栏复用现有设计字段、关联校验、只读与删除限制、草稿及保存语义；新增、修改或删除工作单后卡片、汇总统计和关系同步更新，不产生另一套保存流程。
- [ ] 原“编辑六岗设计”弹窗、叙事视点和关系导航仍可到达；打开、关闭侧栏和只读浏览不触发保存，未保存输入在正常视图切换中得到保护。
- [ ] 验证共享空卡、动态工作单、新增与删除、无权限／只读、关联校验、保存回读、桌面与窄屏键盘焦点；运行受影响的前端测试与类型检查。
