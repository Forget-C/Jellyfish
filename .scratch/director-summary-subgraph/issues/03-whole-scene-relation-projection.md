# 03: 全场关系视图投影与追溯

**What to build:** 用户切换到全场关系视图时，看到与子图同源的完整设计对象关系；被汇总的成员以“全场概览”代表，跨组连线仍可逐条核对真实来源。

**Blocked by:** 02: 完整成员与子图关系

**Status:** ready-for-agent

- [ ] 全场关系视图和子图使用当前场次版本同一份真实设计对象引用集合；全场关系视图补显示此前因只汇总镜头关系而遗漏的真实设计对象引用，不新增业务引用。
- [ ] 全场关系视图压缩已归组成员，并把跨组真实关系投影到汇总卡；组内关系留在子图。默认镜头视图继续只显示当前镜头关系，不混入其他镜头的边。
- [ ] 汇总边可展开原始对象、方向、标签、引用者和来源字段；只有外部端点、方向、关系语义及当前视图的直接／间接状态都一致时才合并。
- [ ] 同端点、不同标签的投影边可分别聚焦和查看，路径不完全重叠；入向关系、缺失引用和不同组之间的边均保留正确身份，不把设计对象关系画成执行顺序。
- [ ] 原文、场所与项目资产、生产单元沿用已有入口；验证全场与子图对同一真实引用的对应关系、镜头视图原有线型与筛选、关系查看的键盘操作，并运行相关前端检查。
