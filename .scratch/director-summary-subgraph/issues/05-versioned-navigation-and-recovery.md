# 05: 视图记忆与导航闭环

**What to build:** 用户在外层、全场关系视图和子图之间往返、定位组外对象及切换镜头或场次版本时，始终回到正确的对象与视口；失效目标有明确提示，不误指另一张卡。

**Blocked by:** 03: 全场关系视图投影与追溯；04: 子卡片侧栏编辑

**Status:** ready-for-agent

- [ ] 每个场次版本分别记住默认镜头外层、全场关系视图和子图的有效位置、缩放及焦点；返回恢复原外层现场，重新下钻恢复子图现场。切换版本只恢复目标版本的记忆，若无记忆则进入其默认外层视图。
- [ ] 子图始终为整场范围：在子图内切换当前镜头只更新选择，返回后显示新镜头的外层关系，不重建或跳动画布；无镜头时仍能浏览整场成员。
- [ ] 点击边界节点的“在外层定位”先返回外层并定位原设计对象；默认镜头视图若隐藏目标，则切到全场关系视图，保留当前镜头选择；目标属于另一汇总组时定位其汇总卡，不自动连续下钻。
- [ ] 浏览器前进／后退、下钻动效、侧栏和未保存内容保护协同工作；视图操作不保存或更改业务内容。键盘焦点可见，减少动画偏好不阻断导航。
- [ ] 版本切换、引用变化或对象删除后不自动重绑失效定位；角色情境、镜内活动等无持久 ID 的数组项仅在可无歧义识别时恢复位置与焦点，否则清除并提示“原对象不可用”，不按新数组下标误指。
- [ ] 覆盖桌面与窄屏、边界目标被隐藏、重复无 ID 行、删除／重排、浏览器历史、未保存草稿及多版本往返；完成相关浏览器回归与前端类型检查。
