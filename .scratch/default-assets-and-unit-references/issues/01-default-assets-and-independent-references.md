# 01: 默认资产与单元选材解耦

Status: ready-for-agent
Blocked by: None (can start immediately)

**What to build:** 创作者可先建立人物／物件设计，再为单元独立选择实际参考。导演的关联只提供默认候选；无默认、默认不同或存量默认失效时，合法的单元参考仍可保存、检查并进入生成预检。导演入口以“设置默认资产”明确这一职责。

**依据：** [实现规格](../spec.md)。主要覆盖用户故事 5、11–23、39、49，以及故事 7 的导演详情与保存边界；承接故事 38、50 的相关校验。

## Acceptance criteria

- [x] 人物、物件及场所的默认资产均为可选关联。既有参与对象没有默认时，仍可选择当前项目内可用资产的具体素材；默认 A 时选择 B，保存回读及实际输入均保留 B。
- [x] 选择其他资产不将参考的目标对象切换成该资产原先关联的人物／物件，不自动新建对象、修改镜头参与名单或回写导演默认及其他单元。
- [x] 默认候选按当前单元全部覆盖镜头中的明确参与对象及本场场所产生，并按对象身份去重。明确空名单保持为空；范围未知时提示补全，不从背景文字、默认或其他工作单推断参与者。
- [x] 其他可用项目资产仍可手动选择，已有文件与上传入口继续可用。候选无默认、无图片或失效时均有真实状态，不阻断独立选材。
- [x] 打开页面、默认变化、切换资产，以及资产仅含一张图片，均不自动选图。候选数量、已选数量与真实准备缺项分别表达，候选不能计入模型输入或消除缺项。
- [x] 只切换资产而未明确选入并应用素材，不持久化单元资产选择；再次打开允许回到默认候选，不新增单元默认配置层。
- [x] 修改或解除导演默认不替换、删除或否定已选参考；已应用的参考只更新目标单元。实际引用与设计默认关联分别展示，不将当前场次关联列表描述成项目实际使用统计。
- [x] 导演资产操作及标题使用“设置默认资产”，目标由对象上下文表达；沿用右侧非模态详情、当前手动／自动保存及只读行为，保留已有未保存输入。
- [x] 保存和执行不再要求参考来源属于设计关联集合或等于目标对象默认；这一行为同时覆盖场次设计校验、参考来源校验、人工保存、指令准备／应用／依据核对、检查、单次及批量生成预检。
- [x] 存量失效默认保持可识别并显示不可用，只影响候选。目标对象或无关对象的失效默认，均不能独立阻断其他合法内容的保存、指令检查或生成准备。
- [x] 新增或改选默认仍核实当前项目归属与可用性，拒绝无效及越权资产并保留原内容。AI 设计原样保留无关存量失效默认可通过，但新增／变更的伪造或无效默认仍被拒绝。
- [x] 新选择素材仍校验真实资产、项目归属、文件访问、媒体类型，以及文件确实属于声明资产；项目权限及其他真实设计约束保持有效。
- [x] 仅默认偏好变化不使本来有效的当前指令依据／检查失效，也不恢复此前失效或未确认的状态；实际参考变化仍触发既有依据和检查核对。
- [x] 对外保存与参考语义变化同步接口说明、OpenAPI 和 generated client，生成前确认后端加载当前工作区；前端沿用 generated client。实现后修订已不准确的默认关联与参考使用说明。

## Validation

- 通过真实场次版本 HTTP 和数据库事务，覆盖无默认、A 默认选 B、默认修改／解除、同单元及无关对象默认失效、跨单元隔离；保存后重新读取，核对对象身份、来源、默认与实际输入。
- 在同一集成边界覆盖人工保存、指令准备／应用／依据／检查及单次／批量生成预检，不能只测选择器。比较“仅默认变化”和“实际输入变化”对有效及已失效检查的不同结果。
- 覆盖人工与 AI 的无效新增默认、原样保留失效默认、越权资产、伪造来源、文件不属于资产及不合规媒体；失败不得覆盖已保存内容。模型调用使用受控替身，不调用付费服务。
- 通过真实导演与单元画布浏览器流程验证候选范围、明确空与未知名单、无图／单图／失效候选、切换未应用、保存回读和导演详情命名；确认没有自动选图、对象偷换或未保存输入丢失。
- 运行受影响契约、集成和浏览器测试，完成前端类型检查及相关工作台组件、四画布样式与设计完整性回归；后端应用改动完成 Pylint。共享校验变更按影响范围扩展测试，记录必要检查的结果及局限。

## Scope and handoff

本票交付从候选、选择到保存及执行校验的完整解耦行为，复用既有场次业务存储和工作台组件。API 负责鉴权、收参和响应，业务存储负责规则；不通过放宽全部设计或文件校验实现解耦。

来源资产消失后的既有引用例外由 [02](02-fixed-reference-source-lifecycle.md) 负责；主体分组与存量整理由 [03](03-identity-groups-and-existing-data-cleanup.md) 负责。本票不引入新默认层、项目使用统计或历史无消费范围回执迁移。[05](05-card-actions-and-reference-entry.md) 可独立进行，导演“设置默认资产”的语义与命名归本票。
