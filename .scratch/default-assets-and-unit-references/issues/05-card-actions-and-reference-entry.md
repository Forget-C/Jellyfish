# 05: 卡片入口精简与动作横排

Status: ready-for-agent
Blocked by: None (can start immediately)

**What to build:** 用户直接激活卡片即可进入相应内容，卡面只保留独立业务动作并横排换行。单元参考卡直达“编辑参考素材”管理弹窗，先展示已选内容；鼠标、触摸、键盘和只读查看均保留完整能力。

**依据：** [实现规格](../spec.md)。主要覆盖用户故事 1–4、6、8–10、50，以及故事 7 的参考弹窗与应用边界。

## Acceptance criteria

- [x] 对打开相同编辑内容的普通对象卡，移除重复“编辑此卡”。整卡激活仍打开原内容，不批量改动其他不同语义的卡片动作。
- [x] 卡片保留悬停反馈、可见键盘焦点、Enter／Space 激活与触摸入口；只读／不可用状态清楚，原有阅读能力不因删除按钮而消失。
- [x] 子图进入、引用定位、标题拖动及卡内独立按钮保持各自语义；事件互不串触发，一次独立动作不能同时打开编辑或触发两次入口。
- [x] 卡片底部多个动作默认横向排列，空间不足自然换行；保持完整文案与点击尺寸，不强制单行、压缩目标或产生重叠和横向溢出。
- [x] 单元参考操作、相关标题使用“编辑参考素材”。参考卡整卡点击及键盘激活直接打开现有参考管理弹窗，移除通往同一内容的重复卡面编辑按钮及额外只读中间入口。
- [x] 管理弹窗先展示已选素材，再按需进入添加或更换；没有参考时展示真实空态与候选入口，不能仅因打开管理而自动加入素材。
- [x] 只读场景直接进入可阅读的参考管理内容，但不能应用修改；入口及标题结合业务上下文表达当前单元与状态。
- [x] 参考选择沿用弹窗明确应用边界，普通对象字段沿用右侧非模态详情和当前保存机制；不把两者强制改成同一种容器。
- [x] 开合、展开、切换、应用／取消及后台刷新不移动或缩放画布、不重排卡片，不丢失滚动位置或现有未保存输入。
- [x] 复用工作台共享按钮、详情、弹窗、动作区及主题；保留正确焦点进入和关闭恢复、内层 Escape 优先、门户主题及窄屏行为，不能污染工作台外页面。
- [x] 界面变化同步已不准确的参考卡入口与工作台操作说明；不把未实现的默认解耦或来源替换行为写成当前事实。

## Validation

- 使用真实导演与单元画布浏览器流程，逐一验证鼠标、Enter、Space、触摸及只读入口，确认普通卡原编辑目标不变，参考卡直接打开管理且无重复按钮。
- 验证已选优先、空态、添加后应用、取消、只读阅读与保存回读；以既有管理能力即可验收本票，不能依赖后续 03、04 才使原流程可用。
- 回归子图、引用定位、卡内独立动作与标题拖动；断言没有双触发、误编辑、视口缩放、布局重排或未保存输入丢失。
- 在桌面与 390px 窄屏检查横排换行、完整文字、点击尺寸、无重叠及无横向溢出；验证焦点恢复、嵌套 Escape、门户主题和非工作台页面隔离。
- 完成前端类型检查、相关工作台组件、四画布样式与设计完整性回归，并记录真实浏览器验收及无法完成的必要检查。本票不要求无关后端或付费模型测试。

## Scope and handoff

本票无前置，可与 01–04 并行。导演“设置默认资产”的语义及命名由 [01](01-default-assets-and-independent-references.md) 负责；本票只按既有行为整理卡片和管理入口，保持参考选择与保存契约。

来源规则、存量整理和显式整组替换分别由 02–04 交付。若 [04](04-replace-identity-reference-source.md) 已落地，集成时保留它的更换入口和取消／并发保护；若尚未落地，本票不得用占位行为冒充更换来源。变更限于涉及的工作台卡片，不做全站控件重构或通用配置抽象。
