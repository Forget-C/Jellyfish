# 05: 从卡片引用入口定位来源

Status: ready-for-agent
Resolution: completed
Blocked by: 04
User stories: 35, 36, 37, 38, 39, 40, 63

**What to build:** 用户点击提取卡底部“引用”，通过共用浮窗定位原文、设计卡或其文本片段。

- [x] 所需卡片共用浮窗，无来源不占空间，只展示必要索引信息。
- [x] 同画布定位能展开遮挡结构并打开对应字段／文本；Unicode 变化或证据不再匹配时降级提示，目标删除显示失效项，不猜测替代目标。
- [x] 来源索引不加入生成输入，不改变普通点击或诊断导航。
- [x] 通过实际提取结果验证保存后定位、键盘操作、Escape、窄屏与失效提示。
- [x] 文本验证覆盖中文、换行及非 BMP 字符；章节出处通过固定原文卡承接，不扩展跨画布导航或全文阅读系统。

## Testing Decisions

实际提取来源经公开 API 保存重开，浏览器验证卡片／字段／文本定位、折叠目标、内容变化及删除；覆盖键盘、焦点和窄屏。

遵循[主规格](../spec.md)已确认的测试边界：真实浏览器和服务端公开接口，只替换外部 LLM 与媒体供应商；保留真实保存、引用校验、编译与任务状态，使用隔离数据，不以真实付费生成为自动测试前提。接口、类型检查及受影响回归按项目规范执行。

## Scope

本票属于[已确认的票据拆分](../ticket-breakdown.md)。ready-for-agent 保留为分诊状态，实施结果记录在 Resolution 与验收记录。共同基础只实施已批准扩展；新的必要基础行为变更须先说明影响并确认。首版不做存量迁移、新增兼容逻辑、整画布复制、批量或自动媒体执行、新产物接入旧下游及旧代码清理。默认入口仅在 12 验收后切换。
