# 11: 后台任务、离页完成与失败恢复

Status: ready-for-agent
Resolution: completed
Blocked by: 10
User stories: 52, 53, 54, 55, 63

**What to build:** 用户提交提取后可以关闭操作容器或切走；返回时可查看真实进度、候选结果与恢复入口。

- [x] 关闭容器不取消任务；仍在原等待流程才自动进入首次结果，已经切走则只提示完成和查看入口，不抢导航或焦点。
- [x] 展示真实阶段、失败原因及重试，不使用虚构百分比；任务和保存回执未知时沿用幂等与恢复能力，不重复建卡或覆盖人工编辑。
- [x] 受控任务时序验证切走完成、后台失败、任务期间编辑转差异、冲突及恢复；已有对象准备和画布内容不丢失。
- [x] 两入口同时编辑、切换画布、提交或保存回执未知均纳入恢复用例；重试不重复创建画布、任务或应用结果。
- [x] 键盘、对话框焦点恢复及窄屏操作使用已有共享规则；验证持久文档和可观察导航，不只验证 UI 假状态。

## Testing Decisions

控制外部响应时机，真实浏览器和公开接口复现离页、后台失败、迟到结果、回执未知及并发编辑；验证焦点、导航和持久结果，不替换内部保存或任务状态。

遵循[主规格](../spec.md)已确认的测试边界：真实浏览器和服务端公开接口，只替换外部 LLM 与媒体供应商；保留真实保存、引用校验、编译与任务状态，使用隔离数据，不以真实付费生成为自动测试前提。接口、类型检查及受影响回归按项目规范执行。
