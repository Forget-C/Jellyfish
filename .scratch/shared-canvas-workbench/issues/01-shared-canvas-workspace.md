# 01: 抽取共同画布工作区，保持自由生成行为

Status: ready-for-agent
Resolution: completed
Blocked by: None
User stories: 1, 2, 5, 6, 7

**What to build:** 自由生成入口通过可复用工作区完成原有创建、编辑、保存、预检及单卡运行，宿主只保留列表与导航责任。

- [x] 抽取现有真实编辑及执行组合，不复制整页、不创建第二套保存或运行状态。
- [x] 普通画布的字段编辑、引用删除保护、冲突、恢复、撤销、编译和运行结果行为不变。
- [x] 用现有浏览器与公开接口流程回归保存重开、引用与单卡运行；共同基础影响面按项目要求扩展验证。
- [x] 共同工作区不要求章节／场次上下文，不引入通用页面配置平台；原宿主和路由保持可用。

## Testing Decisions

复用现有画布 API、浏览器编辑及运行 journey，对比抽取前后可观察行为；共享基础变更扩展受影响回归。

遵循[主规格](../spec.md)已确认的测试边界：真实浏览器和服务端公开接口，只替换外部 LLM 与媒体供应商；保留真实保存、引用校验、编译与任务状态，使用隔离数据，不以真实付费生成为自动测试前提。接口、类型检查及受影响回归按项目规范执行。

## Scope

本票属于[已确认的票据拆分](../ticket-breakdown.md)。ready-for-agent 保留为分诊状态，实施结果记录在 Resolution 与验收记录。共同基础只实施已批准扩展；新的必要基础行为变更须先说明影响并确认。首版不做存量迁移、新增兼容逻辑、整画布复制、批量或自动媒体执行、新产物接入旧下游及旧代码清理。默认入口仅在 12 验收后切换。
