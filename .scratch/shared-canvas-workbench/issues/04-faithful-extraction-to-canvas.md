# 04: 忠实提取到可编辑画布的首条完整路径

Status: ready-for-agent
Resolution: completed
Blocked by: 03
User stories: 2, 19, 26, 29, 30, 31, 33, 34, 41, 42, 43, 45, 51, 52, 55, 64

**What to build:** 从准备页明确提交忠实提取，将简单场次的明示设计直接建立为可编辑、可保存的真实共同画布。开发验证先贯通这一窄路径，不提前改变最终默认模式。

- [x] 冻结原文、对象、目标画布基线及所选模型；复用现有设计任务能力，最多一次纠错，非法结构、来源或范围不应用。
- [x] 程序生成真实卡片身份、来源索引、实际采用关系和公共区／镜头分组；共享对象不重复，漏提对象可形成空参考，未选模型保持待配置。
- [x] 明示事实与未知保持准确；新增显式提取编辑上下文，人工编辑保留状态、用途和来源，分别识别提取创建与人工修改；普通字段含已有模型来源字段保持原行为。
- [x] 有效初次结果整批应用且可撤销；如果基线已改变，保留候选并显示待应用，绝不覆盖新编辑。差异应用操作由 10 补齐。
- [x] 从真实提取接口到浏览器中的卡片编辑、保存重开、撤销及模型输入预检完成验证；不靠直接写入最终画布替代流程。
- [x] 本票覆盖直接适用镜头的设计与简单模型配置；复杂阶段与分段的闭环由 07 承担，不能把不支持的结果伪装为成功。
- [x] 来源索引独立于实际输入绑定，支持稳定卡片、字段／阶段／片段、文本区间与校验依据；记录采用的任务、模式和原文证据，不能以最后编辑者判断创建来源。
- [x] 提取内容的正文、引用和结构化字段编辑均保留提取语义，允许用户明确调整状态／用途；序列化、保存、展示及编译输出一致。
- [x] 结果可作为任务记录保存，但不另存一份可编辑设计或创建旧版本；范围或来源错误不能靠静默删掉重要设计或伪造出处通过校验。
- [x] 引用候选不等于真实采用；空参考不绑定不存在的媒体。公共区和镜头组使用真实尺寸排列，普通画布整理行为保持不变。

## Testing Decisions

以简单场次从真实提交到卡片编辑、保存重开、预检与整批撤销贯通验证；覆盖未知字段、无模型、漏对象、非法来源、有限纠错及基线改变。对照普通字段原有编辑与输出行为。

遵循[主规格](../spec.md)已确认的测试边界：真实浏览器和服务端公开接口，只替换外部 LLM 与媒体供应商；保留真实保存、引用校验、编译与任务状态，使用隔离数据，不以真实付费生成为自动测试前提。接口、类型检查及受影响回归按项目规范执行。

## Scope
