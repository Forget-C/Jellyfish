# 07: 复杂范围和生产分段正确落到模型输入

Status: ready-for-agent
Resolution: completed
Blocked by: 06
User stories: 28, 29, 30, 41, 42, 43, 64

**What to build:** 多镜头、不同阶段或条件的设计，经确定性拆卡和按需生产组织后，模型卡只采用适用内容。

- [x] 需要时改进复用现有生产单元组织能力；真实模型、端口、文件和坐标仍由程序确定，不新增模型自动选型或媒体自动执行。
- [x] 拆卡保留内容、原因、状态、用途、来源、顺序和时长，重映射引用及画面目标，不复制唯一镜头／节拍身份。
- [x] 以代表性复杂样本从提取到画布再到预检输入逐项验证，包括依赖闭包，不能只看直接连线或文本仍在。
- [x] 范围落实为显式采用，普通保存不按范围文字重连；布局扩展只用于工作台初始化。
- [x] 隔离夹具覆盖已核对样本中两镜头、129 项设计及 122 项适用性声明的代表复杂度；逐项核对语义与来源，禁止以 JSON 可序列化或仅保留文字证明无损。
- [x] 复杂分段按真实所选模型能力组织，不默认增加每镜头额外调用；拆卡后的连续性关系与画面目标仍有效。

## Testing Decisions

以隔离复杂样本经提取、组装、公开保存与真实编译验证模型输入和依赖闭包；浏览器核对镜头顺序、分组及共享对象，密集异常可补公共契约测试。

遵循[主规格](../spec.md)已确认的测试边界：真实浏览器和服务端公开接口，只替换外部 LLM 与媒体供应商；保留真实保存、引用校验、编译与任务状态，使用隔离数据，不以真实付费生成为自动测试前提。接口、类型检查及受影响回归按项目规范执行。
