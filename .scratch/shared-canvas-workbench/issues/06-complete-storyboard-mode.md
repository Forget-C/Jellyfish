# 06: 增加完整分镜模式并设为默认

Status: ready-for-agent
Resolution: completed
Blocked by: 04
User stories: 25, 26, 27, 28, 64

**What to build:** 用户在生成配置中选择两种模式，默认自动产出完整分镜；生成后可直接检查和编辑事实、建议及待定设计。

- [x] 一个流程入口复用分镜与六部门设计能力；不新增六个部门 Agent、布局 Agent 或常驻审稿 Agent。
- [x] 完整模式补充适用设计但不把补写当原文事实；忠实模式仍只提取明示内容，不强求所有类型或字段都有值。
- [x] 两种模式均贯通真实任务、校验、建卡及编辑保存；纠错耗尽保留现有画布并明确失败。
- [x] 使用已准备对象身份，新增对象明确标为补漏；正常生成、一次纠错成功、纠错耗尽及供应商失败均可区分，不只测试提示词文本。
- [x] 配置同时保留可修改的默认画布名及可待配置的生产模型；缺参考不阻止文本分镜。

## Testing Decisions

从模式选择、任务固定输入、真实校验到卡片内容及保存重开验证两模式差别；验证默认值、纠错和失败不覆盖。

遵循[主规格](../spec.md)已确认的测试边界：真实浏览器和服务端公开接口，只替换外部 LLM 与媒体供应商；保留真实保存、引用校验、编译与任务状态，使用隔离数据，不以真实付费生成为自动测试前提。接口、类型检查及受影响回归按项目规范执行。

## Scope
