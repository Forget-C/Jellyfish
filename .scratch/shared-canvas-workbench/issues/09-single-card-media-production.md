# 09: 从提取画布继续单卡图片／视频生产

Status: ready-for-agent
Resolution: completed
Blocked by: 08
User stories: 24, 30, 55, 56, 57, 58

**What to build:** 用户在提取画布中预检并明确执行一张模型卡，查看结果和运行历史。

- [x] 空创作参考使用现有卡片状态提示，用户确认后可省略缺失媒体继续；硬性输入、失效绑定及能力错误仍阻断。
- [x] 只执行当前模型卡，不补跑上下游、不默认选择模型；文本提取不授予媒体执行权限。
- [x] 复用当前运行、固定输入、结果与历史；用受控外部供应商验证真实 HTTP 和浏览器图片／视频生产流程及失败行为。
- [x] 未配置生产模型可保存但不得标为就绪；选定后按真实能力配置和预检，禁止用忽略警告绕过硬错误。
- [x] 从公开请求、Worker、运行结果到历史展示验证实际链路；候选连线和提取完成都不能触发其他媒体任务，普通画布单卡行为保持原状。

## Testing Decisions

复用公开 HTTP 文本→图片→视频 journey 及受控供应商浏览器宿主，保留真实任务状态、预检、编译和结果处理；核对警告、阻断与用户明确授权。

遵循[主规格](../spec.md)已确认的测试边界：真实浏览器和服务端公开接口，只替换外部 LLM 与媒体供应商；保留真实保存、引用校验、编译与任务状态，使用隔离数据，不以真实付费生成为自动测试前提。接口、类型检查及受影响回归按项目规范执行。
