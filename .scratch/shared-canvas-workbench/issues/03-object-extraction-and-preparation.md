# 03: 提取场次对象并准备参考

Status: ready-for-agent
Resolution: completed
Blocked by: 02
User stories: 11, 15, 16, 17, 18, 19, 55

**What to build:** 用户从准备页启动对象提取，在分类列表中关联资产、上传或选择参考图，并明确操作现有参考图生成能力。

- [x] 复用任务执行器，拆出前置对象语义能力；稳定对象身份及真实资产归属由程序校验，不按同名盲目合并。
- [x] 展示缩略图、名称、关联和参考状态；不引入对象准备画布，不自动启动图片或视频。
- [x] 缺图不阻止后续分镜；对象提取结束停留在准备页，后续阶段仍需用户明确操作。
- [x] 从真实任务提交到结果列表、资产关联及重开完成验证；失败保留已有准备，非法关联被拒绝。
- [x] 未关联对象保留独立身份，不编造资产或文件；支持关联已有资产、新建关联及复用既有资产编辑。
- [x] 准备页明确场次候选与画布已采用参考的区别；更新候选不自动改写已有画布。

## Testing Decisions

公开任务提交与受控 LLM 响应验证对象提取；真实资产／文件校验配合浏览器准备操作，覆盖同名不同身份、非法关联、失败保留与缺图继续。

遵循[主规格](../spec.md)已确认的测试边界：真实浏览器和服务端公开接口，只替换外部 LLM 与媒体供应商；保留真实保存、引用校验、编译与任务状态，使用隔离数据，不以真实付费生成为自动测试前提。接口、类型检查及受影响回归按项目规范执行。
