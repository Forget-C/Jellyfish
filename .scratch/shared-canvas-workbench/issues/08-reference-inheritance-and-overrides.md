Status: ready-for-agent

**What to build:** 对象参考被各画布独立采用；用户可修改画布默认参考或单个镜头的特殊参考。

- [x] 只有出现该对象的镜头继承参考；镜头独立指定优先，更换默认仅更新仍继承者。
- [x] 两画布共用文件不等于共享可变配置；漏提对象与空参考可人工补齐。
- [x] 通过真实编辑、保存重开和预检核对实际绑定；方案间不串改，已有媒体及运行固定依据保持不变。
- [x] 关联依赖稳定对象身份，不按显示名称匹配；默认参考变化仅影响当前准备，不改写旧执行依据或既有素材。

## Testing Decisions

真实界面及公开 API 操作两个画布和多个镜头，对比默认更新前后的实际绑定与预检输入，验证局部覆盖、空参考补齐及既有运行依据不变。

遵循[主规格](../spec.md)已确认的测试边界：真实浏览器和服务端公开接口，只替换外部 LLM 与媒体供应商；保留真实保存、引用校验、编译与任务状态，使用隔离数据，不以真实付费生成为自动测试前提。接口、类型检查及受影响回归按项目规范执行。
