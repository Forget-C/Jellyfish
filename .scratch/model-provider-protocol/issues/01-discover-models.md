# 01: 通过供应商协议发现和选择模型

**What to build:** 管理员在模型管理页选择供应商配置后，可以浏览模型目录，也可以直接绑定目录外的型号。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 模型管理页和 API 通过 ModelProvider 的 list_models 获取模型 ID 和目录来源，可分别用远端目录和内置目录完成选择。
- [ ] 手动填写目录外的模型 ID 可以保存、重新读取并用于后续能力查询。
- [ ] 注册表按接入方式和操作解析适配器，绑定所选配置并注入共享 HTTP 客户端。未知接入方式返回可识别的配置错误。
- [ ] 用可控的目录响应验证发现和绑定，回归既有型号的调用入口，确认引入注册表后仍可执行。
