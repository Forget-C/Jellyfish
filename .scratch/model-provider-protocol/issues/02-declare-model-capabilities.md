# 02: 按配置和操作声明模型能力

**What to build:** 管理员可以为同一型号在不同网关配置下分别维护能力，并从管理页面和 API 查看手动声明、内置默认、来源及最终生效的值。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 按配置、模型 ID 和操作保存声明，describe_model 返回对应的有效能力。布尔项可选支持、不支持或未知，未填写的数值保留未知。
- [ ] 文本表单区分输入和输出模态、最大输入和输出 token 数、非流式和原生流式。工具与结构化输出字段覆盖工具调用和结果回传、流式参数、并行工具、JSON 对象和 JSON Schema。
- [ ] 按适配器操作展示可编辑字段及交付方式。声明可补充、收窄或覆盖内置默认值，有效范围受适配器实际编码和解析能力约束。用一个声明超出适配器范围的例子验证页面和 API 的结果一致。
- [ ] 用两个配置绑定同一型号，验证修改其中一个的声明只影响该配置。保存新的 Base URL 后保留绑定和声明，新调用使用新地址。
- [ ] 保存端点不检查历史数据，不发起风险提示、自动探测或复核阻断。通过上游请求记录验证，真实能力验证只由用户主动触发。
- [ ] 未知能力的兼容型号仍可用于普通文本。要求工具能力的自动流程可以从查询结果区分有效支持与未知。
