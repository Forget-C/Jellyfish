# 05: 声明图片能力并完成同步出图

**What to build:** 管理员声明各图片操作可接受的参数，生成用户通过既有任务入口提交合法请求并按供应商顺序取得图片。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 表单区分文生图、参考图生成及编辑，可按模式设置尺寸、分辨率、宽高比、出图数、参考图数、seed 和水印。
- [ ] 页面、预检与发送前使用同一组有效能力规则。对不支持的模式、参考图数量或参数组合给出一致的字段或组合诊断，上游收到零次生成请求。
- [ ] 迁移 OpenAI 与火山引擎既有的直接返回图片操作，复用适用的媒体输入及请求解析逻辑，经注入的共享 HTTP 客户端发送请求。公共调用保持异步，调用结果直接包含图片。
- [ ] 从任务入口用受控响应覆盖参考图编辑、URL 和 Base64 两种结果形式，核对多图数量、顺序及归档。
