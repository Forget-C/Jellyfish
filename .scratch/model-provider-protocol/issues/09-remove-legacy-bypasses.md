# 09: 移除旧调用旁路并完成跨入口回归

**What to build:** 完成所有业务调用方的迁移，统一由供应商协议决定模型有效能力并执行请求，原有业务入口继续完成各自的工作流。

**Blocked by:** 04, 07, 08

**Status:** ready-for-agent

- [x] 核对画布、实验室、Agent、脚本和生成任务的实际调用点；能力判断归入供应商层，工具执行、审批和产物采用仍由业务使用方负责。
- [x] 在相应入口通过回归后移除过渡模型工厂旁路和重复 HTTP 实现。验证未知供应商返回配置错误，避免回退到火山引擎等其他供应商。

- [x] 从 Agent 入口回归同步、异步、流式、并行工具往返与结构化输出。三个入口均使用供应商边界的可控响应完成验证，无需真实付费调用。
