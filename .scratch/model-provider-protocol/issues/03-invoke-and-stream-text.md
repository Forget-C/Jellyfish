# 03: 通过统一协议完成文本调用与原生流式输出

**What to build:** 画布或实验室可以通过同一个异步供应商接口获取完整文本回复，或在回复生成时逐段消费原生事件。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] invoke 接受现有文本消息、多模态输入及适用的模型参数，返回完整回复、工具调用、结束原因和供应商提供的用量。供应商协议独立于业务和 LangChain。
- [ ] stream 以异步迭代交付上游增量、结束或错误事件。用受控事件确认首个增量可在上游结束前读到，关闭消费只终止本地等待。
- [ ] 交错发送两个工具调用的参数片段，调用方能按调用 ID 还原参数并传回各自的工具结果。工具执行和审批由调用方负责。
- [ ] 通过普通调用和流式入口核对发往兼容网关的地址、消息及参数，验证更新 Base URL 后的新请求使用新地址。
