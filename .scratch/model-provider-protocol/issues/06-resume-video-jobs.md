# 06: 用视频任务贯通条件校验、提交和断点续查

**What to build:** 选取一个已支持的远端视频操作，贯通能力录入、请求校验、单次提交和 Worker 重启后的结果归档。可优先使用 Vidu。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 视频表单区分文生、首帧、首尾帧、关键帧和主体参考。按模式和分辨率设置时长及宽高比，声明参考素材类型、数量及组合，分别描述音频参考输入、原生音轨输出和音轨开关。
- [ ] 同一模式在 720p 允许 5～15 秒（含端点），在 1080p 只允许 5 或 10 秒。验证端点、区间外值，以及 8 秒在两种分辨率下分别通过和拒绝。页面、预检和提交诊断一致，拒绝时没有上游生成请求。
- [ ] invoke 受理后返回远端任务引用，Worker 保存引用及冻结配置并调度 poll，每次 poll 只查询一次。调用方自行决定是否等待。
- [ ] 受理后更新 Base URL 并重启 Worker，仍使用原配置和引用查询并归档。用请求计数验证查询暂时失败后只重试查询。
- [ ] 模拟发送提交后断线且未取得引用，任务保留提交结果未知的状态，恢复流程不会自动重复创建。
