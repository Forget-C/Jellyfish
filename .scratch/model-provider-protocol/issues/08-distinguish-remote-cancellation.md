# 08: 让远端任务取消结果可区分

**What to build:** 用户停止等待或请求取消时，可以从任务页面和 API 判断上游是否支持取消、是否已受理以及是否已确认取消。

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] 按操作公开远端取消有效能力。对不支持取消的操作返回明确结果，上游收到零次取消请求。
- [ ] 对支持的操作，cancel 使用既有任务引用。用受控响应分别验证取消请求已受理、后续查询确认已取消，页面及 API 仅在确认后显示远端已取消。
- [ ] 停止本地等待或关闭流时，远端状态保持可查询，页面和 API 不将该动作记为供应商确认取消。
