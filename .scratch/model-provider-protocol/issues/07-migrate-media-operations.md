# 07: 将其余异步图片和视频操作迁入协议

**What to build:** 把其余已接入的异步媒体操作逐项迁入供应商协议，使既有生成任务沿用各供应商自己的请求和交付规则。

**Blocked by:** 05, 06

**Status:** ready-for-agent

- [ ] 按现有供应商和操作列明迁移覆盖。仅在请求、认证和响应格式兼容的操作上复用适配器，独有协议显式注册。
- [ ] 通过任务入口和受控 HTTP 响应核对既有操作的端点、认证、请求字段及超时处理，并验证已知能力限制能在发送前被校验。
- [ ] 覆盖任务 ID、进行中和终态映射，以及适用的结果下载请求头、URL 或 Base64 交付。多结果的数量和顺序与既有行为一致。
- [ ] Worker 能以原引用恢复各已迁移任务。每项操作通过回归后收敛对应的重复请求路径，同一次生成只发送一次创建请求。
