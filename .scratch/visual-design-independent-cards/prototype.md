## 已选 A 与本轮调整

- 连续 Modal 表面：移除标题、底部及左右栏的硬分隔线，压缩间距与重复标题。
- 移除顶部“管理关联”按钮及展开管理区；“＋”沿用模型卡添加入口，候选查看使用浮层，不推挤主体。原型仅当前画布候选可添加，上传与素材库暂禁用。
- 桌面左侧图库独立滚动，右侧详情、标题、候选和底部固定。展开变更明细替换右侧预览，超长明细可局部滚动；高级设置及窄屏内容独立滚动。
- Node 24 typecheck、差异空白检查通过；Chrome 1440×900、1280×640、390×844 检查通过。小高度窗口图库滚动 130px 时，其他固定区域坐标不变。
- 六类详情、预设应用、候选添加／查看、真实 @ 插入、浮层 Escape 与窄屏操作区已检查；无页面脚本错误或业务 API 请求。
- 当时补拍了 9 张 A-refined 截图。B／C 仅用于历史比较，正式实现的验证见[最终审查](review.md)。
