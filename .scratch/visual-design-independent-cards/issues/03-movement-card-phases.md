# 03: 独立运镜卡与稳定阶段

Status: ready-for-agent
Blocked by: 01

**What to build:** 创作者独立配置运镜方式、起始与结束画面、触发条件、路径、速度和明确阶段，并把完整运镜设计交给模型。

依据：[规格](../spec.md)、[共同执行约定](README.md)。前置票据：[01](01-style-preset-modal.md)。覆盖用户故事：1–17、29、38、44–48、51。

## 验收标准

- [ ] 运镜入口创建独立类型，目录、保存、摘要及输出均不依赖隐藏的完整摄影卡；拒绝其他设计卡字段及新契约中的局部采用范围。
- [ ] 默认使用 A 预设图库，展示对应运镜示意；示意不被宣称为当前真实生成结果。应用、部分合并、完整撤销和高级设置共用同一份数据。
- [ ] 高级设置直接展示所属运镜参数及阶段配置，无更多参数、摄影分区或独立正反例。
- [ ] 阶段可新增、编辑、重命名、重排和删除；阶段身份与名称、数组位置分离，重命名和重排不改变身份，删除后不复用原身份绑定另一阶段。
- [ ] 创建多个运镜实例、复制、保存刷新和重新打开均保留正确的内容与阶段关系；副本独立编辑不改变原卡。
- [ ] 真实输出包含有效运镜内容、起始／结束画面及明确阶段的稳定标识；空白、不适用及其他字段状态遵循规格，不虚构有效画面。
- [ ] 模型明确整卡采用后能够编译完整运镜设计，不提供逐阶段采用；多画面的图片目标歧义在 09 接入前不得静默按首项或数组位置消解。
- [ ] 只读及长阶段列表下，阶段内容仍可阅读、固定操作区可达；完成[共同完成条件](README.md#共同完成条件)。

## 验证路径与范围

通过真实运镜页面与公开保存／编译接口，验证预设、手动阶段、重排、删除、复制和刷新后的输出身份。复用摄影画面状态与公开编译测试；阶段身份断言依据公开输出，而非组件内部结构。

跨卡构图定位、图片目标选择与相关冲突诊断由 09 完成。为 09 提供稳定公开画面状态，不提前引入设计正文互引。
