# 04: 独立景别与构图卡

Status: ready-for-agent
Completion: resolved
Blocked by: 01

**What to build:** 创作者独立填写构图文字和结构化景别，使用构图预设，在保存后由模型整卡采用设计。

依据：[规格](../spec.md)、[共同执行约定](README.md)。前置票据：[01](01-style-preset-modal.md)。覆盖用户故事：1–17、29、38、44–48、51。

## 验收标准

- [x] 构图入口创建独立类型，具有自己的保存契约、摘要及设计输出；不再打开完整摄影卡的某个分区。
- [x] 参数保留景别、构图重心、画面位置、空间层次、留白、构图要求及已有结构化景别能力；拒绝混入机位、运镜等其他类型字段。
- [x] 复用 A 预设优先界面与现有构图预设；文字参数及结构化景别都可在高级设置直接编辑并保存，无额外 Tab 或更多参数入口。
- [x] 可组合应用只声明部分字段的预设；未涉及文字和结构参数保留，填写／覆盖明细准确，一次撤销恢复整次修改。
- [x] 多张构图卡独立创建、编辑、复制和删除；保存刷新后文字、状态、用途与结构化景别保持一致。
- [x] 真实编译保留有效文字与结构化景别要求，模型只支持明确整卡采用；不按字段过滤输出，不自动关联运镜或猜测目标阶段。
- [x] 只读、保存失败、预设／高级切换、长内容与窄屏行为复用 01，提供该卡截图和交互证据；完成[共同完成条件](README.md#共同完成条件)。

## 验证路径与范围

复用构图相关摄影保存／编译用例和真实设计页面，执行预设 → 修改文字与结构化景别 → 保存刷新 → 模型采用；覆盖字段越界、部分预设组合和实例隔离。

跨卡定位与画面阶段相关硬冲突由 09 完成。本票无需等待 03，不新增临时默认关联。
