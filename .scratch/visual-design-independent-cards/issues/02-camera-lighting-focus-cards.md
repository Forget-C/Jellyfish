# 02: 独立机位、光影、焦点三类设计卡

Status: ready-for-agent
Blocked by: 01

**What to build:** 创作者从三个入口分别创建机位与视角、光影与色彩、焦点与成像卡，在 A 界面配置、保存，并分别作为完整设计交给模型。

依据：[规格](../spec.md)、[共同执行约定](README.md)。前置票据：[01](01-style-preset-modal.md)。覆盖用户故事：1–17、29、38、44–48、51。

## 验收标准

- [ ] 三类卡在创建目录、数据契约、保存、输出和界面中具有各自独立身份；入口不再创建完整摄影卡并切换分区。
- [ ] 机位卡只拥有观察视点、位置、高度与角度、焦段与透视意图、支撑方式等所属参数；光影卡拥有光源、方向、明暗区域、曝光色温及色彩关系；焦点卡拥有景深焦点、焦点变化、光学效果、运动质感、技术意图、衔接及禁止项。
- [ ] 各类型只接受自身合法字段，越界数据返回明确错误；不复制完整摄影字段到每个类型，不引入隐藏内容所有者或统一新增约束字段。
- [ ] 每类可按需创建多张；编辑、复制、删除、连接及保存重开不影响其他类型或同类另一张卡，不自动铺满六张。
- [ ] 三类复用 01 的 A 外壳并使用对应既有预设；预览／对比不保存，部分预设合并不覆盖未声明字段，完整撤销和高级参数编辑在各类均可用。
- [ ] 三类卡分别提供真实摘要和有效设计输出，模型显式整卡采用后可编译使用；新类型没有分区、字段或阶段采用能力。
- [ ] 不保留摄影分区导航、设计参数／参考与关联 Tab、更多参数和独立正反例；只读、保存失败、模式切换与关闭重开的行为延续 01。
- [ ] 提供三类真实页面截图与保存／编译证据，包含桌面固定区域和窄屏可达性；完成[共同完成条件](README.md#共同完成条件)。

## 验证路径与范围

复用摄影公开保存／编译和设计卡浏览器用例，针对三类分别执行创建 → 应用预设 → 自定义 → 保存刷新 → 模型采用；验证跨类型非法字段、多个实例隔离和只读。共用测试数据可以参数化，但验收对象必须是实际创建和编译行为。

本票不处理运镜、构图或旧摄影存量清理；新旧类型切换遵循集成分支约定，05 完成前不发布部分替换版本。
