# 08: 视频模型配置携带素材用途

Status: ready-for-agent
Completion: resolved
Blocked by: 07

**What to build:** 视频模型接收设计实际引用的受支持素材，用户在接收模型中指定主体参考、首帧、尾帧、关键帧等用途及必要分组，保存并执行。

依据：[规格](../spec.md)、[共同执行约定](README.md)。前置票据：[07](07-image-model-carried-media.md)。覆盖用户故事：30–35、39–41。

## 验收标准

- [x] 视频模型合入已采用设计的有效素材声明，复用 07 的稳定来源、可追溯信息及代号映射，不需要额外直连原素材，不扩大到任意导演卡或未引用候选。
- [x] 用途控件仅提供当前模型支持的媒体和用途组合；主体参考、首尾帧、关键帧及必要主体分组可明确配置并保存重开。
- [x] 已有明确有效用途可复用；缺失时提示补齐，不自动猜首帧、不按设计卡名生成主体分组，也不从普通文字推断用途。
- [x] 用途变化只决定接收模型如何使用素材，不改写设计正文、不自动新增引用；素材是否携带仍由有效设计引用和整卡采用决定。
- [x] 同一稳定来源的合法多用途不会被通用去重抹掉，来源直接加携带路径不会产生重复候选；有序用途保留正确顺序和对应关系。
- [x] 合并后统一检查媒体类型、数量、重复素材、用途互斥及主体分组约束；不支持或缺配置时明确阻断并定位到接收模型配置或失效设计来源，不静默丢弃。
- [x] 视频预览、规范化执行参数和真实 worker 接收输入包含配置的媒体、用途及分组，导演设计／模型补充关系保持一致；不增加图片画面目标选择步骤。
- [x] 用途、分组和有效素材变化进入保存修订、依据摘要与预检过期判断；提交后快照固定这些配置，后续编辑或来源更新不改变已运行任务输入。
- [x] 取消设计采用、删除最后有效引用或来源失效后，输入列表和运行诊断正确更新；只读模式禁止修改配置。
- [x] 真实页面和公开保存／预检／执行路径检查通过，包含图片路径回归；完成[共同完成条件](README.md#共同完成条件)。

## 验证路径与范围

复用视频输入用途、公开编译及执行依据用例，覆盖主体图片／视频、首尾帧和受支持关键帧组合；以既有供应商替身验证实际执行 DTO。包含同源多用途、直接加携带、数量超限、缺分组、来源失效和预检后修改用途。

本票扩展 07 的通用携带路径，不新增媒体内容识别、自然语言用途推断或供应商协议重设计。
