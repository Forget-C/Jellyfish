# 01: 画面风格卡落地 A 方案

Status: ready-for-agent
Blocked by: None

**What to build:** 创作者打开画面风格卡即可选择预设，进入高级设置调整同一份参数，保存后重新打开，并由模型整卡采用设计。以这一条完整路径形成六类设计共用的 A 方案 Modal。

依据：[规格](../spec.md)、[已确认原型](../prototype.md)，视觉与交互来源为原型提交 `7e0367fc`。覆盖用户故事：1–17、29、44–48、51。

## 验收标准

- [ ] 风格卡可以独立新建、编辑、复制、删除和连接；卡面展示当前有效内容的紧凑摘要，刷新重开保留保存结果，不自动创建其他设计卡。
- [ ] 默认打开预设图库，左图库／右详情；无自动选中或自动应用首项。未选择时右侧展示当前配置摘要或选择提示，不把预设示意冒充当前设计。
- [ ] 标题、候选区域、主体及底部使用连续表面，取消硬分隔线和重复标题；桌面图库溢出时独立滚动，其他区域位置不变。窄屏上下布局、内容可滚动、底部操作可达，长内容不被裁切。
- [ ] 预览和最多两项对比不写入卡片；应用前准确显示填写／覆盖摘要及明细。只更新预设声明字段，保留其他字段、状态、用途和来源；一次撤销完整恢复本次修改。
- [ ] 右上角高级设置直接展示风格方向、色彩倾向、视觉特征、材质倾向、自定义说明及已有必要元信息；没有设计参数／参考与关联 Tab、更多参数或独立正反例界面。
- [ ] 预设与高级设置使用同一份受控数据；应用后留在图库并反馈结果，手动修改后按真实匹配情况显示预设或自定义配置。关闭清除未应用预览，模式切换保留输入、选择、对比和各自浏览位置。
- [ ] 手动编辑沿用真实自动保存和修订冲突机制；保存失败保留输入，后台结果或较早保存回包不覆盖后续编辑；只读允许查看和对比，禁止写入和应用。
- [ ] 模型明确采用后，风格有效内容进入真实编译输入；普通连接不自动采用，只支持整卡采用，字段状态和用途保持原有输出语义。
- [ ] 先完成此次必需的共享容器／预设控件整理，再接入风格卡；复用工作台主题、动作、焦点与关闭机制，验证受影响原消费者，不复制原型内存业务逻辑或建立通用表单引擎。
- [ ] 对照 A 原型提供桌面、小高度视口、窄屏及高级设置证据，验证关闭、返回、应用和焦点恢复；完成[共同完成条件](README.md#共同完成条件)。

## 验证路径与范围

复用真实生成画布的预设、设计编辑器及 Modal 浏览器用例，完成创建 → 预览／应用 → 高级修改 → 保存 → 刷新 → 模型采用；通过公开保存和编译接口检查结果与非法字段诊断。对比、撤销及保存失败验证用户可见内容，不断言组件内部状态。

本票建立可复用的设计外壳；候选添加与字段结构化引用由 06 完成，素材携带由 07／08 完成。既有风格内容不因界面调整被清空；冲突遗留示例按 05 的有限清理规则处理。
