# 06: 六类设计的候选添加与字段引用

Status: ready-for-agent
Blocked by: 02, 03, 04

**What to build:** 用户通过六类设计卡顶部候选条添加内容，在高级参数中输入或插入真实引用，保存后保持来源身份，并由实际有效字段统一决定使用状态与设计依赖。

依据：[规格](../spec.md)、[已确认原型](../prototype.md)、[共同执行约定](README.md)。前置票据：[02](02-camera-lighting-focus-cards.md)、[03](03-movement-card-phases.md)、[04](04-composition-card.md)。覆盖用户故事：8–10、18–28、38、44、45、49–51。

## 验收标准

- [ ] 顶部候选条复用模型卡的缩略图、名称、状态及“＋”入口；上传参考素材、素材库和当前画布选择在真实页面可用，连接只增加候选。没有独立管理关联按钮、展开管理区或素材采用开关。
- [ ] 抽取此次真实共用的候选展示／添加能力时先保持原模型卡行为，再接入设计卡；不把模型提交、能力配置或运行结果装入设计编辑器，原型中的禁用菜单不进入正式实现。
- [ ] 候选限于直接连入本卡且符合契约的普通文本、对象、媒体及允许的模型正式输出；不按名字搜索任意祖先，不新增设计正文互引、跨画布动态引用或自动连线。
- [ ] 预设界面点击候选仅查看；高级设置的 @ 与点击插入使用当前明确编辑字段及其光标位置，没有目标时仅查看。查看浮层不推挤主体，Escape 先关闭内层并恢复焦点，保留 Modal。
- [ ] 字段持久化稳定结构化引用，不保存显示代号作为身份；保存重开、重命名、候选重排和本地代号变化不换绑，普通文本展开后不二次解释引用或系统指令。
- [ ] 中文输入、完整代号确认、复制粘贴及失效显示复用模型规则；无边、跨画布、缺失来源或循环等异常遵循正确的保存／运行边界，不能绑定同名来源或尚不存在的未来输出。
- [ ] 多字段共同维护使用状态；删除某一处引用不清除其他字段引用，删除最后一处后停止使用但保留候选连线。
- [ ] 未填写／不适用字段保留文字与引用但不输出、不声明实际携带，显示已引用未生效；其他有效字段使用同源时仍显示使用。恢复字段可重新生效，明确没有／待确定等状态及各用途保持既有含义。
- [ ] 断线或删除来源前检查全部保留引用，包括停用字段；失效引用保留身份和定位，实际生效时阻塞相关运行，停用引用不凭空增加运行输入。
- [ ] 应用预设只替换声明字段及相应引用；覆盖明细准确显示引用变化，一次撤销恢复字段、引用与跨字段使用状态，不损坏未涉及字段。
- [ ] 设计输出明确声明有效字段实际引用的素材来源身份、内容可用性和字段来源关系；不收集全部候选。07／08 尚未支持的消费路径明确诊断，不静默丢弃素材后继续生成。
- [ ] 六类均验证真实保存、字段引用及只读行为；完成[共同完成条件](README.md#共同完成条件)，包括原模型候选与编辑器消费者回归。

## 验证路径与范围

复用真实页面引用编辑和公开引用保存／编译用例，覆盖文本、对象与媒体候选、跨字段同源、停用／恢复、来源失效、中文输入、复制粘贴和部分预设撤销。公开设计输出证明依赖声明正确；模型实际请求中的携带与用途由 07／08 验收。

05 与本票无相互阻塞；对旧冲突内容的定向清理仍由 05 负责，不能借普通引用编辑扩大删除范围。
