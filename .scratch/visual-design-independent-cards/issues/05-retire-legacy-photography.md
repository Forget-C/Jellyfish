## 验收标准

- [x] 处理旧存储的入口在移除旧类型前能够识别原始不兼容内容；混合新旧画布不会因旧文档解析失败而整体无法读取。
- [x] 只清理不兼容旧摄影卡及其关联失效连线、输入顺序、分组成员、引用绑定、提示词引用和依赖这些绑定的画面目标，不迁移成新卡或猜测拆分内容。
- [x] 保留其他卡片、普通提示词正文、有效引用和配置；不删除项目文件、媒体成果、无关历史或整张画布。清理操作遵守项目归属、版本和真实引用校验边界。
- [x] 旧正向示例／反例不自动变为有效字段引用或实际携带素材；冲突部分按同一有限清理策略处理，既有有效风格参数不被顺带清空。
- [x] 清理后可再次读取和保存；重复处理幂等，不重复破坏内容或产生误导状态，受影响模型的缺失依据提示具有可追溯原因。
- [x] 受影响模型不会因引用被删而被误标为原方案已完整配置；用户能够通过重新配置或明确处理缺失问题恢复正常流程。
- [x] 历史运行及快照不被原地改写；不兼容历史提供明确不可用状态，不伪装成新契约可执行输入，也不因其存在阻断其他有效画布和运行。
- [x] 正式目录和新契约只保留六类独立设计入口及整卡采用；旧完整摄影类型、五入口别名和分区／字段／阶段采用能力退出，不留下长期双轨兼容。
- [x] 提供混合存量画布清理前后、缺失提示和修复后的真实页面与公开接口证据；完成[共同完成条件](README.md#共同完成条件)。

使用隔离的旧存储样本和公开读取／保存／编译入口，验证受影响与无关内容的边界、幂等性、修订冲突和历史快照行为；真实页面验证缺失依据可定位、可处理。不得以直接改 JSON 的测试替代公开读写行为。

本票是类型切换的发布前置条件，不依赖新字段引用 06 或素材携带 07／08。开发验收只使用隔离数据，不在票据发布时执行任何清理。
