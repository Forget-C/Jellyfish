# 05: 六类视觉设计卡面

Blocked by: 01
Status: ready-for-agent
Resolution: completed

**What to build:** 画面风格、机位、景别与构图、光线、焦点、运镜六类卡保留明确的用途示意图，同时通过有限的实际参数摘要帮助用户识别设计并打开完整详情。

**规格范围：** 视觉设计档、六类参数摘要及用途图边界；依赖01的统一入口和摘要约束。

- [x] 六类卡采用包含标题的360×368候选外框；用途图之外的参数摘要合计最多4行，用真实内容验证并记录最终高度。
- [x] 图示明确表达用途，不冒充生成结果；保持原有风格，不通过放大图示填满剩余空间。
- [x] 各类型优先显示其实际配置的风格、机位、景别／构图、光线、焦点要点；运镜优先展示起止画面与运动要点。
- [x] 构图保留明确画面定位语义，运镜阶段全文通过详情可达；不增加阶段或隐藏配置数量提示。
- [x] 默认值不冒充已配置，核心缺失与辅助信息分别表达；状态和失效来源保持准确，不用AI重写摘要。
- [x] 名称仅在标题，卡面不滚动全文，不恢复编辑按钮、更多图标或额外配置计数。
- [x] 空态、只读、参数或阶段更新不改变档位，完整编辑及预设阅读沿用既有容器。
- [x] 几何、连线、分组、缩略图和历史缓存一致，保留已有坐标与视口，不自动重排。
- [x] 复用视觉设计、构图、运镜及字段引用浏览器用例，覆盖六类长短内容、引用、阶段、只读、桌面／窄屏与缩放；运行typecheck及受影响检查。
- [x] 更新本票尺寸、摘要及用途图规范，记录最终视觉证据，不扩展摄影或生成业务功能。
