# 06: 按有效设计决定预设／参数入口

Blocked by: None
Status: ready-for-agent
Resolution: completed

**What to build:** 用户普通打开设计详情时，系统按当前有效设计选择预设页或参数页；编辑会话不自动跳页，应用预设保留其未覆盖内容。

**规格范围：** 当前内容分类、预设匹配、直接参数例外及明确问题定位与默认入口的边界。可通过现有入口独立交付，无需等待卡面换档。

- [x] 有预设的卡在无有效设计或清空后进入预设页；只有名称、来源、范围或关联时仍按无有效设计处理。
- [x] 当前设计完整匹配预设且无额外实质设计时进入预设页并标识匹配；手写相同设计和撤销恢复匹配具有相同行为。
- [x] 仅名称、来源、范围或关联变化不改变设计归类；设计参数改变或增加预设外实质设计则进入参数页。
- [x] 完整识别额外设计内容，包括连续性分类相关场景；不能仅比较预设的局部字段或显示文字而忽略实际结构化引用。
- [x] 对白、不可改事实、空间锚点没有预设，始终直接参数页，不显示空预设列表。
- [x] 仅在普通打开时判断；当前会话中输入、应用预设或匹配状态变化不自动切页，用户仍可主动切换。
- [x] 应用预设只覆盖其声明配置，保留未覆盖内容；从A切换B后保留额外设计时仍为自定义，下次进入参数页。
- [x] 不新增持久化预设标记、操作历史或编辑模式历史；沿用现有保存、撤销和只读语义。
- [x] 保留明确字段定位进入参数页的现有能力；不得把所有问题入口统一转为参数页，检查卡会话恢复不受此规则影响。
- [x] 扩展现有预设浏览器场景覆盖上述分类、清空、撤销、混合预设、辅助信息、直接参数卡、只读和窄屏；不只断言内部匹配函数。
- [x] 运行typecheck和受影响检查，同步默认入口与应用预设规范，记录实际验证；不修改预设内容或业务校验范围。
