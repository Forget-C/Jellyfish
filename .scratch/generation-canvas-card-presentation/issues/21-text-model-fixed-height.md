# 21: 文本模型独立固定高度定标

Blocked by: None
Status: ready-for-agent
Resolution: completed

**What to build:** 文本模型卡使用适合文字预览的独立固定高度，减少大块闲置空间。用户在生成、失败或查看成果时都能读到必要内容和状态，流式更新不会改变外框；媒体模型、检查卡及内容和结果阅读保持原有尺寸与行为。

**规格依据：** [规格第二版](../spec.md)，固定尺寸目录及文本模型定标；本轮Q9、Q16、Q18。

- [x] 文本模型宽度360px，先以包含标题的224px固定高度验证；四行输出摘要、适用的临时输出说明和底部状态完整可读，独立操作可达。
- [x] 空态、流式、成功、失败、取消及保留旧成果均使用同一固定高度；新输出、多输出状态或状态刷新不按文字长度反复升降档。
- [x] 若224px无法容纳必要内容，基于真实页面样本重新定标并记录最终值与原因；不得通过缩小字体、删除必要说明或隐藏裁切使候选值强行通过，也不得改为随流式内容增长。
- [x] 未完成预览与正式输出、失败时保留的成果保持既有语义；不改变生成、执行、检查或素材采用逻辑，不通过尺寸调整扩展实际输出能力。
- [x] 文本模型卡面、连线端点、选框、分组、小地图、适应全部及放置判断使用同一新固定尺寸；保留左上角、既有其他卡片位置和视角，无伸缩动画或自动重排。
- [x] 旧424px或其他历史尺寸缓存不能覆盖新固定尺寸，重开不先显示旧大卡再缩小；保留已有位置、视口与手动布局信息，不要求用户清缓存。
- [x] 图片与视频模型保持360×424，检查卡保持400×424；文本内容／描述／依据及文本结果保持400×172，音频内容与结果保持300×172，图片／视频内容、资产参考及对应结果保持300×251。
- [x] 媒体继续完整等比预览，比例空边不按设计摘要留白阈值裁掉；播放器、图片操作、检查卡最多四项及快捷操作不受压缩。四模态结果继续复用内容阅读并保持只读与更新关系。
- [x] 复用model-card-shell页面用例，覆盖全部文本模型运行状态、短文、长文、临时说明、旧成果及历史缓存；独立验证实际外框与必要状态，不只替换高度常量断言。
- [x] 按受影响范围回归image-fit、check-model、linked-results及媒体阅读，覆盖桌面、390px、缩放、只读和原生播放；使用可控运行数据和本地测试素材，不调用付费生成或检查模型。
- [x] 人工查看各状态截图，记录最终固定高度及定标证据；运行前端typecheck及受影响测试，实施后同步文本模型尺寸的设计标准和架构事实。共享尺寸入口后续与14集成时保持一致，不复制一套尺寸规则。
