# 10: 标题问题清单及名称／模型配置定位

Blocked by: None
Status: ready-for-agent
Resolution: completed

**What to build:** 用户从标题感叹号阅读明确归属于卡片的已有问题，并能定位名称或明确的模型配置位置。图标严重程度、无目标说明和画布全局错误各有清晰边界。

**规格范围：** 可用的问题清单、诊断目标传递及名称／模型配置两类真实导航；后续目标在11–13接入，不新增诊断规则。

- [x] 标题操作菜单前显示一个问题图标：明确错误红色、警告黄色，合并显示最高级别，清单保留各项说明；无问题不显示错误。
- [x] 图标支持悬浮、键盘聚焦和点击，可访问名称明确；点击先展示清单，不直接打开参数页，不触发拖动或整卡激活。
- [x] 仅消费已有明确诊断及所属对象；待确定／不适用不自动当错，不推测责任卡片，不靠错误文案生成目标。
- [x] 页面到画布导航保留诊断的完整有效目标信息，包括路径和引用身份；为已接通目标显示明确动作名称，不提供假定位入口。
- [x] 名称问题打开详情并定位标题名称，不为改名强制切参数页；只读时可阅读问题，不开启编辑。
- [x] 明确模型配置问题定位对应配置；只有文字的能力提示只解释，不推测要改哪个设计参数或自动换模型。
- [x] 保存、网络、版本冲突等全局问题留在画布状态区域及已有恢复入口，不复制到所有卡片。
- [x] 无可靠目标仅说明；目标字段失效但卡片存在时可打开卡片并说明，卡片也失效时不跳替代对象。尚未接通目标保留既有有效入口，不伪装为字段定位。
- [x] 导航只查看和定位，不改文档、解除关系、触发生成或检查；保留现有浮窗／Modal和普通打开规则。
- [x] 通过现有预检和编辑页面的可控诊断验收严重程度、名称／配置定位、无目标、失效目标、全局错误、只读及键盘／触摸；不只测试内部路由函数。
- [x] 运行typecheck及受影响检查；更新问题图标和已接通导航的规范，保留诊断／执行职责边界，不新增后端API或推测性检测。
