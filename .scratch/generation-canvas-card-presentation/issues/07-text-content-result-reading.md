# 07: 文本内容与文本结果统一阅读

Blocked by: None
Status: ready-for-agent
Resolution: completed

**What to build:** 用户在基础文本、创作依据、四类对象描述和文本结果卡上浏览有限摘要，点击后使用已有文本阅读机制查看全文；结果保持只读、正确来源及当前输出更新关系。

**规格范围：** 文本档、文本结果的展示和详情复用，以及后续媒体可复用的结果详情装配。以真实文本阅读行为交付共享改动。

- [x] 基础文本、创作依据、人物／场所／道具／服装描述和文本结果使用包含标题的400×172外框，正文最多4行及适用的字数、来源或状态。
- [x] 卡面不滚动全文、不增加更多图标；点击或键盘打开完整内容，原有文本及描述编辑能力不受损。
- [x] 文本结果复用对应内容卡展示与阅读组件、已有浮窗／展开／窄屏Modal，完整正文可选择复制，不新增复制全文按钮。
- [x] 结果在可编辑画布中也只读，隐藏不适用的导入／修改操作，来源明确为生成结果；不把投影送入普通内容更新回调。
- [x] 保留结果虚拟身份、输出标识及来源连线；仅打开或阅读不创建持久内容卡、不推进画布文档修订。
- [x] 详情跟随对应位置最新正式输出，输出缺失如实显示不可用；失败／未完成内容不替换正式输出，历史报告仍保持固定证据。
- [x] 显式复制为内容卡后才生成独立可编辑副本，副本不随后续输出变化；保持既有复制／粘贴业务语义。
- [x] 尺寸与连线、分组、缩略图及缓存一致，保留历史坐标、视口和手工布局，不自动重排。
- [x] 共用结果详情装配只提供实际需要的只读和来源能力，媒体由后续票接入；本票不破坏原有图片及音视频展示。
- [x] 复用文本、描述、卡壳及文本结果复制浏览器用例，验证长文阅读、选择复制、正式输出更新、缺失、只读、文档无写入、副本独立及桌面／窄屏。
- [x] 使用可控运行数据，运行typecheck及受影响检查；更新文本尺寸、结果身份及阅读复用规范，不新增持久类型或API。
