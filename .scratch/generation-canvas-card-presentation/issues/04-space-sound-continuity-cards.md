# 04: 空间、声音与连续性卡面

Blocked by: 02
Status: ready-for-agent
Resolution: completed

**What to build:** 空间锚点、声音安排、空间规则、连续性四类卡通过结构化摘要表达位置、声音设计及前后变化，用户能阅读全文且不会将配置误解为制作完成或检查通过。

**规格范围：** 四类结构化摘要及对应业务语义；复用02的档位。

- [x] 四类卡统一采用已确定结构化档，2–3项摘要、合计最多6行，一般每项最多2行；空态、只读和多字段不改变尺寸。
- [x] 空间锚点优先展示位置、朝向、空间关系，示例与位置标记按辅助信息处理；原有标记编辑和参考阅读保持可用。
- [x] 声音安排优先展示声源描述、环境／动作声音、声音层次；音乐等其他配置在详情可达，不标识声音已制作完成。
- [x] 空间规则优先展示可拍区域、轴线、尺度；空间依据等其他内容在详情可达。
- [x] 连续性展示分类及前态、变化、后态，后续约束作为辅助；不丢失明确没有、不适用或待确定含义。
- [x] 采用标题类型图标及原文摘要，不显示大幅通用图、重复名称、编辑按钮、更多图标或额外配置计数。
- [x] 核心缺失但有辅助配置时如实表达，默认值不冒充设计；来源失效可读，不暴露内部ID作为名称。
- [x] 空间锚点继续直接进入参数，其他编辑器沿用自身入口和容器；本票不改变声音字段、生成职责或连续性校验规则。
- [x] 尺寸同步连线、分组及缩略图，保留历史坐标、视口与整理布局行为。
- [x] 复用空间、声音约束及连续性浏览器场景，覆盖四类长内容、引用、状态、只读、窄屏及完整阅读；运行typecheck及受影响检查。
- [x] 更新对应规范与视觉证据；若需调整共享高度，同时验证已迁移结构化卡，不能单独增高某类卡绕过档位。
