# 16: 视觉设计卡按图示与摘要选档

Blocked by: 14
Status: ready-for-agent
Resolution: completed

**What to build:** 画面风格、机位与视角、景别与构图、光影与色彩、焦点与成像、运镜六类卡按用途图和实际摘要选择高度，消除空风格卡及短运镜卡的过量底部留白，同时保留正常摘要和稳定详情操作。

**规格依据：** [规格第二版](../spec.md)，视觉档、摘要目录、锁高与留白标准；本轮Q1–Q8、Q18。

- [x] 六类固定宽360px，从240／272／304px选择最小可容纳档。保留96px用途示意图及用途说明，不放大图示填空白，不将其表达为实际生成成果。
- [x] 按现有职责展示最多3项、合计最多4行参数摘要；保留名称只在标题的规则，不增加更多图标、额外配置数量、编辑按钮或卡内滚动。
- [x] 空风格、单项、三项短摘要及四行长摘要分别选档；只有范围、阶段或关系时同时表达核心未填写与真实辅助内容，默认值不冒充已配置。
- [x] 运镜保留起始、结束及运动要点优先级，中间阶段全文在详情可达；构图保留实际已选画面名称和失效提示，不丢失定位语义。失效、待确定等业务状态参与正常摘要预算。
- [x] 六类复用14号票的详情锁高；预设应用、参数编辑、阶段切换和模式切换期间实际高度稳定，摘要与问题提示继续更新。真正退出且无其他锁后一次应用最新档位。
- [x] 锁高时按当前容量省略最新摘要，不使用临时截断结果倒推正常目标高度。解锁后预算内内容完整，最大档仍裁切判为缺陷。
- [x] 非最低档未锁高时额外底部留白小于32px；最低视觉档允许必要空态空间。尺寸变化与连线、选框、分组及小地图同步，无伸缩动画或自动平移、重排。
- [x] 复用设计摘要、构图及运镜页面用例，逐类覆盖空态、短长摘要、范围／阶段／关系、失效画面、只读、桌面、390px及缩放，验证原有预设与详情操作不回归。
- [x] 人工查看空风格、短运镜、满四行运镜及构图失效目标截图，运行前端typecheck及受影响测试，回归已接入的紧凑／结构化类型。实施后同步视觉档规范和必要架构事实，记录证据。
