# 02: 创作与叙事类结构化卡面

Blocked by: 01
Status: ready-for-agent
Resolution: completed

**What to build:** 创作控制、生成指导、叙事概览、叙事节拍和镜头设计五类卡使用结构化档，用户能从稳定摘要读到关键创作要求和叙事变化。

**规格范围：** 结构化档首次落地、五类摘要和相关几何／交互回归。依赖01提供统一卡面入口及通用摘要约束。

- [x] 五类卡采用包含标题的360×304候选外框，展示2–3项关键内容，合计最多6行，一般每项最多2行；按真实样例记录最终高度。
- [x] 创作控制优先展示必须保留、允许变化范围、自由度；生成指导优先展示优先要求、禁止事项、参考要求。
- [x] 叙事概览优先展示信息变化、关系变化、转折；节拍展示目标、阻碍、预期变化；镜头设计展示可见结果、叙事作用、预计时长。
- [x] 声音策略、观众必须看到等其他内容在详情完整可达，不显示额外配置计数或更多图标。
- [x] 移除大幅通用示意图，保留标题类型图标；名称不重复，按原文摘要，不依据字段存储顺序选重要内容。
- [x] 空核心及已有辅助内容如实呈现，默认值不冒充配置，业务状态及失效来源不丢失；未填写和只读状态保持同档尺寸。
- [x] 复用01的整卡打开和子操作隔离，不新增编辑按钮或改变既有浮窗／Modal规则。
- [x] 新尺寸同步连线、分组、缩略图及缓存；保留历史坐标和视口，不自动重排；镜头设计不恢复旧Shot业务。
- [x] 页面级验收覆盖五类短／长内容、缺失核心、多字段、状态及桌面／窄屏，记录结构化档视觉证据；运行typecheck与受影响检查。
- [x] 更新本票落地的尺寸、摘要和组件复用规范；后续结构化卡可复用本档，不为未来场景引入通用配置框架。
