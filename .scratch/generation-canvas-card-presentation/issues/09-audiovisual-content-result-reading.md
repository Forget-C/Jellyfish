# 09: 音视频内容与结果统一播放

Blocked by: 07
Status: ready-for-agent
Resolution: completed

**What to build:** 基础音视频与对应结果通过一致的卡面和已有播放器阅读。用户可以独立播放，生成结果换文件时不会突然播放或沿用旧文件时间。

**规格范围：** 音频／视频档、07结果详情入口的媒体接入及播放器生命周期。

- [x] 基础音频及音频结果使用包含标题的300×172，展示播放器、名称、已知时长和状态；未知时长不编造。
- [x] 基础视频及视频结果使用300×251，保留视频预览、原生播放控制及已有音轨能力。
- [x] 结果复用对应内容组件和共享详情容器，结果只读且正确显示生成来源，隐藏添加、替换等不适用动作；普通内容编辑能力保留。
- [x] 详情随当前正式输出更新；换成新音视频文件后不自动播放、不继承旧文件播放位置；仅同文件状态刷新不无故重置播放。
- [x] 关闭或隐藏详情沿用已有暂停行为，播放、拖动进度、音量和菜单操作不误开其他详情或触发拖卡。
- [x] 缺失或加载失败真实显示，不把旧文件或未完成成果冒充当前正式输出；保留结果身份、依据状态和来源连线。
- [x] 阅读不写画布文档、不创建持久卡片；显式复制副本后独立，不继续跟随模型输出。
- [x] 音频新尺寸同步几何、连线、分组、缩略图和缓存，保留旧坐标及视口，不自动重排。
- [x] 使用固定音视频及可控输出更新，验证四类卡、同文件刷新／换文件、播放位置、无自动播放、只读、复制副本、桌面／窄屏与文档无写入。
- [x] 回归三类模型卡固定尺寸及运行状态、原有媒体预览；运行typecheck及受影响检查，更新音视频尺寸与结果播放规范，不调用付费生成模型。
