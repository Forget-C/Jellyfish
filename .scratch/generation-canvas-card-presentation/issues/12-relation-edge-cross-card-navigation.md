# 12: 关系、连线及跨卡问题定位

Blocked by: 10
Status: ready-for-agent
Resolution: completed

**What to build:** 用户从问题清单查看明确涉及的来源、关系、连线或多个卡片，而不会被统一送到参数页或被自动修改关系。

**规格范围：** 基于10的目标传递接通关系及画布对象导航，保留已有候选、采用和引用保护语义。

- [x] 明确关系目标打开对应关系控件，明确连线目标定位相关线，来源或整卡目标定位对应卡片；仅实际处理位置需要详情时才打开。
- [x] 来源输出缺失、依据变化等没有字段目标的消息不能冒充具体字段问题；不通过文案推断应该修改哪张卡。
- [x] 跨卡或多目标问题分别提供可读入口，让用户选择，不自动指定责任对象。
- [x] 整卡普通打开沿用该类型规则，关系定位不统一切参数页；已有引用保护和候选关系操作保持有效。
- [x] 目标已删除、断线或不可用时如实说明，不定位到同名、相邻或替代对象；部分目标仍有效时对应入口仍可用。
- [x] 堆叠成员沿用已有堆叠定位和解除提示，不自动拆堆或强开隐藏卡。
- [x] 定位可按现有明确导航机制移动视口，但不改卡片坐标、分组、连线或采用关系，不自动解除、替换、生成或检查。
- [x] 只读模式可阅读和定位，不能借问题入口绕过只读限制。
- [x] 复用来源关联、连线、构图画面定位、跨卡及堆叠浏览器场景，覆盖多目标、仅文字、失效来源／连线、只读、窄屏与导航无业务写入。
- [x] 运行typecheck及受影响检查，更新关系／连线问题导航规范；不扩展连接类型或诊断规则。
