# 11: 设计字段与运镜阶段问题定位

Blocked by: 10
Status: ready-for-agent
Resolution: completed

**What to build:** 用户从已有问题清单进入明确的设计字段或运镜阶段，自动展开相应位置并阅读问题；失效目标有真实说明，普通卡片打开规则保持独立。

**规格范围：** 复用10的问题入口和完整目标传递，接通设计参数类目标。

- [x] 只有诊断提供有效明确字段／阶段目标时显示定位动作，不根据问题文案猜位置。
- [x] 进入设计参数页并展开所属分组／运镜阶段，滚动和聚焦目标，必要时定位明确引用；保证目标控件及焦点轮廓可见。
- [x] 用稳定目标身份定位，不因字段顺序或阶段重排跳到其他内容。
- [x] 名称、模型配置、关系、检查报告等非设计参数目标不被此路由接管。
- [x] 显式定位优先于该卡默认入口，仅用于本次导航；关闭后普通打开仍按有效设计规则处理。编辑时不因匹配变化自动切页。
- [x] 字段／阶段失效但卡片存在时打开卡片并说明无法定位原位置；卡片不存在时只解释，不选择相邻或同名目标代替。
- [x] 堆叠内不可访问目标沿用堆叠定位与说明，不绕过组织状态强开隐藏成员；只读仍能查看有效目标。
- [x] 导航不修改设计、展开阶段不增加阶段、不触发检查或生成；保持卡片坐标与保存语义。
- [x] 扩展现有设计引用、参数分组、运镜阶段及焦点浏览器用例，覆盖普通字段、结构化引用、阶段重排／删除、只读、窄屏和失效卡片；与已落地普通入口行为组合验收。
- [x] 运行typecheck及受影响检查，同步字段定位规范和实际导航边界，不新增通用导航框架。
