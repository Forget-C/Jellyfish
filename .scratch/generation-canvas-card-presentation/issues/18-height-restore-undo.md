# 18: 重开、保存失败与撤销恢复

Blocked by: 14
Status: ready-for-agent
Resolution: completed

**What to build:** 历史画布重开即使用当前摘要的正确高度，保留原有布局。用户在保存缓慢或失败时继续看到本地有效内容对应的卡面；撤销内容或位置不会恢复与当前内容不符的旧高度，也不会多出一次撤销步骤。

**规格依据：** [规格第二版](../spec.md)，当前有效内容、首次展示、缓存及撤销；本轮Q3、Q7、Q12、Q13、Q16、Q18。

- [x] 旧尺寸缓存不覆盖当前内容与规则得出的实际显示尺寸；保留位置、缩放、视口、分组和手动布局信息，不要求用户清缓存或整体删除缓存。
- [x] 重开或刷新首次可见卡片采用当前内容对应档位；布局就绪前不展示可操作的错误临时外框，不先展示旧大卡再逐张缩小。沿用现有测量和恢复机制，不新增用户设置。
- [x] 选档依据当前本地有效内容，包括未保存成功的修改。延迟或失败保存不回退卡高、不冻结过时摘要；保存回包本身不导致无内容变化的选档。
- [x] 用户明确恢复版本或接受服务端内容时按实际生效内容计算目标高度，沿用现有冲突与恢复流程，不新增自动接受、丢弃草稿或覆盖机制。
- [x] 内容撤销／重做重新计算目标高度，但详情仍打开时遵守锁高；退出详情后一次应用最新目标，不恢复某个历史操作时偶然锁定的高度。
- [x] 拖动或既有整理撤销恢复对应位置及视图状态，高度继续由当前内容与当前锁派生；布局历史中的旧sizes不能强制复原旧外框。
- [x] 纯选档、测量及缓存更新不新增画布文档字段、保存修订或独立撤销步骤；内容修改与移动继续使用原有操作顺序。新的64px整理行为及其直接回归由20号票交付。
- [x] 高度变化不移动其他卡片或视角；恢复后连线、选框、分组、小地图和适应全部与实际外框一致，不因旧缓存暂时错位。
- [x] 扩展现有页面级自动保存、卡面几何与布局恢复用例，覆盖旧大尺寸缓存、无缓存、保存延迟／失败、本地恢复、接受服务端内容、内容及布局撤销重做，含详情锁定中的组合路径。
- [x] 核对首个可操作外框而不只检查加载完成后的截图；核对修订和撤销可观察结果，避免把“最后恢复正确”当作无闪跳或无额外历史的证明。覆盖桌面、390px及原有缩放。
- [x] 运行前端typecheck及受影响测试，同步恢复和派生尺寸的设计标准、架构事实与验收证据。使用14提供的详情锁即可独立验收，不增加对17的阻塞关系。
