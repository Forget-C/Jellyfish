# 08: 图片内容与图片结果统一阅读

Blocked by: 07
Status: ready-for-agent
Resolution: completed

**What to build:** 用户点击图片结果后，使用现有图片内容阅读机制查看完整图片及已有文件信息，清楚识别生成来源；结果更新和复制副本保持可靠。

**规格范围：** 图片结果接入07的结果详情入口，保留基础图片与四类资产参考卡既有能力。

- [x] 基础图片和图片结果使用包含标题的300×251外框，预览完整适配；复用对应内容展示和图片阅读组件，不另建结果阅读器。
- [x] 详情支持既有完整预览、加载／失败反馈及可用文件信息，沿用共享浮窗、展开、窄屏Modal和焦点规则。
- [x] 结果详情只读，隐藏替换、导入及选择素材动作；来源明确为生成结果，不能错误显示为项目文件。
- [x] 普通基础图片的编辑／替换能力保留，不能因复用结果只读模式而被禁用。
- [x] 当前输出替换后卡面和详情同步；缺失结果如实表达，保留输出身份、依据状态及来源连线；不回退到其他结果假装成功。
- [x] 阅读不创建内容卡、不推进文档修订；显式复制后副本独立，原模型后续更新不改副本。
- [x] 人物／场所／道具／服装参考卡保留300×251以及名称、角度、来源／关联状态，不因图片组件复用丢失业务信息。
- [x] 图片操作、菜单及拖动与整卡打开隔离，原有布局坐标、几何和视口保持正确。
- [x] 使用固定图片和可控运行数据扩展现有图片阅读及结果复制验收，覆盖只读、更新、缺失、加载失败、窄屏、来源和文档无写入；回归四类资产参考。
- [x] 运行typecheck及受影响检查，更新对应图片／结果阅读规范和架构事实；不新增媒体处理或模型调用。
