# 03: 人物表演与场面活动卡面

Blocked by: 02
Status: ready-for-agent
Resolution: completed

**What to build:** 用户在角色情境、人物表演、站位与走位、镜内活动、环境活动与留白五类卡上直接浏览关键情境、动作及空间活动，完整细节通过卡面进入既有详情。

**规格范围：** 复用02已落地的结构化档，扩展五类职责明确的摘要。

- [x] 五类卡采用02确定的统一结构化尺寸，不因动作长度、空态、只读或状态变化单独增高；摘要2–3项、合计最多6行，一般每项最多2行。
- [x] 角色情境优先展示当前情境、人物关系；人物表演展示身体动作、反应顺序、结束状态，其他表演细节在详情可达。
- [x] 站位与走位展示位置、路径、转换原因；镜内活动展示活动任务、路径、出入画；环境活动与留白展示环境活动、留白、原因。
- [x] 保留实际反应顺序与动作语义，不调用模型改写；不把辅助描述或默认值当作核心设计完成。
- [x] 采用类型图标，不恢复大幅通用图、重复名称、编辑按钮、更多图标或额外配置计数。
- [x] 长动作、引用及状态摘要按预算显示，核心缺失和已有辅助信息分别表达，来源可读且失效明确。
- [x] 详情继续复用已有编辑器，复杂设计保留Modal，整卡打开与拖动、关系控件互不干扰。
- [x] 验证新尺寸的连线、分组、缩略图、历史坐标及视口兼容；不自动重排。
- [x] 扩展现有表演／场面活动浏览器场景，覆盖五类空态、长文、多字段、只读、窄屏和展开阅读；运行typecheck及受影响检查。
- [x] 更新本票对应摘要与尺寸规范并记录视觉证据；若统一档高度需调整，同步验证已落地结构化卡，不修改已确认内容预算。
