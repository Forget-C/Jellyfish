# 15: 结构化设计卡按摘要收紧高度

Blocked by: 14
Status: ready-for-agent
Resolution: completed

**What to build:** 十四类结构化设计卡按实际摘要采用合适高度，空态和短摘要不再保留满卡空间，长摘要仍可按已确认预算阅读。编辑及只读详情复用已建立的锁高规则。

**规格依据：** [规格第二版](../spec.md)，结构化档、设计摘要目录及统一选档／详情规则；本轮Q1–Q8、Q18。

- [x] 接入创作控制、生成指导、叙事概览、叙事节拍、镜头设计、角色情境、人物表演、站位与走位、镜内活动、环境活动与留白、空间锚点、声音安排、空间规则及连续性，共14类。
- [x] 宽度固定360px，高度从128／160／192／224px选择最小可容纳档。正常摘要最多3项、合计最多6行，一般每项最多2行；保留原有职责优先级、字段元信息和真实引用表达，不按全文或字段填写数量选档。
- [x] 空态、单项、三项短摘要、满预算及只有辅助信息分别准确呈现；隐藏配置不撑高，核心缺失与已有辅助信息同时表达，不把默认分类或待定初始值误判为完整配置。
- [x] 声音安排按声源、环境／动作声和层次呈现，保持设计而非已制作的语义；连续性保留分类、各已配置前态／变化／后态及后续约束的逐行预算，不因缩高截掉后续状态。
- [x] 镜头长可见结果、人物表演动作、空间锚点位置等代表长文本保持既定省略规则；必要提示和业务状态参与正常容量，错误全文仍留在问题入口及详情。
- [x] 所有类型复用14号票的实际尺寸与详情锁高，不复制会话管理。详情内编辑、应用预设、清空、只读浏览和会话切换保持高度；真正退出后一次升降档并恢复正常摘要容量。
- [x] 锁高期间显示最新摘要，按当前空间临时省略；不冻结旧设计、不增加滚动、更多入口或特殊编辑按钮。不改变预设／参数默认入口及既有关系操作。
- [x] 非最低档未锁高时额外底部留白小于32px，最大档下预算内内容完整。保持左上角与视角，连线、选框、组框及小地图与实际外框一致。
- [x] 扩展既有页面级设计摘要用例，对14类逐一覆盖空态和短长代表内容，含辅助配置、引用或失效业务状态、只读、桌面、390px及缩放；声音与连续性的组合摘要单独核验可读性。
- [x] 人工查看代表截图，运行前端typecheck及受影响测试，回归紧凑卡。实施后同步结构化档的设计标准及必要架构事实，记录证据；不改变声音字段、检查执行或设计采用语义。
