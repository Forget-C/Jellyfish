# 01: 紧凑设计卡与统一卡面入口

Blocked by: None
Status: ready-for-agent
Resolution: completed

**What to build:** 用户通过点击设计卡面打开完整详情；验收要求、不可改事实、对白、叙事事件、表演规则五类卡采用紧凑档，以核心正文代替通用大图和重复入口。必要的共享卡面整理在本票内完成，其他档位后续逐类接入。

**规格范围：** 卡面规格的紧凑档、通用摘要、卡壳和编辑容器规则、几何兼容。

- [x] 五类卡在100%缩放下采用包含标题的360×240候选外框；核心最多4行、辅助最多1行。用实际内容验证并记录最终高度；不改变内容预算或按正文动态增高。
- [x] 摘要依次表达：验收要求的可观察标准及范围／条件；事实及来源依据；对白的说话对象、正文及语言／声画关系；事件的动作变化及来源；表演规则、适用对象及范围。
- [x] 紧凑卡移除大幅通用用途图，使用标题类型图标。合理留白不通过重复信息或拉伸内容填满。
- [x] 所有设计卡名称只在标题出现，移除开始／编辑／查看设计按钮、额外配置计数及更多图标；未迁移档位保留其当前尺寸和主体展示。
- [x] 所有设计卡鼠标、键盘及触摸打开详情；只读卡可以阅读。拖动、菜单、链接、端口及独立控件不会误开详情；现有内容、模型、检查卡入口不回退。
- [x] 保留已有浮窗、展开及Modal规则和共享表单样式。关闭／展开不改卡片坐标；不另建编辑器容器。
- [x] 摘要显示原内容，不调用模型改写；核心缺失与已有辅助信息分别表达，保留待确定、不适用、明确没有及失效来源含义，不用默认值冒充完成。
- [x] 长文按行数省略，卡面不滚动全文，点击后完整内容可达；来源使用可读名称，不用内部ID作为正常名称。
- [x] 尺寸同步作用于卡壳、连线锚点、分组、缩略图及视口适配。历史画布保留坐标、视口、分组和手工布局，刷新／撤销无漂移；不自动重排或改整理布局算法。
- [x] 扩展现有页面级浏览器验收，覆盖五类空白、短文、长文、辅助配置、只读、缩放、窄屏及历史缓存；用行为和几何断言配合截图验证。
- [x] 回归共享卡壳的播放器、模型状态及检查卡最多四项与快捷执行隔离；运行前端typecheck及受影响检查，记录结果和未完成项。
- [x] 同步本票已落地的工作台设计规范和生成画布架构事实，不提前把其他档位写为已实现，不修改父规格。
