# 20: 按实际外框主动整理布局

Blocked by: 17
Status: ready-for-agent
Resolution: completed

**What to build:** 用户主动整理画布时，普通卡按真实宽高和64px间距排布，缩小的卡片不再保留旧的560px行距。分组作为整体移动、结果保持专用排布；详情锁高与整理共存，解除锁高不会偷偷整理第二次。

**规格依据：** [规格第二版](../spec.md)，主动整理、分组及撤销；本轮Q10、Q11、Q12、Q15–Q18。

- [x] 普通卡继续按现有方向排三列，每列宽度取该列最宽实际外框，每行高度取该行最高实际外框；相邻列与行的布局间距均为64px，外框包含标题。
- [x] 不再用固定行距代替实际行高；混合类型与不同档位正确参与计算。同行较短卡、同列较窄卡产生的差额允许保留，不强行错列或改为新的智能排布。
- [x] 分组作为整体沿既有方向排列，与相邻排布单元保持64px间距，内部成员相对位置不变；不能通过重排组内成员消除已有重叠。
- [x] 结果卡沿用跟随模型的专用排布及避让，不进入普通三列网格；收起分组和堆叠使用其实际封面外框，不用隐藏成员大小替代。
- [x] 详情打开时允许整理，按当前锁定中的实际高度计算；不关闭详情、不提前解锁。之后详情关闭引起升降档时，保持整理后的坐标，不自动执行第二次整理。
- [x] 沿用17号票的手势互斥：拖动或连线期间不能启动整理，结束或取消后恢复。整理不释放其他会话或操作持有的锁。
- [x] 日常内容变化不自动整理，不移动邻卡；主动整理仍是用户明确操作，保留原有撤销入口。撤销恢复原有位置及相关视图，尺寸继续服从当前内容与当前锁，不恢复过时高度。
- [x] 整理完成及撤销后，连线、选框、分组、小地图和适应全部同步反映实际外框，不新增伸缩动画或基于尺寸变化的额外视口让位。
- [x] 扩展页面级organization及alignment场景，覆盖不同宽高的三列布局、末行不足三项、分组整体、收纳封面、结果跟随、详情锁定时整理、解锁后不二次整理和撤销；按实际外框独立验证64px间距。
- [x] 覆盖桌面、390px及已有缩放，人工查看整理前后截图；运行前端typecheck及受影响测试，同步主动整理与撤销的设计标准和架构事实，记录验收证据。
