# 19: 新增、复制与分组堆叠的尺寸一致性

Blocked by: 14
Status: ready-for-agent
Resolution: completed

**What to build:** 新增和复制卡片按真实外框寻找与呈现位置，分组边框准确包围当前成员。收起分组和堆叠保持稳定封面，展开后成员恢复当前摘要所需高度及原有坐标，不沿用旧类型常量误判位置。

**规格依据：** [规格第二版](../spec.md)，统一尺寸消费者、分组与堆叠边界；本轮Q11、Q13、Q16、Q18及新增／复制验收矩阵。

- [x] 新增空位搜索与现有卡片避让消费统一尺寸规则：待新增卡使用其当前内容对应尺寸，已在画布上的卡片使用其实际显示外框，包括锁定值，不继续直接套用旧类型固定高度。
- [x] 复制、粘贴、重复创建的定位与可见性判断按实际内容尺寸完成；新副本的尺寸不错误沿用来源卡临时锁定高度，原卡内容、位置和会话保持。既有引用与副本身份语义不变。
- [x] 展开分组外框随成员实际尺寸同步更新，不移动成员或重排组内关系；框选、小地图、连线及适应全部与可见组织形态一致。
- [x] 收起分组外框保持300×110，堆叠封面保持400×300；其边框、连接端点和命中区域继续按封面几何计算，不被隐藏成员的高度变化撑大。
- [x] 展开分组或解除堆叠后，按成员当前摘要和适用锁恢复实际高度，并保留原有成员坐标，不把隐藏前的旧尺寸当作权威值。
- [x] 收纳中内容发生变化后，恢复时展示最新内容与正确档位；隐藏成员不产生可操作的临时错误外框或错误连线，不改变原有堆叠内目标访问边界。
- [x] 增高造成组内重叠时保留位置，由用户手动处理；不新增组内自动重排或假定整理整组能够修复内部重叠。组拖动锁高由17号票负责。
- [x] 结果卡保留跟随模型的专用位置、已有避让及输出身份，不混入普通创建或复制语义；显式复制结果仍创建独立内容卡，阅读结果不建卡。
- [x] 复用页面级新增、组织、堆叠及结果用例，演示新建空卡、复制短长内容、视口边缘粘贴、分组内容增减、收起／展开和解除堆叠；核对坐标、实际边界及旧尺寸缓存不干扰这些路径。
- [x] 覆盖桌面、390px、缩放和适用的只读浏览，人工查看组框与连线截图；运行前端typecheck及受影响测试，同步放置与收纳的规范、架构事实及证据。
