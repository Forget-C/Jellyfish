# 10: 人物表演与情境生成

**What to build:** 用户从文本对象或命名图片参考选择参与对象，编写情境、表演和规则，按完整卡片采用后直接生成文本或视频。

**Blocked by:** [06 视频生成的用途与实际采用](06-video-generation-inputs.md)、[08 四类命名图片参考](08-named-image-references.md)

**Status:** ready-for-agent

- [ ] 三类卡片保留规格完整字段，使用专用摘要与展开详情；人物表演先呈现触发、反应、动作和结束状态，背景、细节与约束可继续编辑。
- [ ] 参与对象与作用对象从直接对象引用按类别明确选择；独立图片参考可直接提供人物身份，不要求先建立描述卡，也不携带其主图。
- [ ] 人物表演的参与对象、目标、目光、身体动作等形成完整设计输出，多张表演卡逐卡采用，不提供单项勾选或自动补齐的局部采用机制。
- [ ] 在首条导演链路落实字段状态及背景／设计／约束用途：空值与不适用不生成要求，明确没有保留否定，提议／待确定不升级成硬要求或自动确认。
- [ ] 本卡设计和必要对象标识直接进入文本／视频生成；模型需要人物描述或图片时须分别直接采用，不沿业务引用或素材关联追读。
- [ ] 允许从直接图片、视频等候选按本类型字段声明关联示例并定位用途／有效区间；示例只供当前卡参考，不随文本输出传给模型。
- [ ] 没有镜头或节拍也能独立使用；声明后续所属节拍、接收事件、对白依据和验收依据的可选契约，不伪造来源或把完整导演计划作为前置条件。
- [ ] 卡片字段、采用、输出与诊断可保存重开；本票已有关系即完成统一无环、失效绑定及素材删除保护，不把基础保护留给混合运行票据。
- [ ] 图片的结构化目标状态交互由摄影与图片目标状态票据接续；本票不临时拆分表演字段来绕过完整采用规则。

规格依据：[总体规格](../spec.md)。共同约束与验证边界见[任务索引](../README.md)；本票未开始实现，勾选项不代表已通过验收。
