# 22: 左侧卡片列表与添加操作

**What to build:** 用户从左侧添加按钮打开可搜索的卡片列表，按三组目录点击添加或拖入画布，随后编辑、保存并重新打开该卡片，无需常驻长目录。

**Blocked by:** 20

**Status:** ready-for-agent

- [ ] 左侧添加入口的位置、按钮样式和悬浮行为对齐场次工作台的默认资产入口，但明确命名为添加卡片，具有 tooltip、可访问名称和展开状态。
- [ ] 默认不常驻长目录；打开列表可搜索并按基础内容、模型生成、导演工具箱及其既有分类浏览，完整覆盖现有目录，不新增模态或物理卡片类型。
- [ ] 点击条目创建相应卡片，拖入按实际投放位置创建；已有摄影多入口仍维护同一内容所有者，不因目录展示拆分成独立摄影内容卡。
- [ ] 新卡片可打开现有详情编辑，约 1 秒合并保存后重开保留内容及既有布局语义；导入和命名等仍遵守各类型原有规则。
- [ ] 添加卡片不自动连接、建立业务绑定或采用，不继承场次默认资产选择行为；只读或编辑权不可用时阻止创建并明确反馈。
- [ ] 列表开合、搜索和取消拖入不平移、缩放或重排画布，取消不留下卡片；键盘和触摸用户可通过点击添加完成同一创建路径。
- [ ] 真实页面验证搜索→点击添加及拖入→编辑→保存→重开，核对目录入口与真实卡片对应以及未自动产生关系；提供桌面／窄屏入口与展开列表对照，列表不使关闭及必要操作不可达。

规格依据：[页面布局与卡片交互](../spec.md#与场次工作台一致的页面布局)、[视觉与交互验收](../spec.md#本次布局视觉与交互验收增补)。共同边界见[任务索引](../README.md#布局对齐增补2026)。
