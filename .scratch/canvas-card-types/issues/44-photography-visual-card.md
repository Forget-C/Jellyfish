# 44: 摄影卡图解与关键值展示

**What to build:** 用户在画布上直接通过摄影图解或合法效果缩略图与关键值分区理解摄影设计，能够从选中卡进入现有编辑能力，而不是阅读一整段通用摘要。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 摄影卡内容区上方展示摄像机图标与卡名；主体使用摄影／光学图解或合法效果缩略图，旁侧按标签／关键值分区显示当前已填写设计，如风格、机位／景别、光影／焦点。
- [ ] 图解和关键值仅来自已有字段与合法示意，不新增或伪造焦距、光圈、品牌、器材资产等字段；图解不成为新媒体输出或模型输入，不复制原型截图为项目资产。
- [ ] 默认展示有限关键项，保持标签弱、真实值清晰的视觉层级；空内容简洁提示，长内容及多字段按有限尺寸摘要，不以完整正文或待填写清单撑高卡片。
- [ ] 选中／键盘聚焦时右上调整按钮可达，普通卡面选择不自动打开复杂Modal；保持既有拖动、取消、连接点、媒体与独立按钮事件隔离。45会重排编辑Modal，本票在既有编辑入口即可独立验证卡面。
- [ ] 摄影五入口仍对应一张摄影内容卡的不同区域，独立方案保持独立身份；卡片摘要不裁剪对外设计输出，不改变摄影局部采用、对象身份与来源关系。
- [ ] 示意图、真实参考和实际生成结果各有清晰身份；复用合法素材或清晰设计的原创图示，不把粗略占位或表单截图当完成的专用卡面，也不承诺真实模型效果。
- [ ] 通过真实页面编辑已有摄影字段、保存重开、预览变化及直接采用验证摘要与实际输出一致；HTTP核对字段、输出与绑定不被显示方式改变。
- [ ] 提供默认、悬浮、聚焦、选中、空内容及长字段的桌面／窄屏图，实际查看原图和关键区域放大图；对照用户摄影卡参考与B，记录图解、关键值、标题和按钮状态差异，不只检查存在图标。

规格依据：[B「素材编排」视觉基线](../spec.md#b素材编排视觉基线)、[完整卡片类型表](../spec.md#完整卡片类型表)、[B 原型与参考图的对照验收](../spec.md#b-原型与参考图的对照验收)。共同边界见[任务索引](../README.md#b素材编排视觉对齐增补4348)。
