# 23: 卡片阅读、选择与右侧编辑闭环

**What to build:** 用户在工作台式卡片中阅读摘要、媒体和模型状态，通过标题拖动或框选组织内容，通过单击或键盘进入右侧悬浮详情连续编辑，操作之间互不误触。

**Blocked by:** 20

**Status:** ready-for-agent

**Completion:** implemented

- [x] 卡片标题、拖动柄、卡面、边框、圆角和文字层级对齐场次工作台；优先用户命名、类型为辅助信息，删除收进可访问菜单，不常驻危险按钮或复选框，保留清楚的选择状态。
- [x] 文本与导演卡提供有限字段摘要，不铺完整表单或卡内滚动全文；摘要不裁剪实际输出，全部既有目录仍能进入对应专用编辑器。
- [x] 图片／视频／音频卡直接展示缩略图、封面或音频预览以及名称和必要状态；模型卡显示模型名称、输入采用摘要、运行状态与结果预览，参数及采用操作在详情可达。
- [x] 单击卡面或 Enter／Space 打开详情；标题拖动仅移动卡片，框选及批量选择保持可用，媒体、按钮、菜单独立消费事件；播放、结果切换和预览不改变采用或输出集合。
- [x] 卡片采用有限默认尺寸与摘要规则；如保留手动调整，使用明确的调整柄而非浏览器原生 resize 外观。调整尺寸只影响布局，不改变生成依据。
- [x] 右侧单一详情目标与工作台一致：右上留边、无遮罩、不侧滑、不挤压画布、常规／展开两档；自身字段、输入采用、输出与来源按适用内容组织，沿用各类型编辑器，不重做业务字段。
- [x] 重复选择或点击空白不关闭详情；关闭按钮或 Escape 退出、内层控件先消费 Escape，关闭恢复有效焦点。展开不重建编辑器，切换对象保留各自编辑；窄屏使用近全屏内容并保护焦点。
- [x] 连续输入及自动保存期间，详情开合、展开、对象切换和媒体操作不丢输入或上下文、不移动画布；普通编辑不增加确认／取消事务，保存失败和冲突仍明确保留编辑。
- [x] 真实页面覆盖文本、导演、命名参考、四种媒体模态及模型摘要／详情，验证拖动、框选、播放和编辑互不误触；桌面／窄屏对照默认、选中、编辑、运行和错误状态，并通过保存重开核对字段不丢失。
