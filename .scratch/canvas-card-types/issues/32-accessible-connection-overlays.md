# 32: 触摸／键盘连接与浮层协作

**What to build:** 用户用触摸或键盘选择目标并建立候选，无需精确拖小圆点；添加、连接和右侧编辑栏协作时不丢失编辑会话与视角。

**Blocked by:** 27、29

**Status:** ready-for-agent

- [ ] 卡片菜单提供连接到…进入明确连接状态并显示目标；键盘可从连接点启动等价流程，触摸不必先打开详情或精确拖线。选择目标不触发普通卡片详情，退出后恢复普通点击行为。
- [ ] 目标选择沿 29 的零／一／多种用途与取消规则，只建候选；替代入口不绕过兼容、权限、无环或明确采用。使用可访问名称、可见焦点和可达关闭／取消动作。
- [ ] 添加面板与用途菜单互斥，开始连接收起添加面板。桌面详情可保留但不得遮住正在选择的目标；窄屏进入添加／连接时暂隐详情，取消或连接完成恢复原会话。
- [ ] 创建成功选中新卡并打开其详情，原卡会话保留；普通结束／取消恢复不得覆盖创建后的新目标，不丢已输入内容、播放位置或结果预览。隐藏媒体暂停，不重置会话。
- [ ] Escape 先由内层控件及当前菜单／连接处理，再作用于详情；关闭恢复合理焦点。浮层开合、临时隐藏和恢复不平移／缩放画布或改变布局。
- [ ] 真实页面分别以鼠标、触摸、键盘完成入口→目标→用途确认／取消，包含窄屏近全屏详情已打开、连续编辑自动保存、创建成功和连接取消场景；HTTP 核对候选／采用与保存结果。
- [ ] 提供桌面与窄屏组合浮层、焦点和目标可达性证据，确保新手势、菜单、筛选、底部工具和小地图不遮挡必要动作。

规格依据：[交互增补](../spec.md#二级卡片入口与图标分组)、[视觉与交互验收](../spec.md#二级入口与四边连接点验收增补)。共同边界见[任务索引](../README.md#二级入口与连接交互增补2733)。
