# 25: 底部工具、小地图与历史操作对齐

**What to build:** 用户在工作台式固定位置找到定位、缩放、布局、小地图和历史操作，多选后进行分组；视图调整与内容编辑、生成依据保持分离。

**Blocked by:** 20

**Status:** ready-for-agent

- [ ] 左下统一提供定位、缩放比例、缩放、适应全部和布局操作；右下放撤销／重做及非阻断状态，小地图在其上方避让详情和提示，位置、样式和间距对齐工作台。
- [ ] 分组操作仅在适用的多选状态出现，框选及既有分组／解散能力仍可用；生成操作放到对应模型或顶部区域，不与底部视图工具混成常驻长条。
- [ ] 定位、缩放、适应全部、小地图导航和布局整理均作用于正确画布；明确视图操作可移动视口，普通浮层开合不能移动或重排画布，布局缓存仍按原范围恢复。
- [ ] 内容撤销／重做、布局整理历史、浏览前进／后退保持独立；入口标签、提示及禁用状态能区分其作用，不合并为新混合历史或使用场次版本历史。
- [ ] 移动、尺寸、缩放及布局整理不改变卡片字段、绑定、输出、生成依据或预检有效性；内容编辑仍按既有规则使相关依据失效。
- [ ] 非阻断状态不挤占画布；窄屏移至右下工具上方并避让小地图，错误与失效目标保留明确恢复入口，不仅用颜色表达状态。
- [ ] 真实页面验证多选分组、定位缩放、小地图、布局整理及各历史操作，保存重开后保持原布局恢复语义，并用现有公开行为核对生成依据未被布局改动影响；提供桌面／窄屏底部状态对照和键盘可达证据。

规格依据：[页面布局与卡片交互](../spec.md#与场次工作台一致的页面布局)、[视觉与交互验收](../spec.md#本次布局视觉与交互验收增补)。共同边界见[任务索引](../README.md#布局对齐增补2026)。
