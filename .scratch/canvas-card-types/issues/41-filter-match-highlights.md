# 41: 筛选高亮与组织容器联动

**What to build:** 用户通过筛选突出匹配卡片，保留所有内容与连线作为上下文；匹配状态与操作选择独立，并在堆叠和编组中保持同一含义。

**Blocked by:** 40

**Status:** ready-for-agent

**Completion:** integrated

- [x] 分类、模态与问题条件只给匹配卡加蓝紫色边框，未匹配保持原样，不隐藏普通卡、编组成员或原可见连线；问题只使用已有明确诊断，不增加正文或图像语义检查。
- [x] 匹配高亮与实际选中轮廓、操作反馈及运行状态可区分；筛选不打开编辑、不显示多选菜单、不触发关联线高亮，不改变现有选择集合。
- [x] 编组成员按各自匹配情况高亮，编组成员、外框范围和坐标不因筛选改变；不把匹配集合变成组织或执行范围。
- [x] 堆叠不自动展开；有成员匹配时高亮外框并显示匹配数量，总数仍可辨。只读查看层展示全部成员，仅给匹配成员加高亮，不默认过滤成员。
- [x] 清除只移除匹配高亮，收起保留条件；选择、编辑会话、位置、候选与采用不变。适应全部不遗漏未匹配卡，堆叠仍使用其收纳几何、不强行摊开。
- [x] 真实页面覆盖部分／全部／无匹配、匹配同时被选中、多选及线选择、堆叠查看、清除／收起、适应全部和重开；HTTP 核对内容与绑定不变，并提供桌面／窄屏高亮对照证据。
