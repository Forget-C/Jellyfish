# 09: 多角度参考与视频名称映射

**What to build:** 用户明确添加同一对象的其他角度参考，在图片或视频模型中逐张采用，并看到按身份、角度和实际用途组织的映射。

**Blocked by:** [06 视频生成的用途与实际采用](06-video-generation-inputs.md)、[08 四类命名图片参考](08-named-image-references.md)

**Status:** ready-for-agent

- [x] 添加另一角度参考时，通过直接名称关联明确复用同一对象身份；新参考拥有独立参考身份、主图和角度，不自动采用原图。
- [x] 同一身份可在多份参考中复用名称，标题可区分正面／侧面；不同独立对象仍保持同画布名称唯一，不按名称自动合并。
- [x] 图片与视频模型可逐张采用同一对象的多份参考，数量、用途与组合仍遵守真实模型能力；同一对象多图本身不构成冲突。
- [x] 视频编译自动包含已采用参考的名称、身份和角度；用户明确选择首帧、尾帧、关键帧或主体用途，不因名称映射额外增加主体输入。
- [x] 需要主体分组时由用户明确组织，参考角度描述主图，不被解释成目标运镜或生成视角；额外服装／道具图片仍须直接采用。
- [x] 多人或多要素参考可按具体对象引用；同一身份的多角度来源不增加参与人数，绑定保持选定直接来源，不自动换用另一份同身份参考。
- [x] 保存重开、取消采用和来源失效保持相同映射与定位；名称或角度改变不修改已受理运行与历史。

规格依据：[总体规格](../spec.md)。共同约束与验证边界见[任务索引](../README.md)；本票已完成实施，验证范围与限制见下方记录。
