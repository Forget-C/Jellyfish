# 27: 二级分类入口与卡片创建闭环

**What to build:** 用户从八组悬浮分类图标进入二级目录，搜索并点击或拖入创建卡片，创建后立即在右侧编辑；摄影入口创建独立设计，整个过程保持画布视角及原有候选／采用边界。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**Completion:** integrated

- [x] 八组入口、图标语义、顺序、前三组与导演五组分隔均按规格；二级目录覆盖既有全部类型，业务归属仍为三组，不新增模态、音频生成或第三级菜单。
- [x] 一级悬浮显示名称、点击展开；分类切换、同入口关闭、Escape、焦点恢复、当前分类搜索及切换清空搜索行为明确，无匹配显示空态。面板有边界避让与内部滚动，窄屏关闭入口可达。
- [x] 点击添加在当前可见空闲位置创建，避开浮层并尽量避免重叠；拖入按释放位置创建，取消不建卡。成功均选中新卡、关闭面板并打开右侧详情，不自动平移、缩放、连线或采用。
- [x] 五个摄影入口每次创建独立摄影设计卡并定位对应字段；每份设计只有一张内容卡，已有卡不按选中状态或镜头自动合并。画面风格独立，修改已有摄影字段通过该卡详情。
- [x] 只读时允许浏览目录但禁用创建；已有素材库／上传动作若保留则与分类分隔，不因此新增管理能力。
- [x] 真实页面验证分类、搜索、点击／拖入、取消与只读；通过既有 HTTP 保存／重开核对卡片身份、内容、独立摄影实例和无自动绑定。
- [x] 提供桌面与窄屏目录、空态、选中态和创建位置的实际截图并查看；卡片侧的手势改版由 28 负责，跨入口浮层协作由 32 负责，本票不等待它们才能验证创建闭环。
