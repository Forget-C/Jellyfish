# 17: 创作控制、生成指导与验收要求

**What to build:** 用户编写控制、指导和验收要求，明确供镜头、表演或摄影采用；生成使用完整要求，验收规则不被误当成素材已经通过验收。

**Blocked by:** [12 摄影设计与图片目标状态](12-photography-and-image-target.md)、[14 叙事与镜头设计](14-narrative-shot-design.md)

**Status:** ready-for-agent

- [ ] 创作控制保留发挥程度、保持项与待确定信息；生成指导保留优先级、参考要求、声音策略及禁止项；验收要求保留稳定身份与可观察判断标准。
- [ ] 设计文本默认完整采用，按用途和状态参与文本、图片、视频编译；不把参考要求直接变成素材采用，也不重写用户自由文本。
- [ ] 验收要求作为直接来源，由镜头、人物表演、摄影的验收依据端点明确选择；验收卡只读展示被使用情况。
- [ ] 拒绝通过验收卡的作用对象建立等价反向镜头关系；未采用候选也必须无环，关联区和选择器不绕过规范方向。
- [ ] 适用对象、正向示例与反例按字段资格和媒体类型选择，候选不成为本卡自身字段，示例不随文本输出传递。
- [ ] 结构冲突按已知目标、状态和硬要求判断，提议／待确定不被错误升级；不做纯文本纠错或图片语义检查。
- [ ] 验收要求被采用只表示提供判断标准，不写入素材审查、真实覆盖或剪辑采用结论，不扩展旧场次生产流程。
- [ ] 在摄影与镜头均可用的链路核对对象指代、相关诊断、保存重开及取消／替换保护；其他已有导演功能的独立使用保持有效。

规格依据：[总体规格](../spec.md)。共同约束与验证边界见[任务索引](../README.md)；本票未开始实现，勾选项不代表已通过验收。
