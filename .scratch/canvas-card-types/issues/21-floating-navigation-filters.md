# 21: 悬浮面包屑与筛选闭环

**What to build:** 用户通过左侧工作台式悬浮面包屑辨认浏览范围，并按分类、模态及明确问题聚焦卡片；筛选始终只是展示操作，不改变内容采用与实际生成。

**Blocked by:** 20

**Status:** ready-for-agent

**Completion:** implemented

- [x] 面包屑紧贴顶部菜单下方靠左，样式与留边对齐场次工作台；默认总览，仅在实际进入已有分组浏览范围时增加该层级，打开卡片详情不改变路径，不虚构镜头或场次导航。
- [x] 面包屑、明确导航与顶部浏览前进／后退保持一致，仅恢复对应画布的真实浏览范围及视角，不混入内容撤销；普通筛选操作不进入浏览历史。
- [x] 筛选条位于面包屑下方并左对齐，横向展开、右端收起；支持基础内容／模型生成／导演工具箱分类、文本／图片／视频／音频模态及仅显示问题卡片，问题仅来自已有明确诊断或失效状态。
- [x] 筛选默认展开，按生成画布类型记住收起偏好；收起保留条件及可访问的生效提示，窄屏条件可换行，无适用条件时不显示空面板。
- [x] 筛选及其开合不改变卡片位置、布局、视角、当前选择或业务文档，不删除被隐藏卡片及连线，不取消绑定或采用，也不扩大或缩小运行范围。
- [x] 隐藏已采用卡片后，模型详情及生成前预检仍能核对其实际输入，不能显示成不存在；清除筛选可恢复原卡片与关系，不创建重复内容。
- [x] 真实页面执行筛选、收起、恢复和预检，以现有公开接口或实际请求核对筛选前后绑定及实际生成输入不变；提供桌面／窄屏导航和筛选与场次工作台的成对截图及键盘操作结果。
