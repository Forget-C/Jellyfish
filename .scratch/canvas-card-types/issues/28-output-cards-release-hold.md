# 28: 输出优先卡面与松开／长按交互

**What to build:** 用户在卡面阅读输出，在右侧编辑字段；普通点击和正常拖动均在松开时打开该卡详情，拖动期间保留原编辑会话，明确取消与独立控件的操作边界。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**Completion:** implemented

- [x] 基础文本、媒体、四类参考、导演及三类模型使用顶部名称与弱类型、中部主要输出、底部辅助状态；普通状态弱化但可读，失败／失效有文字语义，不常驻参数、候选计数、内部 ID 或完整字段列表。
- [x] 模型优先最近已发布结果，多结果仅切换预览；无结果、临时流式生成、失败保留旧结果与依据变化可辨，预览不改变输出集合或采用。参考卡展示主图、已绑定名称与角度，不展示候选描述正文。
- [x] 卡面正文只预览、不内联编辑或拖选；右侧负责编辑与文字选择／复制。卡片按下不打开或切换详情，短按在容差内松开打开当前卡，Enter／Space 提供等价操作。
- [x] 鼠标约 200ms、触摸约 350ms 长按保持后给出反馈并允许拖动；阈值前明显移动取消点击及长按，不移动卡片、不转为画布平移、不打开新详情。初始阈值可按真实验证微调，不增加用户配置。
- [x] 拖动期间原详情保持；正常拖动完成松开打开被拖卡详情，同卡不重建会话。Escape／指针取消恢复拖前布局、不打开新详情，取消后释放不补触发点击。
- [x] 端点按下立即连线，媒体、按钮及菜单保持独立事件；键盘移动、框选、修饰键多选不误触普通详情打开。只读不绕过既有权限。
- [x] 右侧编辑沿约 1 秒合并保存；切换、展开、隐藏和重开保留访问过的编辑会话、结果预览与播放位置，隐藏媒体暂停。布局移动不修改内容、采用或生成依据。
- [x] 真实页面覆盖鼠标／触摸阈值前后及取消、原详情未开／同卡／其他卡、播放器和多选；HTTP 核对保存内容与采用不变。提供各模态、运行／错误和桌面／窄屏卡面实际视觉证据。

规格依据：[交互增补](../spec.md#二级卡片入口与图标分组)、[视觉与交互验收](../spec.md#二级入口与四边连接点验收增补)。共同边界见[任务索引](../README.md#二级入口与连接交互增补2733)。
