# 49: 基础文本卡编辑区与空态

**What to build:** 用户在文本卡下方直接编辑、导入并保存自身正文，空内容时清楚知道如何开始；展开和切换保持同一编辑会话，不把基础内容卡变成模型卡。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 采用 C 一体化暗色圆角编辑面，保留外框、可见“正文”标签和描述性占位；内容为空仍显示输入区，不照抄原型的固定正文或超大空白。
- [ ] 正文选择、复制、中文输入法、清空和现有合法文本导入可用；底部低强调显示字数及必要状态，不出现采用依据侧栏、模型参数或运行提交。导入修改本卡内容，不新增持续输入。
- [ ] 默认下方编辑与展开复用同一会话；切换、关闭和重新打开不丢输入，约 1 秒合并保存、在途编辑保护及主动打开时最小平移保持既有规则。
- [ ] 只读内容可查看，编辑／导入禁用且原因可辨；长文局部滚动，桌面与窄屏关闭和必要操作可达，无页面横向溢出。
- [ ] 通过真实页面完成空正文→输入／导入→展开／切换→保存重开，HTTP 核对正文与固定内容语义；按 C01、C02 及会话、IME 边界验证，不用纯组件截图代替真实页面。
- [ ] 实际查看同主题、同画布缩放的桌面／390px截图及关键区域，对照 C 统一表面要求与基础文本参考，记录合理适配和差异；不将模型依据布局套在内容卡。

规格依据：[最新实现规格](../spec.md)中的 C「焦点编辑」专节及 C01–C08 验收；既有候选／采用、卡片字段、单模型提交、保存和输出协议继续适用。共同范围与依赖见[任务索引](../README.md)。
