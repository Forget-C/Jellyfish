# 47: 基础内容导入与连接控件样式补齐

**What to build:** 用户通过主题一致的入口导入基础内容，并能清楚识别卡片左右圆形加号进行连接；样式调整保留导入、连线和明确采用的完整行为。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 文件input可作为隐藏技术触发，用户看到的是工作台暗色按钮／适用加号菜单，不直接显示浏览器白色选择文件／未选择任何文件控件；文件名、上传进度、成功及失败提示使用统一主题。
- [ ] 文本文件导入和基础媒体原有适用能力保持，取消、失败、替换、只读及保存冲突不丢原内容或文件生命周期；不为普通文本新增媒体持续输入或直接生成能力，也不通过删除导入功能消除样式差异。
- [ ] 左右连接点为圆形边框＋居中加号：100%画布比例下可见直径约28–32px、加号约14–16px，保留足够命中区。不能仅增加透明命中区却仍显示10px空心点。
- [ ] 默认隐藏、悬浮／聚焦／选中及连接过程的可见规则保持；光标、兼容提示与焦点可辨，键盘和触摸等价操作可达。视觉加号与编辑区素材加号位置／可访问名称明确区分。
- [ ] 拖线持续反馈、零／一／多用途确认、去重、独立用途及侧边保存保持；唯一结果／唯一用途仍只建立候选，不能自动采用。普通基础卡不因加号获得新输入能力。
- [ ] 剪刀引用提示、单一操作对象、堆叠接收端保护和删除来源导致的连带断线门禁保持；不同缩放下连接不会误触卡片拖动或编辑。
- [ ] 真实页面串联合法导入／取消／失败／重开、悬浮／聚焦、拖线／取消／用途确认、候选与明确采用；HTTP核对输出、候选边、绑定及文件引用，验证没有跨级读取或自动任务。
- [ ] 实际查看导入入口和反馈、左右加号默认／悬浮／聚焦／选中状态的桌面／窄屏图及100%局部放大图，与用户参考和B对应区域对照；不以几何命中断言代替可见加号与主题验收。
