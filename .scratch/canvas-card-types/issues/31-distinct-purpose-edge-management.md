# 31: 重复候选去重与多用途连线管理

**What to build:** 用户重复连接时找到已有关系，同一对卡不同用途则分别查看、采用和删除，避免重叠线与重复候选干扰编排。

**Blocked by:** 29

**Status:** ready-for-agent

**Completion:** integrated

- [x] 按来源卡、来源输出、目标卡、目标输入用途判定相同候选；同点或不同侧边重复拖线均提示已存在并高亮原线，不新增关系、不更改已有绑定／采用。
- [x] 同一对卡不同合法用途允许独立关系，不按卡片对一概去重；仍遵守类型、模型能力、统一无环和实际采用数量规则。
- [x] 多用途线以轻微错开曲线独立呈现、可分别选中；默认不堆文字，悬浮／选中显示用途与采用状态，不只依赖颜色。线随固定侧边、卡片移动和缩放保持正确。
- [x] 分别采用、取消与删除对应实际用途；纯候选直接删除，已采用关系要求先明确取消／替换，不能影响其他用途或其他接收端。
- [x] 保存重开后边和用途不重复、不合并，已有侧边与绑定保持；错误及重复操作不使实际生成依据静默变化。
- [x] 真实页面验证重复连接和至少一组同源多用途的选线／采用／删除；HTTP 核对候选唯一性、各用途绑定与受控生成输入，并验证不兼容、环路和采用保护。
- [x] 提供桌面／窄屏多用途线默认、悬浮、选中与移动后的截图；逐线可访问操作不得依赖精确命中重合曲线。
