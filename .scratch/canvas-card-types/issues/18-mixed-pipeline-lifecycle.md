# 18: 混合管道运行与引用生命周期

**What to build:** 用户在模型、参考卡和导演卡组成的管道中运行到目标或执行选定范围，明确输入、固定依据与结果去向；重开和删除操作不会改变已有采用或历史。

**Blocked by:** [03 约 1 秒自动保存与下游刷新](03-autosave-output-refresh.md)、[09 多角度参考与视频名称映射](09-multi-view-video-mapping.md)、[10 人物表演与情境生成](10-performance-direction.md)

**Status:** ready-for-agent

- [ ] 在已交付类型上打通图片生成到参考卡再到视频生成、对象参考到表演再到模型等混合链路；全部候选边统一无环，逐卡只消费直接明确输出。
- [ ] 按实际采用组织执行依赖和范围，保留既有运行到目标、严格框选及范围占用规则；未采用候选不产生任务，参考和导演输出处理不成为隐式模型任务。
- [ ] 当前输出引用与固定产物分开：已有合法当前位置可按冻结计划使用本轮上游新结果，固定参考主图不自动替换或迫使来源重跑。
- [ ] 从未发布或当前缺失输出不能以计划中即将生成的承诺放行；保留失效身份与定位，不自动改用旧结果或其他候选。
- [ ] 相关性按实际采用输出判断：只改人物年龄不影响仅使用命名图片的依据，改名称映射影响有关输入；改示例媒体不影响未采用该媒体的模型。
- [ ] 运行受理后固定文档、绑定、范围和执行计划，下游提交前固定实际请求；自动保存、后续编辑及新输出不改写在途运行或历史。
- [ ] 取消、失败、结果未明、重开与事件恢复保持真实状态和幂等，生成成功只发布结果，不自动采用、覆盖本卡或启动下游。
- [ ] 在各类型已有保护之上核对混合关系的取消／替换、来源删除和文件保留；固定图可明确另存、改绑再删来源，不静默断开或制造替代来源。
- [ ] 本票负责混合执行和生命周期协调，不替前序票补做其本来应交付的保存、单卡生成、无环或绑定基础保护。
