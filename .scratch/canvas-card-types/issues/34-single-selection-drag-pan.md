# 34: 普通单选、卡片拖动与空格平移

**What to build:** 用户能明确选择一张卡片或一条线，通过移动距离直接拖动卡片，并在空白区域按住空格平移；释放、取消和切换不会误改内容或丢失编辑会话。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**Completion:** integrated

- [x] 卡片内容区上方展示对应图标与名称，主要区域展示输出，底部弱化状态；使用有限尺寸，不新增卡面表单或字段级端点。
- [x] 普通状态仅有一个选中操作对象。点击卡片替换单选与编辑目标，点击线取消卡片选择并收起旧编辑展示；普通空白点击或 Escape 清除选择和编辑展示，输入与保存状态保留。内层控件和进行中的手势优先处理 Escape。
- [x] 按下不激活编辑；容差内松开按点击处理，越过移动容差立即拖动，不等待长按计时。普通卡正常释放激活编辑，复杂卡只选中；本票建立选择与编辑请求边界，下方容器由 36、复杂 Modal 由 37 接续。
- [x] 卡面 grab、拖动 grabbing、连接控件 pointer；标题与卡面同一拖动单元。表单、播放器、菜单、按钮及连接点执行自身操作，不误触整卡激活或移动。
- [x] Escape／指针取消恢复拖动前布局，不切换编辑目标，取消后的释放不再次触发点击；正常拖动仅改布局，不使输出或生成依据过期。
- [x] 空白处 Space＋鼠标开始平移，经过卡片不切换用途；开始后先松开 Space 仍拖动至鼠标释放。尚未拖动就释放 Space 则退出；失焦／取消不残留抓取状态。输入、播放器、菜单和 Modal 中 Space 保留原义。
- [x] 保留键盘激活／移动和触摸可达操作；空白点击与空白拖动分开识别，为 38 的框选及组内手势提供一致边界，不建立与后续规则冲突的替代快捷键。
- [x] 真实页面验证快速／慢速拖动、轻微抖动、释放、取消、卡→卡／线／空白切换及 Space 提前释放；保存重开与公开 HTTP 核对内容、采用及关系未被布局操作改变，提供桌面／窄屏卡面和光标状态证据。

规格依据：[卡片点击、移动与事件隔离](../spec.md#卡片点击移动与事件隔离)、[普通选择与显式多选](../spec.md#普通选择与显式多选)、[空格拖动画布](../spec.md#空格拖动画布)。共同边界见[任务索引](../README.md#q1q32-交互收口增补3442)。
