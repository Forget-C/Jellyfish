# 15: 对白与声音设计

**What to build:** 用户编写对白和声音安排，明确说话对象并选择参考媒体，完整采用后按真实模型能力参与生成。

**Blocked by:** [10 人物表演与情境生成](10-performance-direction.md)

**Status:** ready-for-agent

- [ ] 对白保留稳定身份、正文和版本；声音安排保留声源、环境声、动作声、音乐约束及同期生成／待后期／待确定等制作安排。
- [ ] 说话对象和声源作用对象从直接、类别适配的文本或命名图片参考中选择，不从正文或图中人脸猜测身份。
- [ ] 对白对象可被人物表演通过对白依据明确采用；这不是表演卡到对白卡的反向文本依赖，不建立传输环。
- [ ] 视频表演／口型和音频参考使用直接素材关联，保留具体产物、用途及必要有效媒体区间；选择参考不携带其上游输入。
- [ ] 对白和声音设计默认完整采用，文本、图片和视频编译保留字段用途；图片中的可见声源／说话状态不被宣称为生成了声音。
- [ ] 同期或后期安排按真实能力表达，不把待后期当作本次已生成声音；不新增音频生成、音频模型输入、音轨替换或隐式转写。
- [ ] 播放、预览或关联参考不等于模型采用，声音媒体不随设计文本跨级传递。
- [ ] 保存重开、字段状态、关系方向、素材不可用及删除保护均与统一协议一致。

规格依据：[总体规格](../spec.md)。共同约束与验证边界见[任务索引](../README.md)；本票未开始实现，勾选项不代表已通过验收。
