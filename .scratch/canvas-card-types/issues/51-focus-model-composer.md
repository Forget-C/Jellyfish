# 51: C 一体化模型编辑区与紧凑操作

**What to build:** 用户在 C 焦点编辑面中同时核对紧凑采用素材和创作描述，通过全宽单行参数栏提交当前模型；统一底色与无分割线布局贯穿默认、展开及不同输入状态。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 文本、图片模型按 C 呈现；视频模型沿用同一结构和既有专属配置。桌面约700px宽、左依据约1/4右正文约3/4，随视口适配；素材、正文与底栏同底色、只有外边框，无贯穿横竖线或素材条目分割线。
- [ ] 左栏仅展示真实已采用素材，约42×44px缩略图／文本图标、名称、用途／角度或单行摘要，每条约68px；长名可查看完整信息，查看来源与具可访问名称的独立关闭图标可用。多项局部滚动，空栏不冒充候选列表。
- [ ] 右栏保留可见“创作描述”标签、placeholder及结构化引用能力，不默认重复已采用标签排、全量候选／日志／诊断表，不新增创作／管理双页签。候选按需浏览，明确采用、取消、顺序、分组与摄影范围保持。
- [ ] 参数横贯整个编辑区底部，约44px高、单行，显示真实模型及实际支持参数和素材管理入口；右侧约32px浅色圆形向上提交按钮固定可见。窄屏仅参数区域可横向滚动、不换行，禁用／加载不改变几何。
- [ ] 空输入／未采用、已有内容、长文／多来源、运行中、失败、来源失效与只读均有真实反馈；没有有效输入或存在阻断时按原规则禁用并解释，失败保留输入及旧成果身份，只读仍可查看和关闭。
- [ ] 展开／收起／切换保留同会话、光标、输入、媒体及自动保存；首开按最终展开尺寸保证参数、关闭和提交可见，不按初始占位高度误判；窄屏依据在上、正文在下，局部滚动，无页面横向溢出。
- [ ] 通过真实页面和 HTTP 串联候选→独立采用文本／图片→编辑参数→保存→预检→确认→受控单模型生成→重开，并覆盖取消采用、失败、失效、只读。名称映射、一级传输、统一无环和当前模型范围不变，不自动补跑。
- [ ] 按 C01–C04、C07 实际查看默认／展开与三视口图片、关键区域，与 C 最终一体化参考对照；像素是密度基准，不牺牲可读性或触摸命中区，不合入原型开关、假任务及固定参数。

规格依据：[最新实现规格](../spec.md)中的 C「焦点编辑」专节及 C01–C08 验收；既有候选／采用、卡片字段、单模型提交、保存和输出协议继续适用。共同范围与依赖见[任务索引](../README.md)。
