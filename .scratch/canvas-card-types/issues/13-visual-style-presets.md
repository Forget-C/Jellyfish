# 13: 画面风格与可视化预设

**What to build:** 用户通过风格及摄影的可视化示例选择预设、修改设计，再明确采用进入生成；示例素材与生成输入保持分离。

**Blocked by:** [12 摄影设计与图片目标状态](12-photography-and-image-target.md)

**Status:** ready-for-agent

- [ ] 独立画面风格卡保留风格方向、视觉特征、材质、色彩及自定义说明，支持图库、对比、大图预览和已选摘要，默认完整采用。
- [ ] 摄影各入口提供与内容相符的展示：景别／构图示意、机位视角对比、运镜短视频、光影与焦点效果预览，沿用同一摄影内容所有者。
- [ ] 预设选择形成可编辑的本卡设计，保存重开后能继续修改；浏览示例或切换预览本身不等于应用预设、建立媒体绑定或模型采用。
- [ ] 预设生成的结构化字段进入统一输出和编译，不能暗中提交示例中的人物、场景、图片、视频或音频。
- [ ] 需要实际使用示例媒体时，必须有合法直接来源和明确采用；内置演示不绕过媒体类型、归属及模型能力限制。
- [ ] 风格与摄影依各自完整／局部采用规则进入文本、图片和视频生成；视觉预设不承诺未接入的专用模型控制。
- [ ] 专用选择与编辑复用工作台主题、操作容器和媒体预览，窄屏与键盘可用，不引入万能表单引擎或隐藏的第二份设计数据。

规格依据：[总体规格](../spec.md)。共同约束与验证边界见[任务索引](../README.md)；本票未开始实现，勾选项不代表已通过验收。
