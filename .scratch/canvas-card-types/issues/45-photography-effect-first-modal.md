# 45: 摄影与风格的效果优先 Modal

**What to build:** 用户打开摄影或风格编辑时即看到大效果预览、可视化选项和关键设置，在同一容器按需展开专业字段并保存或应用设计。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**Completion:** implemented — 本票验收通过，等待集成后的48完整旅程与最终双轴审查。

- [x] 摄影五入口与独立画面风格Modal按B左右分区：左侧大效果预览与当前设计名，右侧视觉选项、关键设置及折叠专业字段。默认不是完整长字段表单，不必另开第二个大型预设窗口才能进行主要选择。
- [x] 五入口定位对应选择区域；景别／构图、机位、光影、焦点使用相应图示／对比，运镜提供可播放短片和起止对照，风格可比较效果。不能仅保留浏览预设按钮宣称效果优先。
- [x] 完整原字段、字段状态、背景／设计／约束、必要对象关系、来源与摄影声明范围在同一编辑器按需可达。必要问题能定位到对应区域，不因折叠专业字段丢失编辑或诊断。
- [x] 普通字段沿用约1秒自动保存及保存后输出刷新；预设选择有明确应用／取消语义，取消不撤销其他已保存字段，不新增整卡草稿或确认事务。预设示例不自动成为媒体输入或被模型采用。
- [x] 关闭按钮、遮罩与Escape遵守原会话／焦点／内层优先规则；操作选择与当前编辑保持合理层级、底层暂停且恢复同会话，不叠加重复完整编辑器，不修改场次工作台交互。
- [x] 窄屏先预览再选择／设置，专业字段折叠，正文内部滚动，关闭、应用及必要动作可达；桌面展开空间充足但有限，不以过大空白模拟参考图。
- [x] 视觉示例明确来源及示意身份，使用合法素材或清晰原创图示；不直接合入原型照片／滤镜、固定参数、假交互或商业效果承诺，不新增品牌器材或未支持能力。
- [x] 逐一通过摄影五入口及风格的真实页面预览、播放／比较、选择／取消／应用、专业字段编辑、保存重开及诊断旅程，HTTP核对字段状态、关系及采用范围。实际查看与B摄影Modal并排的默认／专业展开／窄屏截图及局部图，记录差异。
