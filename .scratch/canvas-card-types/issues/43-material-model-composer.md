**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**Completion:** implemented

- [x] 文本、图片、视频模型均采用 B 式整合面：桌面参考宽约700px、左约1/4右约3/4，随可用视口调整；左侧依据与右侧输入属于同一编辑区，不拆成两个浮窗，不退回纵向全量候选表单。
