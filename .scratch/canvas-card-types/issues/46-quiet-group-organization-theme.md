# 46: 简洁编组控件与组织主题统一

**What to build:** 用户默认只看到编组外框和框外图标名称，选中后再管理名称和成员；编组与堆叠遵循统一主题，同时保留独立卡片操作及组织恢复能力。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 未选中的编组仅显示低强调实线外框、轻背景及框外图标／名称，成员保持独立卡面；不常驻名称输入、解组按钮、成员多选器或白色拖动柄。
- [ ] 明确选择组后出现紧凑管理动作，重命名、解组、成员加入／移出进入菜单或局部编辑，退出后恢复简洁标题；菜单不遮成员、不抢多选上方菜单，不新增布局／下载动作。
- [ ] 原键盘移动入口如保留，使用主题化图标、可访问名称和可见焦点，按状态出现；不能通过删除键盘或触摸能力消除白色控件。
- [ ] 组内空白拖整组，卡片仍独立选择、编辑及拖动；Space平移、修饰键框选及普通组内拖动优先级不变，Portal内控件不被组拖动捕获。
- [ ] 明确改成员、不以穿框自动归组；不嵌套或重复归属、不静默跳过部分成员。解除、整理／撤销及重开保持成员位置、原输出和绑定，不新增组织执行范围。
- [ ] 堆叠表面、叠层与操作条的散落灰色改为共享主题或明确局部语义token；匹配蓝紫边框、焦点、危险及错误各保留语义，不以新硬编码模拟截图。堆叠只读、外部线、解除恢复及运行更新行为保持。
- [ ] 真实页面与HTTP验证未选中→选择→管理→退出，以及重命名、成员变更、单卡／全组移动、框选、触摸／键盘、解除／重开和整理撤销；候选、采用、单模型范围及组织保护不变。
- [ ] 实际查看编组默认／选中／名称编辑／成员菜单及堆叠三态的桌面、窄屏截图，对照B与用户编组图；核对控件出现时机、框外标题、主题值、焦点和遮挡，不只证明创建编组成功。
