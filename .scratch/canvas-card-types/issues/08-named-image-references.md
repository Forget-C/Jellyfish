# 08: 四类命名图片参考

**What to build:** 用户创建角色、场所、道具或服装参考，从直接候选选定名称与主图；图片模型实际采用后自动形成可核对的名称映射。

**Blocked by:** [05 图片生成与结果选择](05-image-generation-adoption.md)、[07 人物／物件与场所描述](07-object-description-identity.md)

**Status:** ready-for-agent

- [ ] 四类参考卡分别保留参考身份、标题、独立对象身份／名称、默认正面且可编辑的角度与必要图内定位；每卡明确选择一张有效主图。
- [ ] 名称关联和图片来源分别从直接候选明确选择，候选列表不保存为卡片字段；名称出口可来自文本对象或已有参考，对应预览不读取描述正文或来源图片。
- [ ] 角色参考接受人物及可选服装、道具名称，表示同一主图中的要素；场所、道具、服装各按类别接收，服装不绑定示例模特或穿着者。
- [ ] 没有本类别主对象绑定时可独立命名；角色可独立命名人物并另选服装／道具。绑定名称由上游拥有，取消或替换后才能改为其他独立对象。
- [ ] 主图固定具体文件或已发布产物及来源，来源再次生成不静默换图；换图保留明确名称绑定，并提示核对角度及位置，不做图像识别或强制视觉审核。
- [ ] 图片出口提供主图、合法默认映射、参考角度与必要定位；对象引用出口只提供具体对象身份。缺主图但合法的对象引用可独立有效。
- [ ] 图片模型明确采用参考后自动编译默认名称映射，无需第二次采用，不反复追加到用户正文；完整人物／场所描述仍须直接连接并独立采用。
- [ ] 一图多名称不因映射数量重复提交同一输出；不自动推断穿着、持有或动作，纯文本原样保留，不作语义冲突检测。
- [ ] 三类候选关系统一无环；已采用主图或名称来源删除时须取消／替换，固定产物不豁免直接关系；可明确另存独立图片再改绑。
