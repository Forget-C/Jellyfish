# 36: 卡片下方编辑区与展开编辑

**What to build:** 用户在基础内容、命名参考和模型卡下方就近编辑，必要时展开到居中 Modal；编辑区跟随卡片并保持可读，保存与输入不会因移动或切换丢失。

**Blocked by:** 34

**Status:** ready-for-agent

- [ ] 通用文本、原文依据、人物／物件与场所描述、基础图片／视频／音频、四类参考及三类模型使用下方编辑区，原有自身字段、绑定、来源、预览、配置及适用媒体动作完整保留；不复制候选为自身字段。
- [ ] 编辑区以固定间隔锚定卡片下缘，浮于画布，不重排其他卡片；控件使用可读屏幕尺寸，不随画布缩放变为微小表单，宽度及高度受视口约束并避让必要工具。
- [ ] 主动点击、键盘激活、切换或点击创建普通卡时，仅空间不足才最小平移视口；不改节点坐标或自动缩放。拖动／拖入释放、连续输入、保存、结果刷新、重复激活和关闭不自动平移。
- [ ] 超高内容限高内部滚动；窄屏使用底部或近全屏容器，不执行桌面式自动平移，标题、状态、关闭与必要动作可达。
- [ ] 展开打开居中大尺寸 Modal 并暂隐下方编辑区，复用同一内容及会话；收起／关闭后回到原卡下方，不产生第二个编辑器或整卡确认保存事务。
- [ ] 卡片完全移出可见区域时暂隐编辑区，返回可见时恢复，不拉回视口；主动关闭或切换不能误恢复旧目标。卡片菜单提供展开编辑，处理释放后下方空间不足。
- [ ] 普通空白点击收起编辑区，切换与关闭保留输入、约 1 秒自动保存、失败／冲突恢复及预览上下文；隐藏媒体暂停并保留位置。添加和连接暂隐结束后按当前选择恢复，不能覆盖新目标。
- [ ] 编辑区加号按类型复用既有上传／选择能力：基础媒体编辑自身，参考主图与名称选择分开，普通文本不增加媒体输入。模型来源快捷选择与提交流程由 39 完成。
- [ ] 真实页面覆盖全部适用类别、不同缩放、边界／超高内容、出屏返回、展开／关闭、切换及保存失败；通过 HTTP 核对字段、绑定与发布输出不丢失，提供桌面、窄屏和宽屏位置证据。

规格依据：[卡片下方编辑区与复杂卡片 Modal](../spec.md#卡片下方编辑区与复杂卡片-modal)、[编辑区加号与上传边界](../spec.md#编辑区加号与上传边界)。共同边界见[任务索引](../README.md#q1q32-交互收口增补3442)。
