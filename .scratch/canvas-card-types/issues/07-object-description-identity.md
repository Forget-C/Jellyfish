# 07: 人物／物件与场所描述

**What to build:** 用户创建人物、物件与场所描述，保留稳定对象身份；模型可采用描述，其他卡片可通过单独出口获得合法对象引用。

**Blocked by:** [01 新协议下的文本生成闭环](01-text-protocol-flow.md)

**Status:** ready-for-agent

- [ ] 人物／物件与场所文本保留规格要求的名称、身份、类别、描述和来源；物件通过结构字段区分服装与道具，不从正文猜测。
- [ ] 描述文本与对象引用分别提供明确出口；对象引用只含身份、名称和必要类别，不携带描述、图片或祖先内容。
- [ ] 同一画布不同独立对象的创建、改名与复制遵守名称唯一；跨画布可重名，不按名称、文件或文本相似度自动合并身份。
- [ ] 对象身份独立于卡片标题和布局；合法未完成内容允许保存，没有合法名称及身份时不伪造有效对象引用。
- [ ] 文本卡不提供人物、道具、服装或场所资产选择；描述直接接入文本模型并按明确采用参与生成。
- [ ] 保存重开、字段修改与只读来源保持一致；同类对象的后续引用使用统一对象契约，不自动创建旧场次实体。
- [ ] 具备真实绑定后，改名与删除沿统一绑定保护传播必要变化；在尚无采用时不制造额外确认或虚构绑定。

规格依据：[总体规格](../spec.md)。共同约束与验证边界见[任务索引](../README.md)；本票未开始实现，勾选项不代表已通过验收。
