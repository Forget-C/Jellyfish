# 03: 约 1 秒自动保存与下游刷新

**What to build:** 用户持续编辑时约每秒合并保存，保存成功后看到相关下游输出更新；网络延迟、保存失败或冲突不会覆盖新编辑或伪造已生效内容。

**Blocked by:** [01 新协议下的文本生成闭环](01-text-protocol-flow.md)

**Status:** ready-for-agent

- [ ] 本卡编辑立即反馈，有修改时约每 1 秒合并提交最新内容；持续输入期间也保存，无修改不发送请求，不改成停止输入后的去抖。
- [ ] 同一画布保存请求串行；在途期间只保留最新待保存内容，不为每次输入排队，回执推进保存基线而不覆盖后续编辑。
- [ ] 保存成功后由后端统一计算相关明确输出与诊断；前端按对应已保存修订刷新候选及已采用内容展示，旧输出响应不能覆盖较新状态。
- [ ] 手动保存和点击生成立即处理待保存修改，不等下个周期；已有请求仍串行协调，保存或预检失败时不继续提交生成。
- [ ] 失败或冲突保留本地编辑并提示，同一无效内容不每秒重复报错；结果未明沿用原请求身份核实，修订冲突不静默覆盖。
- [ ] 已保存输出与本地编辑状态可区分，不新增草稿实体、草稿发布流程或保存前跨卡输出预览接口。
- [ ] 保存与输出刷新不自动采用新增候选、不触发模型、不改历史；模型结果发布仍走既有结果生命周期。
- [ ] 约 1 秒只定义保存合并周期，实际下游延迟还包含请求和计算；布局整理不因此制造生成依据变化。
