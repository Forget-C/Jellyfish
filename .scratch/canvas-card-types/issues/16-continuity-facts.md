# 16: 空间规则、连续性与不可改事实

**What to build:** 用户明确空间规则、连续性前后态和不可改事实，关联具体证据后完整用于生成；证据保持固定且不自动变成模型输入。

**Blocked by:** [14 叙事与镜头设计](14-narrative-shot-design.md)

**Status:** ready-for-agent

- [ ] 空间规则保留可拍区域、轴线、尺度与范围；连续性保留类别、前态、变化、后态和后续约束；不可改事实保留事实、来源、范围、阶段与条件。
- [ ] 所属空间、参与对象、关联事件及作用对象按具体字段限制直接选择，不按名称或素材相同推断身份。
- [ ] 前后态、证据与示例关联明确文件、产物、用途和字段／区间位置，来源再次生成不会替换已选具体证据。
- [ ] 三个工具默认完整采用，保留图片目标配置所需的明确状态标识，不通过删除其他字段来形成静态画面；目标选择交互由摄影与图片目标状态票据提供，双方完成后的组合在收口票据核对。
- [ ] 本卡设计及必要标识直接参与文本、图片和视频生成；证据、场所正文和对象图片仍需模型另行直接采用。
- [ ] 事实标记保留但不验证自然语言或图片真实性；只校验明确结构与数据，开放状态不自动升级为已确认硬约束。
- [ ] 同一明确目标下的已知互斥硬要求可定位处理，不建立全场／镜头自动适用性或完整性系统。
- [ ] 替换或删除被采用来源须明确处理绑定，固定证据不豁免直接关系；运行及历史保留原依据和文件保护。
