# 14: 叙事与镜头设计

**What to build:** 用户组织叙事概览、节拍、事件和镜头设计，明确关联人物与调度，再将完整设计用于生成；不创建完整场次计划。

**Blocked by:** [11 空间锚点与空间调度](11-spatial-direction.md)

**Status:** ready-for-agent

- [ ] 四类工具保留观察视点、信息／人物关系变化、转折、行动目标、阻碍、可见结果、预计时长及待确定状态等完整字段。
- [ ] 节拍、事件与镜头提供各自稳定对象引用；普通文本提到的名称不自动变成这些业务身份。
- [ ] 镜头的参与对象、覆盖节拍、关联事件、调度依据按直接候选明确选择；对象数量、类别和来源按端点限制，预览不增加关系。
- [ ] 新增节拍与事件来源接入既有接收方的所属节拍、接收事件、变化事件、触发事件等可选声明，保留不同用途，不跨级展开正文。
- [ ] 镜头对象可提供摄影所属镜头候选；摄影接收声明与本票来源契约一致，双方交付后在组合流程核对，不要求无镜头摄影先补完整计划。
- [ ] 叙事与镜头设计默认整卡输出，可直接用于已支持的文本／视频生成并向图片编译提供完整设计；明确状态按统一目标契约表达，选择交互与摄影票据在组合流程核对，不根据整场／镜头自动筛选或补齐输入。
- [ ] 预计镜头时长不等于真实媒体区间，关系不代表实际覆盖或自动执行；生成结果不自动确认节拍、镜头或设计版本。
- [ ] 保存重开、复制改名、删除与失效诊断覆盖本票对象和引用；验收依据由后续验收要求来源接入，不预建反向关系。

规格依据：[总体规格](../spec.md)。共同约束与验证边界见[任务索引](../README.md)；本票未开始实现，勾选项不代表已通过验收。
