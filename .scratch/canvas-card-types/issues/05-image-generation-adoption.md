# 05: 图片生成与结果选择

**What to build:** 用户分别选择直接文本与图片输入，核对实际请求并生成图片；结果逐项选择、比较或另存，采用不由连线或预览决定。

**Blocked by:** [04 基础媒体导入与明确输出](04-media-content-outputs.md)

**Status:** ready-for-agent

- [ ] 图片模型使用统一输入绑定消费文本依据与参考图片，支持明确顺序和子集；未选候选不进入请求、不扩大运行依赖。
- [ ] 可选参数、参考数量、重复素材及组合限制来自已接入模型能力，前端提示与后端预检一致，不因卡片目录新增而虚构控制能力。
- [ ] 编译预览列出实际文本、图片、顺序与用途，正式提交固定同一依据；自由文本不被纠错或用于猜测额外绑定。
- [ ] 多结果保持有序结果集与各自身份，预览某项不自动采用第一项、全部结果或改写来源顺序。
- [ ] 当前输出位置、固定产物、历史与未完成成果分别表达；新增结果只成为候选，不扩大已有采用集合。
- [ ] 结果可明确另存为独立图片并保留来源，也可成为下游直接候选；不自动回写输入、建立回环或触发再次生成。
- [ ] 失效选择、文件保护、取消、重开观察及错误定位随该生成路径完成，不能以已有文本链路通过代替本票行为验证。

规格依据：[总体规格](../spec.md)。共同约束与验证边界见[任务索引](../README.md)；本票未开始实现，勾选项不代表已通过验收。
