# 02: 项目入口与独立工作台页面

**What to build:** 用户从项目进入完整画布工作区，选择或新建画布并继续既有编辑与生成；页面布局沿用场次工作台，但使用独立画布身份。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**Completion:** implemented (awaiting integration)

- [x] 项目入口打开独占工作区的完整页面；地址可定位项目与画布，支持直接重开、未选择时选择／新建，以及返回项目。
- [x] 顶部画布身份与保存状态、操作区、左侧三组目录、中央画布、右上单一浮动详情和底部辅助区布局符合工作台约定；目录随实际已交付类型登记，不显示可点击的空壳能力。
- [x] 必要的工作台外壳提取在本票完成并用于真实页面；复用主题、按钮、详情、弹窗和画布交互，不挂载整个场次工作台或引入场次版本与四画布切换。
- [x] 打开和展开详情不挤压、平移或重排画布；窄屏、长文、媒体、弹窗滚动及键盘操作保持可用，标题拖动与内部控件事件隔离。
- [x] 画布选择、新建、名称、只读、冲突、未保存修改及编辑所有权使用画布自己的状态；导航和页面切换保留恢复及未知请求结果保护。
- [x] 保留拖拽、分组、缩放、定位、小地图及撤销／重做等规定操作；内容编辑、布局整理和浏览历史分别管理，布局变化不改变生成依据。
- [x] 运行观察、预检和历史入口在完整页面可用，关闭详情或离开弹窗不终止任务；任务中心仍只显示通用状态并能回跳本画布。
- [x] 共享控件调整保持现有场次工作台业务行为，不引入章节接口改造、导演画布试点或其他画布迁移。

规格依据：[总体规格](../spec.md)。共同约束与验证边界见[任务索引](../README.md)。实际实现与验证证据如下。


## Comments

### 2026-10-28：独立工作台页面实施

- 在独立工作树、分支 codex-canvas-types-02 实施，开始时基于集成分支 06519b3。02 只改变页面、布局和编辑交互，未新增后续票据的卡片类型或接口。

- 工作台使用既有主题、工具栏、按钮、浮动详情、操作弹窗和任务中心；摘要卡打开同一详情位置，宽／窄屏保持编辑内容，详情展开不移动视口。恢复与冲突沿用原动作，在一致性保护弹窗处理。
- 左侧按实际可用类型分组，底部支持视口、定位、小地图、布局整理及整理撤销；内容撤销／重做在唯一文档编辑器中维护，不包含运行或布局。
