# 02: 项目入口与独立工作台页面

**What to build:** 用户从项目进入完整画布工作区，选择或新建画布并继续既有编辑与生成；页面布局沿用场次工作台，但使用独立画布身份。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 项目入口打开独占工作区的完整页面；地址可定位项目与画布，支持直接重开、未选择时选择／新建，以及返回项目。
- [ ] 顶部画布身份与保存状态、操作区、左侧三组目录、中央画布、右上单一浮动详情和底部辅助区布局符合工作台约定；目录随实际已交付类型登记，不显示可点击的空壳能力。
- [ ] 必要的工作台外壳提取在本票完成并用于真实页面；复用主题、按钮、详情、弹窗和画布交互，不挂载整个场次工作台或引入场次版本与四画布切换。
- [ ] 打开和展开详情不挤压、平移或重排画布；窄屏、长文、媒体、弹窗滚动及键盘操作保持可用，标题拖动与内部控件事件隔离。
- [ ] 画布选择、新建、名称、只读、冲突、未保存修改及编辑所有权使用画布自己的状态；导航和页面切换保留恢复及未知请求结果保护。
- [ ] 保留拖拽、分组、缩放、定位、小地图及撤销／重做等规定操作；内容编辑、布局整理和浏览历史分别管理，布局变化不改变生成依据。
- [ ] 运行观察、预检和历史入口在完整页面可用，关闭详情或离开弹窗不终止任务；任务中心仍只显示通用状态并能回跳本画布。
- [ ] 共享控件调整保持现有场次工作台业务行为，不引入章节接口改造、导演画布试点或其他画布迁移。

规格依据：[总体规格](../spec.md)。共同约束与验证边界见[任务索引](../README.md)；本票未开始实现，勾选项不代表已通过验收。
