# 40: 堆叠收纳、只读查看与关系保护

**What to build:** 用户把多选卡片收纳为堆叠，只读查看成员并整体移动；解除后恢复相对位置与多选，输入关系和已有生成任务不会被收纳操作破坏。

**Blocked by:** 35、37、38、39

**Status:** ready-for-agent

- [ ] 多选上方菜单可创建堆叠；只直接收纳普通卡，不嵌套容器，不与编组或其他堆叠重复归属，混合已有归属时不隐式拆组或跳过部分成员。
- [ ] 默认显示重叠卡面与成员数量，悬浮及键盘／触摸等价入口显示数量和解除动作；点击打开覆盖画布的只读查看层，不改变画布视角，全部成员可读、图片可放大、媒体可播放。
- [ ] 查看层不允许编辑成员、拖成员、连线、采用或发起生成；空白、关闭按钮或 Escape 仅退出查看，仍保持堆叠。成员的已有编辑或诊断入口不能绕过只读，诊断定位堆叠并提示先解除。
- [ ] 堆叠整体拖动保存相对位置；解除时未移动恢复原位置，移动后按整体位移恢复，成员回到多选和上方菜单、不打开编辑、不自动网格重排。
- [ ] 内部成员线隐藏，外部线在堆叠边缘汇入但保留原成员、方向和各用途，可读成员名称；不新增集合输出或连接端点，不合并候选与采用。
- [ ] 接收端在堆叠内时剪刀提示先解除，即使未采用也不删除；删除外部来源会连带断开其输入时同样阻止，不能通过卡片删除绕过。接收端在外部则可按正常规则管理自己输入，有引用仍只提示取消、不跳转。
- [ ] 堆叠不冻结输出、不取消既有运行；已受理结果正常更新。新增生成须先解除并进入模型编辑区，不恢复批量／全画布运行，外部模型使用成员的既有有效输出仍遵守直接采用规则。
- [ ] 组织信息与成员身份通过既有画布保存恢复，坐标与视口保持布局职责；刷新重开不丢成员、相对位置或外部线，不把旧可编辑折叠组展开当作只读查看。必要契约同步，不新增跨设备布局同步。
- [ ] 整理将堆叠与编组各当整体，保持成员相对位置；布局撤销与整理后解除均正确。组织动作不改变成员内容、绑定、输出协议或真实运行历史。
- [ ] 真实页面＋HTTP 验证三态、触摸／键盘、移动解除、保存重开、禁止编辑与诊断门禁、多用途线、直接及连带删除保护、外部接收端取消引用、已有运行更新及整体整理撤销；提供三态视觉证据且不预记通过。

规格依据：[堆叠与编组](../spec.md#堆叠与编组)、[删除候选与处理已采用绑定](../spec.md#删除候选与处理已采用绑定)、[卡片下方编辑区与复杂卡片 Modal](../spec.md#卡片下方编辑区与复杂卡片-modal)。共同边界见[任务索引](../README.md#q1q32-交互收口增补3442)。
