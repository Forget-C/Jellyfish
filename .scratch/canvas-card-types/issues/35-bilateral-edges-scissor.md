# 35: 左右连接点、连线高亮与剪刀删除

**What to build:** 用户从左右连接点建立候选，持续看到拖线反馈，能准确选中某条用途连线并通过剪刀删除未使用的候选，而不会误删实际输入。

**Blocked by:** 34

**Status:** ready-for-agent

- [ ] 仅保留左右中点各一个几何连接点，悬浮／聚焦／选中时显示；平时无字段标签，提示仅显示声明输出摘要。点位不代表固定左入右出，也不为无输入基础卡增加接收能力。
- [ ] 按下连接点立即显示随指针移动的临时线；兼容吸附、零用途拒绝、唯一用途直接建立候选、多用途落点菜单选择及取消均保持。唯一结果或唯一用途也不自动采用。
- [ ] 保留无输出预布线、关系去重、多用途独立错线及直接上游／统一无环校验；同卡对不同用途可单独选择，不合并输出或绑定。
- [ ] 旧左右侧边保留，旧上下或无侧边记录按规格仅归一几何落点；移动、缩放及同浏览器重开保持左右侧边，不改业务身份或生成依据。
- [ ] 悬浮／聚焦连线动态高亮；选卡仅高亮直接关系。选线时仅当前线高亮并在点击位置附近固定展示剪刀和用途，移向剪刀不消失；边界避让，减少动态效果时静态反馈可辨。
- [ ] 剪刀只检查通过当前线建立的采用／绑定，有引用仅提示先取消，不自动取消、不提供组合删除、不跳转编辑区；无引用直接删除该用途。目标使用其他连线不阻止删除，其他用途与绑定不受影响。堆叠接收端的额外保护由 40 接入同一删除边界。
- [ ] 空白／Escape 清除线选择和剪刀，切换目标仅保留新操作；提供键盘及触摸等价入口、有效焦点和只读禁用说明。
- [ ] 真实分段拖线、鼠标／键盘／触摸剪刀操作及 HTTP 保存重开覆盖取消、重复、多用途、环路、引用保护与恢复；实际观察动态效果并保留中间状态证据，不以截图替代动作验证。

规格依据：[左右连接点、悬浮输出与连线确认](../spec.md#左右连接点悬浮输出与连线确认)、[连线高亮与剪刀删除](../spec.md#连线高亮与剪刀删除)、[删除候选与处理已采用绑定](../spec.md#删除候选与处理已采用绑定)。共同边界见[任务索引](../README.md#q1q32-交互收口增补3442)。
