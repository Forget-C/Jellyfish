# 11: 空间锚点与空间调度

**What to build:** 用户建立场所内的锚点、人物站位走位和镜内活动，完整采用空间设计进行生成；参考示意与实际模型媒体输入分开。

**Blocked by:** [10 人物表演与情境生成](10-performance-direction.md)

**Status:** ready-for-agent

- [ ] 四类工具按规格保留稳定身份、位置方位、空间关系、尺度、朝向、路径、主动权、延迟、入出画、结束状态及活动／留白说明等适用字段。
- [ ] 锚点位于导演工具箱的表演与调度，可先用文字建立再关联图片标记；替换参考素材不改变锚点身份。
- [ ] 所属空间、参与对象、位置锚点、区域锚点和作用对象仅从直接且类别匹配的候选选择；选择场所身份不读取场所正文或图片。
- [ ] 空间锚点提供明确对象引用供调度选择，站位与走位提供调度对象供后续镜头引用；名称与身份不变成跨级读取许可。
- [ ] 变化事件与触发事件按各自用途声明可选关系，后续事件来源接入时不合并成一种关系，也不自动推导触发行为。
- [ ] 设计默认完整采用，可直接生成文本或视频；位置设计需要锚点全文或示意媒体时，模型须分别直接连接并采用。
- [ ] 素材关联按类型限制图片／视频等允许范围和定位，不自动成为生成首尾帧；关系、输出和文件保护随保存重开保持。
- [ ] 未填写非必要关系不阻断独立有效生成；自由描述不用于猜测同名锚点、参与对象或自动补齐阶段。

规格依据：[总体规格](../spec.md)。共同约束与验证边界见[任务索引](../README.md)；本票未开始实现，勾选项不代表已通过验收。
