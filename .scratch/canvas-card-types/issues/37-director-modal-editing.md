# 37: 复杂导演卡 Modal 与诊断定位

**What to build:** 用户选中复杂导演卡后通过编辑按钮进入集中编辑的 Modal，并可从诊断直接定位相关字段；关闭遮罩也能安全结束展示并保留输入。

**Blocked by:** 36

**Status:** ready-for-agent

**Completion:** integrated

- [x] 摄影五入口、画面风格、表演与调度（含空间锚点）、叙事与镜头、声音、连续性与约束全部进入 Modal。普通卡面释放只选中并显示右上按钮，不自动打开；键盘聚焦可达。
- [x] 选中复杂卡收起旧普通卡编辑区并保留会话；打开已有卡编辑自身内容，摄影新卡记住所选入口并在首次打开定位，不合并不同方案。
- [x] 按实际内容展示预设／预览或背景、设计、约束和关系分区，保留全部自身字段与直接候选能力；不为图示引入未支持相机参数、字段或集合输出。
- [x] Modal 遮罩隔离底层操作，长内容内部滚动，必要动作及关闭可达；可用遮罩、关闭按钮或 Escape 关闭，内层控件优先，遮罩点击不穿透为画布点击。打开不移动画布，退出恢复合理焦点。
- [x] 普通字段沿用约 1 秒自动保存及保存成功后更新输出，关闭不丢弃内容或停止既有保存；预设应用／取消只处理该选择，不新增整卡草稿或确认事务。
- [x] 用户显式点击处理问题／定位字段可直接打开相应编辑容器并定位，普通点击仍需按钮进入；不把剪刀保护提示改成自动跳转。堆叠成员诊断的只读门禁由 40 接入。
- [x] 真实页面逐类验证阅读、编辑、对象关系、预设、诊断定位、关闭重开和失败恢复；HTTP 核对字段、整卡／摄影局部输出及绑定保持，覆盖键盘、遮罩与窄屏滚动并提供视觉证据。
