# 12: 摄影设计与图片目标状态

**What to build:** 用户在一张摄影内容卡中编辑画面设计，按声明范围采用；图片模型可为已有结构化阶段指定画面目标，同时保持表演等设计完整采用。

**Blocked by:** [10 人物表演与情境生成](10-performance-direction.md)

**Status:** ready-for-agent

- [ ] 构图、机位、运镜、光影和焦点入口编辑同一张摄影内容卡；不创建多张可编辑投影同步隐藏对象，也不因所属镜头相同自动合并独立方案。
- [ ] 保留规格中的摄影字段、状态、用途和必要关系，支持专用摘要与详情编辑；没有镜头仍可独立使用，所属镜头按可选对象输入声明。
- [ ] 摄影输出明确列出允许完整或局部采用的区域、字段／状态及动态条目；选择保存稳定标识，改名或重排不改变所指范围。
- [ ] 仅采用运镜后新增光影不扩大输入；字段清空与条目删除分别处理，合法空值不强制改绑，失效条目不得回退旧值。
- [ ] 图片模型可从已采用导演输出明确提供的结构化阶段／状态选择画面目标；对人物表演等整卡输出保留全部设计，仅增加本张图的目标配置。
- [ ] 不从普通文本或动作自由描述推断阶段并强制选择时刻，不为此新建阶段字段；明确结构化多阶段的必要目标校验按规格处理。
- [ ] 文本、图片和视频编译保留背景、设计、约束与状态；只对同一明确目标／状态下必须同时满足的已知互斥结构要求诊断，开放提议不当作硬冲突。
- [ ] 摄影直接对象、参考素材和后续验收／镜头关系遵守一跳与统一无环；关联示例不自动进入生成。
- [ ] 手工编辑到保存、采用、编译预览、图片／视频生成构成可用链路；可视化预设在下一票扩展，不以占位选项替代本票编辑能力。

规格依据：[总体规格](../spec.md)。共同约束与验证边界见[任务索引](../README.md)；本票未开始实现，勾选项不代表已通过验收。
