# 38: 多选工具菜单与视觉编组

**What to build:** 用户通过修饰键、框选或触摸明确选择多张卡片，在选区上方组织为视觉编组；成员可独立编辑，组内空白拖动整体移动，组织与布局可恢复。

**Blocked by:** 34

**Status:** ready-for-agent

- [ ] macOS Command、Windows／Linux Ctrl 点击卡片加入或移出集合；普通画布空白拖动无需按键即可框选并替换集合，松开鼠标或修饰键保留选择。多选期间收起单卡编辑展示并保留会话。
- [ ] 普通点击非上方菜单区域或 Escape 退出多选；点击卡／线接续普通单选，直接拖成员退出多选仅拖该卡。修饰键成员切换、触摸多选和仅调整筛选高亮的动作不先清空集合。
- [ ] 选区上方展示数量及已可用的组织操作，按视口避让；不新增布局／下载菜单，移除旧左下重复编组入口。堆叠行为由 40 接续，不用无效占位冒充可用功能。
- [ ] 没有修饰键的设备可从卡片菜单进入选择多个，点击成员切换而不打开编辑；有完成选择／退出入口，空白退出，仅适用状态显示选择标记；键盘可访问相同动作。
- [ ] 创建编组显示名称及外框，成员仍可选择、编辑及连线；成员身份只通过明确加入／移出改变，拖过边框不自动改组，解除编组只移除组织关系并保留位置和内容。
- [ ] 拖组内卡仅移动该卡，外框随完整成员范围调整；拖组内无卡片空白整体移动。Space 平移优先，其次 Command／Ctrl 组内框选，无上述键才整组移动，手势开始后锁定用途。
- [ ] 编组直接包含卡片，不嵌套或重复归属；混合已有归属的选择不能隐式拆组或静默只处理部分。保存／重开保持名称、成员及既有布局身份，不影响输出、采用与生成依据。
- [ ] 既有左下布局菜单保留；整理时将编组作为整体、未归属卡单独整理，保持组内相对位置，撤销恢复，不增加组内整理功能。堆叠整理由 40 接入同一规则。
- [ ] 真实页面与 HTTP 验证系统按键、框选／取消、触摸模式、创建／改成员／解除／重开、组内三种空白手势及布局整理撤销；检查组织前后候选、绑定和内容不变，提供上方菜单与编组视觉证据。

规格依据：[普通选择与显式多选](../spec.md#普通选择与显式多选)、[堆叠与编组](../spec.md#堆叠与编组)、[画布手势优先级](../spec.md#画布手势优先级)。共同边界见[任务索引](../README.md#q1q32-交互收口增补3442)。
