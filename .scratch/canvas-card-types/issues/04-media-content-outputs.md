# 04: 基础媒体导入与明确输出

**What to build:** 用户导入或选择图片、视频、音频，保存重开并预览；每张内容卡提供有身份、来源与可用状态的明确媒体输出。

**Blocked by:** [01 新协议下的文本生成闭环](01-text-protocol-flow.md)

**Status:** ready-for-agent

- [ ] 图片、视频和音频内容卡可通过允许的上传、项目文件选择等入口建立，保存重开保持实际文件与来源；不新增音频生成。
- [ ] 按真实媒体展示图片、视频或音频预览及必要信息，视频保留自带音轨；预览、播放和选中卡片不建立模型采用。
- [ ] 输出使用强类型媒体内容、稳定输出标识、有效文件引用与必要来源；上传未完成或文件不可用时不提供有效媒体值。
- [ ] 文件类型、项目归属、可用性和使用关系经过校验；跨项目或失效文件有可定位诊断，不能以任意 URL 或文件名代替有效引用。
- [ ] 普通媒体卡通过明确导入、选择或另存形成自身内容，不新增持续输入；复制／另存保留只读来源，不建立反向读取。
- [ ] 保存、恢复、删除及文件保护适配新增输出和引用位置；已有引用或运行历史所需文件不因卡片预览关闭而失去保护。
- [ ] 不隐式执行视频取帧、音频转写或图片描述，不增加文本模型的媒体理解输入；具体模型消费由后续生成票据按能力开放。

规格依据：[总体规格](../spec.md)。共同约束与验证边界见[任务索引](../README.md)；本票未开始实现，勾选项不代表已通过验收。
