# 50: 基础图片卡编辑区与文件状态

**What to build:** 用户在图片卡下方查看大预览及真实文件信息，通过统一主题入口选择、上传或替换图片，并在无图、加载、失败和只读时得到明确反馈。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**Completion:** integrated — 已合入 codex-generation-canvas，最终双轴复核通过。

- [x] 桌面采用大图片预览＋窄文件信息区，显示实际文件名、来源、可获得的尺寸与类型；未知元数据明确为空或未知，不填原型示例值；窄屏先预览后信息。
- [x] 无图时保留图片图标、简短引导及主题化上传／选择入口；有图时替换／选择可达，浏览器原生文件 input 不直接露出。内容卡不出现模型参数或运行提交。
- [x] 覆盖上传／加载、选择取消、替换失败、长文件名和只读；失败不假装成功，不丢原文件；沿用文件归属、保存与迟到响应保护，不因本次视觉修改扩充媒体能力。
- [x] 默认、展开、切换和关闭保持同一媒体／编辑会话；真实文件信息及固定内容保存重开正确，不因来源再次生成自动替换。参考卡的名称、角度和绑定契约不变。
- [x] 通过真实页面与公开 HTTP 验证无图→上传／选择→替换→失败恢复→保存重开；受控外部存储沿用既有接缝，覆盖 C01、C02，不将本地 Object URL 原型当上传成功。
- [x] 实际查看桌面及390px的空态、有图、加载／失败、只读和展开截图，对照 C 的预览／信息比例、一体化底色与主题操作，关闭和必要动作可达，无横向溢出。

规格依据：[最新实现规格](../spec.md)中的 C「焦点编辑」专节及 C01–C08 验收；既有候选／采用、卡片字段、单模型提交、保存和输出协议继续适用。共同范围与依赖见[任务索引](../README.md)。
