# 52: 线旁剪刀与路径焦点

**What to build:** 用户以鼠标、键盘或触摸选择连线时只看到当前线的高亮及原位置附近的小剪刀，删除纯候选或获得明确引用保护提示，不再出现巨大矩形外框和关系详情面板。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 鼠标悬浮／键盘聚焦沿路径高亮，点击清除卡片选择、收起其编辑区并仅选择当前线；无整条SVG包围盒矩形 outline，不通过移除键盘可达性来消除外框。减少动态效果时使用静态路径反馈。
- [ ] 原点击附近在线上固定显示白色小剪刀并做边界避让，不显示大型“连接详情／剪断连接”面板；用途／来源提示仅在剪刀悬浮或聚焦时出现。移向剪刀不会使其消失，命中区与焦点可辨。
- [ ] 纯候选仅删除当前用途连接；当前线存在真实采用／绑定则仅提示先取消，不自动取消、不跳转编辑区；目标使用其他线不阻止当前纯候选删除。接收端堆叠、只读和来源连带删除保护保持原规则。
- [ ] 覆盖切换选线、空白／Escape退出、Tab／Enter和触摸等价操作；删除后焦点回到有效入口，单一普通操作对象、关联高亮及编辑会话保护不变。
- [ ] 按 C05 在真实页面走查并通过 HTTP 保存回读验证边与绑定；保留多用途、堆叠、只读、引用保护回归，不能只用静态截图证明删除正确。
- [ ] 实际查看用户线旁剪刀原图、正式鼠标／键盘选线和边界位置截图，核对图标、尺寸、位置、按需提示及无矩形外框；记录差异，不把旧大关系面板截图当目标。

规格依据：[最新实现规格](../spec.md)中的 C「焦点编辑」专节及 C01–C08 验收；既有候选／采用、卡片字段、单模型提交、保存和输出协议继续适用。共同范围与依赖见[任务索引](../README.md)。
