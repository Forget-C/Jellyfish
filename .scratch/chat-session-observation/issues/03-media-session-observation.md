## What to build

图片和视频试模在进入已有会话后立即观察任务，提交新任务时沿用当前会话订阅。

## Acceptance criteria

- [x] 图片和视频分别验证，快照恢复已有任务、输入、进度和产物，从其公共游标补读间隙提交的事件并继续跟踪活动任务。
- [x] 普通发送返回受理回执后，从已打开的同一条 SSE 读取本次任务受理与进展。通过页面网络请求确认发送前后各只有一条会话订阅。
- [x] 断线后补读未应用的事件，重复载荷按稳定任务和消息身份合并。翻阅历史不倒退实时游标，也不丢失任务进度、终态或产物。
- [x] 图片与视频参数回填及任务卡操作继续可用，切换会话后旧任务事件不更新当前视图。
