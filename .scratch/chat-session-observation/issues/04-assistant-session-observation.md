## What to build

画布助手和实验室多模态聊天沿用同一套快照与事件衔接，继续处理各自的追问、停止和场景待办。

## Acceptance criteria

- [x] 两个页面都在打开时从共享快照建立一条订阅，发送和续答经现有订阅接收结果。断线后按最后已应用游标续读，迟到的旧回执不重置当前订阅位置。
- [x] 连续追问后从历史恢复或补读时，已回答的追问不会重新成为可操作问题。重传原发送或一次续答可取回对应原回执及游标，实际执行次数不增加。
- [x] 收到 202 后、SSE 首帧或追问核实仍挂起时可显式停止。确认停止后释放发送限制。画布停止所返回的历史及游标遵循公共快照规则。
- [x] 关闭后重开可恢复原轮次。画布审批及待答问题仍可处理，多模态任务状态继续更新。切换会话隔离迟到快照与事件。
