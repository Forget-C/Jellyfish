# 02 · 图片和视频迁移只读回执查询

Status: ready-for-agent

Completion: resolved

Integration commit: 42824fd0
Blocked by: None

## What to build

图片和视频试模的发送响应丢失时，用户可以在已绑定的会话内按原请求身份核实受理结果，并取得原来的回放起点。

## Acceptance criteria

- [x] 通过统一会话公开入口按原请求身份查询，核对会话类型与归属。对图片和视频分别验证，任务运行中或已结束时，返回的 session_id、turn_id、cursor 与原发送回执逐字段相同。
- [x] 查询未知身份时有明确的未查到结果。对运行中、已结束和未知身份分别核对，查询均不新增轮次、不提交任务，任务进度和产物从快照与 SSE 取得。
- [x] 使用图片和视频页面复现发送响应丢失，验证正式前端经统一只读查询找回原受理。切换会话后，迟到回执只影响原会话。
- [x] 同步公开契约和生成客户端。旧查询在迁移验收阶段继续服务，待 05 统一退役。
