# 01 · 文本试模重开后续接原轮次

Status: ready-for-agent

Completion: resolved

Integration commit: 9e855909
Blocked by: None

## What to build

用户从历史打开文本试模时，先看到已保存的回复，再持续看到原轮次的新增内容。通过文本试模交付五类会话可共用的快照与订阅流程。

## Acceptance criteria

- [x] 公开快照由共享服务按会话类型读取。用公开 HTTP 和可控的文本运行验证，历史与快照游标对应同一可观察位置。快照读取后、SSE 建连前提交的事件能补读。用消息序号与事件游标不同的样本验收。
- [x] 浏览器中让原轮次保持运行，分别验证切换会话和关闭后重开。离开只解除订阅，未发送停止请求。重开显示已有部分回复，在同一轮收到后续增量和终态，期间没有再次发送。
- [x] 显式点击停止时取消原轮次，页面从服务端确认结果。终态还无法核实时保留已知内容并显示状态待核实。
- [x] 当前视图只保留一条会话订阅。普通发送经该订阅接收结果，断线后按最后已应用事件续读。历史翻页不重置游标，迟到快照和上一会话的响应不会覆盖当前状态。
