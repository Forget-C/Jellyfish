## What to build

所有正式调用方完成迁移后，统一入口接管会话操作及历史恢复。部署方可从公开说明识别退役入口和替代方式。

## Acceptance criteria

- [x] 确认五类页面、媒体只读回执核实和画布停止均使用对应统一契约。删除旧客户端方法和历史 Hook 中的旧读取入口。OpenAPI 与生成客户端只保留仍生效的操作。
- [x] 按父规格退役仅按 ID 的发送、续答和订阅、旧会话快照与消息读取、旧媒体受理查询及两个旧画布停止别名。用原 HTTP 方法和有效输入验证每个入口无法再执行原操作。
- [x] 同步架构文档和公开接口变更说明，列出替代入口和媒体幂等键要求。核对旧历史清空与业务操作仍可用。
- [x] 从统一入口读取并回放旧文本已知终态、画布历史续答和媒体受理载荷。核对各操作的原回执及 SSE 起点仍可取得，重复提交不重复执行。
- [x] 通过五类会话的公开 HTTP 与 SSE 契约回归，以及对应页面的恢复、停止和受理核实回归。
