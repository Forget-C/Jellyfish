# 04: 简化叙事与空间卡的通用对象关系

Status: ready-for-agent
Completion: completed
Blocked by: 01

**What to build:** 用户在叙事或空间字段中表达一般对象关联，事件身份、空间归属和锚点定位继续稳定工作；清理旧作用对象不影响这些卡片作为其他设计来源的能力。

## 范围与约束

- 处理 `direction.narrative`、`direction.event`、`direction.space_rule`、`direction.anchor` 的 `effect_object`。
- 依赖 01 的类型定向清理与运行／编辑历史保护；不依赖其他卡组迁移。
- 不重设计叙事身份、事件用途、所属空间、锚点图片标记及下游定位。
- 规格依据：Implementation Decisions 1、3、6–9；User Stories 1–8、27–28、33–38、42–47。

## Acceptance criteria

- [x] 四类卡片移除通用作用对象输入用途、绑定和控件，字段编辑、名称标签及已有元信息显示保持。
- [x] 叙事概览和事件通过叙事字段／动作或变化说明表达相关对象；纯文本可用，需要稳定来源时引用完整内容，不自动建立角色。
- [x] 事件稳定身份及其他卡片对它的接收事件、变化事件、触发事件等用途保持有效，不因事件内部清理而失效。
- [x] 空间规则与锚点保留所属空间；位置、空间关系等字段可引用完整来源，不能把引用自动转成空间归属。
- [x] 锚点身份、图片标记及下游位置锚点／区域锚点关系保持；顺序、单项约束和定位对象不改变。
- [x] 清理旧通用用途时，同源所属空间、字段引用或其他有效用途完整保留；不存在合法剩余用途才清除连接，仍可引用的来源保留为纯候选。
- [x] 不自动补写正文、转换为其他关系或删除旧素材／其他失效引用；清理只移除废弃用途独有的依赖。
- [x] 同来源经有效字段及保留业务关系进入生成时继续按身份去重；来源身份和字段定位不因重开或排序变化而改绑。
- [x] 四类卡片读取／保存清理幂等；正常编辑可撤销，旧撤销／重做快照及保存重开不恢复废弃用途。
- [x] 扩展四类旧冲突快照的执行拒绝，保留已发起请求、完成历史和无冲突运行的原有行为。
- [x] 契约、生成客户端及受影响说明同步；不改动节拍、镜头、调度等卡片自身的业务规则。

## 验证方式

- 扩展叙事／空间公开接口测试，逐类覆盖旧文档清理、事件与锚点作为下游来源、空间归属与正文同源、编译依赖以及身份稳定性。
- 真实浏览器验证字段引用、名称、锚点标记、下游关系、保存重开及撤销／重做；保留既有覆盖节拍顺序和空间单项关系回归。
- 使用既有快照准入测试验证本票类型，复用历史执行边界证据；前端 typecheck、后端相关测试及应用 Pylint，公共契约变化同步 OpenAPI 与生成客户端。
