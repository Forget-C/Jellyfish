# 02: 简化四类通用要求卡

Status: ready-for-agent
Blocked by: 01

**What to build:** 创作控制、生成指导、不可改事实和表演规则通过各自正文与完整来源引用表达涉及对象，去掉重复的对象采用步骤；用户重开旧数据时，仍能使用原有文字、合法候选和其他有效关系。

## 范围与约束

- 仅处理 `direction.creative_control`、`direction.guidance`、`direction.fact`、`direction.performance_rule` 的 `effect_object`。
- 依赖 01 已打通的用途退役、合法候选保留、旧编辑状态规范化和历史执行保护，按类型扩展，不复制清理机制。
- 不给这四类卡片新增验收式附着关系，不调整其字段含义、本地示例或适用范围。
- 规格依据：Implementation Decisions 1、3、6–9；User Stories 1–8、33–38、42–47。

## Acceptance criteria

- [ ] 四类卡片均移除通用作用对象控件、目录输入用途和可生效绑定，新的连接／保存／输出行为一致。
- [ ] 原有字段支持纯文本和完整来源引用；纯文本同名不自动绑定，字段引用不转成来源字段级采用或全部媒体采用。
- [ ] 创作控制和生成指导的名称标签与 placeholder、事实／来源依据、表演适用说明及其他原有字段完整保留，预设不重建作用对象。
- [ ] 完整来源及明确依赖按已有规则进入实际采用本设计的模型；未引用候选、本地正反例和固定证据不自动进入生成。
- [ ] 旧绑定只按本票废弃用途清理，不自动插入引用、追加对象文字或转换角色；同源有效引用、媒体选择和其他合法用途保持。
- [ ] 尚有合法字段输入的旧来源连接保留为纯候选，无合法用途的连接移除；没有重复线、废弃端点、排序残留或自动采用。
- [ ] 名称、正文、手填／预设／模型提取元信息保持，不重新出现默认状态信息；无关失效数据保留供原有流程处理。
- [ ] 旧通用绑定单独贡献的依赖退出，其他有效用途采用的同一来源继续保留并去重。
- [ ] 清理幂等且遵守修订保护；保存重开和旧撤销／重做快照不恢复废弃用途，正常编辑可原子撤销。
- [ ] 四类冲突快照均复用 01 的执行边界：未发起请求前拒绝并要求重新提交，已发起请求和完成历史不改写，无冲突运行正常。
- [ ] 没有新增随设计附着、自动素材采用、音频字段引用或结果复核能力。
- [ ] 本票公共契约、生成客户端及受影响行为说明同步，其他未迁移卡片仍保持可用。

## 验证方式

- 用公开接口按四类卡片参数化验证新建／旧数据读取／保存／编译；至少覆盖旧绑定单用、同源字段引用共用、合法候选保留及无合法用途清除。
- 扩展真实画布的创作要求、约束和表演规则用例，验证字段引用、预设、保存重开、只读及撤销恢复。
- 对每种退役类型验证冲突快照识别，复用既有实际工作器边界测试；不以只测私有清理函数代替真实执行准入。
- 前端 typecheck、受影响测试；后端相关测试与应用 Pylint。契约变化同步 OpenAPI／生成客户端，复用同代码已通过检查并记录验证局限。
