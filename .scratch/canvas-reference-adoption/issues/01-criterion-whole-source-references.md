# 01: 验收卡改用完整来源引用

Status: ready-for-agent
Blocked by: None

**What to build:** 用户通过标准正文表达验收期望，需要稳定来源时直接引用完整内容，不再选择独立“作用对象”。验收要求仍可直接被模型采用，也可随受支持的设计采用；旧画布可以安全重开，历史运行依据保持原样。

## 范围与约束

- 本票仅退役验收卡 `direction.criterion` 的 `effect_object`；其他卡片在后续票据中按组处理，不提前全局删除同名用途。
- 完成目录、连接前提示、保存／读取、输出、正常编译、运行准入、编辑界面和撤销恢复的完整路径。必要的共享清理能力在此随真实行为建立，不另建兼容框架或独立基础设施阶段。
- 复用既有完整来源引用与依赖闭包；不重新实现图或引入额外持久模型绑定。
- 规格依据：Implementation Decisions 1–3、6–9；User Stories 1–16、33–36、43–47。多路径完整组合由 08 扩展，本票基本采用与去重行为必须已可用。

## Acceptance criteria

- [ ] 验收卡不再提供通用“作用对象”控件、合法输入用途或可生效的专用绑定；前后端行为一致，不仅隐藏界面。
- [ ] 名称与标准可以正常编辑、保存和重开；保留名称可见标签、输入框 placeholder、空名称连接前提示，不新增标准正文必填条件。
- [ ] 纯文本提及素材名称不自动建立绑定；连线、预览或只有一个候选也不算采用。标准显式引用才建立稳定来源依赖。
- [ ] 描述／设计引用采用完整来源，不能只引用来源卡某个字段；明确依赖被携带。媒体和模型多项输出只采用指定项，不扩大到所有输出或历史结果。
- [ ] 标准支持现有文本、完整设计、图片和视频引用；不新增音频引用。目标模型不支持所引用媒体或用途时明确诊断，不静默丢弃；本地示例和未引用候选不自动携带。
- [ ] A → B 提供标准候选，B → 描述／素材禁止，B → D 直接采用标准；B → C 仅支持原七类设计，D 实际采用 C 时才带入 B。普通候选可达性不会扩大生成输入。
- [ ] 直接采用与随设计采用不新增额外模型连线或永久绑定。验收卡互引、互相验收及循环被拒绝；B → C 与 C → B 不可同时成立。
- [ ] 模型结果输入 B 只作标准参考，不表示提交复核；界面及输出不产生通过／不通过结论。既有只读验收缩略区、独立分区、默认收起和定位交互保持。
- [ ] 当前旧文档只清除验收卡废弃绑定，不改写名称、正文、有效引用或元信息，不转换为其他角色。旧用途单独贡献的依赖停止传递。
- [ ] 同源仍有合法用途或引用时保留；没有实际采用但仍有合法字段输入时保留为当前契约下的纯候选；无合法用途时清除连接。不存在废弃端点、重复来源线或自动补写引用。
- [ ] 保留其他有效用途及其稳定身份、顺序、定位；不顺带清除其他失效引用或旧媒体。重复读取／保存清理结果稳定，遵守既有保存修订和并发保护。
- [ ] 普通编辑继续原子撤销／重做；清理不进入普通撤销记录，旧编辑快照、重做和保存重开不能恢复废弃用途，也不丢弃无关有效编辑。
- [ ] 冲突的未执行、等待执行或重试快照在发起模型请求前被拒绝，并提示基于当前画布重新提交；不得清理固定快照后继续旧运行。
- [ ] 已发起模型请求的运行按原固定依据完成；已完成输入、结果集和记录不改写；无冲突快照正常执行。
- [ ] 同步本票改变的公共契约、生成客户端和当前行为文档；不提前将其他卡片的未来改动记为已完成。

## 验证方式

- 扩展现有验收公开保存／读取／编译／运行测试和实际任务工作器测试，覆盖纯文本、完整引用、媒体能力、方向限制、清理幂等及冲突／无冲突快照对照。供应商边界使用既有受控替身，不调用付费生成验证质量。
- 扩展真实后端画布浏览器回归：新卡、旧卡重开、字段引用、直连模型、随设计采用、连接错误提示、撤销／重做、只读和窄屏；观察保存结果与实际编译输入，不只断言内部函数。
- 前端变更运行 typecheck 和受影响测试；后端变更运行相关测试及应用 Pylint。公共契约变化后从确认已加载当前工作区的后端同步 OpenAPI 与生成客户端。
- 共享清理或执行准入变化扩展相关回归范围。记录结果和局限，不将模拟供应商结果写成真实模型效果验收；通过证据追加至 Comments。
