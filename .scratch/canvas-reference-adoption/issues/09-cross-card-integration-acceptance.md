## Acceptance criteria

- [x] 退役范围恰为 18 类：验收 1、通用要求 4、表演／活动 3、叙事／空间 4、画面设计 5、声音安排 1；新建、预设、旧文档、读取、保存及编辑恢复均无残留生效入口。
- [x] 其他七类设计卡的业务关系没有被误删；保留的主体、说话对象、关注／焦点、空间、叙事顺序、锚点和画面定位仍通过原有约束与运行场景。
- [x] 混合旧文档中同一来源同时具有废弃用途、有效角色、字段引用和素材用途时，仅废弃用途退出；一条来源线和各输出身份正确保留。
- [x] 旧连接的三种结果均得到验证：保留其他有效用途、转为合法纯候选、无合法用途清除；重复读取／保存不反复变更，保存修订与并发冲突规则保持。
- [x] 直接与随设计采用验收、多设计共享标准、菱形依赖及媒体多用途共同存在时，生成输入完整且正确去重；逐条解除只撤销其路径，最后有效路径消失才退出。
- [x] 纯文本不推断关系，完整引用不变为字段级采用或全素材采用，未采用候选／本地示例不进入生成；必要媒体能力和失效诊断准确。
- [x] 候选用途、计数和来源线信息与编译实际采用一致；未生效引用、只读、空候选、加载和失败状态准确，浏览不改变文档或撤销记录。
- [x] 失效来源、断线保护、源卡删除及批量删除在跨组混合画布中正确；原子撤销／重做及保存重开不丢失有效用途，也不能恢复废弃用途。
- [x] 18 类旧冲突快照均有准入覆盖：未发起请求／等待／重试要求重新提交；已发起请求按原依据完成；已完成历史保持；无冲突运行正常。历史记录不得被当前文档清理重写。
- [x] 原有名称标签、placeholder、模型提取元信息只读展示、手填／预设默认信息隐藏，以及验收只读缩略区等相关既有行为没有回退。
- [x] 公共卡片目录、保存／编译／运行语义、OpenAPI 与前端生成客户端一致；由当前工作区后端生成并核实，不使用旧进程接口覆盖结果。
- [x] 受影响架构事实和操作说明反映最终行为，包括明确依赖传递；不修改无关历史发布说明或新增路线图。原始规格保持不变。
- [x] 完成适用项目检查并记录命令、结果和未完成项；共享清理／依赖／执行变化按影响扩大回归，不重复运行相同代码与环境已通过且无新疑点的检查。
- [x] 汇总可复核的覆盖记录，区分真实浏览器／公开接口／受控供应商验证与无法在当前环境验证的外部行为，不宣称结果质量或自动验收能力已实现。

## 验证方式

- 复用真实后端浏览器入口建立混合画布：包含 18 类退役卡、其他七类对照卡、直接／间接验收、多用途同源、失效引用及旧编辑状态；按上述用户动作验证最终文档与编译输入。
- 汇总各票的逐类型公开接口回归，并补齐跨组组合、清理幂等／修订冲突及真实任务工作器状态边界；供应商使用原有受控替身。
- 前端 typecheck 和受影响浏览器／单元检查；后端相关测试与应用 Pylint。共享基础能力影响广时扩展到完整画布／必要全量测试，不以文档检查代替行为验证。
- 在 Comments 中记录每组证据及局限；若发现遗漏，修复并运行受影响检查，不仅调整验收描述掩盖问题。
