# 08: 同轮先出图再生成视频，中断后接续

**What to build:** 用户要求「先画雨夜街景，再用这张图做一个 5 秒推进镜头」时，助手在同一轮完成两步。刷新或 Worker 重启后，用户能继续看到原来的任务。

**Blocked by:** 07

**Status:** ready-for-agent

- [ ] 使用可控供应商贯穿实际 Agent 工具循环和生成服务。图片与视频工具调用各有身份，并关联各自任务和同一轮次；图片文件归档后，视频请求才提交。
- [ ] 核对视频供应商实际收到的首帧内容对应上一步归档的图片，时长为 5 秒，两步使用各自选定的模型。工具事件、产物与主模型最终回复能从 SSE 与快照还原。
- [ ] 在任务受理及两步交接时分别覆盖断流、原请求重试和 Worker 重启。恢复时沿用原调用与任务身份，受理状态未知时先核对回执。每一步只创建一次生成，续订和刷新均不重复显示产物。
- [ ] 视频失败时保留可查看的图片并标明失败步骤。图片已提交而视频尚未提交时停止回复，后续不再发起视频生成，已提交的图片仍可跟踪。

对应[规格用户故事](../spec.md#user-stories) 8、14、18、20。
