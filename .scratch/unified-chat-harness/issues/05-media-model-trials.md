# 05: 通过统一客户端完成图片和视频试模

**What to build:** 用户可以指定图片或视频模型直接试模，在原会话中跟踪生成、打开产物和恢复历史素材。媒体任务与产物展示供聊天工具复用。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 两种入口各自展示和预选相应模态的默认模型，改选在本会话沿用。供应商收到用户本轮选定的模型、执行参数和实际参考素材，每次试模独立提交。
- [ ] 统一客户端按同一套有类型的事件呈现任务受理、实际进度、失败和归档产物。卡片显示实际执行模型，可核对公开参数、引用素材及回执。统一产物类型可表达音频，首期生成覆盖图片和视频。
- [ ] 恢复旧媒体会话可查看原结果、回填参数和参考素材。重试原请求恢复同一个任务，用户从历史主动重新发送则建立新轮次。
- [ ] 分别从图片和视频试模公开 API 验证请求、任务与实际文件的关联；浏览器回放事件或刷新页面后，同一产物只出现一次。

对应[规格用户故事](../spec.md#user-stories) 2、3、5、14、20。
