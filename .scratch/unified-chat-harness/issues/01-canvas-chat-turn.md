# 01: 从统一会话入口完成一轮画布对话

**What to build:** 用户在画布上询问选中卡片的内容时，助手能读取卡片、给出回答。打开会话、发送消息、观看回复和刷新恢复均走统一会话客户端。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

Completion: resolved

- [x] 从画布已有的 Deep Agents 运行逻辑提取共用的模型与工具循环。画布提供本轮上下文、工具、Skill 和提示词，主聊天模型经 LangChain 适配器使用登记模型的供应商协议。
- [x] 通过公开会话 API 提问，由可控模型请求读取指定卡片，收到对应工具结果后再回答。在 SSE 中可将受理、工具调用与结果、正文和终态关联到同一轮，工具调用保留自己的身份。
- [x] 原生流式主模型逐段显示回复，仅支持完整正文的主模型一次显示回复。两种模型的工具事件都可在正文完成前交付。页面消费相同的公开事件类型。
- [x] 断开 SSE 后按会话游标续订，或刷新后读取快照，能恢复同一轮历史。用原请求身份重试只产生一个轮次，已执行的工具和页面内容均不重复。

对应[规格用户故事](../spec.md#user-stories) 13、14、20。

验收记录：画布读取工具的受控供应商往返、SSE 续订、整段及流式回复已通过公开 API 用例。草稿和已保存画布均通过 Chromium 验收。
