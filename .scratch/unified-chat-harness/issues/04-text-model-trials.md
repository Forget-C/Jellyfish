# 04: 通过统一客户端完成文本试模

**What to build:** 用户新建或重新打开文本试模会话，用本轮输入和选定参数直接测试文本模型，能查看回复、恢复历史并回填后再次试模。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 文本试模展示文本模型选择器，初始预选全局默认文本模型，用户改选后本会话的后续试模使用该选择。
- [ ] 从页面发送并核对可控供应商收到的模型、文本和有效参数。输入按本轮独立组装，调用不经过 Agent 工具循环。
- [ ] 页面通过共用客户端和公开会话事件展示受理、文本、终态与失败，并能停止适用的运行。断线重连从原游标继续，重试原请求不重复创建轮次。
- [ ] 现有文本试模历史按原模态打开。回填参数和文本后由用户主动发送会建立新轮次，历史回复仍可查看。

对应[规格用户故事](../spec.md#user-stories) 2、3、5、13、20。
