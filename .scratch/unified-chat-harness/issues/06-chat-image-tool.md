# 06: 在实验室聊天中生成图片

**What to build:** 用户可以描述想要的图片，也可以选择 /imagegen 并附图。主聊天模型在本轮调用图片工具，用户能查看生成依据、任务和结果。

**Blocked by:** 03, 05

**Status:** ready-for-agent

Completion: resolved

- [x] 用 Ant Design X 的输入建议选中 `/imagegen` 后可以继续编辑、附图并发送。要求充分时执行出图，影响结果的关键信息不清时可以追问；自然语言走相同工具与事件路径。生成版数由对话决定，参数按执行模型有效能力校验。
- [x] 使用会话选定的图片模型，缺少可用媒体模型时在需要出图时提示选择。主模型缺少工具调用或结果回传能力时保留输入和附件，可切换主模型继续。正文只支持整段返回、工具能力有效的主模型也能完成出图。
- [x] 通过现有生成服务与 Worker 提交和归档。工具卡记录实际模型、公开参数、素材引用、任务回执及稳定文件身份。任务受理和文件就绪分别显示，归档后才将图片作为工具结果交回主模型。
- [x] 用户只要求提交时，取得任务回执即结束本轮并开放发送，原任务卡继续更新。停止回复只结束后续 Agent 动作，单独取消已提交任务时按供应商能力和真实回执显示结果。
- [x] 通过公开 API 与 SSE 验证成功、失败、等待及只提交路径；浏览器验证快捷指令、模型改选、附件保留，以及等待期间的发送状态。

对应[规格用户故事](../spec.md#user-stories) 4、5、6、7、12、13、14、16、18、19。

验收记录：自然语言及斜杠出图通过受控供应商和真实 Worker 验收，覆盖产物回传、停止、仅提交及预检失败的工具身份。
