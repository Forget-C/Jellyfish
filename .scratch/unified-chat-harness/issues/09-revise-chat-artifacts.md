**What to build:** 用户对上一轮的结果说「把刚才的视频改成横屏」，助手可定位原产物并生成新版。多个产物都可能符合时，用户可以在原轮次选择。

**Blocked by:** 07

**Status:** ready-for-agent

Completion: resolved

- [x] 有多个合理候选时，页面显示可辨认的问题卡，回答关联到原轮次。明确选择后才执行本次修订，重开会话仍能继续处理待答问题。
