# 03: 新建实验室多模态聊天并选择主模型

**What to build:** 实验室新建会话默认进入多模态聊天。用户可以先讨论创意，按需要切换主聊天模型或配置媒体模型，在同一会话继续对话。

**Blocked by:** 01

**Status:** ready-for-agent

Completion: resolved

- [x] 多模态入口使用共用 Agent Harness 和通用系统提示词。允许先纯文本讨论，使用自然语言延续本会话的相关对话。文本、图片和视频试模入口仍可选择。
- [x] 页面默认只展示主模型选择器，折叠配置中分别选择图片与视频模型。三项预选相应全局默认模型，改选后在本会话沿用。未配置媒体模型时仍可正常聊天。
- [x] 有无原生流式能力的主模型都能交付正文，无工具能力的主模型仍可普通对话。核对公开事件和页面最终正文均属于同一轮。
- [x] 要求解读附件中的图片或视频时，按主模型在当前供应商配置下的对应理解能力决定是否调用。能力不足时给出原因，用户可保留原输入与附件、切换模型后继续。
- [x] 会话忙碌时前后端均拒绝普通新消息、补充与排队。浏览器刷新后仍能按真实轮次状态禁用或恢复发送，另一个会话可以照常使用。

对应[规格用户故事](../spec.md#user-stories) 1、4、5、6、11、12、13、16。

验收记录：默认入口、折叠模型配置、附件能力、会话重开和发送状态通过实验室 API 及 Chromium 验收。
