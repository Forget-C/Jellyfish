# 07: 在实验室聊天中生成视频并使用指定首帧

**What to build:** 用户可以用自然语言或 /videogen 在当前会话发起视频生成，选定已有图片作为首帧，并从原回复观看结果。

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] 快捷指令可在发送前继续编辑、附加素材，与自然语言复用同一工具循环。工具使用会话选定的视频模型，所需模型缺失时可选择；使用其他模态工具不改变该选择。
- [ ] 主模型具备工具往返能力时，即使不能看图也可把文件引用传给支持首帧的视频模型。若请求要求解读画面，则核对主模型理解能力；若执行模型不接受该首帧或参数组合，则给出相应原因。
- [ ] 使用可控供应商核对实际视频模型、收到的首帧文件与时长等有效参数。受理时展示任务，归档后关联视频产物；失败归属具体工具调用。浏览器可查看实际执行模型、引用和任务回执。
- [ ] 覆盖等待产物、只提交、停止回复和任务取消的区别。只提交后本轮可结束，原任务仍可更新；供应商确认取消后才显示已取消。

对应[规格用户故事](../spec.md#user-stories) 5、7、10、11、14、18、19。
