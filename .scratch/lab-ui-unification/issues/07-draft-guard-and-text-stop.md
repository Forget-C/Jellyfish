# 07: 草稿离开保护与文本停止流程

Blocked by: 06
Status: ready-for-agent
Resolution: completed

来源：[实验室统一规格](../spec.md)，分区五的草稿保护与任务差异。主要用户故事：54–58，衔接模板和素材的应用／取消以及提交恢复。

**What to build:** 用户切换会话或离开实验室时能明确选择保留编辑或放弃草稿。文本生成中离开需要选择停止或等待，图片和视频已成功提交后则可离开且任务继续，界面不承诺无法保证的后台运行。

## Acceptance criteria

- [x] 未发送提示词、变量修改和参考素材触发离开保护；切换类型、会话、新建会话、站内离开及浏览器前进后退遵循同一规则，无修改直接切换。
- [x] 提示提供“放弃未发送内容并离开／继续编辑”。继续编辑保留当前输入、配置与原页面；确认放弃后到达原目标，不重复导航或留下错误选中态。
- [x] 默认模型自动选中、仅打开面板、查看预览、取消临时编辑不触发草稿警告。成功提交的配置不因仍显示而误判为新草稿；提交后的新编辑仍受保护。
- [x] 模板／参考配置面板尚有临时编辑时不静默遗失，也不为同一次离开连续弹出多次重复确认；面板取消仍遵循已确认的放弃本次面板修改语义。
- [x] 文本生成中切换会话、类型或离开实验室，提供“停止生成并离开／继续等待”；继续等待留在当前会话且不请求停止。
- [x] 确认停止并离开时，在站内可控流程中明确请求停止；使用现有文本运行身份，不用先断开连接制造假成功。停止失败保留明确反馈和当前上下文，不显示已停止或按成功静默离开。
- [x] 停止与流式终态同时到达时，已有终态得到正确处理，不将已完成结果错误改为取消，也不反复弹出离开提示。
- [x] 图片和视频确认接收后可以离开，切换不发送取消请求，返回会话可继续读取任务状态；若另有未发送修改，仍按草稿规则确认。
- [x] 刷新或关闭仅使用浏览器允许的离开提醒，不承诺必定拦截、草稿恢复或文本后台续跑。文本流断开继续遵循现有取消契约。
- [x] 不新增跨会话草稿缓存、刷新恢复或跨设备同步。确认及取消的焦点合理，键盘可以完成继续编辑、等待或明确离开。

## 验证要求

- 真实浏览器中覆盖文本、图片、视频的自由输入、模板与素材草稿，验证各种站内入口及前进后退、继续编辑、确认放弃、无修改直接切换，检查页面、路由与输入一致。
- 使用可控 SSE 和停止响应验证等待不取消、确认后请求停止、停止失败、停止与完成竞态；对图片视频检查离开零取消请求及返回状态恢复。
- 覆盖已提交配置不误报、系统自动配置不误报、取消面板不误报、同一离开不重复确认。刷新／关闭记录浏览器实际能力及局限，不以模拟通知冒充恢复保证。
- 运行前端类型检查及受影响回归，复用现有导航与流式测试边界，不修改后端运行契约或调用付费生成。
