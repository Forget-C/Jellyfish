# 02: 模板变量配置与输入覆盖保护

Blocked by: 01
Status: ready-for-agent

来源：[实验室统一规格](../spec.md)，分区二。主要用户故事：14–21、43–44、63。

**What to build:** 用户在三个实验室中选择模板、查看填写摘要、编辑变量并预览最终提示词，通过应用或取消控制当前实验输入，再使用应用后的内容完成现有提交。切换模板、转为自由输入和历史回填不会静默覆盖已有编辑。

## Acceptance criteria

- [ ] 输入区展示模板名称、版本和“已填 N／共 M 个变量”，默认值计入已填；不把所有变量视为必填，无变量模板显示“无需填写变量”。长名称不挤走提交操作。
- [ ] “编辑变量”在桌面打开右侧抽屉，窄屏为全宽抽屉。多变量时只滚动面板正文，应用和取消可达，主页面历史区不被长表单撑高。
- [ ] 面板包含变量编辑、可折叠的最终提示词及“转为自由输入”；最终提示词使用当前面板变量渲染，能在提交前核对。
- [ ] 打开面板时以已应用配置作为初始值，编辑只改变面板草稿；点击应用后更新输入摘要及实际提交内容，不修改模板本体。
- [ ] 取消、关闭按钮、Esc 和遮罩关闭均放弃本次面板修改，保留打开前配置。取消后重新打开显示已应用值，没有残留的临时修改。
- [ ] 转为自由输入使用当前变量渲染结果，确认替换后退出模板模式。取消替换时保留当前编辑；切换模板或历史回填会覆盖已有输入时同样保护。
- [ ] 历史回填只更新可编辑输入，不立即提交；已有快照按现有语义使用，缺失的模型或素材参数明确要求重新选择，不推测补齐。
- [ ] 模板读取区分加载、成功为空与失败，失败有重试，刷新失败保留已有数据和输入。不因模板读取错误退出已应用配置或清空草稿。
- [ ] 仅打开面板、预览或取消编辑不产生有效输入修改；应用、转为自由输入与覆盖确认具有可区分的外部行为，供后续离开保护正确消费。
- [ ] Tab 顺序、字段名称和焦点可用；关闭面板回到原入口，叠加确认或预览时 Esc 只关闭最上层。
- [ ] 文本、图片和视频提交使用各自已应用的最终提示词；应用和取消本身不创建会话或生成任务，不修改原模板。

## 验证要求

- 真实浏览器配合隔离 HTTP／流式响应，覆盖三种实验室选择模板、编辑、应用并提交的完整路径，断言实际提示词请求内容。
- 覆盖有默认值、无变量、多变量、长模板名、自由输入与模板互转、历史覆盖确认和读取失败。分别验证各取消出口，检查无模板写入及无提前生成请求。
- 运行前端类型检查和受影响回归；桌面与窄屏检查面板滚动、焦点及低高度可达性。真实业务数据和付费模型不参与测试。
