# 08: 跨实验室验收与规范同步

Blocked by: 05, 07
Status: ready-for-agent
Resolution: completed

来源：[实验室统一规格](../spec.md)，分区六及全部 Testing Decisions。覆盖用户故事 1–66 的组合验收，其中 65–66 为隔离测试与共享消费者保护。

**What to build:** 用户在三个实验室之间获得完整一致的操作体验，已完成的布局、配置、媒体和任务行为通过组合场景验证；维护者获得与实际行为一致的长期规范、测试入口及明确验证结果，作为后续开发与验收依据。

## Acceptance criteria

- [x] 在已完成票据各自测试基础上验证组合流程，包括模板变量加参考素材、切换模型后修正配置、提交失败后恢复、运行中离开及返回查看结果。每个先行票据仍须独立通过自身测试，不能把全部验证推迟到本票。
- [x] 两种雾蓝外观下检查 1440×900、1366×768、1024×440、375×812，以及 1023／1024、767／768 宽度两侧；侧栏、顶栏、控件层级、内容滚动和操作可达均符合规格。
- [x] 覆盖长标题、长文本、多变量、多参考素材、多图、竖图竖视频、空状态、未知字段、读取失败、运行中及终态，验证输入区不抢占历史，媒体不撑破布局，无整体横向溢出。
- [x] 低高度及软键盘场景中正文、输入、关闭和提交可达；若环境不能验证真实软键盘，明确记录局限，不能将缩小视口称为完整软键盘验收。
- [x] 综合验证加载／空／失败区分、刷新保留数据、媒体重载、任务状态文案、提交未知核对、读取重试不生成及失败恢复，无反复弹出的轮询错误。
- [x] 检查取消配置仍保留资料库文件、延迟上传不污染选择、模型能力乱序、未知能力不冒充不支持、文本停止失败不假成功，以及图片视频离开不取消。
- [x] 完成 Tab 顺序、可访问名称、可见焦点、中文输入法、触摸区域、浮层逐层 Esc 与关闭焦点恢复检查；结果结合交互证据和截图，不只用类型检查或图片比对判定通过。
- [x] 回归首页实验继续入口和草稿入口、项目页与管理导航、主题偏好，以及两个独立画布及共享输入组件工作台消费者的外观隔离。共享改动按实际影响扩大回归。
- [x] 依据已实现行为同步实验室长期前端规范及必要索引，引用既有通用视觉权威来源；更新被改变的相关架构事实和测试说明，不复制三份通用规则，不提前声称尚未实现内容可用。
- [x] 长期文档区分真实数据、未知字段、独立示例、前端验证及真实供应商链路，明确取消上传选择、流式文本离开和提交未知的边界。遵循项目文档维护流程。
- [x] 完成项目要求的前端类型检查、受影响浏览器回归以及按范围必要的 lint／构建检查；复用相同代码和环境下已通过的结果，不执行无关后端或付费生成测试。
- [x] 汇总实际检查结果、截图和未验证限制，区分自动行为通过、人工视觉检查、真实后端链路与生产部署。任何模拟响应均不能作为真实供应商能力或生成质量的证明。

## 验证要求

- 继续使用真实浏览器页面加隔离 HTTP／流式响应，不建立仅为覆盖率服务的底层测试边界。通过可见结果和必要请求验证外部行为，必要时测量实际布局尺寸。
- 复用实验室导航、外观偏好、首页项目布局和管理页面测试先例及已有运行器，补充当前缺失的组合验收；保存可核对证据而非只报执行命令。
- 核查长期文档内容、索引、相对链接及实际实现一致性。不要修改父规格的确认历史或将本票验收等同于部署完成。
