# 04: 视频参考配置与模型能力校验

Blocked by: 03
Status: ready-for-agent

来源：[实验室统一规格](../spec.md)，分区三的视频参考与模型能力规则。主要用户故事：29–35，并复用 22–28 的应用、取消与上传保护。

**What to build:** 视频实验用户在统一面板中配置帧参考和主体参考，核对输入区摘要及比例，切换模型时保留工作并根据真实能力修正冲突，最后通过现有生成入口提交准确素材与参数。

## Acceptance criteria

- [ ] 复用图片参考票据的配置面板与应用／取消语义，将视频参考分为帧参考和主体参考，明确首帧、尾帧、关键帧、主体名称及图片／视频用途。
- [ ] 视频比例在输入区直接可见；复杂配置只显示真实摘要，如已选首帧或主体数量，不让所有帧和主体编辑控件挤在底部一排。
- [ ] 上传、资料库选择、预览、移除、取消不删已上传文件，以及延迟返回不污染会话的规则在视频素材中同样成立。同一集合去重，不能把合法的不同素材角色机械合并。
- [ ] 应用后实际提交按素材角色、主体分组和比例生成现有请求；未应用的编辑不改变当前实验，取消恢复打开前配置。
- [ ] 切换模型保留提示词、素材和原比例，不静默替换比例或删素材。可证实的冲突明确标记，用户调整后才能提交。
- [ ] 使用真实能力中的允许比例、主体图片／视频支持、主体和素材数量上限及组合约束；冲突和限额说明贴近相关配置。真实能力允许帧与主体组合时，不再使用无条件互斥阻止。
- [ ] 能力读取中或失败时暂停依赖该能力的生成，并提供明确状态与重试；字段缺失与读取失败分开处理，不直接视为不支持。
- [ ] 未被能力字段覆盖的约束继续交由现有服务端校验并展示错误，不推断完整能力矩阵，不用模拟能力控制真实提交。
- [ ] 快速切换模型后只采用当前模型的能力响应，旧成功或失败响应不能覆盖新模型状态，重复打开配置不退回过期能力。
- [ ] 主体名称和素材完整性沿用现有业务校验；未完成项的原因可定位，不能仅显示无法解释的禁用按钮。
- [ ] 桌面与窄屏均可配置多个主体、多种素材和长名称，正文滚动、应用／取消及焦点可达。接口、数据库和供应商能力不扩展。

## 验证要求

- 浏览器中完成模型选择、帧／主体素材配置、应用并提交，检查对外请求中的角色、文件身份、主体分组及比例。
- 使用可控能力响应覆盖允许组合、禁止组合、不同上限、未知字段、失败重试，以及模型 A 慢响应晚于模型 B 的情况。验证冲突保留配置且不提交，合法组合正常提交。
- 复用上传取消和延迟响应场景，检查没有自动删除文件或偷偷改比例。运行前端类型检查与受影响回归，不调用真实供应商或修改后端。
