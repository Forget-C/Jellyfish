# 01: 统一实验室布局与基础输入体验

Blocked by: None
Status: ready-for-agent

来源：[实验室统一规格](../spec.md)，分区一及分区二的基础输入规则。主要用户故事：1–13、59–60、64、66。

**What to build:** 用户在文本、图片、视频实验室中使用一致的侧栏、紧凑标题和输入面板，能够切换会话、输入并通过现有接口提交实验，在桌面、窄屏及低高度窗口中都能访问必要内容和操作。保留现有业务能力，先完成可独立验证的基础体验。

## Acceptance criteria

- [ ] 三个实验室保留左侧实验类型与最近会话、右侧历史结果、底部输入的结构。桌面侧栏 216px，小于 1024px 使用导航抽屉；草稿、历史会话及浏览器前进后退正确反映当前选择。
- [ ] 侧栏保留新建、重命名和删除入口，选中项使用浅底色。会话操作在悬停或键盘聚焦时可见，触屏下始终可达；长名称可查看全文。
- [ ] 标题显示“实验室名称 · 当前会话名称”，草稿显示“新会话”；主标题 16px／600，工具栏约 52–56px，会话名为次级文字，长名称不挤走操作。
- [ ] “清空会话内容”位于更多菜单，与删除会话分别确认对象及影响。取消不发送修改请求，执行中防止重复操作，失败保留上下文，既有权限、运行任务及关联限制继续有效。
- [ ] 复用两种雾蓝背景和偏好、白色表面、12px 圆角、主文字 #263244、辅助文字 #536174、强调色 #245FC5、选中底色 #E4EDFB。桌面／手机左右留白 20／16px，区域间 16–20px、区域内 12–16px、控件间 8px。
- [ ] 输入面板采用提示词、按需素材摘要及底部操作的结构，去掉结构分隔线和灰色工具带。正文／输入 14px、操作 13px、辅助信息 12px；桌面控件 32px、窄屏 36px，独立图标触摸区域目标约 44×44px 且不重叠。
- [ ] 默认三行输入，低高度窗口两行，增长至最多约六行后内部滚动。长模型名和模板名不挤走提交按钮；发送或生成是唯一实心蓝主动作，现有文本停止入口移至输入区。
- [ ] 输入框和图标有明确可访问名称及可见焦点。文本 Enter 发送、Shift＋Enter 换行，输入法组合／选词期间 Enter 不发送；图片、视频仍使用显式生成按钮。
- [ ] 桌面会话列表和历史区分别滚动，输入可达。低高度收紧行数及间距，窄屏操作可换行，空间仍不足时允许路由内容滚动，不通过裁切隐藏正文或按钮，不发生整页横向溢出。
- [ ] 空会话保留简短引导和合理留白，不因固定最小高度产生多余滚动，不增加装饰性推荐卡或统计区。
- [ ] 普通输入可以完成现有提交路径，生成配置和接口不被样式改动破坏。模板抽屉、素材面板及完整任务恢复分别由后续票据完成，本票不以提前实现它们为验收前提。
- [ ] 样式只影响实验室，应用顶栏、首页、项目、管理和共享输入组件的工作台外观不被覆盖。

## 验证要求

- 复用实验室导航与外观浏览器先例，通过真实页面和隔离 HTTP／流式响应验证三种模式的导航、基础提交、清空／删除确认及中文输入法行为。检查实际结果和必要请求，不断言组件内部状态。
- 检查两种主题下的 1440×900、1366×768、1024×440、375×812，以及 1023／1024、767／768 断点两侧。验证焦点恢复、长名称和输入增长。
- 运行前端类型检查及受影响回归，检查至少一个共享输入组件工作台消费者。不得调用付费生成或修改真实业务数据；不调整后端与表结构。
