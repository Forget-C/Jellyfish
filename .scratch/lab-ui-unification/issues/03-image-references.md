# 03: 图片参考素材的选择与应用

Blocked by: 01
Status: ready-for-agent

来源：[实验室统一规格](../spec.md)，分区三的图片参考与配置事务规则。主要用户故事：22–28、63–64。

**What to build:** 图片实验用户从统一入口上传或选择参考图，核对缩略图、预览并移除素材，通过应用将选择用于本轮生成，通过取消恢复原选择。上传文件与本轮引用的区别明确，慢请求不会重新写入已取消或已切换的上下文。

## Acceptance criteria

- [ ] “参考图”入口统一提供上传与资料库选择，桌面配置面板位于右侧、窄屏全宽；优先在同一面板切换已选素材和资料库，不反复叠加选择弹窗。
- [ ] 已应用摘要使用约 48px 缩略图、名称、预览和移除操作。最多直接展示四张，其余通过“查看全部（N）”访问；低高度窗口收为数量摘要。
- [ ] 同一选择集合内相同文件去重，顺序及已选状态可核对。摘要移除明确作用于当前输入，面板内移除在应用前保持为临时修改。
- [ ] 应用才将面板选择绑定到当前实验。取消、关闭、Esc 或遮罩关闭均恢复打开前选择；重新打开时能够核对恢复结果。
- [ ] 上传入口附近明确说明“上传文件保留在资料库，应用后用于本轮实验”。取消配置不自动删除文件，也不将文件仍在资料库误报为取消失败。
- [ ] 上传中、失败、已上传未应用状态可辨。失败可重试，已有选择和提示词保持；资料库加载、成功为空和读取失败分别展示，重试不创建任务。
- [ ] 取消或切换会话后返回的上传结果不能重新加入已取消的实验选择，不能污染新会话。配置面板关闭、重新打开也不能复用过期请求改变本轮选择。
- [ ] 素材缩略图和预览有加载／失败占位，完整预览保留比例，关闭恢复触发焦点；移除操作不依赖仅悬停可见的小点击区。
- [ ] 实际生成请求仅携带已应用的参考文件及顺序；未应用或已取消项不提交。应用、取消、预览及重载均不创建生成任务。
- [ ] 面板采用能被视频参考复用的既有共享结构，只提取本次相同语义的配置行为，不预造通用资产框架。对外上传和生成契约保持不变。

## 验证要求

- 在真实页面中使用隔离上传、资料库及生成响应完成“选择／上传—应用—提交”和“修改—取消—提交”，断言引用身份、顺序及没有文件删除请求。
- 用延迟和失败响应验证上传取消、切换会话、重新打开面板、失败重试和重复文件；不能仅测试正常上传。
- 检查超过四张、长文件名、无图及预览失败、桌面和窄屏操作。运行前端类型检查和受影响浏览器回归，不上传用户真实文件或调用付费生成。
