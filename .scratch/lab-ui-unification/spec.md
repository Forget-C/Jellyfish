# 实验室布局、配置交互与结果展示统一

Status: ready-for-agent

确认日期：2026-11-10

## Problem Statement

文本、图片和视频实验室已经共用导航与输入框架，但内容区尚未衔接首页、项目页和管理页的最新视觉规范。标题偏大，清空操作常驻显眼位置，输入区的灰色工具带、分隔线和默认五行编辑器占用较多高度。短消息占据过宽色块，单图结果却在宽消息区内偏小，视频配置集中在底部，信息与操作密度不均。

低高度窗口中，输入区挤压历史区，空会话也可能出现内部滚动。模板变量展开后进一步撑高页面。用户难以稳定区分会话内容、当前输入、模型配置和结果状态，已有图片会话还会同时出现“等待生成结果”与“已完成”。

配置和恢复流程也需要明确边界。取消参考配置不能撤销已写入资料库的文件；流式文本不能像异步图片、视频一样承诺离开后继续生成；模型能力缺失不能直接视为不支持；提交前清空输入会使校验或创建失败后丢失草稿。这些交互问题与本次页面调整一起处理。

## Solution

将三个实验室统一为“左侧实验类型与最近会话、右侧紧凑标题与历史结果、底部紧凑输入面板”。继承普通应用壳的雾蓝主题、字号、间距、圆角和反馈规则，保留不同媒体需要的内容宽度与预览方式。

模板变量和参考素材按需打开配置面板，采用明确的应用与取消。输入区只显示当前配置摘要和主要提交动作。统一状态、草稿保护、失败恢复与键盘操作，通过局部滚动和低高度收紧确保内容与操作可达。

本规格分为六个功能分区，共享一套需求与验收依据，不为三个实验室重复维护通用规则。本次以前端布局、样式及已确认交互调整为范围，复用现有接口。接口不足时省略字段或显示未知；确需演示的展示独立标注示例，不能用模拟能力控制真实生成。

## User Stories

1. 作为实验室用户，我希望三个实验室与首页、项目页和管理页采用一致视觉，以便切换页面时保持操作习惯。
2. 作为用户，我希望继续使用已有两种雾蓝外观及偏好，以便无需重复设置主题。
3. 作为桌面用户，我希望实验类型和最近会话位于稳定侧栏，以便快速切换上下文。
4. 作为窄屏用户，我希望通过导航抽屉访问相同会话，以便为实验内容保留空间。
5. 作为用户，我希望同时看见实验类型和当前会话名，以便明确当前工作对象。
6. 作为用户，我希望长名称可截断但仍能获取全文，以便不挤走必要操作。
7. 作为用户，我希望新建、重命名和删除会话入口明确，以便管理历史实验。
8. 作为用户，我希望清空内容与删除会话的影响分别说明，以便避免误操作。
9. 作为用户，我希望输入面板紧凑且主动作突出，以便将更多空间留给结果。
10. 作为长提示词用户，我希望编辑器适度增长后内部滚动，以便输入时仍可查看历史。
11. 作为中文用户，我希望输入法选词不会触发发送，以便安心编辑提示词。
12. 作为键盘用户，我希望输入框和图标按钮有明确名称与可见焦点，以便完成所有主要操作。
13. 作为模型使用者，我希望长模型名不会挤走提交按钮，以便始终能够发送或生成。
14. 作为模板使用者，我希望输入区显示模板名、版本和变量摘要，以便核对当前提示词来源。
15. 作为模板使用者，我希望默认值计入已填变量且无变量模板有明确提示，以便准确理解填写状态。
16. 作为模板使用者，我希望在独立面板编辑变量，以便长表单不会挤占历史区。
17. 作为模板使用者，我希望能查看最终渲染提示词，以便提交前核对实际内容。
18. 作为模板使用者，我希望应用后才更新当前实验配置，以便可以先尝试修改。
19. 作为模板使用者，我希望取消时恢复打开面板前的配置，以便不留下半完成修改。
20. 作为模板使用者，我希望转为自由输入时使用当前变量渲染结果，以便继续修改完整提示词。
21. 作为编辑者，我希望切换模板和历史回填前保护已有编辑，以便不会无意覆盖草稿。
22. 作为图片实验用户，我希望从同一入口上传或选择参考图，以便减少分散操作。
23. 作为图片实验用户，我希望看见已选参考图的缩略图与名称，并能预览和移除，以便核对输入。
24. 作为多素材用户，我希望素材摘要限制直接展示数量，以便输入面板不会无限增高。
25. 作为素材选择者，我希望同一集合中的相同文件去重，以便避免误重复添加。
26. 作为上传者，我希望失败可恢复且不影响已选素材，以便不必从头配置。
27. 作为上传者，我希望清楚知道取消选择后文件仍在资料库，以便理解上传与实验绑定的区别。
28. 作为用户，我希望取消后返回的上传结果不会重新加入本轮选择，以便取消行为可靠。
29. 作为视频实验用户，我希望集中配置首帧、尾帧、关键帧和主体参考，以便理解各素材用途。
30. 作为视频实验用户，我希望比例直接可见、复杂素材显示摘要，以便快速核对常用参数。
31. 作为视频实验用户，我希望素材角色、数量限制和组合冲突有明确说明，以便修正配置。
32. 作为模型切换者，我希望已有提示词和素材保留，以便切换模型不丢失工作。
33. 作为模型切换者，我希望不兼容配置被标出而非自动删改，以便自己决定如何调整。
34. 作为模型使用者，我希望能力读取失败与字段未知分别呈现，以便不会把未知当作不支持。
35. 作为快速切换模型的用户，我希望只使用当前模型能力，以便旧响应不会影响新选择。
36. 作为文本实验用户，我希望短消息自然收缩、长文本易读，以便减少无意义色块与过长行。
37. 作为图片实验用户，我希望单张结果足够清晰、多图合理排列，以便直接比较结果。
38. 作为视频实验用户，我希望预览保留比例并有明显播放指引，以便识别和查看结果。
39. 作为用户，我希望列表视频不自动播放，关闭预览即停止，以便避免干扰。
40. 作为媒体查看者，我希望竖图、竖视频不撑满历史区且可查看完整内容，以便兼顾浏览和细节。
41. 作为图片查看者，我希望在同一条结果的图片之间切换，以便连续比较。
42. 作为用户，我希望媒体加载和失败均有稳定占位，以便页面不跳动并能重试。
43. 作为历史使用者，我希望回填只是编辑输入，不立即生成，以便自行决定是否再次提交。
44. 作为历史使用者，我希望缺失历史参数时明确要求重新选择，以便不会误用推测配置。
45. 作为任务用户，我希望排队、生成中、完成、失败和取消明确区分，以便判断当前进展。
46. 作为用户，我希望等待占位文案随任务状态更新，以便不会同时看到矛盾提示。
47. 作为用户，我希望只看到可靠进度，以便不会将模拟百分比当作真实状态。
48. 作为提交者，我希望校验和任务创建失败时保留完整输入，以便直接修正或重试。
49. 作为提交者，我希望结果不明确时先核对历史或任务，以便避免重复生成。
50. 作为用户，我希望生成中防止重复提交，以便避免多次触发同一请求。
51. 作为用户，我希望读取失败不会冒充空数据或任务失败，以便选择正确恢复方式。
52. 作为用户，我希望刷新失败保留已显示内容，以便当前阅读和编辑不中断。
53. 作为用户，我希望重试读取和重新生成明确分开，以便恢复界面不会创建新任务。
54. 作为草稿编辑者，我希望离开前能选择继续编辑或放弃，以便避免无意丢失未发送内容。
55. 作为用户，我希望仅查看预览或系统自动选择默认模型不会触发草稿警告，以便减少无效打断。
56. 作为图片或视频实验用户，我希望成功提交后可离开且任务继续，以便处理其他工作。
57. 作为文本实验用户，我希望生成中离开前明确选择停止或等待，以便理解流式连接的限制。
58. 作为文本实验用户，我希望停止失败不会被显示为已停止，以便获知真实状态。
59. 作为低高度窗口用户，我希望输入和素材摘要收紧，以便历史与主要操作仍可达。
60. 作为手机用户，我希望软键盘或极矮窗口下仍能滚动访问全部内容，以便不被固定布局遮挡。
61. 作为历史阅读者，我希望新消息不强制打断旧消息阅读，并可回到最新，以便掌控阅读位置。
62. 作为历史阅读者，我希望加载更早消息后位置稳定，以便连续阅读。
63. 作为键盘用户，我希望浮层逐层关闭并恢复焦点，以便不丢失操作位置。
64. 作为触屏用户，我希望移除、关闭等图标有足够点击区域，以便减少误触。
65. 作为维护者，我希望通过隔离接口验证真实页面行为，以便不修改业务数据或调用付费生成。
66. 作为工作台用户，我希望实验室共享组件调整不改变工作台外观，以便现有制作流程保持稳定。

## Implementation Decisions

### 分区一：共享布局、导航与视觉（Q1、Q2、Q14）

- 复用实验室布局、会话侧栏、普通页面工具栏和高度容器。桌面侧栏宽 216px，小于 1024px 使用导航抽屉。应用顶栏沿用既有尺寸、Logo、品牌和一级菜单规则。
- 侧栏保留实验类型、最近会话及轻量新建入口；当前项使用浅蓝选中底色。重命名和删除入口在鼠标悬停、键盘聚焦时可见，触屏下始终可达。不增加常驻右侧配置栏、侧栏搜索、统计或额外导航层级。
- 标题采用“实验室名称 · 当前会话名称”；实验室名 16px／600，会话名为次级文字，草稿显示“新会话”。长名称截断并可获取完整内容，工具栏高约 52–56px。
- 清空入口统一为“清空会话内容”，收进右侧更多菜单。清空内容和删除会话分别确认，展示对象名称及影响。既有任务、权限和关联限制继续有效。
- 文本停止操作放在输入区，贴近发送位置，不占用标题行主要位置。

| 视觉参数 | 规则 |
| --- | --- |
| 默认背景 | 雾蓝微渐变 `linear-gradient(125deg, #F0F5FC, #F7F8FB)` |
| 可选背景 | 既有雾蓝纯色 `#F7F8FB`，沿用浏览器外观偏好 |
| 内容表面 | 白色，圆角 12px |
| 主文字／辅助文字 | `#263244`／`#536174` |
| 强调色／选中底色 | `#245FC5`／`#E4EDFB` |
| 页面左右留白 | 桌面 20px，手机 16px |
| 间距 | 区域间 16–20px，区域内 12–16px，控件间 8px |
| 正文及提示词输入 | 14px，长文本行高约 1.6 |
| 操作／辅助信息 | 13px／12px，不进一步缩小以塞入内容 |
| 控件高度 | 桌面 32px，小于 1024px 为 36px |
| 图标与触摸区域 | 常用图标 14–16px；独立图标按钮适当扩大触摸区域，目标约 44×44px，不能重叠 |

- 用留白、对齐和轻底色分组，移除结构性分隔线和灰色工具带；输入边界、错误及键盘焦点仍清楚可辨，焦点沿用强调蓝。
- 样式限定在实验室作用域，继续区分共享输入组件的普通页面与工作台外观。不得用全局覆盖改变独立画布或其浮层。
- 桌面会话列表和历史区各自滚动，输入区保持可达。容器可收缩，不能通过裁切掩盖正文或操作。
- 低高度时减少输入行数、区域间距，并将素材缩为数量摘要。窄屏工具栏允许换行；极矮窗口或软键盘使空间不足时，允许路由内容纵向滚动。页面不发生整体横向溢出，body 不承担正常页面滚动。
- 空会话使用简短引导、允许合理留白，不增加推荐卡片填满空间，不设导致额外滚动的固定最小高度。

### 分区二：输入与模板配置（Q3、Q6、Q11）

- 复用统一输入面板、模型与模板选择、提示词编辑和模板变量表单。输入面板分为提示词区、按需出现的素材摘要、底部操作区。
- 编辑器默认三行，低高度窗口两行，随输入增长至最多约六行后内部滚动。给输入框提供可访问名称，不只依赖 placeholder。
- 左侧显示模型、模板及模式配置入口，右侧保留唯一实心蓝发送或生成主动作。长模型名、模板名截断并支持获取全文，不挤走提交动作。
- 文本保留 Enter 发送、Shift＋Enter 换行；中文输入法 composition 期间的选词确认不能发送。图片和视频沿用显式生成按钮。
- 模板模式显示名称、版本及“已填 N／共 M 个变量”；默认值计入已填，但不把所有变量视为必填。无变量模板显示“无需填写变量”。
- 编辑变量在桌面右侧抽屉、窄屏全宽抽屉完成，包含变量表单、可折叠最终提示词及转为自由输入入口。变量多时面板正文滚动，应用与取消保持可达。
- 面板编辑使用临时配置，应用才更新当前实验。取消、关闭按钮、Esc、遮罩关闭均恢复打开前配置，不修改原模板。
- 转为自由输入使用面板当前变量的渲染结果，确认替换后退出模板模式。切换模板、历史回填或其他覆盖已有编辑的操作均提供覆盖保护。
- 仅打开面板、查看预览或系统自动选中默认模型不构成草稿修改。

### 分区三：参考素材配置与模型能力（Q7、Q8、Q11、Q12）

- 图片参考入口统一提供上传与资料库选择，已选项显示约 48px 缩略图、名称、预览和移除。最多直接展示四张，其余使用“查看全部（N）”；低高度窗口使用数量摘要。
- 同一选择集合内相同文件去重，不把不同素材角色机械合并；上传失败可重试且不影响已有选择。
- 视频使用统一参考素材面板，分帧参考与主体参考两组，明确首帧、尾帧、关键帧、主体名称及媒体类型。输入区只显示实际配置摘要，比例直接可见。
- 桌面采用右侧抽屉，窄屏全宽。优先在同一配置面板内切换已选素材与资料库，减少选择浮层叠加；预览仍可按需打开。
- 参考配置采用应用／取消，应用后才绑定当前实验；取消恢复打开前选择。上传文件已写入资料库时仍保留，不自动删除，入口附近说明“上传文件保留在资料库，应用后用于本轮实验”。
- 取消后才返回的上传结果不能重新写入已取消的实验选择；切换会话后的旧结果不能污染新会话。上传中、失败和已上传未应用状态可辨。
- 切换模型保留提示词、素材和已选比例，明确标记可证实的不兼容项，用户调整后才能提交，不自动删素材或替换比例。
- 使用现有视频能力响应中的比例、主体图片／视频支持、数量上限及组合字段。字段未覆盖的约束沿用现有服务端校验，不推断三个实验室所有模型均有完整能力矩阵。
- 能力请求失败与字段缺失分别呈现。请求进行中或失败时暂停依赖该能力的生成并提供恢复入口；字段缺失不能直接当作不支持，也不能通过模拟能力允许真实提交。
- 快速切换模型时只采用当前模型对应响应。互斥或数量限制在相关配置旁说明；若真实能力明确允许组合，不得继续用无条件互斥规则阻止。

### 分区四：消息、媒体与结果预览（Q4、Q9、Q10）

- 复用统一消息容器，以身份与状态、正文或媒体、轻量操作三层展示。身份使用小图标与辅助文字，避免每条消息重复鲜艳标签；状态使用语义色、图标和文字共同表达。
- 用户短消息随内容收缩；长文本限制阅读宽度，建议约 80 个字符宽度。模型回复使用白色内容表面，不强制所有消息占同一宽度。
- 单张图片最大宽约 480px，两张可双列，多张按结果区实际可用宽度排列。图片完整保留比例，不为填满网格裁切结果。
- 视频常规预览宽约 360–480px，按空间收缩，保留真实比例和常驻播放指引。历史列表不自动播放。
- 上述媒体尺寸为上限而非强制放大目标；竖图、竖视频同时限制展示高度，完整内容由预览层提供。
- 图片预览支持同一条结果内切换；视频预览提供播放控制，关闭立即停止播放。查看层不超出视口，长内容和控制可达。
- 加载中和加载失败有稳定占位，可重试加载媒体，不出现破图或明显布局跳动。
- 用户输入消息保留回填入口，回填只修改可编辑输入，不立即生成。缺失历史模型或素材配置时明确要求重新选择，不推测补齐。
- 结果保留预览入口，不增加下载、收藏、入库或独立重新生成按钮。失败后可回填修改，实际生成仍在输入区明确提交。
- 预览与配置浮层具有正确焦点管理，Esc 每次关闭最上层，关闭后恢复相应触发焦点。
- 用户阅读旧消息时新内容不能强制拉到底部，提供回到最新入口；加载更早消息保持阅读位置。

### 分区五：草稿、任务状态与恢复（Q5、Q13、Q15及交叉核对修正）

| 状态或操作 | 确认后的行为 |
| --- | --- |
| 任务状态 | 区分排队、生成中、已完成、失败、已取消；原始用户提示词保留 |
| 系统等待文案 | 随实际状态更新，终态不再同时显示等待结果 |
| 百分比 | 仅使用可靠接口数据，未知时不模拟 |
| 校验、上传、创建失败 | 保留完整提示词、变量及选择，允许修正和恢复 |
| 服务端确认接收之前 | 不清空草稿，禁止重复提交 |
| 提交结果不明确 | 先通过已有历史或任务信息核对，不直接引导重复生成；无法核实时明确未知，不编造任务身份或成功 |
| 状态读取失败 | 显示状态暂不可用，不判定生成失败 |
| 首次读取失败 | 对应区域显示失败与重试，不能显示成功为空 |
| 刷新失败 | 保留已有内容与当前输入，显示可恢复提示 |
| 读取重试、媒体重载 | 不创建新生成任务 |
| 轮询失败 | 使用稳定的区域提示，不反复弹出重复通知 |

- 会话列表、历史、模型、模板和素材分别维护加载、成功为空、失败及恢复反馈。未知字段不伪造为零、已完成或未创建。
- 未发送提示词、变量修改或参考素材需要离开保护。切换实验类型、会话、新建会话或离开实验室时，提供“放弃未发送内容并离开／继续编辑”。无修改时直接切换。
- 草稿修改按真实用户编辑判断，已取消的面板编辑不继续触发警告。站内路由切换及浏览器前进后退遵循相同保护；刷新或关闭只使用浏览器允许的离开提醒，不承诺必定拦截或恢复内容。
- 不新增跨会话草稿缓存，不承诺刷新恢复或跨设备同步。已提交配置不应仅因保留显示而被误认为新草稿。
- 图片和视频为异步任务，确认提交成功后可以离开，任务继续执行；切换不自动取消任务。
- 文本为流式任务，生成中切换会话、类型或离开页面时，提供“停止生成并离开／继续等待”。在站内可控离开流程中明确请求停止，不能承诺断开连接后后台继续生成。
- 停止失败时保留明确反馈，不能显示已停止或静默按停止成功处理。浏览器刷新或关闭仍受流式连接断开契约限制。
- 仅将已经提交的任务与新编辑的草稿分开处理，避免同一次离开连续出现重复确认。

### 分区六：验收、复用与范围隔离

- 将通用规则集中在实验室布局、侧栏、输入、配置面板和消息展示等现有模块边界，文本、图片、视频模块保留自身提交与数据语义。不为了统一外观重构后台任务系统。
- 前端业务请求复用现有生成客户端与文本流入口。没有后端表结构、接口契约或供应商能力扩展。
- 测试复用实际浏览器页面和既有 HTTP 隔离方式，详细范围见 Testing Decisions。
- 实现后根据实际变更同步相关长期规范和架构描述，不能提前把本规格写成已经实现的能力。

## Testing Decisions

### 已确认的测试边界

用户在最终设计确认后单独确认，以真实浏览器页面操作加隔离 HTTP／流式响应为主要测试边界。复用现有实验室导航、外观偏好和页面回归方式，覆盖共享布局、模板配置、参考素材、媒体结果、草稿保护和任务交互。

好的测试验证用户可观察结果、对外请求及必要的布局约束，不断言组件内部状态，不以类名或组件结构匹配代替用户行为。可以读取真实几何尺寸与计算样式验证明确的尺寸、滚动及可见性要求。图片和视频使用本地可控媒体，流式文本使用可控事件，不调用付费供应商，也不修改真实业务数据。

### 行为与接口边界验收

| 验收组 | 关键场景与外部断言 |
| --- | --- |
| 导航及会话 | 类型和会话切换、草稿与持久化会话路由、首页继续入口、前进后退、侧栏选中及窄屏焦点恢复 |
| 清空与删除 | 更多菜单、对象及影响确认、取消不发删除请求、运行中限制、执行防重及失败恢复 |
| 输入与模板 | 行数收紧、长名称、默认变量计数、无变量、最终提示词、应用生效、各取消入口恢复、覆盖保护、中文输入法不误发 |
| 参考素材 | 上传与资料库选择、集合去重、四张摘要及全部入口、角色与数量、应用后绑定、取消不删除资料库文件、失败保留其他素材 |
| 异步配置 | 取消或切换会话后上传返回不污染选择；快速切换模型时旧能力响应无效；读取失败、字段缺失与真实冲突分别反馈 |
| 结果展示 | 短消息与长文本、单图多图、竖图竖视频、媒体失败重载、同条图片切换、视频不自动播放及关闭停止 |
| 提交恢复 | 校验和创建失败保留输入；服务端接收前不清空；双击只提交一次；结果不明确时读取核对而非再次创建 |
| 任务状态 | 排队到终态的文案一致、未知进度无伪百分比、读取失败不等于任务失败、轮询错误不反复通知 |
| 离开保护 | 无修改直接切换、真实草稿确认、继续编辑保留内容、面板取消不误报、覆盖已有编辑时保护 |
| 文本停止 | 流式生成中离开要求确认；继续等待不请求停止；确认后请求停止；停止失败不显示已停止；与图片视频差异明确 |
| 异步任务 | 图片视频已接收后切换不发取消，返回可读取状态；读取重试、回填与媒体重载不创建任务 |
| 阅读位置 | 新内容不打断旧消息阅读、回到最新有效、加载更早消息保持位置 |
| 可访问性 | 可访问名称、Tab 与视觉顺序一致、可见焦点、触摸区域、逐层 Esc、抽屉及预览关闭恢复焦点 |

- 延迟、失败、断流与乱序夹具用于验证边界，不仅覆盖正常成功；断流后的后端取消语义作为现有契约使用，不把模拟响应当作后端真实执行证明。
- 取消配置验证选择回滚和没有删除文件请求；不能把仍在资料库的文件当作取消失败。
- 未知能力夹具不能填入编造的支持字段使流程看似完整。未接通能力只验证诚实反馈与现有契约。
- 使用现有实验室导航浏览器用例作为路由、草稿首提、HTTP／SSE 响应与抽屉焦点的先例；使用外观和管理页面回归作为主题、紧凑工具栏及错误反馈的先例。

### 视觉、响应式与回归矩阵

| CSS 视口／状态 | 重点 |
| --- | --- |
| 1440×900、1366×768 | 216px 侧栏、紧凑标题与输入、消息宽度、单图多图、媒体与控件层级 |
| 1024×440 | 两行输入、素材摘要、历史可达、空状态无多余固定高度、必要时路由滚动 |
| 375×812 | 两行应用顶栏、导航与配置抽屉、控件换行、触摸区域、无整体横向溢出 |
| 1023／1024、767／768 宽度两侧 | 侧栏和顶栏切换无漏档、操作与焦点不丢失 |
| 软键盘及极矮窗口 | 可见区域改变后输入、关闭和提交均可达，不靠裁切隐藏内容 |
| 两种雾蓝外观 | 色彩与焦点可读、偏好沿用、工作台外观隔离 |

- 组合检查长消息、多变量、多参考素材、长名称、空数据、未知字段、失败、运行中和终态，不只检查默认空页面。
- 浏览器截图结合实际交互验收，不能以截图或类型检查单独证明全部行为。若环境无法模拟真实软键盘，记录验证局限，不能把缩小视口当作已完整验证软键盘。
- 回归首页实验入口、项目页及管理导航、普通页面主题，以及共享输入组件的工作台消费者。依据实际共享改动扩大范围，不重跑无关后端或付费生成测试。
- 前端实施至少执行项目要求的类型检查和受影响测试；生产构建、lint 与现有浏览器套件按变更范围及仓库要求完成。纯规格发布只检查结构、覆盖、链接及差异范围，不运行应用构建。
- 隔离测试证明前端行为与请求契约，不代表真实供应商生成质量、后端生产链路或部署已验收。

## Out of Scope

- 后端代码、数据库表结构、API 契约与供应商能力扩展。
- 为布局调整伪造模型能力、进度、任务身份或成功结果，或使用模拟数据覆盖真实读取失败。
- 常驻右侧参数栏、新主题、装饰性统计、空会话推荐卡及新增导航层级。
- 新增结果下载、收藏、入库、独立重新生成按钮或新的资产管理能力。
- 跨会话草稿缓存、刷新后恢复、跨设备同步及文本断线后台续跑。
- 取消配置时自动删除已上传的资料库文件，或取消已成功提交的图片／视频任务。
- 改变既有任务持久化、权限、关联限制或生成画布与场次画布的布局、主题和业务内容。
- 全面重构服务层或为视觉统一新增不必要抽象与底层测试边界。
- 使用真实业务数据执行破坏性验收、调用付费生成，以及本次发布时开始实现、创建实现票据、提交 commit 或部署。
