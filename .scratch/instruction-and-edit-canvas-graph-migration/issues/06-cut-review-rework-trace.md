# 06: 整场验收、落幅与局部返工追溯

**What to build:** 用户从当前整场剪辑查看相关验收结论、落幅证据和受影响后段，准确回到生产单元准备与指令复核，完成现有局部返工闭环。整场结果关联 04 的素材／实际覆盖和 05 的真实接缝，完整历史继续按需追溯。

Blocked by: 04 — 同场素材浏览与实际覆盖追溯；05 — 真实接缝与审查记录联动

Status: ready-for-agent

- [ ] 后端为当前整场剪辑提供相关整场验收、落幅和受影响后段摘要，关联明确片段、真实来源及现有覆盖／接缝对象；问题可定位多个真实片段，不凭展示位置或同名猜目标。
- [ ] 整场验收区分画面、实际覆盖和声音状态，导出成功不代表验收通过或声音完成；审查适用性沿用原内容比较，不因无关指令或生成参数变化错误失效。
- [ ] 落幅证据保留生成时的场次、采用片段、源素材、实际区间和后段依赖身份。采用区间或来源改变时，明确显示有关证据与后段待复核，不自动替换参考或重拍。
- [ ] 从受影响片段、接缝或落幅可精确进入原后段单元，沿现有流程准备／换绑参考并重新核对指令；不新增根据审片问题自动创建补拍计划或生产单元的能力。
- [ ] 提帧、素材复核、接缝审查、整场验收和导出保持原明确操作、保存前置条件及请求核实。图读取、导航、普通保存和任务完成通知均不自动执行这些动作。
- [ ] 主图仅显示当前相关摘要与失效原因，完整历史在原阅读入口按需打开，保留固定版本、剪辑内容和输入；当前编辑不重解释历史结论。
- [ ] 复用底层证据读取与 graph 刷新，独立记录在 revision 不变时可更新。失败保留身份、输入及重试入口；迟到证据不覆盖当前剪辑、后段编辑或新选择。
- [ ] 通过已有整场审查、落幅依赖和来源回跳的 HTTP／浏览器用例验证完整返工路径、相关范围失效、历史来源、无关变化保持适用及独立操作无自动副作用。
- [ ] 同步必要接口与 generated client，完成受影响测试、前端类型检查、后端 Pylint及桌面／窄屏／键盘验收，确认素材、接缝与指令既有流程仍可用。

验收承接：A10（覆盖核对）、A12（相关结论）、A13（整场与落幅历史）、A14（返工目标）、A15、A16、A18、A21、A22（历史与返工）、A23、A24（完整剪辑流程）。
