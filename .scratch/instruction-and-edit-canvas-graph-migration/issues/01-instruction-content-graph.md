# 01: 指令依据、参考与正文编辑接入共享图

**What to build:** 用户进入指令画布后，直接查看当前明确单元的依据、正文和参考关系，并在原主编辑器继续修改完整正文。图由后端提供真实业务内容与定位，保存、撤销和未保存输入保护延续现有工作台机制。该票打通第一条从版本读取、保存到实际编辑的完整路径。

Blocked by: None

Status: ready-for-agent

- [ ] 默认直达当前明确选择的单元，保留单元切换和从单元画布进入的上下文；不新增全场指令总览，不以第一个 coverage 或剩余单元替代失效目标。
- [ ] 后端提供强类型指令 graph，包括单元依据、正文、参考、真实关系、视图成员、摘要、问题与精确目标；前端不再通过业务数组拼这些节点、关系和摘要，也不解析标题或地址前缀推断身份。
- [ ] 依据复用现有实际消费范围，区分执行项、约束、背景、未解决项和制作阶段；来源可定位到真实字段。参考保留绑定身份、用途、输入角色和顺序，正文提及不自动形成绑定。
- [ ] 先完成本切片需要的最小读取整理，再接入投影：证据使用已鉴权、固定的版本快照，不通过会再次构建完整版本的高层服务读取。合法但模型、参考或执行准备未完成的内容仍可展示，缺项返回明确问题。
- [ ] 版本读取与保存响应包含指令图，并与内容、元数据及已有导演图、单元图保持同一版本和 revision。共同校验覆盖新增节点类型、真实来源和编辑目标；此阶段不返回尚未实现的占位剪辑图。
- [ ] 主正文编辑器保持自由文本与完整阅读能力，不按逐句或逐要求拆图；长正文、展开和摘要更新不重建输入控件或丢失焦点、选区与内容。
- [ ] 图对应已保存基线，编辑器读取当前输入；未保存时明确图待同步，新对象仍能从原编辑入口操作，已删除对象不能通过旧卡片误编辑到其他对象。
- [ ] 共用现有周期保存、手动保存、撤销和恢复。保存期间继续输入后，响应只推进基线；新增图响应不满足契约时保留输入及原请求证据，通过原机制核实结果，不新增保存入口。
- [ ] 建议、依据确认、检查和生成等原业务入口在本票交付后仍可使用；不因新图读取、导航或普通保存自动应用、确认或执行任务。相关记录摘要的 graph 迁移由 02 完成。
- [ ] 复用版本 HTTP 与真实浏览器测试，验证同快照响应、非法引用、未完成准备、精确来源、单元切换、长正文及保存期间继续编辑；补齐本切片相关的键盘、窄屏和失效目标行为验证。
- [ ] 同步本切片对外契约的 OpenAPI 与 generated client，完成受影响测试、前端类型检查及后端 Pylint；共同契约变化按规格运行 directing 测试集，记录验证限制。

验收承接：A01、A02、A03、A04、A05、A06（正文）、A14（单元定位）、A17、A18（保存）、A19、A20、A23、A24（指令基础及共同能力）。
