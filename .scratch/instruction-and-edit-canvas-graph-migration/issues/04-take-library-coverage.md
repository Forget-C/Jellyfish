# 04: 同场素材浏览与实际覆盖追溯

**What to build:** 用户从剪辑总览进入独立的同场素材视图，查看所有候选、固定来源和当前方案的审查判断、可用区间及实际覆盖，并继续在原工作区明确编辑和采用。新素材与可用性变化无需保存时间线即可刷新，跨版本取材保留真实生产来源。

Blocked by: 03 — 整场剪辑总览与时间线片段联动

Status: ready-for-agent

- [ ] 同场素材独立视图由后端提供业务节点、成员、摘要、问题和关系，包含有权限查看的未采用候选及现有两类 Take；不因默认聚焦当前剪辑而隐藏素材。
- [ ] 素材源身份和固定生产依据保留，当前版本判断与共享 Take 分开；跨版本引用不修改原生成记录、其他版本的审查或采用。
- [ ] 后端投影当前素材判断、审查摘要、可用区间数量、实际覆盖与明确目标。源区间、观察和当前 unit／coverage 身份可追溯，不从预计计划、正文或生成成功猜测实际覆盖。
- [ ] 素材审查、可用区间、实际覆盖和剪辑采用分别表达。原审查表单、区间与覆盖编辑器继续修改当前内容并使用共享保存／撤销；图摘要仍对应已保存基线。
- [ ] 从素材、采用片段和覆盖目标均能精确定位原对象；素材选择不误选某次采用，也不自动播放或采用。同一文件或 Take 的不同绑定与采用身份不丢失。
- [ ] 新 Take、素材审查记录和文件可用性在同 revision 下可刷新；保留当前素材、未应用片段表单和播放状态。读取失败与目标不可用区别于真实空素材库，提供原位重试。
- [ ] 当前相关素材复核记录提供摘要与原记录入口，完整历史按需查看并保留固定输入；明确复核沿用原保存前置条件与请求身份，不成为普通保存的副作用。
- [ ] 源素材、判断和审查证据基于既定版本快照批量读取，避免递归、逐节点重复查询和无界加载历史正文；图读取不写入判断或执行媒体操作。
- [ ] 完成同场及旧计划素材库、跨版本判断、实际覆盖、可用区间、采用定位与媒体失败的 HTTP／浏览器回归；验证新增候选刷新、未保存判断及失效覆盖目标。
- [ ] 同步必要接口与 generated client，完成受影响测试、前端类型检查、后端 Pylint及窄屏／键盘验收；与 05 无业务前置依赖，可分别实施。

验收承接：A08（全部同场素材）、A09（跨版本来源）、A10、A13（素材历史）、A14（素材／覆盖定位）、A16（新素材／审查）、A17、A18、A21、A22（来源）、A23。
