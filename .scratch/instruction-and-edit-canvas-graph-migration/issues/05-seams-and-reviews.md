# 05: 真实接缝与审查记录联动

**What to build:** 用户在整场剪辑图中看见实际存在的接缝、当前适用的审查摘要与待复核原因，并从接缝进入原审查操作或固定历史。片段变化后的关系和结论适用性由后端投影，保持现有人工审查流程。

Blocked by: 03 — 整场剪辑总览与时间线片段联动

Status: ready-for-agent

- [ ] 后端仅对直接相接的两个真实媒体片段提供真实接缝、成员和精确定位；空白、待拍占位和非直接相接片段不形成接缝，前端不重新推断邻接和审查计数。
- [ ] 接缝保留两侧独立片段、源素材、真实区间及原记录身份；同一 Take 多次采用时不能绑定到错误的片段组合。
- [ ] 当前审查摘要区分适用、待复核、未审查和读取失败等实际状态；替换源素材、调整源区间或构图后仅有关结论按原规则失效。
- [ ] 整体平移且两片段实际衔接未变时保留适用结论，不以绝对时间位置或任意 revision 变化错误判定失效。
- [ ] 点击接缝定位原接缝审查与相应片段，保留播放器和时间线工作区；选择不自动播放、提交审查或修改片段。
- [ ] 当前相关记录摘要在主图可见，完整历史按需打开并保留固定依据；明确提交审查仍遵守原保存前置条件、expected revision 和请求幂等，普通保存不创建审查记录。
- [ ] 未保存剪辑变化时明确图待同步，原编辑器可继续操作；新审查记录或适用性证据在同 revision 下可刷新，迟到响应不覆盖当前输入、选区或播放状态。
- [ ] 审查读取基于已鉴权快照与底层查询，不回读完整版本造成递归；失败保留原接缝和片段身份并可重试，不显示为已通过或以另一条接缝替代。
- [ ] 通过真实时间线与接缝审查 HTTP／浏览器用例验证直接相接、空白、占位、重复素材、替换、裁剪、构图、整体平移、历史查看及同 revision 刷新。
- [ ] 同步必要接口与 generated client，完成受影响测试、前端类型检查、后端 Pylint及窄屏／键盘验收；与 04 无业务前置依赖，可分别实施。

验收承接：A11（真实接缝）、A12、A13（接缝历史）、A14（接缝定位）、A16（审查证据）、A17、A18、A21、A23。
