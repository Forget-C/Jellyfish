# 13: 跨模态完整旅程、协议故障与既有功能回归

Status: ready-for-agent
Blocked by: 09, 11, 12

**What to build:** 验证用户从独立画布创建到文本、图片、视频生成、局部执行、取消、恢复及清理的完整旅程，并留下可复现的交付证据。

**依据：** [实现规格](../spec.md)；[任务依赖与共同验证](../README.md)。验收覆盖：A31、A32，并核对 A01–A30。

## Acceptance criteria

- [ ] 使用先产出再建立引用的文本→图片→视频流程，不用未来输出引用构造捷径；三类模型共享输入组件且实际 payload 与预览一致。
- [ ] 覆盖完整规格 A01–A32，每项关联实际用例／人工验收证据；没有实现或未运行的验证明确留空，不用本票掩盖前票未完成。
- [ ] 真实 SSE 验证并行、断流、重复、游标过期及最终成果；无前端状态轮询、无断线取消或自动再生成。
- [ ] 保存／运行／取消丢回包、模型修改、部分归档失败及流程中断均不丢用户输入、不错误发布结果或留下永久占用。
- [ ] 任务中心仍保持现有通道和通用信息，可回到画布上下文；共享组件与原实验室／场次工作台回归通过。
- [ ] 对外接口、OpenAPI、generated client 同步；TaskService 写入与 contracts 依赖护栏通过，未引入场次／旧 Shot 绑定。
- [ ] 真实页面验证桌面／窄屏、键盘焦点、IME、菜单、长文、媒体预览和底部参数栏；共享工作台控件变化按其设计规范验证主题隔离。
- [ ] 记录实际命令、结果、隔离环境和限制；实现后才更新相应架构事实，不新建无授权 release note 或路线图。

## Validation

- 按 README 的检查要求运行影响范围内后端、架构、前端类型及浏览器回归；共享基础设施影响不明时扩展范围。
- 记录隔离 MySQL 并发验证；没有环境必须明确标识该验收未完成，不用 SQLite 代替。
- 默认所有供应商由受控替身实现；真实外部生成的有效性不由这些用例证明，也不默认花费模型费用。
- 执行 [共同检查要求](../README.md#共同检查要求) 中适用于本票变更的命令，并记录真实结果。

## Scope and handoff

交付可复现的集成验收记录和已核对的规格覆盖，报告仍未完成项；本票完成不自动授权发布、提交或其他外部动作。
