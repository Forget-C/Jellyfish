# 05: 结构化引用编辑、稳定代号与输入编译

Status: ready-for-agent
Blocked by: 03, 04

**What to build:** 用户通过同一套 @ 编辑器引用实际存在的输入，重排或粘贴时保持来源身份，并能定位缺失、断线和编译问题。

**依据：** [实现规格](../spec.md)；[任务依赖与共同验证](../README.md)。验收覆盖：A07、A08、A09、A10、A11、A28、A30。

## Acceptance criteria

- [ ] 保存 PromptDocument 的文本、稳定引用和系统指令结构，定位身份不依赖正文偏移或编辑器内部 JSON；已完成输入不得只保存显示字符串。
- [ ] 接收端按同模态输入编号；同输出在同一接收卡只有一个代号，重排只改显示，不同来源同文件不合并；普通文字不自动改写。
- [ ] @ 分类选择和手写形成相同身份；完整 token 确认前仅匹配，@图片10不能提前绑定图片1；Enter／Tab、分隔符、失焦及 IME 按规则处理。
- [ ] 空卡或无结果卡可连线但不可提前引用，未知代号保留并诊断；已有缺失引用保留位置与来源，恢复同一来源位置才恢复使用。
- [ ] 同画布结构化粘贴保留来源，未连接时标记并要求手工修复；跨画布不绑定／复制；外部纯文本按目标代号解析；转义保留字面语义。
- [ ] 添加入口创建可见内容卡并连接，选择已有卡仅建线；引用删除不自动删候选边。
- [ ] 文本仅在引用处展开，不再解析展开内容；编译记录代号、来源身份和实际输入映射，普通文字不猜测为引用。
- [ ] 对模型切换保留的连接按实际使用校验：未用的不兼容候选只提示，实际使用的不兼容输入、数量超限或无效参数才阻止执行；不自动删除引用或截断内容。
- [ ] 有实际引用时阻止断线／删来源并定位正文、指令或专用配置；清理后可立即操作并一次保存，不要求先保存清理。
- [ ] 提供公开编译／实际使用解析入口和结构化诊断，保存不完整编辑与阻止执行分开；实际运行输入预览由后续运行票消费。

## Validation

- 公开编译边界覆盖顺序、身份、文件相同但来源不同、转义、非递归展开及失效诊断。
- 浏览器验证 IME、@长代号、分类定位、两种剪贴载荷、跨画布、添加入口、删引用后断线并保存。
- 使用真实内容卡构造引用；不得用未来输出 fixture 规避禁止提前引用规则。
- 执行 [共同检查要求](../README.md#共同检查要求) 中适用于本票变更的命令，并记录真实结果。

## Scope and handoff

向运行票提供 PromptDocument、实际使用集合、输出身份解析与基础编译结果；09 完成四条视频指令的具体能力及供应商字段映射，08 完成图片请求映射验收。
