# 10: 运行到目标与实际引用依赖编排

Status: ready-for-agent
Completion: complete
Blocked by: 07

**What to build:** 用户查看依赖预检后运行到指定目标，系统只执行必要节点，固定传递本轮结果，并使失败或中断分支明确退出。

**依据：** [实现规格](../spec.md)；[任务依赖与共同验证](../README.md)。验收覆盖：A09、A19、A22、A24、A25、A29。

## Acceptance criteria

- [x] 只按正文、系统指令或专用配置的实际使用构建依赖；候选未用不导致执行、过期或失败传播。
- [x] 目标总执行一次，有效上游复用，内容存在但依据已变的上游执行；缺失位置无论上游是否在范围内都阻止预检，先补齐来源。
- [x] 受理时固定范围、连接、已知具体输入和有效配置；本轮上游完成后仅用本轮对应位置形成下游快照，不能取旧输出、其他运行或后来编辑。
- [x] 下游提交前校验实际内容、数量及能力；失败不回退旧结果。先生产再引用的文本链可独立完成验收。
- [x] 单分支失败／取消阻塞必要后继，独立分支继续；自身前置校验失败结束本节点，不能留下无 Task 的永久 waiting。
- [x] 确认画布流程中断时终结未建 Task 的等待节点并记原因，不自动重新执行；已有 Task 沿用真实状态，浏览器断流不是流程中断。
- [x] 单节点取消和整轮取消按范围停止调度；当无活动 Task 且无仍可执行节点时结束运行并释放占用，不计算整轮成功等级。
- [x] 受理时即保护所有已知媒体输入，包含尚未创建 Task 的下游；运行编辑不改变已有文件或内容快照。

## Validation

- 真实 TaskWorker 验证先建立实际内容再绑定的 A→B→C 与独立 X→Y：复用、失效、失败、取消、下游校验和确认流程中断。
- 核查下游真正收到本轮上游内容；运行中编辑和其他运行结果不替换快照。
- 在运行受理的公开服务边界，验证已知文件引用随运行受理持久化，不等待 TaskInput 创建；此处使用合法文件与运行输入夹具检查引用保护，不伪称文本模型支持媒体输入。真实图片流程中 waiting 下游所用文件的删除验证归依赖 08、10 的 12，视频组合归 13。
- 执行 [共同检查要求](../README.md#共同检查要求) 中适用于本票变更的命令，并记录真实结果。

## Scope and handoff

提供多节点范围规划、依赖编排、退出及占用基础；11 扩充严格框选和多运行并发，12 完成整画布／项目清理。
