# 07: 取消、运行历史与断线后的观察恢复

Status: ready-for-agent
Blocked by: 06

**What to build:** 用户取消文本任务、查看历史或恢复断线观察时，看到真实状态和已保存正文，并可显式保存为独立内容卡。

**依据：** [实现规格](../spec.md)；[任务依赖与共同验证](../README.md)。验收覆盖：A22、A23、A25、A26。

## Acceptance criteria

- [ ] 节点取消与整轮取消有明确目标；queued／running／已终态沿用 TaskService 行为，接收意图不等于终态。
- [ ] 失败／超时／丢失取消回包不释放占用或假报取消；仍按权威 Task 状态同步，既有迟到结果策略不变。
- [ ] 历史保留每次实际输入、状态及成果；失败／取消保留旧当前输出，未完成正文标记来源并允许复制／显式保存内容卡。
- [ ] 为画布 Task 提供项目、画布、运行及节点来源信息，在任务中心现有业务回跳机制中增加对应定位；卡片已删除时仍能打开画布运行记录。仅新增来源与路由映射，不改任务中心状态通道或把画布专属编辑放入任务中心。
- [ ] 保存为内容卡固定内容与追溯，不持续跟随原模型，不改变所有下游的当前结果选择。
- [ ] 快照／恢复覆盖事件重复、游标过期、传输中断及终态回包先后；单个 run.finished 不关闭画布连接。
- [ ] Task 过期、启动中断、排队取消、执行失败等非成功路径均归并为画布节点事实；不能只依赖成功 deliver 回调。
- [ ] 恢复只恢复显示，不恢复模型执行，不自动取消或重发；前端不因成果非空推断成功，运行层不增加成功等级。

## Validation

- 可控真实 SSE 验证断流、重复、游标过期、最终正文替换和连接持续；检查模型调用次数不增加。
- 真实 Task 生命周期覆盖取消意图未知、已有终态和失败／取消后的累计正文。
- 浏览器验证历史→未完成正文→另存内容卡→引用，原输出仍保持原来的状态。
- 执行 [共同检查要求](../README.md#共同检查要求) 中适用于本票变更的命令，并记录真实结果。

## Scope and handoff

提供公共历史、取消、成果另存和可靠事件归并行为，供图片、视频与多节点流程复用；媒体成果文件归属由 08／09 接入同一结果协议。
