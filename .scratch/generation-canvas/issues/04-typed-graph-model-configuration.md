# 04: 类型化连线、分组与模型卡配置

Status: ready-for-agent
Blocked by: 01

**What to build:** 用户创建三类模型卡，选择模型、查看类型参数，并用兼容端口和分组组织可保存的画布。

**依据：** [实现规格](../spec.md)；[任务依赖与共同验证](../README.md)。验收覆盖：A06、A15。

## Acceptance criteria

- [ ] 轻量 CardDefinition 扩展三类模型卡及四类内容卡的端口、配置、校验与编译入口；模型能力独立描述，不按供应商复制卡类型。
- [ ] 前端通过明确 rendererRegistry、CardShell 和类型参数组件展示；复用共享 Composer 外壳，参考区／正文／底部参数区职责清晰。
- [ ] 拖线突出兼容端口，目标端口决定用途；相同来源端口到相同目标端口不重复建线，不支持输入不给隐式转换。
- [ ] 拒绝自连、循环和损坏端点；每目标端口输入顺序独立保存，新连接追加，卡片移动不重排输入。
- [ ] 分组支持命名、移动、折叠，成员独立；解散组保留卡片，不提供集合输出。
- [ ] 切换模型保留配置和连接并显示能力差异，不完整配置可保存；无效生成参数提供诊断。按实际引用决定输入是否阻塞的完整验收归 05，本票不依赖尚未交付的引用编辑器。
- [ ] 参数选项以真实接入能力为准；视频仅开放模型、画幅、时长和高级随机种子，未接入多模态文本能力不得虚报。

## Validation

- 真实文档保存回读验证端点、顺序、分组与模型配置；图结构异常有定位诊断。
- 浏览器验证拖线拒绝原因、输入排序、移动／折叠不变更输入、模型切换保留现场。
- 能力测试检查声明与现有 DTO／Adapter 一致，不用界面样例中的模型名推断能力。
- 执行 [共同检查要求](../README.md#共同检查要求) 中适用于本票变更的命令，并记录真实结果。

## Scope and handoff

提供候选连接、顺序、类型契约与受控 Composer 参数区。05 实现结构化引用并使实际使用判断完整；06、08、09 分别接通生成，不创建空壳运行成功状态。
