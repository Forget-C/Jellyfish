# 05: 以画布卡片展示方案与真实任务状态

**What to build:** 用户进入第三步先看到当前场次的画布信息卡，可搜索并打开任意方案，清楚区分分镜任务进度、候选就绪、需要核对及当前文档采用情况，后台变化不打乱浏览。

**Blocked by:** 01 — 建立工作台管理页与场次导航

**Status:** ready-for-agent

Resolution: completed

规格依据：[场次工作台共用画布与工作台管理规格，修订 2](../../shared-canvas-workbench/spec.md)，实施决策 13、16—17、20—21、27、29—30。依赖编号指本目录管理页增量；创建、更名、删除和失败重试由各自后续票据交付。

- [x] 第三步默认展示已有画布，信息卡包含名称、适用的真实分镜状态、原文变化提示、打开入口及适用菜单；无画布时提供生成指引，不新增截图或大幅空封面。
- [x] 按创建时间从新到旧稳定排列并支持名称搜索，最近打开只作标记；打开、任务完成、刷新和改名不重排已有卡片，新画布进入前部。
- [x] 从真实任务表达排队、生成、校验组装、失败／取消、分镜已就绪及需要核对等适用状态，不显示虚构百分比；任务成功只说明候选就绪，不等同已写入当前文档。
- [x] 当前采用来源以实际文档采用身份为准，不能仅凭候选可用、历史成功任务或应用回执判定；撤销、替换候选或人工编辑后摘要仍符合当前文档事实。
- [x] 摘要保留正确任务与画布身份，必要状态由服务端轻量查询提供，不靠最近若干任务列表猜测或逐画布加载完整文档；错误和读取失败不显示为空列表或全部完成。
- [x] 可打开任意有效画布，查看或核对入口定位对应画布及任务；失败保留已有内容并提供原因、详情及打开入口，不在管理页建立第二套卡片差异编辑器。
- [x] 同场不同画布的并行任务各自更新，不串状态；任务完成一律留在当前管理页面并轻量通知，切换场次或离页不取消任务、自动跳回或抢焦点。
- [x] 历史场次可查看列表、打开已有共同画布并继续原有编辑和模型运行，不把旧版历史只读规则套到共同画布；列表显示与准备操作权限分别判断。
- [x] 窄屏单列显示画布卡，长名称、状态文字、菜单与按钮可读可达；后台刷新不抖动布局，键盘能搜索并打开指定画布。
- [x] 经真实浏览器与公开接口验证排序、搜索、最近打开、并行状态、失败保留、离页恢复、历史查看及读取错误；特别覆盖当前采用被撤销／替换后不被历史成功回执误标。
- [x] 完成受影响的契约同步、类型、静态及行为检查，不改变文档保存、候选应用或普通自由画布的原有语义。
