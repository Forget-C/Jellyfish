# 02: 贯通场次划分与原文变更提示

**What to build:** 用户在管理页第一步阅读整章正文、定位场次范围、提取或人工调整划分，并在预览影响后明确保存；正文变化与对象准备过时分别提示，保护既有画布的固定原文。

**Blocked by:** 01 — 建立工作台管理页与场次导航

**Status:** ready-for-agent

Resolution: completed

规格依据：[场次工作台共用画布与工作台管理规格，修订 2](../../shared-canvas-workbench/spec.md)，实施决策 5—6、26—27、29、31。依赖编号指本目录管理页增量；复用既有章节划分、草稿、预览和保存能力。

- [x] 第一步以完整章节正文为主阅读区，选择场次会定位并高亮其已确认范围，正文保持可读行宽；没有正文时引导现有章节内容编辑流程。
- [x] AI 提取和人工调整进入同一整章草稿，复用范围、顺序、场次身份去向及影响预览；提取结果不直接覆盖已确认划分，用户明确保存后才生效。
- [x] 保存后留在管理页，不自动提取对象、创建画布或执行媒体；当前选择若失效按实际划分结果重新定位，不误用其他场次身份。
- [x] 当前场次标题旁提供简短的名称／顺序编辑并明确保存；范围调整返回第一步，章节正文进入现有编辑器；保留章节划分历史及恢复机制，不建立画布内部版本。
- [x] 章节正文已修改但范围尚未重新确认时，显示变化提醒和旧的已确认摘录，允许用户继续使用该摘录或前往核对，不能悄悄切换生成依据。
- [x] 确认新范围后，已有对象准备若与新摘录不符则明确标为过时，要求重新提取并采用适用结果后再新建分镜画布；尚未建立准备、成功准备为零和准备过时三个状态不能混淆。
- [x] 原文变更和划分保存不改写已有共同画布固定原文、对象参考或运行依据；已有画布采用新原文仍须在适用操作中明确确认。
- [x] 退出当前划分的场次可从历史入口查看；恢复当前身份后相应准备动作重新可用，既有共同画布不随划分变化被统一设为只读。
- [x] 复用现有未保存草稿、版本冲突、身份归属和提交未知保护；切换场次、步骤或离开页面不丢失未经处理的划分编辑。
- [x] 经真实浏览器与公开接口验证 AI／人工草稿、影响预览、保存与重开、名称／顺序编辑、历史恢复及两种原文变化；外部 LLM 可用受控响应，范围验证、真实保存及冲突裁决不替换。
- [x] 完成受影响的接口同步、类型、静态及相关行为检查，验证现有章节编辑和划分历史仍按原契约工作。
