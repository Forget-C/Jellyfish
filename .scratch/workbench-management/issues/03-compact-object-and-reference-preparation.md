# 03: 在管理页完成紧凑对象准备

**What to build:** 用户在第二步按角色、场所、道具连续处理对象，行内关联真实资产、选择默认参考图，并按需打开既有图片准备功能；没有对象或参考图也能明确继续分镜。

**Blocked by:** 01 — 建立工作台管理页与场次导航

**Status:** ready-for-agent

Resolution: completed

规格依据：[场次工作台共用画布与工作台管理规格，修订 2](../../shared-canvas-workbench/spec.md)，实施决策 7—9、12、27、29、37。依赖编号指本目录管理页增量；对象重新提取的候选审核与应用由 04 交付。

- [x] 第二步以紧凑对象行展示类型、名称、简短描述、关联资产、默认参考缩略图和状态，支持类型及未准备参考筛选；完整描述和出处按需展开。
- [x] 推荐用户明确发起对象提取，复用真实任务和服务端保存；首次适用结果可显示，尚未提取、提取成功但零对象、读取失败分别表达，不把提取设为进入分镜的必经门槛。
- [x] 资产关联选择留在行内，点击参考缩略图完成选图；明确“已关联资产”不等于“已选参考图”，空参考提示可以继续，真实失效资产或图片单独标明。
- [x] 新建并关联、上传及准备图片进入对象操作菜单，复用现有资产编辑器与参考图能力；每次图片生成均由用户明确发起，不引入对象准备画布或自动媒体执行。
- [x] 行内关联和选图使用真实对象及资产身份，并校验项目和场次归属；对象名称不能成为关联身份，同名但不同来源的对象不自动合并。
- [x] 保存后重开能恢复真实关联与图片选择，错误或冲突保留可恢复的编辑现场；对象准备变更不自动同步进已经建立的画布或改写运行依据。
- [x] 历史场次允许读取准备，界面和公开接口一致禁止新的对象提取、资产关联与图片选择修改；恢复当前场次身份后重新允许这些操作。
- [x] 尚未提取、零对象和缺参考均有明确继续分镜入口；对象任务运行中展示真实状态，不把尚未完成结果表示为已经采用，已保存准备继续生成的冻结规则由 06 承接。
- [x] 窄屏使用纵向对象信息行，筛选、菜单、选图和关闭入口可通过键盘访问；不堆叠重复空态或为图片预留大幅空白。
- [x] 经真实浏览器和公开接口验证首次提取、零对象、筛选、行内关联／选图、上传及资产编辑入口、保存重开、失效引用、历史限制和错误归属；仅外部 LLM／媒体供应商可替换为受控响应。
- [x] 完成适用的契约同步、类型、静态及行为检查，回归既有资产准备和画布参考独立性，不改变共同画布的引用或生成规则。
