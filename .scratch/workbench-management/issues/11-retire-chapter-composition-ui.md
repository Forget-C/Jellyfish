# 11: 退役章节组合及配套交付界面入口

**What to build:** 用户不再从章节列表或旧工作台提交已退出界面的章节组合／交付流程，旧链接可理解地回到所属工作台管理；独立审片、剪辑、试拍与整场导出继续使用原记录。

**Blocked by:** 01 — 建立工作台管理页与场次导航

**Status:** ready-for-agent

Resolution: completed

规格依据：[场次工作台共用画布与工作台管理规格，修订 2](../../shared-canvas-workbench/spec.md)，实施决策 4、28、39。依赖编号指本目录管理页增量；本票只退役已确认的界面入口，不退役交付数据或后端能力。

- [x] 移除章节列表中的“章节组合”按钮和当前挂载的专属面板，不将该功能迁入新管理页，也不另设替代入口。
- [x] 同时移除旧画布中的“用于章节／更新到章节”交付操作及“章节当前使用”提示，避免继续向已失去消费入口的流程提交。
- [x] 原章节组合深链接返回正确项目、章节的工作台管理并说明功能已停用；无效或跨项目身份明确反馈，不能静默跳到其他章节或画布。
- [x] 旧导演、审片、剪辑、试拍和整场视频导出保留独立访问路径，进入原宿主和原记录；入口可从管理页当前场次更多菜单找到。
- [x] 交付后端接口、数据表、历史快照、引用和文件使用保护保持有效；不删除历史记录、不为界面退役新增历史交付浏览或提交恢复页面。
- [x] 不把新共同画布产物桥接到旧审片／章节交付，不将“章节组合”解释成新整章渲染能力；名称相近但未挂载的更早跨场检查分支不顺带清理。
- [x] 仅移除本次界面替换直接产生的无效前端接线，不扩展为旧版本迁移、后端退役或无关死代码整理。
- [x] 经真实浏览器验证章节和工作台不再出现退役入口、旧链接说明及独立功能可达；通过公开接口和真实隔离数据确认交付记录、历史读取和文件保护未改变。
- [x] 完成受影响类型、静态和行为检查，并保留支持中的旧宿主；整体默认入口切换及最终用户指引由 12 汇总验证。
