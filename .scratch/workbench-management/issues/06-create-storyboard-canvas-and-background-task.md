# 06: 创建新分镜画布并可靠承接后台任务

**What to build:** 用户在管理页明确配置并创建新分镜画布，提交后立即识别真实目标和后台任务，结果不明时可靠恢复；对象准备可选，任务使用用户确认的原文和参考快照。

**Blocked by:** 05 — 以画布卡片展示方案与真实任务状态

**Status:** ready-for-agent

Resolution: completed

规格依据：[场次工作台共用画布与工作台管理规格，修订 2](../../shared-canvas-workbench/spec.md)，实施决策 6—7、14—15、17、20、26—27、33—34、37。依赖编号指本目录管理页增量；复用既有对象准备服务，创建不要求先完成新的对象候选流程。

- [x] 入口统一文案为“生成新分镜画布”，点击后在同页展开简短配置并保留已有卡片列表；名称预填固定前缀加时间，用户无需改名即可提交。
- [x] 默认“自动产出完整分镜”，可改为“忠实提取”；生产模型可稍后选择，未选择时保留既有图片／视频模型卡类型配置，说明模型用于后续生产，提交分镜不会执行媒体。
- [x] 次级“新建空白画布”只建立含固定原文的独立画布，不预建设计或生产卡；不复制既有画布、不创建旧场次版本或新保存体系。
- [x] 尚未提取对象或成功提取为零可明确继续，缺参考图允许进入分镜；已有准备与新确认摘录不符时阻止以过时准备创建并引导刷新，未建立准备不因此被迫先提取。
- [x] 对象重新提取运行中默认引导等待，已有准备时提供“使用已保存对象继续”，展示本次采用集合；提交前原文、准备或参考变化须重新核对，提交后冻结所展示依据，后来对象结果不得补入已提交任务。
- [x] 章节正文变化但仍采用旧已确认摘录时明确提醒和选择核对入口；创建使用明确依据，不自动采用尚未确认的正文变化。
- [x] 服务端确认创建与任务受理后展示真实画布卡、收起配置并突出新卡；失败保留已创建目标和原因，受理未知先核实同一请求，不凭同名或列表缺项重新创建。
- [x] 同一次提交的重复点击／重试共用请求身份，不重复建画布或任务；同场不同画布可逐次明确提交并行任务，同一画布有非终态分镜任务时界面与服务端拒绝重复发起。
- [x] 成功、失败、切换场次、离页及刷新均不自动进入画布或取消已受理任务；所有媒体执行仍需用户在画布中明确逐卡发起。
- [x] 用户实际改过名称、模式或模型后，切换场次、步骤或离开提示“继续填写／放弃配置”；默认预填不算修改，不提供隐含发起生成的“保存并离开”，已受理任务不阻止导航。
- [x] 历史场次在界面与公开接口均不能新建场次画布或分镜任务，恢复当前身份后重新允许；项目、章节、场次和画布真实归属均需校验。
- [x] 经真实浏览器与公开接口验证默认提交、两种模式、待配置模型、空白画布、无／零／过时准备、运行中采用已保存准备、输入变化、去重、未知受理、并行与同图门禁、配置离开和历史限制；只替换外部 LLM／媒体响应，真实保存、任务、组装和冻结依据不替换。
- [x] 完成受影响的契约同步、类型、静态及行为检查，回归原文锁定、空参考、分镜有限纠错与明确媒体执行边界。
