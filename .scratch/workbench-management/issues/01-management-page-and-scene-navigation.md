# 01: 建立工作台管理页与场次导航

**What to build:** 用户在一个沿用主站风格的章节级工作台管理页中选择场次、查看准备摘要并回访三个步骤，能够明确当前操作作用于本章还是本场，且浏览和切换不会启动生成任务。本票提供可独立访问和验证的新管理路径，默认入口替换由 12 完成。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

Resolution: completed

规格依据：[场次工作台共用画布与工作台管理规格，修订 2](../../shared-canvas-workbench/spec.md)，实施决策 2—4、27、29—30、39。本目录为已确认的管理页增量票据，所有依赖编号均指本目录；既有共同画布与原 12 张完成票据作为复用基线。

- [x] 新页面归属于明确项目和章节，沿用主站布局、导航、主题及共享控件；与独立全幅工作台画布区分，不引入新的方案实体或保存系统。
- [x] 左侧按剧情顺序展示场次序号、名称、对象数量、画布数量，并支持名称搜索；仅在适用时补充任务或原文变化的文字状态，原文摘要放在右侧当前场次区域。
- [x] 列表通过整章轻量摘要取得对象数、画布数、是否已有成功准备、准备是否过时及必要任务身份／状态，不逐场读取完整画布或资产目录，不以旧版导演计数替代新画布准备度。
- [x] 三个步骤明确标为“场次划分〔本章〕”“对象与参考〔本场〕”“分镜与画布〔本场〕”；步骤可回访，点击只导航，后续操作复用已有业务能力，不维护独立的持久化步骤进度。
- [x] 无场次时进入第一步；已有场次时恢复有效的最近场次及步骤，失效记忆有明确回退；显式深链接优先，切换场次不会继承上一场的对象、任务或临时展示状态。
- [x] 当前场次原文和摘要来源明确；历史场次入口置于左栏底部，可查看已有准备与画布，旧导演、试拍、审片和剪辑入口集中在当前场次更多菜单并指向原宿主与原记录。
- [x] 加载、无正文、无场次、搜索无结果、读取失败分别表达；失败不伪装为零对象、零画布或准备已完成，错误及跨项目身份不静默跳到其他场次。
- [x] 使用紧凑分栏和右侧自适应内容区，当前步骤及主动作固定在内容区顶部；窄屏通过场次抽屉切换，关闭、焦点和键盘操作可达，状态不只用颜色表示。
- [x] 经真实浏览器与公开接口验证选择、搜索、导航恢复、深链接优先、无任务副作用、历史查看及错误归属；使用真实业务数据，确认摘要不依赖逐场加载完整文档。
- [x] 接口变更同步公共契约与生成客户端，完成受影响的类型、静态及行为检查；保留现有主入口，交由 12 在贯通验收后统一切换。
