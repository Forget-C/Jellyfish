# 10: 删除画布时统一保护活动任务与并发修改

**What to build:** 用户能从管理卡片明确删除整张画布；两个删除入口与服务端共同阻止删除活动任务目标或确认期间已被保存修改的画布，并在删除结果未知时核实真实状态。

**Blocked by:** 05 — 以画布卡片展示方案与真实任务状态

**Status:** ready-for-agent

Resolution: completed

规格依据：[场次工作台共用画布与工作台管理规格，修订 2](../../shared-canvas-workbench/spec.md)，实施决策 23—25、27、38。依赖编号指本目录管理页增量；本票包含用户明确批准的共同删除保护，保留既有硬删除范围和文件使用规则。

- [x] 管理卡片菜单提供“删除画布”，确认说明删除整张文档及其画布运行历史等记录且不可恢复；不得表述为隐藏、归档、解除场次关联或可用画布撤销恢复。
- [x] 共同删除接口在最终删除事务内核对活动分镜任务与各类画布模型运行，排队／运行等非终态均阻止删除；两个入口表现一致，直接调用接口也不能绕过。
- [x] 补齐分镜任务保护并保留图片、视频及其他模型运行保护，返回“任务结束后可删除”等可读原因；删除不隐式取消任务，仅禁用前端按钮不算完成。
- [x] 打开删除确认时核实当前保存修订，执行时再次核对；确认期间发生任何已保存修改均阻止本次删除并要求重新确认，原文档和新内容保留。
- [x] 两个入口采用同一修订核对规则，缺失或过期的确认依据不能形成绕过；最终校验与删除保持事务一致，覆盖任务启动、保存与删除相互竞态。
- [x] 保留现有当前页面编辑权、未保存保护和离开处理，响应未知先核实原操作，不把网络错误当成删除成功；不宣称能发现其他浏览器尚未保存的草稿。
- [x] 成功后工作台与普通项目画布列表均移除有效入口，旧链接和任务历史中的失效目标明确提示不可用，不猜测替代画布。
- [x] 沿用既有删除范围，解除被删画布自身的文件使用关系，不主动销毁文件实体、其他使用关系或独立历史记录；不增加软删除、回收站或整图撤销。
- [x] 历史场次已有共同画布仍可按相同保护删除，不能因场次历史身份绕过任务或并发检查；普通自由画布同样遵守适用的共同删除保护。
- [x] 经真实浏览器及公开接口分别验证两个入口的活动分镜、各类模型运行、确认后保存、直接请求、未知响应和成功删除；核对真实数据库中文档／任务保留、文件使用关系和其他画布不受误删。
- [x] 完成公共接口与生成客户端同步、相关类型／静态检查及普通画布删除回归；全部并发与删除验证使用隔离真实数据，不操作用户工作记录。
