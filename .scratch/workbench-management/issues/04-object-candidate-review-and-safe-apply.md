# 04: 对象重新提取先核对、再安全应用

**What to build:** 用户重新提取已有对象准备时先获得可恢复的候选，核对新增、移除及人工关联受影响项后整批采用；提取或确认期间的人工作业和原文变化不会被迟到结果覆盖。

**Blocked by:** 03 — 在管理页完成紧凑对象准备

**Status:** ready-for-agent

Resolution: completed

规格依据：[场次工作台共用画布与工作台管理规格，修订 2](../../shared-canvas-workbench/spec.md)，实施决策 9—11、27、34。依赖编号指本目录管理页增量；复用现有对象识别任务，不新增 Agent 或用户可切换的准备版本。

- [x] 首次提取只有在原文与准备基线仍适用时才直接展示；重新提取已有准备成功后只生成候选，已保存对象、资产关联和参考选择继续有效，任务完成不自动替换列表。
- [x] 候选按对象展示新增、移除、人工关联或参考受影响及需重新关联项，用户只能整批确认应用或暂不应用；不提供逐对象勾选、人工配对或按同名自动合并。
- [x] 暂不应用保留旧准备及候选，离页、刷新后可从对应任务结果重新查看，任务和场次归属明确；不增加准备方案版本切换系统。
- [x] 稳定身份与来源匹配的对象可更新提取名称、描述并保留人工资产／图片选择；无法匹配的对象明确待关联，退出列表不删除项目资产或文件，不改写已有画布。
- [x] 模型返回前、预览后或提交前仅发生人工关联／图片变化时，候选与人工选择均保留，重新计算差异并要求再次确认，不新增模型调用，也不仅因准备修订变化就丢弃成功候选。
- [x] 已确认场次摘录变化后，旧候选保留可查看但不可直接应用，明确引导重新提取；章节正文变动但已确认摘录未变时遵守旧摘录提示规则，不混淆两种变化。
- [x] 首次提取运行期间出现人工准备同样受到保护，不能以“首次提取”为由覆盖新选择；原预览已失效时不得继续使用旧确认。
- [x] 应用在真实事务中核对任务身份、项目／场次归属、原文依据及预览准备修订；支持幂等回执、重复提交和响应未知核实，不重复应用或部分覆盖。
- [x] 历史场次不得通过候选应用绕过对象准备修改限制，仍可查看结果；恢复当前身份后也必须重新核对原文和准备基线。
- [x] 经真实浏览器贯通重提取、查看差异、暂不应用、重开和整批应用；经公开接口验证三处人工修改竞态、来源变化、错误归属、过期预览、重复请求与响应未知，断言持久化结果及外部模型调用不增加。
- [x] 仅替换外部 LLM 响应，保留真实任务执行、数据库、差异计算、事务和回执；完成受影响的契约、类型、静态及行为检查，验证资产文件和既有画布未被连带改写。
