# 章节划分与场次版本设计

这里记录已确认的产品边界。当前实现见[章节划分架构](../architecture/chapter-division.md)和[场次版本架构](../architecture/scene-versions.md)。

## 章节划分与历史

- 人工划分和 AI 方案共用整章编辑器。AI 分析结果是可编辑的候选，用户核对范围和身份映射、预览影响并明确保存后，才改变正式划分。迟到结果进入历史，不能覆盖新输入。
- 未保存草稿、当前正式划分和正在查看的历史分别表达。正式版本保存的是当时的原文、有序场次和明确来源。无实际变化不产生新版本，保存关系不明的旧结果按未知展示。
- 只读查看历史保留当前草稿。基于旧版本编辑时，旧快照提供内容及真实身份，当前正式划分提供提交基线。旧原文范围需重新定位，完整核对后保存为新版本。
- 保留、退出及恢复使用显式场次身份；同名或相似原文不构成复用证据。恢复划分不回滚生产成果。任务或引用阻塞在预览中指出，不自动取消任务或迁移素材。

## 独立的场次创作方案

- 同一场次版本把原文依据、设计、生产单元、指令、参考、素材判断和剪辑组织在一起。保存更新所选方案；明确新建得到空方案，另存为复制当前编辑内容。草稿、保存请求和内部并发修订都不是另一套可选方案。
- 原文更新不替换方案依据。同一有效场次可保留旧原文继续创作，也可明确更新该方案所用依据；退出划分的历史场次只读。
- 自动与手动保存共用校验和并发保护。失败保留输入，切换与跨页交接先处理修改。恢复保护只覆盖未保存现场，撤销历史不作为持久的按时间回滚功能。
- 只有关联任务均核实为终态时才允许另存为。任务成功不要求建议已采用或审片已完成；另存为不自动取消任务、不额外保存原方案。复制后的内容与判断分别演进，共享媒体继续指向原生成记录。
- 生成、检查、审片、导出和章节交付保留各自的固定依据。保存或浏览不触发这些操作，编辑新内容也不改变历史结果。
