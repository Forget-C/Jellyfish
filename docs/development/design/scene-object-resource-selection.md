# 对象参考卡片与资源选用设计

状态：2026-11-16 功能已实现并通过集成验收；本次实际库的存量转换已按用户确认的精确计划执行并验收。本文保留设计及后续维护约束，不构成其他数据清理授权。

领域边界见[术语表](../../../GLOSSARY.md)、[场次对象身份引用决策](../adr/0009-scene-object-resource-references.md)及[独立项目导入决策](../adr/0008-image-source-resources-and-project-imports.md)。当前页面规范见[项目内部页规范](../standards/project-internal-ui.md)，当前业务实现见[场次工作台架构](../architecture/directing-foundation.md)。

## 范围与身份

本次包括场次对象卡片、选用与创建流程、由对象派生的画布资源引用，以及实际生产用图解析。对象仍为人物、场所、道具三类，不新增服装提取对象，不扩展其他项目候选，也不改整张画布的布局。

| 提取对象 | 当前项目候选 | 资产库候选 |
| --- | --- | --- |
| 人物 | 项目角色 | 演员，独立导入为项目角色 |
| 场所 | 项目场景 | 场景 |
| 道具 | 项目道具 | 道具 |

“选用”指为提取对象采用已有项目资源。项目内直接复用，库中对象先独立导入；不为每个场次重复复制项目资源。库中导入仍复制全部有效成员图片及既有主图／视角默认选择，不继承来源设定、长期参考或任务。

提取对象保存自己的名称、描述和出处，不随资源选择或资源改名而覆盖。例如故事对象“张三”可以选用资源“青年男子”，卡片及其画布引用仍称“张三”；名称入口打开的详情明确显示实际资源“青年男子”。画布对象名称被明确修改时，引用标签按稳定身份更新。

## 卡片三行结构

卡片的自适应分栏、图片尺寸、三行结构、按钮主次与窄屏规则，以[项目内部页的对象参考样式规范](../standards/project-internal-ui.md#工作台管理的布局与阅读)为权威来源。按窗口断点确定列数并等分正文宽度；同一窗口下卡片等宽，不受内容和数量影响，末行保留空列。

内容依次为对象名称与类型、固定占高的提取描述、等宽操作按钮。三行表示三个内容区域，极窄屏操作区可以分行。名称入口、描述来源和动作状态继续遵循下文业务规则。

dropdown 仅含“描述与出处”和适用的“清空”。不再设置查看关联资源、编辑对象参考或解除关联菜单项。详情复用项目资源对应类型的编辑与图片管理页面，生成和编辑集中在详情；返回恢复列表筛选、滚动和焦点。

## 操作状态

| 状态 | A | B | C |
| --- | --- | --- | --- |
| 无选用且存在同名候选 | 选用同名 | 选用 | 创建 |
| 无选用且没有同名候选 | — | 选用 | 创建 |
| 已选用，包括无图片 | — | 重新选用 | 重新创建 |
| 原选用资源失效 | — | 重新选用 | 重新创建 |

A 存在时为推荐主动作；没有 A 时突出 C，B 为次动作。同名查询未完成或失败不得表示为没有同名，查询中保持操作区域稳定，失败提供重试。后台刷新保留已有内容。

### A：选用同名

按同类、当前项目与资产库范围及服务端名称规则查找精确同名，不把模糊搜索当作同名。共享资源选择抽屉展示图片、名称、来源、描述与采用效果；两边都有候选时一起展示，项目资源排前，用户明确选择，不自动合并或选用。

项目候选确认按钮为“确认选用”，资产库为“导入并选用”。同名项目对象即使无图仍可选用；资产库导入继续要求至少一张有效图片。若选库中对象却与项目同类名称冲突，修改副本名称后导入，或返回选择已有项目对象，不能覆盖或自动合并。

### B：选用／重新选用

复用项目资源导入的 ResourceSelectionDrawer：项目资源／资产库来源切换，默认项目资源；名称或描述搜索、图片网格、分页、选中态和成员图片预览。预览与选择独立，选择候选不立即提交；本流程选用对象，不选择本场固定单图。

重新选用在同一抽屉中说明：将更新本场选用及沿用它的画布动态参考，原资源和图片保留，明确采用的固定图片与已受理任务不变。提交前可取消；失败保留选择并可重试，冲突或来源失效时刷新核实，不自动选择替代对象。

### C：创建／重新创建

提供“上传图片”和“填写设定并生成”。上传复用 Dragger、上传列表、主图与视角设置，直接创建当前项目资源，不先创建资产库对象；人物创建项目角色。填写设定复用对应编辑器并预填提取名称、描述，生成参数由用户确认。项目直接上传是新增能力，本轮入口限定在对象参考流程。

重新创建始终新建资源并替换选用，不代表给旧资源追加图片；追加图片进入旧资源详情。原资源保留，名称冲突须调整，不覆盖。资源创建成功即完成选用；排队或生成失败不回滚到旧资源。创建成功但选用失败时重试原资源的选用，禁止重复创建。

已受理生成关闭后继续，失败在资源详情恢复。任务进行中仍可清空或重新选用，旧任务结果留在原资源，不恢复或覆盖当前选用。创建、选用、清空请求提交期间阻止该卡片的冲突操作，生成期间阻止重复受理相同提交；草稿和离开保护复用现有规则。

## 清空、更新与删除

清空前二次确认，说明解除本场资源选用及沿用它的动态参考，保留提取名称、描述、出处、资源和图片。清空后不删除提取对象，卡片恢复无选用状态；相关画布参考卡及正文引用继续存在，显示未选用资源／暂无参考图。对象参考页不提供删除提取对象操作。

资源编辑和图片更新可被后续动态解析读取；已选用无图资源仍可通过名称进入详情准备图片。资源在管理入口被删除时，动态引用显示资源失效，不猜测同名替代，也不删除提取对象或画布参考卡。不因动态引用存在而一概禁止删除资源；删除文件仍须遵守任务、固定引用及历史保护，资源删除不能连带破坏这些文件。

只读状态仍可阅读描述、预览图片及查看详情，写操作禁用。资源可用、图片成员可用与封面加载成功是不同状态，加载失败可重试，不清空选用。

## 引用关系与实际用图

关系为“画布对象参考 → 场次提取对象 ID → 当前选用项目资源类型及 ID”。不是每张画布直接复制场次当时选用的资源 ID，也不按显示名称寻找对象。清空或重新选用影响仍沿用此关系的画布后续解析；另外明确采用的固定图片保持独立。

场次准备只持久化对象选用，列表按需读取主图及可用状态，无须加载或持久化完整图片集合。当前分镜文字规划模型使用原文和对象文字信息，不接收资源图片；目标设计移除为初始化单图卡而提前固定资源图片的要求。新画布保留对象引用，实际图片／视频生成提交时才解析本次用图并注册文件保护。

| 选择 | 实际解析规则 |
| --- | --- |
| 未指定图片或角度 | 当前有效主图 |
| 指定资源支持的角度 | 该角度当前有效默认图 |
| 明确指定具体图片 | 保留该图片选择，不跟随默认图变化 |

缺图不回退到任意图片或其他角度。必需参考缺失时阻止提交；允许无参考的使用场景须明确按无参考继续。已受理任务固定实际用图，执行、重试和历史核对不重新按资源当前图片解释输入。

### @ 引用交互

复用现有结构化引用编辑器，`@张三` 表示主图，`@张三-正面`、`@张三-左侧` 等表示相应角度默认图；主图不等于正面默认图。候选展示主图、受支持角度、缩略图及必要消歧信息，缺图候选不可用。输入可筛选候选，明确选择才插入引用，未确认文字仍是普通文本。

内部引用保存稳定身份与用图选择，不拆分显示文字建立关系；名字含连字符、同名对象或改名不能导致错绑。场次派生引用沿用故事对象名，资源名独立。指定单图继续用现有图片引用方式，不另造文件编号语法。角度采用资源已有受支持值，不从描述自由猜测，也不把旧参考卡的自由角度说明当作资源角度标识。

同一对象可同时引用主图及多个角度，保留各自选择与同一对象身份，不按资源 ID 把它们合并成一个引用。解析到同一图片时可复用媒体输入，保留各处文字引用；超出模型图片数量或能力时明确提示，不静默丢图。图片集合只提供候选，不全部发送给模型。

## 存量处理边界

不新增旧场次单图格式兼容分支。有效资源选用直接转为对象级关系，资源成员图片保留；旧场次独立上传图片能明确归属时加入对应项目资源，不覆盖已有主图或视角默认图，其他选用该资源的位置也可使用这些成员。

无法直接转换的冲突项可以清理，不按同名猜测归属。实施前须给出具体记录、依赖和文件保护变化清单，再按确认范围执行；方案确认不授权未列明的画布、任务、资源或文件删除。仅解除确定已失效的场次单图保护，保留实际使用方的保护。

已有正常固定图片引用是持续支持的产品能力，不视为冲突或新增遗留兼容模式；已有画布与历史任务不自动改成动态资源引用。已有画布需切换时由用户明确更换参考来源。

## 实施验收

- 三行结构、空描述占高、窄卡及放大字体下操作可达；菜单与标题入口符合状态，图片角度 Select 已移除。
- 三类对象、两个来源、同名双候选、无图项目对象、名称冲突、搜索分页、失败重试和取消均覆盖。
- 上传及生成创建直接归属项目，创建后选用失败不重复创建；清空、重新创建及重新选用不破坏旧资源。
- 画布经提取对象解析资源；清空、重新选用、资源改名及主图／角度图更新不要求改写画布绑定；明确固定图片保持独立。
- 主图、角度、固定图片、多角度同对象、同文件去重、缺图、资源删除、模型限制、连字符和同名消歧均验证。
- 分镜文字任务不读取或固定资源图片；实际媒体任务固定本次输入，后续资源变化不改变运行与历史，文件保护可核验。
- 精确检查存量转换／冲突清单及任务、画布、文件依赖；未确认的额外删除不执行，不引入旧场次格式兼容分支。
- 实施时按开发规范运行受影响测试、前端类型检查、适用的后端检查及接口同步；本次文档确认不等于这些实现验收已通过。
