# 场次设计、生产与交付设计

本文保留旧四画布的交互设计与业务边界，相关前端已退役，不作为当前产品操作指南。当前入口及退役范围见[场次工作台架构](../architecture/directing-foundation.md#旧四画布退役范围)，现行分镜方案见[场次工作台与共同画布设计](shared-canvas-workbench.md)。后端及存量记录保护继续保留，下文前端交互仅供历史参考。实现见[场次工作台架构](../architecture/directing-foundation.md)、[场次版本](../architecture/scene-versions.md)与[素材、剪辑与交付](../architecture/directing-edit-delivery.md)。

## 导演画布

- 导演以场次总览进入镜头子图。原文为总览锚点，镜头入口按计划顺序排列；全场内容、跨镜共享和未关联设计各有独立位置。空方案仍可编辑全场内容和建立首镜。
- 一个设计对象仅有一张可编辑原卡。按明确适用范围区分全场、单镜专属、跨镜共享及未关联。共享计数按不同镜头身份，子图中的虚拟卡仅定位原对象。引用变化更新归位而不复制对象；解除关联保留原内容。
- 业务边以真实字段关系为依据，结构引导线只表达浏览路径。共同名称、人物或位置不能推导关联；间接依赖的证据可追溯，不能变成虚构直接边。定位依赖当前版本对象身份，歧义或已删除时明确提示。
- 卡片预览、导航、布局和内容编辑各自独立。手动位置按视图保存；排列或切换不变更业务顺序。访问旧来源或引用时保留当前未保存输入；不伪造第二套编辑对象。

## 生产单元与指令

- 在单元内明确本次动作范围、模型、时长、画幅和参考。默认资产只提供候选，当前输入由用户明确绑定；模型不支持的已填参数可保留供修正，生成前须通过校验。新单元继承创建时的场次输出画幅，既有单元不随输出画幅修改。
- 建议先查看差异再明确应用，整次应用核对来源、范围和引用冲突。应用更新当前编辑内容并纳入撤销；已选镜头、建议范围、设计完整性和拍摄准备度分别表达。
- 指令保留其实际来源、所选动作、适用约束与参考。相关设计、参数、参考或原文依据变化后，明确更新指令并重新核对受影响检查。无关单元继续使用仍适用的检查；在途结果保留为候选并提示依据变化。
- 保存、应用建议、检查、拍摄分别由用户触发。批量拍摄按明确选择逐项预检，列出可执行与受阻项；提交只消费仍适用的通过项，按项保留状态、核实及取消入口。失败或取消的原依据重试与按当前内容生成分开。

## 审片、交付与导出

- 素材审查记录真实可用区间和覆盖，采用在时间线另行操作。同一 Take 的各采用片段独立调整取材与构图。接缝审查只看实际相接的媒体；整场验收分别记录画面、覆盖和声音。
- 局部返工优先保留有效区间。受影响的落幅依赖和接缝按真实片段定位，用户提取新落幅后明确换绑并更新指令与检查；无关单元仍可操作。
- 使用到章节固定当时的保存内容与适用审片；可以明确交付带占位的顺序预演，阅读时显示缺口及验收状态。普通保存不更新章节交付。
- 整场导出固定保存时间线、画幅、片段适配及尺寸档位。保留真实原声、黑场和空白时长；有待拍占位时先补齐真实素材。验收与声音状态保留提示。原记录重试使用原配置和媒体，成功成果独立保存。
