# 项目内部页前端规范

本规范承接首页与项目列表的通用配色、字号和留白，规定已接入页面的工具栏与下述专属规则。未纳入具体章节的专属改版不能据此视为已实现。独立生成画布和场次画布保留各自布局；五类对象的新建与详情使用管理资产共用抽屉。

## 内容工具栏

普通项目页不显示面包屑和返回项目列表入口，顶部项目一级菜单通往项目列表。每页只有一条内容工具栏和一个语义主标题，不在正文重复同名标题。子页面通过项目专属工具栏入口提供自己的标题和操作；尚未迁移的页面沿用原入口，不能全局改变通用工具栏的默认值。

工具栏标题16px／600，操作13px，辅助信息12px；桌面工具栏约52–56px、控件32px，窄屏控件36px。页面左右留白20px、手机16px，区域间距20px、控件间距8px。沿用雾蓝微渐变、纯色和同浏览器偏好，颜色与焦点规则见[首页与项目列表前端规范](home-project-ui.md)。

章节标题、可靠总数与搜索在左侧，新建章节在右侧；空间不足按组换行。更多只包含当前页面相关动作，不叠加跨资源创建或通用制作入口。未知或失败的总数显示“数量未确认”，不以当前页条数冒充总数。

普通项目内容使用既有工作台高度链和纵向滚动面板，允许正文自然滚动；不继承首页一屏限制。超宽表格由自身局部容器承接横向浏览，不通过裁切正文或缩字维持截图。

## 章节列表

章节名称继续编辑原文，状态标签只表达状态。制作操作集中在右侧：

| 数据状态 | 右侧动作 |
| --- | --- |
| 待补原文 | 编辑原文及轻量工作台管理，历史仍可访问 |
| 已有原文、确认无场次 | 划分场次，进入独立管理页的划分步骤 |
| 已有场次或场次状态未知 | 工作台管理 |

行内动作使用轻量链接，实心蓝主要用于新建章节。保留原文预览、字数、可靠场次数、搜索和分页。工作台返回章节时恢复目标位置与操作焦点；目标不在当前筛选或分页时保留可达的返回反馈。不恢复已停用的章节组合抽屉。

## 原文编辑弹窗

标题16px／600、分节14px、操作13px；白色表面12px圆角、16px内间距。手机沿用全屏外壳。正文在可用高度内滚动，页脚操作可达；标题与操作较多时允许换行。此处只规定外层表现，保存、差异核对、历史、任务、未保存保护及原文变更影响提示保持原语义。

## 项目概览

概览接入同一紧凑工具栏，保留当前制作、生成画布、章节场次三个区域。当前制作仍按有效最近工作章节、首个未完成章节、首章依次选择；摘要截断不能改变此身份。下一步明确显示编辑原文、划分场次或工作台管理，保留真实状态与可靠场次数，未知不写成零。

生成画布保留实际封面、名称和打开地址，读取失败与没有画布分别表达。独立画布的主题和内部弹窗不受概览样式影响。

章节场次按章分组，最多展示三个有场次的章节。当前制作章节有场次时优先，剩余按章序排列；每章最多展示原顺序的前三场。场次用名称和箭头链接到明确选中的工作台管理场次，不重复长按钮文案。超过三场提供“查看本章全部场次”，进入该章工作台管理；区域标题旁的“查看全部章节”回到章节列表。不能把摘要条数当总数，也不以不完整章节读取推算全项目数量。

该区域始终有明确标题，加载、空列表、章节读取失败、场次读取失败及重试分别表达。概览正文允许滚动，不为填满页面添加虚假章节或场次。分节与条目标题14px／600，操作13px，区域间距20px，内容内间距16px；链接保持统一强调色、悬停及可见键盘焦点。

## 项目设置

设置页接入单一项目内容工具栏，标题为项目设置，不叠加制作动作或顶部保存按钮。表单左对齐、最大800px，按基本信息与生成默认设置分组；两组使用白色表面、12px圆角、16px内间距，组间20px。分节标题14px／600，操作13px；常规输入36px，长文本独占一行。视觉与视频风格、种子与比例分别双列，600px以下单列。风格统一以说明和开关展示；有修改时显示未保存提示。

保存与取消只在表单末尾，正文正常滚动，不能以固定高度裁切操作。保存期间保留原有锁和禁用状态，失败显示错误并保留输入；成功返回的项目成为新的已保存基准，取消恢复该基准，不能恢复为旧版本。字段身份、校验、默认值和原有保护流程不因布局变化而改变。表单样式限定项目设置页面，不修改全站设置表单默认值。

## 项目角色列表

角色页以新建角色为唯一突出的主动作，使用项目内容工具栏，空列表不重复创建按钮。复用项目资源卡片：约160px封面完整比例展示，名称14px／600、单行截断且提供完整名称，简介最多两行、缺失显示未填写简介。角色卡片与其他资源使用相同的基础字段，参考主体、服装和道具在详情统一选择，不在卡面增加组合信息行。

项目专属对象名称与编辑在当前地址打开共用抽屉，关闭恢复列表分页、筛选、滚动与焦点；管理区保留独立详情路由。共享对象在项目详情只读，编辑入口标注新标签页并打开资产页。角色使用自身设定及统一参考，详情与新建复用同一内容，不套用演员结构化属性。图片预览与名称入口独立，键盘和焦点沿用资源卡片规则。

角色危险操作明确为删除角色，不称取消关联。确认说明具体角色及移除配置的影响，曾参考的资产不随之删除。执行中禁止重复提交与关闭，失败保留对象和错误供重试，取消恢复入口焦点，成功定位有效入口。专属角色卡片显示进入资产库，转化为只读演员的边界见 [ADR 0007](../adr/0007-project-resource-ownership-and-library-copies.md)。

## 工作台管理的场次划分

沿用左侧步骤导航，正文仅保留原文主体与右侧约260px的本章场次辅助区，使用20px留白分隔；不足900px内容宽度时辅助区收为抽屉。辅助区按原文顺序展示场次并行内改名，不追加重复编辑表单。原文使用白色12px圆角表面，文字选区与已划分范围保留语义高亮；章节正文不可在此改写。

版本与智能划分、历史版本、保存为新版本合并到顶部标题行，分别采用魔术棒、历史时钟和保存图标并保留文字，标题16px／600、操作13px／32px高，窄屏保持可达并允许换行。保存成功短提示，不常驻无修改状态、成功横幅或放弃按钮。普通场次隐藏身份及重复原文，特殊来源核对按需展开。拆分、合并、保存与离开保护遵循[章节划分架构](../architecture/chapter-division.md)。

原文工具栏沿用图标加短文案的阶段主操作；次级操作使用带提示与可访问名称的纯图标，前后并入／合并统一从一个图标下拉菜单选择，不并排增加文字按钮。工具栏集中新建、并入前后场、范围调整、拆分合并及撤销，按选区和明确阶段显示有效操作；右侧场次列表不放新建或原文分配控件。新建名称在编辑区临时输入，先选后建保留选区，普通选区不因列表当前项自动修改已有范围。前后目标显示真实名称；不连续方向禁用并解释。完整覆盖多场时明确选择保留目标；中间抽取产生的残段和关联去向必须可核对。影响已有场次时确认前后范围与关联，取消保留现场；操作确认仅加入草稿，整章仍保存为新版本。具体连续性、空白、身份及撤销规则遵循[章节划分架构](../architecture/chapter-division.md)。

选择方式为右侧两个互斥图标：鼠标框选与键盘／触屏选择，使用浅蓝选中、完整提示、可访问名称和键盘操作，不再下拉收纳。切换保留有效选区与阅读位置，不制造新候选范围；切换场次清除临时选区。桌面32px、窄屏至少36px。

场次名称只显示一处。名称负责选场，铅笔切换同一行的名称输入，确认／取消图标直接可达。Enter、确认或合法失焦提交名称至本章草稿，Esc或取消恢复编辑前名称；输入法组词不触发快捷操作。空名称显示错误并保留输入，历史只读不提供编辑。新建名称在原文编辑区输入，最终由创建场次加入成员。

跨场次或阶段只保护当前临时操作，无实际输入直接切换，有输入提供放弃本次操作／继续；合法名称先完成，无效改名可放弃。跨步骤与离开仍共用一次整页确认，未确认阶段或无效名称阻止顶部保存及保存后继续，不允许跳过临时输入保存旧草稿。取消整页离开恢复输入，不保存离开丢弃草稿和临时操作。关闭窄屏抽屉仅收起界面，保留阶段、输入和错误，正文提供重新完善名称入口。

## 验收

通过真实页面操作，使用隔离HTTP响应检查章节状态和去向、总数未知、编辑器、空数据、失败重试、搜索分页和返回焦点。既有工作台隔离后端回归验证返回行为及原文保护。两种雾蓝主题覆盖1440×900、1366×768、1024×440、375px及相关断点两侧，检查单一工具栏、长名称、横向溢出、键盘可达性和弹窗底部操作。共享工具栏的改动还需回归实际受影响页面，独立画布外观不能被污染。

概览额外检查超过三章／每章三场的上限、当前制作优先与章序、场次原顺序、全部入口身份，以及场次读取失败后重试；双主题与视口矩阵同时检查长名称和所有入口可达性。

项目设置额外通过真实页面和隔离HTTP检查取消、保存锁、失败输入保留、重试成功及新基准上的再次编辑取消；检查校验错误、长简介、输入顺序、双主题和视口变化下的末尾操作可达。


## 项目资源卡片与演员列表

演员页使用项目统一内容工具栏，“从资产库关联”为实心主动作，新建为次要动作，查看资产库为轻量链接。内容不包裹重复标题卡片，空状态不重复工具栏操作。

项目内容滚动面板统一提供桌面20px／手机16px页面留白，演员、角色、场所、道具、服装和文件页不再叠加一层页面padding，首张卡片与工具栏标题左缘对齐。

资源卡片通过明确的项目样式选项接入，新建与详情复用对象抽屉。白色表面12px圆角，内部16px／窄屏12px；封面高160px，演员完整比例展示。网格按实际内容宽度减列，少量卡片保留正常列宽，不拉伸成整行横幅；两处采用同一网格最小列宽228px和16px间距。名称14px／600单行截断并保留完整提示与进入箭头，名称按钮在项目正文打开共用详情；简介13px／20px行高，预留两行40px高度，缺失显示“未填写简介”。卡面显示归属类型，专属对象提供入库按钮；参考配置在详情查看，内部ID和“已关联项目”不常驻。

图片入口与名称入口分开；有效图片用可命名按钮承载，Enter打开完整比例预览、Esc关闭并恢复图片入口焦点。缺图和加载失败显示图标与说明，不打开空预览。显式媒体回调仍可承载文件音视频预览，不把图片失败规则机械套用到其他媒体。

演员更多菜单按归属提供专属编辑／删除，或共享编辑新标签页／取消关联。取消关联只移除项目关系，删除明确移除专属对象；提交期间禁止重复操作，失败确认保持打开供重试。关联资产弹窗使用16px／600标题、13px动作、12px圆角及16px内部留白，正文视口内滚动，主要操作保持可达。

验收使用真实项目演员页面及隔离HTTP响应，覆盖关联、详情去向、菜单、取消关联失败重试、图片键盘预览与焦点、无图及加载失败，并检查双主题和宽窄屏。共享卡片调整须回归资产详情，不能因项目样式选项改变独立详情、内嵌档案或画布。


角色列表额外检查主体、服装和道具参考、缺图与破图、完整名称、预览Enter／Esc、菜单关闭、删除确认取消／失败重试／成功、防重复提交和新建角色；窄屏业务信息允许换行，角色详情及内嵌档案不受列表样式影响。

## 项目场所、道具与服装

场所资产页（导航沿用“场景”名称）、道具和服装与演员列表共用项目资源工具栏及卡片变体。从资产库关联为唯一实心主动作，新建次要，查看资产库为轻量链接；空列表保留解释，不重复整套入口。

场所封面使用填充裁切，道具与服装封面完整比例展示，打开后的预览均保留完整比例。每类资源都有类型图标及缺图提示，加载失败不打开空预览。名称打开当前项目的共用对象抽屉，简介缺失显示“未填写简介”，不重复展示项目关联、标签或内部ID。网格按内容宽度减列，不强制所有业务信息相同行数。

更多菜单按归属区分专属对象删除与共享资产取消关联，确认说明各自影响；执行期间保留提交锁，失败确认保持打开重试。关联弹窗使用项目资源的外层标题、圆角和滚动方式，提交期间禁止重复关联或关闭丢失上下文。场所资产关联与章节场次划分保持不同业务对象和接口。

验收逐类覆盖创建入口、详情／编辑去向、关联、取消关联失败重试、空列表、图片键盘预览及焦点；双主题四视口检查场所填充与道具／服装完整比例、长名称、缺图和失败占位、网格与操作可达性。独立详情与场次档案共用抽屉，画布布局保持原规则。

## 项目文件

文件页的布局、卡片格式、分页追加、批量选择、媒体预览和验收统一遵循[媒体文件展示规范](media-files-ui.md)。单条紧凑工具栏在标题旁提供章节筛选，数据始终限定当前项目及所选章节；默认浏览无复选框，显式进入批量模式后显示选择和真实批量下载。

项目文件卡面保留封面、名称与紧凑下载图标、类型。章节切换重置结果、位置和选择并隔离旧响应；预览不改变已加载内容和选择。外部下载标签页的服务端结果由原下载链路处理，不声称前端已获知下载完成。

## 制作流程导航与划分编辑

### 工作台管理的布局与阅读

工作台管理使用普通应用壳的雾蓝主题。桌面使用216px制作步骤侧栏，固定为剪刀图标＋场次划分、对象集合图标＋对象参考、布局图标＋分镜画布，菜单高40px、字号14px、圆角8px、浅蓝选中；小于1024px使用步骤抽屉。菜单不强制通关，对象参考可跳过。正常状态不显示尾部图标；任务处理中、失败或需要核对时才显示可访问的状态说明，不将内容存在解释为完成。内容顶部按步骤标题、辅助状态与当前动作组织，三页统一为场次划分、对象参考、分镜画布。标题16px／600，卡片与分节标题14px／600、操作13px、辅助信息12px；桌面控件32px、窄屏至少36px。页面左右留白20px／手机16px，区域间距20px、卡片间距16px、白色卡片圆角12px及内边距16px。列表不再外包重复白色面板，原文与完整表单保留独立表面。对象参考、分镜画布采用两行工具栏：第一行左侧聚合步骤标题与紧随其后的场次切换，标题文字至首个选项外框间距24px，与管理资产库一致，选项水平内边距12px、间距4px、圆角6px；第二行左侧筛选／搜索与数量、右侧主操作和更多。标题行与筛选行以52px最小高度、上下8px内边距对齐管理资产库；换行时自然增高。对象与画布内容区顶部内边距为0，对象统一网格不保留旧分组上边距；任务或异常提示与后续卡片间距12px。两步骤共享选中场次。标题行按剩余宽度最多显示三个连续场次，保持原文顺序并包含当前场次，不足时减项，窄屏仅显示当前场次下拉入口。全部场次使用右对齐纵向浮层，宽320–360px且受视口限制，支持名称／序号搜索、当前项标记与历史分组，搜索命中历史时自动展示；浮层内部滚动，不挤压内容。选择经草稿保护，取消恢复原场次，关闭恢复入口焦点。对象类型在空间不足时收为下拉；手机筛选与操作可上下排列。历史场次保留浏览，提取及生成仍受只读保护。场次划分不重复展示切换条。页面整体不滚动。

对象使用统一网格，不按类型纵向分组，不常驻重复标题与说明。类型、关联状态和次级参考状态组合筛选，默认全部，按场次记忆。对象卡片复用资产库的白色12px圆角与顶部通栏160px完整比例图片，内容区桌面16px／手机12px、行间距8px，对象网格采用资产库相同的最小228px自适应列宽、16px卡片间距，手机单列。内容固定三行：名称紧邻类型、更多靠右；出处单行省略并可查看完整内容；关联资产名称与参考图操作同排。图片居中完整比例展示，竖图允许两侧留白，不裁切或拉伸；桌面卡片次级按钮24px、12px字号、轻量图标加“更换／选择／上传”短文案，手机点击区至少36px；不常驻显示“已选参考图”，不显示铅笔图标。关联修改移入更多菜单。关联选择不常驻，桌面浮层／手机底部抽屉支持搜索和即时保存，提交期间锁定重复与关闭；失败保留选择和重试，更换／解除已有参考的关联前确认清除影响，不删除文件或改变画布已采用的参考。描述与出处移入更多按需阅读，手机使用底部抽屉。图片加载失败允许重试，不清除已存选择。关联资产与参考选择独立表达，不以资产封面冒充已选参考。卡面保留直接配置，长描述与出处按需阅读。成功保存后更新计数与筛选，移出当前筛选时焦点移至下一项或筛选控件；失败保留输入和恢复入口。资产新建和详情从当前内容右侧打开共用抽屉，保留左侧步骤、地址及对象列表，关闭恢复筛选、滚动和原入口焦点；保存及离开服从资产详情保护。图片预览、关联选择和资产详情为独立动作。

画布卡采用160px雾蓝默认封面、名称、当前结果、镜头数和创建时间；无镜头摘要显示“— 镜头”并说明暂不可用，不冒充零。当前轻量摘要无封面字段，不逐张读取完整画布；真实封面接入属于后续摘要能力。默认封面不提供预览。已有可打开画布使用名称与箭头进入，不重复提供底部打开按钮。未采用候选仍经明确的核对或“查看并采用分镜”操作处理，名称不得暗含采用。任务、候选、依据变化及采用结果分别表达，浏览标记降为次级；新任务失败不抹去已有结果。更多菜单承接更名、记录和删除，继续保留引用、草稿与未知提交保护。

本次页面会话按章节、场次和步骤记住筛选与阅读位置；全部场次列表保留搜索、历史展开及滚动位置。明确画布或任务深链接优先定位，轮询不重复定位；失效目标提示后保留可用列表，不自动选择替代对象。后台刷新不抢焦点、不覆盖输入、不自动打开或采用结果；失败保留原内容。媒体文件的六列、分页和呼吸箭头不套用到该业务卡片列表。

场次划分遵循[工作台管理的场次划分](#工作台管理的场次划分)中的双栏与窄屏辅助抽屉规则。保存操作即使移出正文，也须保持提交锁与草稿保护。相关弹窗正文滚动、主要操作可达；关闭详情恢复原入口，关闭任务记录不取消后台任务。


工作台与场次划分不显示应用壳面包屑。左侧顶部使用无边框返回箭头＋章节名称，统一返回对应章节列表并恢复定位；内容标题前不重复返回按钮。小于1024px时，返回和章节名称直接显示在步骤菜单入口同行，不必先打开抽屉。从对象或分镜进入范围核对时保留来源；点击来源步骤恢复原场次、画布／任务定位和阅读位置，失效目标明确提示，不自动替换。返回与步骤切换服从草稿保护。资产详情内部返回仍位于详情标题。

工作台不重复顶部步骤切换和继续到分镜按钮。场次名称与原文范围编辑统一进入场次划分，顺序按原文自动排列；原文变化提示可直接定位对应范围。对象页主动作是提取或核对对象差异，画布页主动作是生成新分镜画布，新建空白画布位于更多菜单。错误、历史和冲突不因简化操作而隐藏。

跨页面验收补充同一个资产在项目和资产库的卡片结构及尺寸比较、1／2／多张卡片、统一缺失简介、角色专属信息不驻卡面、明确返回与焦点恢复，以及中宽度抽屉关闭重新打开保留草稿。

项目资源和管理资产共用 ResourceEditorDrawer 的设定、参考、图片及保护。固定标题与底部操作、桌面两栏和手机页签遵循管理详情规范；关闭提供保存、放弃、继续编辑，保存／检测遵守提交锁与取消终态。工作台提取仅发现对象，明确创建才进入资源，可明确复用已有项目对象。显式查看资产库是独立跨区操作。
