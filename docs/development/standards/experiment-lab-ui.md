# 实验室前端规范

多模态聊天与文本、图片和视频试模共用应用壳、会话导航、历史和输入布局。配色、顶栏与页面留白沿用[首页与项目列表前端规范](home-project-ui.md)。本规范描述实验室专有的操作及验收要求。路由、持久化和任务接口见[生成实验室架构](../architecture/generation-labs.md)。

## 布局和导航

- 桌面使用 216px 会话侧栏，小于 1024px 从「会话导航」打开抽屉。四类会话按更新时间倒序混排，每项显示 16px 类型图标、14px 会话名与更多操作；名称单行截断且完整名称和类型可访问。侧栏顶部为「最近会话」（14px／600）和「＋新建」（13px、桌面高 32px）。新建默认进入多模态聊天，菜单还提供文本、图片、视频试模（13px）；选择后进入草稿，首次有效提交才持久化，取消菜单不改变当前内容。暂不设置类型导航、搜索、筛选、时间、摘要或日期分组。当前项使用浅色选中样式。鼠标、键盘和触屏均可访问重命名与删除。
- 标题栏约 52–56px，主标题为「实验室 · 多模态聊天／文本／图片／视频」，16px／600，后接次级文字的会话名；已有会话不直接修改类型。未持久化会话显示「新会话」。长名称可截断，完整名称仍可获取。更多菜单中的「清空会话内容」保留会话，删除会话使用独立确认。确认信息应包含对象及影响。
- 桌面会话列表和历史分别滚动，输入区保持可达。窗口较矮时收紧间距和摘要，极矮时允许路由内容纵向滚动。空状态使用简短引导。保留焦点样式、可读的错误反馈与输入边界。
- 输入面板采用白色表面和 12px 圆角。正文、操作、辅助信息分别使用 14px、13px、12px。桌面操作控件高 32px，窄屏高 36px，独立图标的触屏命中区域以约 44px 为目标。共用组件的实验室样式限定在实验室布局或相应浮层内。

## 输入与配置

多模态聊天默认只展示主模型，图片与视频模型放在折叠的模态配置区。聊天和试模共用可搜索、刷新和重试的模型选择器。聊天生成期间禁用发送；追问、审批和停止在原轮次操作。工具任务卡展示实际模型、公开参数、引用与产物。


- 自由输入默认三行，高度不超过 540px 时默认两行，增至六行后在编辑器内滚动。底部工具栏左侧保留模型与视频比例，右侧依次为参考素材摘要、「＋」和主操作；通过收拢摘要而非换行堆高工具栏。三个实验室统一使用「图标＋发送」。三个实验室的自由输入均以 Enter 发送、Shift＋Enter 换行，输入法组词期间的 Enter 保留给输入法。文本流式生成期间，同一主操作位置切换为「图标＋停止」，不同时保留禁用的发送按钮。
- 模型入口采用图标、名称和箭头，默认透明无边框，悬停轻底色，展开浅蓝底；一次点击直接打开模型列表，当前项勾选，选中后关闭。超过八个模型提供搜索，长名称可截断但完整名称可访问。列表优先向上展开并按视口避让，保留加载、无可用模型和失败重试。
- 「＋」位于发送左侧，文本提供选择提示词模板，图片增加添加参考图，视频增加配置参考素材。模型列表与添加菜单互斥，选中菜单项后关闭菜单再打开配置面板；Esc 关闭当前浮层并恢复入口焦点。比例继续直接可见。
- 模板显示名称、版本和已填变量数，默认值计入已填；底部不再重复显示模板按钮，通过「＋」选择或更换模板。变量抽屉提供编辑、最终提示词预览和转为自由输入。应用才更新实验草稿。取消、关闭或 Esc 放弃临时编辑。转为自由输入、切换模板或历史回填会覆盖已有编辑时先确认。
- 参考配置抽屉统一提供资料库选择、上传、预览与移除。输入区右侧摘要采用 32×32px 缩略图、6px 圆角和 4px 间距，桌面最多三项，剩余显示「+N」；窄屏最多一项，宽度不超过 480px 或高度不超过 540px 时显示「素材 N」。不常驻文件名或小图旁删除按钮。点击缩略图完整预览并可移除，点击数量进入已选配置；文件名及角色通过悬停、聚焦和可访问标签提供。触屏点击区域约 44px。视频首帧、尾帧、关键帧使用简短角标，主体摘要保留名称与顺序，完整预览同步展示角色、主体名称与素材顺序，视频有封面时叠加播放标识，无封面或失效时使用视频图标。比例和素材冲突保持可见。同一集合去重，保留不同角色及主体内的素材顺序。
- 应用参考素材后才绑定当前实验。取消恢复打开前的选择，已上传的文件仍保留在资料库。关闭、取消或切换会话后的迟到上传响应不得改变新的选择。上传失败可重试，其他已选素材保留。
- 切换视频模型保留原有提示词、比例和参考。根据当前模型响应标明可确认的冲突，并在冲突解除前暂停提交。能力请求失败提供重试，缺失的字段按未知处理，依赖现有服务端校验。只有当前模型的响应能更新能力提示。

## 会话、结果与失败恢复

- 历史按身份与状态、正文或媒体、轻量操作排列。短消息随内容收缩，长文本限制阅读宽度。单图约 480px 上限，多图随容器排列。视频预览通常为 360–480px，窄屏可继续收缩。竖向媒体限制展示高度，完整查看层保留原比例。视频历史展示播放入口，关闭完整预览时停止播放。
- 阅读较早消息时保持滚动位置并提供「回到最新」。加载更早消息后尽量保留可见内容位置。回填只更新可编辑输入，历史缺少的模型和素材信息由用户重新选择。
- 分别呈现首次加载、空数据、首次失败与刷新失败。空列表显示「暂无会话，从右上方新建开始」；部分读取失败明确列出失败类型并提供重试，不显示为空数据。刷新失败保留现有数据和输入。可靠状态和进度来自接口。读取任务状态失败提示「状态暂不可用」，不会改变任务终态。媒体重载和读取重试只发读取请求。
- 校验、上传或创建失败时保留完整输入。提交期间拦截重复请求，在服务端确认接收后更新草稿。提交结果不明确时先核对已有会话记录，无法确认则保留未知状态，交由用户决定后续操作。
- 切换实验类型、会话、新建或离开时保护尚未发送的编辑。已取消的临时配置、系统默认值和已接收的输入不单独触发确认。已接收的图片和视频任务在离开后继续执行。文本流式生成中的站内离开需要明确选择停止或等待，停止请求失败时保留会话并反馈。关闭或刷新受浏览器原生离开提示和流连接断开机制约束。

## 验收

使用[前端测试入口](../../../front/tests/README.md#统一检查与浏览器入口)中的 `lab-ui` 验证会话、配置、媒体、提交恢复及离开保护。结合 `home-project-layout` 和 `management-ui` 检查共享壳、主题偏好及两个独立画布的外观。常规矩阵包含两种雾蓝外观、1440×900、1366×768、1024×440、375×812，以及 1024px 和 768px 断点两侧。

通过真实页面操作和隔离 HTTP／SSE 响应检查可见结果及请求。布局检查同时核对滚动、可达性、键盘焦点与截图，浮层关闭按顶层优先。缩小浏览器视口只能验证可用高度变化，实体软键盘与实体输入法需要单独验证。隔离夹具应与真实业务数据区分，未知字段保留未知，产品示例明确标识。供应商真实响应、生成质量及部署状态分别验收。
