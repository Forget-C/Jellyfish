# 管理页面前端规范

适用于模型管理（供应商、模型、运行设置）、资产库、提示词模板、文件管理和 Agent 管理。管理页面继承[首页与项目列表前端规范的通用规则](home-project-ui.md#通用规则)。页面可正常纵向滚动，列表按各自任务选择表格、卡片或双栏。资产库独立档案使用下述详情规范；项目角色及场次档案复用同一对象详情内容，Agent 编辑页与两个画布各自沿用原布局。路由、主题与滚动机制见[前端基础布局](../architecture/frontend-layout.md)。

## 导航、层级与滚动

- 共用普通应用壳的两种雾蓝外观，并沿用[通用尺寸](home-project-ui.md#尺寸间距与字体)中的顶栏、Logo 与品牌文字规则。
- 桌面管理侧栏 216px，菜单高 40px、字号 14px，以浅色背景标记当前入口。小于 1024px 时使用管理导航抽屉，关闭后将焦点还给入口。进入管理优先恢复该浏览器记录的二级根页面，首次默认模型管理。
- 标题为 16px／600，计数为 13px 次级色。模型与资产的业务页签使用轻底色选中态，空间允许时与标题同排。搜索、常用筛选、刷新在左，主创建动作在右。排序、批量管理等次级入口按需打开。桌面工具栏基准 52–56px，搜索约 240px，控件 32px。小于 1024px 允许换行，控件 36px。
- 内容左右留白桌面 20px、手机 16px，区域间距 20px、区域内 12–16px、控件间距 8px。主要动作使用强调蓝实底，白色内容表面圆角 12px。以留白、对齐和浅底色划分区域，表单边界、错误及键盘焦点清晰可见。
- 使用 `WorkspaceLayout`、`PageToolbar` 和 `WorkspaceScrollPanel` 建立内容高度链。顶栏和主要工具栏保持可达，列表或正文负责纵向滚动，宽表格及 JSON 正文仅在自身容器横向滚动。卡片按实际内容宽度减列，手机单列；文件管理使用[媒体文件专属断点](media-files-ui.md#共用布局与视觉)。抽屉和弹窗限制在视口内，保留清楚的关闭操作。

## 各页面的内容与操作

| 页面 | 展示和入口 |
| --- | --- |
| 供应商 | 单一表格比较名称、地址摘要、凭据配置状态和状态。名称打开只读详情，编辑保留原弹窗。凭据配置字段缺失时显示“未知”，读取真实凭据仅限既有编辑流程。 |
| 模型 | 单一表格比较名称、类别、供应商、默认标记及简述。名称打开只读详情，完整参数及创建信息在详情中呈现。工具栏保留默认模型与筛选入口。 |
| 运行设置 | 左对齐表单最大宽度约 640px，纵向排列字段。标签 13px，控件 36px，字段间距 16px。默认模型说明指向模型页签。显式保存，失败保留输入。 |
| 资产库 | 保留演员、场景、道具、服装分类及 `tab` 参数。卡片使用160px封面，下方固定三行信息：名称与进入箭头及右侧更多、来源标签与创建日期、两行截断简介。简介缺失显示“未填写简介”并保留相同高度；日期按本地时区展示，缺失时显示“日期未提供”。场所封面填充，其余完整比例展示，少量卡片不拉伸为横幅。图片开启按需多视角预览，名称进入原资产详情页，图片生成统一在详情中操作，卡片不提供生成按钮或第四行操作区；“更多”位于名称右侧，删除经确认。 |
| 提示词模板 | 搜索名称或简介。普通浏览读取当前页，显式搜索才逐页核对名称和简介并给出实际匹配总数。桌面左栏约 300px，用于选择分类和模板。右侧依次阅读名称与属性、简介、正文、变量及默认值。两侧各自滚动。小于 1024px 时选择模板打开阅读抽屉，关闭恢复列表位置和焦点。编辑、默认和系统预置保护沿用既有规则。 |
| 文件管理 | 遵循[媒体文件展示规范](media-files-ui.md)：仅内容区滚动，六列响应式虚拟网格，每批24条；普通浏览追加，名称／标签筛选采用每轮最多96条的渐进检索。卡面固定名称、类型、时间与标签；筛选、刷新、批量选择及预览恢复按该规范执行。 |
| Agent 管理 | 单一表格比较名称、类型、默认标记、单行简介和更新时间。类型筛选只出现一次，名称直接进入原编辑页，保留测试和有效的管理操作。 |

供应商和模型的测试入口当前标记为“暂未接入”。文件管理的批量标记和批量导出当前标记为“暂未接入”。示例模式明确标注示例数据，不将其作为真实读取失败的兜底。Agent 的复制和导出尚未接入。Agent 管理依赖现有兼容接口，部署未提供该接口时显示读取失败与重试入口。未接通的操作保持禁用或不提供入口，并以明确文案呈现已显示的能力限制。

## 资产库独立详情

演员、角色、场景、道具和服装的新建与详情共用编辑内容，新建使用抽屉，已有对象详情使用页面正文，业务与保存边界遵循 [ADR 0007](../adr/0007-project-resource-ownership-and-library-copies.md)及[图片来源与独立导入决策](../adr/0008-image-source-resources-and-project-imports.md)。

- 新建时，面板与已有详情的完整内容区域对齐，包含标题工具栏及正文，上、右、下贴边，取消外侧留白及圆角；替代来源工具栏。顶部菜单和侧栏支持鼠标与键盘操作，无全局遮罩及焦点锁定，覆盖的来源内容不可交互，点击外部不关闭；导航离开和关闭经过未保存保护，切换外观及打开全局工具保留输入。抽屉实时跟随页面的雾蓝渐变或纯色背景，完全不透明且不使用背景模糊；整张视口渐变定位与页面连续，标题、正文和底部共用背景。左侧存在相邻区域时保留上下渐隐的柔和阴影，移除顶部及整圈投影，否则取消外侧阴影。顶部沿用详情页工具栏，左侧返回和标题、右侧生成设置及创建操作，取消底栏和右上关闭图标；标题16px／600，滚动时按需显示轻分隔。正文最大880px靠左，沿用详情页边距及白色内容分区；窄屏操作在标题下换行并保持可见。子页面左上返回优先回到对象表单，未应用修改沿用取消规则。窄屏贴合实际可用内容容器，保留顶部及必要的局部导航入口，内容单独滚动，不能横向溢出。名称、关键识别属性和补充信息常驻；详细设定、风格、参考按需展开并展示摘要，生成设置从顶部操作打开并替换正文。无图片时不展示独立图片栏目。仅创建成功关闭并刷新来源列表；创建并生成保留面板显示进度和结果，可关闭且已受理任务继续执行，并提供完整详情入口。
- 详情在页面正文展示，标题栏提供返回与保存、生成操作，返回恢复来源列表状态。桌面左侧设定与参考、右侧图片；手机以设定／参考／图片页签切换。沿用雾蓝、Ant Design控件、字段字号和焦点约定；参考选择与生成设置替换当前编辑器正文，不叠加选择弹窗。
- 图片按正面、侧面（左侧）、俯视、背面分组，可多图。主图明确标记，可从任意角度选择；生成只追加，不覆盖主图。局部修改继承源图视角，成功后直接在该文件夹新增图片，原图保留。
- 生成设置附加要求可见、展示设置折叠；预览只读并自动更新，显示默认模型。应用仅限本次打开对象，取消恢复已应用设置，关闭重置。未选角度默认正面，逐角度显示任务和失败重试。
- 对象未保存时可浏览参考与历史，生成先保存；更换主图须先保存设定。明确不生成时，可确认复制一张主体图为主图，或仅创建不采用。
- 未保存离开提供保存／放弃／继续编辑，默认焦点及Esc回继续编辑。提交期间等待完成；检测取消等待终态、失败可重试；浏览器关闭刷新使用原生保护。图片任务受理后允许关闭继续执行。
- 读取对象、图片、预览、候选和保存分别反馈失败，输入保留且可重试。对象保存成功而场次关联失败须明确区分，不能提示整体未保存或重复创建。
- 项目资源卡片沿用资产库的三行信息：名称与菜单、来源标签与创建日期、固定两行截断简介；空简介仍预留40px。卡片不提供“进入资产库”或“查看库中资产”入口，入库从详情进行，入库前预览名称与成员图片。项目只使用独立副本，菜单提供编辑及删除项目对象，不提供共享编辑、外跳编辑或取消关联；转化演员默认锁定详情，图片生成及管理开放；添加或编辑详情需先确认图文不一致风险，首次保存成功后持续开放。

### 资产库分类资产详情

资产库已有演员、场景、道具和服装详情采用左右分区：左侧名称、结构化设定、补充信息及风格，右侧大图预览、底部横向多视角缩略图带与生成入口，左右宽度约55∶45。移除共享资产标签和左侧参考，保留转化只读状态；顶部保留返回及保存设定。首次优先主图，否则最新可用图片。本图生成记录固定保留两行区域；加载时显示动态骨架，无记录时显示“暂无生成记录”空状态并保留同等高度，不伪造记录或持续显示加载状态，切图不改变预览高度。缩略图仅切换预览，不写主图；新增图片不打断已有预览。“查看全部（图片总数）”固定在缩略图横列右侧，缩略图独立滚动；窄屏保持入口可见，无图隐藏。大图及查看全部打开按视角分类的图片集合并定位当前预览视角，主图、视角默认图与局部修改在集合中操作，移除逐图候选入口。主图变更成功后预览跟随新主图；候选采用追加新图片。五官、发型整行多行显示，补充信息在高屏适度增高。

当前预览图片有来源记录时展示生成时间、当时模型、视角及参考数量，可展开已保存参数与提示词；缺失字段不显示，读取失败可重试，切图丢弃旧响应。

常规桌面铺满内容区，正文无滚动；长字段可展开完整编辑，智能检测结果在独立弹窗中查看。宽度小于1200px或高度小于740px时使用设定／图片页签并允许正文滚动。生成Modal配置参考、角度、附加要求、展示设置与图片模型，默认选中系统默认图片模型；展示设置桌面两列、窄屏单列，提示词只读预览。取消不发起生成且保留配置；同一详情会话内复用，离开、切换对象或刷新清空，不写入资产档案。生成先保存未保存设定，模型或提交失败保留输入；受理后回到详情展示视角任务状态，已受理任务不重复提交。新建及场次内嵌编辑沿用原布局。项目资源五类已有详情和角色独立详情路由复用该布局；角色左侧仅名称、角色设定与风格，设定可展开，不套用演员外观字段或检测入口。项目工具栏保留返回、保存和适用的入库操作，归属及只读状态位于名称右侧。旧共享关联须先维护转为独立副本；项目详情拒绝不属于当前项目的对象，提示先导入独立副本；角色转化演员的详情与图片权限独立。项目详情按容器宽度小于960px或正文可用高度小于600px切换设定／图片页签，避免项目导航占用高度导致裁切。角色生成保留主体、服装和道具参考，选择在同一Modal内切换；配置按项目、类别和对象隔离。项目已有详情不提供直接采用参考图片入口，返回恢复列表分页、滚动与焦点。场景的空间布局、环境特征整行，主要材质与色彩两列；道具的类型与尺度两列、外形结构整行、材质与颜色两列；服装的类型、款式层次、纹样与附属配饰整行、材质与颜色两列。三类新版详情不提供直接采用参考主体图片入口。

## 数据状态与危险操作

- 首次加载使用与内容相近的骨架，数量未知时显示“未知”或不报总数。读取成功且为空显示对象化提示。筛选无匹配提供清除入口。真实读取失败给出重试，刷新失败保留上一次结果与筛选条件。可靠的分页总数才写“共 N 项”，仅知道当前载入数量时写“已加载 N 项”。
- 删除确认指明对象和影响。执行期间禁止重复提交，失败保留可核对的对象和上下文。后端继续执行既有权限、关联和默认规则校验。示例数据独立标记，缺失字段与失败响应保留明确反馈。

## 验收

使用[前端测试说明](../../../front/tests/README.md)中的 `management-ui` 和 `home-project-layout` 浏览器套件。在两种雾蓝外观下检查 1440×900、1366×768、1024×768、375×812，补查 1024px 管理侧栏与 768px 顶栏的断点两侧。关注内容滚动、工具栏可达性、长文本和不同图片比例、加载与失败反馈、键盘操作及焦点恢复。浏览器用例使用隔离 HTTP 响应验证前端交互，生产供应商能力和后端链路另行验收。

文件管理与项目文件的共用布局、悬浮箭头、媒体释放和专项验收统一见[媒体文件展示规范](media-files-ui.md)。该规范分别记录基础验收与交叉核对补充项，不能将补充项视为已通过验证。

视角默认图与对象主图分别标记、独立设置。缩略图带优先各视角默认图（正面、侧面、俯视、背面，再列其他已有视角），各视角集合内默认图排首位，其余按新图优先。设置默认不切换当前预览；按钮提供完整视角名称、保存反馈与失败重试，只读资产仅显示标记。存在未保存设定时先保存再调整图片选择。

### 创建方式与图片来源

资产库新建按钮打开“填写设定／上传图片”，项目五类打开“填写设定／从资产库导入”。选择器为按钮旁的 Popover，无遮罩、关闭图标或确认按钮；点击外部或 Escape 收起，键盘可到达操作卡，关闭恢复合理焦点。桌面两列、手机一列。选择本身不落库；上传或导入仍使用共用新建抽屉，明确提交后创建，保留草稿保护、上传重试、失败输入及请求身份。

四类资产库上传采用最大600px宽的右侧抽屉，窄屏贴合内容容器；填写设定的新建沿用原抽屉边界。上传表单按名称、图片区及文件列表紧凑排列，Dragger 区固定168px高，支持点击、键盘选择及拖放多图，使用标准图片文件列表展示缩略图和上传状态，补充逐图视角、主图标记、失败重试及移除；多图列表在抽屉正文内滚动，不撑大拖拽区。逐图选择正面、侧面、俯视、背面，列表首张为主图；失败项须重试或移除，至少有一张有效图，名称及图片未准备完成时禁用创建。

项目五类从资产库导入采用最大720px宽的右侧抽屉，窄屏贴合内容容器。用封面图片卡片选择来源，移除文本下拉；支持按名称或描述搜索及分页，桌面三列、手机两列。选中状态同时用边框和图标标示，支持键盘选择。导入选择同类库中来源，角色从演员导入；选择后显示副本名称和全部有效成员图片，可放大查看，仍按来源整体复制全部有效图片。搜索与翻页不清除已选来源及手动填写的副本名称。来源列表与成员图片各自展示加载、错误及重试；无匹配项展示空状态，无有效图或成员未就绪时禁用导入。项目旧“从资产库关联”新操作入口移除，旧共享关系须先转换为独立项目副本，不再提供共享浏览或取消关联流程。

图片来源详情继续左右分栏，未开放详情时基础字段以禁用控件展示“未提供”，不显示智能检测和字段编辑按钮。标题名称右侧显示上传、项目转化、资产库导入的来源标签，设定创建对象不显示来源标签，归属标记独立保留。图像生成、局部修改和默认图操作正常开放。生成弹窗为图片来源对象增加临时风格，默认参考当前主图；没有主体参考时明确提示并禁用生成。资产库上传的演员、场景、道具、服装与角色来源演员使用下述详情开放规则；其他图片来源对象仍只允许修改名称。

上传对象与角色转化演员复用各自普通字段布局，名称与风格一并锁定，已有值展示、缺失显示未提供，长内容可只读展开。来源标签放在顶部名称右侧；上传标签保留“上传”，角色转化标签在锁定时显示“从角色转化 · 详情只读”，保存开放后显示“从角色转化”。首次确认开放但尚未保存时提示先保存详情，之后才能进入生成或局部修改，保证预览与实际生成一致。图片侧保留生成、局部修改、主图和视角默认操作。锁定详情不参与生成，生成配置使用有效主体参考及临时风格；开放详情后使用对应类别的普通档案规则。空详情显示“添加详情”，已有详情显示“编辑详情”，确认图文不一致风险后进入编辑；首次保存成功才持久化开放，放弃未保存编辑恢复只读，后续不再重复确认。

演员详情的智能检测入口直接提交文字设定检测，运行时显示状态并允许取消，完成后点击查看结果，不自动弹窗。失败需在页面可见并可进入错误详情重试；结果不自动覆盖字段，输入变化后禁止采用过期建议。检测不核对图文一致性。其他资产类别沿用原检测入口。
