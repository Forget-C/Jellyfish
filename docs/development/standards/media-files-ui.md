# 媒体文件展示规范

## 适用范围与状态

本文统一项目－文件与管理－文件管理的内容区布局、媒体卡片、滚动分页、检索和预览规则，作为后续前端开发与验收依据。“管理－资源”在本规范中指文件管理，不包括角色、场景、道具等业务资产档案，也不直接约束画布和实验室消息中的媒体。

通用配色、应用壳和主题偏好继承[首页与项目列表前端规范](home-project-ui.md#通用规则)；页面导航分别遵循[项目内部页规范](project-internal-ui.md)和[管理页面规范](management-ui.md)。本文为两处媒体文件展示规则的统一来源，页面文档保留入口与必要摘要。

正文整理已确认规则并修正交叉核对发现的表述歧义；文末的补充验收项单独标明验证边界，不表示已经全面实现、测试通过或部署。本文不要求替换虚拟化库；Ant Design 替换仅经过方案评估，尚未确定实施。

## 共用布局与视觉

- 使用固定工具栏、独立滚动内容区和悬浮滚动引导。复用 `WorkspaceLayout`、`PageToolbar`、`WorkspaceScrollPanel`，高度链见[前端基础布局](../architecture/frontend-layout.md#路由内容与滚动)。
- 顶栏、侧栏和主要工具栏不随文件列表滚动，仅媒体内容区纵向滚动；`body` 不承担滚动，不出现嵌套纵向滚动条或全页横向滚动。
- 内容区使用剩余可用高度与完整宽度。左右留白桌面20px、手机16px，不重复叠加页面padding，不为箭头预留侧槽或底部空区。
- 网格间距16px。少量文件保留正常列宽和自然留白，不拉伸卡片、不填充虚假文件。底部加载状态属于内容流。
- 沿用雾蓝微渐变／雾蓝纯色、白色卡片和轻底色，通过留白与对齐分区，不添加装饰性边框或重阴影；输入边界、选中态与键盘焦点仍须清楚。

以下断点按视口宽度计算，是两个现有页面的适配规则：

| 视口宽度 | 每行卡片数 |
| --- | --- |
| ≥1280px | 6 |
| 1024–1279px | 4 |
| 768–1023px | 3 |
| 480–767px | 2 |
| <480px | 1 |

| 元素 | 规则 |
| --- | --- |
| 页面标题 | 16px／600 |
| 工具栏控件 | 桌面32px，窄屏36px，可换行；切换阈值沿用所属页面规范 |
| 卡片圆角 | 12px |
| 封面区域 | 高160px，加载前后保持尺寸稳定 |
| 文件名称 | 14px／600，单行省略，完整名称仍可获取 |
| 辅助信息 | 12px、次级文字色 |
| 操作 | 紧凑图标或轻量文字按钮，具备提示、可访问名称和可见焦点 |

同一网格使用稳定、等高的卡片结构。项目文件当前高度254px，管理文件270px；这些是两个页面的适配参数，不是所有媒体列表的固定高度。字段或尺寸调整须同步虚拟化测量，不通过缩小文字或裁切操作维持等高。

## 页面专属内容

| 页面 | 工具栏与数据范围 | 卡片固定信息 |
| --- | --- | --- |
| 项目－文件 | 单条紧凑工具栏，标题旁为章节筛选；列表限定当前项目及所选章节 | 封面；名称与紧凑下载图标；类型。下载不独占一行 |
| 管理－文件管理 | 名称／标签搜索、标签筛选及刷新；读取文件管理列表 | 封面；名称；类型与时间；标签。详情区内边距12px、信息间距6px |

管理文件标签最多显示两个，超出显示 `+N`，无标签使用低强调占位。时间缺失显示“时间未知”，名称缺失显示“未命名文件”，未知类型明确表达，不伪造字段。文件卡片不套用业务资产卡片的简介、生成或关联操作。

视频优先真实缩略图，无缩略图显示类型占位入口，不能把视频文件地址当图片加载；音频使用相应类型占位。缩略图加载失败与原文件不可预览必须区分：前者保留占位，有有效原文件入口时允许尝试预览；原文件失败在预览层明确反馈，不展示空白成功状态。无有效媒体地址时不提供无效入口。

## 分页追加与渐进检索

### 普通浏览

- 接口分页读取、前端连续追加，取消可见页码分页器，每批24条原始记录。
- 距内容底部约一屏时预加载。首屏不足或底部触发区仍在预加载范围内时继续读取，直到触发区离开该范围或数据耗尽；不是刚出现滚动条就必然停止。
- 同一筛选仅一个分页请求在途，结果按文件ID去重。追加保留当前阅读位置与选择，不自动跳到新增内容。
- 保留手动“加载更多”入口，不能只依赖滚动触发。加载中、追加失败重试和全部加载状态在内容末尾明确表达。
- 追加失败保留已有内容并暂停自动请求；重试失败页。首次读取失败与成功为空分别展示，失败有恢复入口。
- 只报告可靠数量。普通浏览展示已加载数及可获得的总数，不将已加载数冒充总数。

### 管理页筛选检索

项目章节筛选继续按接口条件分页；管理页名称／标签检索采用有限批次扫描，不能套用普通浏览的持续自动追加：

- 搜索匹配文件名称或标签；选定标签与搜索条件共同生效。
- 每轮最多检查4页／96条原始记录；本轮找到至少24条匹配、达到检查上限或数据耗尽时暂停。按整页处理，匹配数可能超过24条。
- 普通检索逐页展示结果，用户点击“继续检索”才开始下一轮；滚动不自动越过检索预算。
- 未完成显示“已找到／已检查”，当前范围无匹配不等于全库无匹配。只有完整扫描后才能显示匹配总数或“无匹配文件”。
- 标签选项来自已读取文件，标注“已发现标签”，不声称是全库标签全集。
- 中途失败保留结果，从失败页重试。刷新采用下述原子替换规则，不以逐页刷新破坏旧结果。

## 筛选、刷新与批量选择

- 切换筛选取消旧列表请求，清空结果与选择、退出批量模式并回到顶部；旧条件迟到响应不能污染新列表。
- 管理页刷新保留条件，准备好首轮结果后整体替换；成功重置位置和选择，失败保留旧结果、选择和继续读取位置，并提供重试。
- 默认浏览无复选框。显式进入批量模式后显示复选框、选中数量和批量操作；退出清空选择。
- “选择已加载文件”只作用于操作时已加载的匹配内容，后续新增文件不自动选中。预览不改变选择。
- 无选中项时禁用批量执行。项目页单项和批量下载使用真实下载路径，不以提示消息模拟成功，也不声称已获知外部下载完成。
- 管理页批量标记和批量导出未接入时保持禁用并注明“暂未接入”。示例数据独立标识，不能用来掩盖真实接口失败。

## 虚拟化与媒体生命周期

分页追加控制接口批次，缩略图懒加载减少提前读取，按行虚拟化限制挂载规模，三者不能互相替代。

- 仅挂载视口附近及缓冲行；聚焦卡片和预览源卡片保留，以便操作恢复。键盘应能继续访问未挂载区间中的文件。
- 卡面优先缩略图，原图用于完整预览和下载；列表不批量创建视频、音频播放器或自动播放。
- 统一预览支持键盘激活、Esc关闭。关闭后停止播放、销毁媒体内容，恢复阅读位置与触发入口焦点，不丢失已加载文件和选择。
- 筛选切换及离开页面取消列表请求，并隔离旧响应。
- 已加载元信息和选中ID可以保留，不承诺内存固定上限。节点卸载、网络请求结束和浏览器图片缓存释放是不同过程，不能将懒加载等同于资源已释放。

## 悬浮滚动引导

箭头表达“下方仍有内容可浏览”，不表示一定还有未请求的分页。全部数据已加载但下方仍有内容时，可以继续显示。

| 项目 | 规则 |
| --- | --- |
| 位置 | 内容区右下角，右、下各20px，完全悬浮，不占网格空间 |
| 图形 | 两段短横、实心箭身和向下三角；SVG 24×36px |
| 点击区域 | 透明44×44px，无底座与边框 |
| 颜色 | 半透明浅蓝、轻微阴影，悬停加深 |
| 点击行为 | 向下滚动约四分之三屏，不直接绕过分页或检索规则 |
| 呼吸动效 | 每个筛选首次出现时两次，每次1.8秒；滚动或点击即结束 |
| 减少动态效果 | 静态显示，使用即时滚动 |

滚动中隐藏，停止800ms后重新判断。加载、失败、预览、空列表、不足一屏或距底不足80px时隐藏。点击区域与下载、选择等操作重叠时隐藏，不上移避让；允许覆盖普通封面和静态信息。

普通滚动过程中不突然移除已获键盘焦点的箭头；该例外不能覆盖弹窗焦点管理。打开预览时焦点进入弹窗、背景箭头不可交互；页面或筛选重置需保留合理焦点去向。相关优先级列入下述补充验收，不因存在焦点状态代码就视为通过。

## 验收与补充检查

### 基础验收

- 两种雾蓝主题覆盖1440×900、1366×768、1024×440、375px宽及实际断点两侧，检查列数、长名称、少量文件、工具栏可达性和单一内容滚动。
- 覆盖首屏补齐、连续追加、手动加载、追加失败重试、末尾停止、筛选快速切换及迟到响应。
- 管理页覆盖96条预算、继续检索、未完成计数、标签来源与刷新失败保护。
- 检查批量进入／退出、选择已加载快照、追加不自动勾选、真实下载目标与禁用操作。
- 使用有效音视频验证预览播放、失败反馈、关闭释放、滚动和焦点恢复；箭头不挤占网格且不阻挡关键操作。
- 用240／1,200／5,000条隔离数据及代表性图片记录挂载规模、内存趋势和滚动帧间隔，区分元信息、图片缓存与进程内存，不能仅凭采用虚拟列表宣布性能合格。

执行入口及隔离测试边界见[前端测试说明](../../../front/tests/README.md)。前端隔离验证与真实存储服务性能分别验收，不能互相替代。

### 交叉核对补充项

以下为补充验收目标或建议，不表示现有页面已全部满足。本次文档整理不包含前端修复或新的浏览器验收，后续涉及相应能力时须逐项验证：

| 检查项 | 验收目标与边界 |
| --- | --- |
| 加载反馈 | 首次加载有明确反馈；追加只更新末尾状态，不整页替换已有卡片，不抢焦点。完成、失败、检索暂停可被辅助技术感知，不逐卡片重复播报 |
| 跨断点阅读 | 六列变四列等重排后，尽量保持原阅读文件在附近；预览期间变更断点，关闭后优先定位源文件，不仅恢复旧像素值 |
| 键盘连续性 | 跨虚拟化边界保持合理焦点顺序，不丢焦点、不困住用户；验证箭头聚焦、弹窗打开和筛选重置的优先级 |
| 触控区域 | 小屏独立下载、选择等图标建议通过透明内边距扩展至约44×44px，不放大桌面工具栏，不重叠、不拦截封面预览；这是补充建议，不是已经全面实现的规则 |
| 完整信息 | 完整名称和标签不能只靠鼠标悬停获取，须核查键盘与触屏路径 |
| 箭头辨识度 | 在白色、浅色及复杂图片背景上检查；呼吸最低透明度仍可辨，焦点轮廓稳定。未经实际检查不宣称对比度合格；正常滚动和手动加载独立可用 |
