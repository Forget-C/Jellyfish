# 首页与项目列表前端规范

普通列表的内容宽度统一遵循[两种内容区布局规则](../architecture/frontend-layout.md#普通列表内容区宽度)，额外占位由局部容器处理，同一窗口下卡片等宽，不随内容或数量变化。

## 适用范围与使用方式

本文将已确认并落地的首页（`/`）、项目列表（`/projects`）布局、视觉与交互规则作为后续开发和验收依据。以项目卡片四行布局、场次数与章节数同排的最终方案为准，不再沿用早期原型的独立底部按钮、大标题、右侧项目速览或多视图切换。

“通用规则”适用于这两个页面及普通应用壳内后续采用同一视觉体系的页面；“页面专属规则”只约束相应页面，不能直接套用为全站组件默认值。生成画布编辑器、场次画布保留各自的主题与布局；其验收遵循[工作台前端设计标准](workbench-design.md)。本文不要求改造其他既有页面。

本规范记录已确认行为，不表示生产部署状态。接口不足的展示继续使用明确标注的本地示例，不为视觉调整扩展后端或表结构。路由、布局组件及主题实现机制见[前端基础布局](../architecture/frontend-layout.md)，开发与检查要求见[开发规范](development.md)。

## 通用规则

### 应用壳与视觉层级

- 顶部左侧保留产品 Logo，中央依次为首页、画布、项目、管理、实验室，右侧保留任务和用户入口。Logo 返回首页；“项目”返回项目列表。
- 首页和项目列表不设固定左栏；具体项目、管理、实验室使用各自二级导航。
- 使用留白、对齐、白色内容表面和轻底色区分内容，避免用结构性边框线、重阴影分割页面。输入框边界、错误提示和键盘焦点仍须可辨识。
- 标题只说明当前内容，不增加大字号宣传式标题或重复引导文案。局部控件不能比一级导航更抢眼。
- 主动作使用实心强调蓝；导航、筛选的选中态使用浅底色。普通信息卡不做成指标看板，不重复展示时间、进度说明和同义入口。
- 复用 React、Ant Design 和既有布局组件。样式限定在应用壳或页面作用域，不能覆盖独立画布及其浮层。

### 配色与主题

| 用途 | 固定值或规则 |
| --- | --- |
| 默认背景 | 雾蓝微渐变：`linear-gradient(125deg, #F0F5FC, #F7F8FB)` |
| 可选背景 | 雾蓝纯色：`#F7F8FB` |
| 内容表面 | `#FFFFFF` |
| 主文字 | `--app-text: #263244` |
| 次级文字 | `--app-muted: #536174` |
| 链接、主动作、焦点 | `--app-accent: #245FC5` |
| 选中底色 | `--app-selected: #E4EDFB` |
| 状态 | 浅底色配可读文字；颜色不能单独承载含义 |

用户菜单“外观”和个人设置使用同一个偏好。选择立即生效，与个人资料保存独立；在当前浏览器本地保存，刷新及重新打开后恢复。无有效记录时使用默认微渐变；存储不可用时仍允许当前页面切换。普通页面偏好不改变独立画布主题，不承诺账号跨设备同步。

### 尺寸、间距与字体

以下单位均为 CSS px；页面专属参数优先于通用参考值。

| 元素 | 桌面基准 | 窄屏规则 |
| --- | --- | --- |
| 顶栏 | 高 56 | ≤767 时为 56 + 44 两行，一级菜单仍全部可见 |
| Logo / 品牌文字 | 32×32；20 / 700，行高 28，图文间距 8 | ≤767 品牌文字 18 / 700，Logo 与行高不变 |
| 一级菜单 | 字号 14、字重 600；点击区高 40；间距 8、圆角 8 | ≤767 点击区高 36 |
| 页面左右留白 | 20 | ≤767 为 16 |
| 主要网格间距 | 20 | 常见窄屏网格为 12，具体见页面规则 |
| 内容卡片圆角 | 12 | 保持一致 |
| 图标底座、紧凑控制圆角 | 8 | 保持一致 |
| 标签圆角 | 4 | 保持一致 |
| 区块标题 | 16 / 650，行高 1.4 | 不额外放大 |
| 普通条目标题 | 14 / 650 | 单行截断时保留完整名称可访问性 |
| 轻量操作、项目卡信息 | 13 | 不能依靠放大字号突出次要控件 |
| 时间、摘要、类型等辅助信息 | 12 | 不继续缩小以强行塞入内容 |

普通壳其他路由现有页标题为 20；这不是首页或项目列表应新增大标题的理由：首页视觉隐藏 H1，项目列表标题为 16 / 600。内容密度通过行距、封面高度和分组调整，不通过隐藏必要状态、压小字体或强行占满空白解决。

顶栏与浏览器页签共用 [前端 Logo](../../../front/logo.svg)，保留水母轮廓及青紫粉渐变，不另外维护简化副本。浅色背景的小尺寸版本使用 `#0891B2 → #7C3AED → #BE185D`；在 200×200 viewBox 内，外轮廓描边为 9、触须为 7，主轮廓不透明，移除发光、内部细线和装饰圆点，避免缩小后的模糊与杂点。品牌文字保持主文字色，不使用渐变；图文垂直居中、不换行，不增加上下内边距或顶栏高度。验收检查两种背景下的清晰度、一级菜单居中，以及手机品牌与任务／用户入口互不遮挡。

### 滚动、交互与数据状态

- `body` 不承担页面滚动。普通页面由路由内容区滚动；自行分配滚动职责的页面须建立明确高度链，可收缩容器保留 `min-height: 0`、`min-width: 0`。
- 不用 `overflow: hidden` 掩盖超出可用高度的正文或操作。横向内容确需滚动时由局部容器显式处理，不能让全页横向滚动。
- 图标按钮必须有可访问名称；装饰图标不重复朗读。链接使用真实链接，保留键盘操作与可见焦点，默认焦点描边为 2px 强调蓝。
- 悬停、选中、加载、禁用、错误不能只有颜色变化。长名称截断后仍可获取全文，不允许挤走必要操作。
- 区分加载中、成功为空、字段未知、读取失败。失败提供恢复入口，不能把失败或未知转换为零数量或“未创建”。
- 优先真实数据。示例必须标注“示例数据”或“示例资产”，不伪造业务跳转，不用示例覆盖真实数据读取失败。

## 首页专属规则

### 内容结构与高度分配

顺序固定为最近画布、项目进展与最近实验室会话、最近资产。保留语义 H1，但不显示独立的“工作概览”大标题行。

桌面起点为 1024px：顶栏下使用可用高度，首页不出现整体纵向滚动；优先保留项目与会话及其继续入口。窗口变矮时压缩封面、区块间距，列表按需内部滚动，标题和底部入口保持可达。小于 1024px 时按页面顺序自然纵向滚动，不强制塞入一屏。

### 最近画布

- 合并生成画布和仍有有效场次归属的场次画布，按画布文档更新时间展示最多三张。生成画布副标题显示「独立画布」，场次画布显示所属项目。卡片用于展示，封面缺失或加载失败时显示占位。
- 桌面三列比例 `1.3 : 1 : 1`，间距 20；768–1023 为三等列，480–767 为两列，≤479 为一列。
- 桌面封面高 `clamp(48px, calc(29dvh - 151px), 142px)`；480–767 为 112，≤479 为 130。
- 卡片标题 14 / 650，说明 12；正文默认内边距 16，桌面上下内边距随窗口高度在 8–16 调整。

### 项目进展与最近实验室会话

| 项目 | 规则 |
| --- | --- |
| 桌面布局 | 两栏等宽等高，比例 1:1，间距 20，标题与底部入口对齐 |
| 展示条数 | 每栏最多三条真实记录，不为凑满添加伪记录 |
| 窄屏 | <1024 改为上下排列 |
| 白色面板 | 圆角 12，内边距 6px 12px |
| 列表条目 | 最小高度 58，条目间距 4；图标底座 34×34、圆角 8 |
| 信息层级 | 标题 14 / 650；章节、摘要、时间 12；轻操作 13 |
| 项目进展操作 | 可保留当前章节对应的继续动作，靠行尾；不等同于项目列表卡片的统一入口 |
| 实验室操作 | 会话整行进入对应会话；底部提供文本、图片、视频草稿及实验室入口 |

不恢复独立“快捷开始”大区块。实验快捷入口合并到会话面板底部，防止额外占高。加载、空数据和失败使用同一视觉层级，失败有重试；展示支持不足时的示例必须独立标注。

### 最近资产

- 按资产档案更新时间合并展示资产库中的演员、场景、道具和服装，最多六项。图片变动只有在更新档案时间时才影响排序。
- 标题行提供「查看资产库」入口。点击卡片打开预览。最近画布与最近资产独立显示加载、空数据和失败状态，各自支持重试。
- ≥1400 单排六张；1024–1399 单排四张；桌面高度 <700 时隐藏内联卡片，改为抽屉入口，抽屉可查看全部返回记录。
- <1024 展示全部返回记录，默认两列；<400 一列。网格间距 12。
- 桌面图片高 `clamp(88px, calc(13dvh - 10px), 120px)`，窄屏高 112；卡片圆角 12，名称 14 / 650，类型和时间 12。
- 场景缩略图使用 `cover`，角色、道具和服饰使用 `contain`；预览完整展示图片。无图或图片加载失败显示类型图标与“暂无预览”，不能出现破图或布局跳动。
- 预览显示于资产抽屉之上，关闭后恢复触发焦点；卡片可访问名称包含名称，并关联类型、时间及必要的无图说明。

## 项目列表专属规则

### 紧凑工具栏

只保留卡片网格，不恢复列表／多视图切换。标题与项目数量、搜索、制作阶段筛选、排序与批量入口组成左侧操作组；新建项目在右侧。搜索不独立居中。排序与批量操作放入次级入口，不与新建争夺主操作层级。

| 参数 | 桌面 ≥1024 | <1024 |
| --- | --- | --- |
| 工具栏 | 最小高 52，上下内边距 10，水平使用页面留白，组间距 8 | 允许换行，标题和新建在上，搜索筛选在下 |
| 标题 / 数量 | 16 / 600；数量 13、次级色 | 保持层级 |
| 搜索、筛选、按钮 | 高 32，字号 13 | 高 36，按可用宽度换行 |
| 搜索宽度 | 最大 240 | 可收缩，最大 240 |
| 阶段筛选 | 宽 120 | 最小宽 112 |
| 新建项目 | 实心 `#245FC5`，白字；悬停 `#1D50AA` | 保持主动作，不能挤出屏幕 |

排序和筛选选中态使用轻底色。窄屏的 DOM／Tab 顺序与视觉顺序一致。工具栏尺寸是项目列表的覆盖值，不把共享 `PageToolbar` 的默认高度改成 52。

### 网格与封面

- 网格按共享对象卡片列数断点等分内容区，间距16px；少量卡片与末行保留空列，详见两种内容区布局规则。
- 卡片白底、圆角 12，无结构描边。封面桌面高 `clamp(128px, 9vw, 160px)`；<1024 宽高比 2:1，真实图片按 `cover` 展示。
- 无封面时使用雾蓝浅渐变、几何叠层及视频图标；按项目 ID 稳定选择三种近似构图，不随机闪换，不以默认封面冒充真实内容。示例图片明确标注。
- 封面仅展示，不能点击跳入章节、场次或配置。右上角删除控制 32×32、圆角 8，距上和右各 12。

### 项目分页

- 分页栏在列表右下方，末页只有一张卡片时仍保持同一位置。结果至多一页时隐藏控件并保留栏高。视口宽度达到 1024px 时显示上一页、页码和下一页；更窄时显示上一页、当前页／总页数和下一页。
- 按卡片区的实际可用高度计算完整行数，计入卡片高度、行间距，以及工具栏、分页栏和已展开的批量操作栏占用的空间。每页容量为实际列数乘以完整行数，并取接口 100 个上限内能排满的最大整行数。能放下 4 列 × 5 行时每页 20 个；六列且空间充足时最多 16 行、96 个。手机沿用同一规则。极矮窗口至少分配一行，可滚动查看该行。末页按剩余数量展示，允许不足一行。
- 服务端先按项目名称或描述搜索，再叠加制作阶段筛选，在全部匹配项目中按最近更新、名称或章节数量排序后分页。排序值相同的项目按项目 ID 稳定排序。待补原文包括没有章节的项目，以及至少一章原文为空或纯空白的项目，判断覆盖全部章节。标题使用服务端总数，未搜索且未筛选时显示「共 N 个项目」，否则显示「匹配 N 个项目」。
- 更改搜索、筛选或排序时回到第 1 页。从项目详情返回时恢复查询条件和页码，包括刷新详情后通过顶部「项目」返回。窗口尺寸稳定后，仅在容量变化时重新分页，定位到包含原页首项排序位置的新页。例如每页 12 个时，第 3 页从第 25 项开始；改为每页 20 个后显示第 2 页。删除造成当前页超出范围时回到新的最后一页。
- 批量操作限当前页。主动翻页或更改查询时清空勾选；容量变化时仅保留新页中仍可见的勾选，并更新已选数量。

### 固定四行信息与入口

卡片正文使用四行，每行 24，行间距 4，内边距 `12px 16px`。有无章节或场次都保留对应行，不因缺失数据缩减结构；移除底部按钮与独立操作行。

| 行 | 内容 | 样式与行为 |
| --- | --- | --- |
| 1 | 项目名 + 右箭头 | 16 / 650，行高 24；强调蓝，箭头 14；悬停下划线，键盘焦点可见 |
| 2 | 类型／风格；有依据的更新时间靠右 | 类型标签 12、浅底、圆角 4；时间 12，只出现一次，未知不编造 |
| 3 | 图标 + 代表章节 | 13，单行截断并提供全文；必要时同排显示重试 |
| 4 | 场次图标 + 本章数量；章节图标 + 总章数 | 13；两组同排、间距 10，图标与文字间距 6；缺原文时同排浅金“待补原文”标签 |

项目名是卡片进入项目的唯一入口，统一进入 `/projects/:id` 的项目概览，由用户进入后选择章节、场次等。不再根据阶段跳转不同制作页面；不让整张卡片、封面或计数变成另一个入口。

代表章节优先选择待补原文章节，否则为章序最前的章节。“本章 N 场”只统计这一个代表章节，“共 N 章”统计该项目全部章节；展示与章节数量排序使用相同统计口径。

| 数据状态 | 展示要求 |
| --- | --- |
| 类型缺失 | `未设置类型` |
| 确认没有章节 | `未创建章节`、`未创建场次`、`共 0 章` |
| 已有章节但场次为零 | `未创建场次`，保留总章节数 |
| 已有章节但计数字段未知 | 对应显示 `场次数未知` 或 `章节数未知` |
| 加载中 | `读取中`，保留四行结构，不先显示零 |
| 读取失败 | `读取失败`，章节行提供重试，不用“未创建”代替 |

重试期间不能重复发起请求，保留可聚焦的忙碌状态；再次失败仍可操作，成功后原重试按钮消失时妥善移回项目名焦点。长名称和长章节不能改变四行高度或覆盖其他信息。

删除入口使用图标及可访问名称，二次确认显示项目名并说明不可逆性。批量模式在同一位置用复选框，项目名暂停跳转，避免误入项目。卡片不恢复“详情”操作集合；配置位于项目设置，显式保存，失败保留输入，取消恢复已保存值。

## 独立画布列表

一级菜单「画布」的 `/canvases` 沿用项目列表的紧凑工具栏、等宽网格和 16px 卡片间距。桌面把标题、数量与名称搜索放在左侧，新建画布放在右侧；窄屏保留标题与新建同排，搜索换到下一行。

画布卡片使用白底圆角，封面贴边，缺图或加载失败时显示雾蓝默认封面。正文显示名称与箭头和更新时间。名称是进入编辑器的入口，封面只展示。右上角更多菜单提供重命名和删除，删除继续核对画布当前保存修订。

画布列表沿用[项目分页](#项目分页)的右下角位置、窄屏控件、整行容量、100 张接口上限、缩放定位和末页回退。服务端在全部独立画布中搜索名称，按最近更新排序后返回摘要与匹配总数。从编辑器返回时恢复进入时的搜索及页码。专项浏览器入口为 `PLAYWRIGHT_CHANNEL=chrome node front/tests/run-browser.mjs independent-canvas`，覆盖桌面整行、手机单列、跨页搜索、编辑器返回和删空末页。

## 开发与验收清单

### 视口检查

尺寸按浏览器 CSS 视口记录，不能以操作系统截图尺寸替代。

| 视口 | 必查结果 |
| --- | --- |
| 1366×768、1440×900、1920×1080 | 首页无整体纵向滚动；双栏等宽等高；标题和底部入口对齐；资产单排；项目卡四行对齐，工具栏层级明确 |
| 1024×440 | 首页仍保留可达的标题与继续入口；列表内部滚动；最近资产改抽屉，不靠裁切藏内容 |
| 375px 宽 | 顶栏两行；首页自然纵向滚动；项目单列、控件换行；操作可达，无整页横向滚动 |
| 断点两侧 | 检查 1024、1400 的布局切换；767/768、399/400、479/480 及桌面高度 699/700，避免边界漏档 |

### 状态与交互检查

- 检查普通数据、长项目名／章节名、零章节、零场次、未知计数、加载、失败及重试，不把未知与失败验成空状态。
- 检查项目名始终进入项目概览、封面没有跳转、删除确认、批量选择、搜索筛选排序和项目设置保存／取消。
- 分页检查覆盖右下角位置、4 列 × 5 行的 20 张容量、六列的 96 张上限和窄屏按可见行翻页。验证从第一页能搜到原排第 21 位的项目，且只有第 101 章缺原文的项目也能被筛出。验证刷新详情后返回、缩放后保留可见勾选、主动翻页清空勾选及删空末页回退。
- 检查首页项目继续动作、会话链接、三类实验草稿入口以及真实资产库入口。
- 检查默认封面稳定、资产无图／加载失败占位、示例标记、预览与抽屉层级及关闭后焦点恢复。
- 检查 Tab 顺序、Enter 激活、可见焦点、图标名称和长文本可访问性；不能只做截图比对。
- 检查两种主题即时切换、刷新恢复、存储失败回退；独立画布主题不受影响。
