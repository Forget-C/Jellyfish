# 工作台前端设计标准

适用于场次四画布及其工具栏、弹窗和任务抽屉，也适用于下文明确列出的生成画布界面。全站浅色页面与全站任务中心沿用各自的主题。新增或修改这些区域时，优先复用现有共享组件。现有工作区的部分动作仍使用 Ant Design 按钮，整场导出已共用弹窗和底部操作区，按钮覆盖与容器覆盖分别判断。确需例外时，在变更说明中写明原因、影响范围及验证方式。

## 开发顺序

1. 确定当前操作区域的主动作、次动作与状态。生成、应用、保存等业务含义由调用方决定。
2. 从下表选择已有组件；重复业务流程不因布局相似就合并。调整公共颜色或尺寸时修改 `ui/WorkbenchTheme.tsx`，用示例页检查全部状态。
3. 在真实页面接入，保留原有禁用条件、焦点、未保存输入和任务生命周期。
4. 执行本页的验证命令，检查桌面与窄屏截图。完成标准是状态、布局、交互与主题隔离均符合要求，而非仅颜色相近。

## 共享组件入口

目录：`front/src/pages/aiStudio/directing/`。

| 组件 | 用途与边界 |
| --- | --- |
| `ui/WorkbenchTheme` | 局部 AntD 暗色主题与语义 CSS 变量；主题同时覆盖 portal 弹窗及任务抽屉 |
| `ui/WorkbenchButton` | `primary`、`secondary`、`quiet`、`danger` 四种动作；透传 loading、disabled、事件及可访问属性 |
| `ui/WorkbenchIconButton` | 通用纯图标操作；必须提供 `label`，统一 tooltip、可访问名称与点击尺寸 |
| `ui/WorkbenchDetails` | 单个非事务性悬浮详情目标；常规／展开尺寸、窄屏焦点约束与关闭恢复，字段和保存由业务层负责 |
| `ui/WorkbenchModal` | 明确选择、预览、提交与一致性保护的操作容器；正文滚动、固定操作区，关闭保护由业务层提供 |
| `ui/WorkbenchDialogActions` | 左侧次动作、右侧当前主动作；正文滚动不带走操作区 |
| `CanvasTextPreview` | 单份正文按真实溢出折叠，默认六行，可指定四行；短文无切换入口，宽度变化重新测量 |
| `CanvasToolbarMenu` | 菜单持续挂载、Escape 收起与焦点恢复；菜单关闭不终止任务 |
| `WorkbenchChrome` | 顶部身份／版本／保存／画布切换／主操作、当前位置与导航；各画布保留适用的中央工作区 |
| `CanvasBrowse` | 顶部前进／后退、独立面包屑、可收起筛选及对应操作／提示宿主；不承载业务选择状态 |
| `GraphCanvas` / `GraphSubgraphPreview` | 服务端 graph 的通用容器和聚合预览，布局状态使用 `useGraphLayout`，浏览历史使用 `useGraphBrowse`；接入方式见[共享 graph 指南](../guides/canvas-graph.md) |
| `components/canvas/Canvas` | 通用视口、几何、标题拖动、卡片鼠标／键盘激活及事件隔离；导演布局、分组和关系留在业务适配 |

使用 AntD 已有表单、选择、提示与语义标签，不重复实现基础控件。任务中心仅在工作台实例采用共享按钮，全站实例保持原主题。AI 设计的生成／检查／应用阶段属于业务组件，不放入通用弹窗。

```tsx
<WorkbenchTheme>
  <WorkbenchModal title="AI 设计" open={open} onCancel={close}
    footer={<WorkbenchDialogActions
      secondary={<WorkbenchButton variant="quiet" onClick={close}>暂不应用</WorkbenchButton>}>
      <WorkbenchButton variant="primary" disabled={!canApply} loading={busy} onClick={apply}>
        应用到当前版本
      </WorkbenchButton>
    </WorkbenchDialogActions>}>
    <CanvasTextPreview text={sourceText} label="原文" lines={4} />
  </WorkbenchModal>
</WorkbenchTheme>
```

实际工作台根部已提供主题，业务组件直接复用即可。`WorkbenchModal` 不自带确认／取消业务逻辑，调用方明确提供 footer。

## 动作与状态

| 语义 | 表达 | 使用规则 |
| --- | --- | --- |
| 主动作 | 较亮灰底、亮文字、清晰边框 | 同一操作区域突出一个当前动作；弹窗放底部右侧 |
| 次动作 | 深灰底、细边框 | 如发起新设计、查看记录；不能表现成不可点击的说明 |
| 低强调 | 无底色或边框，悬停反馈 | 如取消、收起；不会取代主动作的位置 |
| 危险 | 保留红色语义 | 删除等不可轻易恢复的动作；通用灰阶规则不得覆盖 |
| 选中 | 中性灰底，`aria-pressed` 或控件自身选择状态 | 选择不是提交，不用主动作颜色冒充选中 |
| 禁用 | 暗底灰字，原生 disabled | 原因在附近可读区域解释；不只用颜色表达限制 |
| 加载 | 保持尺寸，阻止重复提交 | 图标不改变按钮可访问名称；后台轮询不插入额外加载行 |
| 焦点 | 清晰细蓝描边 | 键盘操作必须可辨，不能因“更简洁”而移除 |

蓝色用于链接、键盘焦点；成功、警告、错误保留业务语义色。已有区域可能仍显示蓝色主按钮。新增或修改的工作台主动作遵循上表的中性灰层级。

常规控件高 32px；显著入口可使用 38px；窄屏固定操作区至少 36px。常规图标 16px，入口强调图标可为 20px。间距使用 4／8／12／16／24px 的有限等级，避免每个按钮单独微调。共享动作的颜色和高度由 tokens 与公共 CSS 决定，业务 CSS 负责位置与布局。

## 文本、图标与内容层级

- 区块按“标题 → 内容 → 辅助信息”组织。正文清楚可读，辅助文字较弱；不要把正文降到占位文字的对比度。
- 用明确动词命名操作，入口、弹窗标题与主动作保持同一业务上下文。
- 原文、用户要求、模型结果与系统状态分区。未填写用所属标题旁的空态标签，不拼接到上一段正文末尾。
- 图标优先搭配短标签。刷新、关闭、撤销等熟悉操作可仅用图标，但必须有可读名称和提示。
- 装饰图标使用 `aria-hidden`；生成、应用、失败原因等关键语义保留文字。
- 长正文用 `CanvasTextPreview` 原位展开，不能同时显示摘要和全文。历史与固定依据可以按需展开。
- 对象摘要卡单击或键盘 Enter／Space 打开详情；子图入口进入对应范围；引用卡标明只读身份并定位原对象。删除与整卡激活重复的“编辑此卡”；卡片独立动作横排优先、空间不足换行。按钮、菜单和标题拖动独立，拖动不打开详情。卡面按类型使用有限尺寸与最多两行字段摘要，不在卡内滚动全文；触摸和键盘都能访问菜单。
- 导演总览继续按全场、跨镜共享、镜头入口和可收起的未关联设计组织。浅灰无箭头结构线不进入业务关系检查；镜头入口保留真实布局预览与计数。导航和明确定位可以移动视口，详情开合与展开不改变视口或布局缓存。
- 单元配置分别从各卡片详情编辑，不设置整份单元总设置入口；种子及额外参数在生成配置详情直接编辑。当前单元准备结论位于顶部状态入口，问题清单仅解释、重试和定位，生成指令使用独立操作。参数沿用直接编辑；前段承接先比较原首帧与拟用落幅，明确应用后一次替换唯一依赖和首帧，取消不修改；指令依据、素材固定依据与历史审片只读查看。单元首帧、尾帧分别使用固定输入位置卡，普通参考按显式组显示；空添加卡不产生输入关系。参考卡使用 360×480 的有限尺寸，为缩略图、对象／用途／来源和问题状态留出空间；激活后只管理当前帧位置或参考组，明确应用后一次更新并可撤销，取消不改原绑定。只读场景可阅读但不能应用。主指令编辑器、素材库、主播放器、内联素材／接缝审查与时间线保持业务工作区，不套用紧凑卡片尺寸或新增提交弹窗。
- 多个真实使用点共享相同语义时才抽组件。标题区目前按上述排版模式实现，不创建万能卡片或表单配置系统。

生成画布在卡片菜单前显示一个明确归属的问题入口，红色错误优先于黄色警告。悬浮及键盘焦点显示说明，点击打开可操作清单。定位名称进入详情的名称控件，明确模型配置定位到对应控件。文字提示只说明，画布级错误继续在状态区展示。无有效卡片或字段时给出失效提示。

## 详情与操作边界

桌面详情在右上方四周留边，无遮罩、不侧滑、不挤压画布；常规／展开两档复用同一内容。新对象替换当前目标，重复选择与点击画布空白不关闭。关闭图标或 Escape 退出，内层选择器／菜单先消费 Escape。窄屏使用近全屏的同一内容，标题、保存／只读状态与关闭入口固定可达，焦点限制在覆盖区域。生成画布三类模型、四类命名参考及四类描述编辑卡在桌面按已确认 A 方案例外移除卡名标题栏与关闭按钮，仅保留右上展开／收起；小于 1280px 时自动模态，统一改为右上一步“关闭详情”，热区至少 44×44px，并为顶部字段留出空间。Escape 先消费内部菜单或候选管理，再按桌面收起／退出或窄屏直接退出。参考卡参数位于顶部，底部仅保留状态，不提供生成动作。描述卡复用相同编辑基础，名称在顶部、正文居中、底部仅字数／只读状态；卡面固定为 400×172。其他基础内容与导演详情沿用本节通用规则；验收覆盖三区布局、内层 Escape、草稿保留、OS 发送快捷键及桌面／窄屏固定操作可达。入口已消失时回退到有效的工作台控件。

设计字段、资产关联、附加信息、关系、来源版本、任务固定记录、历史审片及导出记录使用详情。关系总览进入只读对象时在当前容器内阅读并返回，不叠加大型窗口。固定来源、记录与媒体区间按原身份解析，不用当前内容重解释历史。

参考选择、原文依据比较更新、时间线整理预览、AI 设计准备／比较／应用、批量预检提交、导出配置提交使用独立操作。AI 设计记录、拍摄任务记录与导出记录提供独立的非模态阅读入口，后台任务不由容器可见性决定。保存冲突、离开、所有权、恢复、复制及未知结果保护继续由原业务逻辑负责，危险删除仍明确确认。

操作弹窗覆盖时，底层详情保持挂载与输入但暂停交互。操作内核对来源、历史依据或参考图时，在同一弹窗内只读进入与返回，保留选择和输入；不打开第二个大型窗口、不激活底层详情、不复制完整编辑器。任务中心及其历史维持原容器；其排除范围不作为新业务详情的实现范例。

## 布局与刷新稳定性

- 生成画布开始单卡、多卡或编组移动时，锁定本次移动的可见成员高度。连线锁定来源及指针所在连接点或键盘焦点所指的当前目标。各手势与详情分别持有锁，全部释放后一次采用最新摘要所需高度。手势期间摘要和问题状态继续刷新，整理布局入口禁用。

- 四画布的前进／后退位于顶部状态栏，只恢复当前画布、当前版本的浏览位置和视角。面包屑紧贴状态栏下方靠左覆盖在节点与连线上，不计入画布视口高度；长路径可横向滚动。菜单、详情与弹窗位于其上。错误与核实提示单独预留空间。
- 面包屑下方的筛选条与面包屑左对齐、留边悬浮并横向展开，只放真实筛选／选择条件，无独立标题行，右端收起；窄屏条件可换行。默认展开，浏览器按画布类型记住收起状态；收起后保留同样留边的搜索图标按钮，点击展开筛选，不新增搜索框，筛选生效时以可访问圆点提示，不清空选择，不进入导航历史，不改变画布视角或节点布局。没有条件时不显示空面板。刷新、附加信息和编辑视图切换放顶部对应操作区。
- 非阻断画布状态位于右下撤销／重做左侧，窄屏移到其上方靠右，小地图避让；不占用画布视口。待归镜头与未关联设计计数只在导演总览显示，零值隐藏，不提供额外操作；图待同步等状态按当前画布显示。单元准备结论继续位于顶部，错误与失效目标保留明确恢复入口。
- 镜头／单元选择即导航，与面包屑及业务操作对象同步。导演镜头进入单元画布时只继承该镜头的概览；单元概览不保留隐藏单元的准备状态或生成操作，进入指令画布须明确选择单元。具体单元与指令画布之间保留该单元。

- 操作弹窗整体高度受视口约束，标题与动作保留在可见范围；窄屏动作允许换行且至少 36px。主要纵向滚动由弹窗正文承担，底部动作固定；暗灰细滚动条、透明轨道，正文使用 `scrollbar-gutter: stable`。
- 长内容和窄屏不能产生页面横向溢出。差异内容仅保留必要的横向滚动。
- 首载可显示加载占位；后台刷新保留当前内容、展开状态与滚动位置。错误提示使用稳定状态区域，不清空已有结果。
- 详情展开不重建编辑器；关闭、对象切换和重开沿用当前版本的输入保留策略。字段编辑继续自动／手动保存，不新增普通编辑的确认／取消事务。
- 打开工作台浮层默认不自动平移、缩放或重排画布。生成画布常规编辑器为明确例外：固定在卡片下方，打开、切换、收回展开态及桌面窗口缩小时，允许约150ms的最小视口平移；用户输入可打断，减少动态效果时直接定位。关闭或窗口放大不恢复视口，输入和内容更新不反复让位。编辑器字号与尺寸保持稳定，空间不足优先编辑区可操作，卡片可部分出屏；不更改卡片坐标、不重排其他对象。手机、复杂导演和主动展开继续模态。关闭菜单／浮层不丢失未保存内容。

## 可重复验证

开发环境访问 `/dev/workbench-ui`：真实组件的默认、选中、危险、禁用、加载、焦点、长文及弹窗状态。此路由仅开发模式提供，不请求业务数据或执行付费任务。

在项目根目录执行（项目 Node 版本见 `front/.node-version`；安装本机 Chrome、后端测试依赖及 ffmpeg/ffprobe）：

```sh
pnpm --dir front run typecheck
PLAYWRIGHT_CHANNEL=chrome pnpm --dir front run test:workbench-ui
```

若使用 Playwright 已安装的自带浏览器，可省略 `PLAYWRIGHT_CHANNEL`。命令先预检依赖、本机监听及浏览器启动能力，再执行工作台浏览器套件，覆盖组件示例、四画布样式、设计完整性、单元设计和指令相关流程，输出临时截图目录。设计完整性可用 `pnpm --dir front run test:design-scope` 单独运行。相关 PR 与 merge queue 由 Frontend checks 工作流执行相同检查。

验收清单：

- 主次动作有区别，普通选择不冒充主动作，危险色与禁用态保留。
- Tab 焦点可见，纯图标可命名，菜单 Escape 与弹窗关闭正常。
- 1440px 与 390px 下按钮不重叠、不越界，长文展开仍只有一份正文。
- 门户弹窗／抽屉继承局部标准，全站浅色任务中心不受影响。
- 轮询、草稿和画布视角使用已有业务回归；业务状态变化时补相关测试，不能用组件截图代替业务验证。

生成画布高级参数输入为外扩焦点轮廓保留8px垂直滚动安全距离，避免长表单定位到视口边缘时裁切上下轮廓。`pnpm --dir front run test:browser generation-canvas-design-focus` 从公开目录遍历全部25类设计卡，在1440px与390px下逐一聚焦正文、普通输入、数值、下拉、名称和运镜阶段控件，检查四边轮廓与所有裁切祖先的几何边界；该用例已纳入 `canvas-design` 套件。

例外应记录：为何现有组件无法表达、例外作用域、替代方案和对应检查。不通过提高选择器优先级或增加散落的硬编码颜色绕过标准。

单元画布的只读投影核实中或失败时，临时配置卡使用当前草稿原字段及共享卡片样式，摘要仍限制为两行；明确的详情按钮暂代整卡激活，以区分本地配置编辑与尚未核实的业务图。例外仅覆盖该临时编辑区，核实成功即恢复原图卡；通过 AI 应用后预览失败、修改、重试及保存恢复浏览器用例验证。


生成画布右键菜单使用 AntD Menu／Menu.Item／SubMenu 的菜单语义，作为普通 WorkbenchButton 的局部例外：菜单需要多级悬停、键盘导航和独立浮层，不能继承动作按钮的固定高度及禁用背景。颜色仍消费 WorkbenchTheme tokens。桌面独立三级浮层、窄屏逐级返回及单行禁用样式通过 `generation-canvas-context-menu` 的真实画布用例和截图验收；不改变其他工作台按钮。

生成画布基础文本、创作依据、四类对象描述及文本结果统一采用 400×172 外框（100% 缩放，含标题），卡面最多四行正文及适用的字数、来源或状态。正文在卡面省略，详情提供完整阅读。文本结果沿用文本内容卡的浮窗／展开／窄屏 Modal，正文只读且可选择复制，无导入操作；新正式输出到达时更新同一详情。

文本模型卡采用 360×304 的固定外框（100% 缩放，含标题）。预览区同时容纳最多四行正式或保留结果、适用的临时生成说明及最多四行临时正文，底部状态独立显示。空态、流式、完成、失败、取消及保留旧结果均使用此高度。224px 候选在旧结果与临时预览并存时实测超出约 65px，计入 12px 底部内边距后的最小外框约 301px，按 8px 间距定标为 304px。图片和视频模型卡采用 360×424 外框，为等比媒体预览留足空间。使用 `generation-canvas-model-card-shell` 核对上述状态、实际外框、连线、历史缓存与缩放。

基础图片和图片结果统一采用 300×251 外框，在固定预览区等比显示完整图片。点击图片结果卡打开共享图片阅读布局，详情提供加载或失败反馈、实际图片尺寸和可用文件信息，来源标为“生成结果”。桌面浮窗、展开和窄屏 Modal 沿用基础图片详情规则。结果详情只读，导入、替换与选择素材动作由普通内容卡提供。卡面独立的完整图片按钮只打开图片预览。四类命名参考仍保留 300×251 和名称、角度、来源及关联状态。

基础音频和音频结果统一采用 300×172 外框，播放器旁显示可读取的文件名称，底栏显示实际读到的时长与状态。基础视频和视频结果保留 300×251 外框、原生播放控制及视频音轨。音视频结果复用同模态内容的播放器和共享详情，来源标为“生成结果”，媒体无法加载时提供明确反馈。普通内容卡提供上传或替换，结果详情只读。状态刷新保留同文件的播放位置，替换为新文件后由用户主动开始播放。关闭或隐藏详情暂停其中的媒体，卡面播放器的操作保持独立。

生成画布参考卡与描述卡的顶部参数使用可见字段标签和固定提示位，名称优先，参考角度与图片选择随后排列；按编辑器实际宽度换行。名称错误就近关联控件，底部仅保留状态。已关联名称作为局部例外保持可读文字，并明确显示“已关联”及取消关联入口；普通只读控件保留禁用表达。长名称静态省略，悬停／聚焦可读全文，实际保存值不截断。





画面风格编辑器采用可切换预设与参数的 A 布局，普通打开按下文的有效设计规则选择模式。预设页使用连续 Modal 表面、左预设图库与右侧选中预设详情，右上“高级设置／返回预设”替换主体。预览优先使用本次会话选择，否则展示完整匹配或声明字段匹配的预设；没有匹配或选择时，右侧显示当前真实摘要或选择提示。浏览或选择预览不自动应用预设，也不切换当前会话模式。标题、底部及左右栏不增加硬分隔线，桌面只让图库滚动；展开变更明细时在右侧替换预览，超长明细局部滚动。高级设置直接显示全部风格参数及统一的状态／来源开关，不保留 Tab、更多参数或独立正反例。预览、对比和模式切换只更新会话；显式应用只合并声明字段，留在图库反馈结果，撤销复用画布历史。关闭清除未应用预览，模式切换保留浏览位置，保存失败和较早保存回包继续由画布保存机制保护输入。窄屏上下排列，内容区滚动、动作固定。六类独立设计已接入，旧摄影及五分区入口退出；候选添加与字段引用按下述公共规则使用。

风格编辑器的标题工具和底部动作通过真实卡片容器的保留宿主渲染，容器继续负责焦点约束、Escape、关闭恢复和画布不平移；没有新增第二个 Modal 或复制保存状态。以 `generation-canvas-visual-presets` 的真实页面保存、撤销、只读及桌面／小高度／窄屏证据验收，旧摄影清理和六类设计菜单由真实浏览器用例回归。

机位与视角、光影与色彩、焦点与成像卡各自维护独立字段集，复用上述 A 预设／高级设置容器。卡面展示对应用途示意与有限真实摘要，点击卡面进入设计详情。高级设置直接展示本卡参数，以及已有所属镜头、验收依据、适用范围、条件、阶段和来源；焦点保留关注／焦点对象关系。新类型不提供独立正反例或局部采用；预设合并与画布撤销不改变未声明的关系。添加菜单由公开目录给出真实类型，已独立类型出现后不再显示同名旧摄影创建入口。三个类型以 `generation-canvas-static-designs` 的真实创建、预设、保存刷新、只读和桌面／窄屏证据验收。

景别与构图卡现为独立类型，复用画面风格卡的 A 容器，按当前有效设计选择预设或参数页。高级设置直接提供本卡文字及结构化景别，不含摄影分区导航、更多参数或正反例；不自动关联运镜。构图入口不再创建完整摄影卡。跨卡阶段定位采用显式选择。
独立运镜卡复用画面风格的 A 外壳，按当前有效设计选择预设或参数页；高级设置以起始、途中关键画面与结束的单行导航为主体，单项编辑并提供全部画面选择；中间画面可增删、重命名和重排，身份保持稳定。关键画面编辑横跨整宽，下方以短横线轻分隔，运动方式、路径、速度与触发条件按两列直接展示，窄屏单列。导航行右侧固定添加按钮；关键画面列表独立横向滚动。限制浮层已填写时显示状态点，引用定位自动展示目标画面。适用说明随整卡传递，不自动筛选画面；不新增摄影分区。运镜图库示意仅表达用途，完整输出按整卡采用，阶段不提供局部采用。 设计卡详情不重复展示常规保存进度，统一沿用画布状态，保留异常与只读反馈；设计参数标题及漏斗位于内容滚动区外。运镜分隔线上下间距为4px，画面输入区随可用高度在120–140px间收敛。桌面阶段区与参数区使用稳定高度，切换画面只替换阶段正文，短内容优先首屏完整，长正文局部滚动；窄屏参数单列并保留必要正文滚动。中间画面名称双击或F2原位编辑，Enter或失焦确认、Escape放弃；新增后直接改名。Tab支持拖动和Ctrl/⌘+Shift+左右键排序，排序不切换当前画面；标题左侧常驻12px铅笔提示，与文字间隔4px，无独立按钮或焦点；鼠标、触摸双击标题或F2改名，拖动后取消双击识别。删除为贴近右上边缘的10px悬浮角标，24px热区不遮挡标题，编辑名称时隐藏，是常规32px图标按钮的局部尺寸例外；删除角标悬停、聚焦或触摸选中时显示，通过浮层脱离滚动容器，不占Tab宽度，不增加Tab高度。起始与结束固定；被构图或图片模型定位的画面删除前提示影响，确认后保留失效定位并阻止相关生成，不自动改绑；普通删除沿用撤销。全部画面入口仅在Tab溢出时显示在导航行。

旧摄影存量读取时只清理冲突卡及实际相关绑定、连线、顺序和分组成员。受影响模型在正文附近显示“缺失设计依据”，在用户补充或明确点击“已处理缺失设计”前阻止运行；不能通过清理后空绑定伪装成完整方案。六类卡面使用有限用途示意与真实字段摘要，不再显示独立正向／反例。历史固定依据不原地改写，不兼容的旧画面设计等待节点明确失败并要求重新提交。

独立构图的高级设置提供可选运镜卡与目标画面选择；中间选择可保存，未选完或失效时保留定位并显示提示，不猜默认阶段。图片模型的画面目标配置保留失效选项的明确说明，允许清除；只读时可以查看定位与问题，不能修改。选择阶段只明确画面时刻，不切成局部采用。

设计卡和生成卡的来源区共用 `CanvasAssociations`，按素材、设计分组，各来源复用 64px 方形 `MaterialReferenceButton`。同一非模型卡的正文、对象身份等用途合并入口，模型各个实际输出分别展示。条目和空态“＋”固定一行高度，素材优先排列，组内按首次连接顺序保持稳定。空类别不保留空间，两类同时存在才显示分隔线。超出容量的条目由各组 32px 的 `+N` 入口打开完整列表，隐藏异常汇总到该入口。窄屏减少可见项，极窄时使用分类计数入口，内容不增加 Modal 的纵向高度。

点击来源统一打开详情，显式执行引用或采用。设计高级设置提供“引用当前字段”，没有明确编辑目标时禁用该动作，输入 `@` 继续使用原引用机制。模式切换清除字段目标。名称、类型、使用位置及异常在详情中展示，至少一项用途生效时显示“使用中”，异常优先显示。字段未填写或不适用时保留引用并标记未生效。关闭浮层恢复入口焦点，定位源卡或正文时将焦点交给目标。只读模式仍可浏览来源，所有写入操作受现有禁用和公共连接策略保护。添加来源继续使用上传、素材库及从当前画布选择菜单。

生成卡的直接来源展示在关联区。随设计携带的素材和验收要求归入对应设计条目的详情，复用图片查看、设计字段定位及携带用途控件。直接采用和间接携带相同素材时保留两条来源路径并说明直接采用状态，取消其中一条由其自身的业务操作处理。来源定位进入对应设计的高级参数，等待编辑器解除 inert 后恢复字段焦点，普通重开按当前有效设计选择入口。
视频接收端的携带素材区按模型能力显示可设置用途；主体参考需明确填写分组，已保存用途可删除和排序，直接采用中的明确用途显示为沿用。仅配置接收方式，不增加模型到素材的连线或改写设计；取消最后有效设计引用后该素材退出实际输入，保存的用途配置不自行采用来源。只读模式禁用所有用途与分组修改。

机位、光影、焦点、构图与运镜的对象和所属镜头操作复用 `VisualDesignRelations`，放在对应来源的详情中。验收要求以设计类条目直接展示，详情复用 `AcceptanceBasisDetails` 展示只读标准、范围、来源及定位入口。连接与解除使用公共连接策略。构图的运镜画面选择继续复用 `CompositionFrameCandidate`，本地素材参考、区间和图片标记复用现有专属控件。

设计卡复用 CardShell 的选择、拖动、菜单与位置缓存。单击卡面、触摸或按 Enter 打开详情，拖动与卡上独立操作保持独立。可读名称只在标题出现，卡面不放置开始／编辑／查看设计按钮或额外配置计数。只读仍可打开详情。验收要求、不可改事实、对白、事件与刺激和表演规则使用宽 360px 的紧凑外框。100% 缩放时，包含标题、有限摘要和标准内边距，按实际可见内容选择 128／160／192px 中最小可容纳高度。标题使用类型图标，卡面核心最多四行、辅助最多一行，无大幅用途示意图。优先展示可观察标准、事实、说话对象与对白正文、动作变化或表演适用规则，辅助信息按卡片职责选取。核心缺失而有辅助配置时，两种状态同时表达。创作控制、生成指导、叙事概览、叙事节拍和镜头设计使用宽 360px 的结构化外框，保留标题类型图标。十四类结构化卡统一按实际可见摘要选择 128／160／192／224px 中最小可容纳高度，尺寸包含标题和标准内边距。按卡片职责展示最多三项关键内容，通常每项最多两行，合计最多六行。创作控制优先保留项、允许变化范围、自由度；生成指导优先要求、禁止事项、参考要求；叙事概览优先信息变化、关系变化、转折；叙事节拍优先目标、阻碍、预期变化；镜头设计优先可见结果、叙事作用、预计时长。只有辅助配置时同时显示核心未填写与已有信息。空间锚点、声音安排、空间规则和连续性设计同属结构化档。锚点优先位置、朝向、空间关系，示例与位置标记为辅助；声音安排优先声源、环境声与动作声、声音层次；空间规则优先可拍区域、轴线、尺度。连续性按分类、前态／变化／后态、后续约束组织；前后变化每个已配置字段各占一行，分类一行，后续约束最多两行。仅默认分类时沿用空态；只有后续约束等辅助配置时明确提示核心未填。下文列出的五类表演与调度卡也使用结构化档。其余设计卡使用 360×368、用途示意与有限标签摘要。卡面直接显示已有内容，不改写设计或滚动全文。同一内容在编辑和只读画布中使用相同几何；紧凑卡和结构化卡的只读状态由画布和详情标明。已配置与模型可运行分别表达，不适用等状态保留其原意。

紧凑和结构化设计详情会话打开时锁定当前显示高度。会话切页、展开、收起或临时隐藏保持锁定，关闭或切换卡片后直接采用最新目标档位。锁定时以当前容量显示最新摘要，按原优先级省略后续内容。正常目标高度根据原预算内的摘要测量，不为未用行预留空间。未锁定且使用非最低档时，扣除标准底部内边距的额外空间小于 32px。最大档仍裁切预算内内容属于布局缺陷。画布、连线、选框与小地图共用实际显示尺寸，高度变化保持原坐标和视角。


画面风格、机位与视角、景别与构图、光影与色彩、焦点与成像和运镜使用 360×368 视觉档，尺寸包含标题。卡面保留原有 96px 用途示意图，图注标明示意用途。已配置参数按卡片职责展示，最多三项，合计最多四行。运镜优先展示起始、结束画面及运动要点，中间阶段全文在详情查看。构图优先展示景别、构图重心与已选画面目标，保留目标的实际名称或失效提示。仅有阶段、范围或关联时，同时展示核心未填写与已配置的辅助信息。

六类编辑器继续复用 `CanvasCardEditor` 的 Modal 生命周期与 `DesignPresetEditor` 的 A 预设／高级会话，范围、制作阶段、适用条件和来源通过 `DesignScopeEditor` 使用同一布局；运镜保留原有可访问字段名称。对象／镜头／验收关系仍由 `VisualDesignRelations` 承载，运镜阶段和构图目标等专业控件由各类提供，不增加另一层空 Modal 包装或通用表单引擎。真实 `canvas-design` 套件检查六类空态、仅阶段／景别／范围／状态／引用／关联配置、最多四行参数摘要、统一示意高度、只读以及桌面／窄屏的编辑和保存。

设计详情普通打开时按当前有效设计选择模式：未配置或完整匹配预设进入预设页，其他设计进入参数页。名称、来源、范围和关联不独立改变归类；明确字段定位直接进入参数页。对白、不可改事实和空间锚点直接编辑。打开后保留当前模式，关闭时清除未应用的试选与对比。预设只覆盖声明的配置；额外设计使整卡归为自定义，切回预设页仍可查看已匹配声明字段的用途图或视频。无匹配时继续展示真实文字摘要，不自动选第一个预设。应用按钮统一为“应用”，填写／覆盖数量和明细保留在详情中。底部提示与撤销按钮在桌面及窄屏垂直居中对齐。


表演与调度七类复用画面设计的连续 Modal、共享卡面 `DesignCardBody`、预设会话 `DesignPresetEditor` 和范围控件 `DesignScopeEditor`。角色情境、人物表演、表演规则、站位与走位、镜内活动、环境活动与留白在预设页左侧显示预设列表，右侧显示过程／路径示意与变更详情；右上高级设置显示真实字段，不嵌套更多参数。空间锚点直接编辑参数，名称位于标题，图片标记通过候选浮层编辑；桌面参数两列、窄屏单列，不新增交互式走位绘图。关系控件在预设／高级模式均可操作，继续明确选择参与对象与事件，不按正文推断。空间锚点的参考例图按需查看，预设不改写关系、例图或稳定身份。

七类顶部候选、字段 `@`、只读、停用引用及最后编辑字段插入沿用画面设计规则；有效图片／视频引用随整卡采用进入模型，视频用途与分组在接收模型配置。锚点与其他设计统一完整来源引用，接收字段决定引用位置；明确采用的有效依赖由模型编译递归携带，本地示例不自动携带。表演规则采用紧凑档；空间锚点采用结构化档，优先表达位置、朝向和空间关系。角色情境、人物表演、站位与走位、镜内活动、环境活动与留白采用同一结构化档。角色情境优先当前处境和人物关系。人物表演优先身体动作、反应顺序和结束状态。站位与走位优先位置、路径和状态切换原因。镜内活动优先持续任务、路径和入出画。环境活动与留白优先环境活动、刻意留白和理由。标题显示类型图标，点击卡面可查看包括其他表演参数在内的完整设计。摘要保留适用的关系、范围及实际状态。`generation-canvas-photography-card` 验证五类卡面尺寸、摘要优先级、长动作截断和布局兼容。`performance-design` 套件覆盖预设、引用、携带、停用、保存重开、只读及桌面／390px。


旧表演调度文字中的代号保持字面，查看或失焦不新增引用；用户显式选择候选后才建立结构化来源。预设／高级模式切换同步保留按钮焦点，不用延迟焦点恢复抢占随后点击的字段。普通图片／视频候选可以在高级设置关联为本地示例，关联成功不表示已进入模型输入。

叙事与镜头四类接入共享 `DesignCardBody`、`DesignPresetEditor` 与 `DesignScopeEditor`，采用连续 Modal，按当前设计选择预设或真实参数页。标题名称与候选跨模式保留，普通关系操作位于对应候选浮层；节拍顺序沿用已采用绑定排序。预设的过程示意仅表达用途，声明字段之外的名称、身份、关系、预计时长和待确定问题不变。四类字段整卡引用、实际素材携带与明确依赖递归传递沿用共享规则；名称和范围等辅助信息不支持结构化引用。镜头保留本地参考示例，其他三类不新增示例模块。验收覆盖四类预设、保存重开、只读、关系排序、引用及桌面／窄屏，图片模型继续选择镜头可见结果目标。

声音与连续性约束八类复用共享有限卡面、Modal、预设会话和范围控件；对白与事实直接编辑，其余六类按当前设计打开预设或参数，分类与关系跨模式可操作。默认版本、分类和待定初始值不独立表示已配置。对白正文仅插入文本，音频候选标为本地参考；其他七类实际图片／视频引用随整卡携带。参考区间只定位本地素材，存在区间的视频引用提示完整文件。对白稳定身份、连续性前后态目标、固定证据和只读验收使用记录保留；真实 sound-constraint 套件覆盖八类入口、预设、引用、保存、关系与窄屏。

全部25类设计字段以目录返回的真实 `default_value` 判断配置：默认用途和默认待定状态不独立计入自定义，实际状态、用途和引用参与设计判断；来源保留在展示中，单独变化不影响预设归类。对白、事实、锚点的空态提示匹配直接编辑入口。所有设计卡音频仅作本地参考，不允许字段插入；上传／素材库为本地音视频保留对应示例端口，普通媒体端口与示例端口不重复展示。连续性六分类提供各自的后续约束预设，切换保留字段和证据，清除不适用的会话试选。共享 `PresetIllustration` 保留真实使用能力；旧 Tab、旧图库会话、更多参数与相应样式已退出。


设计参数不再提供“显示状态与来源”开关或元信息编辑控件。状态、用途和来源以 12px 辅助文字放在对应输入框下，消费现有次级文字 token，支持长来源换行，并与输入框建立可访问描述关联。用户设定不显示默认元信息；模型提取显示实际信息；历史字段隐藏真实默认值，保留有意义的状态、用途与定位。空信息整行隐藏，不显示“未指定”。不生效且有内容的字段明确说明“不参与生成”。卡片原始来源在范围说明区只读显示一次，原文依据卡仍可编辑自身来源。验收覆盖提取只读、手填转换、清空、预设局部应用、历史语义、只读卡片及桌面／窄屏。

设计卡面摘要与编辑器统一遵守来源类别：用户手填及主动应用预设不显示内部“事实／设计”等默认元信息；提取与未标记历史字段保留有意义的状态。25 类设计卡由 `generation-canvas-design-metadata` 真实浏览器用例覆盖只读说明、手填转换、预设应用及摘要，并在保存重开、清空、撤销／重做及刷新后核对正文和完整字段元信息。

验收展示由 `generation-canvas-guidance` 覆盖七类卡片的默认收起、切换查看、跨模式保留、关闭重开、保存刷新、解除与撤销，以及桌面／窄屏；`generation-canvas-design-relations` 覆盖只读浏览和关系控件。验收内容不混入素材候选，不提供字段编辑或预设应用。

验收要求卡空名称连线被拦截后，打开来源卡直接进入标题名称编辑，输入框下显示就近错误，填写有效名称后清除。示例“例如：手部与钥匙清晰可见”仅作为输入框 placeholder，不增加说明行。

全部25类设计卡中，9类具有独立名称：创作控制、生成指导、验收要求、叙事概览、节拍、事件、镜头、空间锚点及站位与走位。名称统一通过 `DesignNameField` 渲染到 Modal 标题宿主，正文不再显示独立名称框。实际名称作为主标题，与“重命名 - 类型”排列在同一行；仅“重命名”为12px蓝色可点击小字，分隔符与类型为灰色不可点击文字，按基线对齐。长名称省略时保留操作与类型，极窄屏将操作和类型整体换行；只读隐藏重命名及其后分隔符。点击后原位切换单行输入。未命名时保留“未设置名称”入口。一般未命名不标红，实际名称错误用红点及可读说明表达；保留原有必填／重名规则，不按显示去除原值空白。只读显示名称或未命名说明，不提供编辑入口。 标题的名称编辑入口为局部样式例外：使用保留原生键盘语义的文本按钮，以12px链接色小字紧随实际名称，后接灰色分隔符及卡片类型，不继承共享动作按钮的固定高度、内边距或悬停底色；悬停下划线、键盘焦点轮廓仍保留。
标题输入沿用自动保存与画布撤销，Enter／失焦结束编辑，Escape 仅结束名称编辑并保留输入，输入法组合时不结束；键盘退出将焦点返回编辑入口，点击其他控件则尊重目标焦点。模式按钮使名称失焦后结束编辑并保留最新值，重开默认展示标题。名称错误就近显示且不强制困住编辑；网络、修订冲突和其他字段保存失败沿用原有画布反馈，不误标名称或还原本地输入。长标题省略并可悬停读取，窄屏工具允许分行，编辑不触发画布视口让位。`generation-canvas-design-names` 覆盖九类原位编辑、键盘、模式切换、保存刷新、重名反馈、窄屏及只读。

设计候选条同时展示有效字段引用与明确关系采用，查看浮层和可访问名称列明各个字段／角色用途；同源多用途不重复生成候选项。暂不生效字段保留引用但标明未生效，本地示例与音频本地参考不表示模型已采用。候选计数中的使用项仅统计当前可用且有效采用的输出。空来源、首次加载和读取失败分别提示，后台刷新保留原候选；只读可以查看用途但不能插入或修改，预览和展开不保存文档或产生撤销记录。`generation-canvas-candidate-states` 覆盖角色、字段、多用途解除、停用引用、空／加载／失败、只读和窄屏。

创作控制、生成指导、不可改事实与表演规则不再提供通用“作用对象”入口。创作要求保留常驻可见名称，事实与表演规则直接在原有字段表达或引用完整来源；不留下空对象关系区，不新增对象采用列表。旧通用用途只清理自身，合法来源保留为候选；恢复本地内容、撤销／重做和保存重开均不能重建废弃用途。其他明确主体、空间、事件和媒体用途保持原规则。真实 sound-constraints 回归覆盖四类字段引用、预设、旧草稿恢复、撤销重做、只读及窄屏。

叙事概览与事件卡移除通用作用对象后，不再显示空的叙事关系折叠区；名称和字段引用常驻规则保持。空间规则与锚点保留所属空间入口，位置／空间关系正文可引用完整来源，不按引用推断所属空间。`generation-canvas-narrative-spatial-objects` 验证四类旧本地恢复、同源有效归属、完整字段引用、撤销重做、保存重开和窄屏。


情境、人物表演和镜内活动不再提供通用作用对象选择；相关对象在具体字段中用文字或完整来源引用表达，参与对象仍单独明确主体，正文不会自动设置主体。表演的节拍／事件／对白与镜内活动的区域锚点／触发事件保持原有关系交互。旧对象用途清理保留有效主体与字段引用，正常撤销和保存重开不得恢复废弃用途。

生成画布批量删除允许来源与其消费者一起删除；若集合外仍有正文或业务引用，继续提示具体位置。`generation-canvas-multipath-protection` 以真实页面覆盖外部停用引用保护、内部整组删除、连线及引用随撤销／重做完整恢复和保存刷新。
五类画面设计（机位、光影、焦点、构图、运镜）不再提供通用作用对象入口。一般对象在具体字段以文字或完整来源引用表达；运镜／焦点的关注对象、焦点的焦点对象、所属镜头、验收关联、运镜阶段和构图目标继续独立配置。旧通用用途清理不改变这些用途，合法来源保留为候选。真实关系回归覆盖五类旧本地恢复、专用关系及只读，候选状态回归以关注／焦点双用途验证单用途解除。


声音安排不再提供单独声源对象选择，使用现有字段引用；本地音频参考继续保留，正文引用不自动建立对白说话对象。真实声音约束回归覆盖旧本地内容恢复、撤销重做及保存重开，废弃声源用途不会重新出现。

全部25类设计卡共用底部修订号：`revision N` 使用小号灰字且不可点击，取服务端已确认的画布修订号；保存中或失败保留上次编号，未知隐藏，0正常显示。高级模式与自动保存说明同行靠右；预设模式放在应用按钮左侧，只读模式同样展示。窄屏可分组换行，修订号不拆词且保持右对齐。19类原有完整已保存输出折叠区已移除，字段、关系及模型编译审稿入口保留。

验收要求卡不展示下游“被使用记录”或未采用空态。设计关系区只显示承担实际关系操作或失效警告的行；普通候选的纯名称留在统一候选区。没有内容的关系标题和容器隐藏，独立设置（如连续性分类）保留，只读时仍展示有效关系。此规则不改写连线、绑定和历史数据。

25类设计卡统一在13px“设计参数”标题行右端使用公共 `DesignScopePopover` 漏斗浮层，原始来源只读展示；候选区与标题行相隔8px，验收展开内容上下各8px。浮层共用“内容适用范围、适用制作环节、适用条件”的单值可输入选择框：常用选项仅提供填写起点，支持选择后改写与直接输入；清空恢复未限定，提示文字不保存。旧制作阶段值原样保留并按中文回显，自定义阶段在卡面和验收详情显示原文。限制只作为说明传递，不自动筛选执行；整卡预设不覆盖限制。三个限制字段同一时间仅展开一个菜单，切换不保留关闭动画；失焦或点击外部收起，选项点击正常采用。下拉中Enter确认高亮项或保留原输入，Escape仅收起下拉，失焦与编辑沿用画布自动保存，只读禁用修改。

设计Modal输入内容使用主题字体：正文14px/400、1.8行高，单行文本、选择当前值与数字输入14px/400并保留控件行高；占位同字体大小与字重，使用统一次级色。内联引用跟随正文并保留既有形态与状态颜色。只读和窄屏不缩小输入内容；标题重命名、按钮、预设与独立阅读面不套用输入规则。

设计字段辅助说明统一为11px/400、1.6行高，状态／用途／来源带前缀且始终单行；优先保留状态用途，来源占剩余空间并省略，极窄时其他说明也可省略。整行支持悬停、聚焦或点击查看全文，来源可复制。原始卡片来源采用相同辅助样式但独立在原位置展示；手填、缺省值、模型声明与不参与生成的判断不变，卡面和预设变更摘要不套用单行规则。

多字段短参数复用 `design-preset-fields` 与 `design-preset-fields-compact`：桌面两列、窄屏单列，输入框使用一致的紧凑高度与辅助信息槽；叙事概览、节拍、镜头、空间规则、连续性、不可改事实、创作控制、生成指导和声音安排接入。单个主要正文及长表单、媒体区保留正常阅读高度与必要滚动。既无可展示关系、也无失效绑定时不渲染空关系区。

构图的标准景别选择器位于景别字段标签右侧，与文字独立编辑。运镜候选通过浮层明确选择字段引用或画面定位，连线不自动定位；一张构图卡最多定位一个明确画面，已有无连线定位仍在候选中回显。解除定位保留候选；仅用于定位的连线断开前确认，并在同一历史步骤清除定位及连接；存在字段引用时先处理引用。目标失效保留警告及生成阻断，不自动改绑。

人物表演与镜内活动使用公共 `DesignParameterTabs` 固定分组，沿用 AntD 键盘语义和工作台灰阶样式。人物表演分为动作过程、动机背景、表现细节；镜内活动分为活动内容、空间与时序。这两类长表单的 Modal 高度上限为840px，仍受视口留边约束，以容纳四行正常字号参数；其他设计卡沿用原高度。候选、标题和底部固定，页签正文按需滚动；同一会话保留页签和各页位置，关闭后恢复默认页。切换页签清除隐藏字段的引用目标，不改写输入或新增历史。

表演、空间、叙事、声音与约束卡的普通关系操作位于现有候选浮层，由 `DesignCandidateRelations` 与集中关系规则复用；关系候选单击先预览，明确采用、替换或解除。单值替换一次更新，解除仅影响当前用途并保留连接、其他用途及正文引用；无连接的历史用途可查看、解除，不可重新采用。普通使用中连接继续由画布引用保护阻止断开。镜头覆盖节拍顺序保留专用排序，连续性分类在高级设置的设计参数区编辑，构图定位和验收沿用专用规则。

设计卡 Modal 不展示锚点、调度、节拍、事件、镜头和对白的内部身份编号；底层身份及画布修订号保持原语义。空间锚点参数恢复整宽两列，素材参考和标记在顶部候选浮层内管理，沿用明确采用与断线保护。同源历史参考可在同一候选中切换，固定文件及说明不随来源新输出自动替换。

锚点图片默认查看，显式进入标记模式后才允许放点或拖动；坐标相对实际图片矩形归一化且限制于图片边界，一次完整手势提交一次历史。精确坐标以百分比支持键盘编辑；清除标记保留参考，取消本地参考同时清除其标记但保留连线和正文引用。预览可在同一浮层展开，视频保留参考区间而不增加打点。只读允许查看与展开，失效文件明确提示并保留取消入口。

### 设计 Modal 内页签

固定参数分组复用 `DesignParameterTabs`；运镜动态阶段保留 `MovementPhaseTabs` 的改名、排序与删除能力，并共享以下视觉规范。正文导航采用轻量下划线，移除整行底线，仅选中项显示2px短下划线。文字12px、常规字重，普通项次级灰、选中项正文色，悬浮和按下使用中性灰反馈；蓝色仅用于键盘焦点。图标12px、图文间距4px，固定分组间距16px，页签与正文相隔8px。桌面固定分组高32px，窄屏或触摸至少36px，运镜动态阶段保留40px。空间不足单行横向浏览，不缩小文字或改成多行。

固定分组标签右侧始终预留同宽状态位：无内容留空，已有内容显示低强调圆点，存在错误显示语义色错误图标并优先于圆点。内容标记仅说明已配置，不代表完成或验收通过；悬浮或键盘聚焦可读状态及错误说明。状态改变不移动相邻页签。选中、焦点、只读浏览、模式切换与滚动记忆沿用现有行为。验收使用 `generation-canvas-parameter-groups` 的桌面／窄屏尺寸、状态宽度、键盘及截图，以及 `generation-canvas-movement` 的动态阶段交互。

卡片问题清单中的明确设计字段或运镜阶段入口打开参数页和对应分组／阶段，并滚动到目标控件。问题带有引用片段身份时，焦点定位到该字段内的对应引用。只读和窄屏保留目标及其焦点轮廓。目标失效但原卡仍在时提供“查看卡片”，并说明原位置已不可用。关闭后普通打开按有效设计选择入口。

对白与表演规则使用共享单正文布局。对白不再维护独立修订编号，声音安排不再维护制作安排三态；设计正文连接模型即采用，实际声音产出取决于模型能力。对白的音视频、声音安排的音频本地参考统一在候选浮层明确采用，同源多份集中管理，固定文件不随来源输出替换。普通采用防重复，明确新增允许同文件多份用途或区间。取消仅移除当前参考，保留连接；仍有参考时断线受保护。区间以秒编辑、毫秒保存，成对应用和撤销；未应用草稿关闭即丢弃，区间仅用于本地定位。当前画布退役字段通过迁移清理，本地草稿与撤销恢复同样清理；历史执行证据保持原样，旧结构须从当前画布重新提交。

连续性卡使用六个固定分类预设，每个明确携带分类和后续约束；预览与对比不写入，变更清单展示两项差异，应用一次更新、一次撤销。前态、变化、后态作为额外设计保留，已有实质内容时下次打开参数页，仍可在预设页查看匹配分类和后续约束的预览；内联引用不能仅凭显示文本相同判为匹配。手动改分类不重写正文，已有卡片不自动应用预设。分类使用紧凑选择器，仅在高级设置参数区编辑，预设模式通过方案名称和预览表达。


### 连接用途与解除反馈

拖线、键盘连接和从画布选择均建立来源连接，无须先选择用途。常规或收起状态下，同一来源与接收卡之间只显示一条线，重复连接定位已有线。模型参数栏展开结果卡后按结果位置显示下游连线，所选结果线只提示该项的采用用途和引用位置。普通连接在关联区提供合法用途，打开浮层仅预览，采用、单值替换和解除使用现有业务动作。唯一白名单用途仍按公开目录直接采用设计或关联验收要求。模型候选受当前能力约束，切换模型保留既有采用。

模型取消采用遇到正文或指令引用时禁用取消，列出定位入口；用户清理引用后再取消，仅移除绑定拥有的配置。同源多用途断线先汇总全部阻止项；构图画面定位只有在其他引用解除后才显示“解除定位并断开”确认，一次撤销恢复。


关系问题按结构化目标定位。采用绑定和画面定位打开现有候选浮层，保留当前卡片的普通详情模式。连线问题定位已有线，明确的整卡或跨卡问题定位画布对象。多个相关卡片分别提供入口，失效项显示不可用，其他入口仍可选择。仅有文字说明时保留原消息。只读仍可定位，关系修改保持禁用。堆叠成员定位到所属堆叠并提示先解除，用户可继续阅读现有堆叠内容。折叠编组内的成员定位到编组并提示限制。定位只调整选中和视口。

### 生成画布检查卡

左侧分类浮窗统一以240px作为桌面最小宽度，受视口剩余空间约束，搜索框占满内容宽度。检查卡使用400×424的有限卡面，最多展示四项，不在卡内滚动；条目正文打开对应详情，独立按钮仅执行该项。卡面生成前计数与生成后产物状态分开，状态同时提供文字，不使用整卡通过标志。

检查详情固定使用 `CanvasCardEditor` 的长表单 Modal，与人物表演和镜内活动共用尺寸规则，并复用表单外壳、轻量页签和 `WorkbenchDialogActions`。标题、公共配置、页签和当前页操作区固定，正文独立滚动；生成目标与检查模型在宽屏同排，窄屏上下排列。生成前类别行集中展示展开、数量和开关，条目展开后展示要求、来源、范围和最近结果。检查开关沿用中性灰，历史来源与固定依据按需展开。

关闭、Escape 和遮罩只退出详情，配置沿用画布保存机制，已受理检查继续更新。普通重开恢复会话中的页签、展开项和滚动，显式条目或报告入口优先定位，首次打开默认生成前检查。定位来源由来源编辑器替换当前 Modal，返回检查时继续阅读。窗口标题只显示必要的保存异常或只读，执行状态留在页脚和条目。

检查卡标题问题清单列出已有的逐项结论及待重查状态，包含单独执行且未纳入整卡检查的条目。查看检查报告进入指定报告与条目，并保留本次检查的结论边界、证据和固定依据。定位当前来源是单独操作，只在同一画布中仍存在明确字段时提供。最近一轮的生成后报告按产物位置提供独立入口，固定产物展开时读取本报告记录的文本或媒体。当前结果卡的缺失及依据变化使用同一问题清单，查看产物打开对应位置的只读阅读。

`generation-canvas-check-model` 覆盖卡面快捷执行、关闭详情后的进度、单项重查与历史阅读分离、超过四项的摘要、开关保留、只读及桌面／窄屏；`generation-canvas-post-check` 与 `generation-canvas-auto-check` 验证历史产物、复核和多产物自动报告。
