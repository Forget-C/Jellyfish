# 资产图片管理架构

资产库中的演员、场景、道具和服装共用图片卡片。列表用于快速浏览和发起默认生成，资产档案负责图片槽位、提示词和历史结果管理。卡片尺寸与响应式规则见[管理页面前端规范](../standards/management-ui.md#各页面的内容与操作)。

## 项目资源与对象参考

演员、场所、道具和服装保存在共享资产库，项目资源按项目关联展示；角色直接归属项目。工作台对象准备允许检索资产库的场所、道具和演员，确认选用时在同一事务中补齐项目关联并保存对象选择。浏览不会建立关联，选图非法时整次写入回滚；解除或更换本场绑定保留项目关联。原有项目资源页的手动关联入口继续可用。

人物选用演员后使用项目角色表达身份，不把演员直接当作角色。同一场次对象选用同一演员建立稳定角色身份；同名角色冲突时要求明确选择已有角色，不自动合并。角色组合编辑允许检索共享演员、服装和道具，保存时自动关联到项目，以组合内容摘要核对并发修改；重复保存同一目标可核实成功。组合是项目角色的共享设定，不新增造型层。保存失败保留输入，生成失败不撤销已保存组合。

对象可直接使用角色图、其关联演员的图片或该对象上传的图片；图片带原始资产、槽位和角度，不从文件排序推断视角。选用演员时默认正面优先，无正面图则使用其他可用图片，完全无图则留空。同角度按资产详情当前展示的槽位取默认，其他图片仍可手选。主动切换角度沿当前已选图片的原始资产来源选择，缺图时留空提示，不自动使用其他角度或跨来源采用尚未选用的角色图；手动选图可以明确切换来源。

默认选图只在选用演员或明确切换角度时执行；已选文件不会因刷新、生成完成或角色组合变化而自动替换。手选保持到再次切换演员或角度，切回原角度重新应用默认规则，不保存每角度手选记忆。明确采用的参考建立独立文件保护，图片槽位更新后原参考仍保留；更换、清除或移除对象时释放该处保护。角色图生成与本场参考选用分别操作，生成成功不自动替换对象或既有画布参考。画布内部仍从当前图片内容卡选择默认与镜头参考。

相关接口为 `objects/{object_id}` 的对象选择，以及 `characters/{character_id}/composition` 的组合读取和保存，均位于项目 directing 路由。参见[领域决策](../adr/0006-project-character-and-shared-assets.md)。

## 卡片行为

- 封面使用资产列表响应中的缩略图，缺少缩略图或加载失败时显示对应占位。名称打开资产档案。
- 卡片底部的生成入口优先使用正面槽位，没有正面槽位时使用第一个可用槽位。没有槽位才创建正面槽位。
- 生成先渲染槽位提示词，再通过既有接口创建图片生成任务。卡片使用任务中心的排队和运行状态防止重复提交，并读取本次发起任务的真实终态。成功后刷新资产列表。

## 多视角预览

点击卡片封面会打开图片预览。预览弹窗按需读取单个资产的图片列表，避免资产列表加载时为每张卡片额外请求图片。

- 预览默认选择正面图，若不存在则选择任一已生成图片。
- 弹窗只展示已绑定文件的图片视角，并提供正面、左侧、右侧、背面等切换按钮。
- 没有已生成图片时，弹窗显示空态。生成入口位于卡片底部。

## 职责边界

- 资产库提供封面浏览、默认生成、已有视角预览与编辑入口。
- 资产详情页：编辑资产元信息、管理图片槽位、调整提示词、查看和采用历史生成结果。

## 资产档案布局

演员、场景、道具、服装和角色编辑共用 `AssetEditPageBase`。资产库独立路由采用管理区的表单／图片双栏，项目角色与场次内嵌档案保留原档案骨架。具体尺寸、图片交互和验收依据见[管理页面前端规范](../standards/management-ui.md#资产库独立详情)。分类字段沿用 `AssetFactsFields`；长字段整行只在资产库详情启用。

独立详情读取档案与图片分别反馈状态。进入页面只读取已有图片；缺少视角时通过保存或明确的「准备图片视角」补齐。保存先更新档案并采用服务端响应作为基线，再补齐视角。后一步失败会标记部分成功，重试时先读取已有视角，只补缺失项；没有新的字段修改时不重复更新档案。生成或采用完成仅重新读取图片，避免覆盖用户随后编辑的档案字段。

独立详情的 `AssetDetailLeaveGuard` 处理站内路由、前进后退与浏览器原生离开提示。未保存修改、写入中的操作、进行中的智能检测以及部分保存失败均受保护。图片任务在服务端接收后可随页面离开继续运行；检测取消需要终态确认。内嵌档案继续注册到工作台的 `WorkspaceDrafts`，不会重复注册独立路由拦截。

名称、分类字段、补充描述、标签、视角数与风格参与修改判断；生成或采用前需先保存。视角数只增不减、最多四个。资产编号与完整描述按需展开，智能检测建议仍由用户明确采用到表单并保存。

## 分类设定与完整描述

演员、场景、道具、服装分别保存固定字段和 `supplementary_info`。固定字段允许未知值；创建草稿不要求填写全部属性。

| 类别 | 固定字段 |
| --- | --- |
| 演员 | 外观年龄、性别设定、体型、五官、肤色、发型发色 |
| 场景 | 场所类型、空间布局、环境特征、主要材质、色彩 |
| 道具 | 类型、外形结构、尺寸或相对尺度、材质、颜色 |
| 服装 | 类型、款式层次、材质、颜色、纹样与附属配饰 |

`description` 为后端按固定顺序派生的只读属性，不再单独存储。空字段和“不适用”不进入描述，补充信息完整保留。数据库检索使用同源表达式。分类字段 PATCH 未传表示不修改，传 null 表示清空；补充信息以空字符串清空。旧描述写入与跨类别字段被拒绝。

演员只保存身份外观，角色继续通过演员、服装、道具关系表达组合。角色图提示词读取关联资产的实际设定与参考图。分镜提取回填保留分类字段，角色草稿通过嵌套演员信息保留身份设定。

## 图片提示词规则

生成面板先读取保存后的资产事实，再按以下内容整理提示词：用途、主体设定、画风题材、当前视角、展示参数、参考图用途和本次要求。检索标签不自动写入提示词。

- 展示参数的优先级为本次设置、图片级覆盖、模板默认值；只允许构图、背景、灯光、细节强调和排除内容。
- 主体事实、资产画风、槽位视角和参考说明不能被图片级键值覆盖。
- 场景保留环境与布局；演员、道具和服装采用各自展示用途，不强制所有类别使用同一画面规范。
- 模板必须实际使用用途、描述、画风、题材、视角、参考说明与本次要求；缺少变量或遗漏必要内容时拒绝渲染。
- 未绑定数据库模板时使用同一内置契约模板；绑定了不匹配类别的模板时返回错误。

用户通过普通展示字段调整生成要求，最终提示词只读。修改展示要求后必须更新预览；提交使用预览中的提示词和有序媒体，不重新选择参考图。资产表单有未保存设定时需先保存。

提交快照保存模板版本、变量、渲染标识及实际输入。渲染元数据只用于重现，不作为授权或模板真实性证明；提交的提示词、参考图与该元数据不一致时拒绝。

## 参考图与局部修改

参考图先确定集合、校验文件及存储可访问性，再生成编号说明。未传参考集合使用推荐图，显式空集合表示不用参考图。每张图指定身份、服装、道具、布局、画风或主体设计用途；同一文件去重后保留多个用途，编号与最终媒体顺序一致。

生成面板支持从文件库选择或上传参考图并修改用途。演员侧背面默认参考正面图；角色组合按实际关联收集演员、服装和道具图。提示词不引用不存在的来源。

局部修改模式要求一张待修改图和明确修改项，并可填写保持项。`save_as_candidate` 让产物仅归档为待采用候选，原槽位不变；用户通过图片历史明确采用。普通生成继续自动采用，发布时同时核对资产类别、所属资产、槽位及版本，防止跨资产同编号写回。

## AI 整理建议

智能检测返回字段候选、缺失与冲突提示，不生成可直接覆盖整段设定的 `optimized_description`。每条候选标明原文提取或 AI 推断；原文提取必须提供存在于输入中的证据片段。字段范围、长度、重复项均被校验。

界面展示当前值、建议值和依据，只有明确采用才填入表单，保存后才生效。设定变化或恢复旧任务时先重新比较。引用存在不等于语义推断必然正确，仍由用户确认。

场次设计页负责六岗设计与确认，单元试拍页负责参考绑定与生成。任务中心不承载提示词或字段建议细节。

### 视觉结果边界

结构化字段和提示词快照用于核对已确认内容是否进入生成输入。供应商对视角、背景、构图和细节的还原由用户在资产页面验收。
