# 资产图片管理架构

资产库、项目资源和场次对象准备共用对象档案与图片能力。归属、引用与复制的决策见 [ADR 0007](../adr/0007-project-resource-ownership-and-library-copies.md)及[ADR 0008](../adr/0008-image-source-resources-and-project-imports.md)，展示约定见[管理页面前端规范](../standards/management-ui.md#资产库独立详情)。

## 归属与独立副本

演员、场景、道具、服装的 `project_id` 为空表示共享资产，非空表示项目专属；角色始终属于项目。项目列表展示自己的专属对象及已关联的共享资产，资产库只展示共享资产。历史共享对象不根据关联数量推断归属。名称按类别与归属范围唯一，数据库以 VIRTUAL `name_scope` 保证并发唯一性，兼容 MySQL 的项目删除级联外键。

存量共享关联只建立项目关系。新入口使用独立导入，见[图片来源决策](../adr/0008-image-source-resources-and-project-imports.md)。项目专属对象不能取消自身归属，只能删除；共享对象可以取消关联。共享对象在项目中只读，编辑入口在新标签页打开资产页。存量角色转化演员的资料、图片、主图及生成均只读；存在项目关联或对象直接参考时不能删除。

`POST /studio/entities/{type}/{id}/publish-to-library` 锁定项目来源、校验库中名称，复制名称、全部有效成员图片和独立文件，保留主图，通过 `library_copy_id` 核实重复请求。原对象保留，后续各自编辑，不复制参考链、任务和未采用候选。五类新入库均需要有效图片；新角色入库成为图片来源演员，其他类别同类入库，不复制设定。存量 `source_character_id` 标记对象仍整体只读。来源角色可删除，转化演员不会随之删除。删除库中副本会释放原对象的入库标记。

使用库图生成时直接引用文件；直接采用参考主体为主图时，`adopt-reference-main` 复制文件和图片记录。同一对象重复采用同一来源可核实原结果。复制的文件信息和存储内容独立于来源。

## 明确的对象参考

长期 `references` 保存具体文件、用途及对象来源的类别、身份、图片行和角度；上传图片不伪造来源对象。项目专属对象可选择当前项目对象、共享资产和上传图片；共享资产只能选择共享资产及上传图片。演员与角色互为主体，其他类别仅同类；一个主体可选多图，角色另可选择一项服装和多项道具。

来源对象与文件归属均在服务端验证。生成只读取当前对象事实及明确选择的图片，不递归读取来源组合或动态拼接来源文字。保存长期参考或提交临时生成参考均不建立项目关联、不自动复制，不回写长期配置。选择、取消、预览、应用设置和任务受理均不建立项目关联。

## 主图与视角文件夹

每个对象只有一张主图，可来自任意角度；首张有效图片自动成为主图，已有主图时生成结果只追加。更换主图立即保存，未保存对象设定时需先保存。删除或清空主图后，有其他有效图片时自动选择一张。场次和画布已明确采用的文件不会随主图变化。

默认展示正面、侧面（左侧）、俯视、背面文件夹，同一视角可保存多张图；历史右侧、细节等角度保留真实分类。生成任选一个或多个角度，空选默认正面，每个角度分别创建图片记录并受理任务，成功部分保留，失败角度单独重试。生成发布在对象锁内维护主图，并校验所属对象、图片身份和版本，避免过期任务覆盖手动操作。

资产卡片使用主图缩略图，缺图或加载失败显示占位。封面预览按需读取图片，默认主图，保留完整比例及视角选择。卡片的默认生成直接创建一张新的正面图片记录，沿用任务中心状态防止重复提交。

## 共用编辑内容

新建、详情及场次中的档案入口复用 `ResourceEditorDrawer` 的编辑内容，由 `ResourceEditorFrame` 分开承载容器。新建使用与详情标题栏及正文区域对齐的贴边滑入面板，保留顶部导航及侧栏的鼠标和键盘操作；窄屏按实际内容容器定位，保留导航入口。面板无全局遮罩和焦点锁定，覆盖的来源内容不可交互，外部点击不关闭，导航离开及关闭沿用未保存保护。抽屉实时跟随页面背景，使用不透明表面及连续的视口渐变，左侧存在相邻区域时以两端渐隐的柔和阴影分界，否则无外侧阴影；顶部左侧返回与标题、右侧操作，取消底栏与右上关闭入口；正文最大880px靠左，沿用详情页边距与内容分区，滚动时按需显示标题分隔。已有对象详情在页面正文展示，资产库保留独立路由，项目及场次保留当前地址，返回恢复来源列表状态。新建固定顶部标题与操作，详情在标题栏提供返回与主要操作；新建首屏只展示名称、关键识别属性和补充信息，详细设定、风格及参考按需展开，生成设置从顶部操作打开并替换正文；已有详情桌面左侧设定和参考、右侧图片，手机使用设定、参考、图片页签。参考选择、生成设置、主体采用确认、入库预览均替换当前编辑器正文。

仅创建与创建并生成都明确保存对象。仅创建成功关闭面板并刷新来源；创建并生成保留面板展示进度与结果，提供完整详情入口，已受理任务可关闭后继续。未生成而选择主体时，明确确认采用一张独立主图或仅创建不采用。提交失败保留草稿；对象已保存而后续场次关联失败时单独提示，重试核实原身份。图片刷新不覆盖表单设定。

`AssetDetailLeaveGuard` 处理独立路由、返回、关闭和浏览器原生离开保护；内嵌编辑器注册 `WorkspaceDrafts`，避免两个路由拦截器。未保存内容可保存、放弃或继续编辑；提交期间等待操作结束。智能检测取消必须等待终态，失败允许重试。服务端已受理的图片任务关闭后继续执行，任务中心恢复状态。

资产库已有演员、场景、道具和服装，以及项目资源五类已有详情使用共用的大图预览、横向缩略图带及生成Modal，具体展示与断点见[管理页面规范](../standards/management-ui.md#资产库分类资产详情)。资产事实保存与生成配置分离：参考、生产角度、附加及展示要求、所选模型只属于当前详情会话；取消生成Modal仍保留，离开详情、对象切换或刷新清空。图片模型通过统一提交请求的 `model_id` 明确传入，不写入资产。提示词草稿预览沿用现有Renderer契约，模型选择属于执行配置。局部修改继承源图视角，成功后直接新增图片；图片集合不再提供逐图候选按钮；旧候选数据保留在任务历史中。

`GET /film/tasks/asset-images/{entity_type}/{entity_id}/{image_id}/parameters` 支持演员、角色、场景、道具和服装，只读取当前图片文件对应、且任务类别与输入快照所属对象一致的图片任务；原演员专用接口保留兼容。投影当时模型名、时间、视角、参考数量、白名单展示要求及最终提示词，不返回供应商执行配置，不新增存储字段或补录历史。上传及无来源图片返回空，图片不存在或对象不匹配返回404。候选追加后可通过同一文件身份找到原任务；读取不按当前默认模型或当前演员字段推导历史。

## 提示词、临时设置与局部修改

生成以当前对象事实、风格、目标角度、展示参数、明确参考用途及附加要求构建提示词。展示参数仅接受构图、背景、灯光、细节强调、排除内容；主体事实与角度不可通过展示覆盖修改。模板须保留用途、描述、风格、视角、参考与附加要求，缺项或类别不匹配拒绝渲染。

生成设置仅在本次打开对象期间应用，取消恢复已应用设置，关闭恢复默认。附加要求常驻，展示参数折叠，显示固定默认图片模型。草稿预览 `POST /studio/generation-prompts/assets/draft/render` 不落库，逐角度只读预览随输入更新；提交重新渲染最新已保存事实与应用设置，冻结提示词、媒体顺序和审计元数据。审计快照用于重现，不作为授权凭据。

局部修改只接受一张明确图片和修改要求，可填写保持内容。每次为结果创建新的空图片记录，源图作为单张明确参考；成功后填入新记录，直接加入原视角文件夹，不替换原图、主图或视角默认图。旧任务的 `save_as_candidate` 历史仍可读取并明确追加。图片历史可读取候选并明确追加，历史分页使用服务端游标。

## 场次对象准备

提取卡片只表示自动发现的对象，不创建项目资源。新建入口将提取名称和描述传入同一抽屉；明确创建后进入项目资源并绑定当前卡片，取消不创建。也可明确复用已有同类项目对象，不以同名自动合并。

`objects/{object_id}` 只接受当前项目对象，并在首次绑定时默认使用其主图。场次图片可从对象成员中选择或明确上传，选中具体文件后建立文件使用保护。切角度按对象成员的真实角度与 `is_view_default` 选择，无图留空，不再回退到旧关联演员图片。角色组合接口与直接从演员自动创建角色的路径已移除。画布已采用的文件保持独立选择。

## 分类事实与智能检测

演员保存外观年龄、性别、体型、五官、肤色、发型发色；场景保存类型、布局、环境、材质、颜色；道具保存类型、结构、尺寸、材质、颜色；服装保存类型、层次、材质、颜色、纹样配饰。均有 `supplementary_info`，允许未知值。`description` 由分类字段派生，空字段不进入描述；PATCH 未传不修改、null 清空。

角色使用自身 `description`，没有旧演员、服装和道具组合外键。智能检测保留字段候选、缺失与冲突提示，区分原文提取与 AI 推断。建议需要明确采用到表单再保存；检测期间编辑受保护，设定变化后不能直接覆盖旧结果。

## 数据库切换与验证边界

迁移 `a714d2c98e31` 增加归属、参考、入库身份和主图，改为范围内名称唯一及同角度多图；清理旧角色组合关系与场次演员来源元数据，保留对象、成员图片、历史任务和场次具体文件。具体操作及不可逆回滚要求见[资产结构化切换](../guides/structured-asset-switch.md)。

API 和浏览器回归验证业务输入、复制隔离、任务受理、候选采用及交互；供应商成图对视角、构图和细节的还原仍需实际视觉验收。

## 视角默认图

五类对象图片使用 `is_view_default` 标记各视角的默认成员，与 `is_primary` 独立。图片创建、文件填入、清空、删除和生成发布都在父对象锁内维护每视角唯一选择。首张有效图自动成为默认，后续新增保留已有选择；PATCH `{ "is_view_default": true }` 明确切换，空图、取消标记及改变已确定视角被拒绝。删除或清空后按创建时间、ID补选同视角有效图。只读转化演员不允许调整，入库复制保留选择。

普通生成使用新空槽位，发布CAS要求文件仍为空，不能向已填充图片写回新结果。局部修改的源图与结果槽位分别表达，结果继承源图视角。引用仍固定具体文件，仅新选择按视角解析默认图。

迁移 `b8e4d1a9f602` 为五类图片新增默认标记，每视角优先现有主图，否则按创建时间与ID选最早有效图片；排除已删除及待删除文件，不改已有引用。缩略图带优先各视角默认图，图片集合内默认图首位，预览选择与默认身份独立。

## 图片来源与创建方式

`origin` 为 created、upload、library、project，另存来源类别和身份用于追溯，无来源外键级联。迁移 `c6e5a1b8d203` 为已有对象写入 created，不改变原字段或 `source_character_id` 权限。普通创建请求不能指定来源；`POST /studio/entities/{type}/image-source` 接收客户端请求身份、名称及上传列表或来源资产 ID，服务端决定来源和项目归属，同一次请求重试返回原对象，内容不同则冲突。角色导入仅从演员来源建立项目角色。

上传限资产库四类，每张图指定四个标准视角之一；首张为主图，各视角首张为默认图。独立导入支持项目五类，复制有效成员的文件与图片身份，保留主图和视角默认图，空槽位、旧候选、任务及基础设定不复制。失败回滚对象和成员写入。名称及当前范围唯一约束仍生效。字段 PATCH 仅允许改名，图片操作权限与档案权限分开。新对象删除继续遵守直接引用保护；来源元数据不阻止独立来源删除。

图片来源的生成默认明确选择当前主图，用户会话内覆盖后不随主图变化。没有有效主体参考时拒绝生成。临时风格默认使用项目风格或系统初始风格，可在生成 Modal 调整，仅写入任务快照；正式和草稿渲染都从已保存对象取得只读基础事实，不接受草稿注入。局部修改继续继承源图视角。

迁移回退在删列前检查是否已存在图片来源对象；若存在则拒绝删除来源元数据，需通过备份恢复回退，避免悄悄解除基础字段权限。升级与并发检查须使用显式配置的隔离 MySQL；SQLite 回归不代替真实 MySQL DDL 和行锁验证。

图片来源的基础风格在读取接口中返回空，不把旧表非空列的兼容默认值当作设定；基础风格筛选只匹配设定创建对象。生成默认风格单独从项目或系统选项解析，不回写基础字段。
