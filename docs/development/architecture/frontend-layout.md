# 前端基础布局

首页与项目列表的配色、尺寸、间距及交互验收见[首页与项目列表前端规范](../standards/home-project-ui.md)。管理区另见[管理页面前端规范](../standards/management-ui.md)。本文说明当前布局机制与页面职责。

## 应用壳

`MainLayout` 是路由共用入口。生成画布和场次画布使用各自的独立工作区及任务入口，与普通页面共用任务运行时。普通页面顶栏左侧是可返回首页的 Jellyfish 品牌，中央是首页、画布、项目、管理和实验室，右侧是任务入口与用户菜单。项目入口返回项目列表，个人设置通过用户菜单访问。

首页与项目列表不设固定左栏。进入具体项目、管理或实验室后，在当前页面显示对应的二级导航。手机顶栏分两行：第一行放品牌、任务和用户，第二行保持五个一级入口可见。导航依据当前路由显示选中状态，链接保留可读名称和键盘焦点。浏览器 `body` 不承担页面滚动。

首页先展示最近生成画布，再用等宽等高的面板展示项目进展和最近实验室会话，每侧最多三条真实记录。会话面板底部可打开文本、图片和视频实验草稿。桌面首页占用顶栏下的可用高度，空间不足时由面板列表滚动，标题及底部入口保持可见。窄屏按页面顺序纵向滚动。跨项目画布汇总使用标记明确的示例，真实项目和会话的读取失败单独反馈。

双栏下方展示最近资产。当前各分类接口缺少统一的更新时间响应，首页使用独立的本地示例并提供预览。桌面卡片保持单排，极矮窗口改用抽屉入口。窄屏沿页面展示全部示例。标题栏的「查看资产库」进入正式资产库。

项目列表使用单一卡片网格。紧凑工具栏将搜索、状态筛选和排序与批量入口放在标题旁。项目名统一链接至项目概览。封面用于展示，缺少封面时按项目 ID 选择默认构图。卡片固定展示名称、风格、代表章节和计数四行。该章场次数与项目总章数同排，已知更新时间与风格同排。章节读取失败时可在对应行重试。卡片上的删除入口需确认项目名称。项目配置在项目设置中使用现有项目更新接口显式保存。

`#root`、应用壳和主内容区均建立了明确的高度链，并在可收缩的 flex 容器上设置 `min-height: 0` 与 `min-width: 0`。这使子页面能正确计算 `height: 100%`，也避免长内容或宽表格撑破父级。

## 路由内容与滚动

路由出口由 `.app-route-viewport` 承载。它是普通页面的默认滚动边界：没有自行声明滚动容器的页面仍可纵向滚动，且超宽内容不会绘制到应用壳之外。

页面无需为常规列表、表单或详情页重复设置页面级 `overflow`。页面内需要横向查看的表格、代码块或素材带，应在其自身容器上显式使用 `overflow-x: auto`。

前端通过 `src/components/layout/PageLayout.tsx` 提供公共工具栏与工作台容器：

- `PageToolbar`：白色标题与操作栏，默认最小高度 64px、水平间距 16px，窄屏允许换行。
- `WorkspaceLayout`：建立满高、可收缩的工作台根节点。
- `WorkspaceScrollPanel`：作为自然高度内容的默认垂直滚动面板；它会隐藏意外的横向溢出。

布局组件的选用及局部滚动要求见[前端布局规范](../standards/development.md#前端布局)。

## 满高工作台

场次设计、单元试拍、模型管理等多栏工作台可以在根节点使用 `height: 100%`（Tailwind 的 `h-full`），并把滚动职责分配给实际需要滚动的面板。

- 工作台根节点：`height: 100%`、`min-height: 0`，通常为纵向 flex 容器。
- 可收缩的中间容器：必须保留 `min-height: 0`；横向分栏同时保留 `min-width: 0`。
- 单个可滚动面板：使用 `overflow: auto`；只应在需要裁切视觉素材或固定画布时使用 `overflow: hidden`。

全高的 Ant Design `Card` 应使用 `app-fill-card`，使 Card body 获得可分配的剩余高度；消息列表、表格等内容区再使用 `flex: 1`、`min-height: 0` 和 `overflow: auto` 成为唯一的局部滚动面板。

这样普通页面保持单一、可预期的滚动入口，而工作台仍能拥有独立的列表、画布和检查器滚动区。

## 上下文与任务

普通应用壳不呈现面包屑。资产详情通过无边框箭头返回有效来源，制作页使用相同模式返回明确上级；项目列表从一级菜单进入。保留既有路由解析能力，不将路径ID当作名称。

页面通过 `usePageTitle` 发布已经加载且身份与路由匹配的标题。`useNavigationTitles` 仅补取当前页面未读取的上级项目和章节名称；请求结果核对身份及项目归属，离开路由后的迟到结果不写入上下文。加载中使用中性名称，读取失败显示名称暂不可用；长路径或窄屏将上级收进菜单，当前标题截断时仍提供完整提示。

`TaskRuntimeProvider` 位于路由出口外，在页面切换时保持同一轮询实例。任务入口位于顶栏，数量只计算排队和运行中的任务；抽屉沿用当前页、运行中、最近结束、全部及任务类型筛选，保留取消、业务回跳和独立任务历史。运行状态与内容版本历史保持不同语义。用户菜单提供个人设置与语言切换。

## 主题与页面分栏

普通页面在应用壳内使用局部 Ant Design 主题。默认页面背景为雾蓝微渐变（`#F0F5FC` 至 `#F7F8FB`），内容表面为白色，主要操作使用 `#245FC5`，导航选中底色为 `#E4EDFB`。用留白、对齐和轻底色区分内容，表单与键盘焦点保留可辨识边界。用户菜单与个人设置共用外观偏好，可即时切换为雾蓝纯色（`#F7F8FB`），同一浏览器刷新后恢复。存储不可用时仍可在当前页面切换。独立画布继续使用原有主题和浮层样式。

- `ManagementLayout` 为五个二级入口提供共用领域左栏，小于 1024px 时通过导航抽屉访问。顶部“管理”首次打开模型管理，之后恢复浏览器记录的二级根页面。领域内容提供普通滚动边界。各管理列表使用 `PageToolbar` 保留页签和工具栏，再将内容滚动交给 `WorkspaceScrollPanel`。提示词在桌面分别滚动模板列表与正文，窄屏把正文放入阅读抽屉。模型分类与 Agent 类型从内容工具栏打开筛选，资产分类继续用页签和 `tab` 参数。资产库独立详情沿用原地址，使用紧凑工具栏与可收拢的表单／图片双栏，详情自身负责正文滚动；Agent 编辑页沿用原布局。
- 项目内部页的工具栏由 `ProjectToolbarProvider` 承载；已迁移的章节页通过 `ProjectContentToolbar` 把本页标题、计数、搜索和操作放入同一固定栏，正文不再重复标题。未迁移页保留原工具栏入口。尺寸与章节动作规则见[项目内部页前端规范](../standards/project-internal-ui.md)。
- 项目左栏显示项目名称和返回入口，按创作、项目资源、项目管理分组。项目入口、角色详情和章节场次列表共享项目上下文；小于 1024px 时通过项目导航抽屉访问。原有 `tab` 参数继续定位项目内容，独立生成画布不带项目左栏。项目概览和章节列表的场次操作进入独立工作台管理页；填写原文仍使用章节编辑器，待划分章节定位管理页的场次划分步骤。章节组合旧链接沿用停用提示与管理页重定向，不恢复旧抽屉。
- 工作台管理使用216px制作步骤侧栏（场次划分、对象参考、分镜画布），小于1024px改为步骤抽屉。对象和分镜采用两行工具栏：标题与场次切换在左侧相邻排列，按可用宽度展示最多三个连续场次，窄屏收敛为当前场次入口；全部场次通过可搜索、历史分组的纵向浮层选择，不占正文空间。第二行左侧筛选／搜索与数量、右侧当前动作，不重复继续下一步入口，正文分别承接划分编辑、对象准备或画布卡片；详情在当前内容区复用资产组件并恢复原位置与焦点。具体规则见[项目内部页面规范](../standards/project-internal-ui.md#制作流程导航与划分编辑)。
- 实验室左栏组合三类混排的最近会话及选择模态的新建菜单。小于 1024px 时从「会话导航」打开同一组内容。会话列表和消息历史各自滚动，输入区保持可达。极矮窗口由路由出口承接纵向滚动。标题、抽屉及交互要求见[实验室前端规范](../standards/experiment-lab-ui.md)。
- Agent 编辑页的参数区默认 344px；手机端上下排列并可滚动。资产编辑保留自身长表单与图片工作区。
- 当前场次入口使用 `SceneCanvasWorkbench`，准备页展示已确认的场次摘录、对象准备和本场画布列表，编辑页挂载 `GenerationCanvasWorkspace`。节点位置和缩放按画布身份保存于浏览器；节点标题把手可拖动或用方向键移动。旧阶段路由及宿主已退役，不提供兼容入口。
- 业务抽屉中触发的离开保护对话框显示于抽屉之上；关闭接缝抽屉不销毁未保存输入。当前控件验收遵循[工作台设计标准](../standards/workbench-design.md)。


场次四画布使用局部中性黑灰主题：近黑点阵背景、深灰节点与弱描边；新增工作台动作采用中性灰层级，蓝色用于链接与键盘焦点，不改变其他页面的浅色主题。节点名称统一放在外部标题栏，长原文及叙事内容可展开，指令默认使用紧凑正文区、聚焦或明确展开后编辑。镜头列表在选择区展开，节点默认保留当前镜头摘要；媒体预览、检查问题及其处理入口继续显示。

工作台普通选择状态（六岗栏目、镜头选择、关系树与总览、设计建议范围、下拉选项及任务过滤）使用中性灰底与亮文字；主操作采用较亮灰底，键盘焦点保留蓝色；通用按钮样式不覆盖危险操作、来源链接及禁用态。顶部入口与弹窗统一命名为“AI 设计”，入口采用 20px 魔棒星芒图标、38px 高灰阶按钮。弹窗按准备、生成中、查看结果展示：准备时分区展示原文摘要与设计要求，原文在同一文本区原位展开／收起，仅超过四行时提供入口，历史记录按需展开；辅助入口使用图标与短标签，“发起新设计”为带加号的次级按钮，结果依据中的原文与设计要求分区，空要求以标题旁“未填写”标记；生成中展示真实任务状态，后台刷新不插入加载节点，刷新失败保留旧内容并在固定状态区提供重试；结果展示六岗摘要、变更与应用前校验。弹窗采用暗灰细滚动条，正文预留滚动条空间并承担主要纵向滚动；生成和应用是底部右侧的灰阶主动作，关闭为次要操作。首次主动作是“生成场次设计”，局部入口为“只设计部分内容”；当前设计已有正文或人工对象时使用“重新生成整场／调整部分设计”。该判断不依赖 AI 历史记录。局部仍仅生成已有字段，不新增对象或改变引用。生成结果不自动应用，保留原请求核实、冲突检查与手动整次应用流程。版本与任务入口使用统一的小箭头及间距。工作台任务计数统计排队与运行任务，0 时隐藏，超过 99 显示 `99+`，可访问标签保留完整数字；全站其他页面沿用原有计数外观。任务抽屉及卡片使用局部暗色样式，状态标签保留语义色。

顶部按场次身份／版本保存、四画布切换、当前画布主操作／任务／关系导航／更多分组。新建与另存为归入版本菜单，自动保存开关归入保存设置，导出尺寸与记录归入导出面板；导演设计、单元准备、指令检查和剪辑导出分别显示当前操作。菜单只切换可见性，任务组件持续挂载；关键保存、导出和交付错误仍有外部提示与恢复入口。前进／后退位于顶部，独立面包屑紧贴其下靠左覆盖节点与连线，不计入视口高度；下方筛选横条与面包屑左对齐并留边悬浮、右端收起，收起时显示搜索图标入口，无标题行且只承载实际条件。收起偏好按画布类型在浏览器记忆，不影响视角或节点布局。左下角集中节点定位与缩放，右下角保留撤销和重做；其左侧显示当前画布的非阻断状态，窄屏改到按钮上方且小地图避让。导演总览统计仅显示非零待归镜头与未关联设计计数，准备状态和明确错误入口继续保留顶部。

桌面顶部紧凑排列，较窄屏幕按分组换行，实际高度由 `ResizeObserver` 写入工作台局部 CSS 变量。画布、关系导航和快捷编辑据此让出顶部空间，主操作位于顶部操作组内；尺寸选择与检查反馈不改变业务内容或节点布局记录。

关系树初始收起，入口位于顶部，和六岗关系导航、轻量字段编辑共用右侧区域，同一时间只呈现一种侧栏。侧栏悬浮覆盖画布，开关不收窄画布、不自动平移或缩放，也不重排节点；主动定位与适应画布仍执行各自的导航动作。切换侧栏保留已输入的未保存内容。六岗设计、原文差异和历史记录继续使用宽弹窗，并沿用同一深色外观。

场次画布的保存与恢复错误横幅独立占位，按实际高度向下调整主操作和画布工作区；多条或长提示在限制高度内滚动，不能遮挡失败后的重试入口。

场次画布的视频与指令活动使用同一个可滚动通知容器，保留各任务身份及主动回跳入口。长任务身份可换行；窄屏通知与底部定位／缩放控件分开，关闭与回跳操作保持在视口内。

工作台共享外观由 `src/components/workbench/` 中的 `WorkbenchTheme`、`WorkbenchButton`、`WorkbenchIconButton`、`WorkbenchModal` 和 `WorkbenchDialogActions` 提供。同目录的 `CanvasTextPreview` 按正文真实行数展开。主题局部覆盖画布、portal 弹窗与任务抽屉，全站任务中心保留原主题。开发环境的 `/dev/workbench-ui` 展示真实组件状态，检查入口为 `test:workbench-ui`。共享组件的适用范围和现存例外见[工作台前端设计标准](../standards/workbench-design.md)。

工作台管理的分镜与画布步骤将生成新分镜画布作为主动作，新建空白画布归入更多菜单；创建仍使用原有受未提交配置保护的内联配置区，不改变提交与核实请求身份。画布列表以白色12px圆角表面、16px内部留白呈现名称、真实任务状态与打开入口；来源变化、候选核对、失败及恢复仍可见。卡片菜单先关闭再打开后续编辑或任务详情，任务详情关闭恢复对应菜单触发焦点。任务详情仅统一普通页面外层样式，长正文在可用视口内滚动，底部操作保持可达；这些规则不影响独立画布及其内部浮层。

项目普通页面与工作台管理不再显示应用壳面包屑。项目侧栏只承担项目身份与菜单，项目列表通过一级菜单进入；制作页使用资产详情式左箭头返回明确上级，遵循现有草稿离开保护，完整规范见[项目内部页规范](../standards/project-internal-ui.md)。

## 普通列表内容区宽度

项目列表、资产库、项目资源、对象参考及分镜画布列表共用两种布局规则。同一应用可用宽度 V 下，无左侧菜单的正文宽度为 V − 2P，有左侧菜单为 V − S − 2P。P 由应用壳 `--app-page-gutter` 统一提供（桌面20px，767px及以下16px），S 由 `--app-sidebar-width` 提供（216px）。1024px以下菜单变为覆盖式抽屉，按无菜单场景计算。宽度指 CSS 像素，实际可用尺寸需扣除占位滚动条；不以截图物理像素或屏幕分辨率计算。

布局通过现有 Flex 容器分配剩余空间，正文只扣一次左右边距，不在各页重复计算视口宽度，也不新增 JavaScript 测量。相同窗口与菜单状态下，普通列表正文边界一致。右侧常驻面板、局部分栏或额外内边距由所属容器占位，网格按其实际可用宽度减列；覆盖式抽屉和弹窗不扣正文宽度，顶部工具栏仅影响高度。独立画布和媒体文件专属网格不套用卡片规格。

卡片固定的是同一窗口下的等宽列，不是跨窗口不变的像素宽度。网格使用 `repeat(列数, minmax(0, 1fr))`、统一16px间距，列数不随内容或数据数量变化；卡宽等于（内容宽度 − 总间距）÷ 列数。少量卡片与末行保留空列，不使用 auto-fit。满行横向铺满内容区，无固定像素卡宽带来的额外尾部余量。

应用壳统一提供三组列数变量：资产库及项目资源使用 `--app-media-card-columns`，沿用文件管理480／768／1024／1280px对应2／3／4／6列，默认1列；对象参考及项目列表使用 `--app-object-card-columns`；分镜画布列表使用 `--app-canvas-card-columns`。断点按视口 CSS 宽度计算：

| 视口宽度 | 对象参考／项目列表列数 | 分镜画布列数 |
| --- | --- | --- |
| <576px | 1 | 1 |
| 576–767px | 2 | 1 |
| 768–839px | 2 | 2 |

## 资源选择抽屉

项目资源从资产库导入、对象参考普通选用和同名选用统一使用 `ResourceSelectionDrawer`。组件通过 `ResourceEditorFrame` 提供最大720px宽的抽屉，负责来源查询、搜索分页、卡片选择、图片读取与预览、副本名称及离开保护；标题、操作和搜索区固定，候选与已选详情共用一个滚动区。

三个入口通过 import／select／same-name 模式复用体验，最终提交留在调用方：项目导入创建副本并刷新，对象选用直接绑定项目资源或先导入副本再绑定。提交结果中的 created 表示副本已创建，后续失败锁定来源；调用方保留已创建ID，重试仅刷新或绑定，不重复创建。上传表单独立，不参与资源查询。搜索与翻页保留选择和副本名称，切换来源清空选择；关闭会话后不保留临时输入。
