# 场次版本架构

> 旧四画布前端和旧场次版本 HTTP 接口均已退役。本文记录存量数据契约及历史实现。当前可用入口见[退役范围](directing-foundation.md#旧四画布退役范围)。剪辑源码仅作[实现参考](../../../front/reference/retired-scene-edit/README.md)，不纳入生产构建和常规测试。


本页记录存量场次版本的数据契约，以及已退役宿主的保存、恢复与另存为历史行为。当前场次的默认入口及共同画布保存见[场次入口与旧版记录](directing-foundation.md#场次入口与旧版记录)。章节快照见[章节划分架构](chapter-division.md)，产品语义见[章节划分与场次版本设计](../design/chapter-and-scene-versions.md)。

## 身份、存储与来源

`directing_scene_versions` 保存用户明确创建的场次方案；`id` 是方案身份，`revision` 只作 CAS 保存比较，不是可选择的保存历史。当前内容包含明确选定的原文依据、允许空镜头的强类型六岗设计、可编辑生产单元与输出画幅。人工镜头可以暂未分配节拍，但已填写引用必须存在；固定执行契约仍保留完整设计约束。只接受当前章节真实摘录或该方案已经核实的依据；`source_bases` 保存这些来源证据以支持撤销与旧字段引用，不构成逐次保存历史。原字段来源不随依据选择被重绑。保存与创建经过 `DirectingStore`，校验已填身份、局部关联、项目资产及来源文件，文件引用与正文在同一事务内更新。

`/projects/{project_id}/directing/sequences/{sequence_id}/versions` 提供列出和明确创建，具体版本提供读取和保存。重复创建复用请求身份；保存保留最近成功请求身份，重复相同保存不递增 CAS，旧基准或同请求改内容返回冲突。浏览不创建方案，保存不生成分层版本或业务任务。

明确新建从空方案开始。退役前的旧宿主在未指定版本时打开最近实际编辑的场次版本，浏览或仅新建不改变这一选择；该前端选择逻辑与旧链接现已移除。章节原文修订只在受影响版本内提示，明确选定新段落才更新该版本依据。重新划分保留身份时不改写场次方案；退出身份只读，新身份不自动继承方案。最近工作入口不改变章节当前使用的固定交付。

## 保存契约与旧编辑恢复参考

手动保存和默认开启的自动保存使用同一串行保存队列；自动保存每五秒检查一次，输入、响应和失败不会重置周期。保存可接受未完成方案，已填写的身份、范围、引用与文件仍须通过服务端校验。响应必须匹配请求、提交内容、版本和关系图修订，只推进已确认基线，保留后续输入。普通失败沿用原请求重试，校验错误等待修正，409 冲突保留输入并等待明确处理，不以当前编辑内容覆盖服务端基线。未知提交结果先核实原请求，同一请求不换身份或内容。

同版本切换画布不丢弃输入；跨版本或离开先处理未保存内容及在途请求。撤销与重做按场次版本隔离，保存不清空页面会话历史；撤销已保存的操作会形成新的修改。浏览器持久保留一份未保存编辑现场，刷新先核实在途保存，再按真实基线恢复剩余输入及该段撤销能力。无法确认基线时不盲目重放，本地写入失败保留页面输入并提示保存。历史详情只读；查看不切换当前版本或触发任务。

同一浏览器使用排他锁协调工作台编辑权。交接前先保存或明确放弃旧页输入；旧页未响应时不能仅因超时抢占，旧页关闭后先核对恢复现场。无法使用浏览器恢复能力时不宣称未保存内容已受保护。

## 另存为与记录隔离

整份另存接口在章节锁内重新检查关联设计、指令、检查和视频任务的明确终态，复制点击时内容且不额外保存原版本。独立复制来源账本保留创建请求身份及内容，检查依据仅可沿明确复制链引用，实际执行版本不改写。前端另存期间锁定工作台，已有保存先核实，未知创建结果刷新后重放原请求。设计建议原提交请求同样先持久化，提交未知时阻止另存；成功建议不要求先应用。另存账本另固定单素材审查、接缝与整场审片记录身份；读取和章节交付可引用适用的原记录，保留原版本与原时间，并按副本内容重新核对适用性，不吸收原版本后来新增的审查。连续另存保留这批固定身份，副本新判断独立记录。导出任务已纳入同版本另存检查，运行中的关联导出同样阻止另存。

复制形成独立可编辑内容，共享媒体文件与真实执行来源，不复制或重跑原任务。当前素材判断和时间线后续独立编辑。复制时固定可引用的原判断记录，按副本的实际内容核对适用性。版本创建迁移只建结构，不自动拼装旧数据；固定 revision 的设计、执行和素材仍按既有契约使用。
