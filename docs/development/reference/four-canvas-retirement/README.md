# 旧四画布退役清单

> 本文记录旧接口下线时的清单。空库初始基线的存储和执行边界见 [ADR 0014 的新基线说明](../../adr/0014-retire-scene-version-api.md#从空库初始化的新基线)。

该阶段退役了导演、单元、指令、剪辑 **4 种旧画布模式**及其专属宿主，移除了 **48 个 HTTP 操作**。场次制作的现行入口是场次工作台管理页及其打开的分镜画布。该阶段为当时的存量部署保留了历史任务结果、交付记录和受引用的文件。退役决策和当前入口分别见 [ADR 0014](../../adr/0014-retire-scene-version-api.md) 和[场次工作台架构](../../architecture/directing-foundation.md#旧四画布退役范围)。

## 功能清单

| 范围 | 退役内容 | 旧接口下线时的行为 |
| --- | --- | --- |
| 前端入口与画布 | 移除裸场次路径 `/projects/:projectId/chapters/:chapterId/sequences/:sequenceId` 的宿主、旧任务业务跳转，以及方案编辑、单元组织、指令核对和批量拍摄流程 | 裸场次 URL 按未匹配路由处理。工作台管理页、带 `/canvas-workbench` 后缀的分镜画布、独立自由画布、最近工作读取继续使用 |
| 剪辑与交付 | 退役旧审片、时间线剪辑、整场预览、导出及交付查询入口 | 9 份剪辑组件以 `.tsx.txt` 存放，无生产引用，供后续实现参考。历史导出、交付记录及其文件引用继续受保护。[剪辑参考目录](../../../../front/reference/retired-scene-edit/README.md) |
| HTTP 服务 | 场次版本树下移除 46 个操作，涵盖版本、设计建议、单元与指令、视频、Take、审片、导出和交付提交。另移除章节当前交付和场次交付历史两条 GET 查询 | 同步收缩 OpenAPI 和生成客户端。旧地址无兼容端点或重定向，仍注册的生产计划接口继续服务 |
| 后端图投影与任务执行 | 移除旧四图的投影、聚合关系图、预览和专属编辑分支。禁止提交和执行 `scene_export`、`directing_unit_design`、`directing_instruction`、`directing_instruction_check`。另按 `scene_video` 目标或带 `scene_design` 快照标记的 `directing_design` 识别旧任务 | Worker 可领取并终止存量旧任务，在供应商调用前结束。生产计划提交的现行 `directing_design` 继续执行。项目任务详情仍能读取 `scene_design`、`scene_instruction`、`instruction_check` 类型化历史结果 |
| 共用函数与类 | 清理布局参数 `validViewIds`、`identityAliases`、`onInvalidTarget`、`parseView`、`migrate` 及其专属分支，清理后端旧局部修订执行逻辑 | 导演任务查询从 `DirectingAIService.read_task` 拆至 `read_directing_task`。共享异常 `DirectingOutputError` 和契约 `DirectingOutputDiagnostics` 归入错误模块与诊断契约模块，审查、修正和提示词失败按各自阶段标记，历史诊断仍读取 `output` 和 `issues` |

两端合计**净减 960 个函数或方法定义、126 个类定义**。前端对 `front/src` 下的 TS/TSX 做语法树统计，排除 `services/generated`，计入函数声明、方法声明、变量直接绑定的箭头函数或函数表达式及具名类声明。后端对 `backend/app` 的 Python 语法树统计同步和异步函数以及类定义。两端均含嵌套声明，排除匿名回调。

[函数与类清单](symbols.tsv)按语言、类型和声明名汇总次数。每个名字分别算减少和增加，再合计净值。同名定义跨文件迁移可能抵消，改名可能同时产生一减一增，移入剪辑参考目录也会减少生产定义数。因此 963 个按名称减少的函数定义不能换算成 963 项业务功能。附件列出净次数变化的每个名字及候选文件；减少项的路径取自基线，增加项取自终点，多处同名时列出相应方向上次数变化的文件。
