# 分镜生成前拍摄准备的归属与固定采用

2026-11-17，完整方案已最终确认，已在本地实现。概念见[术语表](../../../GLOSSARY.md)。

## 检查与说明的边界

检查在场次划分页面进行，发生在新分镜画布生成之前，目标画布和镜头尚不存在。检查依据场次实际采用的原文及生成输入，识别影响剧情理解、动作成立或重要表现意图的站位、路线、人物视线与镜头可见性问题，以及需要提前解释的状态连续性，不能验证尚不存在的镜头方案。

结果区分有依据的明确冲突、关键安排待明确和可选设计建议；普通可行拍法交由生成过程决定，不要求用户补齐全部细节，不把假设的站位或镜头当作已有事实。正常出画、有依据的省略、时间跳跃和刻意遮挡不直接构成问题；人物未入镜不等于离场，省略动作过程不等于动作未发生。

用户确认的补充内容统一称为“场次拍摄说明”，是随场次提供的参考依据或解释，不是必须逐条满足的执行约束，不据此设置生成验收门槛。它与章节的原文补充解释、逐字原文事实分别表达。检查可提示说明与原文或彼此之间的矛盾，但不自动改写说明、原文或章节解释，不自动撤销用户选择或阻止生成。

用户可以采用或修改建议、交由生成设计，或暂不处理继续生成。采用表示纳入生成参考，不表示必须逐条执行；未采用的候选不作为生成指令，未解决项不冒充已确认安排。原文含义问题另行提示，不用拍摄方案代替原意澄清。

## 入口与编辑

在场次划分页面“本章场次”列表中，于场次标题编辑图标右侧增加“拍摄准备”图标。点击打开对应场次的 Modal，不立即调用 AI。弹窗包含可展开的实际原文依据、“场次拍摄说明”编辑与采用选择、主动检查与建议处理、报告及检查状态；默认展示已有说明。

用户可以不经 AI 检查直接新增、编辑或删除说明。保存不自动调用 AI；主动检查读取原文及当前说明，结果不自动覆盖用户编辑。未保存的新场次也可打开弹窗，有明确原文范围即可检查。历史版本只读查看，不编辑或重新检查。

分镜生成页面展示采用内容并提供返回编辑入口，不维护另一套准备内容；未执行检查也可直接生成，不强制每次重复检查。

## 存储与版本归属

生成前尚无目标画布，说明属于具体场次的创作准备，因此在场次记录新增独立 JSON 字段 `shooting_preparation` 保存当前准备内容，不放入章节补充解释或只留在浏览器。首版不为每个条目建立独立表。

每次 AI 检查的原始输入与报告保留在检查任务中；场次准备保存用户编辑的说明、原文片段或全场范围、来源及采用、交由生成设计、暂不处理等选择，并记录所依据的内容和准备修订。原始报告与用户确认内容分别保留，重新检查不直接覆盖用户编辑。

场次拍摄说明随场次进入章节划分版本，仅修改说明也形成新版本。复用的是 `directing_division_versions` 的不可变整章快照，不是旧版场次方案版本；需要扩展草稿、差异预览、保存、快照及恢复契约，单加场次字段不会自动纳入版本。

保存路径按当前场次是否有未保存的划分改动判断，而非仅按是否已有数据库身份：

- 新场次或已有场次的范围、名称等划分改动尚未保存时，说明先进入场次草稿；页面“保存为新版本”将场次及说明在同一事务内保存。
- 当前场次仍与已保存的划分内容一致时，在 Modal 点击保存立即持久化说明，并形成新的章节划分版本，不再要求回页面重复保存。
- 仅其他场次存在草稿改动，不阻止当前场次保存，也不得连带提交或丢弃其他场次草稿。

每次有效保存记录对应检查报告及覆盖状态。最终保存内容与受检内容一致时记录适用报告；不一致时保留报告来源，标明该版本内容尚未完整检查，不强制重查或阻止生成。旧版本及其报告保持原样。无变化保存和相同请求重试不创建重复版本；保存前草稿编辑不等于已形成正式版本。

历史查看和恢复采用当时的说明，不混入最新准备内容，不回退已有画布。旧版本缺少说明时按空说明处理；空说明是正常情况，读取、保存、恢复和生成均须兼容，不增加专门警告或复核门槛。

## 分镜生成采用

分镜生成采用已保存场次中标为采用的全部说明，不提供单次生成的临时勾选。修改说明须回到准备区保存新版本；交由生成设计的项目传递问题及已知边界，暂不处理的建议不作为指令。未保存草稿不能直接用于生成。

完整分镜与忠实提取均使用这些场次说明，不将其视为模型自行新增设计，不提示切换模式，也不静默忽略；说明与逐字原文摘录分别标注来源，不伪造原文出处。

提交生成时，实际采用的说明固定到生成任务输入快照和新画布文档的独立区域。场次准备内容后来修改不回写已提交任务或已有画布。这增加了快照管理成本，但兼顾生成前恢复编辑与每份画布依据可追溯，避免共享场次准备内容悄悄改变历史方案。

## 原文选择与划分变化

章节正文变化不直接改写已有场次，也不单独触发该场次说明失效。已有场次进入划分、且原文变化时，提示“原文有变动，是否使用最新原文”，允许选择使用或不使用。

选择不使用时继续沿用原版本依据，不强制为编辑说明而采用最新原文。选择使用时保留现有场次作为编辑起点，在最新原文上核对范围；唯一且准确匹配的原摘录可定位，内容变化或多处匹配须用户重新定位、调整，或主动发起智能划分，不直接沿用旧坐标。选择本身不调用 AI、不立即保存覆盖原版本；核对并保存后才形成采用新原文的新版本。

仅改名或调整顺序保留说明采用状态。实际改变场次原文内容或范围时，相关说明保留内容和来源并转为待复核；拆分、合并展示来源说明，由用户确认归属、修改或删除，不自动复制为各场已采用。复核前不作为生成指令，不阻止保存或生成。

原有划分编辑和保存按最新章节正文校验；本轮在固定场次摘录的基础上增加上述新旧原文选择流程。生成依据校验也仍包含当前章节版本和有效解释。实施时需保持实际输入与报告覆盖状态一致，不能将已有生成校验令牌的变化直接等同于场次说明失效，历史解释与对象准备仍按原有契约处理。

## 范围限制

本决定只涉及生成前的场次拍摄检查、说明维护、版本保存及分镜输入传递。不包含生成后的分镜审查扩展，也不恢复此前暂停的非法字段约束、错误提示与自动纠错故障修复。方案确认不构成实施授权。
