# 生成画布独立归属与场次隔离

2026-11-17：入口、归属、生命周期、卡片分类及前后端能力约束方案已确认，已在独立工作树实施，尚未部署；存量清理入口已提供，未对现有数据库执行升级或清理。

生成画布成为独立于项目和场次的自由创作空间，以一级菜单“画布”提供卡片展示与新建入口。场次画布继续归属项目和场次，自由画布入口不再读取或编辑场次画布。两者共享卡片、关系校验、编辑保存和生成执行能力，分镜提取、原文依据、审查与采用由场次业务层处理。

这一方向调整 [ADR 0001](0001-independent-generation-canvas.md) 的项目归属，并替代 [ADR 0005](0005-shared-canvas-foundation.md) 允许从生成画布入口编辑场次原文档的决定；共享共同画布基础的决定继续保留。选择业务归属隔离和共同能力复用，是为了让自由创作无需项目上下文，又避免两套编辑和生成规则长期分化。代价是需要同步解除文件引用、任务、恢复和导航对项目身份的依赖，仅移动菜单不足以完成独立化。

画布上传及生成的图片、视频、音频文件直接进入文件管理，本期不提供同步到资产库的功能，也不因本次归属调整增加新的媒体生成能力。文本继续保留在画布和运行历史中，不自动生成文本文件。

文件与画布分别管理生命周期：删除画布清理文档和专属运行记录并释放对应文件引用，上传及生成文件继续保留，由用户在文件管理显式删除。画布当前内容或历史仍引用的文件受到删除保护；有活动运行的画布不能删除。这使用户整理画布时不丢失已有媒体成果，代价是删除画布后仍需在文件管理按需清理文件。

自由画布允许直接上传，或从文件管理选择当前用户有权访问且媒体类型匹配的文件。多张画布可以引用同一文件，不因此复制文件；不直接接入项目角色、场所等业务对象。项目产出的媒体若在文件管理可选，也可作为普通文件使用。两类画布本期不提供整图复制、相互转换或跨画布动态引用，通过文件管理复用媒体。

一级画布列表提供新建、名称搜索、分页、重命名及删除。卡片展示封面、名称和更新时间，默认按最近更新排序；新建或点击卡片进入对应编辑器，返回时回到画布列表。首版不增加文件夹、标签、收藏和整图复制。

新建沿用一键创建“未命名画布”并进入编辑器，不增加创建前配置弹窗。名称允许重复，但不能全为空白，最长 255 字；列表和编辑器均可重命名。无封面时显示统一占位图，由用户在编辑器选择图片显式设为封面，列表负责展示；不自动使用第一张生成图片，本期不增加列表上传封面的入口。

已有自由画布允许丢弃，不提供迁移或旧接口、旧路径兼容逻辑。清理范围包括旧自由画布文档、保存回执、专属运行结果、检查报告、事件及对应文件引用；上传和生成文件保留在文件管理，其他业务引用保持完整。场次画布及其记录保留。清理前要求相关任务全部结束，发现活动任务则停止清理，不强行删除。

自由画布与分镜画布继续共用任务中心，任务来源和导航按实际归属区分。自由画布任务返回对应独立画布及运行，分镜任务返回所属场次。删除画布后保留通用任务历史，显示“画布已删除”，保留仍可读取的任务信息并关闭返回画布入口，不恢复已删除的画布专属运行记录。此规则同时适用于旧自由画布清理与正常删除。

独立画布继续使用全局默认模型，参数和画幅由卡片配置；本次不增加画布级默认模型、统一画幅或统一风格设置。复用现有配置语义可减少独立化附带的新状态，避免引入画布配置与卡片配置之间的隐式覆盖关系。

卡片范围按现有界面分类划分：自由画布保留“基础卡”“参考卡”“模型生成”三类；“画面设计”“表演与调度”“叙事与镜头”“声音设计”“连续性与约束”“检查”六类仅在分镜画布开放。分镜画布同时保留前三类共同能力。

“基础卡”包括文本、图片、视频、音频内容卡、原文／创作依据卡，以及人物、场所、道具、服装描述卡；“参考卡”包括对应的四种对象参考卡；“模型生成”包括文本、图片、视频模型卡。自由画布中的对象描述和参考仍由用户在画布内组织，不因此接入项目资产或场次对象来源；创作依据卡也不因此取得章节／场次的固定原文关联。自由画布在普通文本和提示词中表达风格要求，不提供风格设计卡。[ADR 0003](0003-generation-canvas-check-cards.md) 的检查卡行为继续用于分镜画布，自由画布保留输入、模型能力和引用有效性等必要校验，不提供检查卡及其报告流程。

共享卡片实现、编辑器及执行基础，由后端按真实画布归属维护明确的允许类型集合，对外返回对应卡片目录和连接规则。前端据此开放分类、新建、粘贴和恢复，后端在保存、编译和运行入口复用同一能力约束；禁止类型应明确报错，不静默删除或转换。此方案可防止仅隐藏入口后通过粘贴或请求写入分镜专属卡片，无需复制两套卡片实现或建设通用插件系统。
