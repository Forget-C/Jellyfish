# 退役旧场次版本 HTTP 接口

旧四画布前端已退役，现行分镜画布使用独立的画布身份和保存接口。已确认将项目 directing 路由中 `/sequences/{sequence_id}/versions` 及其子路径的 46 个 HTTP 操作全部移除，并同步更新 OpenAPI 和生成客户端。更早的生产计划接口另案评估。

切换后，旧客户端将失去通过这些地址编辑、查询历史、访问素材与导出记录、核实已提交请求或重试的能力。接受这一契约变更，无兼容端点或重定向。切换前核对可取得的访问记录及已知外部集成，发现实际调用时单独决定对应操作的移除时间。

切换时直接移除旧接口和仅供旧场次版本任务使用的执行逻辑，无需等待排队中或执行中的旧任务结束。这些任务可能无法完成。现行分镜画布和其他任务仍使用的共享执行逻辑继续保留。

保留历史任务记录、已生成的导出成品及其 `scene-export:<task.id>` 文件引用。旧导出的专用删除接口随本次退役移除。由于通用文件管理无法解除这类引用，用户将无法从文件管理中删除仍受引用保护的历史成品。

本工作树已移除旧场次版本 HTTP 接口，并同步 OpenAPI 和生成客户端。当前仓库状态见[场次工作台架构](../architecture/directing-foundation.md#旧四画布退役范围)。
