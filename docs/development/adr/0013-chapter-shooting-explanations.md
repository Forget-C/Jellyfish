# 拍摄解释按章节原文版本维护

[ADR 0012](0012-pre-generation-shooting-preparation.md) 记录原有的逐场维护方式。场次拆分或合并并不改变对应段落的拍摄含义，因此将解释归到章节原文版本，在划分页面通过「拍摄解释」统一维护，弹窗标题为「本章拍摄解释」。无场次也可编辑；只改解释不产生划分版本。

一条解释可适用于全章或一段连续原文。用来支持解释的引文和解释适用的范围可以不同。空间关系、动作、状态和用户选定的拍法都是生成参考，不写回原文，也不构成分镜验收条件。

用户可以手动填写，也可以主动分析整章原文及已有拍摄解释。分析围绕创作者对人物路线、具体动作和空间关系的已有预期，区分原文可支持的解释、待判断的问题和可选拍法。用户在差异弹窗逐项核对新增和修改建议，将选中项加入抽屉草稿，再统一保存。

沿用旧原文的场次继续使用对应版本的解释。选择新版原文时，局部解释只有在适用范围及引用依据均未改变且可唯一定位时才直接继承；其余局部条目以及全章通用条目保留待复核。待复核条目不参与新版生成，不阻止生成，也不改变旧版解释。

弹窗标明当前使用的原文依据，独立保存该版原文的解释，不提交或丢弃划分草稿。生成新分镜画布前展示该版原文的全章通用解释及适用范围与本场相交的局部解释，按采用选择传递；忠实提取和完整分镜使用同一规则。已提交任务与已有画布保留当时实际使用的解释，已有画布重新提取也使用其固定依据。

恢复历史划分只恢复场次及其原文依据，不回退拍摄解释。新建画布读取对应原文版本最近保存的解释，再按本场原文范围取用；拍摄解释不与划分版本单独绑定。

实施时移除旧的逐场入口、写入逻辑及当前场次上的说明数据，不迁移旧说明，章节拍摄解释从空开始。历史划分快照不批量改写，恢复时忽略其中的旧说明字段；已提交任务及已有画布保留当时的生成依据。
