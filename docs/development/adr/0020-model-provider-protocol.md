# 模型供应商协议与能力声明

以独立于业务和 LangChain 的供应商协议统一模型目录、能力查询和调用。画布、实验室、剧本处理和 Agent 共用适配器。显式选择 OpenAI Responses API 的配置目前仍使用 LangChain 兼容客户端。

## 接入与配置

供应商适配器负责鉴权、请求编码、响应和流事件解析、远端任务状态映射。自定义供应商或网关按操作判断兼容性：兼容操作复用已有适配器，新协议由代码提供适配实现。例如，用户可在产品页选择 OpenAI 接入方式并配置第三方 Base URL 来调用兼容的文本模型。图片和视频须各自满足相应操作的协议。

模型绑定具体的[供应商配置](../../../GLOSSARY.md)。管理员按这份配置下的模型和操作声明能力，即使模型 ID 相同，两个接入地址也可有不同声明。修改 Base URL 视为知情变更：保存后新调用使用新地址，沿用绑定和手动声明，不检查历史数据、不提示风险、不要求复核，也不自动探测或阻断调用。真实能力验证由用户主动发起。

## 能力查询与声明

模型管理页展示适配器已实现的操作及相关字段。管理员可补充未知项、收窄范围或覆盖内置模型默认值，有效能力以适配器实际能够发送、接收和解析的范围为上限。界面分别展示声明值、来源和有效值。布尔能力区分支持、不支持、未知，数值留空表示未知。手动添加的模型可直接按 ID 查询，普通文本调用保留既有兼容行为，依赖工具等能力的自动流程按有效能力选模。

| 操作 | 可声明的能力 |
| --- | --- |
| 文本与多模态理解 | 分别声明输入、输出模态，非流式和原生流式响应，最大输入、输出 token 数。 |
| 工具与结构化输出 | 工具调用及结果回传、流式工具参数、并行工具调用；JSON 对象输出与 JSON Schema 结构化输出分别声明。 |
| 图片生成与编辑 | 文生图、参考图生成、编辑，各模式的尺寸、分辨率、宽高比、出图数、参考图数，以及 seed、水印等选项。 |
| 视频生成 | 按文生视频、首帧、首尾帧、关键帧、主体参考等模式声明时长、分辨率、宽高比及其组合；可限制参考素材的类型和数量，分别声明音频参考、原生音轨和音轨开关。 |
| 交付与取消 | 按操作从适配器已支持的直接返回、远端任务、原生流式和远端取消中选择。 |

参数规则支持含端点的区间及离散值，并保留条件间的关系。例如，某视频模式在 720p 下允许 5～15 秒，在 1080p 下仅允许 5 秒或 10 秒，8 秒只对前者有效。页面展示、请求预检和实际提交共用同一组规则。

## 调用与职责

- `list_models` 通过远端目录或内置目录返回模型及来源。`describe_model` 按模型列出各操作的有效能力与约束，查询不触发试生成。`validate` 对具体请求返回参数及组合诊断。
- 公共 I/O 接口统一使用 Python 异步调用。`await invoke(...)` 可直接返回完整结果，也可返回远端任务引用；后者只表示已受理。调用方决定是否等待。`stream` 提供异步迭代的原生事件，保留文本增量、并行工具调用身份、参数分块、结束及错误语义。
- `poll` 单次查询已有任务。`cancel` 按操作能力提供，区分取消请求已受理与远端已确认取消。关闭流或结束本地等待仅代表本地消费结束，远端终态以回执或查询为准。
- Worker 冻结执行配置、保存远端任务引用、安排轮询和结果归档。若提交后连接中断且受理结果未知，保留该状态，避免自动重复创建任务。供应商适配器复用注入的 HTTP 客户端，业务层负责审批、工具执行和结果采用。
- LangChain 集成层提供 `LangChainChatModelAdapter`，向现有 Agent 提供 `BaseChatModel`，把消息、工具定义、调用 ID、工具结果和流分块映射到公共协议。同步调用方在调用侧处理等待。迁移期间原模型工厂可供已有 Agent 过渡使用，待同步、异步、结构化输出与流式工具回归通过后移除旁路。

## 迁移验收

复用已有文本客户端、媒体输入契约、供应商请求构造及状态解析函数。迁移每个操作时收敛重复的 HTTP 实现，把模型能力判断从画布移到供应商层，并使用显式注册项解析供应商。未知供应商须返回配置错误，未知模型的能力保留未知或标明默认值来源。

1. 文本模型流式返回工具调用，适配器能按 ID 拼接并行参数。Agent 执行工具后，供应商收到对应结果并完成下一轮响应。
2. 同步图片调用直接交付全部产物，数量与顺序正确；参考图编辑及 URL、Base64 两类既有返回方式均可用。
3. 异步视频提交只创建一次远端任务。Worker 重启后使用原任务引用继续查询并归档结果。提交或查询中的网络错误不会导致重新创建已受理的任务。
