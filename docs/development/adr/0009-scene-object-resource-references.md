# 场次对象身份引用与生产用图分离

2026-11-16 确认并实现，本次实际存量转换已按确认计划完成。由场次对象派生的画布参考绑定提取对象身份，再解析该对象当前选用的项目资源；资源主图或指定角度默认图在实际图片／视频生成提交时解析，只有该次生产实际使用的文件进入固定任务输入。场次准备和分镜文字规划不固定整套资源图片。

选择这种关系，是为了让同一个故事对象在清空、重新选用或资源图片更新后，相关画布的后续生产自然使用当前选择，无须逐张更新画布；直接绑定项目资源不能跟随场次清空，提前固定图片则需要反复维护引用。代价是画布保存不再固定动态对象参考的实际用图，预览与生产提交均需核验当前资源，资源缺失或缺图时必须明确诊断。

提取对象与资源的名称、身份分别维护。清空只解除提取对象的资源选用；删除资源只使动态引用失效，不删除提取对象或画布参考卡。已受理任务、历史输入及用户明确采用的固定图片继续独立，并保留相应文件保护。正常固定图片引用仍是产品能力，不为旧场次单图格式新增兼容分支；冲突数据按精确清单处理。

本决定补充[共同画布基础](0005-shared-canvas-foundation.md)的场次参考来源边界，沿用[独立项目导入](0008-image-source-resources-and-project-imports.md)的资源归属规则。交互、转换边界和验收要求见[对象参考卡片与资源选用设计](../design/scene-object-resource-selection.md)；当前实现仍以[场次工作台架构](../architecture/directing-foundation.md)为准。
