# 项目角色身份与共享资产复用

2026-11-13：整体方案、领域边界及默认选图规则已完成最终确认；工作台直接选用、角色组合和演员图参考已在本地实现，当前机制见[资产图片管理架构](../architecture/asset-image-management.md)。本地验证不代表已经部署。术语见[术语表](../../../GLOSSARY.md)，当前图片管理见[资产图片管理架构](../architecture/asset-image-management.md)。

工作台对象准备允许直接选择资产库的场所、道具和演员，确认选用时补齐项目资产关联；项目资源仍由共享资产的项目关联和直接归属项目的角色组成，保留手动关联入口。更换或解除本场对象绑定不自动移除项目关联，因为其他场次仍可能使用该资产。

后续边界调整：[ADR 0007](0007-project-resource-ownership-and-library-copies.md) 已确认将项目专属对象扩展到演员、场所、道具和服装，并通过独立副本入库。该调整尚未实现；本文以上保留原决策及当前机制的历史语义，共享资产的项目关联仍不构成副本。

人物对象选用演员后仍通过项目角色表达故事身份，允许使用演员图片作为参考，不复制图片来伪造角色图；需要组合形象时使用角色所选演员、服装和道具生成角色图。已有角色由用户明确选择，不按同名或相同演员自动合并。选择保留项目角色这一层，而非让人物对象直接绑定演员，是为了使跨场次人物身份不随参考图片来源改变，并保持同一演员扮演不同角色的能力。

本次沿用项目角色的一套共享演员、服装和道具组合，不新增独立角色造型层。组合中的资产可直接从资产库选择，明确保存组合时纳入项目；随后生成失败不撤销已保存的角色和关联。共享组合修改影响同角色后续读取与生成，不能承诺同时维护多套可独立编辑的服装组合；仅更换本场参考图不修改角色组合。

新生成的角色图须经明确选用才替换当前对象参考，已有场次及画布所选参考保持原选择。工作台对象准备与画布内的默认／镜头参考设置分别管理；本次不改变画布内部从图片内容卡选图的入口，也保留对象参考的直接上传能力。

默认选图只在用户选用演员或明确切换角度时应用，选定后保留具体图片，不持续追随资产图片变化。这使直接使用演员图不需要复制图片，也避免刷新或后来生成的结果改变已选参考。首次选用优先已有正面图，无正面图时使用其他可用图片并显示真实角度，完全无图时留空；主动切换到缺图角度时留空提示，其他角度由用户手动选用。同角度有多张图片时，默认与资产详情当前展示一致，其余允许手选，不新增精度优先级配置。手选保持到明确切换演员或角度，切回原角度重新使用默认规则，不额外保存各角度的手选记忆。
