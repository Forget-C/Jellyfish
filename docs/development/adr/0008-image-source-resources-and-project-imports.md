# 图片来源资源与独立项目导入

2026-11-15：为让已有图片直接进入创作流程，资产库支持填写设定或上传图片，项目资源支持填写设定或从资产库导入；项目入库继续创建独立共享副本。上传、导入及新入库对象只有名称与图片，名称可改，其他基础字段展示为空且禁止编辑；图片生成、局部修改、主图及视角默认图正常开放。来源显式记录，不从字段空值推断权限。项目角色从演员导入，角色入库转为演员。

本决策替代 [ADR 0007](0007-project-resource-ownership-and-library-copies.md) 中新操作的共享关联和角色转化整体只读规则。采用独立图片副本而非持续共享编辑，使项目后续生图不会改变库中来源；代价是复制存储及两边不再同步。后续确认：旧共享关联不再继续兼容，改为显式维护转换为独立项目副本，保留资料及有效引用，并按审批清理相关历史；不在普通读取或导入时隐式迁移。角色来源演员的详情与图片权限分离，首次保存确认后开放详情。维护过程见[旧共享关联退出](../guides/retire-shared-assets.md)。普通设定创建及场次快捷创建保留原行为。

上传逐图选择视角，按列表顺序确定首张主图和各视角默认图。导入与入库复制全部有效成员、角度与默认选择，不复制基础设定、长期参考、任务或候选。独立文件身份确保来源修改或删除不影响副本。每个项目对象保留一份入库副本，删除后才可重新入库；主动再次导入可用不同名称创建另一个项目副本。

选择生成参考与主动导入分开：保存长期参考、预览和提交生成均不隐式关联或导入项目资源。图片来源对象默认以主图为明确参考，同一会话内保留用户选择；没有主体参考时不能生成。风格、模型及要求属于临时生成配置，不回写基础字段。已提交任务冻结实际文件和参数。

创建方式选择采用按钮旁的无遮罩 Popover；点击卡片进入共用新建抽屉，实际提交前不创建对象。抽屉沿用失败恢复和草稿保护。当前机制见[资产图片管理](../architecture/asset-image-management.md)。
