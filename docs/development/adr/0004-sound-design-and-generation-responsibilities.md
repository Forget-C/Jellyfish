# 声音设计与生成职责

2026-11-07 确认声音设计和生成的职责划分。声音卡保留创作设计，具体生成由生成卡配置；声音能力由模型端声明，生成界面据此开放配置并提示不支持的要求，不由设计卡宣称模型能力或生成完成。

## 设计职责与字段

保留现有对白卡和声音安排卡。

| 对象 | 保留职责 | 本次字段补充 |
| --- | --- | --- |
| 对白卡 | 说话对象与对白正文 | 可选的语言／发音要求、声画关系说明 |
| 声音安排卡 | 声源说明、环境声、动作声、音乐约束 | 可选的声音层次／主次关系 |
| 人物表演卡 | 语气、气息、情绪、表达节奏及身体反应 | 不在对白卡重复维护 |

声音出现时机优先复用已有适用条件，具体起止及变化在相应声音字段表达。本轮不扩展精确混音或声音时间线控制。

## 生成与能力

声音设计表达希望实现的内容；实际声音生成配置属于生成卡，不恢复声音安排卡已退役的整卡 `production` 字段。制作意图、接口能力与实际声音结果分别表达，留待后期的意图不代表系统能够强制输出静音。

本记录确认生成配置的职责归属，不预设统一的“同步生成／后期制作／待定”制作方式枚举，也未确认按对白、环境声、动作声、音乐分别分派制作方式；这些不能由此前讨论中的候选方案推定为已接受功能。

原生声音输出、声音开关、音频参考输入等能力由模型端声明。模型不支持时给出提示，不因对白写入提示词、本地音频可试听或视频文件包含音轨就宣称相应能力已经可用。声明尚未提供或核实的能力不猜测为支持或不支持；当前接入是否提供对应执行途径需要如实表达。

对白逐字正确、口型匹配及声音效果等属于实际结果核验，不是仅凭接口支持声音就能保证的结果。

## 范围与取舍

本轮完善现有声音卡的设计表达、制作安排的职责归属及能力提示，不新增独立配音生成、混音、音轨替换或口型同步流程。相较于把设计与执行安排同时保存在声音卡，分离职责允许同一设计供不同生成目标采用，并避免设计标签被误认为实际可执行参数或已完成结果。

本轮先完成设计字段、模型端能力声明与提示，不扩展尚未接入的供应商声音参数或音频输入执行接口。模型声明支持但当前未接通的能力标明未接入，不开放无法执行的控件。

首版检查仅核对声音设计的文字落实与接口能力匹配，不加入实际听音、转写或声画同步审核；实际音轨内容标为未核验。
