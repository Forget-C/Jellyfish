# 退役旧场次版本 HTTP 接口

旧四画布前端已退役，现行分镜画布使用独立的画布身份和保存接口。已确认将项目 directing 路由中 `/sequences/{sequence_id}/versions` 及其子路径的 46 个 HTTP 操作全部移除，并同步更新 OpenAPI 和生成客户端。更早的生产计划接口另案评估。

切换后，旧客户端将失去通过这些地址编辑、查询历史、访问素材与导出记录、核实已提交请求或重试的能力。接受这一契约变更，无兼容端点或重定向。切换前核对可取得的访问记录及已知外部集成，发现实际调用时单独决定对应操作的移除时间。

切换时直接移除旧接口和仅供旧场次版本任务使用的执行逻辑，无需等待排队中或执行中的旧任务结束。这些任务可能无法完成。现行分镜画布和其他任务仍使用的共享执行逻辑继续保留。

保留历史任务记录、已生成的导出成品及其 `scene-export:<task.id>` 文件引用。旧导出的专用删除接口随本次退役移除。由于通用文件管理无法解除这类引用，用户将无法从文件管理中删除仍受引用保护的历史成品。

本工作树已移除旧场次版本 HTTP 接口，并同步 OpenAPI 和生成客户端。当前仓库状态见[场次工作台架构](../architecture/directing-foundation.md#旧四画布退役范围)。

## 退役历史交付查询

旧场次版本的交付提交接口退役后，章节当前交付与场次交付历史只剩独立查询接口。现行前端业务无调用，已移除 `GET /chapters/{chapter_id}/deliveries` 和 `GET /sequences/{sequence_id}/deliveries`（相对于项目的 directing 路径），并同步 OpenAPI 和生成客户端。两条查询是上述 46 个操作之外的新增退役范围。历史交付记录、章节使用指向及 `scene-delivery:<id>` 文件引用继续保留。

## 退役旧四画布投影和旧任务执行

已实施。移除旧场次版本的导演、单元、指令和剪辑图投影、聚合关系图、预览及专属编辑逻辑。现行分镜画布和仍注册的生产计划接口继续沿用各自的实现。历史记录校验、资产引用迁移、Alembic 依赖及现有文件引用保护继续保留。

移除旧场次版本专属的整场设计、单元组织、指令生成和指令检查执行逻辑，并禁止提交退役任务。保留 Worker 对存量旧任务的终止路径。排队旧任务仍可被领取并终止，已有供应商任务 ID 的旧视频在发送供应商查询前结束，保留原任务和远端 ID。仍由生产计划接口提交的 `directing_design` 继续执行，旧场次版本任务按快照中的 `scene_design` 标记识别。

保留项目级 `GET /directing/tasks/{task_id}` 中 `scene_design`、`scene_instruction`、`instruction_check` 的类型化历史结果，以及通用任务历史、已生成文件和文件引用保护。验收同时验证存量旧任务在调用供应商前终止，以及已完成旧任务的结果仍可读取。
