# 原文异常修复与补充解释的边界

2026-11-17，完整方案已最终确认并在本地实现。原文一致性检查先确认表达性质，再分别处理原文异常与补充解释。正常称呼、刻意留白以及人物出画但仍在场内，不因下游模型可能误解而直接构成原文异常。

原文异常修复只修改用户确认的错误；原文补充解释与正文分别保存，用于澄清文本特有的身份、叙事层次或有意保留的不确定性。用户也可确认正常且无需处理，或暂不确定。解释不擅自新增剧情、指定拍摄方案或覆盖正文冲突，不伪装成原文摘录。概念定义见[术语表](../../../GLOSSARY.md)。

## 取舍

不把所有解释改写进正文，以免破坏正常对白、文学表达与留白；也不只把解释留在检查报告或最终分镜提示中，因为身份和叙事误解可能先影响划场和对象提取。采用章节独立的结构化解释集合，保存条目身份、片段或全章范围、原文依据、解释内容及确认状态；首版无需为此建立独立业务表。

已确认且有效的解释进入一致性检查、智能划场、对象提取和分镜生成。后续任务固定实际采用的解释，独立标注解释来源；解释提供的理解不冒充逐字原文事实。正文版本与解释版本分别表达，解释变化不能触发原文范围重新定位。

这种选择增加了依据传递和有效性管理的成本，但能避免“解释已保存却未被使用”和“修改当前解释后悄悄改变历史方案”。已有成果在解释依据变化后提示变化，不自动重新划场、重新生成或覆盖历史画布；采用新依据由用户明确发起。

## 有效性与采用

检查覆盖当前编辑的完整章节，包括未保存修改，不默认引入其他章节或资产设定。检查结论绑定正文及解释依据；依据变化后旧检查结果不可继续用于自动改写。旧角色混淆检查记录保留原范围，不冒充完整一致性检查。

解释可直接新增、编辑和删除，不必等待 AI 检出问题；AI 解释建议经用户核对才采用。正文和解释分开展示，随章节一起保存。正文变化后已有解释保留并统一标记待复核，支持逐条或查看后批量确认；未复核解释不进入新任务，明确提示未采用项，但不因此禁止保存或继续生成。

异常修复按用户选中的问题和明确意图生成合并修改稿，保留未涉及问题的正文，预览差异后整批应用到编辑器，保存后才持久化。存在多种解释的问题先由用户选择有依据的候选或填写处理意见，不可靠的候选不凑数；未解决项可以跳过。检查结果区分明确矛盾、待确认歧义和可选补充，不作为生成放行门槛。

## 范围

后续章节调整：完整方案已最终确认并在本地实现。章节检查限定于文字表达，增加病句和语义表达检查，补充解释只澄清原意；不因缺少具体站位、路线、机位或遮挡安排而报告原文问题。以下为本轮已确认范围；分镜拍摄设计检查另行确认。

- 语言表达检查覆盖错别字、影响理解的标点错误、语法搭配、成分缺失、语序和语义不通。有意的口语、方言、省略、重复和文学表达结合上下文判断；仅使表达更优美或简洁的一般润色不作为异常，不默认改变文风。
- 补充解释先依据本章上下文和已有解释。能够明确理解的内容不报问题；存在影响理解的多种解释时，给出有依据的候选或提出问题。不能从正文得出的身份、背景和意图由用户补充确认，AI 不编造；允许确认有意不说明并保留不确定性。
- 收紧边界时，旧检查结果保留查看，新修复须重新检查；已有解释保留内容，统一标记需要按新边界复核，支持查看后批量确认，复核前不进入新任务。历史任务和画布保留当时依据，不回写历史。
- 用户主动发起章节检查时，同时核对正文表达与补充解释适用性：解释是否与正文冲突、是否编造未经确认的背景、是否混入为拍摄新增的安排。结果明确定位到正文或具体解释，分别处理；空间描述本身不是越界证据，应区分澄清原意与选择拍摄实现。保存和编辑不自动调用 AI；AI 疑点不自动删改或作废已确认解释，用户确认越界后退出采用并保留内容待调整。不自动搬到分镜，也不判断拍摄方案是否合理。

本轮验收以边界场景为主：能发现病句及影响理解的文字错误，保留有意口语与留白；上下文已明确的代称不重复报错；下车打招呼但未交代绕车路线、停位或遮挡，不作为章节问题；解释里的原意澄清与新增拍摄安排能分别定位供用户确认；旧规则结果不能用于新修复，未按新边界复核的解释不进入新任务，历史固定依据保持原状。已有预览后应用、正文范围保护、解释独立保存及并发校验继续沿用。

本决定仅覆盖原文一致性检查、异常修复、补充解释及其必要下游依据接入。分镜非法字段约束、错误提示与自动纠错修复继续暂停；通用分镜空间与状态连续性修复不纳入本次。本文记录已采用的决策，当前机制见代码及[章节划分架构](../architecture/chapter-division.md)、[场次工作台架构](../architecture/directing-foundation.md)为准。
